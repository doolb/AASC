# 独立任务代码同步验证

## 已有声明

- 引用 Node test runner、Offline 构建发布测试夹具和 Android JVM 测试 // 使用现有工程工具

## 新增定义

- Fixture { code, dependencies, taskCode, dataDirectory, sourceDirectory, signature } // 所有验证使用隔离目录与虚构数据

## 操作流程

- 验证独立六文件快照、摘要、白名单和链接/越界拒绝 // 防止发布用户数据
- 验证服务版本区间/API 交集、依赖锁指纹、约束冲突与仅改约束的新身份 // 安装前判断真实兼容
- 验证仅任务构建/发布/镜像，记录其他引用与请求不变 // 防止偷偷下载大服务包
- 验证代码入口、元数据、HTTP 与重发来源一致，受管操作失败前实例不变 // 防止代码混用
- 验证代码目录与工作目录分离、文件移除无旧回退、数据摘要保持 // 保证历史和输入不被更新覆盖
- 验证原生任务单独更新、联合更新、首装、旧指针和完整回滚 // 不允许半组合或假健康
- 验证显示端重复恢复释放资源，精确清理保留活动/候选/回滚 // 防止重复轮询和误清理

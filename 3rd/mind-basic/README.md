# MindAR Basic 独立测试页

## 2026-09-30 相机预测与固定世界锚点（当前实现）

IMU 的旋转和平移预测，以及 MindAR 视觉纠偏，最终都写入 `mindBasicCameraRig` 的位置和四元数。角色与参考图片共用 `mindBasicImuStage` 固定世界锚点；首次定位时确定尺度，后续预测、重获和纠偏不再更新锚点的位置、旋转或尺度。角色原有的局部示例动画继续播放，与定位预测无关。

`mindBasicTargetAnchor` 仅提供 MindAR 原始矩阵测量，不挂可渲染内容。融合核心仍用“目标相对相机”的测量坐标做积分和纠偏，输出时取逆得到真正的世界相机姿态：相机方向为目标方向的逆，相机位置为逆方向旋转后的负目标位置。目标像素尺度转换为首次定位的固定世界尺度，相机本身不缩放，保留 MindAR 原投影的 near/far 单位。参考图也移到固定锚点，避免相机移动时再叠加跟踪锚点的变换。

图片可见/不可见两个开关均控制相机旋转和平移；预测不可用时冻结相机并保留已定位模型。重校准和开关切换不改固定锚点；停止定位或切换图片时隐藏锚点、清除尺度并重置相机。关闭相机 look-controls/wasd-controls，避免额外控制叠加。

版本 `20260930-camera-world-5`，静态语法与定向差异空白检查通过，本次未运行测试、未发布外网。现有浏览器用例已将运动断言改为相机位置/旋转；相机坐标、参考图对齐、手机旋转/平移精度和实际帧率待验证。以下旧版“模型父节点跟随融合姿态”的说明属于历史实现，以本节为准。

## 2026-09-30 两个场景预测开关（当前界面）

用户要求将三个预测选项合成两个：“图片可见时预测相机运动”和“图片不可见时预测相机运动”，默认均勾选；每个同时控制陀螺仪旋转预测和加速度平移预测。IMU 主按钮仍负责权限、校准与总体启停。

图片有最近 500 ms 内的新有效观测时使用可见开关：开启时 IMU 预测、视觉平滑纠偏，关闭时直接跟随视觉。图片不可见或观测过期时使用不可见开关：开启时继续旋转与受限平移预测，关闭时冻结最后显示姿态。进入关闭场景时先把累计位移吸收进当前姿态，再清零速度与位移增量；采样和滤波继续，重新开启不补积分停用期间的运动。切换这两个开关不会隐藏模型或清空已定位姿态。

平移仍受最长预测窗口/位移限幅约束；超限后停止平移，陀螺仪可继续旋转。目标实物宽度仍必填，状态判断使用有效视觉更新而非仅等待 targetLost。内部核心保留 translationEnabled 配置供算法独立调用；页面恒为 true，无独立平移开关。切换实物图宽或坐标系仍重置锚定。

本版尚未发布外网；手机上的场景切换连续性与旋转/平移精度待验收。以下历史三开关说明以本节为准。


## 2026-09-30 死区翻倍与快速移动失锁衔接

按用户要求，将计算出的陀螺仪迟滞死区整体乘以 2：低门限为 2×max(0.03,min(0.25,3σ)) °/s，范围 0.06–0.50 °/s；开启门限仍为其 1.8 倍。此处调整的是计算出的陀螺仪死区，线性加速度固定死区仍为 0.16 m/s²。低速转动可能更容易被抑制，需要真机比较。

MindAR 首个原始跟踪失败帧即进入 IMU 失锁补偿，不再只跳过旧矩阵并等待 targetLost/视觉超时。保留最后显示姿态及原平移窗口；反复失败不重置失锁时间。每个失败帧清空重获确认计数，恢复后连续三帧稳定观测才平滑纠偏，避免断续成功被当作连续稳定。原始检测器、missTolerance/warmupTolerance 和 One Euro 参数未变。

快速横移或转动造成的模糊、图案离开视野等仍可能使视觉定位丢失；此次处理的是接管和重获衔接，并不保证视觉不中断。模型仍受实际视锥裁剪。尚未发布外网，现场效果待确认。


## 2026-09-30 旋转与平移抗漂移

静止校准改为至少 1.2 秒、24 样本且无大于 120 ms 的间断，同时估计设备坐标的陀螺仪/去重力加速度均值与噪声。有新鲜视觉时，视觉运动会清空校准样本。8 秒未完成只显示提示并继续等待，不自动切换到未校准积分。

陀螺仪先扣零偏，再使用噪声相关迟滞死区：低门限 max(0.03, min(0.25, 3σ)) °/s，高门限为其 1.8 倍。低速采用 20 ms 时间常数滤波，≥3 °/s 直接响应。线性加速度扣偏置，低速轻量滤波，≥0.3 m/s² 直接响应，沿用原 0.16 m/s² 积分死区。断流清除滤波记忆，不跨异常间隔积分。

只有原始视觉在固定基准附近持续 600 ms（位置变化≤3 mm、角度≤0.25°、最后视觉≤200 ms），并且校正后角速度<0.3 °/s、加速度<0.12 m/s² 同时持续 600 ms，才判定静止、速度置零，并按 15 秒时间常数缓慢更新两类零偏。没有视觉时不做静止归零/在线学习；失锁立即撤销静止判定，避免把匀速移动学成偏置。保留之前积分的位置，不清零位置造成跳变。

面板显示原始与校正后角速度/加速度及静止状态。使用同一 performance.now 时间基准，仍没有相机曝光/IMU 硬件同步。死区可能抑制极慢转动，微小匀速运动也存在静止误判边界，参数尚需真机标定。本版未发布。


## 2026-09-30 MindAR 可信度观测

新增“MindAR 可信度（估算）”面板，显示 0–100 质量分、有效点数/总数、有效点比例、特征分布面积、重投影 RMSE（输入视频像素）与样本状态。这是基于已有跟踪点对的启发式质量评分，不是 MindAR 官方置信概率，也不是相机位姿真实误差。

`mind-basic-quality.js` 在 arReady 后包装当前实例的 tracker.track 与 Controller._trackAndUpdate；保留原调用上下文、参数、返回的原矩阵及原异常，复用点对统计，不触发额外检测，不开启 debugMode 或 GPU 图像回读。停止时恢复原方法并忽略未完成回调。依赖固定的 MindAR 1.2.5 内部接口，接口变化时显示不可用。

分数综合有效点数（12 点达到该项上限）、有效点比例、点包围框相对目标面积（25% 达到该项上限）和按视频最长边归一到 640 像素的重投影误差（衰减尺度 3 像素）。常数尚未通过真机标定；当前只作诊断，不参与融合增益或接纳判定。数据超过 500 ms、目标丢失或停止后清除分数，IMU 关闭时仍显示质量指标，DOM 更新最多每 100 ms 一次。

官方库源码及原始矩阵未更改。应用层仍分解官方矩阵，将 IMU 预测与视觉平滑纠偏融合，拒绝孤立突跳、要求失锁重获稳定三帧，并忽略失败容忍期间的旧矩阵；因此最终显示位姿会与官方瞬时输出不同。当前新增的是运行时只读观测包装。


## 2026-09-29 IMU 与 MindAR 同时定位实验（当前实现）

IMU 高频预测旋转及可选平移，MindAR 首次建立定位图坐标参考，之后持续平滑纠偏。页面默认勾选平移预测，仍须用户点击启用 IMU 并授权；定位图真实宽度必须填写，20 cm 只是示例。实现继续使用相机坐标下目标的逆运动，与固定目标、移动虚拟相机等价；不会改动真实视频或模型局部动画。

跟踪期间也积分去重力加速度。视觉方向校正时间默认 800 ms，位置校正时间 250 ms；每次接受视觉后吸收位移增量，并将速度转入新的积分坐标系，避免每帧清零速度。MindAR 的失败容忍窗口可能重复旧矩阵，isTracking=false 时不接纳为新视觉。未接收可靠视觉超过 500 ms 进入失锁；重获要求连续三帧姿态相近，再平滑纠偏，未提供或宣称官方 confidence。

失锁平移窗口默认 1800 ms（200–3000 ms），从最后接受视觉起计时；速度上限 1.2 m/s，位移上限 0.25 m。超时或达上限停止平移，陀螺仪仍新鲜时继续旋转。传感器过期时冻结已显示姿态或接受有效视觉纠偏，不跨断流积分；关闭 IMU/失锁补偿保留已显示模型，停止/切换清除。

算法及浏览器回归 22/22 通过。浏览器事件测试覆盖连续平移、失效旧矩阵过滤、冻结/重获、停止清除和拍照裁剪流程；传感器和图像识别使用模拟数据，不代表真机定位精度通过。本版尚未发布，Android 坐标轴、漂移和跟手效果仍需现场测试。当前没有相机曝光与 IMU 硬件时间同步，也没有 SLAM 环境地图。


这是 MindAR 官方 `basic.html` 图片追踪示例的独立 HTTPS 副本，发布地址为 <https://c.aasc.us/mnt/mind-basic/>。页面使用 MindAR 1.2.5 与 A-Frame 1.5.0，保留官方卡片识别，也支持拍摄自定义图片：先拍摄完整画面，再显示默认四边各内缩 10% 的矩形选区；可拖动选区移动，也可拖动四角或边缘调整大小，始终保持矩形。自定义照片只存于当前浏览器，不上传。上方控制面板默认展开，可手动收起并重新展开。官方目标或自定义目标识别成功后，均显示 Softmind glTF 动画模型。

手机浏览器需支持 WebGL、摄像头并允许该 HTTPS 页面访问摄像头。定位运行时默认显示实时镜头背景；等待识别或丢失定位时不再覆盖扫描框，镜头画面继续显示。目标资源来自 MindAR 示例仓库固定的 `v1.2.2` 路径。Softmind 模型作者为 hiukim，采用 CC BY 4.0，页面保留可见署名。

首次使用自定义目标时点击“拍摄自定义定位图”并允许摄像头；拍摄后可在整帧照片上移动或缩放蓝色矩形选区，不另显示裁剪缩略图；确认选区或重拍，再保存并在目标列表中选择。MindAR 在开始定位时本地编译矩形裁剪图并显示进度；刷新页面后目标从该站点的 IndexedDB 恢复。清除浏览器站点数据会移除保存的自定义目标。此前保存的四角选区会兼容转换为轴对齐外接矩形。

控制面板的“IMU 姿态实验”默认关闭。点击“启用 IMU 辅助”并授予设备运动权限后，保持手机静止进行陀螺仪偏置校准。开启“IMU 主导旋转”后，传感器预测每帧用于模型显示；转动相机时同时补偿目标位置和朝向。MindAR 负责初始锚定、平移距离和慢速方向纠偏；大幅视觉突跳需要连续观测确认。短暂失锁后的重获渐进纠偏，超时后重新锚定。原始摄像头视频不做防抖。

“视觉纠正时间”默认 800 ms，可调 200–2000 ms；越大越依赖 IMU，也越慢消除漂移。“失锁保持时间”默认 1800 ms，可调 200–3000 ms。陀螺仪超过 250 ms 没有有效样本时回退到可用视觉结果；500 ms 没有可靠视觉更新时按短时失锁处理。保持超时、没有可用传感器或位移达上限时隐藏模型。切换横竖屏、进入/离开后台或更改位移模式后等待新视觉锚定。

“失锁位移积分”是独立实验，默认关闭，旋转保持无需线性加速度。若启用位移积分，请把“定位图实际宽度”改为实物宽度：默认 20 cm 仅为示例值。位移用米计算，再按图宽转换到 MindAR 场景单位；限速 1.2 m/s、限距 0.25 m。平移仍依赖视觉，纯 IMU 长期积分会漂移，不能当作完整六自由度定位。本次优化已完成本地算法与浏览器模拟回归，尚未同步外网；真实 Android 的轴向、视觉延迟和跟手观感待现场验收。

## 2026-09-29 黑底兼容处理与失锁模型保留（前版记录）

跟踪视频使用专属类设置层级，启动时明确设置 muted/playsInline 并调用 play；场景背景清空且 renderer.clearAlpha 为 0。本地 CSS/JS 带统一版本参数，避免新首页使用旧缓存。桌面 Chromium 真实 A-Frame/MindAR 与模拟视频诊断可见镜头画面，手机黑屏原因尚未复现。

失锁后短时 IMU 预测仍受原有时长、传感器新鲜度及位移上限约束；预测结束、关闭 IMU 或关闭失锁补偿后，保留最后渲染姿态。首次识别前不显示模型，停止、切换目标和坐标系重置会清除保留姿态；重新识别恢复更新。保留显示不等于持续可靠的空间定位，模型仍可能因相机视锥裁剪而不可见。

本次修改尚未发布，未运行自动化测试；Android 实际镜头背景、失锁和重获效果待确认。

# MindAR Basic 独立测试页

这是 MindAR 官方 `basic.html` 图片追踪示例的独立 HTTPS 副本，发布地址为 <https://c.aasc.us/mnt/mind-basic/>。页面使用 MindAR 1.2.5 与 A-Frame 1.5.0，保留官方卡片识别，也支持拍摄自定义图片：先拍摄完整画面，再显示默认四边各内缩 10% 的矩形选区；可拖动选区移动，也可拖动四角或边缘调整大小，始终保持矩形。自定义照片只存于当前浏览器，不上传。上方控制面板默认展开，可手动收起并重新展开。官方目标或自定义目标识别成功后，均显示 Softmind glTF 动画模型。

手机浏览器需支持 WebGL、摄像头并允许该 HTTPS 页面访问摄像头。目标资源来自 MindAR 示例仓库固定的 `v1.2.2` 路径。Softmind 模型作者为 hiukim，采用 CC BY 4.0，页面保留可见署名。

首次使用自定义目标时点击“拍摄自定义定位图”并允许摄像头；拍摄后可在整帧照片上移动或缩放蓝色矩形选区，不另显示裁剪缩略图；确认选区或重拍，再保存并在目标列表中选择。MindAR 在开始定位时本地编译矩形裁剪图并显示进度；刷新页面后目标从该站点的 IndexedDB 恢复。清除浏览器站点数据会移除保存的自定义目标。此前保存的四角选区会兼容转换为轴对齐外接矩形。

原始示例：<https://hiukim.github.io/mind-ar-js-doc/samples/basic.html>

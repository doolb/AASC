# 项目规则

- 使用 TypeScript 和 Node.js ESM。
- 使用 `const/let`，异步操作使用 `async/await`。
- 可能失败的外部操作使用 `try-catch`，错误信息包含设备、Flow 或文件路径。
- ADB 命令必须使用显式设备序列号。
- OpenCV 匹配器不直接执行点击。
- Flow ID 和图片文件名不能通过路径遍历逃逸。
- 默认使用 dry-run 验证真实设备。
- OCR 是图片节点的附加条件；OCR 请求失败必须 fail-closed，本轮不得点击。
- OCR 服务请求只发送当前截图，不执行服务器控制、设备切换或其他外部动作。
- OCR 显示器选择由 AASC OCR 服务调度，客户端不得通过文件名或 CLI 强制指定显示器。
- 一个文件只负责一个模块，单文件不超过 1000 行。
- 中文注释说明关键算法、坐标转换和安全边界。

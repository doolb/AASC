# 测试 ASR 普通识别固定中文

## 任务描述

测试 ASR APK 的普通非流式识别和网页声纹测试不再暴露语言选择，默认使用中文语言提示，避免中文唤醒词被自动语言识别为英文或日文。

## Design 需求

- 内置网页删除语言选择控件。
- 普通 ASR 和声纹分段 ASR 使用 `zh`。
- Android 原生识别使用 `zh`。
- 流式 ASR 继续使用固定中英双语 Zipformer，不受本次调整影响。
- HTTP 接口保留语言参数，兼容外部直接测试。

## Spec 设计

- 网页普通 ASR 请求固定追加 `language=zh`。
- 网页声纹测试请求固定追加 `language=zh`。
- Android 原生 `AsrCoordinator.submit` 固定传入 `AsrLanguageMode.ZH`。

## 受影响功能模块和代码

- `AsrWebPage.kt`：移除语言下拉框并固定网页请求语言。
- `MainActivity.kt`：固定原生普通识别语言。
- `AsrHttpServerTest.kt`、保存 WAV 静态测试：更新网页和原生语言契约。

## 自测用例

- 网页不包含语言选择控件。
- 网页普通 ASR 和声纹请求均使用 `zh`。
- Android 原生识别提交 `AsrLanguageMode.ZH`。
- 流式 ASR 页面和模型配置保持不变。

## 兼容性测试

- 普通中文、中文唤醒词和带英文单词的音频继续通过同一 SenseVoice 模型识别。
- 直接调用 HTTP 接口时仍可显式传入 `auto`、`zh` 或 `en`；`zh-en-filter` 已在后续任务中移除。
- 流式 WebSocket 继续使用中英双语 Zipformer。

## 性能测试

- 固定 `zh` 不增加额外语言探测逻辑。
- 语言切换次数减少，避免网页测试频繁重建普通 ASR recognizer。

## 风险评估

- 网页不再适合直接选择英文专用或自动语言模式；需要其他语言时使用 HTTP 接口。
- `zh` 是 SenseVoice 语言提示，不是绝对字符白名单，英文仍可能被识别出来。

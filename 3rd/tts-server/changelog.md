# 变更日志

## 2026-08-25

- 修复：`tts-wine.js` 将队列任务绑定到 `drain()` 已预留的 Wine worker，恢复 `/api/tts` 与 `/api/voices` 正常请求。
- 优化：参考 `tts.js` 增加 FIFO 队列的断连清理、排队超时、队列上限和状态字段。

## 2026-04-17

- 修复：`/api/tts` 在生成失败、参数校验失败时统一返回 JSON 错误结构，便于调用方识别失败原因。

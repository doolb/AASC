# doubao2api source attribution

The AASC `doubao.web` task adapts the browser fetch, media payload, and file
upload flow of [SeiShonagon520/doubao2api](https://github.com/SeiShonagon520/doubao2api)
at commit `d575d5817d8029a17a04854eb2595b4523daa0a6` into JavaScript and
Android Kotlin. The source project is licensed under Apache License 2.0. Its
license text is included in `LICENSE.doubao2api.txt` in this directory.

AASC changed the account lifecycle, request bridge, API integration, error
handling, and Android runtime. No automatic CAPTCHA solving, conversation
deletion, or account switching is included.

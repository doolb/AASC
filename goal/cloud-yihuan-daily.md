请阅读 `/mnt/AASC/AGENTS.md` 和本文件，通过 ADB 操作已连接的安卓手机，完成云异环每日主流程：进入游戏后，打开右上角面板，到都市大亨的一咖舍选择 **24 小时补货**、提取收益；返回面板第二页，打开探索指南，选择左侧第二项，领取下方奖励，再点击上方礼物图片领取当前可领的每日奖励；之后领取邮件附件，并检查活动中明显可领的免费每日赠礼。一般完成这条主流程即可，不为活动逐页深入、不额外做挑战或消费来凑满活跃度。云异环可能排队，手机也可能息屏，请按本文处理，逐步截图核验。**结束后必须用 ADB 强制停止云异环进程，并验证关闭。** 完成后逐项汇报，包括未达标的奖励档位。已有任务完成则跳过，不能把点击成功当成领取成功。本任务默认直接使用 ADB 实机操作；如果需要新增或修改程序，先按项目规则说明代码方案并等待确认。

## 每次开始及进入游戏

1. 检查 ADB 连接、屏幕是否亮起、当前前台应用和截图。已在游戏内则从当前界面接续，避免重启或退出已有云会话。
2. 息屏时使用唤醒键，例如 `adb -s <设备> shell input keyevent KEYCODE_WAKEUP`；避免使用会切换亮灭状态的电源键。亮屏后重新截图，确认是否锁屏。
3. 如果需要密码、验证码或设备解锁，请用户在手机上处理；不保存认证信息。人工完成后重新观察并继续。
4. 需要启动应用时先核对已安装包和实际启动入口。云客户端首页点击“开始游戏”；资源校验、云会话建立和游戏加载过程中等待页面变化。
5. 游戏标题页显示“进入游戏”后点击，等待角色、小地图、队伍头像、生命值及操作 HUD 出现。仅有云客户端首页、排队、标题页或加载画面均不算进入角色场景。

## 云排队、息屏与中断

- 云异环可能排队；保留当前队列，读取队列提示和预计等待时间，定期截图检查。不要反复点击开始游戏、退出或重启，以免丢失排队位置。
- 建议每 20～30 秒检查一次等待状态，长时间等待时向用户报告进展；若页面提供更长预计时间，按现场情况继续等待。队列不动、网络失败或时长不足时报告实际情况，不宣称任务完成。
- 等待期间手机可能自动息屏。先检查并唤醒，再截图确认仍在队列、加载界面或游戏内；不要为了防息屏不断点击游戏区域。
- 默认不永久更改系统息屏设置。若另行获准临时修改，先记录原值，结束后恢复。
- ADB 断开时先恢复原设备连接，再读取现场；游戏流中断时确认是否可恢复原会话，不重新盲点整套流程。
- 恢复后从首个未核验完成的步骤继续。对“刚点过但不知道是否到账”的奖励先检查状态，不重复扣费或补货。

## 每日操作顺序

### 1. 都市大亨 → 一咖舍

1. 在角色场景点击**最右上角的游戏按钮**展开手机面板；如果已展开则直接接续。区分游戏菜单与云客户端悬浮设置。
2. 找到“都市”入口；上次面板观察到的名称为“都市大亨”，以当前界面为准。
3. 打开用户指定的**一咖舍**，核对店铺名称后再操作。
4. 点击**补货**进入“原料库存”，选择底部 **24 小时**，先核对选中高亮，再点击右下方“补货”。不要使用初始默认的 4 小时，也不改成 72 小时。
5. 原料不足时会出现“库存提示”，列出咖啡豆、椰子和可可粉缺口。可用**送货上门**补齐普通原料；核对弹窗仅花费普通游戏货币“方斯”后确认。2026-11-23 的 24 小时补货实际花费为 1,104 方斯，配送费 0；金额随库存变化，不硬编码。本授权包含日常补货需要的普通方斯支出，充值、付费货币、扩建和升级仍需另行确认。
6. 确认后应出现**补货成功**，店铺库存变为**充足**。送货确认可能直接完成补货，不要再重复采购。
7. 点击**提取收益**，阅读“营收报告”，点击“确定”，核对“获得物品”弹窗，再点击空白关闭。应看到累计营收归零、计时重置；正常营业后的新增小额收益无需反复领取。
8. 点击商铺右上角关闭，返回都市大亨；再关闭都市大亨，返回游戏手机面板。两个页面的关闭按钮位置不同，逐屏确认。

### 2. 面板第二页 → 探索指南 → 每日奖励

1. 在手机面板的图标区域向左滑动，切换到**第二页**，通过中间分页圆点及首行“探索指南、成就、教学、多人游戏”确认翻页成功。
2. 打开**探索指南**。
3. 选择**左边第二个栏目**（跑步人物图标），核对顶部“活跃度”、20/40/60/80/100 礼物档位和下方每日卡片，确认进入每日活跃页。
4. 点击任意已达成卡片下方粉色**领取**；本次一次点击就收取全部已完成卡片，卡片自动重排。务必重新观察，不连续点击原坐标。
5. 点击上方已点亮的**礼物图片**；本次一次点击就领取所有已解锁档位。确认“获得物品”，点击空白关闭，再核对对应档位变为粉色勾选。
6. 本次登录 +20、消费方斯 +20、店铺收取方斯 +30，共 **70 活跃度**，领到 20、40、60 档奖励，80、100 档未达标。一般主流程到此即可，如实报告当前活跃度，不为凑满分自动做额外战斗、赠礼或养成。
7. 关闭探索指南返回面板；本次返回后面板恢复到第一页，继续按现场判断下一步。

### 3. 邮件

1. 在外层游戏手机面板查找**邮件/信封**图标及可领取提示；上次观察到信封位于面板底部。
2. 有邮件时进入，点击左下方**领取全部**，核对“获得物品”。点击空白关闭后，已领附件应显示黄色勾选，单封邮件右下按钮可能改为“删除”；不要点击删除。
3. 区分未读邮件和未领取附件，红点本身不代表有奖励。没有可领取附件则记录“无可领附件”。
4. 领取后返回面板，不删除邮件。

### 4. 活动每日赠礼

1. 打开面板中的**活动**，优先查看明显的赠礼、签到及可领取红点；一般按每日主流程领取即可，无需逐页深入所有挑战、商店或养成入口。
2. 查找每日赠礼、每日登录、签到等可免费领取的奖励；名称以现场为准。
3. 本次已验证**环期赠礼**：第 5、6、7 天均可领，点击一个“可领取”后一次收取 3 天共 5 个红色骰子；重新截图确认七天全部显示“已领取”。**集市分福 → 活动任务**中，已达成的累计登录 3 天可领取 200 分福硬币；本次领取后进度为 200/300，未满足的消耗条件保持进行中。
4. 不购买礼包、开通卡、不使用付费补签或进入充值流程。条件不足的活动记录原因，不能把查看活动当成已领奖。
5. 已领取或当天无奖励则如实记录；查看活动不代表完成其挑战。一般主流程结束后执行下面的 ADB 关闭步骤。

### 5. 完成后用 ADB 关闭进程（必须）

1. 确认最后的领奖状态后，使用以下命令关闭指定云异环应用；不要只按 Home 键或仅返回桌面。

```sh
adb -s <设备> shell am force-stop --user 0 com.pwrd.cloud.yh.laohu
adb -s <设备> shell pidof com.pwrd.cloud.yh.laohu
adb -s <设备> shell ps -A
adb -s <设备> shell dumpsys package com.pwrd.cloud.yh.laohu
```

2. 确认 `pidof` 没有返回 PID、进程列表没有该包名或其子进程、包信息的 `User 0` 显示 `stopped=true`；前台应离开云异环。`pidof` 无 PID 时返回非零状态是预期，不代表关闭失败。
3. 间隔数秒再次检查。本次第一次关闭后进程曾再次出现，原因未确认；再次执行带 `--user 0` 的 force-stop 后，未发现进程且 `stopped=true`。若又出现，重新核对是否有人启动或其他组件拉起，不把回到桌面单独当作关闭成功。
4. 这里关闭的是手机上的云异环客户端进程；不把本地进程退出等同于已查询确认云平台服务器会话释放。结束后不重新打开游戏。

## 执行与验收要求

- 每次按“新截图 → 确认页面及按钮 → 单次动作 → 等待 → 新截图核验”执行，不连续盲点多步。原生节点可用于云客户端页面，游戏流通常需要看截图。
- 出现未知弹窗或与上述路径不符时先读取内容；无法确定再请用户澄清，不凭位置猜测。遇其他人在操作手机时先暂停输入，重新确认现场。
- 每次执行重新检查当天状态，不沿用上次完成结论；奖励已领时跳过，待确认时保留未完成。
- 输出逐项结果，并区分“已完成”“已领取/无需重复”“无可领取”“条件不足”“中断未确认”。任务完成需有实际状态证据。

| 检查项 | 完成判据 |
| --- | --- |
| 进入游戏 | 角色场景及游戏 HUD 已出现 |
| 一咖舍补货 | 补货成功提示、库存变化或明确已满 |
| 一咖舍收益 | 领取成功提示、可提取收益归零或明确无收益 |
| 探索指南下方奖励 | 已领取状态或明确领取结果 |
| 上方礼物每日奖励 | 礼物奖励已领取；未达条件则报告缺口 |
| 邮件附件 | 可领取附件已领完，或确认没有可领附件 |
| 活动每日赠礼 | 主流程中的可领签到/赠礼已核验；未深入的挑战或活动如实说明 |
| 结束关闭 | ADB 强制停止后无该应用进程，包状态 stopped=true |

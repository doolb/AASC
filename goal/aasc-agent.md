# AASC Agent 自主运行目标（Goal）

## 新会话提示词（可直接复用）

请继续完善并运行 `/mnt/AASC/subproject/aasc-agent`，先阅读适用的 `AGENTS.md`、本目标、设计及实现文档。目标是让 agent 接收用户目标后持续自主推进：中层负责解决常规问题，只有遇到自身无法可靠处理的问题时才请求高层；不需要用户逐步监听，卡住或需要用户决策时再说明。

可以由 Codex 担任高层；实际模型和可用性以运行时核验为准。

## 分层职责

- **高层**：理解目标、分析中层上报的能力缺口和异常，提供下一步可执行的决策；高层处理后交还中层，不为每个普通动作重新调用模型。
- **中层**：拆解目标，维护任务状态，采集并复核必要信息，使用本地规划、搜索、启发式和已有经验求解；在可验证的范围内执行、核对结果并继续推进。
- **底层**：通过已授权的工具和 AASC-HIE 完成窗口采集、识别、输入与执行，并返回可供中层核验的状态和证据。

## 运行原则

1. 中层先尝试已实现且可验证的流程；遇到能力缺口、规则或状态不明、执行偏差、搜索不足等无法自行可靠解决的问题，再向高层提供必要上下文和证据。相同缺口没有确认进展时避免反复请求；需要时显式重试。
2. 高层提出的动作须经过宿主权限和现场状态校验；游戏宿主单次高层工具批次只接受一个合法工具，完成后交还中层。执行结果以可观察证据确认，不把建议、截图采集或无效动作当作进展。
3. 同一模型会话优先续接并增量发送新增内容；角色说明默认首次发送，兼容需要重复说明的服务时可显式配置。会话或执行状态不确定时保留证据并停止，避免重复点击或盲目重放。
4. 保存任务进度和必要证据，以便核实和恢复。权限、现场操作规则和用户对模型的授权以当前任务为准。

## 当前进度与待推进目标

- 已实现游戏宿主中层优先、缺口去重、经独立重放的阶段执行，以及高层工具调用后返回中层；会话续接默认发送增量。相关能力以代码及实机证据为准。
- 继续完善新场景识别、特殊机制建模和求解、执行后核验与恢复，让更多可验证任务无需高层逐步介入；完善跨会话去重、进程监管和不确定状态的核验恢复。
- 以 [猪了个猪目标](pig-game.md) 验证持续运行：不使用道具，真实胜利画面才算通关；当前第 112 关仍有大象与炸弹组合待复核，不能将临时脚本或人工处理视为正式宿主已通用支持。
- 扩展到其他真实任务时，继续沿用分层、授权、证据和异常升级原则，并以端到端实测验证，而不假定游戏能力已自动适用于其他场景。

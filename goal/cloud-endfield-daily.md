## 环境和入口

- 2026-11-24设备：`192.168.1.6:5555`，SM_N9500；每次先 `adb devices -l` 核对。
- 网易云游戏：`com.netease.android.cloudgame`，客户端2.9.4（2570），启动组件 `.activity.SplashActivity`。
- 截图竖屏1080×2220、横屏2220×1080；工具预览可能缩放，点击须换算到原图坐标。
- 先检查当前画面；息屏用 `KEYCODE_WAKEUP`，不要切换电源键。需要登录验证时交给用户，不换号、不创建角色。
- 启动：`adb -s <设备> shell am start -n com.netease.android.cloudgame/.activity.SplashActivity`。
- “我的”中找到“游玩历史·一点即玩”，点终末地图标。广告异步加载会把历史区推到下方，必要时上滑，重新截图定位；历史排序会随最近游玩变化。
- “看广告必得时长”提示可选“放弃福利”继续已有免费时长；不购买时长。开始前本次显示手游免费时长30分钟。
- 网易云游戏底部“福利”→“每日福利”可签到领取免费时长；2026-11-24领取第1天奖励，手游和端游各5分钟，手游奖励当日有效。领取前余额分别7分钟和40分钟，领取后核实为12分钟和45分钟。每次依现场余额和签到状态判断。
- 云平台打卡浮窗与游戏内签到是两层页面：前者本次可见第1～4天已领取、今日仍需10分钟活跃，关闭即可；后者进入场景后领取。不要为云打卡额外挂时长。
- 关闭游戏公告，标题页“点击任意位置继续”，等待场景/HUD出现。加载本次耗时数分钟；排队时保留队列、每20～30秒检查，不反复重启。断线恢复后重新核对状态，未核验动作不得直接重复。

## 已验证主流程

### 1. 免费签到

进入后若弹出活动签到，领取当前已开放奖励并核对勾选。2026-11-24“蕈属集群签到”第3天已领：应急理智加强剂1、理智消耗许可2。无弹窗则继续主流程，不逐页翻活动。

### 2. 庄方宜武器仅升一级

主界面右上圆形主菜单 → 左侧“干员” → 庄方宜（本次左侧第一位） → 右侧武器 → 等级提升“+”。

升级页右上等级“+”点一次，确认预览为当前等级 **+1**、目标武器正确、使用的是经验材料，再点“升级”。不点一键填充到上限，不吞其他武器，不突破、不更换装备。截图确认实际等级后立即返回。

本次装备“迷失荒野”：46→47；消耗经验材料31个、折金票770。庄方宜本人仍50级。以后读取当天等级，不固定升到47，更不能因中断重跑再升一级。

### 3. 秋栗仅升一级

干员左下网格展开名单；默认排序下第一个鲜红头发女孩为“秋栗”（本次第三行第二格），选中后关闭网格、切回右侧总览页。核对名字与当前等级，点角色“等级提升+”，升级页右上“+”仅一次，确认预览+1后升级。

用户记忆为20多级，本次实际30→31，消耗初级经验材料4、中级7及折金票394。以名字和外观识别，名单位置只作参考；身份不明确则暂停这一项，不替其他人升级。

### 4. 默认第一项简易制作

主菜单右侧列表上滑 → 背包 → 右上“简易制作” → 默认“应急食药”第一项“芽针粉末”。保持制作份数 **1**，点击制作并核对成功结果。

本次消耗芽针1，产出芽针粉末2，库存26→28。份数1不等于产物数量1；不连续制作、不使用制作出的药品。

### 5. 日常活跃领取

主界面上方行动手册图标（剪贴板）→ 日常。点击一个已完成任务的黄色“领取”，本次自动批量领取登录、角色升级、武器升级、简易制作四项，每项20，共80。

点击左侧已点亮的80档，本次自动领取20/40/60/80档；确认四档勾选和实际活跃数。用户预期90但本次实际80；100未达成，不为凑90/100额外消耗理智、打怪、制造装备或推进委派。领取后列表重排，不复用旧坐标连点。

### 6. 邮件、通行证

- 邮件：主界面左上信封 → 左下“全部收取”，核对到账。不删除邮件、不跳转外部网页。本次领到嵌晶玉1000、折金票10000、初级认知载体8、武器检查套组4。
- 通行证：主菜单右侧第一行“通行证” → 看免费奖励及任务。只领明确已完成的奖励，不购买等级或高级配给；红点/NEW不等于可领取。
- 本次通行证56级、3200/4000，56级免费奖励已勾选，后续锁定；检查周任务第一页、当期、活动、提速、启程的当前可见任务，未见可领。未穷尽全部滚动内容，不声称全部任务完成；日常额外通行证经验仍显示0/2000。

### 7. 及时退出并强停

游戏中发送 `KEYCODE_BACK`，网易云游戏弹出推广退出框，选择 **直接退出**，确认回到网易云游戏“我的”页。不要选“进入活动”或只按Home挂机。

```sh
adb -s <设备> shell am force-stop --user 0 com.netease.android.cloudgame
adb -s <设备> shell pidof com.netease.android.cloudgame
adb -s <设备> shell ps -A
adb -s <设备> shell dumpsys package com.netease.android.cloudgame
```

间隔数秒核对无主/子进程、User 0 `stopped=true`、前台回桌面；若重现可有界复停再查，关闭后不重启。本次已确认直接退出、无进程、stopped=true、三星桌面；没有服务端会话释放查询，不把本地检查当成云端计费证明。

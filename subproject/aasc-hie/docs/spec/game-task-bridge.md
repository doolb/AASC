# 关卡任务桥接伪代码

高层调查 := 本关采集截图与布局候选 → AI 指定棋盘内一次试探和可核对的预期 → 独立执行器确认当前关卡、棋盘范围与当前截图 → 保存前图，点击一次并保存后图 → 为改变后的棋盘建立新导航会话 → 将前后差异及证据交回 AI；禁止道具区域，单次点击后不复用旧计划。AI 提交的完整布局与采集截图摘要绑定，仍须经固定求解器和独立重放才能执行完整路线。

已有声明 := NavigationGapQueue.report、AutonomyCoordinator、CommandExecutor、猪关卡自动脚本
新增定义 := GameTaskBridge {脚本路径, 工作目录, 显式启用, 进程启动器}; GameTaskSnapshot {observation, plans, feedback, gaps, evidence}
读取任务目录 → 读取 level.json、plan.json、result.json（缺失表示未产生）→ 校验 JSON 对象 → 复制初始布局、计划和反馈 → 若结果为卡关或中断则生成包含原因与证据路径的 NavigationGap → 输出快照
显式启用且参数合法 → 以参数数组启动 Python 脚本 → 等待退出 → 返回退出码及输出；未启用直接拒绝
桥接层不点击设备，不自动发布导航包；现有脚本负责动作和逐步验证。

关卡快照 + 现有世界状态 → 合并 gameTask 观察 → 将本次 gaps 传给 AutonomyCoordinator.decide → 返回快照与分层决策；调用方自行决定后续动作，重复读取不自动累计上报。

ScriptMaintenance → 列举及读取 scripts 下普通 JS 文件并计算 SHA-256 → 比较旧摘要 → 替换内容 → 语法及可用 HIE 测试 → 成功保留、失败恢复；检测到并发修改则不覆盖。缺失王者荣耀数据集及导航资源的两组测试单独排除。

中层优先调度伪代码:
    默认行为保持三层全部调用；显式启用中层优先时先运行本能与肌肉记忆
    两层没有可用计划，或存在明确需要 intelligence 的缺口 → 调用 intelligence
    否则跳过 intelligence，仍按优先级选择计划并保留安全层结果
猪关卡复核伪代码:
    捕获首屏与候选 → 固定中层适配器匹配同关历史胜利证据及完全一致的棋盘像素
    有可信历史复核布局 → 绑定当前截图摘要，固定求解并独立重放
    识别冲突、未知物件、未验证机制或搜索失败 → 保留证据并报告结构化缺口；不可将候选伪造为已复核

炸弹保守计划伪代码 := 已复核且声明炸弹的布局 → 只搜索无炸弹碰撞的完整路线 → 独立重放 → 保存计划；缺少炸弹逐帧匹配时阻止实机执行。

铁笼中层阶段伪代码:
    首屏摘要和关卡匹配 → 可确认笼外物件 → 中层求解与逐步核对；否则保留缺口
    已复核保守布局 → 绑定截图并独立重放 → 写入执行标记 → 阶段执行和计数核对
    阶段完成 → 重新采集并清除旧复核布局；执行状态不确定 → 停止，不重放旧动作

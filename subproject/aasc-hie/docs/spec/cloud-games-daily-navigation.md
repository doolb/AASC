# 三款云游戏每日导航包伪代码

日期：2026-11-24。设计见 [design](../design/cloud-games-daily-navigation.md)。

```text
现有截图 → 按游戏分别裁剪页面标题和确认过的入口 → 内嵌图片素材
素材 + 页面标记 → 声明每日场景和状态
确认过的低风险入口 → 声明单步导航动作和下一页面目标
补货付款 / 代理次数 / 等级和制作材料确认 → 人工交接，读取当日实际值
当前截图 → 识别候选与置信度 → 同游戏页面及状态复核
无匹配、冲突、版本变化或动作结果不明 → 保留缺口并停止
成功动作 → 新截图验证；不可依照旧坐标重复执行
对每个包 → nav-check校验结构 → 原截图及跨页面截图做正反匹配测试
```

包只是可读取的数据，当前运行时不会自动执行其中的flowId和素材匹配闭环；不得将包结构校验通过视为设备端无人值守通过。若后续要支持，需要单独实现并测试可恢复状态机、真实动作约束和结果核验。

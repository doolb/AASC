# 网易云游戏广告时长伪代码

日期：2026-11-24。[设计](../design/netease-cloud-ad-time.md)；当前控制器已实现，完整真实广告闭环尚未验证。

接口与数据流：

```text
设备序列号 + OCR服务地址 + dryRun + 次数上限 → ADB连接校验 → 读取截图和前台包
界面节点 + 前台包 → 已知状态分类 → 状态处理器 → 安全动作或等待
节点不足以确认状态或定位动作 → 按当前步骤裁剪截图中所需区域 → OCR文字框换算为屏幕坐标 → 再次分类；必要时扩大区域，仍不足则停止
执行动作 → 再次截图识别 → 结果事件 + 已领奖次数 + 奖励秒数
网易结果 + 刷新余额 → 账目核对 → 继续观看或停止原因
未知状态 / 不可确认到账 / 断线 / 超时 → 状态事件与原因 → 中止并汇报
```

```text
设备 + 当前画面 → 连接和前台确认 → 我的页面 → 读取起始余额
入口可见 → 看视频得时长 → 新截图
循环按识别状态处理，限制总时长与重试次数:
    广告倒计时 → 等待并重读，不提前退出
    明确的浏览提示 → 识别允许的详情类型 → 浏览规定时长 → 返回并重读
    未知页面 / 需要安装或付款 / 状态不明 → 保存证据并交接
    提前退出提示 → 标记未完成，不计成功
    广告奖励已领取 → 按当前可见出口返回网易结果
    网易成功弹窗 → 记录本次显示的奖励 → 下一轮或结束时刷新余额
    网易未完成或加载失败 → 记录失败；在上限内按状态恢复
网易成功 → 按当前允许与目标次数继续；结束后余额变化与奖励总额核对
余额未确认或不符 → 记录到账未确认，不宣称完成
达到指定次数 / 平台不可继续 / 识别或到账失败 → 停止并汇报逐次结果
发现云游戏运行中 → 停止且不触碰现有会话；结束后保留客户端
```

2026-11-24人工实测8次成功：120、180、60、120、240、60、120、60秒，余额12→28分钟；结果页“继续观看”可直接进入下一条，第8次显示今日次数已用完。一次提前退出未获奖励；结果弹窗可能移动，广告可能唤起系统安装确认，取消后重新识别。以上为人工操作证据，不代表自动执行已实机验证。

OCR 复测：历史截图的 1000×220 时长卡片区域通过 HTTPS 识别成功，耗时约 27 秒，识别到“看视频得时长”、28分钟和45分钟；较大区域一次响应约 32 秒，超过客户端默认 30 秒。值来自历史图片，非实时余额；完整自动广告闭环仍待实测。

2026-11-25 实测现状：启动加载画面 → unknown 停止；首页重试 → 自动进入我的并读取30分钟 → 启动广告 → 广告“60S内必得奖励”画面被判 unknown → 停止。人工等待及关闭 → 平台显示120秒 → 人工刷新余额32分钟。启动和该广告分支尚未自动通过。

修复伪代码：启动后未知画面 → 限次等待并重新采集；广告截图 → 优先 OCR 上下边缘窄区域 → 匹配 `数字+S/秒+内必得奖励` 等倒计时 → 标记本轮已观察广告 → 等待并重新采集；已观察倒计时且底部出现“关闭” → 新截图再次确认 → 点击文字坐标 → 等待网易结果；边缘无匹配 → 必要时识别中部弹窗 → 未知则停止。奖励到账仍以网易结果和余额核验。

实机提前领奖弹窗 → 未识别关闭控件 → 有限等待并重新采集；识别关闭后再次确认新画面 → 点击并等待网易结果；重试耗尽或画面不一致则停止。

节点采集失败 → 短暂等待后重试一次 → 仍失败则仅依靠新截图局部 OCR；不复用旧节点；无法确认时停止。

2026-11-25 修复后实机证据：我的36分钟 → 广告浏览提示 → 取消安装 → 确认广告完成并关闭 → 网易结果120秒 → 切换页面刷新 → 38分钟 → completed；此为单条素材验证，多轮、其他广告及冷启动实机仍待验证。

后续多轮实测：余额38分钟 → 循环完成4次并记录240、60、120、60秒 → 今日次数已用完 → 刷新余额46分钟 → completed/daily-limit；未安装应用。

OCR 客户端创建 → 默认单次请求超时 60 秒 → 各中层调用复用默认值；调用方显式设置超时时使用其设置 → 超时返回错误并停止。

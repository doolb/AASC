# 云终末地每日主流程伪代码

日期：2026-11-24。人工Agent逐屏执行规范，尚无对应自动化程序。设计见 [design](../design/cloud-endfield-daily.md)，操作见 [goal](../../../../goal/cloud-endfield-daily.md)。

```text
过程 终末地简短每日:
    核对设备、前台、当前截图
    必要时唤醒；认证交给用户；恢复后重读状态
    打开网易云游戏的我的、游玩历史、终末地官服
    需要查询或领取平台签到时，打开福利中心的每日福利
    按当日状态领取免费签到奖励，在我的页面核对手游与端游余额
    按当前截图避开插入广告；拒绝额外时长购买
    关闭无可领的云打卡浮窗和公告
    等待标题、进入场景；排队保留位置并定期观察
    出现游戏签到时领取免费已开放项，核对勾选

    对于 [庄方宜当前装备武器, 秋栗角色等级]:
        打开对应详情，核对身份与当前等级
        当日已确认本项完成则跳过
        选择升级目标 = 当前等级 + 1
        核对预览、经验材料及普通货币消耗
        身份不明、材料不足、达到上限或预览超过一级时停止该项
        执行一次升级，核对新等级并记录
        结果不明时重读状态，不无条件重试

    打开背包、简易制作、应急食药默认第一项
    核对芽针粉末与份数1
    制作一次，记录成功与产出2；不使用产物
    打开行动手册、日常
    领取已完成卡片，重读重排后的列表及实际活跃
    领取已达成活跃档位，核对勾选
    记录用户预期90与本次实际80的差异，不扩展任务追100
    打开邮箱，全部收取并核对；不删除
    打开通行证，检查免费档及当前任务
    仅领取已解锁/已完成项；记录无可领或未达成
    发送系统返回键，在云客户端框选择直接退出
    确认回到客户端首页后强停 com.netease.android.cloudgame
    等待数秒核对无主/子进程、stopped=true、前台桌面
    如进程重现，有限复停并报告结果
    退出后同步goal、design、spec、task、todo及changelog
```

实测：迷失荒野46→47、秋栗30→31、芽针粉末26→28；日常80及四档已领；签到第3天已领；邮件附件到账；通行证56级3200/4000，当前免费档已领、检查到的任务未达成。直接退出后强停核验通过。排队、断线、材料不足和升级上限分支未触发。

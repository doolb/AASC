# 云幻塔每日主流程伪代码

状态 := 2026-11-23 人工 ADB 实测路线；无人值守程序未实现
输入 := 已连接设备、云幻塔包名、当前画面、用户指定任务
设备与包核对 → 息屏则唤醒 → 观察并处理锁屏或认证 → 启动或接续已有云会话
排队或加载 → 保留会话并定期截图等待；断线恢复后重新观察
角色场景确认 → 右上礼物 → 特别行动供给 → 领取可用免费奖励
福利 → 签到 → 领取当天奖励 → 通行证 → 查看版本日常及已解锁奖励
主界面 → 右上交叉武器 → 必做/每周 → 领取已完成在线奖励
米娅私厨 → 逐次品尝、等待动画和领奖 → 次数用完 → 返回并领取已完成任务
次元历练 → 前往 → 参与 → 代理作战 → 核对次数和资源 → 调整为1次 → 执行
作战成功 → 关闭结果 → 返回周常 → 重新定位并领取1/1奖励 → 检查活跃奖励
主界面左侧信封 → 邮件 → 一键领取附件 → 核验到账；不删除邮件
完成或中断需退出 → ADB强停目标包 → 等待 → 检查主/子进程、stopped状态和前台
进程重现 → 有界复停并复查 → 若仍失败如实报告
每步 := 新截图 → 定位 → 单步操作 → 等待 → 新截图核验；中断后不重放旧坐标
输出 := 已领、无可领、条件不足、未确认及关闭结果；排队恢复未实测

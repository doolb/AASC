# 三款云游戏每日导航包

日期：2026-11-24。设计见 [design](../design/cloud-games-daily-navigation.md)，伪代码见 [spec](../spec/cloud-games-daily-navigation.md)。

任务：为云异环、云幻塔、云终末地建立独立每日导航包，将有截图证据的稳定页面和部分低风险入口交给中层参考，旧幻塔周包保持独立。截图裁剪排除UID等个人信息，不嵌入整屏。涉及资源、货币和次数的关键确认交接人工。

受影响模块：`data/packages/cloud-*-daily.nav.md` 与本子工程文档；无主工程代码与Offline发布产物变化。先更新spec，再写导航数据。

自测：每包运行 `npm run nav-check -- --file ...`，对保留截图进行模板正匹配、跨游戏/跨页面负匹配；核对资源和daily周期。兼容性以本次2220×1080实机截图为准，不声称版本、设备缩放或登录/排队分支兼容。性能以本地模板匹配为限，真实设备端到端延迟另测。

风险：旧图、不同分辨率、动态广告、列表重排可能导致误匹配；关键确认未自动执行。完整中层闭环需要现有runtime之外的适配与实机验证。预计本次约1～2小时，后续取决于补采和适配。

## 执行结果

- 新增 `cloud-yihuan-daily.nav.md`（5状态、3入口）、`cloud-huanta-daily.nav.md`（5状态、2入口）、`cloud-endfield-daily.nav.md`（4状态、1入口），各动作后交接；旧weekly包未修改。
- 三包 `npm run nav-check` 均返回空诊断；各选一项 `npm run nav-chain` 均能生成单步及交接节点。这是结构验证，不代表真实调度已接通。
- OpenCV使用14个来源截图测试各状态素材的正匹配，并与其他13幅页面交叉比较，阈值0.94下无误匹配；另用四幅不同截图验证异环一咖舍/日常、幻塔米娅/周常，得分0.998～1.000。采集截图本身正匹配不能证明泛化，未执行手机端中层自动化和实际点击。
- 已知待办：接通包素材与运行时识别/动作闭环，补采跨设备、缩放、弹窗及非目标页面并验证带消耗步骤的数值识别。用户另提出网易云广告加时长独立目标，按用户顺序后续处理。

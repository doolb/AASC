# 猪游戏中层优先自动化（进行中）

## 目标

将猪游戏的常规识别、规则匹配、求解、执行和反馈放到 HIE 中层，已知关卡正常推进时不调用高层模型；仅在中层不能处理的新物件、规则冲突或无法恢复的缺口出现时，将证据合并交给高层。保留原模型会话，并记录调用次数与升级原因。

## 拟修改

1. `subproject/aasc-hie/src/computation/autonomy-layers.js`：增加中层优先的可配置调度，先执行本能与肌肉记忆；只有没有可用计划或存在需要高层处理的缺口时才调用 intelligence，默认兼容其他调用方。
2. `subproject/aasc-hie/src/runtime/pig-navigation.js` 和 `data/packages/pig-game.nav.md`：导航目标先直接驱动中层观察、识别、复核、求解、执行和胜利校验；只把无法处理的结构化缺口交给高层，并对相同缺口与证据去重。
3. `subproject/aasc-game/scripts/auto-pig-levels.py`、`pig_level_auto.py`、`pig_special.py` 与新的中层布局适配器：复用多帧识别、网格拟合和已有特殊物件识别，核对位置、方向、遮挡和候选冲突；形成可验证的布局及明确的未知项。第 81 关炸弹猪需结合历史记录和实机证据建模，未经验证的规则不能凭猜测用于完整路线。
4. `subproject/aasc-game/scripts/pig_locked_candidate.py`、`pig_fast_locked_solver.cpp`、`play-pig-locked.py` 与 `pig-nav-plan.py`：将经过验证的常见规则加入中层求解与独立重放，先尝试避免危险碰撞的保守路线；中层搜索、复验及逐步现场核对均不调用高层。
5. `subproject/aasc-agent/src/pig-cli.js`、`pig-loop.js` 和 `pig-host.js`：先推进中层，只有收到真实缺口时才请求高层；合并必要证据、复用现有会话，对相同未变化的缺口不重复询问。高层提出的规则和动作继续经过中层验证。

## 验证和限制

- 为已知普通布局、已知特殊物件、识别冲突与未知机制建立测试，统计并断言高层调用次数；已知完整路线为零，无法解决的相同缺口不反复调用。
- 离线重放第 71、73 关等历史证据，并对炸弹规则进行独立验证；第 81 关先验证视觉识别与规则，再执行完整计划，不使用底部道具。
- 保留目标进度、断点状态及截图摘要；截图过期、执行中断和现场偏离时重新观察，不重复点击。
- 为避免额外模型调用，旧高层进程已停止；已核对服务端完成的直接后继并恢复同一会话，未消费回复里的命令均未执行。实施后应先重新采集现场。

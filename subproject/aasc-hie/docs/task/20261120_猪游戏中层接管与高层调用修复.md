# 猪游戏中层接管与高层调用修复（已实现）

## 任务描述

第 105 关应由本地中层复核、求解、执行与核验；仅在真实未知规则、无法安全确认布局或搜索达到限制等缺口时调用高层。方案已获用户确认并实现。

## 需求评审

- 结论：可开发；主等级 L6，次等级 L5；置信度 0.62，直接开发风险中等。
- 评分：层级清晰度 21/25、证据充分度 18/20、实现完备度 15/20、风险暴露度 17/20、L4 可落地性 13/15，总计 84/100。
- 证据：`agent.chat` 执行工具后直接再次调用模型；中层仅复用完全匹配的历史胜利布局；临时启动器设置 `instructionsEachRequest=true` 并重复拼接说明；同一缺口退避后仍会重发。
- 下放判定：必须下放；由 L6 契约与 L5 调度规则下放到 L4 状态转换、受限求解与检查。不能将图片已采集当作棋子已离场。

## Design 需求

1. 中层先采集、识别和求解；对可确认的安全阶段，独立重放后自动执行并核验，直到胜利或出现确切缺口。
2. 高层只处理聚合后的缺口；高层调用一次工具后返回中层，再判断是否仍需高层，不能逐步让高层代替求解器。
3. 相同现场和相同缺口不重复请求高层；现场、机制或用户明确重试改变时允许再次上报。失败必须可见并有界重试，不丢弃不确定的现场。
4. 会话首轮发送系统说明；有效续接只发送增量结果，保留服务明确要求重复说明时的现有配置能力。去掉临时启动器的强制重复注入。
5. 未复核的弹簧、遮挡物和铁笼内部不得伪装为普通猪；可以把无法辨认部分保守设为障碍，在安全约束下尝试笼外阶段。禁止底部道具。
6. 窗口、布局、图片摘要、操作和胜利结果必须经独立核验；中断后重新采集，不能重放未确认的点击。

## Spec 伪代码

已有声明：`PigNavigation.advance`、`runPigLoop`、`Agent.chat`、`ResponsesModel.respond`、`pig-nav-middle.py`、`pig_cage_stage.py`。

新增定义：`Gap {关卡, 画面摘要, 阶段, 原因, 状态}`、`MiddleOutcome {已完成, 已推进, 缺口, 不确定, 证据}`。

操作流程：

    当前画面 → 中层复核已知物件及保守障碍 → 本地规划并独立重放 → 分批执行与核对
    已推进 → 重采集 → 中层继续；已完成 → 保存胜利证据
    无安全本地步骤 → 聚合缺口 → 相同缺口有记录则停止或退避 → 新缺口才请求高层
    高层提交复核或试探 → 保存工具结果 → 结束本轮高层对话 → 重采集 → 中层接管
    会话首轮 → 发送系统说明；已确认续接 → 发送增量证据与上轮响应 ID
    图片采集成功 → 仅表示已观察 → 核对位置、计数及机制 → 才可确认实际进展
    现场不确定、复核失败或模型会话中断 → 保留证据并停止，不重放动作

## 受影响模块与代码

- `subproject/aasc-agent/src/agent.js`、`pig-loop.js`、`pig-host.js`：工具执行后交还中层、缺口去重、已观察与已推进分离；保持其他角色默认行为兼容。
- `subproject/aasc-hie/src/runtime/pig-navigation.js`：接入可验证的中层阶段结果和恢复边界。
- `subproject/aasc-game/scripts/pig-nav-middle.py`、`pig-nav-cage.py`、`pig-nav-reviewed-cage.py`、`play-pig-locked.py`：针对已验证机制规划阶段；未知弹簧和笼内占格保守阻挡，不虚构模型。
- `subproject/aasc-agent/src/responses-model.js`：核查首轮与续接说明，默认续接不重复；本次临时启动器不再强制注入。若现有实现满足，只补验证，不无谓改动。
- 对应 `subproject/aasc-agent/test/`、`subproject/aasc-game/tests/` 与 HIE 导航测试；同步本设计、伪代码、待办和变更记录。

## 自测用例与兼容性测试

- 模拟可解阶段：多步执行期间高层调用数为 0，完成或真正卡住后才返回；高层提交复核/试探后下一步先运行中层。
- 相同缺口去重；状态确有变化或用户显式重试后允许重新上报；模型错误和现场不确定不会盲目重试点击。
- 首轮发送说明、同一会话续接不重发，显式 `instructionsEachRequest` 仍兼容；保留 `high` 档位和模型续接保护。
- 笼外阶段独立回放，未知弹簧与笼内保守阻挡；计数、位置、遮挡不符、截图过期及底部区域均停止。
- `npm test`（aasc-agent），按影响运行 `npm run test:pig-navigation`、`npm run test:pig-cage`、`npm run test:pig-locked` 与 HIE 导航相关测试；第 105 关先离线验证再有界实机核对。

## 性能、风险与工时

- 性能：已验证可行的连续阶段高层调用为 0；新缺口只请求一次，记录调用次数、耗时及状态变化。
- 风险：弹簧并行动作、遮挡和动画可能造成误识别；无法安全建模时停止并升级，不能保证第 105 关仅凭静态阶段必然可解。
- 预计工时：约 6～10 小时，视识别与实机复核结果调整。

## 实施与验证

- 中层先求解并独立重放，安全阶段可连续执行；高层仅处理缺口，单次工具后立即交回中层。相同缺口无新进展不重复调用，不确定状态停止。
- 铁笼阶段保护未确认弹簧、红色提示和笼内物件，校验标记、连续稳定画面和 OCR 计数；受保护蓝色区域内的方向未知碎片允许闪烁，但标记变化或其他棋子不匹配仍停止。
- `aasc-agent` 测试 51 项、游戏导航 12 项、铁笼 18 项、HIE 导航 10 项及锁猪回归 10 项通过。第 105 关从铁笼 53 继续实机验证至通关；弹簧与红色提示阻挡时人工复核，开笼后 20 步由中层独立重放并执行，未使用道具。

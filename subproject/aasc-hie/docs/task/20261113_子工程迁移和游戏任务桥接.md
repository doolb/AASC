# 子工程迁移和游戏任务桥接

任务：迁移 HIE、retop、remote-gamepad，保留文件及历史；建立 HIE 对猪关卡脚本结果与执行的适配。
设计：见 docs/design/game-task-bridge.md。
实现：先同步 docs/spec/game-task-bridge.md；独立桥接器读取关卡证据并映射观察、计划、反馈和 gap，显式启用后以参数数组运行现有脚本。
影响：HIE runtime/index、根导出、桥接测试及项目路径文档；不改变 retop 算法和 remote-gamepad 协议。
自测：胜利/卡关/异常/缺失文件、禁用与启动参数；兼容：原 HIE 路径、retop Git 和旧 HIE 仓库历史；性能：结果文件异步读取，无重复启动。
风险：原 HIE 仓库出现已迁出文件的删除状态，自动计划不能代替识别验证；运行真实游戏必须显式启用。预计 4 小时。

# 三款云游戏每日导航包设计

日期：2026-11-24。范围为云异环、云幻塔、云终末地各自独立的每日导航资料，复用已采集实机截图，保留旧幻塔 weekly 包。目标是帮助中层定位常见页面及部分低风险入口；涉及货币、活力、材料及次数的确认必须核对当前值并交接，不能把一次截图当作通用自动化证明。

现有包解析支持图片素材、states、flows 和 daily goals；匹配器支持 OpenCV 模板，执行器支持 ADB 单步。但当前通用 GoalPlanner/UiNavigator 不自动从 flowId 解析素材并驱动截图→动作闭环；本次包不修改运行时，不宣称已实现自动执行。实际操作必须由调用方将匹配、状态、动作及结果验证接通，未知画面停止。

截图按局部稳定标题或已知按钮裁剪，保留截图样本来源和阈值；只描述已观察的页面和动作，动态弹窗、列表重排、不同分辨率和版本必须重新识别。不会把银行卡、UID或整屏嵌入包中。异环补货付款、幻塔代理次数、终末地等级选择与制作确认均保留人工交接；不要重复执行。

本次三包共14个页面状态、6个单步入口：异环5状态3入口、幻塔5状态2入口、终末地4状态1入口。每个动作后声明人工交接；状态和按钮模板是相互独立的素材，不把已识别某一页面等同于动作已经完成。

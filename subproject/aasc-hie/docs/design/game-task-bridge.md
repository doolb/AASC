# 关卡任务桥接设计

将 AASC Game 关卡脚本的结果映射到 HIE：初始识别进入观察，求解结果进入计划，执行与卡关结果形成反馈和 NavigationGap。保留已有脚本自身的识别、验证和 X11 操作；HIE 不把尚未验证的计划视为已执行。启动默认关闭，仅显式启用时允许调用本地脚本，禁止命令行字符串拼接。

迁移：HIE、retop、remote-gamepad 为 AASC 的三个实际子工程。四个子工程统一由 AASC 主仓库管理；旧仓库提交历史不要求合并，工作文件及未提交修改保留。旧 HIE 和 retop 路径保留兼容链接。

`decide` 可将当前观察和缺口交给现有自主协调器，保留调用方已有世界状态；协调器生成的结果仍通过既有执行边界。桥接不自行订阅文件变化，也不自行修复关卡。

猪关卡高层调查由 Agent 驱动：模型读取候选和截图，提出带假设及预期的棋盘试探，固定执行器校验现场并保存前后证据；试探后重新采集，旧导航会话不可再执行。模型也可提交绑定截图的布局，完整路线仍需经过现有求解器和独立重放。

Agent 游戏宿主可以调用独立的 `ScriptMaintenance` 更新 HIE 脚本；该工具核对原文摘要并运行语法和可用回归，失败恢复，不允许模型指定任意命令或任意路径。缺失本机王者荣耀数据集和导航资源对应的两组测试不会参与此项检查。

中层优先：同关卡、棋盘像素一致且留有实机胜利图的历史布局可复用于求解；安全铁笼可交给本地阶段器，显式复核的保守铁笼布局可独立重放并分阶段执行。阶段完成后重采集，不复用旧布局；现场或执行不确定时保存证据并停止。无可靠证据则保留缺口，不能将候选识别视为复核。

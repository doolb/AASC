# 关卡任务桥接设计

将 AASC Game 关卡脚本的结果映射到 HIE：初始识别进入观察，求解结果进入计划，执行与卡关结果形成反馈和 NavigationGap。保留已有脚本自身的识别、验证和 X11 操作；HIE 不把尚未验证的计划视为已执行。启动默认关闭，仅显式启用时允许调用本地脚本，禁止命令行字符串拼接。

迁移：HIE、retop、remote-gamepad 为 AASC 的三个实际子工程。四个子工程统一由 AASC 主仓库管理；旧仓库提交历史不要求合并，工作文件及未提交修改保留。旧 HIE 和 retop 路径保留兼容链接。

`decide` 可将当前观察和缺口交给现有自主协调器，保留调用方已有世界状态；协调器生成的结果仍通过既有执行边界。桥接不自行订阅文件变化，也不自行修复关卡。

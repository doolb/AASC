# 王者荣耀状态识别与采样

当前包仅读取画面并描述状态。采样时可以打开大厅、设置、训练选择、战斗计分板、装备商店、战斗设置和赛后页面；运行时识别器不会点击、移动、攻击或购买，也不会生成 NavMesh。

## 运行识别

单张文件预览：

```sh
npm run hok:preview -- --file data/datasets/honor-of-kings/frames/battle-hud-live.png
```

从设备抓取一帧：

```sh
npm run hok:preview -- --serial 192.168.1.6:5555
```

以 H.264 屏幕流每秒抽取两帧并逐行输出 JSON：

```sh
npm run hok:preview -- --serial 192.168.1.6:5555 --watch --fps 2
```

若本机或配置的 AASC OCR 服务可用，可加 `--ocr` 返回画面文本框；从连续视频帧启用时，识别器会先编码当前帧再提交 OCR 请求，帧率受服务响应时间限制。默认不发 OCR 请求。

Android 的 `screenrecord` 单次流最长约 180 秒；识别脚本会在设备流结束后重连。按 `Ctrl-C` 停止。

输出包括时间戳、帧年龄、场景 ID/标签/置信度、顶层 UI、可见 UI 列表、按钮坐标/状态、已读数值、可选 OCR 文本和未知项。当前战斗 HUD 探针读取血量和蓝量；设置分区按钮与皮肤页的进入按钮使用局部画面样本识别状态。未校准控件仍输出 `unknown`。

## 追加采样

从设备只读抓图，不发送任何触控输入：

```sh
npm run hok:capture -- --serial 192.168.1.6:5555 --count 10 --interval-ms 2000
```

新图写入 `data/datasets/honor-of-kings/frames/`，记录追加到 `manifest.jsonl`，并标为 `pending-review`。复核场景、UI 和按钮状态后，才把它纳入训练指纹；未复核样本不会参与分类。

复核后给记录补上 `sceneId`、`uis` 和可确认的 `buttons`，并把 `annotationStatus` 改为 `screen-reviewed` 前缀，然后运行 `npm run hok:index` 重建指纹索引。预览器会在已复核清单与索引不一致时提示重建。

## 数据集与已知范围

数据清单：`data/datasets/honor-of-kings/manifest.jsonl`。当前 31 张已复核截图覆盖启动提示、大厅、六类大厅设置页、竞技模式和训练入口、英雄/皮肤选择、加载、战斗 HUD、计分板、商店、战斗设置以及赛后结果。各按钮边界是 1480×720 画面坐标。

场景识别用 RGB 网格指纹查找最近样本；距离过大或候选相近时拒绝分类并返回 `unknown`。大厅设置分区用局部 ROI 样本识别选中/可用状态，皮肤页的“进入游戏”用 ROI 样本区分启用/禁用。其余控件只在样本精确匹配或有明确场景规则时输出已知状态。当前还不能可靠识别动态公告、活动弹窗、不同游戏版本和每个英雄技能冷却；遇到这些画面应补样本或接入 OCR/专用按钮检测器，不能把猜测写成已识别状态。

ADB PNG 截图实测约 1.88 秒一帧，约 0.53 FPS。H.264 屏幕流录制的探测帧率为 25 FPS，识别脚本目标抽取 2 FPS；设备实测输出约 1.6 FPS，解码后单帧识别耗时约 3–100 毫秒。更高抽样率会增加 CPU 和解码负载。当前约 1.6 FPS 是实际采样更新速度，不代表所有按钮/场景都已达到同等准确率。

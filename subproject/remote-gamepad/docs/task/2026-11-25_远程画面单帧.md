# 远程画面单帧

需求：独立端口、可调 JPEG 画质、CPU 编码及 GPU/视频能力预留，命令行直接获取。设计与伪代码分别见 `../design/screen-capture.md`、`../spec/screen-capture.md`。

范围：服务端监听和截图、版本化协议、命令行、用法与针对性协议测试。兼容性：旧控制端不受影响；Windows 交互桌面需要 GDI。测试：握手、范围、异常、完整 JPEG、退出资源释放；Windows 游戏实际捕获另行验证。性能：只按请求截图、限制并发及长度。风险：游戏硬件渲染、受保护画面或权限可能导致黑屏；GPU 和视频不声称已实现。预计 4–8 小时。

结果：服务端编译通过；服务端协议测试覆盖能力、画质、GPU/视频拒绝及正常响应，Python 客户端测试覆盖分片、截断和 GPU 不可用。没有可用 Windows 交互桌面，GDI 实际采集与游戏兼容性待验证。

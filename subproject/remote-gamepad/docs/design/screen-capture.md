# 远程画面单帧设计

2026-11-25：在独立画面端口按请求截取主显示器，返回可调画质 JPEG，供命令行调用；保留未来视频流的协议扩展空间。服务端使用交互式 Windows 桌面的 GDI，CPU JPEG 编码；能力协商如实标记 GPU 和视频暂不支持。目标程序若无法被 GDI 捕获，后续考虑 DXGI。默认控制端口加3（26763），继承服务端监听地址，端口不够时禁用并提示。既有控制、音频、聚合端口保持不变。

协议使用独立连接、版本化握手和长度限定的消息，先协商能力，再请求单帧；错误明确反馈。截图受屏幕内容、用户会话、权限及采集方式影响，游戏实机效果需验证。

首版以 `VDF1` 握手、长度前缀 JSON 元数据和 JPEG 二进制数据实现；同时限制连接数、超时及图片大小。命令行提供画质与编码器选择，不支持 GPU 时提示，不自动伪报。服务端编译及本地协议测试通过，Windows 实际桌面和目标游戏尚待实机验证。

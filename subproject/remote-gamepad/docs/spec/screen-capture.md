# 单帧画面伪代码

```text
启动服务端：
    读取监听地址及控制端口
    如果控制端口加3在端口范围内，启动画面监听器，否则提示禁用
    停止时取消画面监听并等待连接结束

画面连接：
    限制并发、握手和读取时间
    验证版本标识，回复支持的单帧格式、CPU编码、GPU和视频能力
    读取有界请求，校验类型、画质及编码器
    请求GPU或视频时返回不支持，不伪装为成功
    使用GDI截取主显示器并用指定画质生成JPEG
    发送包含类型、尺寸、序号、时间戳、编码器和数据长度的元数据及图片
    出错返回有界错误消息，释放画面及系统资源

命令行：
    校验目标、端口、画质和输出路径
    直连目标并协商版本、发送单帧请求
    校验响应大小、JPEG类型和完整数据，写入文件并报告编码器
```

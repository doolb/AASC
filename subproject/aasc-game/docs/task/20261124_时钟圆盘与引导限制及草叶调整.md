# 任务：环境 3 指针时钟圆盘、24h 主光源随时间联动、引导点击限制与拖动不平移

## 任务描述
1. 在环境设置面板中，将季节（春/夏/秋/冬）、天气（晴/阴/雨/雪）与新增 24 小时时段（早/中/晚/夜）组合为 **3 指针同心时钟圆盘**，支持点击表盘扇区切换对应项；
2. 缩短昼夜自动循环周期（从 600 秒缩短至 90 秒），且 **主光源方向**（`sunLight.position`、`uSunDir` 与昼夜光影/月光/星点）随 24h 时间连续变化；
3. 第 1 关新手引导期（前两步）未按提示点击目标猪时，不允许点击其他小猪并提供轻摇提醒；
4. 鼠标或单指在小猪身上按下拖动时不触发相机平移；
5. 移动端草叶三档数量调整为 `8000 / 4000 / 2000`。

## 自测与验证用例
1. 第 1 关默认进入后，在引导阶段点击非引导目标小猪被拦截并提示，点击引导猪可正常离场解锁后续点击；
2. 在猪身上左键按下拖动不改变相机 `panX/panZ`，在空白地面按下拖动仍正常平移；
3. 打开设置抽屉可见 3 指针时钟圆盘，分别点击冬/雪/夜（或早/中/晚）可更新环境 preset、`timeSlot` 及主光源位置 `sunPos`；开启自动时间流逝在 90s 周期内可观察到 `dayPhase` 与主光源方向连续变化；
4. 移动端 grass 三档输出验证为 `8000 / 4000 / 2000`；
5. 运行 `npm run test:pig-web`、`npm run test:pig-animation`、`npm run test:pig-3d` 全量通过。

## 风险评估与预计工时
- 低-中风险：需注意已有 `tests/pig-level-3d.test.js` 中“空白地面左键拖拽”测试用例不应落在第 48 关猪身上，且确保 3 指针同角度时不互相遮挡。预计工时：1 小时内完成并自测通过。

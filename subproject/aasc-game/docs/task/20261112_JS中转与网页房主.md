# JS 中转与网页房主（内网源码已实现）

任务：公网 Node.js 中转；网页本地 JavaScript 游戏管理器担任房主，浏览器和 APK 客户端使用同一 HTTPS/WSS 通道与 AASC 消息，保留现有 APK 局域网模式。设计和伪代码见 game 文档；与游戏更新方案协同实施。

影响：新增中转服务和房间身份管理，提取共享游戏规则、改造网页与 APK 通信、增加联机及部署说明。自测：网页与 APK 跨端对局、多房间隔离、非法消息、重复/乱序、身份盗用、房主断线及恢复、页面刷新、原局域网回归。兼容：主流 HTTPS 浏览器和 Android WebView；性能：并发房间与消息频率限制；风险：房主浏览器关闭或休眠暂停、服务可用性与恶意输入；预计工时 4–7 天。正式部署和具体容量约束待确定。

用户已确认先只在内网运行 Node.js 中转，默认本机监听，按需显式绑定内网地址；暂不开放公网。后续公网能力不作为当前发布或部署动作。

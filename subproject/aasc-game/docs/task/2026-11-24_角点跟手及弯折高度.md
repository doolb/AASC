# 角点跟手及弯折高度

状态：已完成实现、本地验证与外网发布核验。

设计与伪代码：design/gami.md、spec/gami.md 的角点跟手章节。固定高度反投影后圆柱弧造成额外水平和高度变化，需以实际材料角点投影反求目标，降低新弯折幅度。

涉及模块：app.mjs 手势和吸附、scene.mjs 实际表面投影、held-fold.mjs 弯曲参数，必要时独立求解 helper；tests/gami.test.js 屏幕误差及高度回归。

自测与兼容：正面/斜视连续拖动、再次抓取、触控按下偏移、吸附释放、取消/预折痕；旧存档保留原合法弯曲范围。性能：限制每事件求解步数，不能在每次迭代重建场景。风险：不可达点、角点切换、纸层遮挡与错误吸附；失败保留最近有效候选。预计实现与验证约半个工作日。

实施记录：增加 drag-projection.mjs 有界投影逆解；app.mjs 保存按下角点屏幕锚点并对未吸附手工角点校正目标；held-fold.mjs 降低新弯曲与继续拖动增益，旧存档保留原合法范围。

已验证：23 项几何/状态用例通过；新增 DISPLAY=:0 / SDDM 浏览器用例验证正面、斜视、按下偏移和继续拖动误差均小于 2px，新折形高度不超过 0.09（纸边长 2）。求解最多 6 轮、31 次几何评估，无迭代场景重建；复杂分区帧耗时及真机触控仍由既有性能待办跟进。

兼容回归：厚度、吸附、松手、刷新、继续调整、压平、撤销及预折痕双模式、整轮取消、双角鼠标触控全部通过。此次按影响范围分组通过 26 项（23 项几何/状态 + 3 组浏览器），未重跑与此次改动无关的独立分开及 HUD 专项。

外网：14 个资源 HTTP/大小/SHA-256 一致；公网硬件浏览器重复通过连续跟手、抓取偏移、斜视、再次拖动及低抬高专项，页面错误 0。

# 窗前折纸模拟器首版任务与验收记录

依据[设计](../design/gami.md)与[伪代码](../spec/gami.md)，拟新增独立网页目录 `web/gami/`，分开维护折纸几何、场景材质和交互入口。拟在子项目 tests 与 package.json 接入几何自测和网页验证。

| 阶段 | 可验收结果 | 粗估 |
|---|---|---|
| 首页与本机存档 | 验收首次和回访两种首页、横竖屏切换；先裁纸再摆两件作品，刷新后继续，逐件核对姿态；导出后重新导入副本，验证损坏文件不会覆盖原桌面 | 1～2 天 |
| 折纸几何 | 对角压折两次再撤销，逐步核对折轴固定、面积守恒、层序与背色；90°折形可立起 | 2～3 天 |
| 多角与整边 | 两角、四角向心折后整组撤销；重叠移动区保留预览；四条边分别向中线和对边折，检查两端同时对齐 | 1～2 天 |
| 程序声音 | 首次手势后试听拖折、压痕、裁切与落桌；四角同步无叠音；分别关闭音乐和音效、刷新复核，切后台再返回无音符堆积 | 1 天 |
| 水彩与裁纸 | 验证快捷 3×3、4×4 与手动 5×5、2×3、1×4 分别产出 9、16、25、6、4 张；空值、小数、零、1×1 和超预算输入不可提交，子纸面积之和等于母纸，纹理无断层，取消预览保留母纸 | 1 天 |
| 窗前课桌与陈列 | 截取平纸、抬角、双作品全景，对照窗光和接触阴影；移动作品后检查其余物件坐标 | 2 天 |
| 浏览器验收 | 桌面 Chromium 鼠标、移动浏览器触控各完成一次裁折摆放；16 张纸与两件作品同框连续拖动 30 秒，记录设备、分辨率和帧耗时，暂定桌面 60 fps、移动 30 fps | 1 天 |

风险集中在共面层闪烁、极窄碎面和移动端阴影成本。实现时按层序处理深度，合并容差内交点，低画质先降低阴影分辨率。设计假设为裁切产生独立小纸、放置对象为玩家自己折出的模型；任意非共面多轴连折留待后续评估。

发布阶段沿用 Pig-game 的静态游戏目录约定，将独立资源上传至公网游戏根目录下的 gami/，核对入口和资源摘要，并从目标地址实际走通首页、新建与继续。

首版静态资源已上传至 gami/，公网 HTTPS 七个文件逐项 SHA-256 与本地一致；实体移动设备性能采样待完成。

手工拖折交互验收：验证角与边自动识别、纸背吸附松手提交、折弯预览与平折数据分离，以及撤销后继续裁纸。

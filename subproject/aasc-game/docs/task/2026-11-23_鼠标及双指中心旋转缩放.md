# 2026-11-23 PC 右键/滚轮鼠标射线锚点与手机双指比例中心交互

## 任务描述
实现 PC 端右键旋转与滚轮缩放围绕鼠标下方地面射线交点进行，同时在移动端双指旋转与捏合缩放时以两指比例中心对应的地面点为锚点，实现零漂移焦点操纵体验。

## Design & Spec
- 见 [spec/pig-game-3d.md](../spec/pig-game-3d.md) 第 12 节（已先同步更新伪代码规格）。

## 受影响模块与代码
- `web/pig-level/3d/view.mjs`：
  - 新增 `pickGroundAt()` / `pickGroundTarget()` / `lockPivotToScreen()` 共用解析反解辅助函数与 `pivotMode`（`none`/`spin`/`wheel`）：不仅更新 `targetPan`，并在每帧按当前渲染姿态实时反解 `panOffset`（放宽至 `[-28, 28]`），彻底消除旋转/缩放过渡期间的弦线漂移；
  - 大幅收紧旋转惯性：`applySpin()` 上限降至 `2.6 rad/s`（瞬时角速度权重 `0.25`），`frame()` 指数阻尼增至 `8.5/s`，松手停顿 `> 45ms` 即零惯性过冲，滚轮缩放同步清空残余 `yawVel`；
  - PC 右键按下与滚轮缩放锚定光标处地面射线点；移动端双指旋转与捏合缩放围绕两指比例中心地面点进行；
  - 取消双击地面 `dblclick` 触发 `resetCamera()`，避免快速连点误触复位（保留 `V` 键与全息复位按钮）；
  - 暴露 `window.__pig3d.getGroundAtScreen(x, y)` 与 `window.__pig3d.projectWorld(x, y, z)` 供自动化检验。
- `web/pig-level/3d/holo-ui.mjs`、`web/pig-level/3d/post.mjs`、`web/pig-level/3d/view.mjs`（`?v=20261123g`）：修复移动端双指旋转或切换画质/横竖屏后全息 UI 可能消失的隐患——取消正交 HUD 的 `root.rotation.y` 偏航倾斜并设为 `DoubleSide` 与 `frustumCulled = false`、扩大 `uiCam` 纵深 `[-1000, 1000]`、将默认 `uClipRect` 改为 `[-32000, 32000]` 避免移动端 GPU `mediump float` 溢出，并在 `post.applyTier()` 降档时同步 `renderer.setSize()`、`low` 档渲染前调用 `renderer.clear()`，同时监听 `orientationchange` / `visualViewport` 并守卫双指手势有限值。
- `web/pig-level/{index.html,app.mjs}`、`web/pig-level/3d/*.mjs`：版本号统一升至 `?v=20261123g`。
- `tests/pig-level-3d.test.js`：补充 PC 偏心 `(300, 220)` 滚轮缩放（`< 6px`）与右键旋转（`< 8px`）地面点锁点精度检验，以及移动端偏心 `(120, 280)` 双指比例中心旋转缩放锁点校验（`< 8px`）。

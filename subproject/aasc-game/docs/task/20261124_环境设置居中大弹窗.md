# 任务：环境面板升级为居中大号弹出框

## 任务描述
将右上角偏小的侧边环境设置面板改为点击 `⚙ 环境` 时居中弹出的大号全息弹窗，放大 3 指针时钟圆盘与设置按钮尺寸，提升触控与桌面点击易用性，并适配竖屏与矮横屏。

## 设计与 Spec 依据
- 见 `docs/spec/pig-game-3d.md` 第 9 节。

## 受影响模块与文件
- `subproject/aasc-game/web/pig-level/3d/holo-ui.mjs`：将 `settingsBg` 与控件提升至弹窗层（`z = 8..9`），新增标题 `settings-title` 与关闭按钮 `settings-close`，放大至居中 `344×448`（表盘 `232×232`）及矮横屏双栏布局，扩展遮罩与点击穿透/滚轮拦截。
- `subproject/aasc-game/web/pig-level/index.html`、`app.mjs`、`3d/*.mjs`：升级缓存版本号 `?v=20261124e`。
- `subproject/aasc-game/tests/pig-level-3d.test.js`：补充验证环境设置弹窗居中显示、放大表盘点选与 `settings-close` 关闭交互。

## 自测与验证用例
1. 打开设置弹窗后验证 `settings-title` 居中、`settingsBg` 宽高放大且表盘扇区仍精准命中；
2. 点击 `settings-close` 可正常关闭环境设置弹窗，不触发底层棋盘；
3. 运行 `npm run test:pig-web`、`npm run test:pig-animation`、`npm run test:pig-3d` 全部通过。

## 风险评估与预计工时
- 低风险，预计 20 分钟内完成修改与测试验证。

## Spec（实现前补到 `docs/spec/pig-game-3d.md`）
```
// 已确认：棋盘不抬高；玩法坐标零改动
createScenery(level, tier, decor):
    buildBorderFrame(cols, rows)  // 合并网格：贴地圆角原木框(高 0.12) + 四角短桩 + 下沉土带卵石
    buildLawn(lawnTex + gridLines(alpha=0.06) + occupancyAO)
    flowers = FLOWER_MODE[tier]       // high: 花带+摆动, medium: 花带静止, low: 收紧聚簇散花
    buildFlowers(flowers, cap = TIER_CAP.flowers)
    buildBushClusters(count = TIER_CAP.bushes)
    buildPond(position = 左下中环)
    buildFenceLights()                // 冬季/铁笼月夜显示
    buildTreeLine(count = tier == low ? 0 : TIER_CAP.treeLine)
    setDecor(decor)                   // 只切换 visible
loadDecorPrefs():                     // localStorage pig3d.decor.{pond,lights,flora,treeline}，读不到时默认全开
    try 解析 catch 使用默认值
    applyPreset(preset): 写入 palette（lawnLit/lawnShade/frame/soil/accent/shadowTint）
updateOccupancyAO(board):  // 每次关卡加载或一步结算后调用
    for each cell: ao[cell] = 被占用 ? 0.9 : 1.0；相邻猪之间的接缝 = 0.82
post shader:
    col = saturate(col, uSaturation)
    col = splitTone(col, shadowTint, warmTint, 0.12)
    col += bloom(tier)；col *= paperGrain(tier)
```

## 受影响模块与代码（预计）
- `web/pig-level/3d/scenery.mjs`：地台、花带、灌木、池塘、林线、栅栏加粗、树冠细分与位置内收
- `web/pig-level/3d/presets.mjs`：新增 `palette` 字段、铁笼 `dusk` 下限（`0.85`），以及下调阴天（`sun 0.85 / hemi 0.54 / ambientScale 0.80`）与雨天（`sun 0.58 / hemi 0.44 / ambientScale 0.68`）光照与环境光倍率
- `web/pig-level/3d/models.mjs`：猪的轮廓光、个体色差、移除底部暗椭圆贴片、`uLightDir` 实时同步太阳方向；铁笼加粗和发光计数牌
- `web/pig-level/3d/environment.mjs`：逆光轮廓光、半球光取季节色、地面距离雾
- `web/pig-level/3d/grass.mjs`：统一世界坐标云影、AO 采样、`medium` 54k / `low` 28k 密度提升、根部无缝衔接地面/草坪色及冷暖多色草叶变化
- `web/pig-level/3d/post.mjs`：修复饱和度空操作，加入冷暖分离、medium 档柔光和纸纹
- `web/pig-level/3d/view.mjs`：读取装饰偏好并传给场景；保持现状默认俯角（保留 `DEFAULT_PITCH` 常量）
- `web/pig-level/3d/holo-ui.mjs`：环境设置抽屉新增“装饰”开关行（池塘/灯串/花带灌木/远景林线）
- `web/pig-level/3d/textures.mjs`：花瓣面片、落叶/落樱贴花、纸纹、格线
- `tests/pig-level-3d.test.js`：新增像素取样验收

## 自测用例
1. 第 48 关（春）、第 70 关（秋）、第 61 关（铁笼）、第 100/113 关（冬）分别截图，对比地台与外草地的亮度差 ≥ 10%。
2. 冬季阴影取样 B > R + 15。
3. 横屏 1280×720 与竖屏 390×844 下至少 2 棵完整树；花带或池塘可见。
4. 点击猪、离场动画、小鸭寻路、炸弹爆炸的位置与改动前一致（棋盘不抬高，坐标零改动）；离场滑过贴地木框时不被遮挡。
5. 装饰开关：4 个开关切换即时生效，刷新后保持；清空 `localStorage` 后默认全开。
6. 花分档：`?tier=high/medium` 显示花带，`?tier=low` 显示收紧散花。

## 风险评估
- 贴地木框与离场轨迹重叠：木框高度限制在 0.12，低于猪身中线。
- 花带和灌木遮挡离场轨迹：近环景物高度限制在 0.6 以内，并离开棋盘出口方向 1 格。
- 后期 pass 增加开销：medium 档只开柔光和冷暖分离，并合并到同一 pass。

# 折痕与预折痕双模式

状态：合并功能、完整回归及公网资源发布验证已完成。

需求与设计：见 design/gami.md 双模式章节。实现伪代码：见 spec/gami.md 双模式章节，先更新伪代码再修改代码。

涉及模块：web/gami/index.html、style.css（模式与确认反馈）；app.mjs（模式状态及原子确认）；held-fold.mjs、paper-topology.mjs（原姿态分区、折痕记录及层位移映射）；tests/gami.test.js（回归）。

验收：两模式结果不同；预折痕前后空间位置/纸形/层次相同，材料分区可细分；原折痕保留，新折痕交点可拾取并可用于后续折叠；取消/无效操作不留痕；撤销、刷新和导入导出一致；旧存档兼容；390px 窄屏可操作；多分区保持现有拓扑及接触预算。

风险：直接追加线条而不细分面片会导致折痕不可实际旋转；直接使用零角度折叠输出可能改变原层序，需按来源面映射原层位移；不能把恢复原姿态实现为清空历史。公共平面限制需明确展示。预计工时：实现与回归约半个工作日；实机触控体验独立验收。

已确认：按用户命名，折痕模式保留折后纸形；预折痕模式确认时留痕并还原，而非拖动松手即自动提交。

补充范围：弯折时显示材料角点球，新增取消未完成弯折按钮。新增影响 scene.mjs 的标记生成，app.mjs 的手势清理和按钮状态，index.html/style.css 的公共取消入口。

补充验收：拖动中与松手待压平角点球贴合实际表面，条带细分不产生额外球；多次继续调整后取消恢复本轮起折前状态；原折痕与层位移保持；取消后松手不重新提交；刷新无待压平状态；无待处理状态按钮隐藏；预折痕确认与取消结果明确区分。拟使用 DISPLAY=:0 npm run test:gami 及窄屏图形浏览器回归。

# 猪关卡引导手指识别和位置标注

需求：检测游戏画面引导手指，降低遮挡引起的朝向错误；在标注图片中同时展示各猪位置及朝向。遵守只读取截图的约束。

设计与伪代码：参见 docs/design/pig-game.md 和 docs/spec/pig-game.md。涉及 scripts/extract-pig-level.py、游戏画面导出的手指模板、tests/pig_level_extractor_test.py 和使用文档。保留原图，不覆盖历史输出；手指匹配不可靠、眼睛受遮挡时方向为未知。

自测：第一关有手指、第二关无手指、遮挡未知、坐标方向表与 JSON 对应、重复输出保护和原识别回归。兼容性：Linux X11、已有 PNG、不同截图比例；模板和 UI 变化可能需要更新。性能：记录第一、二关处理耗时。风险：模板误检、手指遮挡眼睛、提示红框影响方向、密集排版。预计 0.5 天。已实现：第一关手指及遮挡小猪识别，截图右侧按编号列出位置朝向，第二关不误识别；缩放 0.75、1.0、1.25 参考图检测通过。

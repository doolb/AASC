# 2026-11-23 反转镜头拖拽交互与局域网 HTTP 高画质适配

## 任务描述
按确认将 PC 与移动端镜头拖拽交互反转（PC 左键/手机单指改为平移，PC 右键/手机双指改为旋转，保留双指捏合缩放），并修复桌面端在非 HTTPS 局域网地址下因浏览器隐藏 `navigator.deviceMemory` 而误落入 `medium` 档的问题。

## Design & Spec
- 见 [spec/pig-game-3d.md](../spec/pig-game-3d.md) 第 11、12 节（已先同步更新伪代码规格）。

## 受影响模块与代码
- `web/pig-level/3d/view.mjs`：
  - 将 `activePointers.size === 1` 的非右键拖拽从旋转切换为 `applyPan(dx, dy)`（保留 `<= 8px` 短按点击小猪 / UI）；
  - 将 PC 右键拖拽（`rightRotating`）改为调整 `targetYaw` / `targetPitch`（继续全局拦截 `contextmenu`）；
  - 将移动端双指（`activePointers.size === 2`）拖动改为旋转视角（调整 `targetYaw` / `targetPitch`），同时保留捏合距离缩放 `targetZoom`；
  - 暴露 `window.__pig3d.getCameraState()` 供测试校验视角状态。
- `web/pig-level/3d/post.mjs`：
  - `detectInitialTier()` 在非移动端且 `cores > 4`、但浏览器因非 HTTPS 上下文未暴露 `navigator.deviceMemory` 时默认按 `8GB` 回退，使局域网 HTTP 下多核桌面端也能默认进入 `high` 档。
- `web/pig-level/{index.html,app.mjs}`、`web/pig-level/3d/*.mjs`：资源版本号统一升至 `?v=20261123b`。
- `tests/pig-level-3d.test.js`：补充 PC 左键平移/右键旋转及移动端单指平移/双指旋转缩放测试。

## 自测与验收结果
- 自动化测试（`npm run test:pig-web` `118 / 118`、`npm run test:pig-animation` `1 / 1`、`npm run test:pig-3d` `4 / 4`）全部通过。

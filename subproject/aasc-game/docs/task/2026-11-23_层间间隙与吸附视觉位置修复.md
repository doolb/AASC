# 层间净间隙与吸附视觉位置修复实现与验收

## 问题、证据与目标

用户反馈“重叠之后应该还有间隙，还有吸附的角度和视觉上位置不一样”。本次按层间净间隙及角点吸附视觉位置偏差处理。

只读复现：两面平折纸在厚度 0.002、0.008 和 0.02 时，`layerDisplacements` 的层中心距均等于纸厚，因此扣除两侧半纸厚后净间隙为 0。`paperControls` 计算表面位置，但 `projectedCorner` 和橙色指示仍按零高度绘制；继续拖动时混用这两种屏幕位置。

拟保留纸厚 25% 的净间隙，统一物理层间距和接触规则；吸附目标、橙色标记、纸角拾取与继续拖动统一使用可见表面锚点。材料角点对齐时保留真实层高造成的视差。需求见 `../design/gami.md`，执行伪代码见 `../spec/gami.md`。

## 需求分析（analyze-requirement-level，enterprise）

- 结论：方案可开发，具体代码修改范围已由用户确认。主等级 L6、次等级 L5，邻层混合。
- 强证据：几何层间距与接触参数为 L6；可见锚点、标记及投影契约为 L6；旧存档迁移、释放和撤销一致性为 L5。
- 置信度：6 / 9 × 0.90 = 0.60，中。评分：层级清晰度 24/25、证据充分度 18/20、实现完备度 17/20、风险暴露度 18/20、L4 可落地性 14/15，总分 91/100。
- 风险：中。旧层位移重复放大和屏幕重合被误解为材料重合；分别通过间距规则标记及表面锚点处理，保留物理层高。
- 下放判定：必须下放到 L4；按 spec 拆成间距读取、兼容恢复、接触候选、锚点定位、投影及存档恢复数据流。不自动调用额外翻译或同步技能。

## 受影响文件与实现步骤

1. `web/gami/paper-topology.mjs`：层中心距、表面锚点所需的材料定位和旧层位移读取规则。
2. `web/gami/paper-contact.mjs`：折痕运动、厚度变更和接触检查纳入净间隙。
3. `web/gami/scene.mjs`：统一投影、可见拾取和橙色标记实际位置。
4. `web/gami/app.mjs`、必要时 `held-fold.mjs`：吸附目标保存材料锚点，继续拖动使用同一投影，兼容已有存档。
5. `web/gami/fold.mjs`：在既有平面容差校验后恢复精确公共平面，平折输出精确零高度，避免残差导致漏分层。
6. `tests/gami.test.js`：增加间隙、投影、视角和存档回归；同步设计、伪代码、使用说明、目标、任务、待办和日志。

## 自测与兼容性

- 两层及多层平折，最薄、默认和最厚纸张，验证表面净间隙大于零并与厚度成比例；立起及背面法向同样成立。
- 正面、背面和旋转/缩放视角，标记中心投影与实际目标角表面锚点一致；最厚纸张下也不出现零高度偏差。
- 角点吸附、释放、刷新、再次拖动、压平和撤销；目标材料角对齐且真实层位移保留。
- 旧存档、已保存的非共面层位移、导出导入及反复刷新，验证兼容转换不会重复放大。
- 回归厚度滑块、改厚度的接触扫描、已有折痕展开和内部交点操作。
- 使用既有 `npm run test:gami`，浏览器用 `DISPLAY=:0`、SDDM 硬件 WebGL；真实移动设备保留待办。

## 性能、风险及预计工时

复用现有材料拓扑缓存和接触预算，不逐帧重新迁移存档。增加间隙可能使复杂旧纸形更早触发接触，需要保留原有效状态及提示。预计 0.5～1 个工作日，取决于多层存档兼容和不同视角回归。方案已由用户确认；完成后发布外网，验证资源大小及 SHA-256，并只上传折纸相关 Git 改动。

## 实现记录

- `layerPitch` 统一使用纸厚的 1.25 倍，实际纸面正背表面仍只偏移半个纸厚；接触包络包含净间隙。
- `layerSpacingVersion: 1` 标记新的层位移。旧存档通过过渡扫描后转换并保存一次；失败保留原层位移，展开时按旧距离检查，完全展平且新间距检查通过后再记录新版本。
- `surfaceProjection` 统一拾取、实际材料点投影及橙色标记。手工吸附保存目标材料 UV 到 `heldFold.snapTarget`，预览期间重新定位目标；继续拖动恢复原目标并从可见纸尖投影起算。
- 浏览器回归发现边中点和鼠标反投影仍使用零高度会使第二条折线偏移；边中点改为在所在面插值，拖动射线改为与所选表面高度平面相交。
- 自测增加四层纸正面、竖起及翻面间隙，旧层位移重复刷新和非共面兼容，失败保留及旧距离展开；浏览器在最厚纸、旋转和背面视角下，直接读取截图橙色像素的中心，与实际材料表面投影比较，容差 1.5 像素。
- 多次折叠回归捕获到约 `1.14e-8` 的高度残差，使新平折的固定面与翻折面被误分为不同平面。新折线只在原有公共平面容差通过后复制到精确零高度，并对 0/±180° 使用精确零正弦；原存档与接触容差保持不变。
- 另补充面积 `7.2e-9` 的真实重叠三角片：旧面积阈值漏分层而接触检查判为穿透。共面重叠改用与接触相同量纲的线性投影检查；公共边和微小坐标噪声不额外分层。
- 操作点提示按实际层位移去重，随相机更新正背表面偏移；避免厚纸提示点仍在中面，或叠层只保留最低一层的提示点。
- 截图测量使用无光照橙色标记的恒定 RGB 众数隔离暖色纸面纹理，避免背面视角下颜色阈值混入纸面像素；位置容差仍为 1.5 px。

# 任务：恢复小猪身上拖动平移相机并修复旋转视角后引导手指偏移

## 任务描述
1. 恢复在小猪身上左键/单指按下拖动时的相机平移体验（保留拖动超过 8px 抬手不误触发点击离场）。
2. 修复旋转视角（改变 `yaw`）后 3D 新手引导手势精灵 `handSprite` 偏移目标小猪的问题。

1. 第 1 关右键旋转视角（>90°）前后，验证 `getGuideHandScreen()` 与 `screenOf(1)` 间距均紧贴目标小猪范围内（不漂偏）；

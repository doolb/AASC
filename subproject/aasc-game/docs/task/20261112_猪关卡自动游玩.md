# 猪了个猪自动游玩（已实现，实机待验收）

需求：由脚本自动判断并操作关卡，无需人工逐步思考；首次操作前保存当前状态与候选布局并记录通关画面；仅处理当前关，不切换关卡。只访问 Linux X11 截图与输入。

设计和伪代码：docs/design/pig-game.md、docs/spec/pig-game.md；新增 scripts/play-pig-level.py、对应测试和 package.json 命令，复用现有提取器。每次选择、X11 输入后截图确认、可终止及无进展退出；记录独立逐关证据，不覆盖原数据。

自测：阻挡关系、候选排序、第一关手势人工值匹配、流程状态、卡住/遮挡/失焦停止、证据先于点击、通关后记录并停止、禁止点击下一关、模拟输入与 X11 受控实测。兼容性：Linux X11、现有 Python/OpenCV 和 ImageMagick；当前游戏窗口可用时才做实机验证。性能：点击后等待动画稳定，记录每关时间及截图间隔。风险：视觉误检和未观察规则、道具可能涉及消耗；禁止自动执行未验证的消费/广告动作，无法继续时保存记录并报告。预计 1–2 天。

验证：`npm run test:pig-play` 6/6，覆盖阻挡、已记录首关手势方向的布局匹配、先保存后输入、通关停止、无进展上限和画面变化停止；`npm run test:pig-extract` 7/7。活动窗口目前不是游戏容器，未执行真实 X11 点击和真实通关验收。

用户确认修复实机缺陷：第 2 关约剩 21 只候选时，脚本会继续选取已判定有阻挡的目标；动画造成坐标漂移，某些目标重复尝试。按用户要求每步重新计算阻挡与可移动猪，只点击可信的无遮挡目标；将中间截图改为内存识别、仅关键画面落盘。自测需覆盖密集阻挡、未知方向、动画漂移、无可移动目标停止与点击后重算。

修复已实现：只点击经最新两帧识别一致并判为无遮挡的目标；方向在未知与已知间波动时保守标为未知，位置变化用容差匹配；没有可靠目标标记 stuck，默认保存开始及结果截图，可通过 --save-steps 额外留存逐步截图。`npm run test:pig-play` 9/9。

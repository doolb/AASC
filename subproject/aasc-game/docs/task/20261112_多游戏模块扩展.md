# 多游戏模块扩展（源码已实现）

任务：将现有五子棋项目演进为可扩展游戏平台注册表和房间协议，五子棋为首个正式模块，后续按需求增加游戏。设计与伪代码分别见 `docs/design/game.md` 和 `docs/spec/game.md` 的多游戏章节。

影响：`client.js`、`game-host.js`、`server/relay.js`、Android `RoomServer.java` 与网页入口；新增共享注册表、五子棋规则/渲染模块及适配层、定向测试。具体落点按实现拆分。

自测：游戏目录、建房及加入、不同游戏房间隔离、游戏协议不兼容和非法命令拒绝、不同人数上限、断线恢复、五子棋完整对局。兼容性：现有网页/APK 邀请、消息、局域网房主及旧存档；性能：房间并发、模块加载、消息大小；风险：旧协议迁移和 APK 原生服务与 JS 规则重复维护；预计工时 3–5 天。测试用第二模块只用于验证扩展接口，不作为正式游戏发布。

结果：共享目录与模块入口、五子棋模块、按游戏约束人数和操作的中转、原生 `NativeRoom` 适配入口已实现。`npm run test` 6/6 通过，包括真实浏览器三人测试模块、五子棋与旧邀请/存档恢复、原生服务兼容；调试 APK 构建成功。本机 30 房间握手抽样 454 毫秒；真实 Android 多设备验收仍待完成。

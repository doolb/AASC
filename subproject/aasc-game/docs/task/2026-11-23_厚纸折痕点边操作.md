# 有厚度的折纸、折痕与点边操作实现与验收

## 任务描述

按 [设计](../design/gami.md) 和 [伪代码](../spec/gami.md) 引入纸张厚度、层间接触、持久折痕及直接通过点边折叠和展开。原纸边界与折痕交叉产生的点和边均应可操作；展开不限定为撤销最近一步。

## 受影响模块

- `web/gami/fold.mjs` 与新拓扑/接触模块：维护原纸坐标、点边面连接、折痕交点、纸层和折叠姿态。
- `web/gami/scene.mjs`：绘制纸面厚度、边缘、正反面及折痕；支持可见点边拾取。
- `web/gami/app.mjs`、`held-fold.mjs`、`index.html`：点边手势、活动侧选择、拖动折叠/展开、存档与导入校验。
- `tests/gami.test.js` 及必要的浏览器自测：覆盖几何拓扑、碰撞、持久化和操作。

## 验收

1. 连续压折后层间可分辨且不互相穿透；同一点/边从正面和背面拾取的是可见层，快速拖动不穿过已检测到的接触面。
2. 两条折痕交叉后出现新的可拾取交点和被分割的边；拖动交点可建立新折线，拖动已有折痕边可展开或重新折叠对应纸瓣。
3. 展开后折痕保留；多次折叠、展开、撤销、刷新、本机继续、导出和导入后点边连接关系与纸形一致。
4. 旧存档能打开且不凭空生成无法恢复的历史折痕；原有角点吸附、多角、整边、裁切、陈列和声音分别回归。
5. 桌面 `DISPLAY=:0` 硬件 Chromium 测试鼠标交互；移动触控及多层折形需设备实测，记录帧耗时、测试规模和未覆盖的复杂碰撞场景。

## 风险、边界与预计工时

内部折痕活动侧根据可见命中面和拖动方向决定。厚度接触、自相交、折痕多次相交和共线重叠都可能使求解复杂；遇到无有效结果的操作应保留上一个有效状态。逐项实现并验证拓扑、接触、交互、存档及兼容性，初估 5～10 个工作日，实际取决于复杂折形的接触求解与设备性能。

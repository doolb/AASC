# 猪关卡条件死锁与假设分析

## 任务描述

在不使用道具的前提下，为弹簧猪关卡增加离线条件死锁分析，输出可复核的最小假设变化，辅助寻找可用解法。

## 设计需求

根据 `subproject/aasc-game/docs/design/pig-game.md`，分析受阻依赖时只把现有识别和碰撞规则作为显式假设；生成的反事实不能被当成已验证布局或可点击路线。

## spec 设计

根据 `subproject/aasc-game/docs/spec/pig-game.md`：将棋盘中可能移动的棋子乐观移除，迭代得到条件固定集合；枚举有限的方向及弹簧碰撞假设，输出是否消除固定集合、证据依赖和未验证状态。仅支持普通猪、弹簧猪且无额外障碍的单格宽棋盘；其余机制拒绝分析。

## 受影响模块和代码

已新增 `subproject/aasc-game/scripts/pig_hypothesis_solver.py` 和 `tests/pig_level_hypothesis_test.py`，在 `subproject/aasc-game/package.json` 添加离线分析和测试命令。

## 自测用例

固定闭环、翻转方向解除固定集合、碰撞假设解除固定集合、未知编号拒绝、未支持机制拒绝、畅通棋盘不误报；第 92 关还应识别两组独立闭环，且假设输出永远不可直接点击。正式专项 7 项已通过，普通求解、锁猪、启发式及弹簧回归共 34 项通过。

## 兼容性测试

不改变现有求解、执行及数据格式；对不支持的鸭子、炸弹、锁、障碍或宽棋子显式拒绝，不猜测行为。

## 性能测试

16 个固定棋子的第 92 关枚举单项和双项变化应在本地短时间内完成；较大候选集应设枚举上限。

## 风险评估

条件固定集合依赖方向、占格及弹簧碰撞假设；解除固定集合仅是必要条件，不证明完整解。截图或实机证据冲突的假设不能执行。当前游戏窗口不在活动状态，实机试探被保护机制阻止。

## 预计工时

约 1–2 小时，含正式集成、回归和文档；真实关卡求解耗时不确定。

# 剪刀猪和捆绑猪自动游玩

- 任务：接入剪刀离场逐根解绳，继续第 41 关与后续关卡采集。
- Design / Spec：见猪游戏设计和实现伪代码；锁定时捆绑猪占位不可点，与鸭子共同搜索并验证。
- 影响：特殊外观识别、搜索、独立重放、现场核验及相关测试。
- 自测：锁未解除不可移动、剪刀移动不算离场、多剪刀逐根解锁、鸭子共存、计划独立重放和实机状态偏差停止。
- 兼容性：普通、数字锁和鸭子关卡行为保持；识别不确定时保留现场。
- 性能：复用有界搜索，超过预算停止；不得声称搜索超时即无解。
- 风险：图案遮挡可能影响方向、占格和检测；实机动画需核验。
- 预计工时：约 4 小时。
- 补充：识别红色高亮并标记对应猪为游戏提示可点，检查实际高亮帧和邻近猪的误关联；方向独立判断。
- 后续实机：第 43 关锁与小象混合；搜索预算内未找到完整解时，使用游戏唯一红框提示走一步，确认后重新搜索并累计留证。
- 补充：自动判断已复核朝向的小象前方通路，开放时尝试移动并确认离场，避免把可移动小象永久视为固定阻挡。

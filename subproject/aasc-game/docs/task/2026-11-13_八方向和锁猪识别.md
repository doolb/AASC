# 八方向和锁猪识别

- 任务：优化固定八方向识别，区分黄色锁与鸭子。
- Design：主轴、头部特征与候选方向评分交叉校验；锁猪未经方向和数字复核不得自动执行。
- Spec：见 `docs/spec/pig-game.md` 八方向与黄色物件复核。
- 影响：提取、黄色候选检测、自动游玩与回归测试。
- 自测：八方向及遮挡、红色高亮、第 34 关锁和已记录鸭子样本。
- 兼容性：保持现有候选字段，无法确认的方向仍为 unknown。
- 性能：模板匹配仅限黄色候选区域，检查截图处理时间。
- 风险：外观变化、遮挡、动画可能导致误识别；低置信度停止自动操作。
- 预计工时：约 2 小时。

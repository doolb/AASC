# 占格对照补充（2026-11-13）

用户补充：小象未移动因前方阻挡，未知物件默认按障碍考虑。求解器对暂定阻挡格做重叠、边界校验，将其加入移动和鸭子路径判断；验证阻挡移动、鸭路封闭和候选复算。固定阻挡不会证明未知物件已离场；仍需完成第 21 关占格取证和高棋盘兼容。预计工时 1 小时，路径计算保持线性占格构建及原有搜索复杂度。

用户进一步授权按图像框估计未知物件占格并运行到卡关：自动采集标记网格及重叠冲突，阶段搜索与快速后备使用相同障碍并逐步核对；阶段终点不是通关。新增映射、碰撞和快速搜索兼容测试，搜索复杂度仍受状态上限限制；视觉框随动画浮动及真实碰撞不等于外形是风险，现场不符即停止。第 21 关连续自动流程原本就覆盖完整棋盘；之前提取小区域属于单次提取参数问题。

用户澄清仍需搜索，但阶段目标不必整关通关：新增 `scripts/unlock-pig-object.py` 与 `unlock:pig`，以释放小象前方为目标遍历状态，优先边缘可离场猪并保存计划后逐步验证；可选推进小象并重复。第 21 关第一阶段一只猪移动一格，小象随后向下移动一格；继续执行后续阶段。自测阶段搜索达到目标、搜索上限及矩形物件全宽阻挡；搜索时空复杂度取决于访问状态上限，图像误差或实际动作不符需停止排查。预计工时 2 小时。

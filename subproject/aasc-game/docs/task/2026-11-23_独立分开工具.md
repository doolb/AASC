# 独立分开工具

用户已确认推荐方案：独立「分开」工具，通过点和边沿已有折痕真实展开压平纸瓣。需求及交互见 `../design/gami.md`，实现先按 `../spec/gami.md` 的声明级伪代码执行。

## 需求分析

使用 analyze-requirement-level 的 enterprise 模式。主等级 L6（点边关联已有折轴、可见投影与接触契约），次等级 L5（切换、松手、取消和撤销）；三条证据为独立工具入口、折痕高亮及点边展开、松手保持和物理约束。邻层一致性 0.90，主等级证据权重 6/9，置信度 0.60。评分 24/25、18/20、18/20、18/20、14/15，总分 92/100；结论可开发，风险中，必须下放到 L4，按已有拓扑、候选轴、可见投影、接触预览和提交数据流实施。不自动调用其他技能。

## 实现与影响范围

1. `web/gami/index.html`、`style.css`：分开工具及窄屏布局。
2. `web/gami/separate.mjs`：可见点边对应的材料面与折痕候选，不生成新折线。
3. `web/gami/app.mjs`：分开手势、展开轴选择、安全预览、取消及松手保存。
4. `web/gami/scene.mjs`：折痕高亮、所选轴及试转投影；复用表面遮挡检测。
5. `tests/gami.test.js`：候选材料轴与真实浏览器鼠标/触控回归。
6. 同步 usage、goal、design、spec、todo 和 changelog，验证后提交 Git 并按已有授权发布外网。

## 自测、兼容性与性能

- 压平后从角点、边界中点和折痕展开；原折痕及 UV 保持，不能产生新折线。
- 无折痕、待压平、已摆放纸张不被意外修改；多折痕先选轴，交点仍可用。
- 松手保持、刷新、撤销、pointercancel 和工具切换；旧存档和现有折叠吸附流程回归。
- 多层纸受阻保留安全状态，沿用纸厚和间距版本；背面/旋转视角及 390×844 触控布局。
- `DISPLAY=:0 npm run test:gami`，SDDM Chromium 硬件 WebGL；沿用接触预算，不增加常驻动画循环。

## 风险与工时

多个折轴可能对应同一点，优先采用用户已选轴并允许点折痕重新选定；弯折轴及复杂耦合仍遵循已有提示。真实设备触控性能沿用待验收项。预计 0.5～1 个工作日。当前无待确认需求。

## 实现记录

- `separate.mjs` 按拾取的材料面过滤已有折痕；点和边界匹配同面最近折轴，交点分段按同一材料直线匹配，支持先点折痕选轴。
- `app.mjs` 新增独立工具分支，沿用 `safeTurnCrease` 接触扫描，以小角度候选的表面投影确定拖动方向；分开提交不依赖折法菜单当前是否为手工模式。
- `scene.mjs` 将普通折痕和所选轴分色，点标记使用青色；投影候选可显式传入物理层位移。点边可见性继续由原表面射线检测决定。
- 待压平、无折痕及已摆放纸张保留原形；切换工具和 pointercancel 丢弃临时预览，松手保存、撤销和刷新沿用原版本 1 数据。
- 浏览器自测通过真实 JSON 导入加载各样纸，避免旧确认按钮被异步导入替换造成测试误点；刷新等待使用与原有测试相同的 120 秒上限。390×844 使用视口缩放加 CDP 触控事件，真实设备性能仍保留为待办。

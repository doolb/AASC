# 折纸松手保持折形

## 任务与设计

依据 [设计](../design/gami.md) 和 [规格](../spec/gami.md)，让手工折纸松手后保存当前弯曲形态，可再次拖动调整，显式压平后继续加工。

## 影响与实现

先更新设计和伪代码，再修改 `web/gami/` 的几何状态、交互和工具栏；扩充 `tests/gami.test.js` 及浏览器交互自测。同步使用说明、待办与变更日志。

## 验收

- 手工角折、边折松手后形态不变，停留、环视和刷新后仍保持；继续拖动不跳变，压平后可继续折和撤销。
- 无效拖动、取消或指针中断不会覆盖之前的形态；切换纸张及多纸状态各自独立。
- 存档导入导出支持待压平状态，旧版存档继续可读，非法状态拒绝导入。
- 测试鼠标、触控、正反面、角点吸附和原有精确折法；真实移动设备触控验收如暂不可用须记录。
- 以原有曲面条带数量为预算，拖动保持现有渲染开销；确认无计时器自动改变折形。

## 风险与工时

非共面纸瓣的再次拾取与操作平面投影会受极端侧视角影响；几乎平行时保留上次有效形状。预计 0.5～1 天；实际移动设备性能和手感需后续验收。

## 验证记录

`npm run test:gami` 覆盖折形重建、旧存档、非法状态、反向调整曲率与精确压平；指定 `DISPLAY=:0` 运行时另以 Chromium 验证松手、保持、刷新、继续拖动、指针取消、压平和撤销。桌面图形会话使用 Intel HD 610 硬件 WebGL。实体移动设备的触感、性能和双指手势仍需实机验收。

## 角点吸附修复

现象：手工折角提示已吸附，但弯纸仍带有高度和位置偏移，松手后纸尖未到目标。依据设计和伪代码，手工角点锁定时收平弯曲量，使纸尖与目标点重合，同时保留待压平事务和自由拖动。验收覆盖鼠标及触控容差、两面折向、松手后存档重建、撤销、再次拖动和脱离吸附；原有精确折角与未吸附弯纸行为保持兼容。风险为吸附时形状变化较快；当前几何模型需要收平才能保证贴合。估计 0.5 天，性能保持现有几何预算。

验证：`DISPLAY=:0 npm run test:gami` 6 项通过，鼠标拖至目标角后检查纸尖三维坐标、松手存档、刷新恢复、继续调整、取消和撤销；公网 Chromium 复测吸附、松手、继续和压平通过，8 项资源大小与 SHA-256 一致。两面几何由单元测试覆盖，真实移动设备手感及性能仍待验收。

3. 美化网页界面视觉与交互体验，重点修复顶行及边缘小猪的提示标识（`.hint-arrow`）有时会被 `.board { overflow: hidden }` 裁剪的问题。

## 2. Design 需求与 Spec 设计
- **规则引擎扩展**（[engine.mjs](file:///mnt/AASC/subproject/aasc-game/web/pig-level/engine.mjs)）：
  - `spring` 弹簧猪：移动前遇任意阻挡时弹回原位（即使途中已滑过空格仍返回 `ok: false`）。
  - `elephant` 大象猪：兼容带 `shape` 的直出大象与矩形 `width=2, length=3` 的滑行大象，离场递增 `exitCount` 并校验无遗留鸭子。
  - `timer_bomb` 计时炸弹：记录 `timerSeconds`，碰撞普通猪可停靠不引爆，离场正常计数。
  - 无步骤关卡（`steps: []`）：`verifyPlan` 在空步骤时校验 `createState(level)` 合法性并返回 `true`。
- **界面与防裁剪**（[style.css](file:///mnt/AASC/subproject/aasc-game/web/pig-level/style.css)、[app.mjs](file:///mnt/AASC/subproject/aasc-game/web/pig-level/app.mjs)、[index.html](file:///mnt/AASC/subproject/aasc-game/web/pig-level/index.html)）：
  - 拆分 `.board-backdrop`（负责 `overflow: hidden`、浅草地渐变与隐约网格底纹），`.board` 改为 `overflow: visible`，同时对 `y === 0` 的顶行小猪确保 `.hint-arrow` 位于高层级且有上边距安全区，彻底消除提示裁剪。
  - 美化猪 SVG（耳朵、猪鼻与鼻孔、卷尾、面部红晕）、弹簧蓝圈、计时炸弹秒数胶囊、铁笼栏杆及卡片质感；新增快捷上下翻关按钮、受阻轻晃反馈与键盘快捷键（`ArrowLeft`/`ArrowRight`/`z`/`r`/`h`）。

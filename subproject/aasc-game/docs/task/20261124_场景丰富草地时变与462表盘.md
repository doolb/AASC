# 任务：参考概念图丰富场景细节、草地全时段光照、夜晚月色强化与 462×462 大表盘

## 任务描述
1. 严格参考 `concept_spring_1795316035738`、`concept_winter_1795316060759` 与 `night_moonlight_concept_1795524058937` 的物件细节、布局定位与氛围色彩重构场景（粗段原木围框+立柱+雪顶、带右前短段与左前池塘豁口的粗柱栅栏及冬暮灯串、原木双窗人字顶高脚木屋、中偏右山脊风车、角隅三簇灌木+围巾雪人、四角三层雪松与樱花树描边、走廊聚簇花丛、春季柔和晨雾与冬季粉紫暮雪天空、午夜深靛星月氛围）。
2. 修复草地着色器与环境光照：接入写实 24h 日光光谱 `SOLAR_24H_STOPS`（日出桃金→正午纯白→夕阳橘红→午夜银蓝），大幅压低夜晚补光使草地与地形真实进入深靛月夜，仅草尖保留月光银蓝轮廓高光。
3. 升级角色材质 `toonMat`（猪 / 鸭 / 象）：保留原 Painted Valley 水粉双阶哑光质感与 `topRim`，动态跟随太阳/月亮主光方向与 24h 色温 `setLightState`，仅在明暗交界线处精准叠加暖桃粉次表面散射 (SSS) 透光带。
4. 将桌面端环境设置弹窗中的时钟圆盘尺寸升级至 `462×462`（移动端按安全视口自适应等比最大化）。

## 自测与验证用例
1. 切换 `早/中/晚/夜` 时，验证 24h 日光色彩真实演变（早暖金、正午纯白、晚橘红夕照、夜银蓝月光），草地着色器与猪模型 `uLightDir` / `nightMix` 同步跟随主光源移动和变色；
2. 验证桌面端 `1280×720` 下设置弹窗表盘尺寸达到 `462×462`，各扇区点击准确且不溢出视口（含 `390×844` / `360×640` / `844×390`）；
3. 运行 `npm run test:pig-web`、`npm run test:pig-animation`、`npm run test:pig-3d` 全部通过。

# 第48关静态网页

- 任务：根据截图布局与候选步骤实现离线可玩的静态网页，使用 `/?level=48` 选择关卡。
- Design：固定 48 关，三只剪刀猪离场各解除一根绳，绳子解除前不能点击绳猪；支持回放、进度条、提示开关、自由点击与撤回。
- Spec：见 `docs/spec/pig-game.md` 第48关静态网页与步骤回放；启动时独立重放并验证计划。
- 影响：新增静态游戏页面、游戏引擎、关卡数据、启动脚本和自测，不依赖本地忽略的 references。
- 自测：176 步完整重放、绳猪阻止与解除、碰撞和边界、撤回、进度跳转、偏离提示、移动端交互。
- 兼容性：独立静态目录，可由任意静态 HTTP 服务发布；不修改现有联机入口。
- 性能：95 猪、176 步回放应在浏览器中流畅运行，进度条跳转从初态重建。
- 风险：初始布局由单张截图识别并人工补充，实际游戏规则差异需后续实测。
- 预计工时：约 4 小时。

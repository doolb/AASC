# 锁猪完整计划执行

- 任务：对含锁猪关卡先验证完整计划，再逐步操作并保存证据。
- Design：记录初始布局、锁的阻挡范围与解锁阈值；红色高亮为界面提供的可移动提示，模型无解不能作为游戏无解的证明。
- Spec：先独立重放每步、锁状态和空棋盘终态；运行时核对窗口及棋盘，动作确认后记录；异常保留现场。
- 影响：`scripts/play-pig-locked.py`、`package.json`、`tests/pig_level_locked_test.py` 及猪游戏文档。
- 自测：检查提前点击锁猪及未完成计划被拒绝；使用实机首屏核对完整候选。
- 兼容性：使用既有 X11 截图及输入适配器，不操作底部道具。
- 性能：逐帧图像核对可能受动画与设备性能影响，超时停止。
- 风险：占格与锁阈值依现场复核；红色高亮尚未自动识别，后续需补充校验。
- 预计工时：约 2 小时，实际通关时间另计。

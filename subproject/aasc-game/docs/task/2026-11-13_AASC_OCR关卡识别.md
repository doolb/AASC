# AASC OCR 关卡识别

- 任务：在自动采集中默认接入 AASC OCR，提供关闭开关，识别关卡编号及锁计数。
- Design / Spec：见猪游戏设计与伪代码；调用现有 OCR CLI，输出及置信度留证，不确定时保留原有复核流程。
- 影响：新增 Python OCR 桥接、自动采集、锁候选识别、测试和使用文档。
- 自测：OCR JSON及坐标映射、高低置信锁数、标题冲突、失败回退；第40关真实截图调用 AASC OCR。
- 兼容性：默认开启，可关闭；通过参数指定显示端、短边和超时，沿用 AASC_URL 等环境配置。
- 性能：只在采集首屏时调用，OCR 通常需要数秒，不影响每步匹配。
- 风险：OCR 可能误读或超时，识别到数字不自动推断小猪朝向；多个候选或冲突不应猜测。
- 预计工时：约 2 小时。

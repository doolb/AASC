# 2026-11-23 双指无极旋转与高度自动计算俯仰

## 任务描述
优化移动端双指交互体验：解除 `±0.62` 弧度角度墙实现 360° 无极滑动/拧转与松手惯性滑行，限制双指仅控制垂直转盘轴（`yaw`）和缩放距离，俯仰角由缩放高度自动平滑计算，并消除双指依次抬手时的镜头跳变。

## Design & Spec
- 见 [spec/pig-game-3d.md](../spec/pig-game-3d.md) 第 12 节（已先同步更新伪代码规格）。

## 受影响模块与代码
- `web/pig-level/3d/view.mjs`：
  - 新增 `autoPitchForZoom(z)`（`clamp(0.91 + (z - 1.0) * 0.72, 0.58, 1.24)`），在双指捏合及 PC 滚轮缩放时自动驱动 `targetPitch`；
  - `pinchInfo()` 记录两指角度 `angle`，双指移动融合拧转角解卷绕增量 `dAngle` 与纯平行横滑增量 `parallelSpin`，忽略双指上下移动 `dy` 对俯仰的影响；
  - 去掉 `targetYaw` 的 `[-0.62, 0.62]` 限制，增加 `applySpin()` 与 `yawVel` 指数惯性衰减，`resetCamera()` 先将 `yaw` 归入 `[-π, π]` 就近平滑回正；
  - `onPointerUp()` 当 2 指落回 1 指时同步剩余手指坐标并保持 `dragged = true`，避免跳变与误触。
- `web/pig-level/{index.html,app.mjs}`、`web/pig-level/3d/*.mjs`：资源版本号统一递增至 `?v=20261123d`。
- `tests/pig-level-3d.test.js`：补充双指纯竖滑不改 `pitch`、超 `±0.62` 拧转、松手惯性滑行及缩放拉近自动降俯仰断言。

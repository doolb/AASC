# 任务：SVG 矢量皮肤表盘、精简晴阴雨天气、UI 随天气换肤与夜间月光修复

## 任务描述
1. 精简天气分类为 `sunny / cloudy / rain`（晴/阴/雨），消除“雪”与“冬”重复；冬季降水（`winter + rain`）自动按冬雪飘落与冷霜雪地呈现。
2. 对照概念图 `env_modal_one_hand_dial_concept_1795524187444.jpg` 制作 5 个纯矢量 SVG 皮肤资产放入 `web/pig-level/assets/ui/`，并将表盘改为外圈 24h 单三角指针（完全不挡字）、中环 120° 晴阴雨（无指针）、内环 90° 四季（无指针）。
3. 全息 UI 背景与按钮颜色随当前天气（晴/阴/雨）、冬季与昼夜时段同步自动切换皮肤配色。
4. 修复夜晚月光主光方向（与天空中月亮一致）、压暗双光叠加过曝，并隐藏夜晚天空中的白天太阳光斑。

## 自测与验证用例
1. `WEATHERS` 校验为 `['sunny', 'cloudy', 'rain']`，`winter + rain` 返回 `precip: 'snow'`；
2. 本地静态服务返回全部 5 个 `.svg` 为 HTTP `200`；
3. 弹窗表盘支持点击 `season-winter`、`weather-rain`（120° 三等分）、`time-morning/evening/night`，切换晴/阴/雨/夜时 UI 面板背景主题同步切换；
4. 夜晚时主光 `getSunPosition().z < -10`，与月亮方位一致；
5. 运行 `npm run test:pig-web`、`npm run test:pig-animation`、`npm run test:pig-3d` 全量通过。

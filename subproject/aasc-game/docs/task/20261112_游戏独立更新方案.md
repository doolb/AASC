# 游戏独立更新方案（待实现）

任务：支持公网分发网页、APK 下载游戏网页包与安装新版 APK；复用 Offline 更新服务器及 RSA 签名体系，使用独立游戏制品，不替换现有服务清单。

设计：见 `docs/design/game.md`；实现伪代码：见 `docs/spec/game.md`。影响 Android 更新与安装器、房主资源服务、网页客户端、游戏制品构建与发布脚本、测试及使用文档。具体文件在实施前按现有代码拆分确定。

自测：签名有效与篡改、大小/SHA 错误、路径穿越、版本降级或不兼容、网页健康失败回退、离线使用、APK 包名与签名不匹配、系统安装确认、房主分发更新后的网页和公网网页转入局域网房间。兼容性：现有 APK 初始版本、不同 Android 版本及主流浏览器；性能：大包下载与解压限额和空间检查；风险：调试与正式 APK 签名不同、HTTPS 到局域网 HTTP 的浏览器安全限制；预计工时：3–5 天。独立游戏制品的实际发布目录及正式 APK 签名证书需实施时依据现有发布环境核对。

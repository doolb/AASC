# 2026-11-23 默认镜头内圈棋盘填满适配与手机草叶降档

## 任务描述
优化 `fitCamera()` 默认镜头距离与中心偏移计算，使内圈棋盘在横屏时填满安全区高度、在竖屏时按透视最长前边填满安全区宽度；同时将手机端每档草叶数量再往下调降一档。

## Design & Spec
- 见 [spec/pig-game-3d.md](../spec/pig-game-3d.md) 第 6、12 节（已先同步更新伪代码规格）。

## 受影响模块与代码
- `web/pig-level/3d/view.mjs`：
  - `fitCamera()` 收紧至内圈棋盘实际边界（`hw = cols/2 + 0.15`、`hh = rows/2 + 0.15`、`y = 0..0.92`），二分范围 `[6..64]`，按横屏填满 `safeH * 0.96`、竖屏填满 `safeW * 0.96`（兼顾另一轴不溢出安全区）并迭代反推精准居中 `baseLookTarget`；
  - `window.__pig3d` 新增 `getBoardScreenBounds()` 与 `getGrassCount()` 便于测试验证。
- `web/pig-level/3d/grass.mjs`：
  - 新增 `grassCountForTier(tier, isMobile, isSoftware)`，手机端每档降一档为 `high 36000 / medium 22000 / low 12000`（桌面端维持 `140000 / 36000 / 22000`），`setTierCount()` 共用同一查表函数，暴露 `getCount()`。
- `web/pig-level/{index.html,app.mjs}`、`web/pig-level/3d/*.mjs`：资源版本统一递增为 `?v=20261123c`。
- `tests/pig-level-3d.test.js`：补充 `grassCountForTier` 单测、手机端实际草叶数检验以及横屏 `heightRatio >= 0.88` / 竖屏 `widthRatio >= 0.88` 占满率断言。

## 自测与验收结果
- 截图实测横屏 `1280×720` 与竖屏 `390×844@2x` 内圈棋盘填满且居中不压 UI；`npm run test:pig-web`（`118 / 118`）、`npm run test:pig-animation`（`1 / 1`）、`npm run test:pig-3d`（`5 / 5`）全部通过。

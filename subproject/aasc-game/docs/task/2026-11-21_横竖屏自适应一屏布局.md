# 2026-11-21 横竖屏自适应一屏布局

## 1. 任务描述
无论竖屏（桌面高窗口、手机 `390×844` / `360×640`）还是横屏（桌面 `1280×720` / `1024×600`、手机横屏 `844×390`），猪了个猪练习网页都应完整呈现于一屏之内，不超出视口高度产生纵向滚动，同时保持 12:17 棋盘等比例不拉伸、顶行 `.hint-arrow` 不被裁剪。

## 2. Design 需求与 Spec 设计
- **外层一屏框架**：`.app` 采用 `height: 100vh; height: 100dvh; overflow: hidden;`。
- **容器尺寸驱动等比棋盘**：在 [index.html](file:///mnt/AASC/subproject/aasc-game/web/pig-level/index.html) 棋盘外增加轻量容器 `<div class="board-stage">`，在 [style.css](file:///mnt/AASC/subproject/aasc-game/web/pig-level/style.css) 中设 `container-type: size; overflow: visible;`；`.board` 使用 `width: min(100cqw, calc(100cqh * 12 / 17), 560px); height: auto; aspect-ratio: 12 / 17;`。
- **横竖自适应编排**：
  - 竖屏：`topbar` + `game-card(minmax(0, 1fr))` + `controls` + `footnote` 纵向四行排布，收紧窄屏边距。
  - 横屏（`@media (orientation: landscape) and (min-width: 560px)`）：双栏三行 Grid，左列通高 `.game-card`，右列依次为 `.topbar`、`.controls`、`#ruleText`；`@media (orientation: landscape) and (max-height: 520px)` 紧凑高度保证手机横屏一屏容纳。

## 3. 受影响模块与文件
- `web/pig-level/index.html`、`web/pig-level/style.css`
- `tests/pig-level-animation.test.js`
- `docs/spec/pig-game.md`、`docs/design/pig-game.md`、`changelog.md`

## 4. 自测、兼容性与风险评估
- **自测用例**：`npm run test:pig-web`、`npm run test:pig-animation` 在 `390×844`、`360×640`、`844×390`、`1280×720` 下验证 `scrollHeight <= innerHeight`、`scrollWidth <= innerWidth`、棋盘比例接近 `12/17` 及 `.hint-arrow` 不裁剪。
- **风险与工时**：`container-type: size` 与 `cqw/cqh` 需在无头 Chromium 实测验证对 `.hint-arrow` 绝对定位与 `overflow: visible` 无任何裁剪副作用；预计 0.5 小时。

## 5. 完成记录与验证结果
- `npm run test:pig-web`：`118 / 118` 全部通过（`0` 失败、`0` 跳过）。
- `npm run test:pig-animation`：`1 / 1` 通过（`0` 失败、`0` 跳过），在 `390×844`、`360×640`、`844×390` 与 `1280×720` 四个横竖视口下均满足 `scrollHeight <= innerHeight`、`scrollWidth <= innerWidth`、`.app` 无内部裁切溢出、棋盘比例保持 `12:17`，且横屏呈左棋盘右控制区双栏；第 117 关第 54 步 `.hint-arrow` 在顶行保持未裁剪。

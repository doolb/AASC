# 自动识别关卡特殊猪

- 任务：减少新关卡对猪、剪刀、捆绑方向和位置的人工复核。
- 设计及伪代码：见猪游戏设计与实现文档；蓝色局部定位、方向证据、网格及多帧交叉校验。
- 影响：特殊物件候选检测、连续流程、离线截图测试与使用说明。
- 自测：第 41、44、45、46、49 关截图的位置、类别、方向及网格占格；错误方向、漏检、多帧不一致禁止执行。
- 兼容性：普通关、计数锁和已复核布局保持既有行为；未知样式回退留证。
- 性能：仅在每关初始截图与必要的多帧复核中处理局部画面。
- 风险：动画、遮挡、缩放和蓝色背景可能造成误判；不足证据时不得猜测。
- 预计工时：约 4 小时。

- 扩充黄色候选显式过滤：只合并同格、外框充分重叠的重复检测；第 30 关密集鸭样本和同格歧义回归通过。
- 后续限制：第 52 关铁笼动态模型和完整求解尚未纳入通用流程；两次阶段执行进入模型死局，需继续研究。

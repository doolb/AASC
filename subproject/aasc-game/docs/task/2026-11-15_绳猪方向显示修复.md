# 绳猪方向显示修复

- 任务：绑绳横跨猪身，跟随猪的朝向。
- 设计：横向猪使用竖直绑绳，纵向猪使用水平绑绳，按剩余数量居中排列。
- 规格：见 `docs/spec/pig-game.md` 网页绳索绘制。
- 影响：网页小猪 SVG 绘制及相关设计文档。
- 自测：第 41、44、45、49 关覆盖西、东、北、南四个方向的绳猪。
- 兼容性：Chromium 验证 SVG 线段及静态网页加载。
- 性能：每次绘制最多生成少量 SVG 线段。
- 风险：绳索只改变视觉方向，剩余数量仍取原有状态。
- 预计工时：30 分钟。
- 验证：四方向浏览器检查通过，公网脚本 SHA-256 与本地一致。

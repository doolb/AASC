# 猪了个猪屏幕关卡提取脚本（已实现）

用户需要快速获取每只猪的位置和朝向，并要求只通过 Linux 截图及输入接口接触游戏。脚本只截图与处理截图，不点击和操控游戏；从已保存文件处理也不连接游戏。

设计与伪代码见 `docs/design/pig-game.md`、`docs/spec/pig-game.md`。已新增 `scripts/extract-pig-level.py`、Python 自动化测试及 npm script；输入关卡编号、截图文件或 X11 显示、指定窗口 ID 和可配置窗口内裁剪区域，输出原图、坐标/朝向候选 JSON 和编号方向标注图，避免覆盖。对斜向首关与网格第二关分别测试，低置信及遮挡报告人工复核，不能虚报准确度。

自测：参考图数量、已人工核对的方向、JSON 坐标与原图一致、未知方向提示、空图、重复输出保护以及 X11 截图；兼容性：Linux X11 与本机 Python/OpenCV，显示尺寸和 UI 缩放可配置；性能：分别记录单张截图和识别耗时；风险：遮挡、画风或分辨率变化降低识别率，网格需要单独确认；预计工时 0.5–1 天。用户已确认；已完成离线参考图、遮挡、标题匹配、无目标和防覆盖测试。实际游戏窗口实时截图尚待窗口可用时验收，逐只方向及其他关卡仍需复核。

# 对向抓取与预折痕调研

状态：调研及语义确认完成，单轴成对抓取已实现，新增浏览器专项测试通过。

需求：分开支持对向平行角点，围绕折叠产生并复用折痕建立真实手工流程。设计与伪代码见 design/gami.md、spec/gami.md 的对应章节。

涉及模块：web/gami/app.mjs（鼠标与多触点状态）、separate.mjs（成对抓取约束）、scene.mjs（纸层和抓取反馈）、paper-contact.mjs（两侧姿态的接触校验）、tests/gami.test.js。必要时再扩展材料拓扑，不能直接把单轴方法当作多轴求解。

验收草案：两层重叠角可区分；固定一角拖另一角；双指对向分开及回拖；不拉伸纸面、不穿透；压平后展开保留折痕；交点边可再拾取；取消/撤销/刷新保持一致；双指抓纸与空白缩放无冲突。兼容：旧存档与已有单点操作。性能：记录每次求解耗时并保留现有接触预算，不在此阶段宣称达到实机帧率。

风险：屏幕重叠不等于材料相同；两个抓取目标可能几何上不可同时满足；复杂压扁折和花瓣折需要多轴协同。预计工时：与双模式合并实现及回归约半个工作日。

已确认：不同纸层对应角对向拉开；鼠标固定一侧、触屏双侧抓取。编号柄明确选择纸层；实现范围为共同直折轴，复杂压扁折与花瓣折仍待后续设计。

用户已确认合并方案，进入实现。新增独立 pair-controls.mjs 管理双角编号、抓取与多触点，避免与原环视状态混合。

执行结果：2026-11-24 完整 test:gami 25/25 通过，包含鼠标成对抓取、双指共轴展开、取消后迟到松手、刷新和旧单点操作回归。

# 第48关离场动画

- 任务：为离场动作增加沿方向移出棋盘的动画；棋盘内滑动保持即时。
- Design / Spec：先播放离场动画，再提交游戏状态；动画期间禁止重复操作，拖动进度或重置可取消动画并重建状态。
- 影响：静态页面的交互模块、样式和浏览器自测。
- 自测：上下左右离场、非离场即时移动、动画期间重复点击、进度跳转及重置取消、解绳和胜利时序。
- 兼容性：使用浏览器 Web Animations API；系统要求减少动态效果时跳过动画。
- 性能：单次只播放一个猪的位移动画，不重建动画帧中的整盘 DOM。
- 风险：页面切后台、动画取消和不同设备刷新率可能影响回调时序，必须保护状态。
- 预计工时：约 1 小时。

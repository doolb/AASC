## 2. 美术方向

- 关键词：**吉卜力水粉 + 立体园艺地台 + 暖光冷影**。
- 三条原则：
  1. **主体优先**：棋盘区最亮、对比最高；外围逐级降饱和、降对比（色彩透视）。
  2. **成团成带**：景物按“花带 / 灌木团 / 树林”成组摆放，不再均匀撒点。
  3. **冷暖分离**：受光面偏暖黄，阴影偏蓝紫，阴影里的饱和度不低于受光面。

## 3. 场景分层构图（由内到外）

```mermaid
flowchart LR
    A["L0 棋盘边框<br/>贴地木框+土带+草坪"] --> B["L1 近环 0~3 格<br/>花带/灌木/卵石小路"]
    B --> C["L2 中环 3~9 格<br/>栅栏/池塘/树丛/木屋"]
    C --> D["L3 远景 9 格以外<br/>丘陵/风车/林线"]
    D --> E["L4 天空<br/>穹顶/积云/远山"]
```

### L0 棋盘地台（解决 P1、P2）
- **贴地边框（已确认不抬高棋盘）**：棋盘和草坪高度保持现状（`y≈0.008`），猪、射线拾取、离场路径和小鸭寻路的坐标都不变。只在棋盘外沿 0.25 格处铺一圈贴地的圆角原木框（截面 0.22 宽 × 0.12 高，四角各一根 0.3 高的短桩），框外再加一条 0.35 宽、略微下沉的暖土带（`y=-0.01`），内嵌碎卵石。边界靠颜色、明度和木框的阴影来区分，不靠高差。
  - 木框高度 ≤ 0.12，低于猪身中线，不挡离场滑出；离场动画越过木框时不做跳跃，直接穿过（视觉上被猪身遮住）。
- **草坪**：保留修剪条纹，与外草地拉开亮度：草坪亮度 +12%、饱和度 +8%；外草地降 6%。
- **格位暗纹**：草坪贴图上叠加极淡的格线（透明度 0.06），帮助判断格子，不抢猪的视觉。
- **猪间 AO**：按棋盘占用格生成一张低分辨率 AO 贴图（每格 4×4 像素），把相邻猪之间的草压暗 18%，猪身底部压暗 10%。只在关卡加载和每步结算后更新。
- **猪的材质增强**：
  - 轮廓光：根据视线方向在猪背边缘加一圈暖白 `fresnel` 光（强度 0.25）。
  - 个体差异：每只猪的色相 ±2°、明度 ±3%，按猪 id 随机，同一关卡结果固定。
  - 底部阴影：移除早期的深色椭圆接触阴影贴片，仅保留实时太阳阴影与猪间占格 AO。
- **草叶溢边**：地台框外沿生成一圈小草丛（每格 2～3 丛）盖住接缝。

### L1 近环（解决 P3）
- **花带按画质分档（已确认）**：
  - `high` / `medium`：用花带取代彩纸屑。先沿棋盘外 1～3 格画 3～5 条样条曲线，花沿曲线成带分布（带宽 0.8～1.4）。花朵由平涂圆片改成 5 瓣星形十字面片加花心，朝向随机；`high` 档随风摆动，`medium` 档静止。数量是现在的 60%，但都集中在花带里。
  - `low`：保留现在的均匀散花圆片，只把聚簇阈值收紧（`cluster < 0.05` 时跳过），减少彩纸屑感，不新增开销。
  - FPS 自动降档到 `low` 时，下一次切关或重建场景再换成散花；本局内不热切换，避免卡顿。
- **圆灌木团**：12～20 团，每团由 3 个噪声球组成，使用季节叶色，主要放在棋盘四角外侧，框住视线。
- **卵石小路**：从左上石板路接到地台左侧的入口台阶，形成视觉动线。
- 近环所有景物高度 ≤ 0.6，不能挡住棋盘和猪的离场轨迹。

### L2 中环（解决 P4）
- **栅栏加粗**：柱子半径 0.06 → 0.1，顶部加圆头；横杆改成两根略弯的原木（截面 0.09）。颜色提亮到 `#c48d59`，并加 2 阶描边。
- **池塘**（新增，左下）：不规则圆形浅水面，`MeshToonMaterial` 加竖向渐变（岸边浅青、中心深蓝），上面放荷叶和睡莲。晴天叠加程序波纹高光；雨天叠加现有涟漪粒子。
- **树木**：
  - 树冠细分 9 → 14，树冠顶部加暖色高光、底部加冷色阴影的顶点色渐变，柔化棱角。
  - 位置整体内收 0.8～1.2 格，保证横竖屏下至少 2 棵完整出现在画面角落，起取景框作用。
  - 春季在树下铺一圈落樱地面贴花，秋季铺落叶贴花。
- **木屋**：窗户改成自发光（`emissive`），黄昏和夜晚亮起暖光并在地面投一块暖光贴花；加门廊小灯。

### L3 远景与 L4 天空（解决 P5）
- **地面距离雾**：在草地和地面材质里按到棋盘中心的距离做“色彩透视”：12 格外开始向地平线色混合，24 格处混合 45%，同时饱和度下降。
- **林线**：远坡上一圈实例化低模树剪影（40～80 棵，single draw call），颜色接近远山色。
- **默认镜头俯角（已确认先不降）**：保持现有初始俯角（约 52°），确保棋盘与操作可读性；仅在代码内保留 `DEFAULT_PITCH` 常量以便后续按需微调。默认俯视下主要依靠地面距离雾化、色彩透视及外围丘陵抬升营造景深；玩家手动旋转/降低仰角时可看到完整天空、积云与三层远山。
- **云影**：沿用草叶里的云影噪声，同时作用到地面、地台和外围景物（统一的世界坐标噪声），让整个场景出现大块漂移的明暗斑。

## 5. 季节与天气专项

- **春晴**：樱花瓣飘落粒子密度 +30%，花带以奶黄和粉为主；蝴蝶在花带上方盘旋。
- **夏晴**：高饱和蓝天，池塘高光更强；向日葵沿栅栏排成一列；黄昏萤火虫向花带聚集。
- **秋**：枫树冠加入 2 种色阶；地面铺落叶贴花；稻草堆和南瓜移到近环角落作为取景。
- **冬（P7）**：
  - 雪地阴影改为 `#7d8fd6`（明显的蓝紫），受光面加 `sparkle` 闪点（屏幕空间噪声阈值）。
  - 地台木框顶部铺圆润雪檐，四角雪堆。
  - 栅栏挂暖色灯串（点状自发光，不加真实点光源），木屋窗暖光，构成冷暖对比。
- **雨**：地面湿润时整体变暗、加反光；主光/半球光下调后配合更暗的云底色，突出雨丝、闪电与木屋暖窗对比，靠逆光轮廓光保持猪体可读；地台土带出现小水洼贴花，雨滴落在上面产生涟漪。
- **铁笼关 / 月夜（P8）**：
  - 铁笼关的 `dusk` 下限固定为 0.85，不再被昼夜循环冲淡。
  - 笼杆半径 ×1.6，金属卡通材质（2 阶 + 高光条），笼顶加横梁。计数牌改为发光圆牌，带描边和轻微脉冲。
  - 场景加木屋暖窗、灯串和萤火虫，形成蓝紫底色上的暖光点。

## 7. 验收标准

1. 棋盘边界在 4 季 × 4 天气下都能一眼认出；地台与外草地的亮度差 ≥ 10%（截图像素取样）。
2. 相邻猪之间可见暗缝，100 只猪的密集关卡（第 100、113 关）能读出个体。
3. 横屏 1280×720 与竖屏 390×844 的默认视角下，至少 2 棵树完整出现，并能看到一条花带或池塘。
4. 铁笼关有明显的月夜蓝紫色调，计数牌清楚可读。
5. 冬季阴影可测为偏蓝（阴影区 B 通道 > R 通道 + 15）。
6. `npm run test:pig-3d` 和 `npm run test:pig-web` 全部通过，控制台 0 报错；medium 档帧率不低于现状 −5fps。

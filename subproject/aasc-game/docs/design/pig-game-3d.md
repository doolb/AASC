# 猪了个猪 3D 化（手绘风场景、四季天气、卡通浮动 UI）

## 需求
- 参考 Patch 上 Blendi 的 Painted Valley（Three.js 吉卜力手绘水粉风格：高饱和明快色彩、共享统一草甸色板、短阶明暗对比、水粉刷痕草叶、金色麦草秆、漂带花丛、大朵积云、三层远山、昼夜光线流转），把 `web/pig-level/` 网页游戏全面 3D 化。
- 纹理、模型、音乐与音效全部由程序生成，不引入外部美术或音频资源。
- 地面铺满可交互草地：指针划过拨开草叶，点击空地溅起草屑花瓣，小猪滑动/离场压倒草并留下逐步回弹的轨迹。
- 参考原游戏关卡背景（前期草地/石板路/高脚木屋/花盆，蓝底铁笼关卡为月夜蓝紫云团），支持春夏秋冬 × 晴雨阴雪 16 种组合，支持昼夜流转与月光照明。
- UI 改为 3D 卡通风格浮动 UI，包含居中平滑滑动关卡列表（不循环）、紧凑双栏横屏与竖屏适配，并保留“简洁 2D 控件”切换开关与 `?view=2d` / 无 WebGL 自动回退。

## 已实现模块（阶段 1～4 全部完成）
- `web/pig-level/3d/presets.mjs`：16 组季节×天气参数、关卡号季节映射、种子随机天气、铁笼关月夜黄昏叠加。
- `web/pig-level/3d/textures.mjs`：程序噪声、高亮度水粉刷痕草地与修剪草坪、石板、木纹、三层山脊剪影、粒子图集、卡通数字牌（LRU 缓存）、地面贴花提示纹理。
- `web/pig-level/3d/geometry.mjs`：顶点色部件合并（支持保留已有渐变顶点色）、线性坐标轴渐变着色 `shadeGradient`、共享外围地形高度 `groundHeight`、法线外扩卡通描边 `outlineOf`、噪声扰动球、螺旋管与卷尾几何。
- `web/pig-level/3d/models.mjs`：前版造型微加粗圆肚的胖猪（头部下颌深珊瑚红→额顶暖蜜桃渐变、深饱和鳃红/猪鼻与双耳、眼睛以眼窝中心为局部 Y=0 原点确保眨眼原位闭合不掉出）、小象、小鸭、铁笼及锁/剪刀/绳/弹簧/炸弹/计时炸弹（最后 10 秒脉冲缩放）3D 配件；高对比双阶+包裹曲率水粉明暗着色器；地面接触软阴影；地面 + 猪体顶部双重表面贴花提示环。
- `web/pig-level/3d/scenery.mjs`：远景丘陵、修剪棋盘草坪、卵石镶边、石板路、高脚木屋与屋顶积雪、木栅栏、风车、季节树（树冠开启相互投射与接收阴影且贴合外坡地形高度）、成片花丛漂带、向日葵/稻草堆南瓜/雪人季节道具。
- `web/pig-level/3d/grass.mjs`：22k～140k 实例化水粉宽草叶（`medium` 36k 兼顾密集刷痕与集显 60fps；外坡草叶通过 `aBaseY` 贴合丘陵高度；含奶油金色麦草秆与大尺度晴天阳光/云影明暗区对比，冬季积雪与雨天湿润先与草叶基底融合再统一进入云影及 5 点 PCF 太阳阴影贴图压暗，确保冬季雪草同样呈现清晰冷青阴影），柔和提亮草根与草坪自然融合，`DataTexture` 交互贴图驱动拨开与踩踏回弹。
- `web/pig-level/3d/particles.mjs`：草屑、花瓣、落叶、雪花、雨丝与地面涟漪、冲刺白金尾迹、障碍撞击火花、解锁火花、烟花、爆炸冲击波。
- `web/pig-level/3d/environment.mjs`：手绘天空穹顶（太阳光晕、昼夜弧线、夜晚月亮圆盘与星点）、漂移积云、三层远山、太阳与月光方向光（晴天太阳 2.55 / 半球光 0.58 拉大亮暗比、阴影范围 22 覆盖木屋与树木，并暴露阴影矩阵与贴图供草地采样）、指数雾、2 秒平滑过渡、雨天闪电。
- `web/pig-level/3d/holo-ui.mjs`：3D 卡通描边浮动 UI（文本贴图最高 3x 高分屏采样、顶部/底部栏、环境设置抽屉、强惯性居中平滑滑动关卡列表并禁用底板 hover 变色/缩放、胜利/爆炸浮窗、精确包围盒拾取与竖/横屏适配）。
- `web/pig-level/3d/audio.mjs`：WebAudio 四季五声音阶田园背景音乐（默认首次交互后开启）与 14 种程序音效 + 风雨鸟鸣雷声环境声。
- `web/pig-level/3d/post.mjs`：三档画质分档（高分手机端不再按像素强降 `low`，各档位分别保留 `2.5x/2.0x/1.75x` 清晰 DPR；桌面端硬件 GPU 即使 2 核默认启用 `medium` 阴影与后期；软光栅自动识别降级 `low`）、FPS 自动监测降档；后期着色器末尾统一补全 `#include <tonemapping_fragment>` 与 `#include <colorspace_fragment>`，保证与 `low` 档直出一致的 ACESFilmic 与 sRGB 色彩空间。
- `web/pig-level/3d/view.mjs`：镜头自适应、左键/单指旋转、PC 右键平移（全局拦截浏览器右键菜单）、移动端双指平移缩放、像素级躯体网格射线拾取、离场期间支持连续点击下一只猪、小鸭通路打开时基于空格 BFS 寻路蹦跳逃出动画、炸弹定位爆炸、滑行撞障回弹、受阻摇摆与撞击动作。
- `web/pig-level/app.mjs`、`index.html`、`style.css`、`scripts/serve-pig-level.js`：3D 默认入口、计时炸弹每秒实时倒计时与归零引爆（支持撤回保底恢复 15s）、简洁 2D 控件切换、`?view=2d` 回退与静态资源白名单。

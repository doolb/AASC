多阶段顺序合并 := 初始关卡布局及有序阶段、物件点击证据 → 利用各阶段网格原点、已确认动作和方向长度跟踪同一初始小猪 → 阶段边界必须唯一匹配且数量一致 → 把物件前后位移或离场证据纳入步骤 → 使用通关界面校验整关完成 → 在最初截图上标注全部有效步骤并保存合并记录；匹配歧义或证据缺失时拒绝生成已确认通关结果。

## 锁猪阶段搜索
复核布局 := 首屏网格、普通猪、锁猪暂定阻挡格、完整棋盘范围 → 全局搜索或有界阶段搜索 → 每次只执行已校验动作，画面与计划不一致停止 → 被锁猪格保持阻挡，锁计数预计归零前结束阶段并重新识别；计数变化与解锁状态由现场取证确认。

复核布局若提供 board → 连续游玩首帧与后续逐步匹配均采用该范围；否则使用既有默认范围。范围越界直接停止，不使用工具栏区域。

蓝色大象候选 := 蓝色连通域且满足最小尺寸 → 候选视觉框不得覆盖棋盘面积的一半或更多；整片蓝色棋盘背景不是独立物件；保留真实大象样本回归。

锁猪多阶段顺序图 := 首屏猪及锁猪身份 → 按时间读取已确认动作 → 以固定猪身份和阻挡规则重放，每只锁猪仅在足够数量离场后可操作 → 验证每步起止、距离、离场与胜利结果 → 在首屏绘制全部步骤，保存顺序及胜利图；有缺口则不宣称完整通关。
顺序合并支持仅验证前缀：重放至已有证据末尾后返回步骤数，不生成胜利图或标记通关。

第 33 关复核 := 两只锁猪（50、35）占已观察网格；锁未打开前作为固定阻挡；画面和活动窗口验证通过后才执行阶段计划，计数即将归零时重新识别。


锁猪完整计划执行 := 首屏复核布局 + 每只锁猪解锁离场数 + 完整候选动作 → 使用独立 Python 模型逐步校验动作合法、锁未提前点击及终态清空 → 按窗口、棋盘与当前已解锁猪集合逐步匹配 → 匹配后执行 → 下一画面确认才保存动作 → 不匹配、窗口异常或目标越界时留证停止 → 胜利后保存首屏顺序图与通关图。


## 八方向与黄色物件复核
八方向 := 从猪身主轴建立八个固定方向候选 → 结合两端头部暗像素和轴对齐程度评分 → 不一致或证据不足输出未知 → 被手势遮挡时继续输出未知；保留候选分数供复核，不将视觉框当阻挡框。
黄色候选 := 颜色与尺寸候选 → 检查锁的局部外观模板 → 命中锁模板的候选记录为锁猪；方向与解锁数可信时参与完整搜索；其余仍按既有鸭子规则及模板输出 → 锁方向、占格和数字无法识别时不得执行。

锁猪自动计划 := 黄色候选匹配已复核外观模板 → 仅当模板能高置信确定锁的方向及解锁离场数、网格与全部占格无冲突时将锁猪加入状态 → 搜索时锁未达阈值不可选但始终阻挡 → 完整候选由 Python 独立重放 → 实机按锁猪执行器逐帧核对 → 保存步骤及胜利图；模板无法确认、与鸭子混合或搜索失败时保留现场。

蓝灰小象识别 := 颜色连通域无法区分蓝色背景 → 棋盘内匹配已复核的小象局部外观 → 命中后与颜色候选去重 → 估计矩形占格并保留视觉证据；遮挡或背景变化时仍需逐帧核对，不能把未检出视为空。

锁猪与鸭混合 := 锁猪、普通猪、鸭子与阈值共同构成初态 → 锁猪未解锁占格且不可点击 → 每步计算鸭子自动离场并累积猪离场数 → 完整候选独立重放 → 实机逐帧核对普通猪、锁及鸭子后记录动作；初态不一致或候选未经验证则停止。

混合关卡锁计数 := 每次确认小猪离场数 + 鸭子自动离场数 → 共同累计解锁进度；第 39 关 25 猪 + 14 鸭使 50 锁剩 11，逐帧根据该进度核对已解锁猪。

剪刀绳子离线计划 := 截图复核猪的占格和八方向 → 剪刀尖确定遮挡猪方向 → 未全部移出剪刀猪前绳猪保持占格但不可操作 → 搜索候选并独立重放每步及终态 → 输出首屏顺序图与逐步状态图；离线结果不操作游戏。

## 第48关静态网页与步骤回放
关卡读取 := 查询参数 level 为 48 → 加载固化的复核棋盘和候选步骤 → 否则显示关卡不存在。
移动规则 := 点击存活猪 → 绳猪且剩余剪刀猪大于零时拒绝操作 → 沿朝向逐格检测其它猪占格 → 遇阻则停在障碍前，前方无空格则不移动，到达边界则离场 → 剪刀猪离场减少一根绳 → 保存撤回状态；所有猪离场显示通关。
步骤验证 := 从初始状态逐步执行候选步骤 → 对照猪编号、位置、目标及离场状态 → 全部匹配且终态清空才允许回放；异常显示错误。
回放与自由操作 := 进度条重建指定步骤前的棋盘；前后按钮按计划跳转；显示提示时高亮下一只计划猪；自由点击合法猪并记录历史，偏离计划后禁用预设下一步，撤回可恢复；提示关闭时仍可自由点击。

第48关离场动画 := 合法动作导致小猪离场 → 保留当前画面并沿小猪朝向移动至棋盘外 → 动画结束后提交棋盘、解绳、进度及通关状态；动画中拒绝重复操作，拖动进度条或重置可取消动画并重建状态；棋盘内滑动立即更新；系统要求减少动态效果时立即完成。

第40关静态规则 := 查询参数 level 为 40 → 加载 90 猪和完整参考步骤 → 锁猪初始计数为 30，每只猪离场计数减一 → 未归零前禁止点击且仍占格，归零后可以操作 → 前进、撤回、进度跳转使用同一状态快照并恢复锁进度 → 加载时独立重放完整计划。
第48关步骤整理 := 仅当交换候选动作后每一步起点、终点和离场结果均不变，且完整重放终态清空、剪刀规则成立 → 优先采用相邻位置更近的动作顺序；拖动与手动操作沿同一新步骤表执行。
关卡选择 := 顶部选择第40或48关 → 更新当前网址的 level 参数并重新加载所选关卡初始状态；不带参数默认48；不支持的关卡显示错误。

AASC OCR 可选接入 := 自动采集默认启用 OCR（可显式关闭） → 定位并裁剪关卡标题、疑似锁区域 → 调用项目现有 vision-ocr.js，传入局部图片、短边、可选显示端及超时配置 → 验证响应状态、文本置信度、坐标及图片尺寸 → 提取标题中的关卡号并与目标编号核对，提取疑似锁区域内数字 → 保存原始 OCR 结果和识别依据 → 可确认的计数加入锁候选；锁方向仍依既有画面识别或人工复核 → OCR 不可用、超时、低置信或无结果时保存原因并回退现有流程，绝不猜测；若高置信标题与目标关卡冲突则停止。

锁计数证据冲突 := OCR 高置信数字与已复核模板解锁数不一致 → 记录两种结果 → 清除可执行解锁阈值 → 阻止该锁的自动计划；OCR 不推断未知朝向。

剪刀与捆绑猪 := 首屏定位蓝色剪刀、绳子候选 → 识别所属小猪、方向与绳数 → 已确认布局并入普通猪与鸭子状态 → 搜索时以剪刀猪离场集合决定剩余绳数，绳数大于零时捆绑猪保留占格且不可移动 → 独立重放完整候选并验证每次离场与解锁 → 执行前及动作后核对现场 → 状态不符或识别不确定时留证停止。

红色可点提示 := 关卡画面棋盘内提取高饱和红色轮廓 → 计算轮廓与各小猪视觉区域的关联强度 → 唯一且超过阈值时标记对应小猪为游戏提示可点 → 其他候选不标记 → 高亮消失或无法唯一关联时无提示；方向仍按视觉头部或多帧证据独立判断。

单关选点 := 依据方向与阻挡估计选择；红框提示仅对用户确认的关卡首次点击有效，不作为续跑条件。

未复核蓝色小标记 := 普通连续流程在棋盘内检测到疑似剪刀或绳索蓝色连通域 → 保存原图、候选位置与停止原因 → 不按普通猪求解；明确提供且现场匹配的特殊布局使用剪刀解绳路径。

高饱和锁候选 := 在棋盘提取高饱和金色连通域 → 依比例筛选局部大小并与黄色候选去重 → 加入锁数字局部 OCR → 将可靠数字保留为证据，方向未确认时维持不可点击阻挡并停止不可靠的完整计划。

锁与未知物件混合 := 已复核锁方向和计数 + 未知物件按图像范围估计的不重叠占格 → 与普通猪共同进入搜索与独立重放 → 实际执行持续核对未知物件外观与位置；外观变化、占格歧义或搜索失败时保留现场。


有界部分计划 := 搜索同时记录离场对象最多且步骤较少的有效路径 → 达到搜索预算时输出非空阶段路径及未完成状态 → 独立重放验证每步、锁及固定阻挡 → 执行并逐帧确认最终棋盘 → 保存阶段动作与新布局 → 从当前状态重搜；只有胜利界面才能报告通关。红框仅允许用户确认的关卡首次点击使用，后续不得依赖或自动点击红框。

剪刀搜索顺序 := 与普通猪共用动作排序 → 仅以剪刀离场更新解绳状态 → 不因剪刀身份额外提高优先级。

# 窗前折纸工作台伪代码（网页版首版）

```text
已有声明
  输入来自网页指针事件；场景以悬空编辑平面定位纸张和作品。

新增定义
  纸样 = 风格、水彩种子、正反配色、单面或双面
  纸张 = 标识、纸样、面片集合（原纸UV、局部顶点、变换、层序）、折痕
  桌面 = 待加工纸集合、活动纸标识、已摆作品集合、撤销记录

操作流程
  首页 ← 读取本机桌面索引，按最近编辑时间确定继续目标
  新建 → 选纸并确认后分配新桌面标识；打开新桌面
  操作提交 → 单次写入本机桌面列表，保存版本、纸样种子、面片、活动纸与成品变换，同步更新桌面索引
  继续 → 读取最近快照，重建工作台；没有快照时禁用入口
  浏览 → 按修改时间列出桌面；选中后显示陈列视角，允许转入编辑或导出快照
  导入 → 解析并校验版本、字段、有限坐标及面片数量；预览后用新标识保存并打开
  导入失败 → 保留已有桌面与最近记录，显示错误
  新纸 ← 用单位正方形及完整UV建立正反面，按种子缓存水彩材质
  裁切输入 ← 手动行列或快捷预设；联动时同步两值
  有效分区 ← 行列均为正整数，且 2 ≤ 行数 × 列数 ≤ 首版 64 片裁切预算
  裁切预览 ← 在未折新纸上绘制 行数−1 条横线、列数−1 条竖线，并显示总片数；无效时禁用确认
  确认裁切 → 用 行数 × 列数 张独立纸片替换母纸，每张继承对应子区UV和世界位置
  拾取 ← 射线命中的最近可见纸面，将拖动端点投影到活动纸平面
  折轴 ← 起点和终点的中垂线；两点重合或未分开纸面时取消预览
  多角输入 → 收集选中角与共同目标，为每个角生成中垂线及该角一侧的移动区域
  整边输入 → 把拖动投影到选边的面内法向；以半位移平移选边所在直线得到折轴
  折轴集合 ← 按当前工具选用单角、多角或整边的结果
  多角校验 → 各移动区域须有面积且内部互不重叠；允许共边共点，冲突时保持原纸
  对集合内每条折轴，在同一份操作前快照上计算下述候选面与移动面
  候选面 ← 在压平纸的共同平面沿轴裁分各层面片，对交点插值原纸UV
  移动面 ← 含选中角或整边的那一侧候选面；绕轴旋转有符号折角，固定侧保持原位
  确认 → 合并各折轴结果，固定区域只保留一份，整组原子替换面片并保存上一步；完全压平时反转移动层顺序并根据折向叠放
  放置 → 保留网格与材质，沿用纸张的局部高度并分配独立物件变换
  移动物件 → 仅更新选中物件的平面位置与朝向
  首次手势 → 初始化或恢复音频上下文，将操作声、音乐分别接入增益节点
  拖折开始至结束 → 从共享噪声缓冲触发短声，按 130 毫秒限流，淡出并停止
  压平确认、裁切确认、落桌 → 按已提交事件各触发一次对应合成音
  音乐时钟 → 按乐句调度振荡器与和弦包络；后台挂起音频上下文，恢复后继续调度
  撤销 → 恢复上一步涉及的纸、物件、层序和选中状态
```

## 悬空观察与吸附

```text
进入编辑或浏览 → 隐藏室内陈设，保留环境受光，按作品包围盒确定观察中心
环视 → 相机可转入纸面上下两侧，持续朝向观察中心
拖折 → 射线与活动纸的操作平面相交，交点转入纸张局部坐标；接近平行时保留有效预览
陈列 → 多件作品共用展示空间，沿用各自的陈列位置、折角与材质
```

```text
角点拖折 → 将活动纸未选中的外轮廓角点投影到屏幕，剔除被其他作品遮住的目标
鼠标进入 14 CSS 像素 / 触控进入 24 CSS 像素 → 采用最近角点的精确局部坐标并高亮
手工单角已吸附 → 弯曲量设为零，依据吸附目标生成预览；拾取角与目标角重合
手工单角有效松手 → 保存同一目标和零弯曲量；刷新、继续和撤销按保存状态重建
重新捏起已吸附纸瓣 → 超过释放范围后，根据相对吸附点的位移恢复弯曲预览
离开吸附半径的 1.5 倍 → 恢复自由拖动；提交与撤销仍使用同一折叠事务
```

## 手工拖折

```text
按下 → 屏幕空间命中角或边，记录拾取点及初始纸形
微移 → 保持待选；超过阈值 → 锁定相机并进入拖折
拖动 → 投影当前指针到活动纸面，更新吸附目标与几何折轴，渲染临时弯曲纸瓣
松手且预览有效 → 将拾取起点、目标、朝向及弯曲参数保存到活动纸的待压平状态；记入撤销并存档
取消、指针中断或无效折线 → 保留该次手势前的形状
精确折角模式 → 使用角度控件保存立体折形
```

手工模式以屏幕像素拾取角和边；拖动时沿折线把活动纸瓣离散成圆弧条带。待压平状态保留原面片作为重建基础。

## 保持翻折

```text
有效松手 → 在原始面片旁保存拾取侧、起点、目标、角度和当前弯曲参数；同一参数重建最后一帧
恢复或继续 → 以原始面片与已保存参数重建折形；拖动可见点或边时，以指针相对按下点的位移更新目标
压平 → 由保存的折轴生成平折面片，原子替换当前形状、清除待压平状态并记入撤销
待压平 → 禁止该纸裁切、摆放及更换折法；允许选择其他纸、环视和缩放
导入 → 校验待压平字段及其能够从原始面片重建；不接受损坏状态
旧存档缺少保持状态 → 直接使用现有面片
```

## 有厚度的点边折纸

```text
已有声明
  纸张 ← 面片与原纸纹理坐标、待压平折形、现有本机存档

新增定义
  材料顶点 ← 标识、原纸坐标、当前三维位置
  材料边 ← 两端顶点、相邻纸面、边界或折痕、折向及当前角度
  材料面 ← 有序顶点与边、正反朝向、层序、物理层位移及纸张厚度
  可操作集合 ← 可见纸层上的边界点边、折痕端点、折痕交点和分割线段

操作流程
  旧纸张 → 以现有面片建立可编辑初始状态；缺失的历史折痕不凭空补造
  拾取 → 投影可操作集合并筛选视线上最近的可见纸层；点与边按屏幕容差命中
  拖动点 → 依据起点、目标和当前纸面确定折叠候选；必要时沿候选折线分割纸面
  拖动折痕边 → 从命中纸面和拖动方向确定活动侧；围绕选中边调整该侧折角或展开
  折线与已有边或折痕相交 → 在原纸坐标中插入交点，分割相关边及相邻面，更新连接关系
  运动候选 → 将厚度、层序和纸面接触送入碰撞检查；活动侧的物理层位移随折轴一起旋转；绘制与接触检查使用同一层位移
  若检测到穿透 → 限制至最近有效状态，保存该状态的面片及层位移
  压平 → 按厚度保持纸层间距，将新折痕及其连接关系加入纸张；更新纸形并保存
  展开 → 调整所选折痕的纸瓣角度，保留材料坐标及已产生折痕；更新纸形并保存
  导入或继续 → 校验并恢复拓扑、厚度、折痕与姿态；旧格式沿用兼容入口
  撤销 → 恢复操作前的纸面、拓扑、层序及折痕状态
```

```text
实现约束
  纸厚 ← 读取当前纸张 thickness，缺省 0.008；逻辑原纸边长为 2，正背表面沿法向各偏移半个纸厚
  共面叠层 ← 仅对投影实际重叠的面分配层高；立起的共面层沿其法向分离
  叠层间距 ← 层中心距为纸厚的 1.25 倍；表面净间隙为纸厚的 25%，接触包络使用同一层中心距
  点边拾取 ← 优先命中可见点，其次命中可见边；射线落在接缝时仍采用屏幕容差
  可操作拓扑 ← 只从材料面边界及已保存折痕生成；弯纸显示条带仅裁分线段绘制，不生成新操作点
  继续拖折 ← 仅由可见点或边启动，保存材料坐标，避免把折痕交点误当外轮廓角
  已有折痕调整 ← 选中材料侧绕同一空间直轴转动；折线已在空间弯折时保留有效姿态并提示
  新建折线 ← 当前纸形须展回公共平面；立体状态仍可继续调整已有直折痕
  接触求解 ← 三角面扩为厚棱柱，使用分离轴检测；沿折角扫描中间位置
  连续折角步长 ← 最大材料点位移不超过半个纸厚；每次最多 64 面、1600 步及 16000 面对步预算
  超出求解预算 ← 保持最后有效位置，提示分步调整，不删除纸面或折痕
  材料数据预算 ← 至多 128 条折痕和 2048 个面片顶点；超限拒绝新操作或导入，不截断已有数据
  存档 ← 在原有版本 1 中新增可选 creases、layers 与 thickness；缺少字段的旧存档正常加载
```

### 可设置厚度

```text
已有声明
  纸张 ← 当前工作台选中的材料面、折痕、层位移与待压平状态
  默认厚度 ← 0.008；原纸边长 ← 2
新增定义
  纸张.thickness ← 可选内部厚度；合法区间 0.002 至 0.02
  厚度输入 ← 左上工具栏下方的滑块和数值，按原纸边长百分比显示；不增加底部面板高度，避免遮住纸角
操作流程
  新建或添纸 ← 将厚度输入转换为内部厚度并保存到纸张
  选中纸张 ← 缺少厚度则使用默认值；同步显示滑块及数值
  绘制、拾取、层间距、接触检查 ← 读取同一纸张的有效厚度
  调整厚度 ← 校验数值与当前手势状态；创建纸形副本
  纸形副本 ← 按新旧厚度比例调整已有层位移；待压平纸张使用重建后的可见面检查，不保存临时显示面层位移
  厚度扫描 ← 从旧厚度到新厚度分步检查所有面接触；步长限制表面位移不超过较薄纸厚的一半
  计算预算 ← 最多 64 面、16000 面对步；超限拒绝变更并保留原值
  滑动输入 ← 同步显示候选数值；松手或输入确认后只执行一次候选校验和存档
  校验失败 ← 保留纸张原状态，恢复输入，显示失败原因
  校验通过 ← 记录一次撤销快照；替换材料厚度及层位移，刷新场景并保存
  导入 ← 缺少字段兼容；非有限数值或超出范围则拒绝
  撤销、刷新、导出和导入 ← 恢复相同厚度及对应纸层状态
```

### 层间净间隙与吸附位置修复

```text
已有声明
  纸厚 ← 当前材料厚度；面片 ← 材料点、法向与层位移
  修复前问题 ← 层中心距等于纸厚；部分吸附投影及标记位于零高度
新增定义
  层间净间隙 ← 纸厚 × 0.25
  层中心距 ← 纸厚 + 层间净间隙
  可见表面锚点 ← 材料坐标、所在面、层位移、朝向相机的正背表面位置
  间距兼容标记 ← 可选 layerSpacingVersion，当前值 1；旧 layers 缺少标记时按原层距解释
操作流程
  载入或导入旧纸形 ← 将旧 layers 候选放大 1.25 倍，逐步校验接触；通过后写入版本 1 并存档，失败保留原形并提示
  旧纸形转换失败 ← 展开过程沿用旧接触距离，保留旧版本；完全展平后再生成新间距及版本，避免旧纸层因新间隙而无法展开
  生成叠层 ← 沿纸面法向使用统一层中心距；表面仍只偏移半个纸厚
  共面重叠判定 ← 在两面边的法向投影上使用线性容差检查内区重叠；保留细小真实重叠片，公共边接触不分层，避免面积阈值漏分层
  翻折、展开或改厚度 ← 接触检查纳入净间隙；绘制使用同一物理层位移
  拾取目标角 ← 保存材料 UV 锚点 snapTarget；预览中重新定位该材料点所在纸层，不只保存平面坐标
  吸附距离 ← 在当前预览重新投影目标材料锚点；已锁定目标即使被活动纸瓣遮住仍可按释放半径保持
  继续拖动 ← 从已显示纸尖投影加鼠标位移起算；恢复已保存目标材料锚点，避免遮挡后换到另一层
  拖动反投影 ← 鼠标射线与所选纸层的表面高度平面相交；边中点投影通过所在面的插值确定，避免厚度导致折线平移
  新折线前的公共平面 ← 已通过原有平面容差的材料面复制到精确零高度，消除多次展开留下的数值残差；平折的正弦高度取精确零，接触容差保持不变
  绘制吸附标记 ← 在当前预览纸形中定位目标材料锚点，叠加层位移及表面偏移
  操作点提示 ← 根据层位移去重，显示在朝向相机的实际表面；旋转视角时更新正背表面偏移，与拾取位置一致
  释放或压平 ← 保存材料对齐关系与物理纸层；允许层高引起的真实视差
  刷新、撤销及导入导出 ← 保持净间隙、锚点和纸形一致，不重复累积位移
```

### 独立分开工具

```text
已有声明
  材料拓扑 ← 已保存折痕、交点、分割边与面片 UV
  可见控制点边 ← 当前相机下通过遮挡检查的材料点和边
  安全折痕旋转 ← 保留材料厚度、层距版本、逐步接触扫描和计算预算
新增定义
  工具 ← 新增 separate，界面名称「分开」
  展开轴 ← 临时选中的材料折痕，不写入存档
  分开手势 ← 起始纸形、层位移、材料侧、可见控制点、拖动方向与最后安全角度
操作流程
  进入分开 ← 重置临时选择；高亮已有折痕，显示可见材料点
  待压平纸张 ← 提示先压平或回到折叠继续调整；不静默提交
  拾取 ← 沿用可见表面及鼠标 14 像素、触控 24 像素容差
  拖动折痕 ← 选择该折痕；根据拾取面确定活动材料侧
  拖动点或边界 ← 从所选面片已有折痕中优先匹配展开轴，否则选择最近的有效折痕；选中材料侧围绕此轴转动
  多个候选轴 ← 用户可先点所需折痕锁定展开轴，再拖动该侧点边；交点仍可作为控制点
  无可用折痕 ← 保留纸形并提示；不建立新折线
  拖动方向 ← 通过实际表面抓取点的投影轨迹求角；小角度试转排除被压住的起始方向；折轴上控制点用活动面中心作为虚拟抓取点
  分开预览 ← 从手势起始面片绕同一折痕旋转；接触受阻保留最近安全位置，提示先展开外层
  松手 ← 有效形状写入面片、层位移及间距版本；保留折痕，自动存档并记录一次撤销
  取消、无效点击或切换工具 ← 丢弃预览，保持操作前纸形；已选展开轴仅作显示辅助
  空白拖动、双指和滚轮 ← 沿用环视与缩放
  刷新与导入导出 ← 使用已有纸形数据；工具状态不影响存档格式
```

### 分开抓取点跟随

```text
已有声明 ← 材料折轴、抓取材料点、起始层位移、相机投影及安全接触扫描
新增定义 ← 抓取点屏幕轨迹、按下偏移、上次安全角度、可行转动区间
按下 ← 固定所选纸瓣和折轴；边界使用透视深度校正后的指针最近材料点；高亮活动侧
轨迹 ← 折轴仅使用三维空间坐标，忽略附带材料 UV；将实际表面抓取点绕折轴转动并投影，保持原纸厚及层位移
目标 ← 指针当前位置减去按下时指针与抓取点的偏移
求角 ← 在连续轨迹上寻找距目标最近的位置；相近候选优先上次安全角度，允许沿轨迹回拖
展平端点 ← 候选距正负 180 度不足 2 度且指针距端点小于 4 像素时精确到端点，消除纸厚表面切换误差
接触 ← 候选角度仍经过原扫描；受阻停在安全位置，不允许跳过中间纸层
折轴控制 ← 折轴上的点使用活动面中心作为虚拟抓取点并保持按下偏移
松手及取消 ← 沿用保存、撤销和取消规则，结束活动侧高亮
```

### 对向抓取与预折痕（已实现）

```text
已有声明 ← 材料点边与纸层、已有折痕、单轴安全旋转、压平记录折痕、存档与撤销
新增定义 ← 成对抓取点、各自材料面、固定/移动状态、共同有效折轴、触点对应关系
语义确认 ← 区分不同纸层对应角对向分开与同一纸瓣双角同步移动
选择 ← 明确两处材料抓取位置；重叠候选显示层身份并由用户选定
展开 ← 在同一有效直折轴范围内依据抓取约束求纸瓣姿态，保持材料长度及厚度，接触时停在安全位置
预折痕 ← 对齐点边、压平建立材料折痕、展开保留折痕，再沿折痕继续塑形
取消 ← 恢复本次手势起始状态；松手保存有效姿态并记录一次撤销
复杂折形 ← 多折轴协同另行设计，不能强行套用单轴旋转
```

### 双模式预折痕（已实现）

```text
已有声明 ← 起折前材料面片、纸层位移、位置朝向、旧折痕、待压平预览、拓扑校验、撤销快照
新增定义 ← 操作模式（折痕/预折痕）、本次起折快照、压痕候选、原姿态分区映射
折痕模式确认 ← 沿用压平并保留折后纸形
预折痕预览 ← 对齐点边并展示折叠；松手供调整，不自动永久留痕
预折痕确认 ← 从起折快照计算压痕；沿新折线细分材料面且保持原姿态、原层次与原厚度
材料点边 ← 新折痕与旧折痕相交生成交点和分段边，允许再次抓取和沿痕折叠
写入 ← 校验全部候选后一次保存原姿态的新分区和折痕，清除本次待压平状态
取消或失败 ← 保留操作前数据，不产生部分折痕
撤销 ← 恢复本次预折痕确认前状态；旧折痕保留
约束 ← 新建折线沿用当前公共平面条件；不以回到初始方纸代替恢复起折前姿态
```

### 弯折角点球与取消（已实现）

```text
已有声明 ← 原材料拓扑、弯曲预览面片、heldFold、原面片与层位移、吸附状态、手势及存档
新增定义 ← 弯折控制点映射、当前未完成状态、取消弯折按钮
显示 ← 从起折前材料拓扑取得角点与既有交点，按 UV 映射到当前弯折表面，使用当前厚度和纸层偏移
过滤 ← 渲染条带细分顶点不生成控制球；角点显示与可见拾取保持一致
按钮 ← 有未完成预览或 heldFold 时显示，不因切换工具把取消入口隐藏
取消 ← 先终止活动手势并释放对应捕获，再丢弃候选、吸附、预览与 heldFold
恢复 ← 保留起折前面片、层位移、位置朝向和旧折痕；不创建新折痕
保存 ← 持久化恢复状态并刷新界面；迟到的 pointerup 不得重新提交
无状态 ← 取消无操作；已确认折叠使用原有撤销
```

### 合并实现的数据流

```text
预折痕分区 ← 按原面逐个裁分，子面回映原面 XYZ 与 UV，继承来源面的层位移与顺序
预折痕写入 ← 记录材料折痕并校验预算，仅替换分区及新增折痕；位置/旋转/厚度/folded 状态保持
操作模式 ← 默认折痕；待压平时禁止切换，预折痕确认执行完整压痕，不接受未压实的任意角度
取消 ← 先清空手势再释放捕获；原 faces/layers 从未被 heldFold 修改，删除 heldFold 即恢复原姿态
角点球 ← 材料顶点源采用 item.faces，而显示位置采用 preview 或 heldFaces；带 UV 标识供可见性回归
成对抓取入口 ← 分开工具内显式开启双角分开，显示带编号的材料层控制柄，近邻重叠柄错开并连接真实角点
候选 ← 可见且偏离有效折轴的材料角点；被遮挡点仅在与可见对应角邻近且存在共同轴时提供显式编号选择
鼠标 ← 点击第一角固定，按下第二个相对侧角拖动；第一角不移动
双指 ← 第一指抓角，第二指抓共同折轴另一侧角；两指位置各自驱动对应侧角度，不触发镜头缩放
约束 ← 各角按自身真实投影圆弧求绝对角，第二角与第一角之差经过已有接触扫描
纸形 ← 安全相对折角生成的全部面和层位移再绕同一轴整体转过第一侧角度；刚性变换不改变纸内接触和材料长度
提交 ← 任一手指抬起时一次保存，取消则全部恢复；切换工具、撤销、离开和取消按钮清理双角临时状态
范围 ← 一条贯通直折轴，两侧刚性运动；不模拟多折轴耦合或柔性拉伸
```

预折痕重复校验：同一直线已有折痕区间的并集覆盖新线段时，不追加重叠短线，避免相交裁分后重复压痕消耗预算。

裁纸兼容：现有等分裁切仅处理未分区原纸，有预折痕的材料面不进入旧裁纸路径，避免旧纹理边界和折痕坐标错误复制。

浏览器自测启动：SDDM 硬件 Chromium 启动等待与页面导航统一最多 120 秒，避免繁忙桌面在旧 15 秒启动上限退出；操作断言不降低。

取消入口布局 ← 按钮放在左上材料参数下方，独立于底部面板；避免新增一行抬高面板并遮挡待压平角点。

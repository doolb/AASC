# 鸢一折纸（Goal）

## 新会话提示词（可直接复用）

请在 AASC 的 aasc-game 子项目中开发网页版折纸模拟器。首页展示游戏名《鸢一折纸》与窗前木课桌，提供「新建折纸」「继续」「导入」「浏览」。新建后镜头推近桌心的方形水彩纸。玩家可以沿自选直线折纸、停在想要的角度，也可以先把整纸等分，再用小纸分别创作。做完一件就把它摆到桌边，继续折下一件；拉远镜头能一起欣赏这些作品。

先阅读[交互与美术设计](../docs/design/gami.md)、[几何与状态伪代码](../docs/spec/gami.md)和[首版任务](../docs/task/2026-11-23_窗前折纸模拟器.md)。首版已发布，可从 [鸢一折纸](https://c.aasc.us/mnt/game/gami/) 进入。

## 首版体验目标

1. 近景能读出纸纤维、颜料晕边和翻折处的层次；全景能看到窗框投影、桌面木纹和作品落影。
2. 可从任意纸角起折，可同时选两个到四个角向中心折，也可抓住整条边向中线或对边翻折，折起时看到背色；可改变折角、确认、撤销，再沿另一条线继续折。
3. 裁纸时可手动填写行数和列数，也可点 3×3 或 4×4 快捷预设。默认联动行列以裁出方纸，解除联动可裁出矩形纸片，例如 2 行 3 列得到 6 张，拼在原位仍能还原整幅水彩图案。
4. 可选单面着色（背面原纸色）或双面分别配色。首发水彩风格，纸样接口预留其他风格。
5. 将两张小纸折成不同形状并分别摆上桌。移动、旋转其中一件时，另一件保持原位。
6. 参考 Pig-game，用 Web Audio 实时合成折纸摩擦、压痕、裁切和落桌声，以及独立可关闭的水琴旋律与和弦铺底。

## 待推进目标

发布目标为 `http://c.aasc.us/mnt/game/gami/`。先验证首页四个入口与本机存档，再验证连续折叠和裁切，再用同一组样纸验收窗光、正反面与多作品同框，最后实测桌面鼠标和移动触控。

## 悬空观察与角点吸附

首页继续呈现窗前课桌。进入编辑或浏览后，纸张与成品悬空，支持绕当前作品观察正面、侧面和背面。

单角和多角拖折时可以吸附到同张纸的其他外轮廓角点。

默认手工拖折已接入：捏角或边缘中段起折，移动时纸瓣卷起，松手保持当前折形，再次拖动继续调整，点「压平」完成折叠。多角与精确角度操作从折法菜单进入。

纸张厚度与折痕：压平后保留材料折痕，交点和分割边都可拾取；拖动已有直折痕边调整或展开，受纸层接触约束，存档保留折痕和物理层位置。新折线当前从展开到公共平面的纸形建立。

每张纸的厚度从新建/添纸输入和工作台滑块/数值框设置，范围为原纸边长的 0.1%～1%，默认 0.4%。显示、层间距与碰撞使用同一厚度，设置可保存和撤销；已折纸的变更需要通过接触校验。

重叠后的纸面保留纸厚 25% 的净间隙；吸附判断和标记使用实际表面锚点，保留材料对齐后的真实层高视差，刷新或继续拖动不切换目标纸层。

独立「分开」工具：高亮已有折痕，从可见点、边和折痕抬起纸瓣；多个折轴时可先点折痕选轴。按下高亮活动纸瓣，抓取点沿实际投影轨迹跟随鼠标或手指，支持沿原路回拖，松手保留角度与原有折痕，支持撤销和存档。纸厚及接触约束继续生效，待压平纸张先回折叠完成压平。

新增折痕/预折痕模式：前者压平保持折形，后者确认后留痕并还原起折前姿态；弯折过程中保持材料角点球，取消整轮待压平弯折不留新痕。分开工具增加编号选层的双角分开，鼠标固定一角、触屏两指分别抓住共同直折轴两侧角点；保留原单点操作及厚度接触限制。

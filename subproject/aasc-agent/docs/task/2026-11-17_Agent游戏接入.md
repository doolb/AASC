# Agent 游戏接入

- 任务：连接 Agent 与 HIE，继续猪关卡并按目标保存证据和同步网页。
- 设计：游戏宿主显式启用模型角色和 HIE 工具；游戏输入沿用现有 X11 脚本；HIE 既有脚本允许按摘要更新并通过测试，否则恢复。
- 实现：按 `subproject/aasc-agent/docs/spec/aasc-agent.md` 和 `subproject/aasc-hie/docs/spec/subprojects-hie.md` 的伪代码实现；涉及 Agent、HIE 游戏桥接与使用说明。
- 自测：角色授权、模型调用、固定游戏参数、路径约束、更新失败恢复和既有回归。
- 兼容性：默认聊天模式不启用游戏或脚本更新；既有桥接 API 保持兼容。
- 性能：模型请求复用既有超时；游戏求解与脚本测试保持现有上限。
- 风险：网页模型可能返回错误数据；识别不确定、测试失败或不可确认胜利时停止，保留证据。
- 预计工时：约 1 个工作日，复杂关卡耗时不确定。

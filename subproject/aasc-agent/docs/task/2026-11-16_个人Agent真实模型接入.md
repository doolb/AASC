# 个人 Agent 真实模型与正式角色配置

需求：依据从 HIE 拆分的设计接入实际模型，API 放入配置，终端使用主助手及游戏专用角色。

设计和伪代码：见 `subproject/aasc-agent/docs/design/aasc-agent.md`、`subproject/aasc-agent/docs/spec/aasc-agent.md`。Responses 适配器通过配置的地址、模型和密钥连接，按角色隔离续接点；默认不依赖 HIE；命令和能力仍受显式授权，本地能力均由宿主按需注入。范围为独立子工程、测试及文档，不改 HIE 运行时。

测试：覆盖配置校验、密钥保护、真实协议构造与错误、角色隔离、内部命令的权限及无 HIE 行为；使用隔离测试会话实测本机 API。兼容旧宿主注入与演示。风险：模型生成可能有误，权限不能仅依赖人设；网页上游超时后会话可能无法继续，须明确告知。预计工时：一天。

实现情况：新增本地私有 API 配置和 Responses 模型适配，默认主助手及游戏角色各自维护进程内续接点；默认不注册任何本地工具，不依赖 HIE。`/new` 显式清除当前角色续接点；请求异常不静默清空历史。32 项自动化测试通过，包含真实本机 HTTP 模拟服务的多角色续接；本地配置已 Git 忽略并限制文件权限；独立子工程不改变 Offline 发布产物。

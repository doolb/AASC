# 修正个人 Agent 的自然语言输入

需求：终端接收人说的自然语言；方括号命令由 AI 提出并调用本地角色，不能把人输入直接当成本地命令。

设计、实现与范围：见 `subproject/aasc-agent/docs/design/aasc-agent.md`、`subproject/aasc-agent/docs/spec/aasc-agent.md`；修改独立 Agent 的聊天接口、终端入口及测试。模型适配器须显式区分自然语言文本与内部命令，并由宿主配置可调用角色，既有角色权限不变。真实模型与 HIE 不在本次范围。

自测：自然语言及人输入的方括号均只交给模型；模型指令经过解析、角色白名单和工具权限；无授权、格式错误、批量无效均不执行；界面错误恢复和 EOF 正常。兼容：保留原 runCommand 接口，旧解析入口迁至 npm run parse。性能：顺序执行，单次调用数量有限。风险：模型命令可能触发宿主授权的真实动作，由宿主审慎配置角色；长任务取消和模型上下文仍由宿主负责。预计工时：半天。

完成情况：终端改用自然语言聊天，`Agent.chat` 只执行模型结构化返回的命令，先校验本轮所有命令的格式和宿主授权角色，再保留原有能力权限检查；本地结果送回模型，限制调用轮数。人输入的方括号只作为文本发送，普通 AI 回复中的方括号也不会自动执行。npm test 17 项通过，伪终端自然语言输入和退出通过；真实 Responses 与 HIE 尚未接入。独立子工程不改变 Offline 发布产物。

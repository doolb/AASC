## 终端聊天界面

默认终端入口使用 Node.js readline 接收人的自然语言，显示 AI 文本、状态和本地调用结果；旧解析工具以独立开发命令保留。方括号 CSV 是模型提出本地调用的内部格式，不要求人输入，也不会把人输入的方括号直接执行。宿主模型以 `respond` 返回文本或明确携带命令的对象，Agent 校验所有命令并只允许宿主配置的角色，再执行既有权限检查并将结果交回模型；每次聊天的模型调用次数有限，默认不允许模型调用任何角色。终端通过 /role 查看角色、/role 名称 切换聊天角色，并将角色名称和人设传给模型；/role --default 恢复未选角色。聊天角色不改变可调用角色或工具权限，角色上下文由模型适配器管理。界面保持可注入，演示只本地回显，真实模型、HIE 与模型的跨轮会话由宿主提供。长任务暂不支持界面取消或流式输出。

## 真实模型与正式角色配置

独立 Agent 默认读取自身本地配置，模型走已配置的 Responses 兼容地址；默认聊天按角色维护进程内续接 ID；猪游戏宿主将续接点关联到导航会话并持久保存，试探后新导航会话沿用同一模型会话。首次请求发送角色说明，续接时只发送新增内容；中断和并发冲突不静默新建会话。可显式新建猪游戏模型会话，不删除旧网页会话。

终端 `/new` 显式重置当前角色的本地续接点，不删除服务端网页记录；会话异常不自动重发以免丢失上下文。未选择角色时使用配置的默认主助手，`/role --default` 恢复它。

正式运行时保留本地截图与试探记录；高层错误称工具达到上限不视为真实工具结果，同一缺口不反复上报。请求或工具状态不确定时不静默新建会话、不重放旧点击，停止并记录故障；通用续接核验仍待完善。

单步试探的 `observed` 表示前后画面已采集，不能代表目标已离场；宿主拒绝连续两次试探同一坐标并返回现有证据。请求状态不确定时不自动恢复。

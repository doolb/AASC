# Retop AI 四边重拓扑设计

日期：2026-11-24。状态：方案已记录；独立 CPU 基线已执行且候选质量未通过，正式功能未接入。完整研究、来源和技术取舍以 [goal.md](../../goal.md) 为准。

## 需求与边界

从高模和可选源贴图生成可编辑低模与可选低模贴图，改善现有 CSI/规则工具在人物等复杂形体上的泛化。用户最终偏好四边面，面数可调；三角输入不限制四边输出。计划设备为 2080 Ti 22GB，训练峰值以 16GiB 为目标，尚未实测。

先在 SQuadGen 预训练权重上做领域适配，冻结 Geometry AE、SQ-VAE。独立 `local_train/` 已实现 SQ-Diffuse LoRA、离线缓存、FP16 autocast 与梯度检查点，CPU 小模型工程自测已执行；GPU LoRA 更新与真实领域训练未执行。预算条件仍待新增，不能表述为已实现。

首版不用 Qwen3.5：几何编码器负责三维形状；文本意图和多视角语义作为后续适配器，不阻塞几何、UV 和烘焙。源颜色与法线细节以原高模为依据，不推测原图不存在的手绘内容。

## 模块与数据边界

| 模块 | 输入 → 输出 | 约束 |
| --- | --- | --- |
| 输入与代理 | 原高模/材质 → 工作副本、采样、源映射 | 原件只读；不强制闭合、不跨壳焊接 |
| 几何编码 | 表面坐标/法线 → 几何条件 | 保留官方输入格式，采样不受原顶点密度支配 |
| 布局模型 | 几何条件、目标面数、可选导线 → 布局 latent | 基于预训练模型适配；面数条件是新增设计 |
| 布局解码/提取 | latent → CDF/DCDF → 四边补片图 | 记录非四边区域、T 接头和提取失败 |
| 预算与拟合 | 补片图、目标、源映射 → 真实低模 | 共享边整数分段联合求解、原高模限制贴合、实际计数 |
| UV/烘焙 | 定稿低模、原高模与可选源通道 → UV/图集 | 逐纹素源对应、部件隔离、缺失通道明确报告 |
| 验收 | 导出回读资产 → 几何/拓扑/外观/资源报告 | 多视角，原版与微调版同预算对比 |

不在 Blender 插件内部引入 PyTorch；使用独立本地环境和文件任务，遵守现有插件无外部依赖边界。肩甲试验经用户确认后在 `/mnt/SQuadGen/.venv` 安装独立依赖；未新增服务或修改 AASC 运行配置。若以后跨 AASC 集成，再单独定义配置消息流程。

## 面数与四边约束

`targetFaceCount` 必须带 `budgetUnit`；默认面向四边预算，显示实际四边/三角/其他面及渲染三角面数。SQuadGen `res` 仅是 latent 分辨率，不能作为面数控制。

目标预算同时进入模型和几何阶段。默认建议上限约束下尽量接近目标，精确模式可返回不可行；不伪造理论最小面数。四边优先与严格全四边分别记录，混合输出需显式选择。局部修复增加的面数也计入预算。

对合法源拓扑保持开口、孔洞与组件，不以全局细分、任意三角面合并或隐藏对角线代替布局质量。最终纯四边要求和目标预算冲突时报告诊断候选，不作为通过结果。

## 训练与验收

训练产物采用“不可变底模 + 独立 LoRA”管理。底模包括匹配的 SQ-Diffuse、Geometry AE/SQ-VAE 和编码配置，按权重 SHA-256 与架构指纹绑定。不同底模各有适配器；相同架构不同权重也不默认通用。首版后端仍仅为 SQuadGen，每次只激活一个 LoRA。

SQ-Diffuse 的融合 attention qkv 与 proj 为首轮注入目标，rank/alpha 暂取 8/8。推理包保存 LoRA、注入配置和来源清单；新增条件模块须额外完整保存，首版尚不支持并明确拒绝。精确续训另存 optimizer/scheduler/scaler、随机状态和数据游标，比较训练实现指纹。切换撤下旧包装后再注入，底模参数未被合并；校验缺失或不匹配时失败，禁止覆盖原底模。独立训练/读写代码与 CPU `--adapter` 推理接入已实现，详见 [goal 训练契约](../../goal.md) 与 [任务](../task/2026-11-24_SQuadGen_LoRA保存加载设计.md)。

优质四边低模提供布局监督；派生高模或配准高模提供输入。官方原生四边网格训练与高低模配对扩展分别验证；采样锚点、表面映射、归一化必须一致。按基础资产分组隔离测试，旧 retop 自动候选需要筛选。

P0 先验证 AE 重建、官方推理、FP16 与完整训练 step 显存；P1 准备数据和基线；P2 领域微调；P3 面数条件和几何预算；P4 UV/烘焙与接入；P5 动作/语义增强。性能、质量目标与实验矩阵详见 goal。

独立 LoRA 工程链路已实现；主工具的领域训练、预算控制、UV/烘焙和集成仍待完成。原生 CDFGen 样本提供监督，缓存使用冻结 AE 后验 mode；高模输入与低模标签的配准扩展尚未实现。独立 CPU 基线见下节。既有 retop 待办不因工程自测通过而标为完成。

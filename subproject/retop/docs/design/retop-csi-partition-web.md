# Retop 独立 CSI 分区网页

用户已确认上述范围。独立网页已实现，见 `web/csi-boundary/`。

## 目标和范围

提供一个独立网页，以已有肩甲为首个样本，对高模运行现有 CSI 识别并查看、保存和导出分区结果。用户明确不需要生成低模，因此不调用五档候选、低模构面、UV、贴图或低模导出流程。TopoGun 接入与后续构面不属于本次范围。

## 页面与操作

- 打开网页后可选用工程内肩甲，或导入 OBJ、STL、网格 JSON；显示源文件信息和识别状态。
- 在后台任务中运行源网格预处理、现有四尺度边界分析和 CSI 分区识别；支持取消并保留上一次结果。
- 在同一高模的三维视图按分区着色，显示共享分界，并支持旋转、缩放、正、背、侧、顶及斜视。列出分区数、面数、邻接、开口和超容差等识别报告；分区和边界均标为候选。
- 导出版本化 JSON，保存源指纹、识别参数、分析网格及其分区面标签、相邻关系和边界数据，确保可回读和复查原坐标。导出不声称是 TopoGun 原生导入格式。

## 实现方案

`web/csi-boundary/` 下的页面、交互、后台识别与测试复用 `web/contour-lab-3d/engine.js` 的源处理和 `boundary-guides.js` 的边界分区能力以及已有三维查看器。源处理接口增加 `prepareWorkingSource` 导出，旧流程未改；识别结果只保留源和分析信息，不调用 `process()` 内的候选构建流程。

小网格在定向副本上分析；当原有预处理需要清理或构建简化的**内部分析代理**时，页面和导出明确标注代理、原始及分析网格指纹、面数和坐标。代理仅用于识别，并非生成或交付低模；其分区标签对应代理面，不能冒充原高模逐面标签。源文件保持只读。

## 验收

1. 同一肩甲与默认参数下，和此前完整流程的分区标签、接口及曲线逐项一致，识别为 7 区、13 接口、3 段超容差，4595 个源面均有标签。
2. 自测阻止调用完整候选流程，核对源模型未改变和 JSON 回读；浏览器实际验证导出、回读、取消并保留已有结果。
3. 浏览器通过本地 HTTP 检查彩色分区、视角操作及窄屏布局。网页显示代理归属；本次未运行真实大模型代理样本。构建提供单文件网页，但内置浏览器策略阻止 `file://` 自动验证。

## 风险

现有识别是几何候选；推测边和超容差线不能解释为完整正确的结构或共边网格。大模型代理可能损失小细节，不保证识别结果逐面映射到原高模。直接文件打开时 Worker 和资源加载的可用性需实际验证，不预先宣称可离线单文件使用。

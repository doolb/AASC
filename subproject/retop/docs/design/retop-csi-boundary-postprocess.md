## 目标

在 CSI 分区识别后，对共享分区边界作规整，重点检查肩甲示意图中包边交汇处的尖角、折线与小碎边。允许边界为改善整体结构而适度偏离高模细节；原始高模保持只读，不生成低模。处理结果仍是候选，需要多视角复核。

## 已核实的现状

独立网页当前分区视图的黄色线由分析网格相邻面标签差异生成，沿分析网格三角边绘制，线形受原始网格边走向限制。CSI 识别结果也保存了共享接口和拟合导线，但分区视图目前没有以拟合导线替代真实面标签的边界。肩甲默认样本有 13 个共享接口、62 段拟合曲线，其中 3 段的拟合误差超出现有局部目标；不能直接将现有曲线都视为可用的后处理结果。

## 拟处理方式

1. 使用识别出的相邻分区和共享边构造单一边界网络；交汇点在所有关联分区间共享，识别开放边、闭环和分叉。
2. 对边界局部折线及微小凸凹作尺度相关的平顺和 I/C/S 拟合，保留已确认的结构角点、主要轮廓及必要的交汇位置。允许适度移动边界，限制对原表面的偏离、避免交叉或塌缩；无法通过检查时保留该段原始结果并报告原因。具体容差先用肩甲试算后确定，不将固定坐标或对象名写入通用算法。
3. 后处理结果作为真实的共享边界数据保存、导出，并在网页显示；相邻分区引用同一边界和端点。为使颜色分界与处理后的边界一致，在分析网格的临时显示副本上按处理后的分界重新划分或局部切分；原高模和原始识别标签保留，无法安全构造的区域保持原边并标识。曲线可适度偏离高模细节，但需限制过大悬空及穿插。
4. 原始识别边界与后处理结果可对照查看；导出同时记录参数、原始与处理后边界、偏差和回退项。保留现有 0～1 粒度、旧结果读取与取消行为。
5. 增加独立的“CSI 拟合平滑”参数，建议范围 0～1、默认 0.5，允许输入小数。数值越大，对非结构角点之间共享整线的平滑约束越强；数值为 0 时仍可进行基础 CSI 拟合，但不附加可调平滑。更改参数后重新处理并更新实际显示与导出边界；保留必要角点、交汇点及受限偏差检查。强度与分区粒度独立保存。已有网页的 `internalCSISmoothing` 只作用于特定内部接口，不能直接假定覆盖所有包边和交汇边，需核对后复用或扩展。

## 涉及文件与验证

- `web/csi-boundary/partition.js` 及按需新增的边界后处理模块：共享边规整、结果与报告；复用 `contour-lab-3d/boundary-guides.js` 的拟合能力，必要时扩充接口但不改变旧网页默认行为。
- `web/csi-boundary/app.js`、`index.html`、`styles.css` 及查看器适配：显示原边与处理后边界，保证颜色区域和最终边界一致；`build.mjs` 对新模块打包。
- 先更新对应 spec 伪代码、任务与测试，再修改代码；完成后更新 design、spec、task、todo、usage、changelog。
- 用肩甲比较红框附近和正、背、侧、顶、斜视：记录线形变化、偏离、交汇连通、空隙、重叠和回退。对比平滑强度 0、0.5、1 的拟合结果及误差，检查参数影响实际数据、显示与导出。用合成开口、闭环、分叉、尖角及不同模型尺度测试；确认相邻分区共享端点、分区覆盖、粒度范围、原模型不变和 JSON 回读。无预先通过证据时不承诺所有尖角一定可安全平滑。

## 实施约束

后处理在分析网格的显示副本上移动共享边界采样顶点，使颜色分界与实际显示边一致。拟合曲线及控制点单独记录，显示边使用通过局部面检查的采样。近角合并可在显示副本上局部重三角化，原始分析网格、识别面标签和原高模保留。

## 当前结果与限制

肩甲粒度 0.5、平滑强度 0.5 时，7 个分区和 13 个识别接口不变；224 个共享边界顶点移动，14 个点缩小了候选位移，1 个点因局部面形约束回退，最大位移约为模型对角线的 0.406%。232 个原始边界中间转角的平均值由约 19.43° 降至 16.59°，大于 30° 的数量由 46 降至 30；这是整体统计，并不证明图中每个交汇处均已达到期望。交汇点和确认角点目前固定，红框区域仍需用户从对应视角复核。

显示副本的原三角面面积至少保留原值 50%，法向余弦至少 0.8；检查候选是否新增非相邻三角面真穿插，失败时回退。该检查排除共面、共点及端点接触，不能证明完全无接触或无重叠。原始识别有 3 段拟合超原目标，页面保留提示；默认后处理整线复拟合无超新目标段，强度 1 的试算有 1 段超目标，需复核。

浏览器经本地 HTTP 验证了参数显示、原始对照以及处理后 JSON 导出回读；旧网页的边界修复回归通过。当前自动化环境无法打开 `file://` 检查构建单文件；真实大模型代理、用户图示机位及 TopoGun 尚未完整验证。

## 近角并入交汇点的显示修正

沿用 2026-11-06 已有的角点合并规则和 `cornerMerges` 记录。肩甲基线重跑后仍识别到两处沿同一接口的近角合并，源节点 898 并入交汇点 902，源节点 353 并入交汇点 2222。旧规则取消角点的独立 CSI 逻辑分段，独立网页的色块及黄色线仍按显示网格的实际共边绘制，短折线因此可见。当前截图未提供可读回的相机参数，节点对应关系由肩甲数据复核。

`web/csi-boundary/postprocess.js` 将已有合并记录落实到显示副本。短边局部重三角化固定目标交汇点，并按原分区重建邻接面，再重新拟合共享接口。面形约束依据各区原有窄面的面积和法向，在可用三角化中提高最差三角形的质量。拓扑、分区连通、面形或穿插检查失败时保留原边并记录原因。平滑为 0 时显示原边。

`partition.js` 保存处理面的同区来源并兼容旧 JSON，`app.js` 使用处理后网格及其标签绘制色块和边线。导出保存实际共享节点、三角化结果和重新拟合的 CSI 数据。肩甲默认处理合并两处近角，显示 4591 面，原始对照仍为 4595 面，7 个分区保持连通。8 个替换三角面通过非相邻面真穿插检查，本地 HTTP 验证了原始对照和 JSON 回读。用户原截图机位无参数可精确复现。

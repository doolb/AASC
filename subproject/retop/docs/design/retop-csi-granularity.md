# CSI 分区粒度参数

## 需求

在独立 CSI 分区网页加入由粗到细的粒度参数。粗粒度减少分区，细粒度增加可辨识的分区；保持高模分析和原始坐标，不生成低模。

## 设计

页面提供 0 至 1 的连续数值参数，0 最粗、1 最细，默认 0.5。以现有中档分区为基准：向粗方向仅合并相邻分区；向细方向仅依据已有更细尺度的 CSI 边界在当前分区内细分。分区的合并和细分应形成可复现的层级，调粗时分区总数不增加，调细时不减少；分区变化是离散事件，连续参数的相邻取值可以得到相同结果，缺少足够边界证据时不能编造细节。所有分析面继续有唯一分区，分区连通并重建共享接口及报告。

参数变化后显示待应用状态，点击“开始识别分区”后更新结果；识别期间可取消并保留上次结果。页面显示当前粒度与实际分区数。导出 JSON 保存选用数值及对应识别结果，导入旧结果时默认显示原有中档结果。参数变化不会自动修改已导出的结果。

## 实现与验收

涉及 `web/csi-boundary/index.html`、`styles.css`、`app.js`、`partition.js`、`tests/partition.test.cjs` 及必要的现有 CSI 分区接口；在对应 spec 中先写伪代码。按项目要求更新 design、spec、task、todo、usage、changelog 并重新构建单文件网页。

以肩甲为基准：0.5 保持原有 7 区及源指纹；以 0、0.25、0.5、0.75、1 和额外中间值采样统计分区数，并核对所有分析面标签、分区连通、跨区接口及导出回读。再用简单及非对称网格验证空证据和重复结果，检查旧 JSON 导入、取消、浏览器交互及原网页回归。详细数量以实际测试为准。

已实现：数值与滑块双向同步，任意 0 至 1 的合法数值经“开始识别分区”应用。肩甲在 0、0.25、0.5、0.75、1 下分别得到 1、4、7、66、125 区；各结果检查了面覆盖、连通、接口与 JSON 回读。1001 个连续取值另在合成条带上检查了数量单调。无细尺度证据时不增加分区，基准区本身不连通时明确报错并保留上次结果。肩甲 0.75 结果包含单面小分区，细粒度仍需人工复核其结构意义。

## 取舍

现有四种邻域尺度可直接切换，但肩甲的分区数依次是 6、13、7、63，并非按尺度单调，不能直接当作粗细滑块。分层合并和细分以原始 CSI 证据为基础，但不同粒度仍是候选分区，不保证符合美术语义。

# Retop 使用说明

### TopoGun CSI 肩甲试验

本轮产物位于 `artifacts/topogun-csi-trial-2026-11-24/`。在 TopoGun 使用 Load Scene 打开 `shoulder-topogun-final.tgs`，其参考模型为同目录的 `shoulder-reference.obj`。`shoulder-topogun-final.obj` 是 TopoGun 原生导出的 496 四边面网格。可用 View Ref 切换高模叠加查看。

`topogun-preview.png` 为实际窗口，`compare-front/back/side/top/angle.png` 为左右原高模与低模对照。validation.json 记录拓扑、穿插和抽样偏差。此版沿当前 CSI 构面，浮雕被简化，局部轮廓和厚度有偏差，需继续优化保形。

### 高模 CSI 分区网页

在 `subproject/retop` 目录执行 `node web/csi-boundary/build.mjs`，生成 `web/csi-boundary/dist/index.html` 单文件；本次自动化浏览器不允许打开 `file://`，该方式尚未实测。也可执行 `python -m http.server 18765 --bind 127.0.0.1`，在同一机器浏览器访问 `http://127.0.0.1:18765/web/csi-boundary/`。

页面默认分析内置肩甲；也可导入 OBJ、STL、网格 JSON，点击“开始识别分区”。拖动旋转、滚轮缩放，使用视角按钮查看不同方向；识别完成后可导出 JSON 并再次导入查看。取消任务保留之前结果。结果是高模上的候选分区，不生成低模。大模型如使用内部分析代理，页面提示原模型与代理面数，分区标签只对应代理。JSON 并非已验证的 TopoGun 原生格式。

“分区粒度”可拖动滑块或直接输入 0～1 的数值：0 最粗、1 最细，默认 0.5。修改后点击“开始识别分区”应用；结果区显示实际生效的粒度与分区数。分区变化是离散事件，相近数值可能得到相同分区；无法从细尺度证据可靠细分时分区数不会增加。结果 JSON 保存已生效的粒度，旧文件按 0.5 显示。

“CSI 拟合平滑”独立于分区粒度，支持输入或拖动 0～1，默认 0.5。修改后点击“开始识别分区”应用。正值使用原网页 CSI 模式的红色解析曲线，允许偏离高模和分区色块的三角边，色块提供区域参考。曲线控制点和共享接口保存到 JSON。0 显示黄色网格边界，勾选“查看原始边界”可对照原始分析结果。旧 JSON 没有后处理网络时使用已有识别曲线。近角合并沿用已有规则并经过局部网格检查。

### Retop 人物 UV 倍率

在 Retop 工具启用“复杂人物”，展开“UV 与颜色贴图 → 人物 UV 纹素密度”。可分别修改脸、头发、躯干正背、手臂、裤腿和靴子的倍率并点击“应用倍率”。相同表面使用两倍线性倍率时，相对所需贴图面积为四倍。当前档已烘焙且已载入高模颜色图时自动更新贴图，其他受影响档位可按需重新烘焙。

## CSI 贴图辅助分区
先导入含UV的OBJ或完整分区结果，再选择PNG/JPEG/WebP颜色贴图。设置“贴图参与强度”（0～1）并点击“在当前分区上细分”，保留已审查主区及导线；粒度控制区内细分尺度。0恢复贴图细分前的基线。导入已保存颜色证据的JSON后，不必重新加载图片即可调整强度。
轻量代理没有原高模UV，只能复用已保存证据；更换图片时应导入包含原高模UV的完整结果。点击“开始识别分区”是从模型重新识别，需要重新提供图片，并可能丢失人工审查调整。贴图含阴影、绘制缝线，输出仍须审查。小闪第四版使用 HIGH.png、强度0.65，当前审查文件为 artifacts/moxing-csi-review-2026-11-24/csi-review-v4-texture-details.json。

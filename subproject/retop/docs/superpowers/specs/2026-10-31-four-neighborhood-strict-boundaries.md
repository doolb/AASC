# 同一高模的四邻域严格边界

用户纠正：所有四档边界都须使用面积比＋曲率差。进一步明确“四档”指同一高模使用四种邻域尺度，不是在四个已生成的候选网格上分别检测。

## 固定数据流

同一原高模快照 → 面积主方向框架 → 原始面面积与几何铰链曲率 → 远/远中/中/近四种立方窗口 → 逐边面积比 AND 曲率差 → 已通过的源网格边 → 每档独立的分组/矢量显示候选。

原高模及既有远/远中/中/近形体候选不变；四个显示副本具有相同的原高模几何签名。第五档高模本身不进行形体替换。图像、参考模型、候选LOD、历史平滑组、自定义法线不作为边界证据。

## 统一判据

直接邻面面积比和两侧邻域代表面积比均须达到面积阈值，且曲率相对差与最低曲率同时通过。所有档位共用同一阈值和计算定义，只改变窗口。不得根据组数、闭合程度或图像效果加入峰谷分区、单独夹角边、固定模板或无证据连线。

窗口沿源面积主方向归一，远为覆盖整个物件的单一立方容器；其余默认最长边4/16/64分格，取3×3×3邻格。面邻接、同侧半空间、种子法线半球及有限表面距离限制跨层采样。保留原始面面积，不通过重网格人为制造面积差异。缺少内部铰链或两个方向的曲率观测时标未知，不能当零曲率；测试铰链自身不参与双侧曲率测量。

已有严格检测器与新四尺度路径共用 `contrast_passes`，保证没有独立的角度旁路。外部传入边索引仍逐边复核选定档位条件。

## 预览与验证

正式界面移除起伏/单夹角来源；四档可单独切换，报告含各边实际面积比/曲率差、窗口、同一源签名、未决和绕漏。边界断线/为空时保留诊断，不放宽判据以凑分组。旧实验代码只作历史回归，不参与当前四档计算。

独立 background + factory-startup 验证：密度变化但平面不造边、同曲率密度变化不造边、等面积硬折不走角度旁路、真实面积与曲率共同变化可检测、窗口缺证据保持未知、变换、原数据保护、不调用候选形体/起伏路径、输入边不能绕过条件、四档显示几何相同、复用/手改保护与失败清理。实物检查正、侧、顶、背、斜，左原件右对应高模边界副本。测试与数量不代表完整包边或重建成功。

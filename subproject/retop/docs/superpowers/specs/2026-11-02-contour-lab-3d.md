# 浏览器三维形体与卡线实验室

用户要求把既有Blender插件相关形体功能迁移到独立网页`contour-lab-3d`。2026-11-03更新五档：远整体长方体，中远解析规则体，中在规则体上细分拟合转折/关键节点，近在低模上继续细分拟合边界并加入卡线，超近从卡线中模做涡轮平滑。前四档必须全四边面，原高模独立只读对照。静态OBJ/STL/JSON输入、OBJ输出。

## 实际数据流

源只读快照 → 朝向一致的分析副本 → 同源四种立方邻域面积比＋曲率差 → 候选边界及平滑分组 → 解析体全四边基础 → 四边细分＋法向相容的最近面/特征节点拟合低模 → 再细分＋拟合边界 → 沿结构边双侧插入四边支撑带 → 从中模做Catmull–Clark细分平滑 → 逐档拓扑、父级指纹、双向抽样距离、原签名检查 → 当前档自动平滑组与角点法线 → 同步显示和导出。

四种边界邻域不读取LOD、不依赖视角、不以单夹角代替联合条件。邻域不足或单侧超过256面预算保留未知；总访问超过400万拒绝。小结构链按长度过滤，手动修正单独记录，不当作自动识别成功。自动映射到中模后以35°转折过滤过量支撑带，这是加密筛选，不是源边界识别旁路。

`hierarchy.js`管理共享边细分、三角端帽到四边面的对边传播、源壳体锁定与法向相容最近点拟合、局部防翻折线搜索、双侧支撑带及真实Catmull–Clark。低模默认1级，中模额外1级，每次4轮拟合、强度0.85，超近1级；32768四边面预算超限拒绝。父级指纹可核对生成关系。更新基础体后联动重建后续三档，原模、远档和四尺度边界复用。

卡线为真实网格支撑带，未作精确等宽倒角。保持旧OBJ面带分组`g bevel`，报告`geometricChamfer:false`。超近只从中模做Catmull–Clark，不复制/回投原高模；可能收缩。源孔洞若未被基础体表达，后续不能凭拟合补回，源拓扑比较与父级继承分别报告。

## 显示与文件

左真实原高模，右所选候选，五视图及共同轨道相机，可切换正交/透视并保持角度、平移、缩放。模型法线仅在着色器中旋转到相机坐标系，主光与补光跟随相机，左右使用同一光照，不修改几何或导出法线。透视镜头缩放不让相机进入源模型；选边的屏幕深度先转为相机线性深度后比较。UV展开独立为2D，相机投影按钮隐藏；平面/分组平滑法线、线框、结构边、分组颜色和基础UV棋盘可切换。两个独立滚动/折叠面板，参数变化禁用旧结果导出。计算在Worker内，可取消，源变化时终止旧请求。

源码目录`web/contour-lab-3d`，离线单文件`dist/index.html`。默认原肩甲由既有FBX只读提取，记录来源哈希和静态变换；不依赖Blender运行时。不改二维工具、Unity代码、高模源文件或已存在的候选工程，不自动提交或安装依赖。

OBJ包含真实几何、每角基础UV、分组平滑法线及切角面带标签。工程JSON包含源、所有设置、手动/排除边、四尺度证据和五档候选；重新导入从源重算。当前仅静态几何，不保留原材质、UV、蒙皮和动画。

## 研究库与边界

Directional用于研究四向场、可积参数化、跨缝约束和网格提取；BFF用于几何确定后的切割、边界控制和展平。二者没有替代边界识别、误差约束或卡线几何的能力。本版不嵌入、不安装二者，使用自有JS几何路径及基础独立面UV图集；界面明确该图集不是BFF或全局无缝展开。

后续方向场重拓扑必须引入真实场约束、奇点布置、切缝整数条件和网格提取，以及跨缝/翻面/重叠验收。当前全四边化不得更名为这一完整流程。

## 2026-11-03：参考结构线网与四向场分区

新增独立结构补全候选，旧四尺度面积比＋曲率差证据和旧CSI原样保留。以凹凸曲率屏障和最小面片面积形成稳定区域，用四向场的cos(4θ)改变屏障和共享边界的各向异性周长代价；周长下降需保持面片连通。不以角度结果改写原检测。保留与真实输入证据一圈邻面接触的候选网络分量，独立壳体隔离，手动/排除继续生效。

流程为面积/曲率及四向场结构补全 → 物体主方向多视角轮廓匹配 → 共享CSI拟合 → CSI四边补面。`silhouette-match.js`按面积PCA主轴及对角方向取13个投影，与页面相机无关。用固定结构边界的调和曲面作为分区规划代理，比较原高模和代理的投影掩码轮廓。代理仅用于前置分区评估，不输出为低模，不向低模内部回投高模。

只在偏差明显的方向中尝试按平滑分析法线的零交叉拆分大曲面；两侧均需保持相连盘状区域和足够面积，新增共享线需形成两端连接的非分叉通路，且有投影轮廓支持。显式排除边不能用于新分界，已有共享界线保留。只有所选方向的平均偏差改善超过10%、多方向代理综合平方偏差降低超过4%，且其他方向P95退化未超过容差的1.5倍时接受；每次中档规划最多增加2区。不会把每个视角的轮廓都切成永久分区，也不把微小细节补成大量碎区。

多方向轮廓支持的接口限制规整位移；新增轮廓接口还分别约束相应投影平面中的规整偏移，并在CSI拟合后报告对原轮廓链的双向投影抽样偏差。端点、角点、共享连接与I/C/S双柄表示继续沿用原规则。三维边链偏差和轮廓投影偏差分别报告，不能相互代替；复杂空间路线仍可能出现三维拟合超差，不能把投影容差达标称为全面拟合完成。

肩甲参考由6区增加为7区，多方向轮廓参与了实际CSI拟合和低模生成，500面上限内生成496个四边面；新增分区亦成为源预览与低模的第7个结构平滑组。研发中的七视角对照显示正面上沿覆盖和整体平均轮廓偏差改善，但顶/底视局部最大偏差有增加，保留该事实，不宣称所有方向均改善。原高模、其他四档几何和UV保持不变，卡线中模接入仍暂缓。

`tests/silhouette-match.cjs`覆盖关闭回退、代理边界固定、方盒无额外切分、肩甲轮廓分区、排除边、刚体/尺度不变性、投影CSI约束、预算与闭合四边网格及实际七视角形状对照。`tests/silhouette-match-browser.mjs`使用真实Worker从原高模重新计算，不用导线缓存，并通过关闭开关重新拟合验证原6区恢复。最新验证与发布事实见`artifacts/contour-lab-3d/silhouette-match-release.json`。


## 最后匹配轮廓：结构分区固定

当前顺序为面积/曲率与四向场确定结构分区 → 共享CSI拟合 → 协调四边面带并补曲面 → 最后匹配轮廓。“中档最后匹配轮廓（保持结构分区）”默认开启；原参数名保留兼容旧工程JSON。前一版以法线零交叉新增分区的办法已撤回，当前代码不再使用它。

开发参考`artifacts/boundary-image-study/boundary-solid-independent-v4.png`中，整体投影外轮廓与包边、接头、装饰区域的结构界线承担不同作用。参考图仅用于开发理解和对照，不进入正式计算，也不把像素位置、对象名或轴向编码到算法。

`boundary-guides.js`恢复仅按三维结构建立分区、共享整边和I/C/S。轮廓开关和容差不再影响分区标签、分区数量、接口连接、角点或CSI控制柄。补面的拓扑、分段密度与共享采样确定后，`silhouette-match.js`才按物体面积主方向的13个投影匹配原高模与当前候选的轮廓。只使用投影轮廓压力，不查找高模最近三角面，不将高模内部细节回投低模。

每块大曲面使用6个平滑多项式形状模式，模式在四条补片边界上严格为零。多视角轮廓约束联合求解三维位移系数，配合幅度正则和线搜索；只有综合投影偏差下降、其他方向退化未超过容差且四边面有效时接受。窄包边、端部宽度族、共享CSI采样和宽度中线固定。细节不够用时保留残差，不通过加分区或加面来降低指标。默认轮廓容差1.2%，属于像素抽样的优化目标，不是解析误差上界。

最终参数作为`proposal.surfaceMatching`保存，包含补片ID和形状模式系数；`csi-surface.js`可从原结构CSI与这些参数准确重建最终四边网格，不需要原高模的内部坐标。OBJ输出实际匹配后的模型；工程JSON保留参数。`csiCharts`记录四边补片网格的连接索引，未增加面或改变边流连接。

肩甲保持6个结构区、6个结构平滑组、498个四边面。调整两个大曲面的内部形状后，正/背、侧、斜视轮廓改善，顶/底视与原结构CSI生成的结果相同。源高模、源分区、结构CSI曲线、共享边坐标、包边中线以及其他四档网格/UV保持不变。不会把曲面在当前视角形成的上沿轮廓强行当成永久分区。

9项最终匹配检查涵盖模式在边界为零、分区/接口/四边连接不变、原件只读、参数回读重建、高模内部坐标独立、刚体/尺度协变、方盒无额外修正和实际七视角对照。真实网页Worker还比较开关前后的完整结构CSI，要求逐项一致；关闭只恢复原曲面形状。发布与验证事实见`artifacts/contour-lab-3d/final-outline-release.json`。

## 2026-11-08：光滑环带的切向剖面与独立布线

此前低模仅以两圈CSI的位置作Coons/薄板补面，同一边界缺少跨宽度的切向约束，不能唯一确定光滑鼓面；最后的轮廓模式还会改变环带内部。现在识别单孔环带时，从同组边界相邻面提取面积加权单侧法线，作为可导出的CSI `surfaceFrames` 属性。补面只消费CSI控制点、连接和这些边界法线，不向高模内部投射或查找最近点；旧CSI没有该属性时沿用原补面。两端法线约束Hermite跨宽剖面，弯曲量参与横向分段预算；环带剖面不参与后续大曲面轮廓模式。

环带原有几何边界采用有位移上限的正负两步保形平滑，避免预平滑压低凸起；统计分界的预处理仍沿用原有规则。分区标签、角点/接口连接和原高模不改。顶端高度只是研发模型上的验证量，生产算法不读取模型轴向或顶点索引。

每个有剖面的分区在自己的CSI曲面参数域内优化内部点，综合夹角、边长比例和翘曲；共享真实边界固定，内部走线方向可独立变化。曲率高处密、平缓处疏，仍协调相接边上的采样数量以维持焊接四边网格；没有通过错缝或悬空T接点实现独立布线。保留真实凹口可能产生的尖角，不将全四边面或质量指标下降称为完整重建验收。

独立球面环带验证了曲面剖面误差改善、法线随刚体变化、CSI导出回读、源坐标独立及焊接参数缝；实际肩甲还检查弧顶收缩、面带夹角/翘曲、500面预算、闭合与穿插。网页七视角、重新拟合、OBJ和发布事实以artifacts/contour-lab-3d/smooth-profile-release.json为准。卡线中模接入继续暂缓。

## 2026-11-08：保留原始转折，同分区面形匹配

用户要求低模尽量匹配高模的面，并还原包边内侧明显转折。统计分界原先先预平滑、再找角点，会将原始转折移到邻段；现在先在原始路径上用多尺度转角锁定稳定角点，再进行有界正负步平滑。平滑后的统计环带交界约束到相邻光滑组的局部源三角面，并收紧该类边的拟合容差；不改变面积/曲率分区归属。所有组记录单侧边界法线，四侧补片规划用局部法线区分内外角和实际三维转角大小，避免用单个全局投影平面的角度漏掉三维转折。

## 2026-11-08：高模细节过滤参数

在“05 / 分级细分与拟合”增加“高模细节过滤”，范围0～100%，默认60%。0%保持上一版原高模面形拟合；数值越大，拟合目标中的分区内部细小起伏越少。修改后点击“识别结果 → 重新拟合CSI与低模”；改变参数会标记结果过期并禁用导出。工程JSON保存 `settings.surfaceSmoothing`，连续导线JSON的 `proposal.surfaceFitting.report.detailSmoothing` 记录实际过滤强度、轮次、移动顶点数、固定顶点数和位移。

仅在拟合用副本中对大曲面的内部进行成对正负步Taubin过滤，固定跨区节点和开放边，不处理包边/窄侧条，不修改左侧原高模。参数映射为最多180对过滤步，具有退化面和逐步法线反转保护；它是拓扑尺度的过滤强度，不是以世界单位保证的截止频率，不同网格密度效果会不同。强过滤会舍弃部分真实起伏，应以多视角对照选择。着色“平滑”和CSI“结构规整容差”仍是各自独立的功能。

同组面形拟合和最后轮廓匹配均使用这份副本，避免最后一步重新追逐被过滤掉的小细节。CSI曲线、角点、组归属、四边面连接和面数不由本参数改变。只改过滤强度或最后轮廓参数时复用已确认的CSI网络，重新求解低模；更改导线/方向场参数仍重算CSI。原高模和其余四档保留。

独立含波纹的大弧面验证过滤强度、宏观弧顶、开放边与组间固定、源件只读和旋转/尺度一致性；网页原生Worker验证默认60%、调到0%的旧版形状恢复、导出脏状态、七视角及OBJ。实际发布与结果以 `artifacts/contour-lab-3d/detail-filter-release.json` 为准，仍为候选。

| `detail` / 细小面分界 | 原高模近尺度的细分边界，在每个中档父区内部取交集并拆连通区，不能跨越或替代父区；独立连链、锁角、矢量化I/C/S | 仅中模补充候选 |

主轮廓不是全都对应原网格上的固定边。分区仍先按三维证据确定，轮廓约束最后只调整保形，不改分区。`surface.edgeKeys`/`curveIds`引用中档共享交界；`detail.patchGroups`、`regions.parentPatch`、`chains`及`curves`明确细区父属和原高模来源。近尺度大区若跨过中档界线，会在父区内分别拆开，不能直接把原近档分区用作中模父级。粗细层重合处不重复登记为细节；排除边继续排除。

细节基于未被修改的原高模，而不是低模拟合用的细节过滤副本。因此调高“高模细节过滤”可以让低模简洁，同时保留供中模使用的细节证据。既有curve.role的major/detail仅是旧面积显示提示；模型档位用途以新layers策略及引用为准。低模报告显式记录 `boundaryLayerUse.detailConsumed:false`，拒绝将detail注入低模的策略。

## 2026-11-10：按高模剖面修正包边经纬，连续约束中线位置

用户指出包边平直段被做鼓、中线沿宽度滑动。旧流程中，开口包边继承CSI补面的估计剖面，未重新核对同区高模；整线平顺只限制空间误差，允许节点横向移动。即使补上节点居中，连续Gordon线在节点之间仍会相对两侧轨道偏移，因此本次同时修改剖面捕获、整线拟合和实际曲面的连续求值。

所有包边在构造经纬网时读取同一CSI分区的过滤高模副本。用两侧轨道确定沿程站位、宽度与法向，求高模三角面与站位平面的交线，剔除不相容法向、远离宽度走廊和覆盖不足的数据；仅在至少覆盖60%宽度、归一化拟合RMS小于1.5%宽度且弧高小于30%宽度时采用剖面。五项低阶基函数分离端部仿射差和横向曲率：真实CSI边界固定，只将相对端部的曲率用于内部形状。证据不足时明确记录fallback，保留已捕获的法向高度，不跳到其他分区猜测表面。

近直线剖面的过滤尺度沿用“内部CSI平顺”：宽度的0.5%＋3%×强度，默认50%即2%。对剖面弧高使用连续软阈值，避免在略低于/高于阈值的站位之间突然切换平面与曲面；明显弧度保留。这个阈值是低模简化尺度，不宣称被归为近直线的高模数学上完全共面。新报告保存原拟合系数、原弧高、保留增益、覆盖、RMS和阈值。

原始纵向CSI仍做整线C2三次样条拟合；新增独立站位误差约束（包边中位宽度0.5%），必要时允许更多内部支撑，不以整条线误差容差代替站位居中要求。实际曲面在每个连续参数位置按两侧真实CSI轨道构造横截面，只保留法向高度，固定宽度分数并去掉沿程漂移；开口端部的一段站位间距内平滑过渡以保护原端部CSI，环带周期闭合。原始CSI支撑曲线之间的C2不等于声称经过真实边界/横截约束后的所有显示线在结构角点处也全局C2。

保存sourceProfiles版本2与实际sectionNodes；剖面、控制线、导线显示和真实低模使用同一个受约束放样定义。参数重放只读已保存的节点与曲线，不再查询高模；旧定义缺少这些字段时仍按旧算法重放。所有操作只更新中档低模及其UV，原高模、源证据、解析CSI外边界和另外四档保持原样。预算仍按最终三角数核对，未以加面掩盖错误。此修正不替代进一步的CSI外形误差优化，也不接入卡线中模。

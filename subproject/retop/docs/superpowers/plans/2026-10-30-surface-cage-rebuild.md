# Surface Cage Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现三角高模分析、可修正结构分区、受约束重建和细分验证的 Blender 插件。
**Architecture:** 独立分析模块产生面区域/边特征；重建模块仅处理已支持且可检查的网格或选区；界面管理非破坏副本与报告。共享几何接口，不引用任何肩甲坐标。
**Tech Stack:** Blender 4.3 Python，bpy、bmesh、mathutils、标准库。
**Spec:** `docs/superpowers/specs/2026-10-30-triangulated-highpoly-reconstruction-design.md`

## Global Constraints
- 保留源对象及 UV/蒙皮数据，不自动修改游戏文件，不新增依赖，不提交或推送。
- 先识别再重建；不可靠区域必须报告，不用全局自动重网格冒充手工卡线。
- 主要验收对象为 Catmull-Clark 再细分结果；基础中模单独报告。
- 全部运行参数无量纲或相对模型尺度；没有固定名称、轴向和坐标。

## Review Focus
- 同一形状的三角化对角线变化：特征不能依赖对角线方向。
- 源修改、重分析、编辑模式：不能使用过期面索引。
- 多壳/真实开口/非流形：不能跨壳生成或擅自封口。
- 重建失败/取消：原数据不变，不留下伪成功对象。
- 缩放和反射：在统一坐标度量，恢复正确法线与对象变换。

## 用户纠正：鳞片也属于结构边界

- 鳞片边缘同样是需要识别和保留的结构边界，不应因属于内部纹样而剔除。上一轮将鳞片线统称为“误检”的判断撤回。
- 主包边与鳞片均按实际结构追踪；检查各自的连续性、闭合或合理终止、流畅度和真实交汇。需要排除的是无结构依据的碎线、多余分叉与跨片错接，而不是鳞片本身。
- 先确定每条结构边界的一根主线；有倒角截面依据时再生成两侧卡线，不强制所有鳞片边缘使用相同宽度或补成闭环。保持允许适度离面、形状简单、少弯折的要求。
- 本次仅修正判断与文档；现有算法没有加入鳞片排除过滤，保留当前候选。原有测试记录不作为新的几何验收。

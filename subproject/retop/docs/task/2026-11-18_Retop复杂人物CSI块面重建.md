# Retop 复杂人物 CSI 块面重建实施计划

> 使用 writing-plans 制定计划，按 executing-plans 在当前工作区逐项实施；不提交、不推送、不创建 worktree。用户已确认结构重建方案。

**目标：** 从高模自动识别主块面并按 CSI 边界重建，低模不超过 2122 个三角面。

**架构：** 通过连通法线区域的变分拟合建立平面代理和主块面；从区域交界提取共享 CSI、锚点与受约束的离散三角化，平面不增加内部线，复杂边界通过源面图保证连通。中模、UV、贴图沿用实际低模派生与输出接口。

**技术：** 浏览器本地 JavaScript、Web Worker；不增加依赖，独立 Blender 仅验收。

**设计与伪代码：** subproject/retop/docs/design/retop-texture-transfer.md、subproject/retop/docs/spec/retop-texture-transfer.md。

用户指出当前人物胸前袋体与 LOW 示例不符。目标从高模自动重建，在 2122 个三角面内保留大形、袋体主面、侧面转折和下缘，同时恢复 UV、颜色与源着色结构。LOW 仅作验收对照。

设计和伪代码见 retop-texture-transfer 文档中的待确认方案。新增 feature-patches.js 提取预算尺度上的主块面，boundary-guides.js 生成结构 CSI，csi-surface.js 与 structure-grid.js 按补片及共享边构面，engine.js 接入预算分配、失败报告和中模派生。viewer.js 显示真实分区。贴图模块复用现有接口。

实施顺序：先完成胸前主块面的源数据识别及几何验收用例，再扩展多边界补片的构面与最小预算分配，随后检查实际低模派生中模，最后重新展开 UV 并输出颜色。每步保留源几何指纹及独立对照产物。

自测需包含带细小翻盖的凸起块面、主面与侧面转折、多分支与带孔区域、预算不足、共享边无裂缝、中模父子对应、法线连续性和 OBJ/MTL/PNG 回读。兼容旧肩甲、无 UV OBJ、STL 与工程 JSON。性能使用 30000 三角面分析副本及 150 万面原高模，记录分区、构面和烘焙耗时及峰值内存。

风险是主结构与微小细节的分离不准确、闭合高亏格补片切分失败、边界最低预算已超限及低预算的大形误差。首轮实现预计 1–2 个工作日，视觉质量按统一相机逐步验收，不以基础数值检查替代。

## 执行步骤

### 1. 主块面识别

- 文件：新增 feature-patches.js、tests/feature-patches.cjs。
- 接口：build(source, {triangleBudget, patchCount, iterations}, progress) 返回 patchGroups（逐源面）、patches（源面列表、面积、中心、法线、误差）及只读指纹。
- [x] 编写凸起块面带细小细节、闭合曲面、缩放平移和预算调档的失败用例并验证失败；多个壳体补充验收随主流程集成。
- [x] 实现层级种子、连通优先队列分区、面积加权代理拟合、小区域与共面区域合并。
- [x] 验证主面覆盖、源数据不变和高档更低的法线拟合误差；目标 30000 面副本提取 258 个区域，耗时 1.6 秒，源指纹保持。

### 2. 共享结构 CSI

- 文件：boundary-guides.js、tests/feature-patches.cjs。
- 接口：featureNetwork(source, features, options) 返回共享区域交界、I/C/S 曲线、源站位、基础锚点与闭环信息。
- [x] 编写两块共享交界只定义一次、闭环至少三个锚点、曲线复杂度随预算变化的失败用例。
- [x] 在三及以上区域交点和边界分叉处建立锚点，复用现有 I/C/S 拟合；按法向转折加权控制弦偏差。
- [x] 验证真实源面边界及共享方向、重复与缺口。

### 3. 依结构构面与预算

- 文件：structure-grid.js、csi-surface.js、tests/feature-patches.cjs。
- 接口：generateFeatures(source, features, network, options) 返回网格、csiPatchGroups、csiEdges、budget 与形体/拓扑报告。
- [x] 编写平整凸起主面、带孔区域、环状闭合曲面、预算不足及实际三角化的失败用例；球形和真实人物保形继续补充。
- [ ] 在源面图中用锚点距离场做离散受约束三角化，原共享边界共用锚点；按代理平面计算有界锚点位置，局部无效时保留原站位。
- [ ] 按最小锚点、曲线误差与构面结果协调预算；只在同区域匹配四边面；拒绝破裂、拓扑改变与超限。

### 4. 主流程与查看

- 文件：engine.js、hierarchy.js（仅适配需要时）、viewer.js、index.html、build.mjs、app.js 的 Worker 模块序列。
- [ ] 编写复杂闭合源走结构构面、直接重建及从真实低模派生中模的失败用例。
- [ ] 将复杂人物路径接到 feature-patches 与 CSI 构面，报告新路径及未支持分区，不静默全局减面；已支持肩甲路径继续原逻辑。
- [ ] 运行原层级、预算、肩甲、法线及真实 Worker 回归。

### 5. 目标模型完整验收

- [ ] 只从 HIgh.obj 生成，2122 三角面上限；LOW 仅作独立对照。
- [ ] 正、背、侧、顶、斜视查看实际网格，胸前检查主面、侧面、下缘和躯干连接，复核头、耳、手与装备。
- [ ] 对新几何重新展开 UV、从 HIGH.png 烘焙，回读 OBJ/MTL/PNG/SVG 和源法线；记录误差、耗时、内存与未完成项。
- [ ] 更新 design/spec/task/todo/changelog，并完成整体代码复核。

## 执行记录

- Ruling：采用平面代理的法线区域拟合及源面图离散构面，以处理原路径不支持的多边界分区；保持浏览器本地，不引入 CGAL/Blender 运行依赖。风险是离散三角化需逐项验证流形与定向，失败不算通过。

- 主块面模块首轮红绿测试通过；结构 CSI 的共享接口、闭环站位、容差调档测试通过。离散构面已在带微小凸点的闭合凸起板件与环状曲面上保持流形、Euler、共享边及预算；额外验证软曲面参数缝不变成硬着色边。正在验收目标人物。

- Ruling：目标人物的视觉失败优先于基础审计通过；不接入未经目标验收的 feature-patches 路径，不把数字达标的候选标成完成。代价是步骤 4、5 仍未完成，中模、UV 和颜色输出尚未切换至新结构候选。

- 诊断：初始 863 锚点，189 个拓扑修复锚点，7 个保形补点。关闭源法线、取消平面投影仍有头部与胸前形体损失。尝试法向一致性、限制平面扩张、区域约束收线及代理平面误差，均未达到示例质量；试验仅在临时脚本和 artifacts 中，不进入正式算法。
- 对照产物位于 `subproject/retop/artifacts/moxing-csi-structure-2026-11-18/`；`source-check-*` 中左为实际 HIgh、中为 30000 面源分析副本、右为诊断候选。其余三列图左为 LOW 验收参考、中为先前候选、右为本次试验，不能混称原高模。
- 本轮复验：feature-patches、texture-transfer、目标袋体区域回归、hierarchy 的 14 项及 triangle-budget-and-sculpt 的 7 项通过；独立网页 build 成功，git diff --check 无空白错误。上述通过仅说明模块与旧路径未检出回归，不替代人物视觉验收。

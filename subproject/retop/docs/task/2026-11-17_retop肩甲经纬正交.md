自测：最终线交点夹角、实际网格边流、轮廓、穿插、导出回读及正侧顶背斜视。兼容：旧参数回放和其他分区；性能：记录参考模型求解耗时。风险：固定边界、曲面形状与严格正交可能冲突。预计工时：4–8 小时。

启动时记录：高模 749794 顶点、1499606 原始面，低模 1085 顶点、1355 面，两者均是单个人物对象且尺度不同。当前代码允许 256 MiB 导入，已有完整高模实测和工作副本处理；已有文档将低模作为外观及布线参考，同时导入和自动配准当时未验证。工程自带肩甲原有环带回归通过，最终曲面采样仍有角度偏差。

2026-11-17 试验：对轨道配对加局部正交代价，最终曲面 P90 由 12.58° 增至 13.46°；未达到 10° 试验目标，已撤回试验代码。需继续定位后续曲线平顺、边界修正及网格连线的影响。

继续定位：配准轨道站位平均偏差 3.10°；Gordon 原始曲面、边界修正后及剖面约束后的连续采样 P90 分别为 10.21°、10.53°、12.58°。后续方案须检查连续曲面和实际网格之间的参数映射，同时保留 CSI 边界、剖面、旧参数和防穿插约束。

正交流线试验：合成错切圆柱通过；肩甲在单调保护下 P90 降至 7.06°，但会移动接缝，固定接缝后 P90 恶化为 37.69°；没有通过实际边界、网格和穿插验证，未接入产品。参考：椭圆型曲面网格生成 https://www.sciencedirect.com/science/article/abs/pii/S0021999185710789；边界处理 https://www.sciencedirect.com/science/article/abs/pii/S0021999108002878；场对齐网格 https://vcg-legacy.isti.cnr.it/Publications/2015/JTPS15/ 。

验收记录（2026-11-17）：自带肩甲包边中心纬线交角最大偏离 1.98°，实际四边面角偏差 P90 为 32.27°，下缘与两侧转角分别为 31.37°、34.78°、31.71°。两圈边界逐点相同，补线经过实际网格节点，保留 12 个收线三角面，低模共 965 三角面。七组回归通过，覆盖旧参数和新参数回放、穿插、UV 无重叠及 OBJ 往返。Chrome Worker 七视图通过。256 站合成环带的候选采用稀疏或完整状态得到相同回放定义；并行运行中的整体用时接近。历史整线平顺与剖面对照用例所需的旧结果 JSON 在本地缺失，两个文件中的前置合成用例通过。

整人物回归：`HIgh.obj` 经 Node 常规入口约 64 秒，清理 98 处狭长片，30,000 三角面的工作副本输出有效的 2122 三角面混合低模，原数据指纹一致。整人物 CSI 因分区边界未覆盖触发回退，肩甲正交量化采用内置肩甲。

红框弯折复验（2026-11-17）：`curvature-network.js` 以实际跨排边转角调整内部节点，对相邻过钝四边面做局部收线；保留实体两圈和补线跨排边。`annular-section-wiring.cjs` 复现旧结果的 40.79° 转角，并覆盖导出边链转角、四分之一带宽导线转角及节点对齐。新结果红框实边转角 3.03°、显示导线最大转角 3.92°。七组回归和 Chrome Worker 正视复验通过，OBJ 和 UV 往返通过，低模为 965 三角面。

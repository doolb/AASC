# Retop 连续 CSI 分区粒度

任务：为独立 CSI 分区网页增加 0 至 1 连续粗细参数，默认 0.5；不生成低模。

设计：`docs/design/retop-csi-granularity.md`；伪代码：`docs/spec/retop-csi-partition-web.md`。

模块：CSI 分区层级、共享接口及导线拟合，网页参数及 Worker，结果 JSON 与自测。

测试：肩甲与旧默认结果一致；采样 0、0.25、0.5、0.75、1 与其他中间值，检查单调、覆盖、分区连通及接口；简单与非对称模型、无证据、范围错误、JSON 回读、旧结果、取消与网页操作。

兼容性：保持原网页默认行为，旧 JSON 未带参数时取 0.5；窄屏、单文件构建和本地 HTTP 验证。

性能与风险：识别沿用现有四尺度工作量，细分可能增加接口拟合开销；不得凭空制造分界，分析代理仍可能丢失原高模细节。预计 4–8 小时。

自测结果：肩甲 0、0.25、0.5、0.75、1 分别为 1、4、7、66、125 区，检查源面覆盖、分区连通、非默认接口与 JSON 回读。合成条带在 1001 个粒度值下分区数单调，覆盖无细分证据与基准分区不连通；旧边界修复回归通过。

# Retop CSI 分区边界后处理

任务：处理肩甲图中分区交汇与折线，允许适度偏离高模细节，增加独立 0～1 CSI 拟合平滑，不生成低模。

设计：`docs/design/retop-csi-boundary-postprocess.md`；伪代码：`docs/spec/retop-csi-partition-web.md`。

模块：独立网页边界处理和显示副本、CSI 拟合、Worker 和参数、JSON 导入导出、自测；复用原共享接口和相交检查。

自测：原高模不变；共享边/交汇点一致；0、0.5、1 平滑；尖角、开口、闭环、分叉；局部翻面、退化、新增穿插回退；显示色块与边界一致；JSON 回读、旧数据、取消和粒度。

兼容性：原 Retop 网页默认行为不变，桌面与窄屏；检查旧文件、OBJ/STL 输入和单文件构建。

性能与风险：高模采用已有分析副本；拟合和相交检查可能增加耗时。需要记录偏离、回退、未检查的接触与肩甲多视角观察，不把局部通过当作所有交汇的几何正确保证。预计 4–10 小时。

完成记录：肩甲默认强度移动 224 个共享边界顶点，14 点减小位移、1 点回退，最大位移为对角线的 0.406%；232 个中间转角平均 19.43° → 16.59°，大于 30° 由 46 减至 30。检查三角面面积、法向和新增非相邻真穿插；共面及共点接触未覆盖。CSI 按完整共享接口重新拟合，默认新拟合无超目标段，原识别仍有 3 段超容差。浏览器通过 HTTP 验证显示切换和 JSON 导出回读；用户红框机位、单文件直接打开和大模型代理需继续复核。

性能抽样：本机 Node 对已识别的 4595 面肩甲执行默认后处理及整线复拟合约 1.82 秒；此数字不包含首次四尺度识别，也不代表大模型性能。

近角显示修正已完成。复用现有 898→902、353→2222 两条记录，在各分区内重三角化受影响面并复拟合共享接口。目标交汇点保持原位置，显示副本为 4591 面，7 区连通，8 个替换三角面通过非相邻面真穿插检查。JSON 校验处理面到同区原面的映射并保留旧版本读取。用本地 HTTP 验证单文件网页的原始对照、导出和回读。用户截图机位待复核。

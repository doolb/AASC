# 贴图辅助小结构分区实施计划

目标：补齐用户标注的额头窄带、肩带小块，以几何和贴图联合提供实际分区，保持原高低模只读。

设计依据：design/moxing-csi-topogun-review.md；实现伪代码：spec/moxing-csi-topogun-review.md。用户已确认方案。

- [x] texture-evidence.js：UV 图片采样、原高模到代理的有距离/法线约束近邻映射、连通图细分。先测纯色接缝不切区、明显窄条被保留、零强度、坏 UV。
- [x] partition.js：在已有基线内部应用细分，复用共享网络拟合；保留审查导线，导出输入指纹和颜色证据，避免重复细分累积。
- [x] app.js/index.html/build.mjs：图片加载、0～1 强度、在当前结果上应用、回读状态、缺失 UV 提示；不改变旧模型的默认纯几何行为。
- [x] 小闪实测：HIGH.png 与高模 UV 视觉核验、原始数据与证据对照、小分区正面审查；运行已有回归及新增测试。

风险与兼容：贴图含阴影，输出均为候选；代理过粗不能表达亚面宽度细节。空间映射仅在距离和法线门限内使用近邻原面，未命中不使用颜色。UV 岛接缝本身不触发分区。无贴图、强度0保持旧行为。未批准进入 TopoGun。

性能：图片最大缩放到2048边长，代理用原有30000面；空间散列避免高模与代理全量两两搜索。记录样本运行时间，不增加依赖。预计本轮实现、测试与网页审查。

实施备注：肩带同色小块采用独立样本圈选约束，通用代码不含模型坐标。已完成只读代码审查，修正RGBA持久化膨胀、worker成功后source绑定及细分粒度传递，补充入口测试。美术验收仍待用户。

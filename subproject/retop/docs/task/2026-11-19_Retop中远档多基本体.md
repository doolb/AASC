# Retop 中远档多基本体

目标是让中远档自动选择多个闭合基本体，完整包住原高模。对于双足人物，正面应看得到独立胸袋、胸廓和腰胯的收放。允许相交。小闪的 LOW 仅作美术参照。

- 需求与实现见 subproject/retop/docs/design/retop-orthogonal-flow.md 和 subproject/retop/docs/spec/retop-orthogonal-flow.md。primitive-assembly.js 负责分区、选型和包覆，character-volumes.js 提取人物部位，primitives.js、engine.js、app.js、index.html 与 build.mjs 接入计算、预览、工作线程与导出。
- 兼容性与回归覆盖手动基本体、体块上限、原面跨体、刚体变换、参数往返、工作线程生成和源数据不变。人物分区回归命令为 node web/contour-lab-3d/tests/primitive-assembly.cjs artifacts/moxing-quality-2026-11-18/source-proxy.obj，在 subproject/retop 下运行。
- 小闪原高模完整五档计算耗时约 131 秒。中远档导出 24 块、1586 个三角面。独立从 OBJ 检查原文件的 1499606 个三角面，漏面、外露顶点均为 0，体块相交图完全连通。局部正面平均深度偏差从身高的 3.79% 降至 2.62%，斜前从 4.05% 降至 3.08%。
- 风险与实测边界：闭合凸体对腰胯和肩部会有外扩。五视图覆盖原剪影，额外投影面积为 14.25%～18.37%；未评估其他人体姿态的部位识别精度。验证产物在 artifacts/moxing-torso-envelope-2026-11-19。

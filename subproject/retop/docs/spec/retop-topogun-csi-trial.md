# TopoGun CSI 试验伪代码

## 个人技能调用

```text
请求操作 TopoGun ← 发现个人技能 topogun-retopology
读取 SKILL.md ← 核对当前输入和本机版本
需要 TGS 交接 ← 读取 references/topogun2-handoff.md
需要复用 Retop 试验 ← 读取 references/csi-trial.md，核实当前源码与文件是否仍有效
执行 ← 使用当前可用电脑操作工具，保存副本，回读原生导出文件
报告 ← 区分原生步骤、外部处理、验证结果和质量限制
```

```text
输入 ← 已确认肩甲分区 JSON，取后处理整线拟合网络和源网格
参考模型 ← 原坐标源高模写入独立 OBJ，记录指纹
边界骨架 ← 根据接口和共享节点对曲线按弧长采样，分界只保存一份
交接 ← 参考本机 TopoGun 场景 XML 字段写入骨架场景，绑定参考模型
CSI 初稿 ← 复用现有 CSI 曲面器，沿后处理网络按 1000 三角面预算构建连通四边面初稿
原生试验 ← 在 TopoGun 中验证骨架顶点边数，导入初稿，对全部顶点执行 Conform Verts 并另存场景
位移约束 ← 回读原生贴合目标，固定 CSI 分界顶点；外部逐次缩小内部点位移，检查面积比例、法向余弦和真穿插
导出 ← 重新导入检查通过的版本，原生另存 TGS 和 Alias OBJ；回读最终 OBJ 再次检查
检查 ← 回读实际保存结果，统计面数、连通块、开口、退化和原高模偏差
记录 ← 输出原生操作、文件、实测结果和未完成部分，更新设计与任务进展
```

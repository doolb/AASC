```text

来源 ← 原模型指纹、源材质指纹、坐标变换、组件、原面与逐角索引

训练对 ← 基础资产身份、高模条件、四边低模布局、预算、表面映射、许可、数据分组
```

## 推理操作流程

```text
输入审计 ← 读取任务；检查预算单位、坐标、法线、材质引用、源组件与输入健康
来源快照 ← 对原件记录指纹与变换；创建工作副本
代理决策 ← 按内存与采样成本决定是否简化副本；保护硬边、开口、薄层和源对应
代理验收 ← 与原件比较双向抽样距离及细小结构；超差则提高代理精度或跳过简化
采样包 ← 按表面积与组件/特征配额取点；统一比例归一化；保存源三角形和重心对应
几何条件 ← 使用冻结 Geometry AE 编码采样包
预算条件 ← 编码目标数量、单位与用途；与几何条件组成条件包
布局候选 ← 对约定种子从噪声开始，以适配后的 SQ-Diffuse 积分获得布局 latent
表面场 ← 用冻结 SQ-VAE 在相同锚点/对应表面解码 CDF/DCDF 和偏移
布局图 ← 提取补片、共享边与奇点；单列非四边区域及 T 接头
预算求解 ← 在共享边一致与拓扑约束下分配整数分段；候选不能满足上限则报告不可满足
候选低模 ← 由布局图生成真实共享顶点与有序四边面；局部修复必须重新计数
原件拟合 ← 限定源组件和表面层进行贴合；拒绝引起退化、翻面或穿插的更新
几何审计 ← 核对实际预算、拓扑、四边质量、轮廓和源表面距离
候选选择 ← 先排除硬约束不合格项，再按保形和布局质量排序；无合格项保留诊断结果
几何输出 ← 恢复源坐标与单位；写出保留真实四边面的低模及报告
可选烘焙 ← 仅对已请求且有来源的通道展开 UV 并逐纹素映射原件；记录漏采和跨层风险
交付检查 ← 独立回读几何、UV 和图像引用；比较原件指纹与多视角外观
最终状态 ← 分别记录几何、贴图及动作的真实结果；不得以候选替代通过结果
```

## 训练操作流程

```text
环境探测 ← 核对 GPU、驱动、算子与可用内存；验证 FP16 完整前反向
资产分组 ← 以原资产/人物身份划分训练、验证、测试；增强样本继承同一分组
监督布局 ← 从优质四边低模经 CDFGen 生成官方布局数据；检查字段、连接和质量
条件输入 ← 先复现官方原生条件；再加入派生或配准高模条件
对应建立 ← 在共同坐标与参考表面传递布局字段，锁定壳体；无效映射记录 mask 或拒绝样本
编码上限检查 ← 比较 SQ-VAE 重建与监督布局；细节丢失先进入表示诊断
冻结缓存 ← 对几何条件与布局 latent 离线编码，按缓存键保存；增强变化不得误复用
适配参数 ← 冻结基础模型，仅启用 LoRA 和所需条件模块；优化器只接收可训练参数
训练批次 ← 按预算和资产类型采样缓存；按原模型规则归一化布局 latent
噪声路径 ← 采样时间和噪声，以线性插值得到中间 latent 及速度目标
预测损失 ← 在几何/预算条件下预测速度；按有效项计算原版兼容损失
更新 ← FP16 与损失缩放、梯度检查点、累积、有限值检查、梯度裁剪后更新适配器
资源审计 ← 统计完整 step 与验证阶段显存；超过目标则进入配置降级而非隐式扩大预算
断点保存 ← 引用不可变基础权重指纹；单独保存适配器与必需条件模块；在完整更新边界保存优化器、调度器、缩放器、随机状态、数据游标、划分与配置
验证 ← 在留出资产解码实际网格，按同预算比较原版、微调版和旧 retop
接入门槛 ← 资源和质量同时通过才接入；最终测试集不参与训练与调参
```

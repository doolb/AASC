## 第二版审查导线（已实现，等待审查）

```text
输入 ← 第一版分区、美术低模、独立样本选点规则
低模对齐 ← 统一高度比例与包围盒中心；记录变换，只用于参考，不修改原件
碎区合并 ← 只合并指定胸前范围内、无独立体积意义的小区到实际相邻的大区；重新提取接口并拟合
形体导线 ← 在低模选定少量五官及手部引导路径，映射到高模分析表面；作为候选记录，不复制完整低模
结果扩展 reviewGuides ← version=1、analysisFingerprint、命名曲线及来源说明
回读 ← 验证分析指纹、曲线类型、有限控制点及采样；无扩展的旧结果保持原行为
网页 ← 红线为分区边界；青线为审查导线，只追加到显示网络，不增加分区或接口统计
原始对照或平滑为0 ← 不追加审查导线；重新识别生成新结果时不自动沿用旧导线
导出 ← 保留独立的 reviewGuides；待用户审查后再决定是否用于 TopoGun
```

```text
轻量审查副本 ← 完整结果的分区、导线和后处理保持一致
副本 source ← analysisSource；sourceFingerprint ← 分析代理指纹
sourceRole ← analysis-proxy-review-copy
sourceReference ← 原高模路径、SHA256、源指纹和完整结果文件名
名字 ← 明确标注代理审查副本及原高模外置
用途 ← 仅用于网页审查，后续交接读取完整结果及原高模
```

实现文件：`web/csi-boundary/app.js` 仅向绘制网络追加 reviewGuide 曲线；`partition.js` 校验版本、绑定的分析指纹和坐标；`web/contour-lab-3d/viewer.js` 将 `review-guide` 优先归入青色批次，避免现有结构层全部强制为红色。旧结果无扩展时行为不变。10项独立网页测试全部通过（约82秒），单文件构建成功；实际浏览器已验证62分区、121接口、红青线显示及五视图。


## 贴图辅助实现状态与验证

```text
sample(source,analysis,image):
  校验完整UV与RGBA尺寸；分析网格自带UV时直接采样
  否则用原面中心空间散列，在2格邻域选距离小于包围盒对角线2%、法线点积大于0.25的最近面
  在原面三角扇计算夹取并归一的重心坐标，双线性采样OBJ的反向V轴
  返回指纹、每面RGB或null、命中率和最大距离；这是近似映射
segment(base,colors,strength,grain):
  strength为0时直接返回base
  只考虑同一父区的相邻面，权重=色差*strength+法线差*0.12
  按权重排序，用内部差异+k/组件面数执行连通合并；k=8*(1.6-1.2*grain)
  小于4面且边权小于0.1的微区再合并；强边界小区保留
applyTexture(previous,image,strength):
  新图片生成证据，否则复用已保存证据
  从textureBase或原proposal生成分区，不累计上次细分
  重建共享接口并拟合后处理；保留审查导线与源数据
  保存textureBase、textureEvidence、textureReport和textureStrength
网页：
  导入图片前校验当前source含UV；图片限制64MB，缩放到最大2048边长
  在worker内采样与细分；不把textureImage写入持久settings
  当前分区细分使用界面新粒度，重新识别要求原始图片
  模型切换清除旧图片，异步图片用请求序号拒绝过期结果
  worker成功后同时更新source与result，保持继续细分入口有效
回读：
  校验颜色范围、分析指纹、强度及基线面标签
```
自测覆盖：窄带、父区包含、纯色UV接缝、V轴、代理映射/远距离拒绝、零强度、重复应用、导线保留、损坏证据和图片不持久化。网页真实导入测试条带从1区细分到3区，强度0恢复1区；第四版JSON实际导入、正面小结构及背面已查看。

# Retop 独立 CSI 分区网页伪代码

## 已确认角点在二次拟合中保持一致（2026-11-24）

```text
固定角点集合 ← 原分区 sourceCorners 的节点编号集合
显示副本 ← 执行既有受限平滑和近角合并
重新提取接口 ← 从显示副本实际共边及分区标签计算，不沿用旧接口编号
对于每条接口：
    固定索引 ← 当前接口顶点中属于固定角点集合的索引
    常规角点复核 ← 识别新角点并检查可圆滑的假角
    合并角点复核 ← 保留常规角点与固定索引的并集；固定索引不再归入圆滑候选
    近角合并 ← 固定索引受保护；已实际合并并消失的旧节点不会出现在新接口
    预平滑、规整、区域投射和整线拟合 ← 均保持固定索引的原位置
    输出 ← 共享 CSI 曲线经过固定角点，角点之间继续独立平滑
默认调用未传固定角点集合 ← 保持旧拟合规则
验收 ← 原角点仍在新共边上时，其控制端点与显示网格顶点一致；原高模不变
```

本轮验证：新增角点曲线断言在修复前失败（0 个相连端点，预期 2 个），修复后通过。独立网页 9 项回归全部通过（约 97 秒），包括真实肩甲的角点、共享端点、粒度、平滑 0/0.5/1、近角合并、面形及回读。旧 `csi-rounded-corners.cjs`、`csi-corners-junctions.cjs`、`csi-boundary-repair.cjs` 通过；`csi-line-fairing.cjs` 因缺少 `artifacts/contour-lab-3d/curvature-network-public-initial-result.json` 未能执行，未伪造替代样本。单文件构建通过。

```text
输入 ← 内置肩甲 或 OBJ、STL、网格 JSON
原始网格 ← 验证输入并复制，记录原始指纹与原始坐标
分析副本 ← 复用现有工作网格准备规则；记录是否清理或使用代理、原始与分析面数及分析指纹
识别参数 ← 复用现有默认边界与 CSI 参数
源边界 ← 在分析副本上执行现有四尺度邻域识别
分区 ← 在同一分析副本及源边界上执行现有 CSI 分区，保存分区面标签、接口与拟合报告
输出 ← 版本、原始网格、分析副本、源和分析指纹、识别参数、源边界、分区及代理说明
页面 ← 在后台执行识别；按分析网格的面标签着色，绘制共享分界，提供视角和分区统计
导出 ← 将输出保存为 JSON；回读时核验指纹和标签数量
取消或失败 ← 停止后台计算；保留上一次完整结果并显示原因
约束 ← 不调用低模、五档候选、UV 或贴图生成；代理仅供识别，标签不得声明为原始网格逐面标签
```

肩甲验收 ← 与已运行的原流程逐项比较分区标签、接口及超容差；核对源输入未改变和导出回读。另验证无效输入、取消、代理提示、浏览器五视图及窄屏。

实际验证 ← 肩甲源指纹 `b91bdac8`，7 个非空分区、13 条接口、3 段超容差；分区标签、接口及曲线与此前完整流程逐项一致。导出 JSON 在浏览器回读成功；取消任务保留旧结果。自测覆盖无效指纹与不匹配标签。窄屏无横向溢出；真实大模型代理、单文件 `file://` 打开和 TopoGun 交接本次未实测。

## 粒度控制伪代码

```text
基准 ← 现有默认中档 CSI 分区及相邻关系
细分证据 ← 同一分析网格上的更细尺度 CSI 边界
粒度 ← 接收 0 至 1 连续数值；默认 0.5，0 最粗，1 最细
粗侧合并序列 ← 从基准逐级合并相邻分区，保持层级与面覆盖
细侧切分序列 ← 从基准按细分证据逐级切分连通区域；证据不足时沿用原分区
结果 ← 按连续粒度选择已满足阈值的合并或切分事件；重建分区标签、共享接口和拟合报告
应用 ← 用户调整参数并重新识别；取消时保留上次结果
保存 ← 导出粒度与相应结果；旧结果按原默认中档回读
验收 ← 肩甲基准 7 区；采样连续参数检查分区数顺序、面覆盖、连通性与 JSON 回读
```

实测 ← 肩甲粒度 0、0.25、0.5、0.75、1 的分区数分别为 1、4、7、66、125；各分区连通、分析面有标签，非默认结果的接口与标签对应。合成条带以 0.001 间隔检验 1001 个值单调；无细分证据不凭空添加分区。旧 JSON 缺少粒度时按 0.5 显示。

## 分区边界后处理伪代码

```text
输入 ← 分析网格、已识别分区、共享接口与原始 CSI 边界
共享网络 ← 根据相邻关系建立唯一边界和交汇节点，标记开口、闭环、分叉与结构角点
候选边界 ← 固定开口点、交汇点和确认角点；将共享边界顶点向原 CSI 拟合曲线靠近，位移由平滑强度控制
拟合平滑强度 ← 接收 0 至 1，默认 0.5；调整共享整线的平顺约束，不移动固定交汇点和确认角点
整线复拟合 ← 在处理后的显示副本上按相邻分区重建整条共享接口，再统一拟合并检查相邻曲线连接；不得单独拟合每一小段后忽略接续
检查 ← 评估偏差、交汇一致性、穿插、边界重叠与退化；失败部分回退原边界并记录原因
局部面约束 ← 单点位移不超过对角线的 1.5% 或最短邻边的 40%；逐三角面检查面积至少保留原值一半、法向夹角余弦至少 0.8，未通过时缩短位移或回退
显示副本 ← 在分析网格副本上移动通过检查的共享边界采样顶点，使颜色分界和实际显示边一致；继续处理有合并记录的近角
导出 ← 保存原识别结果、后处理边界、粒度与拟合平滑强度、偏差及回退情况
验收 ← 肩甲图示交汇处和多视角对比，核对共享端点、区域覆盖、原高模只读、粒度及 JSON 回读
```

实测 ← 肩甲默认强度调整 224 点，14 点减小位移，1 点回退；最大位移为对角线 0.406%。232 个共享边中间转角平均值 19.43° → 16.59°，大于 30° 的个数 46 → 30；原始交汇点和确认角点固定。新增非相邻三角面真穿插为 0，该检查排除共面、共点与端点接触。整线 CSI 拟合默认无超目标段，原识别结果仍有 3 段超容差；单文件 `file://` 自动测试和用户红框机位仍未验证。

独立平滑分界曲线拟实施伪代码

```text
参考网络 ← 按分区共享接口提取有序采样，复用近角合并和共享交汇关系
独立样条 ← 沿整条接口拟合连续曲线，普通折角参与平顺；共享端点统一，闭环连续
强度 ← 0 使用原边；正值调整平顺程度并记录对参考采样的偏差
显示 ← 复用旧网页 curves 模式，开启共享接口重建和分区着色，关闭方向场、控制柄与节点；红线取解析曲线位置，原表面采样用于深度遮挡；色块显示区域标签范围
数据选择 ← 优先使用后处理整线拟合网络，无后处理时使用识别网络；0 强度与原始对照使用 groups 模式黄色网格边界
导出声明 ← 保存独立 CSI 显示方式，控制点和共享接口沿用已有拟合网络；回读校验三次曲线控制点、样本与接口区域
保存和回读 ← 校验控制点有限、接口相邻区域有效、交汇端点一致，兼容已有 JSON
验收 ← 肩甲红框及多视角、曲线连续、闭环、共享端点、强度和导出回读
```

近角合并显示

```text
候选短边 ← 仅在正平滑强度时复用已有角点合并记录；确认共享短边距离在原记录半径内，普通角点可并入相邻交汇点，避开开口和手动边端点
局部副本 ← 固定交汇点，收缩短边；按面标签提取各区邻接面的边界环，在局部平面中选用环内对角线，按原邻接面面积和法向筛选并提高最差三角形质量
局部校验 ← 比较分区连通片、共享分区对、整网格组件和欧拉特征，检查网格有效性与新面非相邻真穿插；失败部分保留原边
显示和导出 ← 重建同一处理网格的边集和标签，复拟合整条 CSI；保存局部面来源、合并及回退记录；强度 0 和原始模式显示识别网格和原始标签
回读 ← 对较早保存的结果校验等拓扑；近角合并结果校验处理网格指纹、同区来源、边集与拟合网络
```

# Retop 经纬走线伪代码

已有声明：CSI 分区、固定边界、包边轨道、曲面求值器、最终网格和用户参考高低模。

新增定义：局部经纬夹角误差 := 相交方向在曲面切平面的夹角与 90 度之差；只统计有效方向。

操作流程：
1. 读取参考模型副本并核对肩甲形状和低模线流。
2. 对最终曲面和网格计算局部经纬夹角，识别受平顺、轨道配对和边界约束影响的位置。
3. 在保留结构边界和形状的条件下优化对应关系与内部走线；避免翻面、穿插和退化，约束不可兼得时报告残差。
4. 使用合成案例和参考模型比较最终结果，检查空间变换、旧参数回放、OBJ 与多视图。

肩甲环带检查：从最终曲面求值器分别取经向和纬向有限差分 → 计算角度误差分布 → 将结果与优化前基线比较；同时用最终生成的边和顶点检查连线及穿插。尝试在轨道配准中添加两侧切线正交惩罚后，最终曲面 P90 由 12.58° 恶化到 13.46°，该尝试已撤回；应继续研究后续平顺、拟合及最终网格共同约束，避免仅优化中间轨道。

分阶段对照（自带肩甲闭合环带，同一 19×9 内部参数采样）：配准站位平均偏差 3.10°、最大 11.15°；Gordon 曲面 P90 10.21°；边界修正后 P90 10.53°；再执行高模剖面约束后 P90 12.58°。不同阶段统计对象不同，不应将站位最大值直接与连续曲面最大值视作相同口径；这些数字用于定位而非证明实际边流改善。

待验证方法：在最终参数曲面上求两族切向导数 → 以中间轨道为初始线，沿横向积分局部正交方向 → 检查周期闭合、参数单调和退化 → 将映射同时用于导线和实际网格；固定结构边界位置并允许相应参数重配。不能通过检查时保留原结果并报告原因。先用可解析的扭斜圆柱验证，再检查肩甲参考、旧参数重放和面片穿插。

正交追踪试验：扭斜圆柱合成曲面通过；肩甲环带直接追踪产生折叠，加入单调保护后曲面 P90 从 12.58° 降至 7.06°，最大从 31.23° 变为 31.81°。该映射会移动周期接缝与边界采样参数；将接缝固定后 P90 恶化至 37.69°。当前真实网格依赖原接缝和 CSI 采样，尚未实现支持可移动接缝的重布线，试验代码已撤回，不影响现有导线与网格。

曲面基线：在工程自带肩甲的最终闭合环带内部取 19×9 点 → 用数值偏导求交角 → 记录偏离垂直的平均值 6.06°、P90 12.58°、最大 31.23°。另需在用户提供的人物肩甲上验证。

实际网格基线：读取默认流程输出的包边分区 → 遍历 90 个四边面的 360 个角 → 对每个角计算 `绝对值(相邻边夹角 − 90°)` → P90 为 41.92°、最大 67.45°。另有 12 个三角面收线，单独统计数量。现有 `annular-section-wiring.cjs` 的 4 项通过，覆盖轨道、最小内角和既有回放。

环带生成及回放：

```text
固定输入 ← 最终拟合 CSI 曲面、两条共享实体边界、各排顶点、旧环带布线
横截方向 ← 由曲面经纬偏导求沿宽度的周向变化率，投影到垂直于纬线切向的方向
周期对应 ← 从中间纬线以中点积分向两侧追踪，对每排站位施加周期单调约束
环带连边 ← 测试多个周期切点和中间站位初值；在允许的周向跨度内遍历稀疏状态，按实际面角、边长与周向跨距选择局部四边面或收线三角面
内部节点 ← 保持节点位于原拟合曲面，沿纬线试探相邻站位，降低相邻实面的角度代价
导线 ← 普通经线沿周期对应取样；转角补线沿新网格的跨排边选路并通过实际节点
补线平顺约束 ← 测量实际边链的转角；对折点沿拟合纬线调整内部站位；必要时沿有效对角线把相邻过钝四边面分为两个三角面
平顺候选 ← 保留跨排边，复核整体四边面角、最小内角、三角面预算与穿插；用各排实际节点和局部正交切向重建补线
候选检查 ← 比较真实四边面角 P90 和最大偏差，检查退化、三角面数量、包边穿插及经线周期顺序；失败时沿用旧布线并保存原因
回放与显示 ← 保存节点、面与周期展开坐标；补线沿实际边链取遮挡深度，其他导线按三角面的周期区间定位锚点；继续读取旧参数
验收 ← 测量中心纬线交角与最终四边面的角度偏差，核对下缘、转角、两圈边界坐标、OBJ 及 UV
```

默认三角面预算：

```text
新模型上限 ← 已填写的三角面上限，缺省时取 500
旧工程上限 ← 读取已保存的三角面上限；只有旧多边面字段时按历史规则迁移
最终三角面数 ← 对输出低模的所有面累加（面的顶点数 − 2）
提交与导出 ← 普通生成及混合减面回退共用低模交付检查；当最终三角面数超过上限时报告实际数量和上限；否则卡片显示实际数量与已应用上限
低预算复验 ← 以默认上限生成自带肩甲，复查内外轮廓、红框经线折点与导出三角面数；以多壳体复现无法达到上限的回退输入
```

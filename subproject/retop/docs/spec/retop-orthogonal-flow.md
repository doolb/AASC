# Retop 经纬走线伪代码

已有声明：CSI 分区、固定边界、包边轨道、曲面求值器、最终网格和用户参考高低模。

新增定义：局部经纬夹角误差 := 相交方向在曲面切平面的夹角与 90 度之差；只统计有效方向。

操作流程：
1. 读取参考模型副本并核对肩甲形状和低模线流。
2. 对最终曲面和网格计算局部经纬夹角，识别受平顺、轨道配对和边界约束影响的位置。
3. 在保留结构边界和形状的条件下优化对应关系与内部走线；避免翻面、穿插和退化，约束不可兼得时报告残差。
4. 使用合成案例和参考模型比较最终结果，检查空间变换、旧参数回放、OBJ 与多视图。

肩甲环带检查：从最终曲面求值器分别取经向和纬向有限差分 → 计算角度误差分布 → 将结果与优化前基线比较；同时用最终生成的边和顶点检查连线及穿插。尝试在轨道配准中添加两侧切线正交惩罚后，最终曲面 P90 由 12.58° 恶化到 13.46°，该尝试已撤回；应继续研究后续平顺、拟合及最终网格共同约束，避免仅优化中间轨道。

分阶段对照（自带肩甲闭合环带，同一 19×9 内部参数采样）：配准站位平均偏差 3.10°、最大 11.15°；Gordon 曲面 P90 10.21°；边界修正后 P90 10.53°；再执行高模剖面约束后 P90 12.58°。不同阶段统计对象不同，不应将站位最大值直接与连续曲面最大值视作相同口径；这些数字用于定位而非证明实际边流改善。

待验证方法：在最终参数曲面上求两族切向导数 → 以中间轨道为初始线，沿横向积分局部正交方向 → 检查周期闭合、参数单调和退化 → 将映射同时用于导线和实际网格；固定结构边界位置并允许相应参数重配。不能通过检查时保留原结果并报告原因。先用可解析的扭斜圆柱验证，再检查肩甲参考、旧参数重放和面片穿插。

正交追踪试验：扭斜圆柱合成曲面通过；肩甲环带直接追踪产生折叠，加入单调保护后曲面 P90 从 12.58° 降至 7.06°，最大从 31.23° 变为 31.81°。该映射会移动周期接缝与边界采样参数；将接缝固定后 P90 恶化至 37.69°。当前真实网格依赖原接缝和 CSI 采样，尚未实现支持可移动接缝的重布线，试验代码已撤回，不影响现有导线与网格。

曲面基线：在工程自带肩甲的最终闭合环带内部取 19×9 点 → 用数值偏导求交角 → 记录偏离垂直的平均值 6.06°、P90 12.58°、最大 31.23°。另需在用户提供的人物肩甲上验证。

实际网格基线：读取默认流程输出的包边分区 → 遍历 90 个四边面的 360 个角 → 对每个角计算 `绝对值(相邻边夹角 − 90°)` → P90 为 41.92°、最大 67.45°。另有 12 个三角面收线，单独统计数量。现有 `annular-section-wiring.cjs` 的 4 项通过，覆盖轨道、最小内角和既有回放。

环带生成及回放：

```text
固定输入 ← 最终拟合 CSI 曲面、两条共享实体边界、各排顶点、旧环带布线
横截方向 ← 由曲面经纬偏导求沿宽度的周向变化率，投影到垂直于纬线切向的方向
周期对应 ← 从中间纬线以中点积分向两侧追踪，对每排站位施加周期单调约束
环带连边 ← 测试多个周期切点和中间站位初值；在允许的周向跨度内遍历稀疏状态，按实际面角、边长与周向跨距选择局部四边面或收线三角面
内部节点 ← 保持节点位于原拟合曲面，沿纬线试探相邻站位，降低相邻实面的角度代价
导线 ← 普通经线沿周期对应取样；转角补线沿新网格的跨排边选路并通过实际节点
补线平顺约束 ← 测量实际边链的转角；对折点沿拟合纬线调整内部站位；必要时沿有效对角线把相邻过钝四边面分为两个三角面
平顺候选 ← 保留跨排边，复核整体四边面角、最小内角、三角面预算与穿插；用各排实际节点和局部正交切向重建补线
候选检查 ← 比较真实四边面角 P90 和最大偏差，检查退化、三角面数量、包边穿插及经线周期顺序；失败时沿用旧布线并保存原因
回放与显示 ← 保存节点、面与周期展开坐标；补线沿实际边链取遮挡深度，其他导线按三角面的周期区间定位锚点；继续读取旧参数
验收 ← 测量中心纬线交角与最终四边面的角度偏差，核对下缘、转角、两圈边界坐标、OBJ 及 UV
```

默认三角面预算：

```text
新模型上限 ← 已填写的三角面上限，缺省时取 500
旧工程上限 ← 读取已保存的三角面上限；只有旧多边面字段时按历史规则迁移
最终三角面数 ← 对输出低模的所有面累加（面的顶点数 − 2）
提交与导出 ← 普通生成及混合减面回退共用低模交付检查；当最终三角面数超过上限时报告实际数量和上限；否则卡片显示实际数量与已应用上限
低预算复验 ← 以默认上限生成自带肩甲，复查内外轮廓、红框经线折点与导出三角面数；以多壳体复现无法达到上限的回退输入
```

两档自适应分割：

```text
中远档 ← 沿用解析体拟合与四边面化，独立生成解析体大形
低模上限 ← 当前低模三角面上限
中模上限 ← 低模上限 × 6 × (4 ^ (当前中模细分级数 − 1))，应用已有全局细分上限
曲面与基础结构 ← 从原模型读取 CSI 大曲面分区、共享链、角点、包边和手动边
低模 ← 先规划共享 CSI 四边面带；当面带无法满足预算时，启用低预算分区布线
低预算曲线 ← 固定确认角点和共享端点，以随面数放宽的局部容差拟合共享曲线；优先保留包边，可尝试合并法线连续且无手动边的弱内部 CSI 分界
低预算候选 ← 从源曲面按 CSI 分区约束收线，在同一区内配对四边面；真实共享节点在受限距离内拟合到 CSI 曲线
低模验收 ← 复核预算、拓扑和穿插；以原高模的多方向轮廓及前表面深度对真实三角面评分，记录所选候选残余误差
中模父级 ← 当前生成或重建的低模网格；读取逐面 CSI 分区和实际共享边，记录父网格指纹
锁定边界 ← 固定低模的分区界线、外轮廓、折边及其顶点；需要接入切线时，只沿原边插点，两侧引用同一顶点
中模细分 ← 有 CSI 分区时按硬折边卡线流程构面；混合减面路径按长度和曲面偏差细分共享边；投影检查失败时在线性细分中撤回冲突局部的新增站位后重试
候选验收 ← 检查最终三角面数、父界覆盖、面方向和穿插；混合减面父网格已有穿插时仅做原三角面的线性细分，并记录继承的穿插
重建 ← 更新低模后，使用同一个中模派生入口同步重建中模及其派生档位
验证 ← 比较不同预算下中远档网格的指纹；核对每条低模分区边在中模中的覆盖、子面归属、包边和下缘的实际走线；复核各档三角面数和 OBJ 回读
```

中模硬转折卡线：

```text
中模控制笼 ← 取得实际低模的面、分区、共享边、CSI 曲线和角点；记录父网格指纹
可布线折边 ← 以原高模局部二面角、连续 CSI 结构线、细节层和手动边匹配真实折边并连成边链
支撑带计划 ← 按硬折边连续链分配双侧支撑线；单条自动内部分界须有同区连续证据；按相邻面宽限制局部宽度；共享边统一登记插点
规则细化 ← 先布置支撑带，再从面积大的控制面开始加密；四边面采用对向连线，局部转换区使用相容的四边面与三角面
曲面拟合 ← 固定低模边界和支撑线；新增点优先使用现有 CSI 曲面求值，局部不适用时回贴同区高模；逐点与整面检查法线和穿插并回退冲突位移
校验 ← 从最终网格取支撑边和三角面，检查两侧线距、边链连续性、拓扑、翻面、穿插、UV 和 OBJ 回读
平滑复验 ← 从中模进行 Catmull–Clark；检测实际三角面穿插并局部限制平滑位移；对照关键折边截面、包边下缘、转角与高模多视图轮廓
```
### 中远档自动多基本体拟合

```text
分析 ← 对高模工作副本沿主轴试切；每侧按面邻接分开，保留具有面积的连续区域
拟合 ← 在区域主轴和继承坐标架上，按面积采样表面，比较球、椭球、圆角盒、盒、圆柱、截锥的距离与法线误差
分配 ← 比较每增加一个体块带来的误差下降，达到上限或无有效改善时停止
人物躯干 ← 验证成对下肢、侧臂分支与面部朝向；从正面深度突变提取胸前装备的上下沿和相邻袋体间的低谷，沿腰部收窄和下颏转折分开胸廓、腰、骨盆与头部；各部位分别校核包覆
截面 ← 为胸廓、腰和骨盆各拟合有独立斜率的支撑平面；按正面深度谷划出的各袋体保留前平面与侧边
局部交界 ← 在腕口与靴口的候选高度测量两侧轮廓并定位收窄，测量腰部宽度以限定胯侧
局部支撑 ← 在各区域坐标架按方位与上下倾角取候选方向；用全部所属面角求支撑距离，逐次切掉空体积最多的外角；胸袋维持主要前平面
平面构面 ← 共边插点配对奇边面；局部无法直接剖成四边面时，以该平面内部中心点连接每两条相邻边，仅细分该面
精度检验 ← 与上版使用同机位；比较五向多余投影面积及躯干深度，再核对部位数、三角面数、原面覆盖和体块相交连通性
重建 ← 仅保留获分配原面或顶点的体块及对应部位名；保存每个选中体的类型、局部坐标架和尺寸，用同一参数生成预览与 OBJ 分组
包覆 ← 给原始高模每个面分配一个凸体；用同一坐标架比较候选的实际离散网格，沿支撑平面外扩至包住整面并留数值余量
复核 ← 对每个原始顶点记录满足该体全部三角面内侧半空间的体块集合；求同一面各顶点集合的交集。所有交集非空才交付，原本共边的面在接头保有重叠余量
补充 ← 在体块上限内对能显著改善形状的区域拆分或追加基本体
验收 ← 输出各体块参数，读回实际 OBJ，核对三角面数、轮廓及交界
```

### 人物包覆实验验收（独立预览）

```text
大形 ← 体素化并平滑高模，简化采样面后按表面凹凸分块
每块候选 ← 从原高模所属面的极值建立凸壳，优化支撑点，外扩至覆盖分配原面
组合 ← 在 2122 个实际三角面的预算中选择总加权误差最低的一组凸壳
导出 ← 将高模与大形的平滑法线按部位混合写入 OBJ
检查 ← 回读 OBJ，检查源面三个角是否同在至少一个凸体内，并验证闭合及体块相交连通性
对照 ← 同机位渲染导出模型、上一版和美术 LOW 拟合体，分别统计遮罩及深度差
```

### 人物布线实验（独立 OBJ）

```text
胸袋与肢体候选 ← 在高模所属区域放置截面，以原面支撑约束拟合凸环；相邻截面连接对应顶点
裤腿 ← 对应部位同拓扑、两侧形状分别求解；在剩余预算内选择成对的截面数量与周向边数
其余面片 ← 按原对角线顺序合并方向相近、形状适合的相邻三角面
验收 ← 从 OBJ 边表逐圈验证连通和二度顶点，用 Blender 导入后的实际三角化再次核对原高模逐面包覆
对照 ← 同机位展示美术 LOW、上一版及本次 OBJ 的多边形边界，并以投影记录外形变化
```

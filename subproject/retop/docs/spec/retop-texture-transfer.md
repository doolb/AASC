# Retop 贴图迁移伪代码

```text
导入 OBJ ← 读取几何索引、逐角 UV、材质分配和材质库名；校验 UV 有限且索引有效
参考低模 ← 读取独立网格与 UV，用统一尺寸比和平移转换为高模坐标，保留原数据
加载颜色 ← 解码 PNG、JPEG 或 TGA 为 RGBA，图像行按从上到下保存
烘焙准备 ← 按实际面片检查 UV 拉伸，将超过约束的大图岛沿空间分区拆成相连的小图岛后重新展开；按原高模三角形构建空间 BVH
纹素对应 ← 光栅化新 UV 三角面；插值得到实际低模表面点与法线；寻找朝向相容的源三角形
颜色 ← 按命中三角形的重心坐标插值源逐角 UV，再双线性采样原颜色图
边距 ← 仅向空白像素扩展最近边缘颜色，记录命中覆盖与距离统计
显示 ← 使用选中模型的实际 UV 与图集进行颜色预览
导出 ← 写出 OBJ、相对 MTL 和 PNG，封装为 ZIP；回读核对三角面、UV 和贴图引用
验证 ← 用合成接缝测试及目标高低模检查颜色、轮廓、UV、输出和源数据不变
```

自动重建质量优化（进行中）

```text
参考职责 ← 仅用 LOW 做输出对照，不读取其拓扑、顶点或 UV 作为生成约束
质量诊断 ← 对比面积误差权重、局部尺度正则化的候选，测量局部轮廓、表面距离及长细面
自动构面 ← 在复杂人物的混合减面路径中，使用面积的平方根作为误差权重，再按每个顶点的累计权重添加位置正则；正则系数 0.5，限制收线位移并检查面方向与流形拓扑
源法线 ← 解析源 OBJ 的逐角法线及索引；复用贴图投影 BVH，在朝向相容的源三角形内按重心坐标插值法线，为低模逐角写入，并记录几何指纹以校验缓存
平滑分组 ← 保留导入文件的 s 记录；高模没有非零组时，按投影法线在低模共享边两端的连续性及实际硬折角生成平滑组；着色插值限定在该组及硬边内，导出同时保存 s 与 vn
着色协调 ← 保持低模几何不变；源法线细节权重取 min(0.4, sqrt(目标三角面 / 源三角面))，避免粗网格照搬高频细节；按该权重混合组内法线与协调后的源法线并单位化；投影失败的角点使用组内法线，明确统计回退数量
光滑连续 ← 按实际共享边、恢复的硬边及 CSI 分区建立角点扇区；同一扇区内先按角度汇总投影法线再单位化，禁止逐面独立投影在光滑边上引入法线跳变
界面同步 ← 应用迁移结果后刷新平滑组和硬边报告，标记高模法线依据；后续自动分组和导出沿用已恢复硬边
自动恢复 ← 初次生成、低模重建及中模层级重建完成后，对含显式法线的源模型构建一次只读空间索引，为低模、中模和超近档迁移逐角法线与平滑组；无需 UV、颜色图或先执行烘焙
显示容错 ← 原模型 CSI 分区全未知或标签不合法时，不把未知标签直接传入着色分区校验；仍按实际几何和显式法线显示
胸前结构验收 ← 检查前面主块面、四周转折、袋体下缘和与躯干连接；关闭源法线对照时先清空源法线及迁移缓存；参数试验未通过形体对照时不合入结构边约束
预算约束 ← 低模实际三角面不得超过 2122；参考 LOW 的组编号、几何和 UV 均不参与生成
验收 ← 对实际三角面、源法线和颜色分别检查，并以统一相机对照脸、耳、手及装备结构
```

已确认的结构分区重建伪代码（进行中）

```text
高模证据 ← 在只读高模的工作副本上提取与低模空间尺度相应的主块面、转折与凹槽
代理分区 ← 由各连通壳体的种子开始，按几何平面残差层级增加区域；优先队列只从已分配邻面扩张，保证源面区域相连；面积加权中心及源面二阶矩的最小特征向量给出平面代理，法线仅作弱方向约束；合并预算尺度以下小区域及相邻共面区域
细节尺度 ← 低于面预算空间尺度的小幅表面起伏不能仅因法线方向变化就拆成多个主块面；以源点到拟合平面的实际偏差控制几何复杂度
主平面保护 ← 在源面及初步代理的方向中搜索预算尺度内的稳定共面支撑；按源面相邻关系拆成连通主面，固定其平面及源面归属，再拟合剩余曲面，避免小面积下侧面被大面积前面吞并；相邻但独立的受保护主面不自动合并
细节分离 ← 小于预算所支持尺度的翻盖、纽扣及内部凹线保留在贴图证据中，避免其挤占主形体面数
CSI 分区 ← 沿主块面边界拟合曲线；有多边界或分支的区域增加必要切线，分成可构面的补片
共享锚点 ← 在三及以上区域交点和边界分叉处建锚点；没有交点的闭环补足三个站位；按代理法向夹角加权的弦偏差增加曲线采样
离散构面 ← 在每个源区域的顶点边图中按至锚点距离着色，再沿源边界强制边界锚点着色；三个不同锚点域相遇的源三角面产生一个新三角面，共享锚点只保存一次；多孔区域保留原面图连通
拓扑修复 ← 锚点域须为可收缩区域；若其 Euler 值、共享边、定向或输出拓扑不正确，则只在对应源域内增加必要锚点后重建；修复后的实际三角数参与预算，超限报告最低需求
光滑曲面分区 ← 新块面标签可作为曲面参数域，不将每条域边界自动设为着色硬边；真实几何硬折及迁移法线证据仍决定硬边，原肩甲分区规则保持原实现
最低预算 ← 先计算保留外轮廓、主平面、转折和下缘所需的边界站位及最小三角化数量
试算与拟合 ← 预算试算先只规划共享站位和离散构面；选定可行分区及采样密度后再执行最终 I/C/S 拟合，避免每次预算试算重复求曲线控制柄
构面预算 ← 若最低预算可满足，则平面采用最少构面，曲面按形状误差分配额外站位，总三角面不超过 2122
曲面补点 ← 在剩余预算内测量软曲面源点至同区域低模三角面的距离，优先增加误差最大的源站位；每次重建须保持拓扑且仍在预算内，否则回退该次补点；硬块面不为微小装饰增加内部站位
结构重建 ← 依据真实补片边界生成共享顶点与面；检查缝合、定向、退化面、非流形与穿插
块面贴合 ← 使用实际低模顶点所接触的区域代理拟合坐标，受保护主平面优先；发现投影引起的穿插时只回退对应顶点，保持其他主块面的拟合，不对全身统一削弱位移
软硬区分 ← 比较结构边界的源面转折曲率与区域内部曲率；有多方向硬转折支撑的主平面才作刚性贴合，连续曲面上的代理仅用于分区与布线，其顶点保留源面站位，避免把头、手和肢体压成平面
分区着色 ← 新 CSI 网格的软曲面恢复协调后的源法线，硬块面维持低模平面法线及预算相关细节权重；权重逐顶点统一，不能在共享光滑边引入额外法线接缝
法线对应 ← 软曲面顶点保存其源面站位的法向依据，用它限制原高模查询朝向，避免粗三角面的暂时偏斜导致法线查询跳到错误表面
派生中模 ← 从实际低模细化，增加 CSI 拟合和硬转折支撑带，保持父子分区对应
失败报告 ← 预算或补片条件不满足时报告具体分区与最低需求，不将全局 QEM 结果标为通过
验收 ← 正、背、侧、顶、斜视检查实际网格；胸前重点检查主面平整、竖向转折、下缘及连接躯干的形状；LOW 只用于对照
```

~~~text

逐个标记区 ← 在三方共有像素上统计与代理的深度绝对差第 90 百分位，除以人物身高；另核对部位边界、走向与外轮廓
独立预览 ← 手选部位与轴向，在原始高模表面采样拟合；美术 LOW 仅在完成拟合后同机位显示
预览计数 ← 仅统计独立面片的三角数；全身接边与预算另行验证
~~~

美术原件 UV 只读验收

~~~text
共享边 ← 用同一对位置索引找到相邻面，再按端点顺序比较两侧逐角 UV

线性密度 ← 贴图边长 × 平方根（UV 面积总和 / 模型表面积总和）
~~~

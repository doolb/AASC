# Contour Lab 3D

浏览器内的三维保形减面与卡线候选工具。源码入口为 [index.html](index.html)，离线版为 [dist/index.html](dist/index.html)。独立于二维网页；不需要安装依赖、Blender、服务器求解器或CDN。通过Web Worker计算，原始网格只读。WebGL负责同步对照显示。

公网入口：[c.aasc.us/mnt/contour-lab-3d/](https://c.aasc.us/mnt/contour-lab-3d/)。服务器静态文件为`/home/as/a/contour-lab-3d/index.html`，发布内容来自离线单文件；导入模型仍在浏览器本地计算。

## 独立手动点线面模式

点击上方“手动点线面”，可直接在只读原模型上编辑，无需先计算五档。空白编辑状态默认启用“放点”，直接点击模型表面就会新增点；视图上方提供工具栏、当前工具说明和选择数量，连线/建面/组合体也可直接在上方操作。进入时显示单个原高模，退出时恢复原件对照和线框设置；手动定义与自动边界、LOD几何互不混写。手动视图只读取原高模几何，不套用当前候选档的UV、切缝或卡线数据；计算完成后也可从任意档位直接进入。

1. 使用“＋ 放点”（空白编辑时默认），点击原模型表面放置点。“选点 / 拖动”用于已有点，不会在空白处新增点；两种状态在上方明确提示。重复点击点可切换选择，编号后的方括号显示选点顺序。普通鼠标放点允许按下/松开间最多10px轻微移动（触屏18px、笔12px），超过时明确显示识别为拖动。上方“点击反馈 · 1105.2”显示事件接收、成功/未命中/拖动等结果，可复制诊断信息；诊断仅保留在当前页面，需用户点击复制。拖动点默认贴原表面；取消“移动点时贴合原表面”后在当前屏幕平行平面移动，也可在右栏输入XYZ坐标。
2. 选两个点，点击“连成贝塞尔线”。每条线为一段3D三次贝塞尔，默认控制柄在弦长1/3和2/3处，形状为直线。选线后拖动H1/H2或编辑其XYZ；“恢复直线”重设两柄。移动端点会带动该端的控制柄。相同两点不会创建重复边。
3. 按边界顺序选至少三个点，再建面。缺失的边自动补为直线；已有边沿用原控制柄。相邻面引用同一个共享边ID，并记录正反方向。每个面自动分配独立平滑组，选单个面可反转点环与边环方向；画面中的半透明颜色用于分区定义预览，不生成面网格。
4. 用“选面”工具或列表选择一个或多个面，再“组合成体”。体保存面引用，保持各面及平滑组；可为开放面组。检查栏按边使用次数和方向显示是否闭合，不执行布尔、体素或合成网格。
5. 导出“点线面参数JSON”。可导入继续编辑，参数按源模型指纹自动暂存到浏览器；更换模型后分别恢复。文件不含原模型，需要另行载入匹配坐标的原模型。Ctrl/Cmd+Z撤销、Shift+Ctrl/Cmd+Z或Ctrl/Cmd+Y重做，Delete删除；删除会处理依赖定义，可一次撤销。一次拖动对应一次撤销，Esc可取消拖动。

Alt拖动旋转，右键/Shift拖动平移，滚轮缩放；“浏览”工具使用原相机操作。默认隐藏和禁止选择被实体遮挡的定义，“透视显示/选择背面定义”可临时穿透选择。支持正交/透视、390px布局、截图和高分屏面内点击。

JSON格式为`contour-lab-3d/manual-definitions`版本1，坐标空间`source-model`沿用原模型的坐标和单位：

- `source`：名称与几何指纹，无原网格。
- `points`：ID、三维`position`。
- `edges`：ID、`kind: cubic-bezier-3d`、起终点ID、绝对坐标的`handleStart`和`handleEnd`。端点由`points`引用，两个控制柄由边保存。
- `faces`：ID、有序点环、共享边环`{edge,reversed}`、独立`smoothingGroup`。
- `bodies`：ID、面ID数组。

导出显式筛选以上字段，不附带采样线段、三角面、合成网格或LOD。导入验证ID、有限坐标、边方向、面环和平滑组；出错时保留原定义。不同源指纹的参数不会直接混入当前模型。

纯JS数据与相机拾取验证见`tests/manual-model.cjs`；真实浏览器操作见`tests/manual-editor-browser.mjs`。覆盖表面射线命中、正交/透视放点、点/控制柄拖动、单次拖动撤销、共享边、面平滑组、面组合、高DPI面内点击、遮挡/穿透选择、参数导出回读、按模型暂存和肩甲五视图。独立模块为`manual-model.js`和`manual-ui.js`，不依赖Blender或外部库。

## 已确认的五档

| 档位 | 实现 |
| --- | --- |
| 远 | 面积加权主方向包围长方体；可按面积权重忽略微小延伸；6个四边面，不保留孔洞 |
| 中远 | 用单个解析体或最多3段共享截面的球壳/锥环组合表达大形；不再采用密集QEM减面 |
| 中 | 从中档CSI共享边界生成四边补片；同组高模面形约束保存为参数，再作最终轮廓复核和穿插检查 |
| 近 | 暂保留旧规则体低模的细分与卡线链；尚未接入新的CSI低模 |
| 超近 | 以卡线中模为唯一父级，进行1～3级Catmull–Clark细分，默认定位到极限曲面；可切换有限级细分；不回投高模 |

远、中远与旧卡线链保留四边面；当前CSI低模以四边面为主，允许局部三角面终止边流。超近沿旧卡线链细分。圆锥尖端和棱柱多边形端盖先做共享边四边化，必要细分沿相邻四边面的对边传播，避免T形接头。原高模独立保留为左侧只读参照，不再作为第五档输出。

`csi-surface.js`实现新的CSI低模补面；`hierarchy.js`保留规则体低模到卡线/涡轮链及四边细分工具；各档记录父级几何指纹、细分级数与拟合报告。低模默认上限1000个三角面，可设48～65536；四边面按2个三角面计，保留实际四边面导出；中模额外1级、每次4轮拟合、强度0.85、超近1级。旧卡线链每级四边细分增加4倍面数，上限32768四边面，超限拒绝并提示调低级数。仅旧卡线中模链使用相容法向的最近三角面查询、源壳体锁定、结构节点吸附和局部线搜索约束拟合；禁止局部翻面、退化及四边面投影内折。已经落在高模上的顶点不会因切向平滑自动收缩。

卡线使用沿结构边两侧的真实四边支撑带，对边传播保证共享连接，OBJ保留实际顶点、面与`g bevel`面带标签。该标签兼容旧导出，不代表已作精确等宽倒角（报告`geometricChamfer:false`）。自动候选映射后只在中模转折超过35°处插带，避免把微小曲面变化全部加密；手动标记不受此角度过滤。面积比＋曲率差的原始边界识别没有被夹角条件替代。加密按转折强度排序，自动支撑带预估面数预算取细分基础面的2倍与原模三角面数的45%较大值，同时给超近预留预算；超预算的较弱卡线明确记录deferredForBudget，手动标记优先。宽度换算为共享的局部边比例并限制在2.5%～18%，不是全局精确物理宽度。

超近遵循Catmull–Clark顶点、边点和面点规则；新增“超近使用极限曲面”默认开启，与Blender的Use Limit Surface对应，关闭为有限级细分。开放边可全部平滑或保留仅邻一面的开口角点。极限投影仅对细分网格做一次，不在每级之间额外平滑；不是只改变法线，也不是复制或投影回原高模。参考[OpenSubdiv细分说明](https://opensubdiv.org/docs/subdivision_surfaces.html)。未接入OpenSubdiv依赖，也不声明与所有DCC的特殊边界/折痕选项完全一致。细分可能收缩，需通过中模形体和卡线控制。

规则体与旧卡线链仍由基础体决定拓扑；新的CSI低模单独检查原高模拓扑。单孔环状CSI分区可生成周期四边面带，参数接缝焊接且不成为结构硬边；多个孔或把手仍需额外切缝，不支持时保留旧结果并显示原因，低模不回退到贴高模生成。每档分别检查相对于原高模的拓扑一致性和相对于父级的继承关系，差异明确报告；这条规则体细分路线不等于完整方向场重拓扑。

## 边界与平滑分组

同一个原高模在面积主方向坐标系内，以最长轴1/4/16/64分格的立方窗口分析。四档都需要：直接邻面面积比、双侧邻域面积比、曲率相对差和最低曲率同时通过。不使用相机方向、生成的LOD、旧平滑组或单独夹角作为识别旁路。

双侧邻域沿面邻接及同侧半空间扩展，排除测试铰链自身；至少3面、有内部铰链并有两个切向方向的空间展布。保留原始面面积。单侧超过256面计算预算或缺少证据时标未知，不当成平面，也不提前截取一小块伪称完整大窗口。当前大窗口可能有较多未知，报告完整保留该限制。总邻域访问预算400万，超过时明确失败。

结构生成先按源边连通链的总长度过滤微小碎链：低模默认使用中尺度，中模默认使用近尺度，最短链为尺寸的3.5%；手动边不受这个过滤。这里没有无证据跨缺口连接、平面交线重建或完整三维I/C/S矢量拟合。低/中/超近按父级派生，几何及连接关系有指纹记录；拟合会移动顶点，细分会增加连接，不能理解为逐面一一不变。

识别边阻断面邻接，得到结构连通分组，用于边界分组视图。中档将CSI结构分区接入着色平滑组：不同结构区之间阻断法线平均，组内仍补充局部几何硬转折。结构识别仍使用面积比＋曲率差及其补全候选，不能反过来把着色夹角当作结构识别证据。稀疏且不闭合的结构边界可能绕漏，不能称为完成了语义装甲分区。

“自动平滑”中档优先使用CSI结构分区作为组界，再保留组内超过60°的局部几何硬转折；远、中远及旧卡线档仍按当前几何法线夹角计算，默认60°。长方体得到6组、12条硬边；圆柱端盖断开、侧壁连续。超近为Catmull–Clark连续曲面，采用180°及壳体连通分组。法线按每个顶点周围的连续面扇计算，硬边阻断；即使相同面组绕其他位置重新连通，也不会跨越本地硬边平均。采用面角加权，减少不均匀三角化带来的法线偏移；只接触于一点的面不会互相平均。左侧原高模在显示时只读计算自动法线，源几何和属性不改动。

生成结果保存`smoothingGroups`、`sharpEdges`和报告，检查栏显示组数及着色硬边数；OBJ写出分组`s`和对应的每角`vn`。逐面组编号不一定能独立表达所有局部硬边，导出的分离角点法线保留这些硬边。关闭自动平滑仅切换显示，UV、几何及结构分区不变。

## 输入、交互与导出

- 支持OBJ、二进制/ASCII STL及`vertices`/`faces`网格JSON；工程JSON保存源、参数、手动/排除边、边界证据和候选，导入后重新计算。导入上限40MB、12万顶点、18万面；该上限不是性能保证，高密度部件仍可能触发邻域预算。
- 本版不导入材质、现有UV、骨骼、蒙皮、动画、FBX/GLB场景。OBJ输出是静态几何及本版新建的基础UV和法线，不声称保留动画或原贴图。
- 左侧始终是真实源网格，右侧是所选档位，同步旋转/平移/缩放，提供正、侧、右侧、顶、底、背、斜七视图。视图底部可切换正交/透视，左右共用投影；切换保留角度、平移和缩放。主光与补光固定在相机坐标系，随观察方向转动，左右使用同一光照；线框、边界色和UV展开保持原样。透视通过镜头缩放，避免放大时相机进入模型；手动选边使用对应的投影及线性深度判遮挡。UV展开保持独立2D视图并隐藏相机投影按钮。可切换线框、结构边、边界分组、UV棋盘/切缝、独立UV展开及单视图。分组边界使用有深色描边的黄色屏幕像素宽度线，在只支持1px线宽的WebGL设备上也可见。
- 在原模点边添加或排除卡线；重新生成后应用。参数改变时禁用旧结果导出；Worker可取消。左右侧栏独立滚动，各分类可折叠。点边有前表面深度遮挡检查，不透过表面选择背面边。异步参考/文件输入使用请求版本，旧读取不能覆盖新模型。
- 导出低模、中模或当前档OBJ、工程JSON和视图PNG。

默认参考是`srcmodel/Shoulder_Highpoly.fbx`的实际静态网格，只读提取2302顶点、4595多边形、4600三角面，并应用该源文件的静态XYZ模型变换。来源SHA保存在参考JSON中。`scripts/extract-reference.py`使用Python标准库，限单个静态参考网格，不是通用FBX场景导入器。方盒用于手动完整卡线测试，圆环用于孔洞拓扑测试；这些形状、名称和坐标不参与通用算法规则。

## CSI边界导线与四向场

新增“CSI边界”页：左右使用同一个真实原高模作底面，左显示原始候选边，右显示拟合导线候选。该页不展示LOD网格，切回“模型”可继续检查低模、中模和超近。导线和十字方向场都不是新网格边，不能据此称为完成了重拓扑。

边界仍从同一高模四档立方邻域的面积比＋曲率差判定中读取。拓扑开放边另外显式纳入，手动边单独计数；排除标记仍生效。新增短断口补接候选，独立于原始识别证据；没有把显示平滑组的夹角判定当作结构边界识别旁路。图的分叉/端点保持源顶点身份与坐标，闭环保持闭合；不以空间接近焊接近邻壳体。

曲线参考2D的几何定义，不套用2D分区数量或类型配额：

|类型|定义|
|---|---|
|I|单条直线；存储等价三次控制点以统一格式|
|C|单段三次曲线，两个端部控制柄；局部主平面中没有曲率拐点、单侧弯曲，沿弦单调，不许回头成环|
|S|单段三次曲线，两个端部控制柄；局部主平面中恰有一次曲率符号变化，沿弦单调|

原始证据导线中，三维转折复杂或扭转明显的链会分段，不用一条C隐藏多次转向；两侧采样误差和离主平面距离均受容差限制。结构补全的空间长段规则见下文。相邻可合并跨度继续尝试合并，平顺节点共享切向，直线锁定相邻曲线的切向。无法在容差内保持切向时如实记作转折，不假称全链G1连续。C/S只有p1、p2两个控制柄；导出包含p0～p3、类型、源边、共享节点及误差，采样点只用于显示。

原始证据导线容差默认0.3%，长段CSI容差独立默认0.6%；远/中远/中/近的实际容差倍率均为2.5 / 1.7 / 1 / 0.7；转折阈值55°，并检查相邻窗口以减少三角边锯齿被误认为硬转折。尺度为“到面积加权表面中心的最大顶点距离的两倍”，旋转、平移不改变它，避免以世界轴包围盒控制容差。解析曲线可能在容差内略微离开三角面；默认显示解析CSI的投影形状，用原高模的深度判遮挡；“贴面检查”才将显示采样投影到对应源边邻接的局部三角面，解析控制点不变。投影不搜索其他壳体，共享端点坐标保持不变。误差为49点采样解析曲线/扩展边链（含补接候选）的双向距离，非严格Hausdorff上界；`joinFromPrevious`给出G1/转折及切向跳变角。

CSI边界与模型视图共用下方五档卡片和同一个选中档位，取消独立尺度下拉框；上方只显示当前档位。远/中远/中/近分别读取原高模的1/4/16/64邻域边界；超近沿用近档边界并明确标注。切换视图保留当前档位，手动点线面模式仍隐藏档位卡片。可叠加紫色四向场、弱场标记、分区填色或控制柄。修改拟合容差/转折阈值后点击“重新拟合导线”，只重算导线和方向场，原模型、四档边界证据与五档网格保持不变。导出“连续导线JSON”保留解析控制点；工程JSON同时保存导线。CSI页禁用“导出当前OBJ”，避免把导线页误当作LOD网格导出。

## 连续导线与断口补接

同一源节点上的CSI段串成连续路径：普通接头直接连接并保留转角，分叉优先延续最顺的主线，其他支线独立保留；已有闭环优先保持闭合。不把空间重合但拓扑不同的点焊接。同一路径统一颜色，颜色循环复用；关闭“按整线着色”可重新按I/C/S类别查看。

“自动连接短断口”默认开启，最大距离默认原尺寸2%，可调整或关闭后重新拟合。仅比较同一源连通壳体中相互朝向的端点，方向误差40°以内，且两端法线兼容。互为最佳且无近似等价的竞争对象才尝试沿真实源网格边寻路；路径不得穿越其他已选节点、已连接边或排除边，长度不超过直连距离1.8倍。较大断口、方向不符、邻近双排线歧义等保留断开。补接只是候选，用粉色虚线单列，既不改面积比＋曲率差证据，也不作为新增方向场约束。

JSON版本2增加`paths`与有序`segments`，每段引用解析曲线ID并记录`reversed`；原始曲线及I/C/S属性仍保留。`rawKeys`是原识别/手动/开放边，`processedKeys`额外含推测补接；`bridges`与`connection`记录补接路线和端点变化。`displaySamples`/`displayPoints`仅用于贴面查看，解析`p0…p3`、`samples`与拟合误差不随显示投影改变。独立重拟合只更新导线与方向场，原高模、四档证据、五档网格和UV不改。

## 参考图质量目标与四向场分区

`boundary-proposal-v1.png`只作研发对照：目标是大形边界连续、鳞片之间形成共享线网、长跨度CSI平滑且不丢真实转折。生成参考图部分形状已被规则化，不能将其当作精确像素真值，也没有把它、肩甲名称、坐标或固定轴写入算法。当前实现仍是候选，未宣称达到参考图完整语义结构或跨视图精确对应。

CSI页默认开启“结构补全”。原始面积比＋曲率差检测、未知项和旧CSI拟合完整保留，左侧仍显示原证据；右侧显示从同一高模推测的共享分区边界。红色大形/青色细节是按相邻面片面积分层的显示分类，不是已完成外包边/鳞片语义识别。关闭结构补全可看上一版原始拟合与粉色短断口补接。

“四向场参与分区计算”默认开启，强度默认1（0～2）。场先从原始CSI软约束求解，再参与分区，而不是只画十字：以局部四向场和候选边的夹角计算`cos(4θ)`，沿两条主轴的方向等价，改变曲率分区屏障及共享边界的各向异性周长代价。凹凸曲率保留几何位置线索，面积支持合并小碎片；连通性检查防止周长优化把面片撕开。场不可靠的面退出方向约束，采用曲率与面积支持的补全并计入弱场报告。关闭计算开关或设强度0会重新计算几何分区；“四向场”显示开关仅控制叠加，不改变任何分区、曲线或求解结果。

分区结束后合并相似的大曲面：两侧都属于大形面片、面积加权代表面面积比小于1.2、曲率相对差小于15%，且分界没有原检测证据或手动边时，才考虑合并。普通凹弧本身不能视为窄槽；用分界铰链曲率与内部非零铰链背景的比值区分两者，明显增强（>1.8倍）的凹槽及长度占比达到20%的25°硬折仍保留。这样四向场可改变方向，却不会仅凭同一平缓曲面的转向制造大形切缝。合并记录写入`similarPatchMerges`，不改变原检测。

补全从共享面片边界提取图，保留分叉/闭环；仅保留能在真实拓扑上一圈邻面接触原识别/手动/开放边证据的网络分量，不跨独立壳体。原检测证据不因补全改变；推测边、与原边重合数量和面片数分别报告。四档最小面片面积为旋转不变源尺度平方的8%/2.5%/0.6%/0.3%；凹凸方向采用不同屏障尺度，非语义分类器。单条手动边仍显式保留，排除边不回填。

“结构规整容差”默认原尺寸1%，四档倍率2/1.5/1/0.7，用于去除补全边链的锯齿，不修改高模。共享端点不移动；当前版本按两侧分区编号追踪共享整边；每条整边内的非角点支撑段共用切向，不再用误差驱动的新逻辑边切碎。四向场继续约束分区，不再强行用分叉方向改变整边端柄。解析→规整链拟合偏差、最大规整位移、解析→规整前链偏差分别报告；第三项不是到真实高模曲面的严格Hausdorff保证。贴面显示仍只改采样，不改解析控制点。

导线JSON从版本3起在四档`proposal`保存`patchGroups`、面片、共享线网、解析CSI、路径、证据来源、规整和方程报告。分区填色只改变右侧显示，不触发Worker；原高模、原始四档检测、旧CSI曲线、五档网格及UV保持不变。尚未执行combing、separatrix奇点追线、可积约束、整数网格无缝参数化或新四边面提取。

## 共享整边与角点（版本5）

每对相邻分区之间的连通公共边只建一个`interfaces`对象，两侧`patches[].interfaces`引用同一ID；按真实源顶点连接，不跨壳体焊接。每条整线仅在局部与邻域同时确认的角点拆成`edges`逻辑边。普通图节点、拟合超差不再生成新逻辑边；分叉保留。单段足以表达时优先用一条I/C/S，C/S仅两端两个柄。

复杂长弧可以在同一角点区间内使用最多4段三次支撑；闭环基础支撑区间可进一步细化，拟合时共用支撑点切向，再协调跨块平滑接续；闭合平滑环是一个逻辑边，必要闭环支撑点不是角点。不将多段样条标成一个C；`curves`记录每段I/C/S，`edges[].curves`记录其归属。界面区分共享整线、角点逻辑边和平滑支撑点，报告未顺接及超差段。C可超过半圆，允许端点附近沿弦投影回转，但需保持单侧无主平面拐点并检查采样投影自交；S恰一个主平面拐点。原证据CSI仍使用旧规则，四向场、分区和LOD前四档保持不变。

误差目标用于单段优先和有限平滑支撑的选择，不再承诺每段在目标内。超差明确记录`errorOverTolerance`，不伪造零误差，不以继续添加逻辑边来隐藏复杂形状。G1只表示切向连续，不等同于曲率连续或贴面保证。方向场仍参与分区，但不再施加跨分区端柄配对。

原生验证：`tests/subdivision-native.cjs`启动独立Blender `--background --factory-startup`，对立方体、开口扭曲四边面、卡线盒和肩甲中模，比较1/2级、极限曲面开关、两种边界规则共32组，Blender Quality=10。顶点双射和面连接均匹配，最大相对顶点偏差约2.97e-7，预定容差2e-6。之前有限级公式本身与Blender关闭极限曲面时一致；本次补齐默认极限曲面及开口角点规则。3ds Max仅查阅[官方TurboSmooth说明](https://help.autodesk.com/cloudhelp/2023/ENU/3DSMax-Modifiers/files/GUID-EA8FF838-B197-4565-9A85-71CE93DA4F68.htm)，没有运行Max，不声明其全部选项或法线逐项一致。[Blender官方说明](https://docs.blender.org/manual/en/latest/modeling/modifiers/generate/subdivision_surface.html?highlight=subdivision+surface)区分Catmull–Clark、极限曲面、开放边及支撑环线。

## 历史长段平滑 CSI（版本4，现由版本5替代）

结构补全边界现在以整链选择较少的长段：先识别局部与邻域同时成立的真转角，避免把大弧累计转向当成一排拐点；固定共享节点，使用自由双柄三次拟合、参数迭代和有限候选的最短路径选择跨度。保留已有拟合作为同容差上界候选；相邻段在误差允许时协调两侧柄的切向。C/S始终是一段三次、只有两个端部控制柄，不把多段样条打包冒充一个C。记录G1、真实转角和未能在容差内顺接的接点，不保证所有交接都G1。

长段CSI直接用三维距离约束拟合偏差，C/S类别在几何自身的局部主平面判别，允许空间深度平缓变化；不再只因偏离某个平面便切成短线。I沿弦单调，C在主平面单侧无拐点，S恰一次主平面曲率符号变化；回头环和多弯需拆开。原始证据CSI仍保留旧近似平面规则，既不改变原边界检测，也不改变方向场或分区。

“长段CSI容差”默认0.6%，独立于原始导线0.3%容差。提高它会以更大空间偏差换取较长线段；四档分别为1.5%/1.02%/0.6%/0.42%。规整位移及拟合到规整前边链的偏差另报，仍非高模表面的严格误差保证。肩甲各档由35/107/242/333段变为17/60/166/227段；减少同时来自长跨度选择和较宽的独立容差，不能写成在原容差下同等幅度减少。

默认显示解析曲线的屏幕形状。为避免其小幅进入高模后被切成断口，另渲染高模深度，在对应源表面采样位置判断前后遮挡；不将解析线的屏幕位置折回三角网格。仅在CSI模式使用，控制柄/场/原始边仍按正常深度显示。“贴面检查”保留投影采样，适合比较曲面偏离，但可能带回三角面的细碎折痕。显示开关不改控制点、误差、源几何或导出；高精度片元不可用或纹理尺寸超限时退回普通深度显示。导线不是实际新网格边。

JSON版本4保留真实空间控制点、I/C/S类型、所属源边与共享节点、路径和`fittingReport`；可用控制柄开关检查双柄。关闭“大形/细节着色”可按I/C/S类别查看。原高模、五档几何、UV、四档识别证据、旧CSI、四向场值与已有面分区保持不变。

## Directional 与 Boundary First Flattening

[Directional 301/302教程](https://avaxman.github.io/Directional/tutorial/#301-power-fields)以已给定边方向为约束，在相邻切平面间协调方向；它不直接提供本项目的面积比＋曲率差识别。这版自有JS实现参考其4-RoSy表示：每个面建立局部正交切平面基，用共享边计算相邻切平面的连接旋转，以拟合CSI的切向作为软约束，迭代降低连接后的方向差。几何权重为共享边长平方/相邻面面积之和，用Jacobi预条件共轭梯度求解同一连接拉普拉斯软约束能量，最多400轮；以逐面预条件方程缺陷最大值小于1e-5判达标，并报告全局相对方程残差。这是自有JS方向场求解器，不冒充Directional库内的可积场、奇点与无缝参数化全流程。

四向场默认显示紫色十字：每个方向含相差90°的四条轴向。橙色小三角抽样标出弱场或未定义面：复数模长低于0.25、未种子壳体或逐面方程缺陷大于1e-4；标记本身不表示可靠方向。无约束壳体保持未定义，冲突面、未种子面和残差都报告；未收敛明确提示。橙色节点是源边界端点/分叉，不是已求解的方向场奇点。当前没有可积性、奇点布置、combing、跨缝积分或新四边网格提取；没有安装、下载或编译Directional C++/Eigen/WASM依赖。不能把“有方向场预览”写成“Directional全流程已经接入”。

[BFF官方项目](https://geometrycollective.github.io/boundary-first-flattening/)用于几何确定后的切割与展开，不能替代结构边界识别。本版基础UV仍是各面独立平面图集，具有共同物理密度和留白打包，导出每角vt；不是BFF、LSCM或全局无缝参数化。实际UV展开/切缝/岛/截图和左右原模对照保留。

## 中远档：解析体与组合

可选球、椭球、半球、圆柱、圆锥、截锥、胶囊、圆环、楔体、3～12边棱柱、超椭球/圆角盒，以及圆柱环扇段、截锥环扇段、球壳扇片和分段组合。自动模式比较主方向与法线分布推导的方向架下的候选，综合双向抽样误差、复杂度、体积和拓扑变化；低体积填充率优先壳体。它不是语义识别，不能保证挑中设计者心中的基元。中远不再沿用低/中模的精确拟合门槛，也可能改变原孔洞。

扇形是角度范围。圆柱环是内外半径间的空心圆柱；`theta1-theta0=360`表示整圈，较小范围就是环扇段。端部半径不同时形成锥环/截锥环扇段。分段组合最多3段，同轴且共用端环和顶点，不是独立体块叠放，也没有做任意位置CSG布尔。球壳与锥环可在同一组合中混用，连接满足位置连续，未强制切线连续。

组合表达式为：

```text
X(θ,z,w) = C + eA·r(z,w)·cosθ + eB·r(z,w)·sinθ + eZ·z
锥环段：r(z,w) = lerp(R[i], R[i+1], t) + (w−1/2)·厚度
球壳段：r(z,w) = sqrt(R(w)^2 − (z−zc(w))^2)
```

参数JSON以源模型单位及局部坐标架表达，角度为度；`radii`是共享端环半径，`kinds`中的`linear`/`sphere`选择锥环/球壳段。可在左栏拟合指定类型，也可编辑JSON后重建。更新中远基础体时，联动重建低模、卡线中模及超近；原高模、远档和四尺度边界保持不变。只改变预览分段时保持参数与表达式不变，但派生网格跟随重建。工程JSON保存并恢复实际参数。非法半径/厚度/角度/坐标架被拒绝，保留旧候选。

参数量表示形体复杂度，网格只是显示与OBJ导出的代理；减少预览分段会改变代理的弦差，不改变解析表达式。本阶段仍是粗略大形候选，尤其肩甲自动圆柱环扇段的抽样最大偏差可能约23%，不能据此声称贴合完整外轮廓。

用户手工定义（8点、12曲线、6面）只用于开发对照，网页不读取该文件、不预设6块。肩甲当前中档由44块候选收敛为6块，覆盖大曲面和窄端部；部分包边位置及面积仍与手工定义有差异。七视角检查、原高模只读、连通性、刚体变换一致性与真实Worker回归通过，不代表已完整还原手工平滑组或完成重建。


## CSI角点与跨分区顺接（2026-11-05）

结构补全先在原始共享边链上用弧长窗口识别局部集中转向，再锁定角点及端点，平滑其余点。多尺度切向比较允许识别分摊在多个小三角边上的转折；持续圆弧和交替锯齿不按累计转角拆分。角点会截断连续路径，仍保持共享端点。角点角度基准同时控制局部强转折和较低幅度的集中转向，不能把所有小于该值的转折都视作平滑。

分区交汇处保持原分区、面片对、节点和源边不动。只为最明确的一对延续分支协调切向，支线保持连接；方向歧义、直角盒体转角、或两侧拟合超出预算时不强行顺接。端部可增加少量平滑支撑段，但每个C/S仍只有两个端柄，也不增加逻辑边或分区。约束误差超过无约束基准加半个目标容差（或目标容差本身，取较大值）时，两侧约束一起撤回。

导线JSON版本6中，`interfaces`保留相邻分区的共享边身份，`paths`可跨多个接口形成连续主线，`paths.interfaces`列出所经过的接口；源角点处分成不同路径。`sourceCorners`记录锁定源点和窗口判断，`junctionContinuations`记录顺接前后角度、是否采用和拒绝理由。CSI统计新增原边界锁定角点、跨分区顺接/拒绝数量。开启“节点”可看角点与交汇点。

肩甲中档保持6块分区，圆角复核后锁定5个角点、完成7处交汇主线顺接；相对规整前源链的最大采样误差由约2.49%降到1.49%，规整后拟合段没有超过当前0.60%目标。数值是采样误差，并不代表严格曲面误差保证；其他档仍有超目标段。回归见`tests/csi-corners-junctions.cjs`及其真实浏览器测试。


## 圆角复核（2026-11-06）

弧长窗口检测到的转折先作为角点候选。对候选两侧到相邻角点/接口端点之间的整段，比较保角拟合与连续双柄C拟合：只有C同时满足规整后的拟合目标、相对原边链的“拟合目标＋规整位移”预算，且相对保角模型的误差增加不超过目标的75%，才解除该角点锁定。原始两侧都接近直线的真实角点直接保留，避免因为全模型尺寸较大就磨掉小硬角。无法用单个C、方向多次变化或超出局部计算预算时保留候选，JSON记录原因。

`cornerReviews`记录原始候选点、通过圆角复核的点，以及两个模型的采样误差与结论；`sourceCorners`只保留最终锁定点。CSI检查栏新增“圆角复核通过”数量。角点复核改变的是边界导线拟合，不改原高模、分区标签、五档网格或UV；C/S仍只有两个端部控制柄，接口端点保持不动。

## 中档低模仅由CSI补面生成（2026-11-06）

中档以CSI结构补全的分区、逻辑边、角点和共享节点作为几何输入。高模仅用于前置识别CSI和提供分区连接索引；CSI固定后，高模顶点坐标、面积、法向、内部起伏和贴高模拟合参数都不影响生成的低模。`csi-surface.js`不调用源表面最近点、不做源三角面反查，也不以高模误差优化内部点。

共享边在解析CSI曲线自身的弧长域采样；分区凹凸方向、面积和布线密度也仅从CSI边界计算。每个分区联合选择四侧网格图，全局协调共享边整数分段数；按累计转向角分配完整面带，避免只按长度让短而弯的方向过稀。确定分段数后，按局部三维曲率和已确认硬角附近的权重生成初始采样位置，弯急处更密、平缓处更疏，初始分布混入35%均匀弧长分布。共享边仍只采样一次，导出的parameters记录实际非均匀弧长位置，误差检查也使用这些位置。

窄包边的相近逻辑角点先按三维距离、相对弧长进度与双向最近关系匹配，在整数面带求解中约束其处于同一横截面，避免内外角点错开一格。只匹配同一接口内不同逻辑边形成的明确角点，闭环同逻辑边的平滑支撑分段不作为角点。随后联合匹配两侧CSI轨道，替代各自独立采样后按序号连接。只沿CSI曲线滑动采样参数，固定角点位置、端点、线数和先后顺序；优先缩短横向连接并限制共同站位漂移，使横向线更接近局部横截面方向。按两侧更大的弯曲需求协调共同线间距，并在角点两侧加入随转角增加的局部密度，形成靠近角点的支持线，再复核匹配。相邻大曲面共用更新后的CSI采样点；不使用相机方向或高模投影。角点和单调顺序约束附近仍可能残留偏斜，不保证所有横线严格正交。

大曲面以四条CSI边界作三维Coons初值，再固定全部共享边界点，按两组对边的平均弧长坐标求解薄板平顺，保留对初始大形的位置约束。短边接头的参数突变不再直接延伸为贯穿补片的折痕。两组对边平均长度比小于0.12的细长补片建立包边宽度族，沿共享短边传播到相邻端部分区。宽度采样为偶数格，50%横截面弧长处必须有独立采样；很短的逻辑边角点仍保留，但不能代替中点。共享边只重采样一次，所有中点锚定一起应用。内部按固定宽度比例铺线；CSI端部若非直线，将原端部截面的偏移在两倍局部宽度内平滑过渡，保持端部CSI曲线、不把它强拉直。远离曲端部的中线严格为两轨道几何中点，曲端部则以实际截面弧长的50%为准。宽度约束点由后续质量/穿插修复锁定。质量修复仍只使用CSI补片及网格邻接，网格连接保持连续纵横面带，每个补片内部点四价。共面直边补片不为填满预算而加密。

默认最多500个四边面，可调24～32768；当前肩甲为498个四边面、6个补片，尺寸为9×21、9×21、2×21、2×21、9×2、2×9。中档近角合并后逻辑边17→15，去掉接头小短边，完整横截面可用两格宽并保持独立中点。页面指标为CSI曲线到对应网格边界弦段的抽样偏差，当前约0.28%。此数值不能与历史高模曲面偏差直接比较，也不是严格误差上界。源面标签只是所属分区的代表性来源索引，不表示网格面回投到该三角面。

非盘分区、少于四个可规划侧点、无法协调面带或不能安全修复时停止更新并保留旧结果，不回退到贴高模低模。穿插检查仍排除共面重叠和共顶点接触，不是一般性无自交证明；CSI和补面均为候选。C/S边界不能唯一确定内部鼓起，内部形状采用边界插值约定，不补回高模内部细节。

重新拟合CSI后同步生成中档网格与UV；其他四档及手动点线面保持原流程，卡线中模CSI接入继续暂缓。旧卡线链的拟合迭代/强度不作用于中档CSI曲面。OBJ和工程JSON使用实际四边网格、共享连接及CSI目标偏差。

验证见`tests/csi-surface.cjs`：固定CSI后仿射改变全部高模顶点，同时改变贴高模拟合参数，并阻止源表面API调用，低模顶点和面仍完全相同。另在相同边界采样与面带上重建旧Coons初值，检查接头转折下降和大形位移，避免单靠增加面数通过。检查窄包边宽度约束、实际网格横线偏斜、配对角点位于同一横截面、角点两侧邻线明显加密、相同点数下的独立高密度CSI弦段误差、关闭硬角密度权重的对照；刚体变换后的浮点弧长参数按1e-8比较，几何仍按1e-6检查。其余检查涵盖解析边界、内部四价、不同面数预算、OBJ回读及声明范围内穿插；真实页面Worker、CSI重拟合、七视角和导出见`tests/csi-low-browser.mjs`。最新事实与发布哈希见`artifacts/contour-lab-3d/csi-corner-supports-release.json`。

## 2026-11-09：曲率引导的三维经纬CSI曲面

默认启用“用曲率经纬CSI构造低模曲面”。生成顺序是：结构分区→按三维边界自身尺度拟合并锁角→同组高模过滤副本→主曲率方向→经纬CSI控制网→曲面补片→预算内独立混合布线。确认角点、分区交汇和原高模保留。边界拟合以每条共享链的三维弧长缩放容差，缩放系数限于全局基准的0.25～1；不依据屏幕像素或相机缩放，角点检测结果不因这项容差缩放而重新分类。报告包含每条链的长度与实际容差。

新增纯JavaScript模块 `curvature-network.js`。在同一父分区内，用面积加权单侧法线及有界邻域拟合法线变化的对称曲率算子，求两个主方向与可信度；邻域目标半径为分区跨度16%，最多80个点，邻域上限会限制实际支持范围。方向近似不可信或接近平面时以CSI边界方向为基准。可靠主方向以四重角统计确定整体方向，再拟合两个带正则项的标量参数；标量等值线构成可积的两族参数线。参数域进行21×21 Jacobian采样、逆映射收敛检查及最终实际网格检查；这不等于实现了Directional的全局无缝参数化、奇点求解或任意拓扑保证。

## 2026-11-10：改为CSI拟合后识别结构对称

## 2026-11-10：按高模剖面修正包边经纬，连续约束中线位置

用户指出包边平直段被做鼓、中线沿宽度滑动。旧流程中，开口包边继承CSI补面的估计剖面，未重新核对同区高模；整线平顺只限制空间误差，允许节点横向移动。即使补上节点居中，连续Gordon线在节点之间仍会相对两侧轨道偏移，因此本次同时修改剖面捕获、整线拟合和实际曲面的连续求值。

所有包边在构造经纬网时读取同一CSI分区的过滤高模副本。用两侧轨道确定沿程站位、宽度与法向，求高模三角面与站位平面的交线，剔除不相容法向、远离宽度走廊和覆盖不足的数据；仅在至少覆盖60%宽度、归一化拟合RMS小于1.5%宽度且弧高小于30%宽度时采用剖面。五项低阶基函数分离端部仿射差和横向曲率：真实CSI边界固定，只将相对端部的曲率用于内部形状。证据不足时明确记录fallback，保留已捕获的法向高度，不跳到其他分区猜测表面。

近直线剖面的过滤尺度沿用“内部CSI平顺”：宽度的0.5%＋3%×强度，默认50%即2%。对剖面弧高使用连续软阈值，避免在略低于/高于阈值的站位之间突然切换平面与曲面；明显弧度保留。这个阈值是低模简化尺度，不宣称被归为近直线的高模数学上完全共面。新报告保存原拟合系数、原弧高、保留增益、覆盖、RMS和阈值。

原始纵向CSI仍做整线C2三次样条拟合；新增独立站位误差约束（包边中位宽度0.5%），必要时允许更多内部支撑，不以整条线误差容差代替站位居中要求。实际曲面在每个连续参数位置按两侧真实CSI轨道构造横截面，只保留法向高度，固定宽度分数并去掉沿程漂移；开口端部的一段站位间距内平滑过渡以保护原端部CSI，环带周期闭合。原始CSI支撑曲线之间的C2不等于声称经过真实边界/横截约束后的所有显示线在结构角点处也全局C2。

保存sourceProfiles版本2与实际sectionNodes；剖面、控制线、导线显示和真实低模使用同一个受约束放样定义。参数重放只读已保存的节点与曲线，不再查询高模；旧定义缺少这些字段时仍按旧算法重放。所有操作只更新中档低模及其UV，原高模、源证据、解析CSI外边界和另外四档保持原样。预算仍按最终三角数核对，未以加面掩盖错误。此修正不替代进一步的CSI外形误差优化，也不接入卡线中模。

03 / 高模边界导线 I / C / S

以面积/曲率证据锚定结构补全，按相邻分区对提取共享整边并规整，只在角点分段，再拟合直线I、单弯C、双弯S。超出误差目标只报告，不自动切短。C/S均为单段三次曲线，仅有两个端部控制柄。中档整线按下方误差目标平顺曲率，过滤细小急弯，保留确认角点。

边界分三层：主要轮廓用于最后保形；大曲面分界用于低模分区；细小面分界只补充中模，不切碎低模。主轮廓可在“轮廓检查”页查看。

05 / 分级细分与拟合 QUAD HIERARCHY
先按三维边界尺度拟合CSI并锁角，再用过滤高模的主曲率构造经纬控制网、曲面补片，最后采样布线。控制线数量与网格线密度独立；先按整边误差目标平顺经纬整线，再对超过约20°的三维转向自动补另一族对应线，附近已有线则复用。补线进入实际布线，仍受总面数上限约束；中模卡线暂缓接入。
四边面计2个三角面，三角面计1个；对称半边复用也按完整模型计数。
越大越过滤内部经纬线及大曲面之间分界的小转折；真实角点和交点保持，外边界使用原误差目标。
越大越忽略大曲面内的细小起伏，0%保留原贴面细节。只过滤拟合用副本，保持CSI分界、角点和包边；调整后点击“重新拟合CSI与低模”。
低模默认最多500个面（四边面＋三角面）：先按中档CSI生成过滤面形，再沿结构方向独立铺面。大面以四边面为主，边缘允许局部三角面收线，不强制每条线贯穿、闭合，也不强制相邻平滑组同密度。基础CSI补面超过预算时会提示提高上限或简化边界。卡线链与涡轮细分每级4倍。卡线中模暂沿用旧规则体低模链。超近从中模做Catmull–Clark细分；默认定位到极限曲面，关闭可对照有限级细分。上限32768四边面，超限会提示调低级数。

五档如何规划 5 LEVELS
  1. 远：忽略微小延伸的整体长方体。
  2. 中远：单个基础体或共享截面的参数化组合。
  3. 中：沿中档CSI结构方向铺低模，四边面为主，局部三角面收线。
  4. 近：暂沿用旧规则体低模的细分与双侧卡线；尚未接入CSI低模。
  5. 超近：在卡线中模上进行涡轮平滑。
远、中远与近档保持四边面；中档允许局部三角面收线，分区独立。原高模仅作左侧只读参照。CSI低模检查原模拓扑；含孔的单个分区尚需先切缝，暂不支持时明确显示回退原因。

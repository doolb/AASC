# Surface Cage Rebuild 0.1 — 实验版

**当前为源码继续开发版。已有 `SurfaceCageRebuild-0.1.0.zip` 未重新打包，不包含下述新增功能。**

Blender 4.3+ 的三角高模结构分析与中模候选工具。已在 Blender 4.3.2 测试。无外部依赖。

**不是任意三角高模一键恢复原始卡线的成品。** 第一版提供可操作的分析/人工修正流程、适用条件明确的逆细分候选和两闭环面带生成。当前肩甲自动分区没有完整识别包边，完整肩甲重建验收尚未通过。

## 安装与入口

在 Blender 偏好设置中使用“从磁盘安装”，选择提供的 `SurfaceCageRebuild-0.1.0.zip` 并启用。也可将此目录作为插件模块安装。入口为三维视图 N 面板 → **卡线重建**。

本次开发已在当前 Blender 会话加载模块；仅临时加载不等于写入永久插件首选项。重启后需要正式安装或再次加载。

## 使用

### 同一高模的四尺度边界与平滑组

边界固定从**同一个原高模**计算远、远中、中、近四档，只改变立方邻域窗口。不是分别检测四个已生成的形体网格，不读取图片或视角。入口为面板 **同一高模计算四档边界 / 分组**，随后用远/远中/中/近按钮切换。每个预览的顶点和面均与同一高模快照一致。

四档共用严格判据：

- 直接相邻原始面的面积比 ≥ 面积阈值，并且两侧窗口的代表面积比 ≥ 同一阈值，默认2。
- 两侧曲率相对差 ≥ 差异阈值，默认0.5，同时较高侧曲率 ≥ 最低曲率，默认4。
- 所有条件同时通过才是候选；不使用起伏分水岭、不额外追加夹角边、不用旧平滑组标记补边。

面积代表值为原始面面积的物理面积/高斯权重中位数；曲率是窗口内同侧内部铰链响应的加权平均，排除被测试的边。两个半侧分别沿面邻接收集，限制在同侧半空间、法线半球及有限表面距离，避免跨层。窗口缺少可测铰链或不足三个非共线面心时为未知，不将缺证据视作零曲率。

默认窗口：

| 档位 | 立方窗口 |
| --- | --- |
| 远 | 源面积主方向框架中覆盖整个物件的单一立方窗口 |
| 远中 | 最长边4分格，每次取3×3×3相邻格，边长为最长边的0.75 |
| 中 | 最长边16分格，3×3×3相邻格，边长占0.1875 |
| 近 | 最长边64分格，3×3×3相邻格，边长占0.046875 |

主方向来自源几何；窗口不依赖相机。三项分格数可调，须保持1＜远中＜中＜近。短线过滤仅删除已通过双条件的连通候选，不产生新边。当前同步计算预算30000顶点/面、1200万次邻域面访问。

平滑组只从每档合格边进行面连通分组：组间边标锐，仍可绕行的边以橙线标出，不强行补齐。FACE属性 `scr_smooth_group`、`scr_smooth_uncertain` 与 EDGE属性 `scr_smooth_boundary` 保存在高模副本。原高模、自定义法线及已有四档形体不改变；预览副本重置自动法线以显示真实锐边。手改副本会保留并另建，未改结果可复用。

分组号是推断的连通区域，不是恢复历史平滑组/重叠位掩码。严格边界可能不闭合或为空，不能因分组少就放宽条件。当前不宣称已恢复完整包边、鳞片布线或完成形体重建。

API：`multiscale_boundaries.detect_four_boundaries(mesh, settings)` 返回同源四档边及逐边判据；`smooth_groups.infer_four_groups(mesh, settings)` 返回四个同几何预览与报告。`infer_groups` 保留单档接口，通过 `smooth_boundary_level` 选择档位；外传边索引仍须重新通过该档双条件，不能绕过判断。旧RELIEF来源已停用；旧转折线实验代码只保留历史回归，不参与四尺度流程。

### 五档形体候选

物体模式选中原高模，在面板上方点击 **生成前四档形体**。可分别点击 **远 / 远中 / 中 / 近 / 超近** 查看。前四档为真实、可编辑的独立网格；超近直接显示原高模。原高模不修改，初次输出按当前视图右向排列，原件在左。

| 档位 | 实际处理 |
| --- | --- |
| 远 | 源表面面积主方向拟合的整体长方体 |
| 远中 | 以去细节曲面规划轮廓和弯曲方向，回到原高模拟合大小与厚度；正背补片和侧壁共享顶点，全部四边面 |
| 中 | 每个独立壳体在归一主方向框架内做体积重采样、去细节平滑和简化，保留整体弯曲 |
| 近 | 面积加权、拓扑受限的法线滤波，有限位移平面约束，再作几何简化；仅合并满足整块平面偏差的面 |
| 超近 | 原高模本身 |

参数可调中档分格/平滑强度、远中大形纵横分段、近档保留比例/结构窗口。**只重建远中 · 连续四边面** 只替换远中档，不重算其他档位。远中默认4×6补片分段，正面24面、背面24面、侧壁20面，共68个四边面；沿源几何曲率与轮廓调整站点，并非均匀套网格或拼长方体。局部平面外推保住边缘厚度，补片内部同时拟合原表面及两种三角化显示方式。

各档是不同几何尺度，面数不必单调增加。重复生成复用各档对象；网格经过人工修改则保留旧件、另建新结果。报告记录拓扑、体积比和原高模的双向表面采样距离；粗档的有意偏离不作为近档卡线误差通过。远中另报告主方向尺寸比和实际单元内部的双向射线厚度；这是沿源主方向的截面厚度，不能当作法线厚度或以中位比接近1宣称局部误差都很小。

此路径只接受闭合流形、有体积、每部件不超过30000顶点/面的网格，最多16个独立壳体。独立壳体分别处理，结果不跨壳焊接；不自动封孔。原 UV、材质、蒙皮保留在原件，候选尚未迁移。原高模以外的四档均是**形体候选**，其中近档还未恢复完整规则包边及切角支撑线；不能把几何简化叫作完整卡线重建。旧边界线网路径继续保留。

远中补片路径目前要求单壳可由连续轮廓参数化；有洞、分叉、补片翻折或前后层穿插会拒绝，不能保证任意复杂形体均可恢复。全部四边面不代表已恢复所有语义结构或通过视觉验收。

API：`shape_levels.build_levels(mesh, settings, levels=None)` 返回所需档位 Mesh 字典和报告，调用方负责管理返回网格；例如 `levels=('FAR_MID',)` 只生成远中。异常时清理中间网格和临时对象。正式计算不读取参考图或视角。研发入口 `tests/review_shape_levels.py -- --source <几何快照.json> --output <目录> --levels FAR_MID` 只能在独立后台运行，输出指定档位的正、侧、顶、背、斜视和真实网格边线对照。

1. 物体模式选中源高模，执行“分析”。工具复制当前求值几何及对象变换，源数据不变。动画模型分析的是当前帧的形状，不会输出新的绑定或动作。
2. 在分析副本切换“区域 / 密度 / 转折响应”，点击“更新分析颜色”。颜色是证据和候选，不是已确认的结构语义。
3. 编辑模式选择面，合并/拆分区域；选择边锁定边界；选择细节面设置保护。可以手工选出正确的包边区域。修改网格位置或拓扑后需要重新分析。
4. 两种全件候选：
   - **保留结构 / 多边面候选**：在锁定边、分区边和保护区域外溶解近共面的冗余边。可能仅减少多边面数量，三角面数量不降；不是完成卡线重建。
   - **规则网格逆细分候选**：先尝试把三角形恢复为规则四边网格，再逆细分和拟合。只适合仍具有规则细分结构的三角网格；不可恢复时会拒绝。非零 crease、锁定边界、保护细节和多壳体不支持该路径。
5. **选区卡线面带**：在分析副本选择连通的环形面带，须恰好两条闭合边界。设置周向分段、横向分段、支撑线间距后生成独立四边面带。它没有自动焊接到源网格；复杂尖角、凹口、跨层和轮廓仍需要检查。
6. 选择候选，点击“验证基础 / 细分误差”。面带与选区快照比较，全件与全件快照比较。“开启 / 关闭细分预览”使用与拟合相同的有限次 Catmull-Clark 设置。
7. 在文本编辑器查看对象对应的 `*_Report.json`。最终人工查看正、侧、顶、背面/斜视，尤其是包边宽厚、内外转折、尖角和凹口。当前版本没有自动轮廓截面判定或三视图截图按钮。

## 结果口径

- 对角线是参考物件的空间包围盒对角线。默认表面容差 1% 是初始设置，不代表小结构可接受；应先按物件和细节尺度设置再运行。
- “细分误差通过”只代表双向有限采样满足容差，不是严格 Hausdorff 距离上界或视觉验收通过。
- 报告分别列基础网格、再次细分的误差与数量，孔洞/壳体/Euler 特征检查。
- 拟合、预览、回验统一为 `CATMULL_CLARK`、`use_limit_surface=False`、`boundary_smooth=ALL`。没有宣称复现 3ds Max 的所有 TurboSmooth 选项。
- 重建网格没有完成 UV / 蒙皮迁移。源高模、原 UV、材质和骨骼必须保留为供体；分析副本使用诊断材质。
- 没有全面自交证明、特征语义自动确认、复杂分叉补片和全人物重建。
- 同时选择多个物件不会批处理，当前活动物件是输入。分析上限为 300,000 面；拟合预算为求值前预计 150,000 面。大型模型应先分部件。
- 当前运算同步执行，尚无长操作中途取消；超出预算会拒绝，不应直接处理百万面整个人物。

## 初版遗留问题

真正困难的部分仍是：在不规则高模上找到稳定的转折带双边界，处理凹口/尖角配对，再建立支撑线。现有肩甲 86 个候选小区中有一个包含 4200 面的大区，说明边界有泄漏，不能直接作为自动建面的依据。需要继续改进多尺度曲率分区、人工种子约束和边界连续性；不能只提高密度阈值或面数来声称解决。

## 本轮续作：结构约束与曲面包边

新增源码能力：

- **多尺度曲率证据**：在面邻域拟合法线梯度，按局部物理距离衡量转折；使用围绕面积重心的包围球直径归一，避免物件旋转改变阈值。密度仍只强化几何证据。
- **人工种子竞争分区**：编辑模式选面 → 设置种子组编号 → “设为该组种子”；可给同一结构多个种子。物体模式执行“按种子 / 锁边重新分区”。锁边不可跨越，无种子可达区域及竞争归属不明确的面会报告。种子分区不是自动识别结构语义。
- **保护人工修改**：新分区操作保留种子、锁边、细节保护；若已经手工合并/拆分区域，则拒绝覆盖。保留该副本，另行分析后采用种子/锁边流程。没有把手工合并/拆分隐式当作自动标签。
- **显式边界对应**：可选内外边界两个顶点配对；也可选完整面带后“预览对应建议”。建议使用循环单调动态规划，不略过明显角点，不改变锚点。检查连线后“采用建议”才会替换当前锚点。建议不代表几何验收。
- **正面局部投影**：仅在选区连通走廊内投影，拒绝已覆盖的跨孔、跨层、扭转、局部翻面案例。
- **沿曲面截面**：新 `profile_strip.py` 在临时三角化副本上沿源面走廊追踪截面，共边交点只能沿对应共边移动；按曲面路径弧长铺四边面，并为可连续识别的转折增加支撑行。基础与有限细分使用独立预算。局部不连续、翻面、拓扑或采样误差失败时删除候选。

两个面带路径均输出独立部件，未自动焊接、未迁移 UV/蒙皮。曲面路径没有解决任意尖角、凹口、全面自交、自动轮廓截面验收或任务中途取消。

API：

```python
analysis.analyze(mesh, settings)  # 可读 scr_seed(FACE/INT)、scr_locked(EDGE/INT)
reconstruct.propose_strip_anchors(mesh, selected_faces, settings)
# 返回 anchor_pairs、requires_confirmation=True、匹配成本和预算信息。
settings['strip_anchor_pairs'] = [(source_vertex_a, source_vertex_b), ...]
reconstruct.build_strip(mesh, selected_faces, settings)
profile_strip.build_profile_strip(mesh, selected_faces, settings)
# tolerance: 细分预算；base_tolerance: 基础网格预算，缺省跟随 tolerance。
```

## 参考卡线与离面导线（实验）

选择“边界单线 + 切角卡线”后，可设置“离面平滑预算 / 物件尺度”和“线条简化误差 / 物件尺度”。主线与两侧线使用共同简化站点，保留检测角点；空间平滑受原始采样点位移预算限制，不强制再次贴面。参数采用分析的曲率尺度，不是验证使用的 AABB 对角线，也不是细分误差预算。

参考中模测量与五视图见 `artifacts/reference-lines/`（仓库根目录）。参考局部外扩约为 AABB 对角线的 0.45%～0.68%（两圈中位值），不能把这个样本数值写成所有模型的固定外扩量。

鳞片边缘与主包边都属于需要保留的结构边界。真实肩甲候选仍有分叉和断线，应逐片检查连续性，不能将鳞片线统一视为误检；当前仅输出导线候选。两侧卡线目前使用全线中位宽度，未实现自适应截面与控制笼外扩拟合；不能把测试通过、点数减少或成对偏移称为完整重建成功。

## 纯高模结构线网（实验）

识别方式新增“结构线网（凹凸分离）”。正式运算只读取源网格，不接受图片、图像点位或固定布线模板。研发图只用于人工比较目标结构。

此模式用带符号的几何曲率分开追踪凹谷/凸脊，限制横向转折带搜索范围；近邻交汇在同壳、同向表面检查后共享顶点。短缺口仅在两端相向、沿途确有几何转折证据时连接。对交点之间整条线做有限离面平滑与折线简化，不对每条线机械地复制两侧卡线。

结果报告含 `network.vertices/edges`、共享交点、证据补线数量及简化前点数。它是可编辑结构线候选，没有自动铺面或可靠恢复全部倒角截面。实际肩甲仍有菱形断线和错向，尚未还原研发参考图05完整布线，不能将测试通过称为重建成功。

### 先筛选边界，再做矢量平滑

在“结构线网”中选择“局部起伏分区”：从高模局部起伏产生区域边界，按交点之间整段线的几何转折支持度筛选，再对保留段作矢量平滑和折线简化。弱区域留空，不为凑网格自动补齐。

可调“边界几何支持度”“边界矢量平滑次数”“平滑位移 / 物件尺度”。平滑保护共享交点、线端及明显转角，允许有限离面；最大顶点位移记在报告 `network.max_smooth_displacement_relative`。它不是源表面误差或细分误差证明。

起伏分区仍可能误分包边或宽曲面，高置信候选不等于人工确认。参考图片仅作研发对照，正式路径只读高模。研发五视图与工程见 `artifacts/relief-network/`。

### 曲率面积边界 → 双侧面延伸 → 硬转折 → 矢量

“结构边界线网”的“面积曲率边界 → 平面交线”路径按以下顺序运行：

1. 使用原“面积＋曲率差异边界”的严格候选：直接邻面及两侧邻域的面积比、两侧曲率差和最低曲率必须同时满足。没有视角或图片输入。
2. 在候选边的两侧搜索低曲率、法线一致的局部面片，优先使用稳定面；曲面局部拟合失败时缩小邻域重试，不放宽平面残差预算。
3. 延伸两个局部平面求交线，按交线方向和外推距离检查生成虚拟硬边。近乎平行、偏离过远或拟合不可靠则拒绝。
4. 将同壳、相同平面对产生的重合交线去重，协调共享点后作有限矢量平滑和折线简化。允许虚拟硬边离开高模，不强制重新吸附。

“平面搜索 / 尺度”和“交线外扩上限 / 尺度”控制局部性。报告单独记录候选、平面拟合、求交拒绝及共享点冲突，不能把未输出部分视为已经恢复。

受控圆角折面能恢复一条虚拟硬转折；肩甲仍有漏段和碎线，未完成整圈包边或中模验收。源码测试不等于实际包边重建成功。

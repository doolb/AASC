# Blender 角色减面、连续 UV 与动画保留

在原模型副本上完成减面、蒙皮、UV 和颜色贴图迁移，以实际外观、变形和导出回读验证结果。用户只要求其中一项时，只执行相关步骤及必要验证。

## 输入与操作范围

优先读取当前 Blender 场景和已有对话，确定源集合、人物与武器、三角面预算、描边处理、UV 通道、骨骼和动画范围、贴图尺寸与输出目录。优先使用已连接的 Blender MCP；工具不可用时明确说明，不声称已连接或已操作。

以下是本次工作流的参考配置，不自动覆盖后续用户要求：

| 项目 | 参考值与口径 |
| --- | --- |
| 面数 | 单档按任务预算；本案例两档为展示版 10,000–20,000、移动版不超过 5,000 **三角面**，均包含人物与武器，同时报告基础网格和修改器求值后的数量 |
| 两档关系 | 先完成展示版的结构与细节，再从展示版派生移动版；原始高模始终保留为形状、贴图和蒙皮供体 |
| 展示版细节 | 腰扣、发饰、角饰、甲片装饰、武器宝石与护手等小物件保留实际几何、厚度和轮廓，不用纯颜色贴图代替应有体积 |
| 对象 | 人物一个 Mesh，武器独立；移除低模外层描边 |
| 重点 | 脸、手、关节保留细节与变形拓扑；其余区域按轮廓和动作分配预算 |
| UV | 最终保留 `UVChannel_1`；相邻面几何法线夹角大于 130° 为主要切缝条件 |
| 开口 | 已获用户同意时，在闭合部位补必要的背面或内侧开口 |
| 贴图 | 2048×2048 BaseColor；保留 Blender 原材质图，不额外烘焙其他通道 |
| 骨骼 | 保留现有骨架和动画；骨骼多只作为变形关注线索，不等同于必须增加面数 |

重新确认的仅是缺失且影响结果的信息。保留原文件与可回退副本；新结果另存，不覆盖原件。安装插件、减少骨骼或删除动画需要对应任务授权。对象名、路径、程序位置和连接参数从实际环境读取。

## 操作顺序

### 1. 建立基线与备份

- 记录每个 Mesh 的顶点、三角面、修改器、UV 名称、自定义角点法线、材质、父子关系、蒙皮组和绑定骨架。
- 记录骨骼数量、静置矩阵、动画片段与帧区间。保留原模型、原 UV 和原始高分辨率贴图作为供体。
- 区分 Solidify 等描边生成的面数与主体面数。对照采用相同动作、帧、相机和显示条件。

### 2. 分区域减面与拓扑整理

先分配人物和武器的总预算，再按部位迭代。脸保留五官与轮廓，手、肘、膝等区域保留变形所需的边；衣服大平面和遮挡区域可多减。

#### 2.1 指定 TopoGun 思路时：先导线和边界，再逐块铺四边面

用户说“像袖口一样”“按 TopoGun / topgun 的方式处理”时，以已确认袖口的连续四边面面带作为布线方法参考，不把袖口的形状或封闭方式套用到其他部位。先在原始高模表面明确结构，再建低模点、边、面。本节描述用户指定的工作流；是否实际使用 TopoGun 软件及其具体工具，需要核实可用环境。使用 Blender MCP 实现等效步骤时，明确报告实际工具与操作，不声称启动了 TopoGun。

用户提供的工具分工按以下方式落实，不假定不同软件或版本具有相同命令名：

| 工具 / 操作概念 | 用途与实现要求 |
| --- | --- |
| Guide Lines | 在高模表面规划布线方向；标出发束走向、衣片边界、褶皱主线、开衩、关节环线及小物件轮廓。保留导线供后续复核。 |
| Create / Extrude / Bridge | 沿导线建立控制点和首圈面，逐排延伸四边面面带，再连接确认属于同一表面的边界。先协调两侧顶点数及方向，避免扭转、跨层连接和封住原有开口。 |
| Draw / Tubes | 沿手臂、腿、手指等轴线布置截面环，再连接成管状结构；在肩、肘、膝、腕、指节安排变形环，按曲率和动作增加密度。 |
| Patch | 先规定衣片或发束补片边界、角点和分段数，再生成内部四边面；边界复杂时拆成多块可控补片，不用规则矩形或直筒改写真实轮廓。 |
| Brush | 调整、滑动和放松顶点间距，同时约束到对应高模表面；固定重要边界和轮廓点，分层投影，防止跳到相邻发束、衣服内层或身体上。 |
| Shell | 仅在需要可见厚度的衣片、甲片和饰件上补内层、边缘连接或局部厚度，计入三角面预算。袖内遮挡封口与完整加厚分别处理。 |

执行顺序：

1. **拆分与预算**：区分原始高模、已确认模型、当前候选；按头脸、躯干与袖、手指、腿、后发、裙子、甲片、饰物和武器分配预算。记录真实开口、分叉和叠层，小物件单独列项，防止整体减面时被削掉。可以分对象工作，最终按要求合并。
2. **画导线**：先定轮廓和结构线，再定横向分段。左右对称只用于确实对称的区域；非对称衣片、甲片、发束按高模保留。导线需要检查正、背、侧视，不能只贴合单张投影。
3. **铺面带与补片**：从已确认边界起建点面，沿导线逐排延伸。相邻补片先匹配边界，再 Bridge / 焊接；极点和必要三角面尽量远离关节主弯折区、面部关键环线与显著轮廓。四边面比例不能替代边流质量。
4. **调整与贴面**：检查面片尺度和长宽比，清理长菱形、细长面、翻面及跨层面；松弛时保护开衩、发梢、指缝和饰件锐边。投影限定到对应部件及正确内外层，不能仅因最近点距离小就接受映射。
5. **补厚度与局部封口**：检查正反面能否穿透及动作时可见性。已获授权的袖内封口放在适当内缩位置，以少量四边面遮挡，不封死真实袖口外观；仅删除经姿态检查确认持续遮挡的内部面。裙子开衩与分层不能套用袖内封口。
6. **局部验收再整合**：每个物件必须检查正、侧、顶三张正交视图，辅以背视和斜视确认厚度与叠层；同时检查素模、线框、轮廓和必要动作，再接入人物。检查通过后继续下一块，不额外索取已授权操作的许可；未通过则保留上个确认版本，修正该区域，不以面数达标或“全四边面”直接进入烘焙和交付。

颜色边界投影必须同时约束到正确的表面层：同色的内部封盖不能当作外侧包边。检查截面半径、相邻采样点距离和侧面法线，发现边线突然朝物件中心收束时，先修正命中的表面层，再铺面。

浮置饰件需要向内收口时，保留正面轮廓，用连续侧壁连接内缩背面；背面应贴合支撑物的弧度，避免整体平移背板造成过深凸入。三视图检查侧面露空、厚度突变和内侧突出；逐壳检查开放边、非流形边、退化面与扭曲面。独立壳体闭合不等于已与腰带或衣服焊接，报告时明确区分。衣服的真实袖口、开衩不得随饰件封口一并封死。

小物件采用“轮廓与硬转折的必要支持线 + 少量内部补面”，分段数由曲率、孔洞、凸起及可见尺寸决定。腰扣中心等平缓填充区不能沿用外框或卷纹的密度；不得为提高四边面比例均匀加密。用户要求先保效果、完成全身时，逐部件比较保形结果并记录尚未完成的边流整理；自动简化或三角面配对只能如实称为混合拓扑工作版，不能称为已完成手工四边面重拓扑。

本案例的部位要求：

- **后发**：纵向边沿发束延伸，横向边跟随曲率和分叉过渡；分别安排主束与分叉束的补片，保留发梢、卷曲和束间空隙。不要按相近位置跨接不同发束；自动横截面跟踪在分叉处必须复核对应关系。
- **裙子**：先描出前开衩、侧开口、内层、衣片边界和真实下摆，再从腰部向下铺连续面带。沿主要褶皱布置纵线，弯折与裙摆增加横线，避免整件改成规则直筒或误缝合开口。
- **手指与关节**：逐指保留指缝和指尖，建立指根与指节环线；保护已确认手部连接和蒙皮。先验证弯曲方向与权重，不能仅因骨骼多就均匀加面。
- **肩甲、上臂甲片与小物件**：分清独立壳体、叠压关系、厚度和硬边；展示版按高模保留腰扣外框与中心件、发饰等实体结构。近看显著的浮雕另列预算，不能默认全部退化成颜色图案，也不凭空添加原模没有的装饰。

#### 2.2 先建立展示版，再派生 5k 版

两档制作时，先让展示版通过上述结构、外观和关节验证，再从其副本删减非关键环线、降低平缓面密度、简化小物件背面与持续遮挡面。保留脸、手、关节、开衩、发梢及主要饰件轮廓；不全身套用统一 Decimate 比例。必要的自动简化仅限已划定区域，简化后重新检查边流和动作。

移动版由展示版派生，不意味着必须复用相同顶点编号或 UV 布局。两档共用原骨架与动作，但分别验证权重、UV、贴图和导出。先按第 3–4 步完成展示版整合与变形检查，再制作移动版；几何定稿后分别执行第 5–7 步。从原始高模采样可避免反复从已缩小图集转移造成损失。

本案例已观察到的失败不作为可复用成品方案：整体 QuadriFlow 会丢失细发梢或改变衣摆；仅用截面自动对应可能在分叉处跳接；减面后合并三角形再细分、回投，可能产生长菱形面。这些方法可用于受控局部试验，但不能替代用户指定的导线与补片流程。出现同类形变后，应回到边界、分区和对应关系修正，不能只提高面数重复试验并宣称达到参考图质量。

用户要求四边面时，检查环线、四边面比例与关节变形，选择合适的重拓扑或整理方法。自动减面后合并三角形不等于完整人工重拓扑；报告实际采用的方法。最终预算始终按三角化后的数量计算。

拓扑变化后，先验证或恢复旧贴图的采样坐标：通过源表面投影和源面角点 UV 的重心插值建立临时 `OriginalSourceUV`，接缝两侧分别取值，不能把 UV 按几何顶点平均。自定义法线也需按对应表面与角点转移，跨对象时使用正确的法线变换并归一化；检查插值后的外观，再进入重新展开阶段。

若一个低模面跨越了原 UV 接缝，仅转移角点 UV 无法表示面内部的采样跳变。优先在减面时保护原 UV 接缝；已有跨缝面时，可在新 UV 的每个纹素回投源表面、按部件隔离采样，或使用经验证的受控烘焙。先检查源 UV 映射有效，再采用第 6 步的同模颜色转移，避免将串色写进新图集。

### 3. 转移蒙皮并合并人物

- 拓扑变化后，用源表面最近点及面内插值等方法转移骨骼权重；坐标转换包含供体与目标的对象变换。
- 仅对名称属于目标骨架骨骼的权重组归一化；保留辅助遮罩组，检查无权重顶点。
- 合并人物各部件，武器独立。核对 UV、材质、自定义法线和 Armature 引用。
- 若原部件有不同的后置 Smooth 等修改器，合并后用分区遮罩保留各自作用范围，并比较合并前后的求值顶点。直接保留活动对象的修改器栈可能改变其他部位的变形。
- 若最终合并或重新转移权重影响了位置、法线或变形，先解决差异再展开和烘焙。

### 4. 保留或重定向动画

绑定姿态相同且无需换骨架时保留原动画。绑定姿态不同时，依据源与目标的对象变换、静置姿态和求值姿态重定向并烘焙，不能直接复制 Action 后宣称动作保留。

逐片段、逐帧比较结果。独立片段按顺序放入 NLA 导出时，检查是否存在 HOLD 向前覆盖其他片段；此布局可使用 `extrapolation='NOTHING'`，并比较 NLA 与直接播放 Action 的骨骼矩阵。现有混合、保持或循环语义按实际用途保留。

### 5. 规划切缝与重新展开 UV

角度定义为相邻面的**几何法线夹角**：共面为 0°。例如通过流形边的 `BMEdge.calc_face_angle()` 获取；不要把它换算成表面内角，也不要使用自定义着色法线来决定切缝。

UV 切缝与着色法线断开分别处理。展开 UV 不自动清除自定义法线、标记硬边或改变平滑着色。

用户要求保留多个 UV 通道时，逐个保留名称、用途和渲染引用；只有明确采用单通道输出时才清理其他通道，临时源 UV 不替代最终通道。

1. 清理旧 UV 的不必要切缝，以配置角度作为主要条件；平缓连接和浅内凹尽量连续。
2. 闭合头部、手指、衣片等无法只靠角度条件无重叠展平时，将必要开口安排在背面、内侧或遮挡处。已有同意可继续；用户要求绝对禁止额外开口时，先说明重叠与拉伸之间的限制，再确认取舍。
3. 在临时代理网格上展开和松弛，仅将经验证的 UV 坐标与切缝映射回真实网格，避免无意改变拓扑、权重或法线。使用 BMesh 或编辑模式处理切缝；修改前后核对顶点、面索引和循环映射。
4. 原生 Angle Based、Conformal 或 Minimum Stretch 仅是候选方法，`no_flip=True` 也不能代替重叠检查。若大岛折叠，先调整必要开口或松弛方式，避免把每个问题面单独切成碎岛。
5. 必要时使用正权重圆盘嵌入获得初始 UV，再进行自由边界的对称 Dirichlet 松弛；限制三角形翻转、边界自交，并留数值间距。圆盘初始图只用于求解，不能忽略拉伸直接交付。
6. 平均基础密度后提高脸和手的密度，联合打包人物与武器，按分辨率设置边距。

UV 岛按“相邻面共享边且两端 UV 坐标连续”统计，不能仅按 UV 顶点连通统计。记录总岛数、单面岛、面积利用率和拉伸指标；岛更少仍可能拉伸更大，需结合外观判断。

### 6. 从原贴图重烘焙 BaseColor

若几何已定型、仅重排 UV，优先采用同一低模上的**原 UV → 新 UV 颜色转移**：

1. 临时保留或恢复 `OriginalSourceUV`，源图使用原始高分辨率贴图，避免反复采样上一版图集。
2. 临时材质连接：`UV Map(OriginalSourceUV) → 原贴图 → Emission → Material Output`。
3. 接收 Image Texture 指向新图集并设为活动节点；新 UV 设为活动渲染 UV。
4. 使用 Cycles `EMIT` 烘焙，关闭 Selected to Active。多个对象写同一图集时，防止后一次烘焙清空前一次结果，并设置合适扩边。
5. 恢复原修改器与 toon 材质图，将对应颜色采样节点改用新图集；检查其 Vector/UV 引用指向最终 UV。
6. 保存 PNG，核对实际像素与尺寸，再打包到 `.blend`；删除最终输出中不再需要的临时原 UV 和供体对象。

只重排 UV 时，盲目高低模射线投射可能在重叠衣层、手和头发产生串色。用户另行要求几何细节或法线烘焙时，再按该任务配置射线、笼罩、切线空间和通道。不要默认附加法线等烘焙结果。

### 7. 验证、导出与展示

交付前从保存后的文件重新验证：

- **网格与蒙皮**：总三角面符合预算；人物与武器对象数量正确；无意外描边；权重有效且骨架引用正确。
- **UV**：配置角度以上的边实际断开；必要额外开口可解释；无非预期重叠、退化 UV 三角形、非有限坐标或越界。用原生重叠选择检查，疑似误报时补充三角形实际相交面积检查。
- **外观**：正面与背面对照，重点看脸、手、衣服花纹、接缝和贴图渗色；量化拉伸，并如实说明密度或拉伸的取舍。
- **对照基准**：本案例左侧固定为原始高模，右侧为当前展示版或移动版；不能用上一版低模冒充高模。统一动作、帧、相机、光照及显示条件，按相机右向量安排左右，防止背视图翻转位置；逐帧更新对象与骨架的坐标变换。另提供无纹理素模及线框近景，展示后发、裙子、袖口、手指和小物件，不能依靠贴图遮盖结构问题。
- **动画**：核对骨架静置姿态、片段数、帧范围和逐帧结果；纯 UV 修改前后，几何、骨骼权重与动画曲线应保持一致。法线允许实际存储量化误差，需核对误差量级。
- **FBX**：重新导入检查 Mesh、三角面、骨架、UV、贴图和动画。FBX 无法完整表达 Eevee toon 节点时，仅在导出阶段使用临时 Principled 颜色材质；`.blend` 保留原材质图，说明 FBX 的材质范围。

输出独立的 `.blend`、`.fbx`、BaseColor PNG、UV 与人物外观对比图及验证结果。经验证后将新版载入 Blender 供用户对照，不覆盖原场景文件。

验证容差在检查前按模型尺度与用途确定，并记录实际最大误差。可沿用本案例的起点：0–1 UV 图集中的 UV 三角形面积小于 `1e-12` 视为退化，坐标越界容差 `1e-5`，同一坐标约定下 NLA 与直接 Action 的骨骼矩阵逐元素最大误差小于 `1e-5`。这些数值不能直接证明跨尺度重定向正确；拉伸需报告 UV/表面雅可比奇异值比的面积加权中位数与 P90，并结合外观验收。未通过时说明差异来源，不为通过检查临时放宽容差。

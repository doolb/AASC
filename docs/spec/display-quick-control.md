# 显示端快捷控制伪代码

```text
初始化：在媒体库入口上方绑定快捷控制面板；打开时读取当前媒体、文本、列表、音量、填充状态。
用户操作：只发送 displayQuickControl 消息，携带允许的操作和值，不携带目标显示端。
服务端：核验显示端连接身份，按白名单规范化操作，将目标设为连接对应的显示端；复用既有控制、播放列表和语音命令流程；语音按名称搜索匹配媒体时，下发显示端识别的 url 类型及文件名。
显示端接收控制或恢复状态后刷新面板；打开时按现有运行状态更新文本分页与批量播放。
音视频进度：读取当前播放元素的已播时间和有限时长；时长有效时展示时间并启用滑块，其他媒体或时长未知时禁用。
拖动滑块时保留用户预览；松开后将百分比作为 seek 操作发送，服务端校验 0 至 100 并使用连接身份转发，仅跳转当前显示端。
切换媒体或拖动取消时放弃旧预览，恢复显示当前播放状态；断线或不可跳转时不发送操作。
断线时提示连接不可用；Android 返回键优先关闭打开的快捷控制面板。
```

# 显示端右侧设置面板互斥实现文档

## 顶层面板互斥（2026-10-19）

```text
面板集合 := [主题, 音色, 灯光, 动作, 定位]
每个入口 := display-stage-lighting-control 的直属 button[aria-controls]
每个面板 := 与入口 aria-controls 对应的直属 section

页面初始化:
    在右侧按钮列注册捕获阶段 click 监听；只处理直属顶层入口
    子分类、弹层内按钮和其他舞台按钮不参与互斥

点击某个入口之前:
    遍历面板集合中除当前入口外的已展开面板
    分别调用主题、音色、灯光、动作、定位模块原有的关闭方法
    关闭方法负责音色定位请求取消、动作进度定时器停止等模块内部清理
    将已关闭面板 hidden=true，配对入口 aria-expanded=false
    若模块尚未初始化，仍按 DOM 状态关闭可见面板
    随后让入口原有 click 监听决定当前面板展开或收起

验证 := 五个入口任意顺序切换始终最多一个顶层面板可见；
        音色关闭后迟到的定位结果不重新打开；动作关闭后停止进度定时器；
        再点当前入口可关闭；子分类开关不触发互斥；Escape 和点空白处沿用原行为
```

# 显示端界面优化伪代码

```text
打开媒体库 → 并发读取各来源根目录 → 成功条目立即汇总，失败或超时来源提示
条目绑定 libraryId + path → 播放/批量/目录导航始终路由到原来源
返回来源根目录 → 汇总页；旧请求完成时若版本失效则丢弃
封面加载/视频元数据 → 读取宽高，设置卡片比例并重新排布；缺失或失败 → 默认尺寸
```

```text
加载显示端原有主题和各功能样式后加载界面样式
快捷控制打开时：
    横屏且宽度至少 720 → 标题和状态占整行，功能区域两列排列
    其他情况 → 功能区域单列；内容过长时面板内滚动
媒体库打开时：
    横竖屏 → 统一展示来源内容，目录和媒体卡片随宽度排列
    背景透明度仍由原变量控制，文字和操作保持可读可触及
聊天、主题、音色、MMD 和壁纸控件 → 使用主题色、清晰边界和适当触控间距
保留原控件标识、事件、隐藏状态、透明度、旋转、安全区域和图层顺序
```

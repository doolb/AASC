# MMD-AR PMX 文件导出实现伪代码

```text
加载原始 PMX 网格、应用工程覆盖之前：
    为每个刚体/关节记录源索引及加载器坐标下的原始参数
    保存、撤销、重建物理沿用来源信息
    新增/复制对象标为无源索引

点击“导出 PMX”：
    读取当前角色原始 PMX 字节，限制256MiB
    校验当前刚体/关节文档
    扫描 PMX 2.0/2.1 结构，记录刚体/关节段起止
    保留头部、顶点、面、材质、骨骼、表情、显示框与软体原始字节
    收集冲量表情及软体锚点对刚体的引用
    由来源索引建立原刚体索引到新索引的映射
    按新增数量保留或扩展刚体索引宽度，更新头部与引用字段
    删除已删除刚体对应的冲量元素/软体锚点，更新对应计数
    现有记录：比较编辑参数与源参数，仅覆盖实际修改字段
    新记录：写入全部编辑参数，英文名缺省为空
    刚体位置：骨骼相对位置加源骨骼绑定位置，还原PMX坐标
    位置/旋转/上下限：按加载器反向变换还原左右手坐标
    未改记录及不涉及引用的其他段保持字节一致
    验证输出结构、计数、刚体引用及文件长度
    Blob下载“源名称-edited.pmx”，保留贴图相对路径
    导出不清除工程脏状态：场景、灯光等仍需保存工程ZIP

旧工程缺少来源信息：
    仅在计数、名称及顺序与原PMX一致时恢复源映射
    无法证明来源时拒绝导出并给出重新加载提示
```

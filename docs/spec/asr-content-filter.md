# ASR 内容过滤伪代码

```text
ASR 文本 → 检查是否含汉字、英文字母或数字；完全不含有效字符则拒绝
从原文提取连续的英文字母、阿拉伯数字和中文数字片段
存在长度2至12且同时含英文字母和数字的片段 → 内容放行，原文进入后续语音路由
数字包含阿拉伯数字与零〇一二三四五六七八九十两；片段内部空格或连字符仍视为分隔
未命中编号 → 沿用 requireChinese、无效短英文和不足两个汉字等已有过滤
内容放行只决定是否交给聊天或语音命令模块 → 不从编号直接生成游戏调用，不绕过声纹、会话和棋局校验
```

验证：下H4。、选A12、下H四。保留原文；C 3、C-3、纯英文短噪声、单个数字与单汉字仍过滤；连续编号长度上限保持12。

# HIE 子工程与游戏任务桥接伪代码

工程路径 := AASC/subproject 下 HIE、retop、remote-gamepad 实际目录
旧 HIE 路径 → HIE 实际目录；旧 retop 路径 → retop 实际目录
关卡证据目录 → 读取识别、计划、结果 → 组装观察与反馈 → 非通关结果映射 NavigationGap → 可选报告到队列
显式启用 → 验证关卡、窗口和显示参数 → 固定脚本与参数数组启动游戏任务 → 返回退出状态；默认不启动

统一仓库 := 将 HIE 与 retop 的嵌套 Git 元数据移出工作树 → 子工程文件由 AASC 主仓库管理 → 源代码和必要文档纳入主仓库；模型、运行日志、设备数据和构建产物按路径忽略并保留本地 → 不自动提交。旧提交历史不要求合入主仓库。

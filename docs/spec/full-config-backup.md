# 全量配置与聊天数据 ZIP 备份伪代码

状态：已实现。导入预览确认后自动重启服务器，在配置模块加载前恢复。

```text
已有声明
  当前运行目录上下文包含 configFile、userConfigDir
  聊天模块维护延迟历史保存与持久化会话
  现有用户 JSON 配置导入导出入口
  控制端文件选择与服务端重启入口
  APK WebView 文件选择器
  APK NativeControl 小文件保存桥

新增定义
  FullConfigManifest 包含 format、version、exportedAt、files
  BackupFile 包含 scope、relativePath、size、sha256
  配置范围集合包含 config、userconfig
  导入模式集合包含 merge、replace
  固定备份暂存目录与独立恢复备份目录
  工作目录及父目录逐级检查为普通目录，不跟随链接
  ZIP 大小、解压总量、单文件大小与数量上限

操作流程：导出
  按当前上下文解析全局与用户配置目录
  完成待保存聊天数据，不因导出改写无变更的历史
  枚举受管持久化普通文件，跳过链接与运行时数据
  复制稳定快照，检查期间没有清单或内容变更
  将原文件归档到 config 或 userconfig 范围
  为每个文件计算大小与 SHA-256，生成 manifest
  纯 Node 生成 ZIP 并返回下载

操作流程：导入校验与预览
  流式接收 ZIP 到固定暂存目录
  检查归档格式、文件数量、解压大小与压缩展开限制
  拒绝绝对路径、路径穿越、重复路径、链接与特殊文件
  拒绝未知顶层范围、运行时文件及未声明条目
  校验 manifest 版本、文件大小与 SHA-256
  解析目标实例目录，不使用备份内源机器路径
  按所选模式计算新增、覆盖和受管删除范围
  返回预览标识与统计，不修改正式配置

操作流程：确认导入
  校验当前上传标识、所选模式与预览内容一致
  将验证后的文件与导入模式写入固定待应用事务
  原子发布待应用标识，返回 restarting 与导入标识
  响应发送完成或连接关闭后，通过共用重启流程自动关闭旧进程
  重启只触发一次，校验失败、预览取消或不具备托管重启能力时不重启
  当前进程继续使用当前配置，不在线覆盖正式文件

操作流程：启动前应用
  在加载配置、用户服务和聊天模块之前读取待应用事务
  重新校验文件与范围，拒绝无效事务
  记录当前目标文件快照与独立回滚备份
  原子替换需要新增或覆盖的文件
  replace 模式只删除受管范围内明确列出的多余文件
  更新事务完成状态，清除本次暂存内容
  任一步失败按事务恢复旧文件，保留可诊断状态
  上次启动在 applying 中断时先回滚，不继续应用一半事务
  已提交但尚未清除 pending 时补写完成结果，不重复覆盖数据
  然后继续正常启动并读取导入后的数据

操作流程：前端与 APK
  保留旧用户 JSON 按钮，新增全量 ZIP 按钮和 ZIP 文件输入
  导入显示统计和模式，确认后显示服务器正在重启
  服务恢复后查询本次应用结果，成功后刷新页面；失败显示回滚结果
  浏览器下载备份响应
  APK 请求当前来源的备份保存，弹系统保存文件选择器
  原生下载与写入成功、取消或失败后返回页面状态
```

ZIP 写入采用直接生产依赖 yazl 的流式归档，读取复用 yauzl。启动恢复使用同步、分块校验，必须早于 config-app-service 加载。APK 在现有 NativeControl 桥增加同来源 ZIP 保存请求，复用 ModelDownloader 的证书校验连接；原生保存使用系统创建文档入口。旧 JSON 功能保持。

发布产物：本次代码包与生产依赖包同时更新；APK 保存原生变更对应 min APK v37（0.2.35-offline-min），复用已编译 MNN。

验证覆盖：普通/release 目录映射、全局与聊天多文件往返、默认合并与明确替换、取消不写入、备份回滚、重启前不应用、启动时应用、延迟保存一致性、损坏 ZIP/哈希、路径穿越、链接、解压上限和 APK 文件保存结果。

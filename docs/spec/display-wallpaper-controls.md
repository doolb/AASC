关闭、页面不可见或旋转 → 清除运动状态；无事件或数据无效 → 提示检查传感器及权限，不回退倾斜
PMX/VRM → 原相机局部右上轴应用偏移 × 模型高度 × 4（较此前 0.4 放大 10 倍），保持手动视角、距离及既有 AR 优先级

## 全息倾斜（2026-11-11）

```text
普通显示与壁纸共用三个本机开关 → 角色倾斜 / 角色平移 / 镜头平移，默认关闭；角色平移与镜头平移互斥
角色开启且页面可见 → 注册设备姿态；首次有效样本作为中心 → 转屏或重新可见后重新定中心
倾斜角 → 按屏幕方向换算、限幅 → 输出角色旋转；含重力加速度与低通基线相减 → 屏幕轴与每帧回中处理 → 输出镜头平移
镜头平移 → 相机本地右/上轴小幅位移并缓动，保持用户相机方向、距离和目标不变；关闭后回到原位
关闭/页面不可见/传感器不可用 → 停止监听并清除偏移；现有手动、AR和镜头动画优先
```

已有声明 := 共享 WebView、壁纸 Engine、前台 Activity、壁纸物理顶部安全距离、显示端旋转布局

系统浮窗 → 读取共享页面语音权威状态与当前主题；大圆调用现有语音操作，小圆点请求现有监听模式切换

拖动、收起或展开结束 → 保存可用屏幕范围内的相对位置、贴边方向和收起状态
桌面以外 → 移除浮窗并保留状态；返回桌面或重建浮窗 → 按新屏幕尺寸还原相对位置、贴边方向和展开/收起状态，再约束在可见区域；未保存时使用默认位置
普通页面面板 → 保留 FPS、时间、音量与内容交互开关；授权缺失时从前台引导设置

时间 → 测量物理屏幕包围盒，若与壁纸状态栏重叠，仅向物理下方移动重叠量；旋转及重排后重新计算
用户关闭前台任务且 Activity、壁纸服务或 Offline Node 服务收到关闭回调 → 暂停壁纸渲染与共享页面
读取桌面当前壁纸组件 → 仅当组件属于 AASC 动态壁纸时 → 恢复桌面系统默认壁纸，保留锁屏壁纸；异常记录日志并继续释放
桌面壁纸恢复后 → 重新启用 AASC 壁纸需要用户在系统预览中确认
系统强制终止或不提供任务关闭回调 → 无法保证执行清理

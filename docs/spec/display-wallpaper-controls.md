# Android 壁纸状态与浮动控件伪代码

```text
已有声明 := 共享 WebView、壁纸 Engine、前台 Activity、壁纸物理顶部安全距离、显示端旋转布局
新增定义 := wallpaperActive、wallpaperSuspended、wallpaperFpsVisible、wallpaperTimeVisible、浮动面板位置和收起状态
壁纸接管共享 WebView → 通知网页进入壁纸状态；前台接管 → 通知退出壁纸状态
壁纸状态 → 隐藏交互按钮层与模型入口；普通状态恢复原有界面
壁纸状态 → 展示可拖动、可贴边收起的面板，包含系统媒体音量、状态提示、FPS 与时间独立开关
手动开关只影响壁纸状态，切换前台不覆盖普通界面状态；偏好在本机持久化
壁纸触摸事件 → 转发给共享 WebView；系统桌面不转发时不可强制接管触摸
时间 → 测量物理屏幕包围盒，若与壁纸状态栏重叠，仅向物理下方移动重叠量；旋转及重排后重新计算
用户关闭前台任务且 Activity、壁纸服务或 Offline Node 服务收到关闭回调 → 暂停壁纸渲染与共享页面
读取桌面当前壁纸组件 → 仅当组件属于 AASC 动态壁纸时 → 恢复桌面系统默认壁纸，保留锁屏壁纸；异常记录日志并继续释放
桌面壁纸恢复后 → 重新启用 AASC 壁纸需要用户在系统预览中确认
系统强制终止或不提供任务关闭回调 → 无法保证执行清理
```

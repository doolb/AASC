# Android 壁纸状态与浮动控件伪代码

```text
已有声明 := 共享 WebView、壁纸 Engine、前台 Activity、壁纸物理顶部安全距离、显示端旋转布局
新增定义 := wallpaperActive、wallpaperSuspended、wallpaperFpsVisible、wallpaperTimeVisible、浮动面板位置和收起状态
壁纸接管共享 WebView → 通知网页进入壁纸状态；前台接管 → 通知退出壁纸状态
壁纸状态 → 隐藏交互按钮层与模型入口；普通状态恢复原有界面
壁纸状态 → 单独恢复网页识别文字可见，沿用原页面识别内容与隐藏计时，不接收触摸
壁纸状态 → 显示独立的语音系统浮窗：状态文字、语音大圆、监听模式小圆点和语音活动指示
手动开关只影响壁纸状态，切换前台不覆盖普通界面状态；偏好在本机持久化
壁纸触摸事件 → 转发给共享 WebView；系统桌面不转发时不可强制接管触摸
壁纸浮动面板 → 显示在网页普通内容的最上层；系统窗口和浏览器顶层元素遵循系统层级
普通显示页 → 展示可拖动浮动面板及设置壁纸入口；壁纸页隐藏网页面板
用户授予悬浮窗权限且真实桌面壁纸可见 → 显示独立系统浮窗；前台、预览、不可见或销毁 → 移除浮窗
无障碍服务可用 → 根据前台窗口与默认桌面匹配控制浮窗显示；其他应用在前台 → 隐藏浮窗；桌面恢复 → 恢复浮窗；服务不可用 → 退回系统壁纸可见状态
浮窗按当前窗口尺寸、字体缩放重新测量，状态单行省略、收起把手减小垂直留白；旋转和缩放后约束在可见区域
壁纸请求音频采集 → 系统麦克风已授权且真实壁纸处于活动状态才授予音频；视频权限仍仅前台允许；点击失败向浮窗反馈
系统浮窗 → 读取共享页面语音权威状态与当前主题；大圆调用现有语音操作，小圆点请求现有监听模式切换
拖动浮窗靠近屏幕边缘 → 贴边并开始 5 秒计时；操作或拖动 → 重置计时；计时结束 → 收起到边缘把手；点击把手 → 展开并重新计时
普通页面面板 → 保留 FPS、时间、音量与内容交互开关；授权缺失时从前台引导设置
壁纸内容交互开关 → 默认开启并在本机保存；关闭时以透明遮罩覆盖面板以外的网页内容并在捕获阶段拦截触摸、指针和鼠标交互，面板始终可操作；开启时移除遮罩并恢复原有网页事件路径
时间 → 测量物理屏幕包围盒，若与壁纸状态栏重叠，仅向物理下方移动重叠量；旋转及重排后重新计算
用户关闭前台任务且 Activity、壁纸服务或 Offline Node 服务收到关闭回调 → 暂停壁纸渲染与共享页面
读取桌面当前壁纸组件 → 仅当组件属于 AASC 动态壁纸时 → 恢复桌面系统默认壁纸，保留锁屏壁纸；异常记录日志并继续释放
桌面壁纸恢复后 → 重新启用 AASC 壁纸需要用户在系统预览中确认
系统强制终止或不提供任务关闭回调 → 无法保证执行清理
```

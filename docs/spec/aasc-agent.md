# 个人 Agent 实现伪代码

已有声明：HIE 角色运行时绑定环境、识别与导航；SubAI 使用 CSV 字段。

新增定义：角色 = {名称, 人设, 允许能力集合}；任务 = {角色, 内容, 参数}；模型 = {decide}；能力 = {名称, execute}。

操作流程：
1. 内部命令输入 → 按配置检查完整方括号 → CSV 解码 → 校验角色与内容 → 任务；格式错误拒绝。
2. 模型提出的任务 → 主角色与模型 decide → 请求能力及参数 → 按主角色允许集合检查 → 能力执行 → 返回结果。
3. 委派请求 → 校验主角色具备 delegate 权限 → 选择已注册角色 → 调用该角色模型 → 按该角色允许集合检查能力 → 返回结果；不接受模型自行扩大权限。
4. HIE 能力通过注入的 execute 接口调用；未注入时明确报错。模拟能力和模型用于自测。

## 终端聊天与内部命令伪代码

```
Agent.chat(用户自然语言, 配置):
    校验可选聊天角色为宿主已注册角色；将角色名称与人设传入每次 model.respond
    将用户文本原样交给宿主 model.respond，不将用户文本作为本地命令解析
    模型返回文本，或 {text, commands}，commands 是模型明确提出的方括号指令数组
    校验本轮全部 commands 的格式、数量和宿主授权的 commandRoles，任何一项不合法则本轮均不执行
    依序将模型指令传给 runCommand；保留角色权限检查；把本地结果交给 model.respond 继续处理
    模型不再提出命令则返回最终回复与本地结果；限制单次聊天的模型调用轮数
Agent.runCommand(模型指令, 配置):
    解析指令；将可选的 onEvent 观察器传入 run
Agent.run(角色, 任务, 参数, 深度, 观察器):
    发出开始、决策、委派、工具执行与结束事件；观察器异常不改变授权或任务结果
TUI(Agent, 输入流, 输出流):
    持续读取用户自然语言；/help 显示帮助；/exit 或 EOF 退出
    /role 列出注册角色与当前角色，/role 名称 选择角色，/role --default 清除选择
    不存在的角色给出错误并保留现有选择；角色选择不改变 commandRoles 或工具权限
    顺序调用 Agent.chat，展示 AI 文本、执行事件和本地结果；错误后继续
    不将用户输入直接交给 runCommand；npm start 启动自然语言界面
    原解析工具以 npm run parse 保留供开发调试
TUI 入口:
    --demo 使用标注为演示的本地回显模型；不连接真实模型或设备
    AASC_AGENT_MODULE 提供实现 chat 的宿主 Agent 或工厂；否则明确提示未配置
```

事件类型 := run:start、decision、delegate、tool:start、tool:complete、run:complete、run:error；每项包含 role、depth。显示输出过滤终端控制字符。模型命令的允许角色须由宿主显式配置，默认为空；现有工具权限仍由角色检查。真实 Responses 适配器、跨轮模型上下文和外部执行由宿主提供。

## Responses 模型与本地配置伪代码

```
加载配置(路径):
    读取 JSON；校验 API 地址、模型、超时、角色、权限与默认角色
    密钥来自本地配置或指定环境变量；不将密钥写入日志或示例
创建正式 Agent(配置):
    注册主助手及游戏角色；默认仅聊天，无须 HIE
    本地能力由宿主按需注入；未注册能力明确报错，commandRoles 仅采用配置明确授予的角色
Responses.respond(消息, 选中角色, 本地结果):
    按角色查找上次 response_id；发送当前输入、角色人设和可调用角色说明
    返回纯文本或严格解析的 {text, commands}；普通文本不自动解析命令
    成功且响应 ID 有效时更新该角色续接点；失败不静默新建会话
Responses.decide(角色, 任务):
    单独请求模型以严格 JSON 选择该角色允许的能力；非法结果拒绝
终端入口:
    显式 --demo 使用演示；AASC_AGENT_MODULE 使用宿主注入；否则加载本地配置与正式角色
```

显式 /new := 仅清除当前角色的本地 Responses 续接点，下一条消息新建会话；不删除网页对话。若宿主不支持重置则明确报错。默认角色由配置指定，/role --default 恢复该角色。

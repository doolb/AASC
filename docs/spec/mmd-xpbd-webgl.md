## GPU 物理姿态直连骨骼纹理（2026-10-12，实现伪代码）

```text
动作面板:
  默认关闭、仅独立网页，保存用户请求的 directBoneTexture 布尔值
  仅在当前模型物理启用、求解器实际为 xpbd-webgl、WebGL2 + RGBA32F 可渲染、骨骼拓扑受支持时启用
  UI 分别显示“请求开启”与实际后端：GPU 直连 / CPU 同步诊断 / 不适用 / 回退原因
  不自动切换求解器；切换动作/模型/上下文时解绑旧纹理并复位状态，关闭时一次同步最终GPU状态

模型准备:
  按骨骼顺序构建父索引、绑定逆矩阵、原始局部 P/Q/S；按 PMX 刚体顺序建立骨骼写回映射与 inverseOffset
  保留 Three 自身 SkinnedMesh 的顶点着色器蒙皮；骨骼纹理按每骨4连续vec4列排布，尺寸与三方取样一致
  分配独立 RGBA32F/Nearest/NoColorSpace 骨骼姿态目标；不改全局 Three 原型，不将渲染目标冒充可从CPU上传的 DataTexture
  复杂/超限拓扑不做不正确的合成，显式报告并保持原帧末同步方案

每帧正常直连:
  MMD helper 先完成 mixer 采样、局部动作融合、IK、Grant；进入物理update前取得是否推进了动画
  推进动画时：CPU 上传最终动画局部 P/Q/S、当前物理临时根及恢复后的网格根；GPU计算本帧锚点
  未推进动画（暂停、无mixer、首帧预热）时：保留上帧 GPU 最终局部姿态，并在当前根坐标重新组合父骨，以获取动态父骨下的锚点
  GPU 存储本帧/上帧锚点供子步内插值，不因暂停改回逐帧读回
  按现有 XPBD 顺序运行所有求解 pass，读取最终 state.texture 的位置与四元数
  按原 CPU _updateBones 顺序语义处理 type0/无 bone 跳过、type1局部位置+旋转、type2仅局部旋转；
    使用父骨完整世界矩阵做位置反算，保留 local scale；同骨多刚体和父子先后写回须与同步基准一致，不能仅混合全局矩阵
  根据恢复后的模型/父级世界矩阵及 boneInverses 合成 Skeleton.boneTexture 兼容布局
  主材质/阴影/深度消费同一新纹理；避免 Three.Skeleton.update 覆盖 GPU 结果，正常预览不执行 pack/full readback/_updateBones
  不读取触点标志；GPU 计时与 readbacks 等状态报告真实 GPU/CPU 成本，不能宣称所有设备变快

需要 CPU 姿态的路径:
  开启骨骼/刚体诊断、需要准确网格拾取或编辑、切出直连时按需一次读取最终 GPU 刚体状态并同步 CPU 骨骼
  诊断开启期间临时保持原每帧同步回读与骨骼回写；关闭后无需重建模型即可恢复直连
  诊断 API 与复选框使用同一兼容条件：物理步进前读取骨骼/刚体 Overlay 的 enabled 状态；开启 API 立即单次同步
  编辑桥 read/face 在访问 CPU 骨树前按需同步；rest 先同步、恢复绑定姿态，再重置物理纹理/速度/插值
  GPU 不支持、状态无效或上下文丢失时释放新纹理和绑定，显示明确回退原因；若 GPU 状态已不可读，从动画姿态显式重置，不能用过期 CPU 刚体继续求解
  页面后台/首帧门控、T-pose/换动作/换模型/关物理和循环物理连续性沿用原有语义
  旋转门控暂停 := 保存旧 physicsTransform -> 读取GPU旧世界姿态 -> 临时映射到当前物理根并回写CPU局部骨姿态
    还原刚体旧世界姿态与旧根基准 -> 基类整体跟随当前根（type2锚点取已恢复局部骨树）并清零/重置
  退出直连/兼容同步 := 读回最新姿态 -> 解绑并失效上一GPU局部姿态缓存 -> CPU回写；下次进入以最新CPU骨树重新种子

验证:
  真 WebGL2 shader + 数值比对：type0/1/2、同骨多刚体、父子逆序、非单位缩放/父级改变、暂停/预热/旋转门控
  当前帧角色颜色/深度/阴影与 CPU 同步基准一致；诊断、拾取、开关、模型/VMD切换、上下文丢失/恢复均无过期纹理
  正常预览及暂停下逐帧完整物理读回为0；诊断/按需同步确有读回并显示，统计 GPU 时间/整体帧耗与回退原因
```

## 拖动飞散修复（2026-10-12，独立场景已验收，累计场景另列）

```text
已有声明 := WebGL2接触点、A到B法线、间距、当前/入射法向速度、接触lambda与摩擦预算
新增定义 := 允许闭合速度下界、单边法向速度修正、拖动验收的蒙皮顶点范围与状态界限
接触已分离 := 允许闭合速度下界取负间距/子步时长；不得主动制造正向分离速度
接触仍重叠 := 下界沿用有效反弹目标；法向速度修正取下界减当前速度的非负部分
摩擦 := 当前接触间距超过容差时不施加已失效的旧接触摩擦；仍在接触时沿用lambda/子步时长预算
  合并速度修正沿用已有有效质量计算
正常GPU直连 := 沿用当前锚点/骨骼纹理流程；修正不增加常规物理读回
显式同步后恢复直连 := type0/type2的位置目标与历史端点从已读回的最终刚体姿态同步
  重新初始化锚点纹理不能使用进入直连前的CPU旧缓存；沿用本次读回，不新增读回或整批重置
验收 := 静止/分离/碰撞反弹/摩擦/受关节推开的旧接触，检查不注入分离能量或负法向拉力
  真实PMX鼠标及触摸平移/旋转 -> 3/45子步、播放/暂停、直连/同步 -> 蒙皮范围与物理状态不发散
  保留正常帧读回0、诊断/按需同步、上下文与生命周期回归
配置独立验收 := 各配置从当前骨姿态重置起始物理；配置内鼠标平移/旋转、触摸平移/旋转连续推进
  不以配置重置后的通过替代携带既有姿态/速度的累计操作及开关连续性验收
范围 := 只改测试端WebGL2接触shader、同步端点缓存及相关测试；CPU XPBD、正式端、APK、发布不改
```

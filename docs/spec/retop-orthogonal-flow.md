# Retop 经纬走线伪代码

已有声明：CSI 分区、固定边界、包边轨道、曲面求值器、最终网格和用户参考高低模。

新增定义：局部经纬夹角误差 := 相交方向在曲面切平面的夹角与 90 度之差；只统计有效方向。

操作流程：
1. 读取参考模型副本并核对肩甲形状和低模线流。
2. 对最终曲面和网格计算局部经纬夹角，识别受平顺、轨道配对和边界约束影响的位置。
3. 在保留结构边界和形状的条件下优化对应关系与内部走线；避免翻面、穿插和退化，约束不可兼得时报告残差。
4. 使用合成案例和参考模型比较最终结果，检查空间变换、旧参数回放、OBJ 与多视图。

肩甲环带检查：从最终曲面求值器分别取经向和纬向有限差分 → 计算角度误差分布 → 将结果与优化前基线比较；同时用最终生成的边和顶点检查连线及穿插。尝试在轨道配准中添加两侧切线正交惩罚后，最终曲面 P90 由 12.58° 恶化到 13.46°，该尝试已撤回；应继续研究后续平顺、拟合及最终网格共同约束，避免仅优化中间轨道。

分阶段对照（自带肩甲闭合环带，同一 19×9 内部参数采样）：配准站位平均偏差 3.10°、最大 11.15°；Gordon 曲面 P90 10.21°；边界修正后 P90 10.53°；再执行高模剖面约束后 P90 12.58°。不同阶段统计对象不同，不应将站位最大值直接与连续曲面最大值视作相同口径；这些数字用于定位而非证明实际边流改善。

待验证方法：在最终参数曲面上求两族切向导数 → 以中间轨道为初始线，沿横向积分局部正交方向 → 检查周期闭合、参数单调和退化 → 将映射同时用于导线和实际网格；固定结构边界位置并允许相应参数重配。不能通过检查时保留原结果并报告原因。先用可解析的扭斜圆柱验证，再检查肩甲参考、旧参数重放和面片穿插。

正交追踪试验：扭斜圆柱合成曲面通过；肩甲环带直接追踪产生折叠，加入单调保护后曲面 P90 从 12.58° 降至 7.06°，最大从 31.23° 变为 31.81°。该映射会移动周期接缝与边界采样参数；将接缝固定后 P90 恶化至 37.69°。当前真实网格依赖原接缝和 CSI 采样，尚未实现支持可移动接缝的重布线，试验代码已撤回，不影响现有导线与网格。

当前基线：工程自带肩甲的最终曲面，以每个条带内部 19×9 点及数值偏导采样；闭合环带偏离垂直的平均值 6.06°、P90 12.58°、最大 31.23°。该结果不代表用户提供的人物肩甲的误差，也不是实际网格边角度。算法调整及实际网格核验尚未完成。

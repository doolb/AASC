# 显示端壁纸控件与监听状态

壁纸使用共享显示页，但应隐藏前台交互按钮，保留一个可拖动、贴边收起的壁纸浮动面板：提供系统媒体音量与状态提示，并独立控制 FPS 和时间。普通前台保留原样；壁纸时间按物理状态栏实际重叠避让，暂不改变文件名。壁纸与前台切换需即时同步页面状态。用户关闭应用且收到关闭回调时暂停渲染，并仅在当前桌面壁纸仍为 AASC 时恢复系统默认壁纸，保留锁屏壁纸；再次使用需在系统预览中重新启用。桌面不转发触摸和强制停止不保证回调的情况需实机验收。

监听按钮同时显示权威模式文字和选中态。需求层级 L5（前后台与交互流程）、L6（原生桥与配置契约），下放为壁纸状态、偏好、事件与坐标转换。主要风险是 Android 桌面触摸事件及任务移除回调受系统和桌面实现影响；不得声称所有设备均可用。

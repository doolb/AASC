# 显示端壁纸控件与监听状态

2026-11-12：镜头跟随改为手机平移产生的短时视差，角色倾斜仍使用姿态。镜头统一使用浏览器 devicemotion 的线性加速度，不增加 Android 平移传感器桥；长时间收不到有效数据时提示检查传感器与页面权限。按屏幕方向转换，积分速度并阻尼，每帧以真实时间衰减镜头偏移并限幅；停用或隐藏清空状态。WebView 壁纸是否提供事件以及无视觉定位的漂移、旋转噪声需真机验收。

SM-N9500（Android 9）Offline v95 主屏壁纸的实际 WebView 在 HTTPS 页面上 5 秒收到 38 个 devicemotion，线性加速度均有效；该结果只证明本机事件可用，不代表其他设备或实际位移精度。Offline v74 已保留数据更新到已发布 v95，主屏幕已设为 AASC 壁纸，锁屏未更改。

普通显示和壁纸共享全息设置：壁纸控制面板提供角色和镜头两个默认关闭的独立开关。角色按手机倾斜轻微转动；镜头依据手机线性运动沿画面上下左右短时平移并逐帧回中，不改变原有朝向与距离。位移受限并平滑处理，隐藏或关闭时恢复原位。无传感器时提示不可用；AR 或镜头动画按现有优先级处理。

2026-11-11：壁纸识别文字显示在网页原有识别区域，不放入系统浮窗；浮窗状态去掉名称与状态之间的分隔点。

2026-11-11：浮窗仅在桌面展示；无障碍可用时识别默认桌面，未授权时退回壁纸可见回调。适配 1080×2309、480 dpi、300% 缩放的尺寸与文字；修复壁纸语音操作，允许已授权的壁纸音频采集，不开放后台摄像头。普通页面保留网页语音控件。

2026-11-11：普通显示页保留网页设置面板和壁纸预览入口。壁纸模式使用独立 Android 语音悬浮窗，显示语音状态、大圆、监听模式小圆点和语音活动，随显示页主题和语音权威状态更新；贴边 5 秒无操作后收起，点击把手展开。浮窗需系统授权，仅真实桌面壁纸可见时展示；受系统窗口层级限制。

壁纸使用共享显示页并隐藏前台交互按钮，普通页面与壁纸分别使用网页面板和系统浮窗；旧版 APK 未提供系统浮窗时继续显示原壁纸网页面板。面板提供系统媒体音量、状态、FPS 和时间开关。壁纸时间按物理状态栏实际重叠避让。壁纸与前台切换需即时同步页面状态。用户关闭应用且收到关闭回调时暂停渲染，并仅在当前桌面壁纸仍为 AASC 时恢复系统默认壁纸，保留锁屏壁纸；再次使用需在系统预览中重新启用。桌面不转发触摸和强制停止不保证回调的情况需实机验收。

网页浮动面板位于网页普通内容的最上层；增加默认开启、保存在本机的壁纸内容交互开关。关闭时阻止面板以外的触摸、指针和鼠标交互进入壁纸内容，面板自身始终可用。系统桌面仍决定是否将触摸事件送达壁纸，系统窗口与浏览器顶层元素不由网页层级控制。

监听圆点以颜色、选中态和无障碍描述反映权威模式。需求层级 L5（前后台与交互流程）、L6（原生桥与配置契约），下放为壁纸状态、偏好、事件与坐标转换。主要风险是 Android 桌面触摸事件及任务移除回调受系统和桌面实现影响；不得声称所有设备均可用。

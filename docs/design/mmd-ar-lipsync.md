# 独立 MMD-AR 文字口型预览

## 需求与范围

2026-10-10 用户要求在mmd-ar动作面板加入「口型」分类，输入文本后点击播放口型。默认先实现无声音的文本口型预览，不调用LLM/TTS、麦克风或服务器，不改正式端面板。

## 方案

- 文本输入、播放口型和停止；显示播放进度/当前音节。按当前PMX自动匹配あ/い/う/え/お及常见A/I/U/E/O别名，可在嘴型映射中手动选择，支持尾随空格真实名称。
- 首次播放按需加载同源pinyin-pro 3.29.5，用上下文中文拼音转为近似口型，按约每字250ms估算节奏，逗号/句号停顿闭嘴；拉丁字母仅按拼写元音近似，不宣称英语音素同步。没有声音时间数据，不能称为精确TTS同步。
- 五种元音曲线平滑过渡，b/p/m闭唇辅音先闭合，结束与停止释放临时覆盖，恢复VMD和手动表情。用户仍可播放默认/VMD/MPL动作，口型不替换动作、不重置物理。用户进一步明确口型必须能和动作同时播放，采用独立临时层满足此要求。
- 使用独立构建副本的临时表情层：与手动表情相同的逐帧恢复/动画后/物理前应用机制，临时口型只覆盖映射的Morph，不修改手动选择；换模型/物理重载清理并停止，过期token不写新模型。
- 未支持/无嘴型PMX禁用播放并提示；可通过手工映射适配不采用MMD常见名称的模型。缺失某元音回退可用嘴型并明确提示。
- 编译器与正式迁移已存在的未提交改动保持。本轮新增逻辑仅3rd独立网页及生成副本，Offline状态不新增影响；资源本地缓存/固定大小SHA校验/附MIT许可证与来源清单，无npm生产依赖。

# 聊天系统重构设计文档

## 概述

重构现有的聊天系统，支持群聊和私聊模式，统一管理所有角色（系统、AI助手、显示端、控制端）的聊天记录，并整合语音播报和搜索功能。

## 系统架构

### 角色定义

| 角色 | 标识格式 | 说明 |
|------|----------|------|
| 系统 | `系统` | 系统消息、指令响应 |
| AI助手 | `{助手名字}` | 各个AI聊天助手 |
| 显示端 | `{显示端名字, IP}` | 显示端语音输入 |
| 控制端 | `{控制端名字, IP}` | 控制端语音/文本输入 |

### 聊天模式

1. **群聊模式**（默认）
   - 所有消息广播给所有参与者
   - 系统和AI助手根据规则响应
   - 语音播报在显示端播放

2. **私聊模式**
   - 只与指定的AI助手通信
   - 发起：`私聊{助手名字}`
   - 退出：`退出私聊` 或切换私聊对象

### 消息格式

```
{角色}: {消息内容}
```

示例：
```
系统: 早上好！今天天气晴朗
小爱: 你好！有什么可以帮助你的吗？
显示端(客厅, 192.168.1.100): 今天天气怎么样
控制端(手机, 192.168.1.50): 播放音乐
```

## 功能设计

### 1. 系统指令

系统指令用于处理特定关键词触发的组合操作。

#### 内置指令

| 指令 | 说明 | 实现状态 |
|------|------|----------|
| `系统帮助` | 显示所有可用指令 | 已实现 |
| `私聊{助手名字}` | 进入私聊模式 | 已实现 |
| `退出私聊` | 退出私聊模式 | 已实现 |
| `提醒{时间} {内容}` | 设置提醒 | 已实现 |
| `每天/每周/每月/每年提醒{时间} {内容}` | 设置重复提醒 | 已实现 |
| `报时` / `现在几点` | 播报当前时间 | 已实现 |
| `开启报时` | 开启整点报时功能 | 已实现 |
| `关闭报时` | 关闭整点报时功能 | 已实现 |
| `搜索{关键词}` | 搜索信息 | 已实现 |
| `拒绝` / `取消` | 取消待确认操作 | 已实现 |
| `{助手名字}{消息}` | 与指定助手对话 | 已实现 |

#### 指令处理流程

```
用户输入
    ↓
handleSystemCommand() 检查系统指令
    ├─ 系统帮助 → 返回帮助文本
    ├─ 私聊{名字} → 切换私聊模式
    ├─ 退出私聊 → 切换群聊模式
    └─ 自定义指令 → executeCommands()
    ↓
processVoiceCommand() 处理其他命令
    ├─ 拒绝/取消 → handleCancelCommand()
    ├─ 提醒 → handleReminderCommand()
    ├─ 报时 → handleTimeAnnounceCommand()
    ├─ 搜索 → handleSearchCommand()
    ├─ 助手名字 → 返回聊天请求
    └─ 其他 → 返回默认聊天
```

#### 自定义指令配置

在控制端配置指令组合：

```json
{
  "commands": {
    "早上好": ["今天天气", "今日提醒", "搜索1", "搜索2"],
    "晚安": ["关闭所有媒体", "设置明天闹钟"]
  }
}
```

当用户说"早上好"时，系统依次执行配置的指令。

### 2. 语音播报增强

#### 播报规则
- **所有聊天消息都要进行语音播报**
- 根据当前选择决定播报到哪个设备
- 播报内容包括：系统消息、AI助手回复、用户消息确认等

#### 显示端播报（默认）
- 所有语音播报在显示端播放
- 同时显示文本内容
- 需要选择显示端才能播报

#### 控制端播报
- 当没有显示端连接时，在控制端播放
- 当勾选"在控制端播放语音"选项时，在控制端播放
- 使用 Web Speech API 或 Audio 播放

#### 播报流程
```
聊天消息生成
    ↓
检查播报目标
    ├─ playOnControl = true → 控制端播放
    ├─ displayId 存在 → 显示端播放
    └─ 无显示端 → 控制端播放
    ↓
生成 TTS 音频
    ↓
发送到目标设备播放
```

### 3. 聊天记录存储

所有聊天记录保存到文件，格式：

```json
{
  "id": "唯一标识",
  "timestamp": 1234567890,
  "role": "角色类型",
  "name": "名字",
  "ip": "IP地址（可选）",
  "content": "消息内容",
  "mode": "group/private",
  "target": "私聊对象（可选）"
}
```

### 4. 搜索功能整合

移除独立的搜索页面，将搜索功能整合到聊天系统：
- 搜索指令：`搜索{关键词}`
- 搜索结果显示在聊天记录中
- 搜索历史作为聊天记录的一部分

## 数据结构

### 聊天记录

```javascript
{
  id: string,           // 唯一标识
  timestamp: number,    // 时间戳
  role: 'system' | 'assistant' | 'display' | 'control',
  name: string,         // 名字
  ip: string,           // IP地址（显示端/控制端）
  content: string,      // 消息内容
  mode: 'group' | 'private',
  target: string,       // 私聊对象（私聊模式）
  displayId: string     // 关联的显示端ID
}
```

### 会话状态

```javascript
{
  mode: 'group' | 'private',
  privateTarget: string,    // 当前私聊对象
  playOnControl: boolean,   // 是否在控制端播放语音
  commands: {               // 自定义指令
    "关键词": ["指令1", "指令2"]
  }
}
```

### AI助手配置

```javascript
{
  defaultName: string,
  assistants: [{
    id: string,
    name: string,
    template: string,
    enabled: boolean
  }]
}
```

## 消息流程

### 群聊模式流程

```
用户输入 -> 解析指令 -> 
  如果是系统指令:
    系统处理 -> 生成系统消息 -> 广播
  如果是搜索:
    执行搜索 -> 生成结果消息 -> 广播
  如果是聊天:
    AI助手响应 -> 生成助手消息 -> 广播
    -> 语音播报
```

### 私聊模式流程

```
用户输入 -> 
  如果是"退出私聊":
    退出私聊模式 -> 生成系统消息
  否则:
    发送给指定AI助手 -> 生成助手消息
```

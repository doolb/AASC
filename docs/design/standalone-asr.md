# 独立语音识别项目

将 ASR 测试 APK 和浏览器测试页独立复制到 `/mnt/asr`，自行提供 SenseVoice INT8 模型和词表。两端采用明亮日光主题、底部圆形按钮和音量阈值 VAD：点击开始监听，语音达到最短时长后静音自动识别，点击停止监听。支持本地 WAV 识别；不提供声纹、流式识别和降噪。原 AASC 组件保留。

实现现状：独立源码及模型已复制，网页识别和 VAD 单元验证通过；Android 调试 APK 已生成并通过签名校验，实机麦克风待验收。识别期间暂停采集新片段，WAV 限制 60 秒。

网页采用相对入口的 `../aimodel/sensevoice/` 模型目录；本地预览提供 `/mnt/asr/` 和 `/mnt/aimodel/sensevoice/` 与线上一致的结构，发布时复用线上模型，不重复上传。

网页预先下载并初始化 SenseVoice；加载前及失败时禁用录音，显示进度与重试。圆按钮内展示实时 RMS 音量及红色阈值，旁边显示等待语音、有效语音时长、静音截止倒计时及触发结果；识别与分段仍使用原有 0.01、300ms、500ms 和 59 秒限制。

SenseVoice 模型与词表使用普通 HTTP 缓存，不启用 IndexedDB。响应携带 `Cache-Control: public, max-age=0, must-revalidate` 和服务器验证器；浏览器可在重新验证后以 304 复用副本。网页模型仍需每次载入内存并初始化，缓存容量与保留由浏览器决定。本地预览对两个文件提供同等条件请求。

Android APK 与网页同步音量可视化：圆形录音按钮内显示实时 RMS 填充和红色阈值，显示说话时长、静音截止倒计时和截止原因；保持本地 0.01 阈值、300ms 最短语音、500ms 静音和 59s 上限。模型未就绪时禁用录音及文件输入，失败可重试；模型内置 APK，无需网页 HTTP 缓存。

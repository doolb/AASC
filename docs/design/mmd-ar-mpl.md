# 独立 MMD-AR：MPL 动作输入

## 需求与范围

用户已确认在独立 mmd-ar 网页测试粘贴 LLM 生成的 MPL。网页只消费已有代码，不调用 LLM。支持姿势、时间线、编译播放、下载 VMD、停止并恢复进入 MPL 前的动作。

## 设计

- 动作面板新增「MPL 动作」分类，提供动态点头＋表情示例、纯表情示例和多行输入。时间单位为秒，角度为度；采用 MMD-MPL 原语法。
- 固定 MMD-MPL 0.3.6，上游提交 `2d3b1c7e3429b508443500801e94c41fd47c9f31`。构建缓存与生成网页分别保存编译器，记录大小/SHA-256并附带 GPL-3.0 许可证和源码链接。
- 页面首次打开不加载编译器；点击编译播放才创建 module Worker，在独立线程加载本地 WASM。限制输入/输出大小、编译时间，报错不替换当前动作。
- 输出 VMD 经已有本地资源注册表交给 `DisplayMmd.loadSelectedMotion`，沿用动画切换、IK、物理初始化和回滚。MPL 替换当前 VMD，未指定的骨骼使用绑定姿态，不与原动作叠加；播放方式沿用当前模型。
- 纯姿势输出补一份第30帧的相同骨骼帧，形成1秒静态保持，避免Three循环零时长动作产生无效时间。
- 保存原动作地址/资源 ID/播放开关。只有同一模型仍在播放本次 MPL 时才恢复；切换模型或其他动作后不覆盖新选择。异步编译完成时校验模型及动作版本，避免迟到结果替换新选择。
- 新生成资源在被当前模型引用时保留，切换/恢复后释放；下载只使用内存字节。刷新不自动播放，也不保存 MPL 输入。

## 边界

2026-10-10读取当前米娅（椛暗式-米娅 ver2.0）PMX：包含29个顶点Morph，分为12个嘴型、11个眼部、6个眉部。可用于表情扩展，例如嘴角 `口角上げ`、笑眼 `笑い`、微笑眉 `にこり`；MPL表情扩展读取这些真实名称并生成Morph帧。名称须保留原始字符，包括 `い ` 的尾随空格和 `ｳｨﾝｸ２右` 的半角字符。

支持PMX；骨骼动作需要标准日文 MMD 骨骼，纯表情无需标准骨骼。部分骨骼缺失明确提示，骨骼和表情都完全不匹配才拒绝播放。仅独立网页构建接入，正式包及独立 APK 不包含此实验。编译器不执行 JS，也不下载用户代码指定的外部资源。上游 VMD 包含自己的 IK 标志，沿用现有加载器的处理；不是新的语音同步协议。

## 表情接入（2026-10-10，用户确认后已实施）

用户已确认接入表情。在 `@pose` 中扩展 `morph "PMX原始表情名" 0.8;`，权重0–1、0为该时间点零权重；姿势仍通过原 `@animation` 时间线引用，可同时定义骨骼与多个表情。

复用通用表情面板读取的模型Morph metadata校验名称/支持类型，不硬编码米娅。Worker先提取表情语句，再把剩余骨骼MPL交给固定WASM；按同一时间线生成表情帧并写入VMD Morph区段。骨骼与表情在同一个VMD中播放/下载/恢复，允许纯表情脚本。

手动面板选择仍优先于同名MPL/VMD表情，取消手动选择后显示时间线表情。名称按原始值校验；未知/不支持/重名歧义报错。VMD名称使用Shift-JIS、最多15字节，不能编码或超长名称须明确报错，不截断到其他名称。默认补0秒零权重；姿势未指定的受控表情沿用上个关键帧权重，每个关键帧补齐；若需回到无表情须显式写0。采用现有播放器的线性表情插值。

动作面板原点头示例已替换为「填入动作＋表情示例」，保留「填入表情示例」：按当前模型嘴型/眼睛/眉毛分类各选一个可编码、名称唯一且支持播放的Morph，生成0→0.7→0时间线。不预设米娅名称。状态显示两类关键帧和匹配数量；若手动选择覆盖本次Morph则提示取消选择。骨骼/表情零时长姿势均补成1秒保持；语法及名称错误不替换原动作。

编码复用实际Three MMDParser的Shift-JIS表反向映射，无新增生产依赖；加载器保留名称及控制字符也明确拒绝。声明支持开括号同行或下一行，送入WASM前规范化并保持原始行号。构建先复制Three vendor，再生成Morph/Worker/UI/入口依赖指纹，保持子目录部署缓存更新。

默认打开时等待PMX加载就绪，自动填入一次点头+表情；用户输入、粘贴或主动选择示例后不再自动覆盖。动作示例与纯表情示例共用动态名称筛选；动作示例含head reset/bend forward 20和0→0.7→0的Morph，时间0/0.5/1.5秒。没有可写入VMD的Morph时动作示例退为点头并提示原因。异步填入有模型/输入/请求序号保护。

# 独立 MMD-AR：MPL 动作输入

## 需求与范围

用户已确认在独立 mmd-ar 网页测试粘贴 LLM 生成的 MPL。网页只消费已有代码，不调用 LLM。支持姿势、时间线、编译播放、下载 VMD、停止并恢复进入 MPL 前的动作。

## 设计

- 动作面板新增「MPL 动作」分类，提供点头示例和多行输入。时间单位为秒，角度为度；采用 MMD-MPL 原语法。
- 固定 MMD-MPL 0.3.6，上游提交 `2d3b1c7e3429b508443500801e94c41fd47c9f31`。构建缓存与生成网页分别保存编译器，记录大小/SHA-256并附带 GPL-3.0 许可证和源码链接。
- 页面首次打开不加载编译器；点击编译播放才创建 module Worker，在独立线程加载本地 WASM。限制输入/输出大小、编译时间，报错不替换当前动作。
- 输出 VMD 经已有本地资源注册表交给 `DisplayMmd.loadSelectedMotion`，沿用动画切换、IK、物理初始化和回滚。MPL 替换当前 VMD，未指定的骨骼使用绑定姿态，不与原动作叠加；播放方式沿用当前模型。
- 纯姿势输出补一份第30帧的相同骨骼帧，形成1秒静态保持，避免Three循环零时长动作产生无效时间。
- 保存原动作地址/资源 ID/播放开关。只有同一模型仍在播放本次 MPL 时才恢复；切换模型或其他动作后不覆盖新选择。异步编译完成时校验模型及动作版本，避免迟到结果替换新选择。
- 新生成资源在被当前模型引用时保留，切换/恢复后释放；下载只使用内存字节。刷新不自动播放，也不保存 MPL 输入。

## 边界

2026-10-10读取当前米娅（椛暗式-米娅 ver2.0）PMX：包含29个顶点Morph，分为12个嘴型、11个眼部、6个眉部。可用于表情扩展，例如嘴角 `口角上げ`、笑眼 `笑い`、微笑眉 `にこり`；当前MPL尚不生成Morph帧。名称须保留原始字符，包括 `い ` 的尾随空格和 `ｳｨﾝｸ２右` 的半角字符。

只支持带标准日文 MMD 骨骼的 PMX；部分骨骼缺失明确提示，完全不匹配拒绝播放。仅独立网页构建接入，正式包及独立 APK 不包含此实验。编译器不执行 JS，也不下载用户代码指定的外部资源。上游 VMD 包含自己的 IK 标志，沿用现有加载器的处理；不是新的语音同步协议。

## 验收

本轮完成实现与 web-dist 构建，并发布外网；9项资源HTTP大小/SHA-256校验通过。实际浏览器点头、恢复动作、模型切换、物理和移动端表现待验收。本轮未执行自动测试。

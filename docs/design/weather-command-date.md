# 天气识别日期设计

## 需求

天气语音命令支持“今天的天气”“明天天气”“后天天气”“成都明天天气”和“后天成都天气”。日期识别在服务端完成，城市解析继续使用现有城市列表和默认城市逻辑。

## 日期规则

- `今天`、`今日` 对应偏移 0，选择天气接口返回的第一天，并保留该日逐时预报。
- `明天`、`明日` 对应偏移 1，只返回目标日期的逐日预报。
- `后天`、`后日` 对应偏移 2，只返回目标日期的逐日预报。
- 不包含日期词时保持现有当前天气、未来多日概览和今日逐时详情行为。
- 服务端使用本地日期计算目标日期，不使用客户端日期。
- 城市解析自动剔除日期词，支持日期在城市前后的语序。
- 目标日期不在接口数据中时播报“暂无该日期天气预报”。

## 输出范围

- 无日期：保持现有 `formatWeatherDetail()` 和 `formatWeatherSpeech()` 行为。
- 今天：完整详情保留当前天气、目标日逐日信息、天文信息和逐时信息；语音保持简短摘要。
- 明天/后天：详情和语音只包含目标日期的逐日信息，不包含当前天气、其他日期和逐时明细。

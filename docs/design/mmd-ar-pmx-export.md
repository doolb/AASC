# MMD-AR PMX 文件导出

用户确认网页直接读写PMX。当前读取继续复用已有本地PMX/贴图选择及MMDLoader；编辑器增加“导出 PMX”，将刚体/关节的参数、增删、复制与镜像结果写入新PMX文件。浏览器通过下载保存，无需Blender、服务器转换或目录写权限。

使用原文件字节扫描和段落重写，而非从渲染网格重建整个模型，保留顶点、SDEF/QDEF、材质、骨架、表情、显示框、PMX2.1软体等未编辑数据。记录加载器处理后的基线，用于识别实际修改，避免把显示坐标或加载器修正的刚体类型误写入原文件。删改刚体时同步冲量表情与软体锚点引用；索引宽度不足时扩展所有相关字段。

导出的PMX使用原编码、贴图相对路径和模型信息。贴图仍需和新PMX放在原相对位置，灯光、动作、求解器等网页场景设置保存在既有工程ZIP。本次不增加顶点、骨骼、材质、Morph编辑控件。旧工程如缺少可靠来源映射则拒绝含糊导出，避免把其他刚体的引用对应到错误对象。

2026-10-09已实现上述导出流程，并生成本地web-dist。7项针对性回归和5个真实模型往返检查通过；浏览器在启动阶段退出，下载交互、PMX Editor交叉打开及移动端保存体验待验收。当前读取器的版本/编码/特性支持范围沿用原MMDLoader；导出器对未编辑数据的字节保留不代表渲染器能显示全部PMX特性。

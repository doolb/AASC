# 控制端主导航响应式布局设计

## 需求

控制端横屏时主导航固定在页面左侧并纵向排列；竖屏时主导航固定在页面底部并横向排列。导航项较多时只允许导航栏沿当前排列方向滚动，主内容区不得被导航覆盖。

## 设计

- 根据视口方向切换导航位置：横屏使用左侧栏，竖屏使用底部栏。
- 竖屏隐藏仅用于左侧布局的导航标题，导航项横向排列并可横向拖动滚动。
- 竖屏主内容清除左边距，并为底部导航和设备安全区留出空间；横屏保留左侧导航边距。
- 方向切换不影响当前面板、导航激活项或最后打开面板的持久化。

## 验收标准

1. 竖屏时主导航在底部，图标与文字可读，导航项可点击且可横向滚动。
2. 竖屏时底部导航不遮挡页面内容，安全区设备上导航不覆盖系统手势区域。
3. 横屏时导航仍固定在左侧并可纵向滚动。
4. 横竖屏切换后当前页面与激活导航项保持不变。

## 右侧三个浮动入口避让（2026-10-10，已确认）

竖屏底部导航高度68px加安全区，floating-control仍固定bottom20px，自测入口固定bottom80px；录音按钮相对floating-control上移120px，整体没有增加导航偏移。拟在portrait样式中让浮动容器和自测入口统一加导航高度及安全区，保持原间距；浏览器验证三按钮和底部导航不相交，横屏原位置保持。

# 显示端状态栏独立开关设计

## 需求

控制端可为每台显示端独立选择是否显示状态栏。默认显示；关闭后隐藏连接状态、语音/摄像头状态、音频监视器及会话倒计时。时间、媒体文件名、语音识别/播报正文和模型任务进度不受开关影响。

控制端竖屏时继续使用固定在左侧的纵向导航。当前页面样式已经满足该布局，本次不改变导航位置。

## 设计

- 在控制端树形和列表两种视图的每台显示端设备行中增加“显示状态栏”复选框。
- 状态以 `showStatusBar` 保存到现有 `displayStates[displayId]`，缺省值为 `true`。
- 控制端通过 WebSocket 发送带 `type`、`displayId` 和布尔值的设置消息；服务端校验后调用现有显示端状态持久化方法，向目标显示端和所有控制端广播权威值。
- 显示端连接初始化时接收自己的配置；未收到配置时保持默认显示，重连后采用服务端持久化值。
- 显示端仅隐藏状态提示节点，不隐藏时间、文件名、语音正文和任务进度；使用可见性样式保留旋转布局测量所需的节点尺寸。
- 不新增配置 HTTP 接口。旧配置中缺少字段时按默认显示处理；旧显示端忽略新增 WebSocket 消息并继续显示状态栏。

## 验收标准

1. 同一控制端能分别关闭/开启不同显示端的状态栏。
2. 刷新控制端、刷新或重连显示端后，各设备仍保持各自设置。
3. 关闭时连接、语音/摄像头提示、音频监视器和会话倒计时不可见；时间、文件名、语音正文和模型任务进度仍可见。
4. 旧配置无 `showStatusBar` 时状态栏默认可见。
5. 控制端在竖屏和横屏下均保持左侧纵向导航。


自测入口位于服务器面板的当前服务器操作区，避免悬浮按钮遮挡控制界面。

代理与媒体用户配置迁移通过隔离配置回归验证，覆盖迁移、冲突、写入失败及重启，不读取真实用户凭据。

壁纸控件新增只读结构自测，验证显示页面板及壁纸专用样式存在；壁纸关闭自测检查组件保护、桌面专用恢复与关闭回调。桌面触摸、旋转与任务关闭效果仍需真机检查。

壁纸内容交互自测覆盖面板层级、开关的事件拦截和本地偏好、关闭交互时面板拖动，以及回到前台后恢复交互。

系统浮窗与普通面板的切换自测覆盖权限声明、生命周期清理和页面偏好同步；语音小圆点与媒体库覆盖关系使用浏览器验证，真实桌面浮窗需要设备验收。

壁纸语音浮窗自测覆盖语音操作桥、权威模式、主题色以及贴边计时清理；真实系统浮窗和收起交互需设备验收。

B 站弹幕旋转和相关推荐增加只读资源结构检查；实播表现通过浏览器测试及设备验收确认。

分享移动文件夹增加弹窗结构只读检查，选择及错误处理由浏览器测试覆盖。

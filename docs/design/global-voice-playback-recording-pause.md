# 全局播放时暂停录音开关设计

## 需求

在控制端“声纹管理”面板增加全局配置“播放时暂停录音”。默认值为 `true`，由服务端保存并广播给全部显示端。

## 行为

- `true`：显示端播放本机或其他显示端的 TTS 时暂停普通 ASR 录音，播放结束后恢复。
- `false`：显示端播放期间继续普通 ASR 录音，不执行暂停和恢复。
- 单次录音、实时录音以及控制端聊天录音不受该配置影响。
- 配置归属于全局 `voiceprint` 设置，即时修改后广播到所有在线显示端，新连接显示端在连接初始化时获得当前值。
- `true` 的语义不依赖声纹是否启用；启用声纹时也按配置暂停或继续。

## 边界

- 仅改变 TTS 与普通 ASR 录音的协调，不改变声纹匹配、ASR 文本和 TTS 路由。
- 播放期间如果切换为 `false`，当前暂停状态立即恢复普通 ASR；切换为 `true` 后，仅对后续播放事件执行暂停。
- 控制端已有的聊天输入“播放时暂停监听”继续独立工作。

## 受影响模块

- `server-app.js`：全局配置 GET/POST、持久化、在线显示端广播和连接初始化。
- `upload.html`、`voiceprint-panel.js`：声纹面板开关、读取和保存。
- `display.html`：消费配置并控制 TTS 播放时普通 ASR 的暂停/恢复。

# 显示端右侧设置面板互斥设计

## 需求

显示端右侧“主题、音色、灯光、动作、定位”五个顶层按钮对应的面板会互相叠盖。用户打开另一面板时，已打开的面板应自动关闭；再次点击当前按钮仍可手动收起。

## 设计

在右侧按钮列统一监听顶层入口点击的捕获阶段。入口原有打开逻辑运行前，协调器调用其他已展开面板各自的关闭方法，再同步 `hidden` 和 `aria-expanded`。模块关闭方法保留自身清理：音色取消定位中的目录请求，动作停止进度定时器；灯光和定位沿用原有关闭行为。协调器只识别直属顶层按钮，不干扰面板内的分类展开、颜色弹层、聊天和角色按钮。若某模块尚未初始化，DOM 状态仍能关闭旧面板。

## 验收

1. 五个顶层面板任意顺序切换，始终最多一个可见；再次点击当前按钮可关闭。
2. 音色关闭不留下正在定位的状态；动作关闭停止进度计时；`aria-expanded` 与可见状态一致。
3. 面板内子分类和 Android 颜色弹层操作不触发顶层互斥；PC 与 Android 行为一致。

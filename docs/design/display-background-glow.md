# 显示端背景光晕设计

## 需求

显示端媒体之外的底色从纯黑改为 MMD-AR 风格的中心亮、向外过渡的中性深色光晕。控制端在“系统设置 → 界面主题”提供全局共享的中心亮度和扩散范围参数，所有显示端使用同一组设置。

参数默认值沿用 MMD-AR 当前外观：中心亮度 100%，扩散范围 58%；亮度范围为 0–100%，扩散范围为 25–90%。默认渐变使用 `#303442`、`#171920`、`#101116` 三个色阶，中心位于画布水平中心、垂直 42% 位置。

媒体图像/视频本身不受背景影响，只有媒体未覆盖的空白区域透出光晕。睡眠遮罩保持现有黑色。控制端在竖屏时将主导航固定在页面底部并横向排列，横屏时继续固定在左侧；内容区留出导航空间。

## 设计

- 在“系统设置 → 界面主题”增加中心亮度和扩散范围两个滑块，并显示当前百分比。
- 参数保存在服务端 `ui.displayBackgroundGlow`，通过带 `type` 的 WebSocket 消息提交；服务端规范化并持久化后，将权威值广播到控制端和所有在线显示端。
- 控制端和显示端连接初始化时接收当前权威配置。离线或配置缺失时使用本地默认值；重连后以服务端配置覆盖。
- 显示端把配置映射到媒体画布背景渐变的 CSS 自定义属性；不新增 HTTP 配置接口。
- 状态栏开关继续按 `displayId` 独立保存，但从设备树/列表行移至 VAD 面板内当前显示端的卡片。

## 验收标准

1. 控制端主题设置页显示亮度与扩散范围，拖动时立即预览，提交后服务端保存规范化值。
2. 调整后所有在线显示端同步变化；新连接或重连显示端恢复服务端保存值。
3. 媒体画面本身不被染色，媒体边缘空白显示中心亮、向外过渡的底色；睡眠遮罩仍为黑色。
4. 两台显示端状态栏开关可分别设置，开关只出现在 VAD 面板的当前显示端卡片。
5. 控制端竖屏时主导航位于底部并横向排列，内容区不被遮挡；横屏时导航仍在左侧。

## 边界与兼容

- 缺少配置、断线或服务端尚未发送配置时，显示端使用 MMD-AR 风格默认渐变。
- 新消息使用独立 `type`，旧显示端忽略未知消息并继续使用原来的纯黑背景。
- 背景参数为全局共享；状态栏开关仍按显示端独立配置。

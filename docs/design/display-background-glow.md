# 显示端背景光晕设计

## 需求

显示端媒体画布底色使用中心亮、向外过渡的背景光晕。光晕位于媒体元素下方，媒体图片/视频保持原样并覆盖底色；媒体未覆盖的画布区域显示光晕，睡眠遮罩继续保持纯黑。

控制端“系统设置 → 界面主题”提供全局共享的中心颜色、中心亮度范围和扩散范围，所有显示端使用同一组设置。中心亮度范围表示所选颜色保持完整、不与外层颜色混合的范围，不表示透明度或 alpha。

默认参数为中心颜色 `#8FA8D5`、中心亮度范围 10%、扩散范围 58%。中心亮度范围允许 0–20%，扩散范围允许 25–90%，保证中心完整范围位于扩散过渡范围以内。渐变中心位于画布水平 50%、垂直 42%；中心范围以外逐渐混合到中间色，并在扩散范围之后向 `#101116` 过渡。

## 设计

- 在“系统设置 → 界面主题”提供颜色选择器、中心亮度范围滑块和扩散范围滑块，并显示颜色/百分比及实时预览。
- 中心亮度范围滑块仅改变中心颜色保持完整的空间范围，不改变颜色透明度；扩散范围控制中心色向外围底色过渡的距离。
- 配置保存在服务端 `ui.displayBackgroundGlow`，结构为 `{ color, centerRange, spread }`，通过带 `type` 的 AASC WebSocket 消息提交；服务端校验、规范化并持久化后，将权威值广播到控制端和所有在线显示端。
- 控制端和显示端连接初始化时接收当前权威配置。离线或配置缺失时使用本地默认值；重连后以服务端配置覆盖。
- 显示端使用 CSS 自定义属性更新媒体画布底色，不新增 HTTP 配置接口，不调整媒体层级和媒体节点的像素内容。
- 状态栏开关继续按 `displayId` 独立保存，但从设备树/列表行移至 VAD 面板内当前显示端的卡片。

## 验收标准

1. 控制端主题设置页显示中心颜色、中心亮度范围和扩散范围，拖动/选色时立即预览，提交后服务端保存规范化值。
2. 中心亮度范围内的渐变颜色与选择器颜色完全一致；调节该滑块改变纯色中心区域半径，不改变 alpha。
3. 调整后所有在线显示端同步变化；新连接或重连显示端恢复服务端保存值。
4. 媒体画面本身不被染色，媒体未覆盖区域显示所选中心色向外过渡的底色；睡眠遮罩仍为黑色。
5. 横屏时右上角灯光/动作/定位按钮列与时间显示不重叠；竖屏时按钮列现有顶部间距和时间四角布局保持不变。
6. 两台显示端状态栏开关可分别设置，开关只出现在 VAD 面板的当前显示端卡片。
7. 控制端竖屏时主导航位于底部并横向排列，内容区不被遮挡；横屏时导航仍在左侧。

## 边界与兼容

- 缺少配置、断线或服务端尚未发送配置时，显示端使用中心色 `#8FA8D5`、中心范围 10%、扩散范围 58% 的本地默认渐变。
- 存量配置中的 `brightness` 字段不再映射到颜色透明度；新规范化配置只包含 `color`、`centerRange`、`spread`，缺失字段回退到明确默认值。
- 无效颜色作为配置错误拒绝；颜色规范化为 `#RRGGBB` 大写格式，数值按允许范围取整并限制。
- 新消息使用独立 `type`，旧显示端忽略未知消息并继续使用原来的背景。
- 背景参数为全局共享；状态栏开关仍按显示端独立配置。

# Retop 肩甲经纬走线

目标：参考用户提供的高、低模和标注图，调整低模包边及主体经纬走线，使相交方向在曲面局部尽量垂直，并保持轮廓、分区和源模型。

先检查最终曲面及实际网格，而非仅检查中间控制点；结合参考模型验证形状、角度、连续性及导出。复杂角点、固定边界和稀疏拓扑可能限制完全正交，须报告实际结果。

现状：工程内肩甲环带在最终曲面采样的角度误差 P90 约 12.6°、最大约 31.2°；旧统计发生在整线平顺之前。已有整人物高模处理流程：256 MiB 导入，复杂雕刻网格生成工作副本并在 CSI 不支持时回退至特征保留混合低模。历史文档记录实际使用用户提供的高模完成生成，低模用于效果参考；目前尚未确认同时导入及自动配准两个文件的功能。需复用现有整人物流程及参考数据进一步验证肩甲走线。

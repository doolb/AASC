# 独立 MMD-AR 手动表情面板

## 用户需求

2026-10-10用户要求先在动作面板新增表情分类，可以手动点击米娅的表情。此阶段不扩展MPL语法、不生成表情动作文件。

## 已确定方案

- 用户进一步确认必须通用、自动读取PMX。独立网页「动作 → 表情」按PMX面板类别分眉毛、眼睛、嘴型、其他；直接显示原始Morph名及模型提供的英文名，不硬编码米娅清单。
- 表情按钮点击启用/取消，允许多项叠加；每项0–1强度滑条独立调节，拖动自动启用该项；「清除手动表情」恢复VMD自身表情。
- 米娅29项全部为顶点Morph，可以直接驱动。其他PMX动态读取，顶点及只包含顶点的组合Morph可用；加载器未实现的骨骼/UV/材质Morph不提供有效控制。
- 动画更新后应用手动覆盖，未选择项目继续使用VMD。保存覆盖前值，逐帧还原后让动画更新；取消时还原当前VMD值而不是永久将权重锁0。
- 物理回调中提前应用，使顶点布料读取相同Morph；无物理/暂停时在帧末补应用。只包装当前helper实例自己的回调，不修改Three原型。
- 换VMD保留手动选择；同模型物理重载保留，换模型清空；刷新不自动恢复。不改PMX文件、工程存档或正式包。

## 实现状态

实现完成：通用PMX metadata、按钮/独立滑条、逐帧覆盖与清除、模型切换保护已接入；`npm run build:web:mmd-ar-test` 成功，源模块/生成入口及Loader语法检查、差异空白检查通过。运行效果待浏览器验收，未新增或执行测试；2026-10-10已发布外网，6项资源HTTP大小/SHA-256校验通过。

## 2026-10-10正式端迁移

首版仅独立网页的范围已扩展：控制器/UI迁为正式 `mmd-expressions.mjs` / `mmd-expressions-ui.mjs`，Loader简表和runtime/API在正式源码中实现，独立构建共用并避免重复注入。正式面板和TTS后续边界见 `mmd-display-expressions.md`，本轮不自动驱动TTS口型。

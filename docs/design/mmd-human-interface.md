### PBD 全身 IK 约束求解（2026-10-13，已实现并通过本地验证）

参考 UE5 FullBodyIK 的 PBD/NPGS 约束求解思路，把当前活动末端与共享祖先骨骼视为一个约束图。每个末端的位置误差按各祖先旋转对该末端的杠杆影响和骨段逆转动权重分配，并在固定次数的顺序投影中反复处理多个活动目标；每轮限制旋转增量，每次应用后恢复 PMX 角度限制。求解只写局部旋转，不改骨骼平移/缩放；PMX根组不参与旋转，角色根位置不移动，center的本地位置由父级层级锚定但其旋转可参与目标分配，避免整体平移漂移。

脚踝目标活动时，若对应膝点没有直接拖动，则额外使用本帧基准腿姿势推导低强度的膝盖弯曲面偏好，减少伸腿方向歧义；直接拖动膝点时该偏好让位给用户目标。求解仍从每帧VMD与原生IK/grant姿态开始，只在有活动目标时运行，不新增碰撞、物理时间步、软体效果或渲染循环；VaM 的关节物理/软体碰撞仍不在范围内。`web-human-ik-pbd.mjs`实现按末端误差梯度、杠杆向量和骨段长度分配的旋转约束投影，最多12轮、单轮每骨最多15°；外层仍施加膝骨150°/其他骨骼45°总修正预算及PMX IK link限位。3项PBD数学单测、原 IK/相机定向测试共8/8通过；真实米娅 PMX 加载控制点和镜头手势浏览器测试1/1通过；`npm run build:web:mmd-ar-test`成功。真实PMX拖点姿态、其他模型和手机帧时仍待验收。

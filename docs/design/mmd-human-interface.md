# MMD HumanInterfaceElement 通用角色控制

## 需求与范围

用户希望将MMD控制归入humanInterfaceElement，在不同PMX中使用同一接口：生理动作（呼吸/眨眼）、生理条件反射、AI高级交互（后天登记/学习的VMD和组合表情）、低级MPL。用户已确认完整方案，并补充后天学习支持用MPL覆写原动作；实现仅限独立mmd-ar WEB_MODE。

## 一个角色一个接口实例

HumanInterfaceElement作为角色控制对象，读取PMX能力并协调动作；调试面板是该对象的操作入口。AI、回复标记、触摸/刺激事件和面板都向同一对象提交命令，不直接写骨骼或Morph。每个实例持有模型token，换模型重新绑定能力并取消旧会话；模型加载异步回包必须匹配实例版本。

## 分层

| 层 | 职责 | 输出与资源 |
|---|---|---|
| PMX适配与资产 | Morph/骨骼/物理能力、VMD兼容性和动作资源登记 | 当前模型真实索引、骨骼与已校验clip |
| 生理层 | 呼吸、自然眨眼、基础待机 | 可用呼吸Morph或小幅躯干增量，眼部闭合曲线 |
| 生理/条件反射层 | 刺激事件触发短反应；可登记事件与反应的关联 | 眨眼/短VMD/组合表情，冷却和淡入淡出 |
| AI高级接口 | 行为意图、情绪、强度、时长、次数 | 已登记的VMD＋语义组合表情；按模型能力选择 |
| MPL低级接口 | 指定骨骼和Morph时间线、控制范围 | MPL编译clip交同一混合器，仍遵守限位与资源约束 |

口型是独立嘴部通道，继续复用同一口型播放器。生理/反射/AI/MPL并非按一个全局优先级整段覆盖。

## PMX通用映射

统一语义如eyes.close、mouth.a、face.joy、body.chest、head、leftArm、rightArm，对应当前PMX的原始名称/索引/骨骼。自动候选只在唯一匹配时采用；缺失或歧义提供手动映射、能力缺失及降级结果。组合表情允许绑定多个Morph及权重，不复用某个模型固定编号。

模型配置按模型身份与骨骼/Morph签名保存；持久化名称和映射定义，真实索引每次加载重建。非标准骨骼、轴向/绑定姿态、长度/根位移/IK差异影响VMD效果，首版按能力声明拒绝或使用模型专用VMD；完整自动重定向另行扩展，不承诺任意PMX无配置即可兼容。

## 生理与反射

自然眨眼按有界随机间隔及闭合/保持/睁开曲线运行；AI闭眼/眨眼占用眼部时暂停重复眨眼。呼吸优先用模型提供的合适Morph，缺失时可配置胸/上半身微小增量；从本帧姿态叠加，不累计旋转或偏移。无可靠绑定则关闭对应能力。

反射首版用明确事件和规则，如touch.head、stimulus.surprise触发已配置短反应；调试面板发送事件，不增加麦克风/摄像头检测。每条规则有阈值、冷却、强度、时长与动作/表情设置，优先级90；同一事件规则可替换，停止按规则owner释放。条件反射可登记事件与VMD/表情反应的关联；自动习得与训练策略尚待后续设计。

## 后天动作库

首版“学习”指登记已有VMD、命名语义动作、组合表情及触发关联。动作条目包含actionId、资源引用、所需骨骼、通道mask、循环/单次、时长/强度支持和表情preset。AI只调用actionId与语义参数，不生成下载地址或PMX索引。现有点头等MPL模板可以作为后备动作，并在调试界面注明来源。

本地File/BlobURL不能作为跨刷新资产路径；实现将VMD的ArrayBuffer连同定义存入IndexedDB，支持含VMD数据的JSON导出/导入。读取已登记本地资源或同源mmd目录VMD，不持久化BlobURL。首版学习由人工登记与版本修正组成。

## MPL覆写与行为版本

登记动作可包含基础VMD和多个MPL修正层。MPL只覆写指定骨骼/Morph及指定时间窗；未指定部位沿用原VMD。override为绝对覆盖，additive为相对绑定姿态叠加，强度可淡入淡出。保存为新的行为版本，保留原动作文件与父版本，可撤销/切换；也可直接使用当前VMD作为基础进行MPL修正。首版修正作为运行时层保存，不改写原VMD二进制。

## 通道混合与物理

身体、眼睛、眉/面部、嘴部拆分所有权；身体可按头、躯干、左右手臂等mask进一步细分。不同通道并行，相同轨道按优先级/覆盖范围处理；显式手动控制保持，嘴部由口型拥有时仅覆盖映射嘴型。保护性闭眼短暂优先于自然眨眼，显式眼部动作抑制重复眨眼；不将一套优先级应用全部骨骼/Morph。

新增运行时混合器：当前VMD提供基础姿态，允许的身体增量/片段在动画与IK流程的适当阶段合成，完成矩阵更新后参与物理；Morph由统一分层控制器合成。必须沿用当前帧恢复/骨骼备份与MMD helper生命周期，不能累加上一帧已处理的姿态，也不能覆盖物理回写的动态骨骼。呼吸/眨眼/反射通过每帧曲线和clip权重完成，不为每次触发重建helper或重置物理。换PMX或明确物理重载仍沿用现有初始化流程。

实现完成并生成本地web-dist：Human面板提供生理设置、能力映射、VMD/MPL行为登记、组合表情、反射、MPL覆盖/增量预览、新版本保存/切换及导入导出。基础VMD持续播放，修正接在骨骼备份之后/IK之前，口型共用现有player。完成构建与静态检查，未新增或运行功能测试；实际多模型与手机表现待验收，未发布外网，正式源码和Offline状态保持。

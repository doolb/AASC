# 控制端 TTS 输入历史

## 需求

控制端“语音播报 (TTS)”输入框需要使用浏览器/WebView 原生输入历史提示。提示由浏览器负责展示和维护，页面不创建自定义历史弹窗，也不在 focus/blur 时操作输入节点，避免页面代码主动关闭原生提示。

## 方案

- 为 `ttsTextInput` 设置稳定的 `name`。
- 显式设置 `autocomplete="on"`，允许浏览器显示历史输入建议。
- 将输入框和播放按钮放入独立的 `autocomplete="on"` 表单，提供浏览器识别历史字段所需的稳定表单上下文。
- 保持现有 TTS 播放按钮和 WebSocket 发送流程不变。
- 不记录或上报输入内容，不修改浏览器原生历史行为。

## 验收

- 控制端刷新后点击 TTS 输入框，浏览器可以显示已有历史输入。
- 鼠标移动到历史建议项或点击外部区域时，页面代码不重建输入框、不切换 autocomplete 属性，原生提示由浏览器自行关闭和重新显示。
- 点击历史项后可以继续编辑并按原流程发送 TTS。

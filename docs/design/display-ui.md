# 显示端界面优化

显示端媒体库根目录合并各来源内容，无来源分组；每个条目保留内部来源和路径，点击目录后在对应来源内导航，返回可回到汇总页。来源失败只提示部分内容失败，其他结果仍可用。图片及可读取尺寸的视频、远程封面按比例显示全幅卡片；目录和未知尺寸使用默认卡片，保留播放、批量播放、B站操作和背景透明度。

显示端继续以媒体与角色画面为中心，优化打开后的快捷控制、聊天、媒体库、主题音色与 MMD 设置面板，以及壁纸控制的视觉层次与触控体验。采用现有主题变量，媒体库继续使用原有可调透明深色背景和高对比文字，避免影响透明度语义。

横屏快捷控制分两列；媒体库各来源根目录统一展示，卡片保留完整操作。短屏、窄屏允许内部滚动，聊天输入和关闭按钮保持可触及。保留安全区域、旋转与键盘避让，以及媒体、角色、字幕、游戏、设置与壁纸现有层级和事件。

# Retop 参考低模、UV 与颜色贴图

使用用户选择的高模、参考低模和本地图片进行形体对照，按逐面角点保存 OBJ UV。参考低模通过统一缩放和平移拟合高模坐标，原网格作为对照保存。生成低模沿用已验证的 UV 展开，从高模原 UV 和颜色贴图采样到新图集。投影需使用朝向相容的源三角面，报告未命中、距离和覆盖率。

界面支持高模的配套 OBJ、MTL、图片导入、参考低模载入、颜色预览和颜色包导出。颜色包包含静态 OBJ、相对路径 MTL 和 PNG。MTL 路径失效时，由用户显式选择本地贴图。参考 LOW.obj 和 lOW.tga 可用作原低模对照。首轮验收采用目标 LOW.obj 的实际 2122 个三角面预算，高模 HIGH.png 为 4096，低模 lOW.tga 为 512。新烘焙图集默认 2048。

目标实测输出 2122 个三角面、210 个 UV 岛和 2048 图集。因原有保守圆盘切割出现高拉伸，烘焙前按空间和面邻接拆分高拉伸岛，并重新展开。各岛面积加权 P90 拉伸约束为 8，单三角形最大值约束为 32，本次测得最大 21.85。源图对应的 1045427 个有效图集像素全部命中，纹素投影最大距离约为模型对角线的 2.02%。独立 Blender 回读 OBJ、MTL 和颜色图通过，生成模型的脸、耳和手指仍比参考低模粗。

用户要求达到示例效果，并明确从高模自动重建，LOW 仅作验收对照。当前继续调整自动收线的局部误差和面形，结合源表面逐角法线改善渲染。面数一致、UV 有效和贴图命中率仅作为基础检查，视觉对照未通过时保留质量问题记录。

低模预算严格限定为 2122 个三角面。复杂人物自动减面改用局部尺度权重和位置正则，减少极细三角面。目标高模的 1499606 个原始面全部为 `s off`，同时有 749546 条显式法线；参考 LOW 的平滑组为 1、2、4 及 off。生成时依据原高模逐角法线与实际折边恢复光滑区域和硬边，不复用 LOW 的组编号。该恢复在低模、中模和超近档生成及重建时自动执行，无需贴图或 UV；颜色烘焙复用相同法线迁移逻辑。投影法线先在共享光滑扇区内协调，再按目标与源三角面比例自适应控制细节权重；该模型低模权重约为 3.76%，避免粗网格带入高频折痕。输出保存逐角 vn 和 s 分组。

独立 Blender 已回读 2122 个三角面、1115 个多边形、1 个 UV 通道和 2048 图集，自定义法线有效。目标角点法线投影 4292 次命中、60 次采用局部法线回退。正背斜视对照仍可见脸部和胸前装备的几何差异，示例质量目标尚未完成。

## 胸前结构问题与已确认方案（实施中）

用户红框明确指出胸前袋体的主面、竖向转折和下缘不符合参考。已拆开几何与着色对照：逐角独立法线投影引入的额外折痕已修复，复杂人物全局 QEM 回退仍没有以袋体的结构块面构面。约束 CSI 边界、位置正则、体积保持和表面过滤等只读试验未通过参考形体验收，未合入几何路径。诊断文件保存在 moxing-quality-2026-11-18，各候选不是交付成品。

拟将复杂人物路径改为结构分区优先：新增尺度与预算相关的大块面识别，将细小翻盖、纽扣和缝线从主结构曲线中分离；CSI 曲线描述块面的真实边界与硬转折，闭合多分支区域先切成可构面的补片，再生成基础笼。低预算优先保留轮廓、主平面、转折和袋体下缘，平坦面不加内部线，剩余预算分配给曲面。中模继续从实际低模细化。新路径需明确报告尚不支持的分区，不用全局减面结果冒充结构重建结果。

影响新增 feature-patches.js、现有 boundary-guides.js、csi-surface.js、structure-grid.js、engine.js 及相关回归。viewer.js 显示实际块面与边界，贴图与 OBJ/MTL/PNG 输出复用现有接口。低模仍限定 2122 个三角面，LOW 仅作独立视觉验收；不得读取其顶点、拓扑、UV 或平滑组作为重建模板。用户已确认该方案，现按分阶段测试实施。

2026-11-18 首轮结构构面仅完成独立模块，尚未接入 engine、Worker 和默认界面。主块面采用源面二阶矩平面拟合及稳定平面保护；共享 CSI 负责交点、闭环和曲线站位；源面图离散构面负责共享顶点、拓扑修复、曲面补点及局部投影回退。合成凸起板、双块面和环形曲面通过基础回归，不代表目标人物通过。

目标 30000 三角面分析副本的候选恰为 2122 三角面、1059 顶点、569 四边面，保持一壳体、Euler=-2，边界、非流形、退化、定向冲突和非相邻面穿插均为零。袋体下侧源面方向覆盖率从 25% 提升至约 73.6%。但正视、斜视和胸前局部显示头部、胸前及衣物仍有明显折面和形体损失，视觉验收失败，不能替换现有默认输出或称为示例效果。

定位到的限制：稳定平面支撑扩张后会吸收不相容的曲面，人工参数域交界和拓扑修复占用了大量预算；172 个区域的候选用了 863 个初始锚点、189 个修复锚点，仅增加 7 个曲面保形锚点。关闭迁移法线、取消代理平面位移后问题仍存在，不能归因于平滑组。法向约束、支撑域约束、区域收线及代理误差试验均保留为独立诊断，没有合入默认算法。后续必须先解决主形体分区与预算分配，再接中模和新 UV/贴图验收。

### 人物模板和装备截面
用户确认允许使用通用人脸模板。单文件网页提供“复杂人物”选项，适用于直立、面部外露的人物。依据源网格的主轴、头宽和前后深度起伏识别鼻尖，在眉缘、眼眶、鼻底与下巴附近增加贴合点。装备的主平面和重复闭合截面参与腰部截面简化，截面转折共用位置。脸部和装备共用同一个三角面上限。识别失败或候选有穿插时提示重试或调整选项。
交付检查使用相同相机分别渲染原示例和重建模型，并在独立进程回读 OBJ、材质、2048 颜色图和 UV。区域表现及光照下的折线仍需与示例逐项比对。

### 人物低模的灰模块面
正面脸颊、前额和胡须使用与头宽关联的表面包络，眉弓、鼻底和嘴部保留高模的局部深度转折。胸袋使用上下对应的闭环固定袋体转角，再接回衣物。无法得到两个简单闭环、改变拓扑或移除手动锚点时沿用普通截面拟合。截面两端的光滑过渡与实际纵边共同决定灰模中的袋体形状。使用高模显式法线在同位置的断点区分真实硬缝和采样方向差。验收持续使用同机位的美术 LOW、上版和新版的裸材质局部对照。

### 耳廓与带尾

耳廓大面应保留连续明暗，耳根逐渐接入脸颊。高模有正反两层的薄带，其正面、背面和封边应有独立的法线。各档按自身网格恢复这些边界，低模预算、现有外形及 UV 保持一致。

### 人物部位 UV

复杂人物沿头部拟合给出的竖轴和前向组织低模及派生档的 UV。两侧脸、后脑、躯干正背、手臂、裤腿和靴子分别形成便于阅读的连续区域。侧脸优先放在左上，后脑位于上方，胸前装备保持正立。分区和图集只使用本次人物重建的数据。覆盖率计算剔除烘焙扩边，允许通过颜色复核的左右部位叠放。实际验收分别检查图集布局和模型上身效果。

### 人物重点部位的纹素密度

对照美术示例时按单位模型表面积的 UV 分配评价脸、头发、胸前装备、手臂、裤腿与靴子。镜像共享的左右表面分别计入使用的纹素，以便比较每侧的细节分辨率。原始 LOW 只用于独立测量。

人物模式提供七个线性纹素倍率，默认取美术示例测得的相对密度。用户可分别调高脸、头发、前胸、后背、手臂、裤腿或靴子。应用倍率只更新人物档位的布局，原模型与已生成的几何保持一致。工程保存倍率，旧工程使用美术默认值。

### 人物结构布线

人物从高模截面确定裤腿、靴口、袖口与躯干面带，两侧采用对应的高度和列数，保留源表面左右差异。面部沿中线与主要转折组织连边。预算以完整模型三角数计算，参考 LOW 只参与验收。

肩袖与躯干、护腕与前臂、两侧下摆与裤腿需能从灰模结构辨认。帽顶需保留源表面的斜向转折。验收时应查看这些位置的近景线框、灰模与局部深度误差。

原高模近景核对后，样例头顶实际为向额前汇聚的发束，胯侧突出部分为带袋盖的裤袋。独立基本体预览用局部截锥拟合卷袖、短椭圆筒拟合护腕、楔形侧片拟合裤袋；头发还需评估分束方向和发梢轮廓。

人物美术对照同时检查物体的几何边界和 UV 的绘制区域。小闪前胸与胸袋在同片 UV 中，双侧脸复用半张脸；卷袖、护腕和腰带附近承担部位间切缝。重要部位分别比较单位表面密度和去除重叠后的实际占图面积。

### 跨模型的看图重建原则（设计）

根据用途、目标观察距离和多个视角识别主形、附着关系、开口及运动部件。语义判断决定哪些结构值得保留，深度和原网格验证尺度与遮挡。分别为几何和纹素分配预算：剪影、厚度、关节与主要折线优先用几何表达；文字、花纹及表面色差优先保证绘制空间。沿主曲率、截面或折边组织走线。优先保持连续图案可绘制，参考自然边界、低可见侧和展开拉伸选择切缝。仅当两侧外观和烘焙结果允许时共享 UV。不把示例部位名称、固定权重和某个视角作为默认约束。

### 看图引导试验状态

小闪高模试验将脸部与肩袖识别为优先区域。网页生成连续候选后，脸部少量顶点沿高模深度限幅调整，脸与胸前 UV 按重要性增加密度。源纹理直接正投影在眼周面片交界产生明显接缝，仍需研究跨面片一致的投射。

脸部贴图验收以原高模颜色与几何为输入。小闪试验在正面可见区域采用高模图像重投影，其余区域使用常规烘焙；对照正面及斜前方的眼周和 UV 交界。

源高模贴图与美术低模贴图需分别对照。脸部的手绘纹理差异、投射误差和低模几何带来的灰模差异分别观察，以实际输入纹理界定可烘焙的颜色细节。

# Chat2API远程交互登录

状态：已实现，真实Provider登录待人工验收。日期：2026-10-22。

## 最终需求范围

普通浏览器控制端调用服务端浏览器完成各Provider网页登录，回传画面并操作。Android显示端暂不接入。全服务同时最多一个登录页面，登录页面与豆包运行页面分开；切换登录Provider不会导航、关闭或清理豆包运行页面。

复用现有浏览器启动/CDP基础能力、Provider登录声明和账号保存流程。现有登录声明覆盖豆包、Qwen、Qwen AI、DeepSeek、GLM、Kimi、MiniMax、Mimo、Perplexity及Z.ai。支持已声明的Cookie、localStorage和Authorization捕获；仅API Key认证的Provider继续使用原手工配置。新Provider通过受限登录声明扩展，不把任意URL当登录来源。

## 页面与会话隔离

服务端维护唯一登录槽位，绑定拥有者控制端连接、Provider、账号或新登录state、视口、帧及输入序号、到期时间。重复打开同一会话复用当前登录页；同一拥有者切换Provider/账号时先结束原采集并关闭原页，再创建隔离登录上下文与页面。存在未保存登录时在控制端确认切换；其他控制端得到占用提示，不接管。

登录页使用独立的浏览器上下文/资料范围，豆包运行页继续由原doubao.web/browser-port管理。现有豆包launcher按账号切换会关闭进程、bridge会整理官网旧标签，所以不能直接把登录页混入运行页集合。实施时抽取通用浏览器启动设施，为登录角色单独管理生命周期；复用浏览器名称/路径选择能力，登录页面数限制为一，不复用豆包运行调试端口或profile。

窗口只有远程登录画面，支持点击、按下/拖动/松开、滚动、中文输入、退格/回车、完成及关闭。验证码由用户手动完成。画面通过既有AASC/WebSocket定向回传，附视口和序号，限制帧大小/频率和在途数量；输入校验会话及视口并保持拖动顺序。断线、超时或关闭释放登录资源，拒绝迟到帧与输入。

登录完成按Provider声明采集所需凭据，经现有OAuth完成或账号刷新服务保存，控制端只接收保存结果。豆包保留请求样本/网页终态验证，网页成功不冒充Node成功。凭据更新遵循现有账号版本与失效逻辑；不在运行中的聊天流内强制覆盖浏览器状态。浏览器路径等可配置值沿用AASC远端权威配置，不建立并行HTTP配置保存入口。

## 文件与验收

已修改chat2api.js及弹窗样式，新增远程登录会话/帧输入路由和通用登录浏览器适配模块；提取/复用现有browser-launcher基础能力、chat2api-login-profiles.js和账号捕获保存服务。豆包运行bridge只做必要的浏览器角色隔离适配，原任务业务和页面保持独立；Android代码不改。

验证全部声明Provider的采集契约、单登录页、重复打开与切换、双控制端占用、跨账号隔离、输入坐标/拖动/中文、帧背压、取消/断线以及登录期间豆包运行页不受影响。真实官网人工登录逐Provider验收，单元契约通过不能替代官网可用性。只影响servicePackage；servicePackage已标记待出包，本次未操作真实账号。

## 实施结果

新增chat2api-remote-browser-session.js、chat2api-login-browser.js、chat2api-browser-capture.js及控制端remote-login JS/CSS。浏览器使用临时独立profile和pipe；复用运行任务的浏览器路径（无运行任务配置时默认vivaldi）。截图1024×720、JPEG65、最大2MiB，客户端解码后约300ms请求下一帧，服务端250ms缓存，命令队列最多64项。会话不超过OAuth有效期；保存锁内比较通用账号快照，避免其他Provider更新被覆盖。

验证包括Chat2API回归、CLI捕获回归、会话隔离和真实Vivaldi本地夹具。真实官网各Provider登录、弹出式第三方认证及验证码仍需人工验收，不把声明覆盖视为官网成功。

## 关闭范围修正（2026-10-22）

用户确认关闭仅针对登录tab。服务级登录浏览器宿主保留进程和初始空白页，每轮登录在独立BrowserContext创建标签；完成、关闭、断线和切换只回收该Context及监听，不退出宿主、不影响其他Context的标签或豆包运行页。下次登录复用同一宿主，新Context隔离前次未保存的Cookie/storage。服务停止时才退出自有宿主并清理profile；浏览器路径变更需重启服务。弹窗仅匹配登录页opener，避免误关手动标签。

12项定向测试通过；真实Vivaldi断言登录tab关闭、其他tab存活、进程PID保持、再次登录未继承凭据、stop后临时目录删除。

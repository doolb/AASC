# 显示端控制页面重构设计文档

## 概述

重构显示端控制页面，使其更紧凑、更易用，并作为浮动组件在所有页面上可见。同时新增播放命令、通用时间解析等功能。

## 已完成功能

### 1. ✅ 浮动控制面板

将显示端控制功能重构为浮动面板，可以在所有页面上访问。

#### 设计要点
- 固定在页面右下角，可展开/收起
- 展开时显示常用控制功能
- 收起时只显示一个小图标
- 状态持久化到 localStorage

#### 功能列表
- 显示端选择（下拉列表）
- 播放/暂停按钮
- 音量控制
- 画面填充模式切换
- 快速播放命令输入框

### 2. ✅ 播放命令

实现 `播放{文件名}` 指令，通过名字搜索媒体文件并播放。

#### 指令格式
```
播放{文件名}
播放 {文件名}
```

#### 处理流程
```
用户输入 "播放电影名"
    ↓
提取文件名关键词
    ↓
搜索所有媒体库中的文件
    ↓
匹配结果:
├─ 无匹配 → 提示"未找到文件"
├─ 单个匹配 → 直接播放
└─ 多个匹配 → 列出选项让用户选择
    ↓
发送到选中的显示端播放
```

#### 搜索范围
- 本地 uploads 目录
- 所有已配置的媒体库

### 3. ✅ 通用时间解析

实现一套通用的时间解析功能，用于提醒和天气等功能。

#### 支持的时间表达式

| 类型 | 示例 | 说明 |
|------|------|------|
| 相对日期 | 今天、明天、后天 | 相对于当前日期 |
| 相对时间 | 3秒后、5分钟后、2小时后 | 相对于当前时间 |
| 相对时段 | 3天前、2周后、1个月后 | 相对于当前日期 |
| 绝对日期 | 3月15日、2024年3月15日 | 指定日期 |
| 绝对时间 | 3点、15点30分 | 指定时间 |
| 组合表达式 | 明天下午3点、后天上午10点 | 日期+时间 |

#### 数字表达
- 阿拉伯数字：1、2、3...
- 中文数字：一、二、三...十、百、千、万
- 混合表达：十2分钟、2十分钟

#### 解析结果
```javascript
{
    timestamp: 1234567890000,  // Unix 时间戳（毫秒）
    description: "明天下午3点", // 原始描述
    type: "absolute",          // absolute | relative
    confidence: 0.95           // 解析置信度
}
```

### 4. ✅ 天气语音播报

天气查询结果自动生成语音播报。

#### 实现方式
- 天气查询成功后，自动生成 TTS 音频
- 发送到显示端或控制端播放
- 同时显示文本内容

### 5. ✅ 天气 JSON 完整本地处理

天气服务继续使用 wttr.in 的 `format=j1` JSON 接口，由服务端本地完成数据归一化和中文文案生成，不依赖接口返回的 `lang_zh` 一定为中文。

#### 数据范围

- 当前天气：温度、体感温度、湿度、气压、能见度、风向、风速、天气编码、云量、降水、紫外线和观测时间。
- 未来约 3 天：最高/最低/平均温度、日照时长、降雪量、紫外线、天气概况和逐时天气。
- 逐时天气：温度、体感温度、湿度、天气编码、降雨/降雾/降雪/日照概率、降水量、紫外线、能见度、风向、风速和阵风。
- 天文信息：日出、日落、月出、月落、月相和月亮照明比例。

#### 输出策略

- 归一化结果作为天气响应的结构化扩展字段，供显示端和后续功能使用。
- 显示文本包含完整的当前天气、逐日预报、今日逐时预报和天文信息；未来日期不展开逐时明细。
- TTS 使用完整数据生成的短摘要，仅播报当前天气和逐日概览，避免一次播报 3 天逐时明细造成语音过长。
- `weatherCode` 使用本地中文映射优先修正 `Mist` 等接口未翻译的天气描述。

### 6. ✅ 自定义指令持久化

将自定义指令保存到配置文件。

#### 存储格式
```json
{
    "commands": {
        "早上好": ["今天天气", "今日提醒"],
        "晚安": ["关闭报时"]
    }
}
```

#### 文件位置
`config/chat-commands.json`

## 数据结构

### 时间解析结果

```javascript
{
    timestamp: number,      // 目标时间戳（毫秒）
    description: string,    // 时间描述文本
    type: 'absolute' | 'relative',
    confidence: number,     // 解析置信度 0-1
    original: string       // 原始输入
}
```

### 播放命令结果

```javascript
{
    success: boolean,
    message: string,
    matches: [{            // 匹配的文件列表
        name: string,
        path: string,
        libraryId: string,
        url: string
    }],
    played: boolean        // 是否已播放
}
```

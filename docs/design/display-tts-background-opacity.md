# 显示端 TTS 字幕背景透明度设计

## 需求

控制端“界面主题”卡片在“显示端背景光晕”之后提供 TTS 字幕背景透明度设置。透明度滑块范围为 0%–100%、步长 1%、默认 20%。界面百分比换算为 0.00–1.00 的 CSS alpha；服务端和 WebSocket 继续保存/传输 0–1 比例值，默认 0.2 保持现有视觉效果。

## 行为约束

- 配置为服务端全局 UI 参数，所有控制端和在线显示端保持同一权威值。
- 控制端展示百分比；发送时按 `百分比 / 100` 转为 alpha 比例，收到权威比例后再转回百分比。服务端校验 0–1 范围并按 0.01 步长规范化。
- 沿用 AASC WebSocket 配置流程；服务端校验并通过 `config.set` 持久化，成功后广播规范化值，控制端和显示端连接时补发当前值。
- 不新增配置 HTTP 读取/保存接口。远端配置未到达或配置缺失时，显示端使用 alpha 0.2。
- 仅修改 TTS 字幕背景渐变峰值；上下透明端点、4px 背景模糊、文字、阴影、三行滚动及字幕生命周期不变。
- CSS 使用独立自定义属性，不改变字幕节点整体 opacity，避免文字透明。

## 验收

验证设置项出现在背景光晕之后，滑块范围为 0%–100%、步长 1%、默认 20%；0%、20%、100% 可正确转换成 alpha 0、0.2、1 并保存/权威回传，越界值拒绝；显示端两个渐变峰值随配置更新，文字不透明度和其他字幕样式不变。

## 显示端直接调整（2026-10-19 已实现）

显示端右侧“音色”按钮上方的“主题”面板同时提供 TTS 字幕背景透明度滑块，范围 0–100%、步长 1%、默认 20%。拖动时仅预览当前显示端字幕背景，松开后通过当前显示端 WebSocket 写入原有 `ui.displayTtsBackgroundOpacity`；服务端校验、持久化并广播规范化值，所有控制端和显示端同步回显。连接断开或保存失败时回到最近一次权威值；重连时服务端补发当前值。字幕文字和播放队列不变。

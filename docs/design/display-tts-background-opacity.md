# 显示端 TTS 字幕背景透明度设计

## 需求

控制端“界面主题”卡片在“显示端背景光晕”之后增加 TTS 字幕背景透明度设置。透明度滑块调节字幕黑色渐变背景的峰值 alpha，范围为 0%–20%，默认 20%，保持当前 alpha 0.2 的视觉值。

## 行为约束

- 配置为服务端全局 UI 参数，所有控制端和在线显示端保持同一权威值。
- 沿用 AASC WebSocket 配置流程；服务端校验并通过 `config.set` 持久化，成功后广播规范化值，控制端和显示端连接时补发当前值。
- 不新增配置 HTTP 读取/保存接口。远端配置未到达时，显示端使用 alpha 0.2。
- 仅修改 TTS 字幕背景渐变峰值；上下透明端点、4px 背景模糊、文字、阴影、三行滚动及字幕生命周期不变。
- CSS 使用独立自定义属性，不改变字幕节点整体 opacity，避免文字透明。

## 验收

验证设置项出现在背景光晕之后，滑块范围/步长/默认值正确；配置保存、权威回传和重连补发正常；显示端两个渐变峰值随配置更新，alpha 0 与 0.2 的边界有效。

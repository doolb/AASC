# 正式显示端口型与 TTS 同步

## 需求与已确认范围

2026-10-10 用户认可独立口型效果，要求接入正式包并同步TTS。确认迁移口型面板、拼音时间线、临时表情层；聊天、本地文本朗读、远程文本播报按音频currentTime/实际时长驱动。无逐字时间戳，因此音节与停顿按文字估算后缩放，不宣称精确音素对齐。

## 设计

- 正式与独立共用mmd-lipsync-ui/timeline和PMX临时Morph覆盖，优先于手动/VMD的映射嘴型，保留其他表情和动作；停止恢复原值，不重置物理。
- 正式「动作 → 口型」保留无声文本预览与手动映射，TTS自动优先并默认启用。本地同步开关仅控制当前显示页，停止口型按钮只停止当前口型，不停止音频；下一句可自动接续。
- 音频准备桥接先于设置src记录同句文本/来源/不可变序号；只有真正消费的句子进入，不同步预取或其他设备语音。口型模块迟加载可读取当前快照。
- 用真实currentTime与duration取样；暂停/等待/seek期间闭嘴，恢复后按当前位置继续；换源/错误/结束/中断释放旧覆盖。换模型清理token并重新匹配，不把旧索引写入新角色。
- TTS与预览使用同一调度器避免争夺；后台停止帧循环和释放权重，回前台以实际播放位置恢复。模块/字典失败不阻止音频播放。
- 固定pinyin-pro 3.29.5完整ESM树、MIT许可证及SHA清单放正式静态目录，首次用口型才加载，不新增npm生产依赖。独立构建只复用并指纹化模块，不再次注入控制器。

已接入正式源码与同源资源，独立共用模块和构建已同步；正式服务包待构建发布，实际设备验收待用户要求。未新增或运行自动/浏览器测试。

# 桌面浏览器媒体服务设计

## 浏览器访问 HTTP 接口与脚本（2026-11-11）

服务端提供受独立令牌保护的状态、同源请求和媒体提取业务接口，复用运行中的浏览器任务、白名单、页面会话及其访问限制。令牌由服务启动环境变量 `AASC_BROWSER_MEDIA_API_TOKEN` 提供，必须是 64 位小写十六进制；未设置时接口关闭，不新增配置读写接口。调用端不接受远程明文 HTTP，避免凭据泄漏；本机 HTTP 可用于开发。独立 Node.js 脚本既可命令行运行也可作为模块调用，不注册 AI 工具。挑战需人工处理，成功与否由上游决定。

## 已实现（2026-11-11）

新增独立 Linux 桌面服务任务，以专用 Vivaldi 和本机 CDP 连接访问经 Cloudflare 保护的网站；验证需要人工参与时呈现专用页面并返回明确状态。国内、国外等媒体源后续通过统一内部接口选择使用该任务，不自动改变既有来源请求。每个来源和站点隔离 profile，代理按调用来源传入，不能泄漏代理凭据或 Cookie。浏览器不存在、图形环境不可用、站点受限或验证失败均报告真实原因。

不安装插件，以 CDP 执行 AASC 自有油猴采集脚本，并提供其必要 GM 接口的受限兼容层；任务卡片“扫描并保存”由用户主动触发，将当前页全部候选保存到现有用户文件媒体源。不执行用户任意脚本。通用油猴脚本的完整权限、沙箱和所有 GM API 不承诺兼容。Android 平台实现见下方 2026-11-12 更新。

来源任务通过 `context.browserMedia` 请求同源文本、最多 2 MiB 的二进制或执行采集；支持传入来源代理和单段 Range，会话上限默认一个，可配置为一至四个来源/站点/代理会话。仅无凭据 HTTP、HTTPS、SOCKS5/SOCKS5H 代理可用于浏览器，Chromium SOCKS5 由代理侧解析域名；未设置时显式直连。既有来源没有自动切换到此接口。允许列表留空时允许访问所有 HTTPS 主站，填写列表时仅允许所列主站；页面请求不可跨源或自动重定向，浏览器子资源遵循浏览器页面自身规则。允许所有站点包含机器可连接的内网 HTTPS 地址。

真实 Vivaldi 独立 profile 验证了普通页面文本、二进制和测试视频采集；本机拒绝连接代理不会回退直连。受保护搜索站点实测进入 Cloudflare 挑战并报告待验证，未完成挑战后成功读取的现场验证。

2026-11-12 本机独立 Vivaldi 会话测试：抖音首页可打开，精选页曾显示推荐与视频元素；现有采集器抓到的候选以图片为主，单次获取的静态域名 MP4 可读取，尚未确认与推荐视频一致。当时 Android Offline 网页媒体尚未接入；此桌面探测不能证明 APK 可播放。

## Android Offline 会话与上限（2026-11-12）

Offline 使用独立进程 WebView 服务和前台查看页面，Node 通过本机令牌接口复用 open/request/extract/stop 契约。任务会话上限 1–4，默认 1；达到上限拒绝新会话，不挤掉已有页面。Android WebView 不支持逐会话代理时明确拒绝，避免静默直连。WebView 与豆包、显示页进程隔离；同一 Android 媒体服务内会话共享平台 Cookie 存储，不宣称跨会话隔离。手动验证和站点实际播放依赖设备与上游。

抖音精选使用 Android WebView 当前 Chromium 版本构造桌面版浏览器标识，尽量与精选卡片布局一致；其他网站仍使用 WebView 默认标识。实际站点兼容性须真机确认。

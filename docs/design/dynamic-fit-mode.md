# 动态画面填充模式设计

## 需求

显示端增加「动态」画面填充模式。模式在「适应」和「铺满」之间循环：适应状态停留后，用指定时长平滑放大到铺满；铺满状态停留后，再用相同的过渡时长缩小回适应，持续循环。

## 配置

- 过渡时间：适应与铺满之间单程动画时长，默认 3 秒。
- 停留时间：适应或铺满状态保持时长，默认 2 秒。
- 控制端设置按当前显示端保存，服务端重启和显示端重连后恢复。
- 输入值由服务端限制为正数，避免无效或过大的计时参数影响页面。

## 交互与边界

- 动态按钮与其他填充按钮互斥高亮。
- 切换到其他填充模式时立即停止循环定时器，避免旧阶段回调覆盖新模式。
- 切换媒体、旋转或媒体尺寸变化时沿用当前动态阶段，并重新计算适应/铺满目标尺寸。
- HTML 媒体继续使用原有铺满逻辑，不执行图片/视频动态尺寸动画。
- 动态循环只改变图片/视频的宽高，不改变裁剪、旋转和播放状态。
- 过渡阶段先提交 CSS transition 并刷新布局，再保留当前宽高写入目标宽高，确保浏览器有可插值的起点和终点。

## 影响模块

| 模块 | 变化 |
|------|------|
| 控制端 | 增加动态按钮、过渡/停留秒数输入和状态恢复 |
| 服务端 | 持久化 `dynamicFitConfig`，转发动态模式和参数 |
| 显示端 | 增加可停止的动态阶段控制器，复用 contain/cover 尺寸计算 |
| 协议 | `fit` 支持 `dynamic`；新增 `dynamicFitConfig` 控制动作 |

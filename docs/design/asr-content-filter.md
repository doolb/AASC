# ASR 内容过滤

短中文过滤原来要求整段文本都是紧凑编号，导致“下H4。”仅有一个汉字而被误拦截。现改为检查原文中是否包含长度 2 至 12、同时含英文字母和数字的连续编号；数字同时支持阿拉伯数字与常见中文数字。

命中编号即放行内容，保留全部 ASR 原文。没有编号时沿用中文要求、短英文和单汉字噪声过滤。空格与连字符切断连续片段，超长编号不截取短片段放行。内容通过后仍接受声纹、会话、命令及 GM 棋局校验。

实现位置为 `server-app.js` 的 `hasValidContent`；`asr-content-filter.test.js` 覆盖带前缀的 H4、中文数字、无效噪声及实际识别路由。状态：源码与定向测试完成，服务包和设备体验待验收。

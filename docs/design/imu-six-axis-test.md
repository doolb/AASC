# 六轴IMU共享3D测试网页设计

日期：2026-10-03。状态：已实现，桌面与Android真实采集/校准/共享验证完成；实际位移精度及iOS待现场验收。

## 需求与本轮优先级

用户要求先写一个独立测试网页：六轴IMU驱动3D物体的平移和旋转，处理零偏、死区与噪声；电脑能模拟六轴输入及噪声，真实手机也能接入，不同设备进入同一个场景。原APK单目IMU/锚点恢复方案作为后续任务保留，本轮交付独立网页实验。

“控制一个物理”按“控制一个物体”理解：显示设备姿态和惯性估计位置，不把陀螺仪值当力推动任意刚体。首版采用带方向标记的3D物体，不给它额外叠加场景重力、摩擦、碰撞，以免与实际设备运动混淆。首版按位姿显示实现。

多设备按每台设备对应不同颜色物体实现，电脑和手机观察同一房间。各设备独立静置校准、原点和航向初始化；进入同一虚拟场景不代表获得真实世界中设备之间的绝对距离/朝向。

## 可以观测的量与限制

陀螺仪给出三轴角速度，位置需要三轴加速度参与积分。首版估计四元数、速度及位置，使用米、秒、弧度；界面角速度可显示度/秒。纯六轴惯性估计存在累积漂移，重力只能约束倾斜，不能提供绝对航向/绝对位置；不能许诺长期轨迹准确。

浏览器DeviceMotion提供的是平台处理后的高层数据，可能缺字段、限频/量化，事件时间并非曝光或IMU硬件时间。显示实际采样率、数据种类、缺样和相对时间；不宣称为Android原生未处理六轴数据。设备自然坐标为屏幕右/顶/外，横竖屏只改变页面布局，不能重复旋转物理传感器坐标。

低角速度、低加速度、低方差不保证真静止，匀速平移也可能满足。默认不自动清零速度，不用隐藏阻尼让物体假停稳；提供显式“已停稳”或可选“手持停稳假设”实验，启用时说明是假设，记录零速修正次数。死区可隐藏小运动，面板同时显示处理前/后数据及门限。

## 页面与输入

用户已确认右侧图形移动/旋转，并要求相机跟随虚拟设备位移，使设备始终位于视野内。每帧同步平移相机位置与观察目标，保持观察方向/距离；相机运动不参与六轴生成。拖拽开始保存交互相机快照，拖拽运算用固定相机，结束恢复当前相机，避免跟随造成射线反馈。该交互已按确认实现。

用户补充电脑界面分为左右两份。左侧为接收/估计场景，右侧为图形化六轴模拟器：通过操作虚拟设备产生运动，不填写角速度或加速度数值。左右各有独立视口和相机，桌面固定左右分栏；窄屏另做响应式排布。

左侧包含物体、坐标网格/轴、设备列表、六轴只读数值、轨迹、速度/位置和状态；选中设备跟随/自由观察，重置原点/航向/速度明确分开。右侧使用带XYZ平移/旋转手柄的虚拟设备交互，切换移动或旋转模式，通过鼠标拖拽设置运动目标。移动和旋转手柄交互已经用户确认。

拖拽目标经过有速度/加速度边界的连续运动模型形成设备真实轨迹，不能把鼠标位置跳变直接视作无限加速度。由位置/姿态的时间变化生成机体系三轴角速度及含重力加速度；六轴数值只读。噪声、固定零偏、随机游走、采样抖动/丢样由单独实验参数调节，使用可重复种子。提供可重复轨迹按钮辅助对照测试，主交互为虚拟设备操作。

右侧真值进入测量生成器后，加噪测量传给同一估计器，再更新左侧；左侧不能直接绑定右侧虚拟设备的位置/四元数。真值仅用于可选轨迹对照和误差计算，不用于纠偏。模拟器也可通过房间共享给其他观察设备。

模拟器与手机共用同一个纯算法模块。手机加入链接/房间，点击授权后开始采集；缺少权限/安全上下文/有效角速度或加速度时明确显示不可用，不把null转换为0。手机可轻量显示自己的控制与诊断，电脑显示全部物体。停止/后台/断流冻结最后有效姿态，不跨长间隔积分；恢复时明确初始化新时间段或要求重置速度。

## 零偏、噪声、姿态和位置

- 静置校准采集有限窗口，验证低角速度/低方差/重力模长，估计陀螺仪零偏、噪声和重力方向；移动则重试。仅一次静置不能把加速度零偏与重力/倾斜完整分离。
- 加速度六面校准使用设备各轴正负方向的静置均值，估计轴零偏/比例并检查各面对称性和方差；未完成时明确显示“未完成加速度六面校准”，不用估算值冒充精确标定。
- 扣除已估计零偏、世界线性加速度按采样dt滤波、可调向量模长死区；四元数积分角速度，仅静置校准或用户明确启用的停稳假设允许重力观测纠正倾斜；普通运动不进行该校正，不借用磁力计或DeviceOrientation航向冒充六轴效果。
- 含重力加速度经当前姿态转到世界坐标并去重力后积分；平台已去重力的线性加速度沿另一明确路径处理，避免二次去重力。速度/位置使用时间一致积分，屏幕布局旋转不改变世界坐标。
- 校准参数属于各输入设备的本地实验数据；首版由输入端设置并处理，再共享结果。没有控制端修改服务端运行参数，也不新增HTTP配置保存接口。后续若加入远端参数控制，必须走既有AASC/WebSocket权威配置规则。

## 多设备共享

新增独立Node测试服务，复用现有three/ws依赖，不接入正式显示端或APK。WebSocket房间分配设备ID/会话代次，每个输入端只发布自己的处理结果及六轴诊断，服务端规范化/限量广播、提供当前设备快照。不同客户端只用源端相对时间与本地接收年龄，不能把手机/电脑不同时间源相减来计算积分dt。

输入端共享`position/velocity/quaternion`及校准状态、原始/处理后六轴摘要；观察端只显示最新位姿，不再次积分。校准/死区/滤波统一发生在输入端，避免同一设备在不同观察端变成不同轨迹。模拟真值仅在源端作为可选对照对象，与估计结果分开显示，不通过房间广播。

房间用临时加入码，消息带type，服务端绑定设备所有者，拒绝跨设备覆盖和过期代次；断线设备保留冻结标识，重连明确新会话，房间空闲后清理。设备数、消息大小、发送率、轨迹点数有上限，慢连接不无限积压。

手机权限需要可信HTTPS/WSS入口；localhost用于电脑模拟。优先复用现有证书或代理入口，证书是否受手机信任需实测；本轮不修改生产代理或发布外网。对应启动参数属于测试服务启动配置，而非远端可配置运行参数。

## 交付与验证结果

启动：`npm run start:imu:six-axis-test`，默认HTTP端口8769，可用IMU_HOST/IMU_PORT调整；IMU_TLS=1读取IMU_TLS_KEY/IMU_TLS_CERT。现有localhost自签名证书不能当作手机可信HTTPS。Android本轮用ADB reverse tcp:8769 tcp:8769后的localhost可信上下文验证。

`npm run test:imu:six-axis-test`覆盖9项算法/轴向/相机测试、1项实际WebSocket测试、1项Chromium双视口真实鼠标拖拽及手机事件适配测试。理想三类运动14秒的自动断言：位置误差<1e-7m、姿态误差<1e-6rad；该结论仅适用于生成器的理想模型。噪声校准对照保留残余漂移，不宣称真实位置精度。

SM-N9500的Samsung Internet通过localhost真实采集：约60Hz、3.5秒208样本、静置校准成功；独立观察端收到70帧，最新样本计数205。实际传感器存在约0.1m/s²量级的重力残差，静置单面无法消除所有加速度偏差，六面校准及真实移动距离/轨迹比较另行现场验收。Android实测未注入模拟事件；自动浏览器手机测试使用事件注入，两者分别记录。

计算与资源有界：模拟100Hz、网络发布最多25Hz、面板约6.7Hz、每设备600轨迹点、每房间12源/24连接、全服务64房间、消息16KiB、空房间2分钟回收；这些是实现限制，不是手机帧率保证。校准与实验参数仅会话内保存。测试服务不含生产服务或APK更新，不新增生产依赖，不触发Offline出包状态。

## 2026-10-03 位置偏移排查（修复方案待确认）

用户反馈左侧计算位置有偏移。使用现有ImuSimulator/ImuEngine执行只读数值复现，关闭所有模拟噪声，连续1000个0.01秒样本；默认处理下纯旋转位置误差0.414024m、纯平移0.516630m、复合2.025530m。全部关闭处理时误差约1e-11m，说明额外偏移不能全部归因于传感器噪声。

单因素结果：只开滤波时旋转2.931954m/复合1.968081m；只开重力倾斜纠偏时纯平移0.494759m；默认处理关闭倾斜纠偏后纯平移降至0.001371m。现有角速度先低通再积分姿态，含重力测量仍取当前时刻，存在时序不一致；重力方向纠偏使用区间末姿态与模拟区间中点测量，且把部分真实平移加速度作为倾斜观测。默认未校准且开启零偏/噪声时，静置10秒也可累积2.840485m误差。

拟修改imu-engine.mjs，使姿态更新和重力扣除按同一测量时刻处理；重力对齐限于明确静置校准或显式停稳假设，运动中不持续把加速度当作重力方向。app.mjs/index.html相应明确滤波与校准状态，并为模拟器提供明确的理想/带噪实验初始状态；保持可调噪声、零偏与死区，不读取模拟真值纠偏。补充tests/imu-six-axis-engine.test.js及必要浏览器回归，使用默认处理参数复验纯旋转不产生明显平移、平移不被倾斜纠偏破坏，以及带噪校准后的残余误差。最终阈值需修复后实测，不提前承诺真实定位精度。

当前只排查与更新文档，未修改功能代码。具体偏移发生于静置、运动还是重置后已向用户询问；上述独立可复现缺陷可以先修。

## 2026-10-03 位置偏移修复完成

已按用户确认实施：姿态积分直接使用当前去零偏角速度及死区，不再单独低通角速度造成姿态相对加速度滞后；使用同一区间中点姿态去重力，再对世界线性加速度低通。普通运动关闭持续重力倾斜纠偏，仅静置校准或用户启用且满足停稳假设时对齐；假设路径也使用同一时刻姿态。静置校准对齐应用已有加速度偏置/比例，避免重新引入已标定误差。

界面明确世界加速度滤波及停稳假设下倾斜纠偏，新增“无噪声，保留当前处理”按钮：清除噪声、随机游走和旧标定并复位，保留用户处理参数；原理想基准仍关闭全部处理。默认带噪实验明确提示先校准。

10秒/100Hz同一无噪输入对照（默认处理）：纯旋转0.414024m→0m，纯平移0.516630m→0.001371m，复合2.025530m→0.015500m。默认种子带噪静置校准后10秒位置残差0.015926m；这只是固定模拟用例，非手机定位精度保证。未校准零偏仍累积；取消原有错误倾斜纠偏后，该固定未校准静置样例漂移从2.84m变为4.84m，不将错误纠偏的偶然抵消当作改善，不隐藏未校准限制。

改动：imu-engine.mjs、app.mjs、index.html、算法/浏览器测试；专用测试新增默认参数三类轨迹、带噪校准/已标定重力对齐，浏览器验证无噪按钮保留处理参数。独立测试页，不改变生产依赖或Offline产物状态。

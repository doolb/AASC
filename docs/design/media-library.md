# 媒体库功能设计文档

## 抖音精选试验（2026-11-12）

点击抖音来源首页时自动调用网页媒体会话打开精选页并读取可识别的真实推荐，不要求填写网址。网页媒体未运行时按需启动；启动失败、会话满或需验证时提示相应原因。仅将能确认 ID 的卡片视为推荐；选择推荐后打开对应网页获取视频地址，取得地址后试播，地址缺失时报告失败。真实 Android 网页访问与播放须在设备上验收。

## WebDAV、抖音和用户采集媒体（2026-11-11）

WebDAV 与本地、HTTP 和 SMB 并列为媒体库类型，使用 PROPFIND 读取目录、流式 Range 和可选写入，可连接 AList 挂载的网盘；跨域重定向不传递认证。抖音通过国内任务来源解析分享链接和流式下载，自动安装指定版本 yt-dlp（部分平台须手动指定），可配置 Cookie。油猴脚本从当前页视频标签、资源记录和结构化数据发现媒体，预览后发送至用户文件媒体源；服务端按站点和内容保存播放列表及下载文件。保存接口使用独立令牌，下载和播放限制公网 IPv4、固定 DNS 地址并逐跳检查重定向。M3U8 仅支持有限分段的无加密 TS 点播，先下载并使用 ffmpeg 转封装再播放。真实 AList、油猴安装及实际抖音 Cookie 待现场验收；公开抖音链接匿名测试返回需要新鲜 Cookie。

## 媒体源统一代理（2026-11-11）

B站、夸克分享及国内、国外、私密任务媒体源按来源选择命名代理；未选择时直连，选择后代理失败不自动直连。私密来源注册时不再按代理名称自动选择，已有逐源选择继续保留。服务端为 B站和夸克提供按请求读取来源代理的 HTTP 客户端；任务来源沿用各自受管任务的请求封装和独立进程代理传递。私密画廊的页面、图片与封面请求均实时读取当前来源代理。既有任务停止、Range、重定向校验和持久化广播行为保持有效。

## 代理与媒体用户配置（2026-11-11）

代理网络配置和媒体用户数据保存在运行模式对应的 userconfig.json，媒体库连接列表继续使用 userconfig 目录中的 media-libraries.json。保留现有配置接口和远端消息。旧主配置的 network、media 按顶层字段迁移，已有用户字段优先；用户配置保存成功后才删除旧值，失败时保留旧值并允许重试。

## 功能概述

媒体库功能为用户提供统一的媒体资源管理能力，支持多种存储后端（本地磁盘、HTTP远程服务器、SMB网络共享），用户可以在控制端查看、上传、删除和预览媒体文件。

控制端发送远程媒体或播放列表时，为每项保留 `sourceNodeId`、`sourceLibraryId` 和 `sourcePath`。主服务器使用来源节点的注册地址生成直连地址，并保留同源代理回退地址。子服务器注册完成或地址变化后，主服务器可以按来源节点找到正在播放的媒体并重发既有正常播放消息；显示端不需要处理子服务器状态。

## 安全设计

1. **路径遍历防护**：验证所有路径参数，禁止 `..` 跳转
2. **权限控制**：readonly 标记防止误删远程资源
3. **密码加密**：SMB 密码加密存储
4. **文件类型验证**：限制上传文件类型
5. **访问代理**：HTTP/SMB 资源通过服务器代理，避免暴露凭证
6. **混合内容规避**：服务器 HTTPS 时保留 http:// 媒体直连地址作为首选，并附加同源 /api/media-proxy 备用地址；浏览器/WebView 直连失败后才尝试代理。代理做 SSRF 基础防护（禁本机/回环/云元数据，内网媒体放行）

### 2026-08-17 HTTP 媒体混合内容修复 + Range 流

**背景：** 服务器启用 HTTPS（res/certs）后，显示端页面为 https://...:8081/display，加载 http:// 媒体子资源被浏览器/WebView 混合内容策略拦截——手动输入 http:// 媒体地址无法播放，HttpProvider 媒体库（mnt/mnt2）同理。

**方案：**
1. **显示端媒体统一规范化**：初次下发与连接恢复都保留原 URL 为首选；HTTPS 页面只把原始 HTTP URL 加入 `fallbackUrl`，代理只在浏览器/WebView 加载失败后启用
2. **通用代理端点 `GET /api/media-proxy?url=`**：流式转发上游 + Range 透传（relay 206/200 + Content-Range）+ 15s 超时 + SSRF 基础防护（禁本机/回环/云元数据，内网媒体放行，因媒体库本身即内网资源）
3. **HttpProvider.getPublicUrl** 改同源 HTTPS 库代理 URL（`/api/media-libraries/{id}/proxy/{path}`，与 SmbProvider 一致），媒体库控制端预览/播放不再被拦
4. **库代理端点支持 Range**：本地/SMB 有精确 size → 解析 Range 走 206；http 库 size 未知回落全量（不回归）
5. **超时**：HttpProvider._fetchHtml/getFileStream 加 8s 超时，修 192.168.1.101 不可达时 init 挂死（此前卡 SYN-SENT 2-3 分钟、8081 不监听）
6. **_parseHtml 垃圾过滤**：剔除 fancy-index 表头排序链接（Name/Last modified/Description/Parent Directory）误当媒体项

**范围约定：** 各 Provider getFileStream(path, range) 统一返回 `{ stream, statusCode, headers }`（无 range 200 整流 / 有 range 206 切片），供 proxy 端点 setHeader。

### 2026-08-17 http 媒体库获取文件大小 + 批量播放视频 seek

**背景：** HttpProvider 的 list/getFile 不返回 size（fancy-index 目录列表只有人类可读大小如 `531M`，无法精确还原字节），控制端媒体库不显示真实文件大小；库代理端点 Range 解析依赖 `getFile().size`，size 未知时恒回落 200 全量，批量播放视频拖动进度条会重新全量下载。

**方案：**
1. **HttpProvider._fetchHead(url)**：HEAD 请求取 `Content-Length` + `Last-Modified`，8s 超时，失败/非 200 返回 null（回落 0，不阻塞）
2. **HttpProvider.getFile**：调 _fetchHead 填 size + modifiedTime
3. **HttpProvider._fetchList**：收集媒体文件（image/video/gif/html）后小并发池（6）发 HEAD 补 size，文件夹不 HEAD；单文件失败回落 0
4. **MediaLibraryManager.getFile(libraryId, filePath)** 委托：修复 proxy 端点此前调 `mediaLibraryManager.getFile` 抛错被 `catch(e){}` 静默吞掉、Range 恒 null 的隐藏 bug

**效果：** 控制端显示真实大小；库代理端点 Range 可解析 → 批量播放视频 seek 返回 206 分段，不再全量重下。

### 2026-09-05 Termux storage 符号链接目录列举修复

**问题：** Termux 执行 `termux-setup-storage` 后，`~/storage` 及其下级目录通常是符号链接。LocalProvider 使用 `lstat` 读取链接自身属性，导致目录链接被识别为文件，控制端无法继续进入并列出目录。

**方案：**
- `LocalProvider.list` 先使用 `lstat` 保留符号链接和断链识别，再对符号链接使用 `stat` 获取目标的真实属性。
- 目标不存在的断链继续跳过；有效目标按真实目录或文件返回，保持现有路径校验和隐藏文件过滤。

**验收：**
- 符号链接目录在根目录列表中返回 `type=folder`、`mediaType=folder`。
- 通过符号链接继续列举目标目录时，可以返回其下级目录。
- 回归测试覆盖 Linux 目录符号链接，并在 Windows 使用 junction 兼容执行。

### 夸克网盘分享

支持通过分享链接和可选提取码添加只读媒体库，浏览分享的多级目录并展示夸克提供的图片预览。预览可能不是原图；视频通过账号态接口获取免转存直链并由服务端代理播放。分享失效、提取码错误或上游接口变更时显示错误，不转存或修改网盘文件。

### 夸克分享独立标签

媒体库增加夸克分享标签，集中列出主服务器和子服务器已有的夸克库，不迁移或复制其配置。顶部可粘贴分享链接或含提取码的分享文字，选择加入或播放；支持手动补充提取码，链接已加入时直接复用。播放继续使用既有逐目录扫描能力，支持视频代理。

### B 站视频链接

URL 上传支持 B 站 BV 视频页链接，保留多 P 分集并交给官方外链播放器。播放由显示端 iframe 执行，自动播放、登录和观看权限受 B 站及浏览器策略限制；现有视频进度、远程暂停及视频列表能力不适用于该跨域播放器。

### B 站视频标签

媒体库中增加独立“B站视频”标签，提供 BV 链接输入、加入与播放；列表持久化并同步到各控制端，展示视频标题和封面，元数据获取失败时使用 BV 号及占位图。允许删除列表条目；多 P 分集作为独立条目。播放优先使用原生流，失败时使用官方外链播放器；暂不支持短链接，回退后跨域播放进度不可控。

### B 站视频原生流播放

参考本地 B 站下载器的分集与播放地址解析，优先对公开 BV 视频请求单文件音视频 MP4，通过受限服务代理分段播放，复用现有视频暂停、拖动与进度。无单文件流、上游错误或显示端加载失败时回退官方外链播放器。匿名清晰度由 B 站决定；DASH 高画质与账号登录不属于本次范围。

### B 站匿名 480P

优先使用 B 站匿名接口的 480P H.264/AAC DASH 分离音视频，通过服务端受限代理和本地 dash.js 合并到显示端单一播放器。播放器不支持或出错时降级到 360P MP4，再降级到官方外链。加载和拖动按需分段，不下载完整视频；清晰度和视频权限受上游限制。

### 夸克视频和分享分类文件夹

移动分享时使用 HTML 弹窗列出“未分类”和当前来源的文件夹，并预选该分享当前分类；用户直接选择后确认，取消不发送消息。B 站和夸克共用交互，沿用现有 WebSocket 权威保存与广播；目标被删除或连接断开时提示用户。弹窗适配浅色和深色主题及窄屏。

夸克分享的视频通过已配置的账号 Cookie 获取免转存直链，由服务端代理 Range 数据供显示端播放；凭证不发送给浏览器，失败时不转存。夸克与 B 站标签使用分别管理的文件夹，支持创建、进入、移动链接和删除空文件夹；旧链接保留在未分类，分类信息保存在服务端并同步到控制端。

夸克 Cookie 可从控制端配置并保存在服务端配置中，或由服务端进程环境提供；快照和配置查询不返回凭据。

### 夸克视频完整缓存后播放

夸克视频先在媒体库所在服务端完整下载至受管缓存，再向显示端切换；正在等待时保留当前媒体，单次请求失败不替换画面。批量播放逐项等待且忽略过期结果。完整缓存支持 Range，合并同视频的并发任务，不保存不完整内容；服务器最多缓存两个视频，单个文件不超过 300 MiB，同一时间只下载一个视频，其他任务排队。夸克和 B 站链接卡片提供复制链接入口。

夸克视频缓存的排队、已接收字节、总字节与百分比实时显示在控制端设备列表上方；单项和批量播放均支持。缩略图独立读取夸克分享返回的 thumbnail，并经媒体库所在服务端转发，不触发视频完整缓存。

### 夸克视频卡片缓存进度

夸克视频缓存时，在对应视频缩略图底部显示状态和进度条；单视频和显示端批量缓存共用标识与展示。以服务器、媒体库、文件路径匹配，避免同名文件混淆。完成或失败后短暂显示结果；取消或切换视频清除旧状态。

### 夸克分享下载

夸克分享的文件卡片提供下载，保存原文件到操作控制端的设备。通过同源代理或远程子服务器代理取得夸克原文件并流式传输，不转存网盘；支持 Range，下载不占用播放缓存及其 300 MiB 限额。下载依赖服务端已配置的夸克登录态。

### 夸克目录下载到本地媒体库

夸克目录可递归下载到用户选定的主服务器可写本地媒体库，新下载在目标库的“夸克分享/<分类>/<来源hash>”下隔离并保留源路径，旧“夸克下载”目录与记录保持兼容；不覆盖已有文件。索引记录来源与本地地址，单项或批量播放通过主服务器代理优先使用已下载文件；文件不存在时回退原有夸克流程。重复下载时跳过来源未变的完整文件；更新文件以新文件名保留，已完成部分在中断后仍可用。目录遍历仍需访问分享，下载不会自动同步源端变化。

### B 站搜索与本地下载

B 站标签支持匿名视频搜索、分页和将结果播放或加入分类。视频、分集及公开收藏列表可下载到选定的主服务器可写本地媒体库；下载优先获取匿名 480P DASH 音视频并通过 ffmpeg 无转码合并，无可用 DASH/ffmpeg 时回退匿名单文件 MP4。下载映射按 BV 和分集记录，单项与新建批量列表优先读取本地文件；已保存的文件不覆盖，任务逐项串行。

### 用户任务媒体源

服务型用户任务可注册命名媒体源工厂；运行中的每个来源直接成为顶部页签，并使用任务参数或来源默认配置进行浏览和播放。已有任务媒体库的配置优先复用；服务停止或启动失败时撤销注册并移除页签，保留已有配置供任务恢复后使用。示例任务 `local-only.web-manifest` 将网页 JSON 媒体清单接入，其他网页可通过编写新任务解析；现有夸克和 B 站逻辑保持原有入口。

本地专用任务放在 `res/tasks/local-only/<名称>`，任务列表以 `local-only.<名称>` 显示；APK 任务种子与独立任务代码包排除整个目录。本地任务可像其他用户任务一样创建服务实例和编辑，且不进入 release。

### 任务媒体页签、红果和 B 站播放

红果多集浏览：剧集页按公开页面的同剧集分集链接显示所有已列分集；逐页确认公开播放地址，未公开或暂时无法读取的集显示不可播放且不可下载。只读文件目录仅提供可播放的集，不推测应用内部接口或媒体地址。

每个运行中的用户任务媒体源单独显示顶部页签，媒体库仍复用已有目录浏览。红果以可发布的服务任务注册，浏览首页推荐剧集或指定剧集，只提供网站结构化数据明确公开的 360P 视频；网站未公开的剧集和时长不作可用承诺。B 站允许配置 Cookie，使用账号允许的最高兼容 AVC 画质，Cookie 不发送到视频 CDN。搜索卡片可复制链接。

B 站 DASH 轨道兼容主地址不可用的情况：从 B 站返回的备用 CDN 中选择符合既有域名、HTTPS 和端口限制的地址。

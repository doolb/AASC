# 控制端主题与 UI 控件分类设计

## 需求

控制端当前混用硬编码颜色、多个按钮样式和动态生成控件，需要支持深色/浅色主题切换，并按 UI 交互职责建立统一分类，便于后续维护和扩展主题。

## 方案

使用浏览器端 `UiTheme` 管理器：

1. 从 `localStorage.controlTheme` 读取主题，缺失或非法时使用 `dark`；主题清单包含 `dark`、`light`、`warm`、`pink`、`lavender-yellow`、`red-blue`、`gold`、`mint`、`ocean`、`forest`、`slate`、`algae-salt`、`girl-pink`、`rose-gold` 和 `new-year-red`。
2. 在 `<html>` 上设置 `data-theme`，CSS 变量负责全局颜色和组件状态。
3. 设置面板提供主题选择框，变化后立即应用并保存。
4. 初始化时为已有和后续动态插入的元素补充 `data-ui-type` 语义标记。
5. 主题只作用于控制端页面，不增加服务端 API 或 WebSocket 消息。

## 分类边界

原生交互类型包括按钮、文本/数字/时间/密码输入、文件选择、单选框、复选框、下拉框、文本域和滑条；项目 UI 类型补充标题、Tip、导航、开关、弹窗、状态/徽章、进度和 Toast。颜色、尺寸和危险/禁用状态作为样式变体。

## 兼容性

保留现有元素 ID、内联事件和模块初始化顺序；旧浏览器忽略未识别的 `data-*` 属性时仍使用默认深色样式。主题持久化失败不阻断页面初始化。

## 浅色主题文字兼容

浅色主题将弹窗、任务确认框和媒体库等容器设置为浅色背景时，必须同步覆盖旧组件中写死的白色标题、正文、下拉选项和动态内联文字。覆盖规则不应影响有色按钮上的白色文字，以保证按钮对比度。

## 浅色主题卡片与弹窗配色

卡片与弹窗使用独立的语义变量。浅色主题统一采用低饱和浅蓝色 `#eaf4ff`，降低大面积纯白带来的刺眼感；卡片使用 `card-background`，弹窗使用 `bg-surface-strong`，保留层级语义。深色主题保持原有半透明深色效果。

## 浅色主题内容区域对比度

显示设备列表、聊天消息和日志内容区使用独立的 `content-background` 与主题文字色。设备名、助手消息和普通日志文字使用深色主题色；用户消息、错误/警告级别和操作按钮保留各自的强调色，避免信息语义丢失。

## 浅色主题开关与路由选中态

浅色主题下，原生复选框/单选框使用当前主题强调色；控制端自定义 toggle 的关闭态使用浅灰轨道、边框和深色滑块，开启态使用主题强调色轨道与白色滑块。设置页天气/搜索的 LLM 与系统路由按钮通过 `active` class 表示选中项：未选中使用浅色背景和次要文字，选中使用主题渐变、白字和强调色外框。路由按钮保留深色主题原有内联背景兼容逻辑。

## 显示控制状态控件

显示控制面板中的画面填充、裁剪旋转和中心缩放等互斥/开关按钮统一使用 `active` class 表示当前状态；主面板和浮动控制面板的画面填充按钮均适用。浅色主题下未选中项使用浅色背景与边框，选中项使用主题强调色渐变与外框。播放按钮按 `playing`/`paused` 状态分别使用成功色/危险色，避免播放状态被通用浅色按钮渐变吞掉。

## 控制端其他状态按钮

语音识别设备和语音生成设备按钮使用 `data-asr`/`data-tts` 标识选项，并由运行时同步 `active` class；自动播报、文本播放和批量播放按钮分别同步 `active` 或 `playing`/`paused` 状态。设备列表的单选/全选/自适应按钮、日志筛选和自动滚动、任务选项、聊天页签、媒体库当前项等已有状态 class 的控件，统一使用浅色主题的中性未选中态和强调色选中态。状态 class 只负责表现，不改变原有业务状态和事件。

## 多主题配色

在统一的浅色组件规则之上提供多套低饱和配色：暖黄、淡粉、淡紫黄、红蓝、尊贵金、薄荷青、海洋蓝、森林绿、极简灰、藻盐、少女粉、玫瑰金和新年红。藻盐主题使用盐白背景与藻绿强调色；少女粉主题提高粉色明度和饱和度，突出甜美、活泼的视觉效果，与柔和克制的淡粉主题区分；玫瑰金主题使用香槟白与粉铜色，新年红主题使用暖白、节庆红和深酒红。每套主题只替换背景、卡片、内容区域、文字、边框、输入框、强调色和阴影变量，设备名、聊天消息、日志、卡片及弹窗继续复用相同的可读性规则。按钮渐变从主题强调色变量生成，确保切换主题后交互控件仍保持清晰的前景色。

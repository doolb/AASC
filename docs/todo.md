# Web MediaCenter - 未完成任务列表

## 功能完善
- 添加纯语音输入和输出的显示端，
  - 支持服务端热重启客户端
    - 服务端监听go编译的文件变化
    - 当go编译的文件变化时，服务端会发送信号给客户端，客户端会重新加载go编译的文件
    - 客户端收到信号后，会重新加载go编译的文件，实现热重启效果

- 添加子服务器功能，
  - 子服务器用nodejs 运行子服务器分发器，选择相应的子服务器，运行子服务器代码
  - 服务端可以热更新子服务器代码，自动重启子服务器进程
  - 子服务器进程可以独立运行，互不干扰，可以运行在不同设备上
  - 子服务器进程可以独立配置，如模型路径、端口号等
  - 当前需要的子服务器有：
    - 媒体库子服务器，可以上传视频、音频等文件，并用http 接口提供下载
      - 会自动加载到媒体列表中，用户可以在控制端查看和播放
    - 语言识别子服务器，可以识别语音输入，将识别结果发送给服务器进行处理
  - 子服务器的代码是独立,不需要完整的服务端代码
  - 子服务器支持不同编程语言, 如go
  
- 添加显示端语言识别功能，
  - 使用sherpa-onnx-wasm
  - 可以在控制端切换语音识别的处理设备，如服务端，显示端
  - 如果在显示端进行语音识别，服务端要先把语音发送到显示端，再进行识别，再发送结果给服务器进行处理

- 静音判断参考ttslive 静音判断逻辑

- 要视频90度和270度宽高切换
  - 比如，0度从左到右横向显示右上角， 90度从上到下竖向显示右上角， 180度从右到左横向显示右上角， 270度从下到上竖向显示右上角

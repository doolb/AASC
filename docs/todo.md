- 添加子服务器功能，
  - 子服务器用nodejs 运行子服务器分发器，选择相应的子服务器，运行子服务器代码

  - 子服务器进程可以独立运行，互不干扰，可以运行在不同设备上
  - 子服务器进程可以独立配置，如模型路径、端口号等
  - 当前需要的子服务器有：
    - 媒体库子服务器，可以上传视频、音频等文件，并用http 接口提供下载

    - 语言识别子服务器，可以识别语音输入，将识别结果发送给服务器进行处理
  - 子服务器的代码是独立,不需要完整的服务端代码
  - 子服务器支持不同编程语言, 如go

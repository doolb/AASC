## 功能完善
  
- 在framework里添加一个以聊天形式的日志系统
  - 参考aasc的层级，物理设备是房间，actor是工作者
  - 可以在控制端查看日志
  - 所有日志都有一个源头
  - 日志分级  info, warn, error, debug
  - 可以在控制端切换日志分级
  - 日志有单聊和群聊两种模式
  - 单聊，只曲士和actor自己相关的日志窗口
  - 群聊，需要和其他actor共同工作的日志窗口，需要有引用关系
    - 比如，用户在控制端点击按钮，发送给服务端，服务端再发送给显示端，显示端再显示，以及服务端再发送给显示端回控制端的消息过程，都需要在日志里记录
  - 消息日志在viewbind处理，隐藏实现细节

# Web MediaCenter - 使用说明

## 1. 快速开始

命令行调用服务器 API 的完整说明见：[API 使用与命令行工具](api-usage.md)。

### 1.1 安装依赖

```bash
cd web-mediacenter
npm install
```

### 1.2 启动服务器

```bash
npm start
```

服务器启动后会显示访问地址：

```
==================================================
媒体中心服务器已启动
==================================================
上传端地址: http://192.168.1.39:8081/upload
显示端地址: http://192.168.1.39:8081/display
==================================================
```

### 1.3 访问界面

- **控制端**: 在浏览器中打开 `http://<服务器IP>:8081/upload`
- **显示端**: 在显示设备上打开 `http://<服务器IP>:8081/display`

## 2. 控制端使用

### 2.1 上传文件

1. 点击 **"选择图片/GIF"** 或 **"选择视频"** 按钮
2. 选择要上传的文件
3. 文件会自动上传并发送到当前选中的显示端

### 2.2 URL 发送

1. 在 URL 输入框中输入图片或视频的 URL
2. 点击 **"发送"** 按钮
3. 媒体会发送到当前选中的显示端

### 2.3 服务器资源

- 显示已上传的所有媒体文件
- 点击 **"播放"** 发送到显示端
- 点击 **"删除"** 删除文件
- 点击 **"刷新"** 更新列表

### 2.4 显示端选择

- 显示所有已连接的显示端
- 点击选择要控制的显示端
- 显示端信息包含 IP 地址和屏幕尺寸

### 2.5 显示控制

#### 画面填充

| 按钮 | 效果 |
|------|------|
| **适应** | 媒体完整显示在屏幕内，保持比例 |
| **高度铺满** | 媒体高度填满屏幕，宽度自适应 |
| **宽度铺满** | 媒体宽度填满屏幕，高度自适应 |
| **裁剪** | 媒体铺满屏幕，可通过裁剪框选择显示区域 |

#### 视频播放

- **播放/暂停**: 控制视频播放状态
- **进度条**: 拖动调整播放进度
- **音量**: 调整音量大小

### 2.6 画面裁剪

1. 选择 **"裁剪"** 填充模式
2. 在预览区域拖动裁剪框调整位置
3. 拖动裁剪框四角调整大小（等比缩放）
4. 点击旋转按钮预览旋转效果
5. 点击 **"重置裁剪"** 恢复默认

**注意**: 裁剪框比例与显示端屏幕比例一致，只能等比缩放。

## 3. 显示端使用

显示端语音会话的详细使用说明见：[语音三种会话状态](usage/voice-conversation.md)。

正式 Android 显示端的 OCR/YOLO11n 通过控制端任务面板调用；任务会请求服务器视觉接口，再由服务器转发给显示端本地推理。

正式 APK 的 ASR、TTS、声纹、RapidOCR、YOLO 和降噪模型均按需从服务器下载并缓存在 APK 私有目录，安装包不携带模型；服务器模型清单和准备命令见：[正式 Android 统一模型分发](design/android-model-distribution.md)。

普通聊天 Agent 后端的配置和会话规则见：[普通聊天 Agent 后端](usage/llm-agent.md)。

### 工作 AI 角色

控制端聊天助手会自动显示已保存到 `ai-roles` 的工作 AI 角色。点击角色列表末尾的“+”，打开“选择工作 AI 角色”窗口，窗口只提供列表选择，会列出当前 `workgroup/members` 下的成员目录、主/副角色标记及角色/历史文件状态，不提供手动输入角色名。弹窗会跟随当前控制端主题调整文字、背景和按钮颜色。

点击“选择”后，系统使用成员目录名创建工作 AI；已存在的角色会标记为“已添加”，不会重复创建。工作 AI 首次使用时才启动 Agent，角色对话历史仍独立保存。

### 3.1 连接状态

- 左上角显示连接状态
- **绿色**: 已连接
- **红色**: 未连接/连接错误

### 3.2 快捷键

| 快捷键 | 功能 |
|--------|------|
| `F` | 切换全屏模式 |
| `空格` | 播放/暂停视频 |
| 点击视频 | 播放视频（如果暂停） |

### 3.3 显示信息

- **右上角**: 当前时间
- **左下角**: 当前播放的文件名

### 3.4 Android 显示端时间同步

当 Android 显示端时间明显不正确时，可以通过 ADB 将其同步为主机当前时间。先确认设备已连接：

```bash
adb devices
```

关闭自动校时后，使用 Android AlarmManager 设置主机时间（`date -s` 在普通 ADB shell 下可能没有设置系统时间的权限）：

```bash
adb -s <设备序列号> shell settings put global auto_time 0
host_millis=$(date +%s%3N)
adb -s <设备序列号> shell cmd alarm set-time "$host_millis"
```

同步后检查 Android 时间和时区：

```bash
adb -s <设备序列号> shell date
adb -s <设备序列号> shell date +%s
adb -s <设备序列号> shell getprop persist.sys.timezone
```

应确保 Android 与主机处于同一时区（例如 `Asia/Shanghai`），并且两端 Unix 时间戳相差不超过几秒。

## 4. 使用场景

### 4.1 单屏展示

1. 在显示设备上打开显示端页面
2. 在控制设备上打开控制端页面
3. 选择显示端，发送媒体

### 4.2 多屏同步

1. 在多个显示设备上打开显示端页面
2. 在控制端选择不同的显示端
3. 分别发送媒体到各个显示端

### 4.3 投屏演示

1. 将显示端页面投屏到大屏幕
2. 使用控制端控制媒体播放
3. 实时调整画面效果

## 5. 常见问题

### Q: 显示端列表为空？

**A**: 确保：
- 显示端页面已打开
- 显示端与控制端连接到同一服务器
- 网络连接正常

### Q: 视频无法自动播放？

**A**: 浏览器安全策略可能阻止自动播放，点击视频区域或按空格键手动播放。

### Q: 裁剪框位置不对？

**A**: 
- 确保显示端已正确连接
- 检查显示端屏幕尺寸是否正确显示
- 尝试重置裁剪

### Q: 文件上传失败？

**A**: 检查：
- 文件大小是否超过限制
- 服务器磁盘空间是否充足
- uploads 目录是否有写入权限

## 6. 网络配置

### 6.1 局域网访问

服务器默认监听 `0.0.0.0`，可从局域网任意设备访问：

```
http://<服务器IP>:8081/upload
http://<服务器IP>:8081/display
```

### 6.2 端口配置

通过环境变量修改端口：

```bash
PORT=3000 npm start
```

### 6.3 防火墙

确保防火墙开放服务器端口（默认 8081）。

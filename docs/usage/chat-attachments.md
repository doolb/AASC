# 聊天附件与自动回收

控制端和显示端聊天输入框点“📎”，选择文本文件、图片或视频，等上传完成后发送。可以只发附件，也可加文字；发送前可点×移除。每条最多4个附件，文本1MiB、图片20MiB、视频100MiB。文本支持TXT/MD/LOG/CSV/JSON；图片PNG/JPEG/GIF/WebP；视频MP4/WebM/MOV。文件会保存在聊天历史中，文本有下载链接，图片/视频可直接查看。

LLM配置中图片上传默认允许，视频上传默认关闭。需要视频输入时先开启对应配置；目前Chat2API原始视频理解支持GLM，已实测识别与续聊。豆包/Qwen当前会明确提示不支持，不会静默只发文字。其他LLM服务需提供/chat/files文件扩展；没有该接口会报错。Agent聊天入口暂不支持附件。

清空聊天、删除轮次或历史淘汰后，服务端自动清理无引用的受管图片、视频、封面与文本。其他会话、显示中的媒体、媒体库及保留历史快照仍引用时保留。备份为上海时区每日一份，由跨日后的下一次保存等操作轮换，不是固定24小时到期。未发送草稿保留24小时；正在生成且未入历史的文件有在途保护。刚写入文件至少保留60秒，回收防抖并每10分钟补扫。

历史或备份读失败时停止删除，服务日志会提示。只裁剪发给AI的上下文不会删聊天或媒体。以上行为需部署包含本次修改的服务包并刷新网页；本轮尚未构建发布。

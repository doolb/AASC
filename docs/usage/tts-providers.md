# 语音服务与音色

在控制端「声纹」页面展开「语音服务与音色」。AI / Agent 回复、文本阅读、报时与系统播报分别选择服务和音色，点击「保存语音配置」，等待服务器确认。其他控制端会同步保存后的值；断线重连后重新获取配置。

默认沿用系统原生 TTS，云端服务默认关闭。展开对应服务设置，启用并填写凭证、模型、默认音色与参数。Qwen API 填百炼 API Key，豆包 API 填 API Key 和匹配音色的资源 ID。目录提供音色候选，也可以手工填写有效 ID；查询失败或目录没有当前 ID 时会保留配置，在合成时验证权限。

国内千问网页服务仅用于 AI / Agent 回复。凭证填写国内 www.qianwen.com 的 Cookie 内容（可含 Cookie: 前缀）或登录 ticket，服务器需有 Puppeteer 可用的 Chrome。用户提供的聊天链接用于确认国内站点，链接本身不能代替登录凭证。网页登录凭证过期、签名接口变化或 Chrome 不可用时会明确报错；不会自动切换为其他服务。

凭证留空可保留服务器已保存值，勾选「清除已保存凭证」才删除。页面只显示是否已配置，保存后清空输入框。业务选择存主配置，凭证和服务参数存用户配置，不存聊天模板。

聊天模板中的「AI 回复 TTS Provider」可以选择「继承系统 AI 默认」或单独指定服务。空音色仅继承相同服务的业务默认音色，切换服务时使用该服务自己的默认音色。群聊使用 AI 默认，临时会话使用当前角色模板。旧控制端编辑其他模板字段时保留已有 TTS 设置。

语速范围 −10 至 10，音量范围 0 至 100。系统服务端与豆包/国内千问使用各自的生成语速；系统显示端与 Qwen API 采用 PCM 重采样调整速度，会同时改变音高。显示端原生合成使用当前已加载的离线音色，服务端使用所选音色。调低音量在完整音频进入缓存前处理。

Qwen API 单次最多 600 字符，较长回复沿用现有分句；若单句仍超长则报告错误。每段完整音频最多16MiB，云端生成默认总超时60秒。不会保存临时音频文件。真实账号合成、声音质量和设备延迟仍需现场验收，当前服务代码包待构建发布。

# 五子棋

在当前显示端的对话中说“我们来玩五子棋”，AI 会根据你的意思调用开局指令，显示端出现全屏棋盘。服务端只在收到 AI 的指令后创建棋局。默认 15×15；也可说“用 9、11 或 13 路棋盘开始”。用户执黑先行，五子及以上获胜。

说“下在 H8”或“我下 A一”，AI 会代用户调用游戏协议。也可以直接点击棋盘交点：棋盘确认后，AI 会收到这步并选择白子的下一手。坐标从左上角 A1 开始，列字母包含 I。

点击“关闭”只隐藏棋盘，不删除棋局；左下角“五子棋”可重新显示。断线重连后会恢复棋盘。中途调整棋盘尺寸时，AI 先提出新尺寸，用户明确确认后清盘并沿用原棋局 ID。

当前是项目内的位置参数游戏协议，不是独立的标准 MCP 服务。服务代码包待构建，Android 真机体验待验收。

在当前在线显示端看模拟一轮：先确认显示端已加载包含五子棋 UI 的新版服务代码，再在服务端机器运行 `npm run demo:gomoku-ui`。只有一个在线主显示端时自动选择；多个显示端时运行 `npm run demo:gomoku-ui -- --display-id=显示端ID`。默认 15 路，也可加 `--size=9`。黑子和白子会依次显示，棋盘一直保留到按 Ctrl+C；退出时恢复原棋盘。脚本按本机证书自动选择 `ws` 或 `wss`，默认端口 8081；端口不同可设置 `AASC_GOMOKU_SERVER_URL`。演示不发送测试聊天消息，不调用 AI，也不修改实际棋局。

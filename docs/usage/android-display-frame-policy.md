# Android显示页帧率与APK系统栏

Android显示网页的JS RAF动画统一限制为60 FPS上限，覆盖当前显示文档中的MMD/VRM、音频监视等RAF循环。通过Android UA或APK的NativeDisplay桥识别，桌面网页使用原浏览器调度。动画收到的仍是真实浏览器时间戳，不人为减慢动作或音频时钟；实际FPS受设备性能影响。

APK向系统请求当前分辨率下约60Hz的窗口模式；没有对应模式时只提交60Hz偏好，不切换物理分辨率。此项取决于系统/显示器是否接受，不代表强制全机刷新率。CSS动画、视频解码和跨源iframe自身的时钟不由当前文档RAF调度器限制。

| APK类型 | 系统栏 |
|---|---|
| Offline min / 完整Offline | 显示状态栏与导航栏，关闭沉浸；首屏、重连、焦点/配置恢复统一应用 |
| 普通noserver / withserver | 保留沉浸模式 |

JS调度可随服务代码包更新；系统栏和原生刷新偏好首次需更新APK。当前仅源码完成、标记服务/min待出包，未构建发布或完成真机帧率/系统栏验收。

# 正式显示端全身 IK

更新服务代码并刷新正式显示端，在角色工具栏点击“全身 IK”，再点“启用全身 IK”。需要已加载PMX模型；默认关闭，首次启用按需加载现有Ammo资源。VRM不提供此功能。

- 拖动彩色控制点调整头、手、肘、膝、脚、胸或骨盆；空白处沿用IK镜头操作。
- 位置和旋转状态：On牵引，Hold保持且不允许直接改目标，Off释放，Comply受力让步。目标世界旋转以度输入。
- 牵引强度默认0.85；可调全局/分部位阻尼。重力默认关闭，骨盆默认固定；自由骨盆允许身体受力移动与转动。
- 控制点大小默认32px，可在20–48px调整。
- “收起”只隐藏面板；“重置控制点”释放目标但保持IK启用；“关闭全身 IK”释放人体物理并恢复原动作。
- IK初始化和启用期间暂停自动对话动作；中断的生成动作不存候选。关闭后恢复自动动作能力。音频播报不受此门禁影响。
- 切模型、隐藏角色/页面及销毁时清理IK。设置只在当前页面会话生效，不新增远端配置。

当前迁移手动交互及身体物理，不含图片识姿、HMR或深度推理。AI动作仍使用MPL；AI语义IK目标接口待后续设计。人体碰撞使用简化形状，不能保证任意姿态不穿模；实际手机性能和非标准PMX需现场核对。

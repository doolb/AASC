# 正式显示端全身 IK

更新服务代码并刷新正式显示端。PMX角色就绪后默认初始化身体物理IK，无需先点启用；右侧“全身 IK”打开设置。VRM没有此身体求解能力。

- 身体预设、旧MPL/VMD和随语音动作采样转换为IK目标；新动作SubAI直接生成目标轨迹。表情与口型保持Morph，服饰继续原PMX物理。
- 后台默认不显示彩色控制点，打开IK面板进入编辑后显示；拖动控制点调整头、手、肘、膝、脚、胸或骨盆；空白处沿用IK镜头操作。
- On牵引，Hold保持且不允许直接改目标，Off释放，Comply受力让步；旋转输入为度。只有活动手动目标接管才暂停自动身体动作，Off/重置后恢复。
- “重置控制点”释放手动目标并保留求解器；“关闭全身 IK”释放人体物理并暂停身体动作，不回退旧身体输出。聊天、TTS及Morph继续。
- 牵引强度默认0.85，重力默认关闭、骨盆默认固定，支持全局/分部位阻尼；控制点默认32px（20–48px）。
- 隐藏或换模型会清理资源；返回前台或新模型就绪后，未手动关闭的求解器重新初始化。页面会话中的显式关闭选择保留。

目标以绑定姿态、模型局部轴和身高归一描述，由求解器处理限位、碰撞和惯性。当前提供11类身体目标，不新增指趾独立控制点；身体约束是简化人体代理，复杂姿态效果需要实际预览。旧动作可能因限位和碰撞改变表现。

内置28类动作直接使用IK目标编排。比心/拥抱先抬手再移至胸前，敬礼控制手和肘的位置与掌向；每轮缓起缓收。时长为整次总时长，重复次数在该时长内完成；过快时会缩小幅度并提示。强度为0时不接管身体。当前没有精细手指IK，“比心/赞同”等手势主要表达手臂与手掌位置。

查看内置动作代码会得到与播放一致的IK JSON，下载为`.json`；用户保存的MPL代码、VMD和独立实验页沿用原行为。缺少对应骨骼时显示能力警告，不会写动态刚体骨骼。

动作生成器仍需在“模型 → 动作 SubAI”中配置并启用“缺库时生成动作”；IK默认开启不替你启用Provider或更换模型。完整播放后的候选操作见[AI对话动作](sub-ai-actions.md)。本次不涉及Android原生代码，正式生效需要更新服务包并刷新页面；Offline实机截图使用临时网页覆盖，不代表已发布到手机。

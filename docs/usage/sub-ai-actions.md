# AI对话动作与动作SubAI

更新服务源码后重启服务，并刷新网页控制端和显示端。在显示端开启MMD并等待角色加载。

打开“模型”面板，在“动作 SubAI”区域选择Provider和具体文字模型，再勾选“缺库时生成动作”。这里的选择独立于主AI、生图、生视频；主AI是Agent时也可以设置。列表只显示当前已配置可用账号的Provider；账号失效会明确报错，不自动换模型。未配置时默认关闭生成，已有动作仍可播放。

对主AI说“请点头两次”或“右手举起来，慢慢挥两下”。主AI通过现有SubAI指令提交动作，当前显示端先查本地登记动作，再查服务器动作和内置模板；没有可匹配动作时调用动作SubAI生成MPL。动作代码通过当前角色编译和轨道校验后播放；模型面板显示执行状态。

这是网页MMD/Human动作功能，Node mpv没有角色/MPL能力。显式动作独立播放，不需要同时开启TTS；原先回复标记触发的已知动作仍跟随TTS。生成较慢不会阻塞正常语音，生成动作当前没有逐句语音锚点同步。

生成动作完整播放成功后，自动保存在“动作 → Human → SubAI候选动作”。候选不会自动替换常用版本：

- **预览候选**：针对当前角色重新校验并预览。
- **查看MPL**：将源码放入Human修正代码区供查看。
- **采用为默认版本**：在“行为名称”填入目标名称后采用；相同名称追加版本，不同名称新增动作。名称留空时使用描述前80字符。
- **删除候选**：删除选中的候选。
- **停止自动动作**：停止当前动作任务及候选预览；中断动作不会保存候选。
- **重试保存动作库**：持久化失败时重试，也可先导出备份。

候选最多32条，和原动作版本共同受总128版本/1MiB元数据限制；满额需手动清理。库仍保存在当前浏览器、按模型区分。导入/导出包含候选；旧schema1库会在读取时迁移，下一次保存写入schema2，旧版程序无法直接读取新版库，升级前可先导出备份。

生成有20秒准备预算，编译失败最多让同一模型修正一次；手动动作优先，换模型/动作库、离开页面、断线或开始新轮次会取消旧任务。校验通过只代表可播放，动作效果仍需实际观看后决定是否采用。

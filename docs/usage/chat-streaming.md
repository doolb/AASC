# 聊天流式显示与TTS

聊天收到可确认的正文分块后，控制端和显示端会逐步显示。TTS按句末标点、换行、第四个逗号或括号边界分段，一段完整就进入原音色队列合成和播放；不是等待整条回答结束，也不是供应商二进制音频协议的逐字合成。

字幕支持Markdown标题、强调、列表、引用和链接等格式；语音只读正文，链接只读文字、图片读说明，围栏代码不朗读。格式可以跨模型分块，动作标记仍由已有MMD有限字典处理。手动朗读、Agent、语音命令和提醒采用同样的正文规则。无自然边界的长句会等尾段完成，不按120字强切。

游戏调用标签只作为聊天tips显示，相关操作叙述等GM确认后才放行。可疑游戏声明会有局部等待，不能承诺每个游戏字词都立即显示或朗读。纯文字显示与TTS字幕不同：字幕随真实音频进度推进；没有逐字时间戳时使用时长比例估算。

字幕的原旋转、三视觉行视口、历史上限、背景透明度和闲置隐藏保持。供应商仍需合成时间，账号排队/限流重试时会等待，原音色和顺序不变；停止按钮沿用原当前聊天停止语义，临时会话在全部实际播放完后才重新计时。

本功能只需更新服务代码包并刷新两端网页，无新增Android原生能力或APK要求。本轮代码尚未构建发布，当前生产进程未重启；部署后再验收Note8声音和字幕观感。

开发自测：`npm run test:chat-streaming`、`npm run test:game-chat`、`npm run test:mmd-production:tts`。控制端自测面板增加“流式分句与Markdown朗读”，仅执行纯文本与渲染检查，不发送测试语音或污染当前聊天。

# 聊天上下文占用与历史计数

控制端和显示端的聊天输入框上方显示：

`上下文 ≈50% · 对话 12/100`

- 上下文：当前聊天管理的文本输入估算，相对于本地输入预算；包括角色和游戏系统提示，不含图片token，不代表远端模型真实窗口占用。固定提示本身过长时可能超过100%。
- 对话：聊天管理经过历史条数限制和预算裁剪后保留的历史条目数/当前上限。私聊现为100，群聊及临时聊天随现有配置和管理选项计算；一问一答不强制合并为一轮，旧成对记录保留原计数单位。
- 发送时显示本次实际组装统计，完成后刷新为当前历史加固定提示的估算；空闲查询不包含尚未发送的输入草稿，不会额外调用AI。
- 切换、清空及重连自动刷新；无可用数据或独立角色Agent显示“—”。悬停可查看估算token和历史单位。

服务代码包更新后生效。

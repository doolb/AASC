# 自动去视频黑边

控制端选择目标显示端，在“画面填充”下面切换“自动去黑边”。默认开启，按显示端保存；网页、Android显示页和Node/mpv共用设置。

播放时按新视频帧触发计算，使用上一帧最近完成结果，连续两帧有效样本确认黑边后，按当前填充方式显示有效画面：

| 填充方式 | 去黑边后的行为 |
| --- | --- |
| 适应 | 完整显示有效画面；比例与屏幕不同时保留画布留白 |
| 铺满 | 有效画面覆盖屏幕，超出部分裁掉 |
| 高度／宽度铺满 | 有效画面按指定轴填充，旋转规则沿用原行为 |
| 动态 | 在有效画面的适应与铺满之间过渡 |
| 裁剪 | 原视频坐标的人工框与有效区域相交，保留人工参数 |

暂停、睡眠、全黑和过暗片段不会确认新的黑边。切换视频后重新检测；关闭开关立即恢复按完整视频填充。当前跨域视频重新开启检测会重试直连，并保留位置和暂停状态。

“黑边调整过渡”是独立开关，也默认开启。检测边界改变时约200ms平滑调整画面，关闭后立即使用最新确认区域，去黑边检测继续工作。动态填充保留自身过渡时长。计算较慢时沿用最近完成结果，不积压播放帧。

跨域视频不允许读取像素时仍正常直连播放，该来源无法自动去黑边。Node依赖mpv的Lua及视频分析能力，优先原生逐帧分析，兼容时回退截图；能力不可用时保持普通播放。只管理本功能自己的分析滤镜，源文件不修改。

本功能需更新服务代码包和Node独立包；Android沿用网页热更，本次无需新APK。Android设备、Windows及高分辨率实际负载待部署验收。

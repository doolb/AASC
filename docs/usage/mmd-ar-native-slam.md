# MMD AR 原生 ORB-SLAM3

独立测试 APK 在本机运行 ORB-SLAM3，无需 Google Play 或 Google 服务。纯网页没有 `MmdArNativeSlam` 接口时继续使用原来的 MindAR；能力查询失败、协议不支持或原生资源不可用也使用 MindAR。

## 网页功能与本地文件

测试APK与当前独立网页共用全部灯光、动作和定位功能，APK额外提供原生定位/标定。灯光面板可正常展开，主光阴影、AO、高光、物理、骨骼名称/点选/轴/碰撞累计和碰撞体使用相同控件。“动作 → 本地资源”可导入PMX及贴图、角色VMD和相机VMD，加载进度与取消/失败提示保持一致。

APK点击“选择模型目录”后，在Android系统目录选择器中选择包含PMX及贴图子目录的目录；保留相对路径，纹理无需搬到PMX旁边。一个目录有多个PMX时从下拉框选择；也可用“选择模型文件”多选PMX及贴图。目录枚举上限4096个文件、1024个子目录，超限会提示重新选择较小目录。取消保持当前模型和动作，文件不上传且只在当前页面有效，刷新需重选。

在“定位 → 视频输入”选模拟摄像头时，APK与网页都使用MindAR；切回真实摄像头才启用原生SLAM。启动原生采集前释放网页重力摄像头预览，停止后恢复既有预览生命周期。

## 开始定位

1. 打开独立 APK，等待角色加载，进入“定位”。面板会显示当前后端。
2. 选择原来的定位图，或拍照、框选并保存定位图；可以使用内置 MindAR 官方示例图。
3. 点“开始定位”，允许摄像头权限。让定位图完整、清晰地进入画面，缓慢平移手机；只原地旋转不足以建立单目地图和尺度。
4. 显示“图片首定位/地图对齐中”时继续保持图片可见；显示“SLAM 跟踪”后角色已锚定，不需要始终看着图片。
5. 暂时失锁时保留角色和最后视角。环境重定位成功后继续跟踪；如果创建了新地图，则需要再次看到原定位图。

图片只负责把角色位置对齐到SLAM地图；完成对齐后，离开图片由环境特征继续定位。短暂失锁后恢复同一地图无需重新看图。目前APK仅保存一份地图锚点，地图切换或参考关键帧失效会清空，切回旧地图也可能需要重新看图；按地图恢复锚点尚未实现。“SLAM初始化中”可能是地图重新建立，不能仅凭该提示判断APK重启。只有“SLAM跟踪”表示世界锚定完成，初次看图出现角色但仍显示“地图对齐中”时请继续缓慢平移。

移动和旋转测量用于更新相机，保留角色手动移动/旋转、动作和物理。相机平移/旋转死区及第二层缓动仍然生效。原生模式关闭网页 IMU 预测，惯性融合由 ORB-SLAM3 完成。界面的匹配点数是诊断量，不是概率可信度。

停止定位、切换目标、进入后台或退出会释放相机、传感器和定位线程。回到前台需要重新开始，地图不持久化。原生预览按当前窗口横竖方向显示，保持比例并居中裁切；横竖屏或180度旋转时同步更新画面与角色投影，单纯方向/窗口尺寸变化不再要求重新开始定位。实际预览表面被销毁或应用进入后台时仍停止采集。

## 相机与 IMU 标定

默认使用单目视觉和 Camera2 焦距/传感器尺寸估算内参；界面明确显示“估算内参”，此模式不是视觉惯性定位。定位状态中可查看实际相机 ID 和采集尺寸。默认采集优先选择 640×480；不可用时从不超过 960×720 的 YUV 尺寸中选择最接近的尺寸。

在定位面板导入标定 JSON，重新开始后应用。标定保存在当前 APK 的 WebView 本地存储，可用“清除原生标定”恢复默认。标定必须对应当前实际后置摄像头和采集尺寸，不要复用其他手机的数值。

| 字段 | 内容 |
|---|---|
| `width`, `height` | 实际灰度采集尺寸，必须完全匹配 |
| `fx`, `fy`, `cx`, `cy` | 原始传感器图像坐标中的内参，单位像素，未应用屏幕旋转 |
| `distortion` | 四个有限数值，顺序 `k1, k2, p1, p2` |
| `imu` | 可选；不提供时使用单目视觉 |
| `imu.Tbc` | 相机坐标到 IMU 坐标的刚性变换，行优先 16 项，平移单位米，旋转行列式为 +1 |
| `imu.NoiseGyro`, `imu.NoiseAcc` | 陀螺仪及加速度计噪声密度，采用 ORB-SLAM3 参数单位 |
| `imu.GyroWalk`, `imu.AccWalk` | 偏置随机游走，采用 ORB-SLAM3 参数单位 |
| `imu.Frequency` | 实际传感器频率，正数；本实现申请 200Hz，设备实际输出频率需标定确认 |
| `imu.timeOffsetSeconds` | 将传感器时间转到相机时间的偏移：`相机时间 = IMU 时间 + 偏移`；确认零偏移时显式写 `0` |

只有提供完整 IMU 标定、设备同时具备加速度计/陀螺仪、Camera2 时间戳来源为 `REALTIME` 时才能开启单目惯性模式。`UNKNOWN` 时间戳来源会报错；外参、噪声、时间偏移不能用猜测数值替代。惯性初始化完成前不固定世界锚点。

未导入含`imu`字段的标定时，默认使用单目视觉，SLAM不会注册陀螺仪/加速度计监听。跟踪状态栏“单目视觉”表示纯视觉，“视觉＋IMU”表示启用视觉惯性模式；“重力旋转”仅控制角色姿态，不能用来判断相机定位是否融合IMU。

## 构建与产物

从仓库根目录运行 `npm run build:apk:mmd-ar-test`。构建机需要 Node、Python 3.12+、JDK 17、Android SDK 34、NDK 28.2.13676358、CMake 3.22.1，以及首次下载依赖所需网络。依赖固定版本和 SHA-256，缓存位于 `build/third_party/`；不新增 npm 生产依赖。

APK 输出 `3rd/mmd-ar-test/output/aasc-mmd-ar-test.apk`，包名 `com.aasc.mmdartest`，当前只构建 `arm64-v8a`，Android 8.0/API 26 起。词袋、原生库、定位图与模型均随包提供；运行时不下载 SLAM 依赖。网页用 `npm run build:web:mmd-ar-test` 构建，网页包不包含原生库和词袋。

新版已覆盖安装到SM-N9500，三面板展开/收起及官方定位图读取已确认。尚需手机现场确认目录/贴图选择、首定位、尺度、预览对齐、失锁/回环、惯性同步、帧率和内存表现；构建成功不代表定位精度已验收。本轮没有发布外网。

## 独立网页接触阴影保边模糊（2026-10-09，本地构建）

在“灯光 → 接触阴影”中启用效果，可调强度、距离、4–64采样步数，以及保边模糊0–3轮。默认1轮、半径3；每轮半径可设1–5效果像素，选0轮直接显示未滤波接触阴影。深度/法线约束模糊范围，半径以低分辨率效果像素计算，不是主画布像素。

这些设置独立于“间接光 → SSGI”的模糊，刷新保存，灯光恢复默认会关闭效果、采样恢复12步、模糊恢复1轮/3像素。近景射线使用局部透视偏置，当前帧半深度粗筛后完整深度确认；屏外、透明及多层遮挡仍可能遗漏。增加轮数或采样会增加GPU成本。本地web-dist已构建，公网效果以实际部署版本为准。

# 聊天模型三档快选

控制端和显示端右下角点击“模型”，选择当前已配置账号的 Qwen 或豆包，再选择轻量、普通、专业。两端共享当前选择；Qwen 初始为普通，豆包初始为轻量。切换 Provider 会恢复各自上次选的档位。选“现有 LLM 配置”则继续使用原聊天 profile。

| 档位 | Qwen 目标 | 豆包现有模式 |
|------|-----------|--------------|
| 轻量 | Qwen3.6-Flash | doubao（思考0） |
| 普通 | Qwen3.7 | doubao-think（思考1） |
| 专业 | Qwen3.7-Max | doubao-expert（思考3） |

选择只影响后续普通 LLM 聊天；角色 Agent 使用自己的配置。列表按 Chat2API 当前运行实例中已启用、有凭据的账号筛选，账号出现在列表不代表远端登录仍有效。代理未运行或账号失效时，聊天会返回错误，不自动换 Provider 或档位。两端断线时不能提交，重连后以服务器保存的选择为准。

三档映射由开发在 `src/apps/server/modules/chat/chat-model-tier-service.js` 维护，界面不编辑映射。面板中的“外部登录（后续开放）”暂不可点；当前仍从控制端 Chat2API 任务卡片进入账户管理和外部认证。Qwen 目标的真实上游可调用性及 Offline APK/ADB 页面还需现场验收。

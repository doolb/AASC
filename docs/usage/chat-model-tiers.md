# 聊天模型三档快选

控制端和显示端右下角点击“模型”，选择当前已配置账号的 Qwen 或豆包，再选择轻量、普通、专业。两端显示当前普通 LLM 配置中的模型名、Provider 和档位；选中档位使用当前主题的强调色渐变和外圈，未选中档位使用中性按钮样式。Qwen 初始为普通，豆包初始为轻量；切换 Provider 会恢复各自上次选的档位。

| 档位 | Qwen 目标 | 豆包现有模式 |
|------|-----------|--------------|
| 轻量 | Qwen3.6-Flash | doubao（思考0） |
| 普通 | Qwen3.7 | doubao-think（思考1） |
| 专业 | Qwen3.7-Max | doubao-expert（思考3） |

选档会修改控制端“LLM 服务器配置”中当前普通 LLM profile 的“模型”字段，控制端手工修改该字段或切换 profile 后，两端也会按当前模型名重新显示。`Qwen3.6-Flash` 按名称显示为 Qwen 轻量，不读取 Chat2API 映射配置；未知模型名原样显示且不选中档位。当前 profile 为 Agent 时不可快选，角色 Agent 使用自己的配置。列表按 Chat2API 当前运行实例中已启用、有凭据的账号筛选，账号出现在列表不代表远端登录仍有效。代理未运行或账号失效时，聊天会返回错误，不自动换 Provider 或档位。两端断线时不能提交，重连后以服务器保存的模型名为准。

三档映射由开发在 `src/apps/server/modules/chat/chat-model-tier-service.js` 维护，界面不编辑映射。面板中的“外部登录（后续开放）”暂不可点；当前仍从控制端 Chat2API 任务卡片进入账户管理和外部认证。Qwen 目标的真实上游可调用性及 Offline APK/ADB 页面还需现场验收。

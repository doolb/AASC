# 独立 MMD-AR：AI 回复与分层动作

本轮仅在本地构建的 `3rd/mmd-ar-test/web-dist/` 生效，尚未发布外网。

## 面板操作

1. 加载 PMX，进入预览，打开「动作 → AI 回复」。
2. 粘贴已有完整回复，点「解析标记」查看口型净文字及实际匹配表情。
3. 点「播放回复预览」，表情、身体动作、口型同时运行。当前不发声，按文字估算节奏。
4. 「停止并恢复」释放本次自动表情/口型与身体动作。后来的手动新动作、表情或口型保留。

手动表情覆盖自动表情，口型优先控制映射的嘴型；眼眉等仍可变化。无映射、重名或当前模型不支持的表情显示原因，不猜写固定索引。口型净文字最多400字符；超过时跳过口型，但仍可预览表情与动作。

## 回复标记

```text
😊你好，主人！*点头* 很高兴见到你。
[表情:眨眼 时长=1 强度=0.8]一起加油吧！
[动作:挥手 时长=3 强度=0.6 次数=2]下次见！
```

- 支持常见开心/悲伤/生气/惊讶/害羞/眨眼Emoji和部分颜文字。
- `（微笑）`、`*点头*`使用有限语义字典；普通括号、Markdown代码与引用不执行。
- `[表情:开心]`使用当前模型的候选表情；也可写真实PMX名称。名称带末尾空格时使用JSON引号，如 `[表情:"笑い " 强度=0.6]`。
- `[动作:点头]`是高级动作。默认时长2秒、强度0.7、次数1；范围0.2–15秒、0–1、1–8次。
- `[表情:平静]`释放自动情绪层，保留VMD、手动表情和口型。
- 明确的 `mpl` 代码围栏或 `[MPL]代码[/MPL]`作为低级动作，不进入口型文字。

回复最多64KiB、64个标记、16段身体动作。表情到标记所在文字时刻开始；身体串行执行，编译或前一动作未结束时会延后并提示。首次MPL编译器加载也可能延迟。

## 两种身体动作

| 分类 | 输入 | 用途 |
|---|---|---|
| 高级动作 | 点头/摇头/挥手/鞠躬/歪头＋时长、强度、次数 | 点击按钮或回复标记，内部生成MPL模板 |
| MPL 低级动作 | pose、骨骼和Morph时间线 | 精确指定骨骼轴、角度和表情 |

高级动作需要标准MMD骨骼；不会搜索VMD动作库。高级按钮和回复动作单次播放，结束后恢复原动作及播放开关。原手动MPL继续沿用既有播放方式。所有身体动作复用同一播放器，新请求取消旧编译，停止只恢复自己仍拥有的动作。

## 页面接入

页面加载且PMX准备完成后：

```js
await window.MmdArReplyPreview.play('😊你好！[动作:点头]');
await window.MmdArReplyPreview.stop();
const parsed = window.MmdArReplyPreview.parse('（微笑）你好。');
```

接收完整AI回复，可用事件或 `receive`：

```js
window.dispatchEvent(new CustomEvent('mmd-ar-ai-reply', {
    detail: { id: 'reply-001', text: '😊你好！*点头*' }
}));
await window.MmdArReplyPreview.receive({
    id: 'reply-002', text: '[表情:眨眼]下次见！👋'
});
```

带id时最近128条去重；流式回复先合并后提交，历史列表不自动播放。`play/receive`返回准备结果，播放状态读 `getState()`。外部真实音频与TTS同步尚未接入，本轮页面不请求LLM/TTS/录音。

换模型、物理重载、编辑、后台或离页会停止回复预览。单次身体动作等待最多两分钟；编译仍有原30秒上限。实际模型表现和移动端性能尚待设备验收。

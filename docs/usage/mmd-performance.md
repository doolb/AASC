# MMD帧率与耗时

正式显示端和独立mmd-ar在角色画面左上角显示FPS，不拦截点击/拖动。「灯光 → 基础光照」显示渲染耗时，单位ms，口径为CPU绘制提交（包括现有阴影和屏幕效果），不等于GPU执行时间，也不包含角色动画、物理步进等全部帧工作。

正式「动作 → 物理」状态行显示Ammo/XPBD实际物理调用耗时；关闭物理或因旋转阈值暂停时显示未运行/已关闭，不保留上帧旧耗时。独立物理状态行继续显示既有信息。

统计窗口约500ms，回显跟随实际渲染帧；低帧率时更新也会变慢。隐藏角色、后台切换或更换模型后清空窗口，恢复后重新计帧。加载/等待时使用占位，不把后台停留算进新FPS。

正式「隐藏角色」同时收起右侧灯光、动作、定位按钮与已开面板；底部「角色」入口保留，重显恢复按钮，参数偏好保留。控件隐藏不会额外停止原定位/摄像头状态。独立编辑工具栏移到FPS下方。

源码与独立本地WEB构建已完成。正式服务包发布状态见changelog和签名清单；独立外网同步、手机观感与实际VRM/GLB头像仍待验收。

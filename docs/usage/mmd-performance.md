# MMD帧率与耗时

正式显示端和独立mmd-ar在角色画面左上角显示FPS，不拦截点击/拖动。「灯光 → 基础光照」分别显示 `CPU xx.xx ms · GPU yy.yy ms`。CPU为绘制提交耗时，GPU为WebGL时间查询异步采样的绘制执行耗时；包括当前阴影和后处理，不包含前面的角色动画、物理步进、AR识别或浏览器最终合成。两者异步重叠，不相加为总帧耗时。

GPU按当前统计窗口收到的有效结果单独平均，可能比当前绘制帧延后。设备/浏览器未开放WebGL计时扩展时显示“不支持”；等待结果、计时断裂（disjoint）或上下文丢失时显示 `-- ms`。隐藏、后台、换模型和上下文恢复清旧查询，不把未采到当0；不会强制等待GPU或额外绘制。软件GPU的数值不代表手机性能。

正式「动作 → 物理」状态行显示Ammo/XPBD实际物理调用耗时；关闭物理或因旋转阈值暂停时显示未运行/已关闭，不保留上帧旧耗时。独立物理状态行继续显示既有信息。

统计窗口约500ms，回显跟随实际渲染帧；低帧率时更新也会变慢。隐藏角色、后台切换或更换模型后清空窗口，恢复后重新计帧。加载/等待时使用占位，不把后台停留算进新FPS。

正式「隐藏角色」同时收起右侧灯光、动作、定位按钮与已开面板；底部「角色」入口保留，重显恢复按钮，参数偏好保留。控件隐藏不会额外停止原定位/摄像头状态。独立编辑工具栏移到FPS下方。

原FPS/CPU及控件隐藏功能随正式服务包v66发布。新增GPU显示的源码与独立本地WEB已完成，尚未发布正式服务包或独立外网；当前线上旧页不会因普通刷新获得本次GPU功能。需要后续发布并刷新目标页后生效，手机扩展能力及实际VRM/GLB角色仍待验收。

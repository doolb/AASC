# 从服务器面板重选 Android SAF 媒体目录

## 前提

目标设备为Android10/API29或以上，安装包含新原生入口的APK并运行新版服务代码。仅热更网页不足以让旧APK获得系统目录选择能力。Android9继续使用旧共享存储流程，不显示SAF重选按钮。

## 操作

1. 在目标Android设备打开显示端，保持应用在前台。
2. 控制端打开“服务器”面板，在目标服务器卡片点击“重选 SAF 目录”。当前Offline服务器和已连接的Android子服务器均可使用。
3. 在目标Android设备的系统文件夹选择器中选择目录并授予读写权限。
4. 控制端等待实际结果；成功后刷新媒体来源及当前SAF根目录。取消或失败保留原目录，不移动或删除旧文件。

按钮只在节点在线且明确声明支持时出现。若提示设备不在前台，请先在设备上打开显示端再重试。若控制端等待超时，选择器仍可能在设备上等待操作；在同一页面再次点击可继续查询。目录范围及Android11+对存储根目录、Download根目录、Android/data等限制仍由系统选择器执行。

当前交付为源码与待出包标记，尚未构建或发布本功能，也未完成Android10+真机验收。

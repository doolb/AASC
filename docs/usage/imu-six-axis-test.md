# 六轴IMU共享3D测试网页

独立的惯性运动实验，页面和左右3D视口使用亮色界面。电脑左侧显示估计场景，右侧拖动虚拟设备移动/旋转手柄，自动生成六轴测量；右相机随设备移动，保持距离和方向。真实手机与电脑共用估计器，可进入同一房间，每台设备对应一个独立颜色物体。

## 启动

在项目根目录执行：

```sh
npm run start:imu:six-axis-test
```

电脑打开 http://localhost:8769/ 。局域网可打开 http://192.168.1.39:8769/ （以当前服务器IP为准）。服务默认监听0.0.0.0:8769，使用IMU_HOST/IMU_PORT覆盖。必须通过此服务访问，直接把文件放入普通静态目录不能替代vendor和WebSocket路由。复用项目现有three/ws，不新增生产依赖。

## 电脑操作

网页默认连接固定房间`AASCIMU1`。需要加入已有的其他网页房间时，可直接在“房间”框中填码，或打开带`?room=房间码`的链接；手动房间优先，切换本机输入来源时会保留当前房间。选择“手机APK回传”后电脑作为观察端接收该房间的原生样本。

1. 右侧选“移动”拖XYZ箭头，选“旋转”拖圆环；背景拖动观察、滚轮缩放。设备按连续运动模型追随目标，相机持续跟随。
2. 可先点击“无噪声，保留当前处理”，观察六轴积分能否重建运动；“理想基准（关闭全部处理）”用于完全关闭处理的基准对照；再调整零偏、白噪声、随机游走、采样抖动与丢样，对照误差。
3. 默认直接使用角速度死区和去重力后加速度死区，无需校准。需要补偿时展开“高级校准（可选）”：静置校准至少2秒，仅估计陀螺仪零偏/倾斜；六面校准用于加速度零偏/比例，模拟器提供自动六面按钮。
4. 左侧可展开原始/处理后六轴、零偏诊断，切换观察设备、轨迹和真值。右侧真值只用于对照，不能纠正估计位置。
5. “已停稳”清零速度，“重置原点”清位置/速度，“重置航向”仅调整相对水平朝向。改变模拟零偏后重新校准。
6. 取消“输出六轴数据”后，右侧仍可操作，左侧保持最后估计位姿。两侧没有直接位姿绑定。

参数/校准只在本次页面会话内保存。模拟器采样100Hz，网页估计帧以50Hz为发送目标；原生手机请求50Hz传感器采样，APK批次也以50Hz为发送目标，实际频率按状态接口核对。默认不自动把低加速度判为静止，匀速移动不会自动清速度；可选手持停稳假设会误判匀速，界面记录修正次数。

模拟器来源已单独启用六轴静稳窗口：角速度、去重力加速度、加速度波动及重力模长共同达到高静稳评分后，若已观测到减速则持续0.7秒清零速度；否则持续1.5秒兜底清零，防止残留速度长期放大位置误差。判定只读六轴数据，不回写模拟真值位置。持续匀速与静止在六轴上可能无法区分，因此兜底可能误清匀速速度。浏览器手机和APK输入仍默认不自动清零，只有显式启用手持停稳假设时才会根据静稳窗口归零。

模拟器纯旋转时，估计器还会用接近标准重力的六轴测量纠正俯仰/横滚；连续判断为只有旋转、没有明显平移加速度时，自动清除平移速度。重力不能校正航向，匀速平移叠加旋转也可能被误清速度。更新后请刷新电脑网页并点击“重置实验”；旧轨迹已累积的位置误差不会自动消失。手机浏览器和APK没有启用此模拟器专用规则。

## 手机与同一房间

电脑创建房间后，手机打开顶部接入链接（带room和role=phone），点击“开始手机采集”，按浏览器提示授权。手机页只显示接收场景和采集/校准；多个电脑也可填写房间码后连接。屏幕旋转不改变自然传感器轴。

手机运动接口要求可信安全上下文。普通局域网HTTP可加载页面，但不能采集传感器。可采用两种入口：

- 使用手机信任、主机名匹配的HTTPS证书启动服务，HTTP与WebSocket自动同步切换到HTTPS/WSS：

```sh
IMU_TLS=1 IMU_TLS_KEY=/path/to/key.pem IMU_TLS_CERT=/path/to/cert.pem npm run start:imu:six-axis-test
```

- Android通过ADB转发本服务，然后从手机访问电脑生成的同一room链接，将主机部分改成localhost:8769：

```sh
adb -s <设备序列号> reverse tcp:8769 tcp:8769
```

例如手机打开 `http://localhost:8769/?room=<电脑房间码>&role=phone`。本轮已为连接的SM-N9500配置该转发。项目现有localhost自签名证书并非手机可信证书；不能以忽略证书错误作为采集保证。iOS需实际授权，后台/停止会释放采集监听，断流会冻结位置并在恢复后从零速度开始。断线后点击“连接房间”重新加入；重连分配新的设备对象。

## Android原生传感器APK

APK直接使用Android `SensorManager`，因此采集不依赖浏览器HTTPS权限。电脑与手机连接同一局域网，电脑执行上面的启动命令后，在网页“本机输入”选择“手机APK回传”，默认观察房间`AASCIMU1`；房间框或URL参数可手动覆盖。APK首次打开预填服务器`192.168.1.39`、端口`8769`和固定房间`AASCIMU1`；若电脑当前IP不同，编辑服务器地址后点击“连接电脑”，再开始采集。服务端口需允许手机访问，默认放通TCP 8769即可。

APK只显示含重力的原始加速度；桌面诊断另显示估计器计算的世界线性加速度。原生端请求两路20ms采样，保留各自测量时间，在陀螺仪时刻插值配对；WebView和WebSocket按有序小批次传送，网络以20ms一批为目标，队列达到128条才丢弃最旧样本并标记断流。20ms是目标，不保证Android硬件实际50Hz。网页房间默认`AASCIMU1`，房间输入框或`room`URL参数可手动覆盖，来源切换时保留选择。

APK构建命令及输出路径：

```sh
npm run build:apk:imu-sender
# 3rd/imu-six-axis-test/android-sender/output/aasc-imu-sender.apk
```

本机诊断接口：

```sh
curl http://127.0.0.1:8769/api/imu/status
curl 'http://127.0.0.1:8769/api/imu/samples?limit=20'
curl 'http://127.0.0.1:8769/api/imu/trajectory?limit=120'
# 指定房间和输入设备：
curl 'http://127.0.0.1:8769/api/imu/trajectory?room=AASCIMU1&deviceId=<设备ID>&limit=600'
```

状态含设备在线、原始样本`sampleRateHz`、APK批次`sampleMessageRateHz`和拒绝计数；服务端对每个连接按平均50条消息/秒限流，容许少量短时抖动。样本接口单次最多返回500条原始六轴数据，包含可用的陀螺仪时间、加速度插值前后时间及`gap`断流标记。轨迹接口默认房间为`AASCIMU1`，可用`room`、`deviceId`和`limit`筛选；每台设备的`frameRateHz`表示最近一秒实际接收的估计帧数。电脑选择“手机APK回传”后，电脑观察端也发布自身估计帧；`points`记录实时历史，最多600帧，静止帧也会记录；`estimatedTrail`还原浏览器绘制的估计轨迹，手机输入没有模拟真值，`referenceTrail`为空。每个实时点带时间、估计位姿及可用参考位置/误差；`current`是最新帧。`lastFrameAt`为服务端Unix毫秒时间，`frameAgeMs`和`stale`用于判断帧是否超过1秒未更新。服务重启后，仍开着的网页点击“重新连接”会把当前两条显示轨迹恢复到缓存。三个诊断接口都仅loopback可访问，只保存在进程内存，服务停止后清空。APK进入后台或断线后会停止采集；固定房间同时只接受一个在线APK传感器。

页面位置误差卡片按X、Y（竖直）、Z、总误差分别显示，分轴值为“估计值 − 真值”，正负表示估计偏移方向；Y正值表示估计位置高于真值，总误差为非负欧氏长度。只有图形模拟器本机输入有真值对照。

## 精度与数据

浏览器数据经过平台处理，不是原生硬件IMU时间戳。角速度按自然设备x/y/z转换为rad/s；世界线性加速度由六轴估计器去重力后计算。滤波、向量死区、陀螺仪零偏/六面标定减少误差，但纯六轴位置和航向会累积漂移，不能替代视觉SLAM或提供长期绝对定位。各设备进入同一虚拟场景不代表物理空间已对齐。

SM-N9500/Samsung Internet实际约60Hz；一次3.5秒真实采集208样本，静置校准成功，独立观察端收到70帧/最新205样本。单面校准后仍有重力残差和位置漂移，实际移动距离精度、手机六面动作、iOS与长时间性能尚待现场测量。

## 自动校准死区

在“估计器处理”点击“静置校准死区（3秒）”，尽量保持手机单个朝向不动，无需翻面。至少采集60点后用该窗口的平均重力方向对齐倾斜，再按对齐后的去重力加速度计算两个死区；角速度和加速度死区均以无固定上限的数值框显示，也可手调。算法使用死区前数据和现有世界加速度滤波，不扣除或改写零偏，不标记六面校准完成。采样期间冻结估计位置并清速度；输入类型变化、断流或取消会丢弃当前窗口。手持高噪声不因固定幅值或方差门槛被提前拒绝，因此实际移动也可能被计入校准，过大的死区会忽略真实慢动作；请查看结果并按需要重采或调低。结果仅在当前页面会话有效。旧轨迹误差无法自动恢复，复测请刷新网页、重置实验，再静置校准后移动。

## APK 静稳修正（2026-10-17）

电脑选择APK观察来源后，仅用陀螺仪和含重力加速度的连续静稳窗口学习本机当前重力模长、纠正倾斜并清零速度，避免设备静止时持续下坠。移动会撤销静稳状态；旧APK附带的平台线性字段被服务端忽略。真机实测静置样本模长约9.685 m/s²，原固定9.807 m/s²扣除会造成约0.12 m/s²的向下残差。手机浏览器仍默认手动清零。六轴会把长时间匀速移动误判为静止，既有位置误差不会自动回正。安装新版APK并刷新桌面页后重新开始轨迹。

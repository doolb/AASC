# 媒体区间循环

源码已实现，更新服务代码包并刷新控制端/网页或APK显示页后可用；Node显示端需同时更新独立包。

临时模式直接上传的视频也支持区间循环。若使用旧显示页，需刷新显示端后重新发送视频；修复后的页面会在元数据加载完成后立即启用手柄，视频暂停时也能设置。Offline设备需先更新包含本次修复的服务代码包，无需新增APK原生改动。

1. 在控制端选中显示端，播放有明确时长的音频或视频。
2. 在“媒体播放”卡片的“区间循环”下，拖动同一条滑条上的两个手柄：左侧为开始点，右侧为结束点。
3. 查看上方起止时间，勾选“区间循环”。播放到结束点会回到开始点。

拖动时只预览，松开后应用；两个手柄不能交叉，也可以分别聚焦后用方向键微调。关闭开关恢复原有播放方式。切换媒体或播放列表项会清除区间；循环开启时，播放列表优先重复当前项。

起止时间带两位小数：不足一小时显示 `00:30.25`，有小时显示 `1:02:30.25`，每个小数单位为10毫秒；小时位按实际数值增长。时间未知时显示 `--:--.--`。深色、浅色和彩色主题共用透明轨道叠层，两个手柄保留实心填充与内外轮廓。

设置按显示端保存，刷新或重连后恢复当前媒体的区间。图片、HTML、文本以及没有有限时长的媒体禁用区间控件。

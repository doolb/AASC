# 正式MMD灯光与动作

AI回答随TTS自动播放动作已随正式服务包v65发布：每句开始请求生成语音时并行解析和准备，生成好并轮到该句播放时同步启动，随后按音频进度推进。暂停/缓冲时保持，继续播放时恢复，停止/打断/手动接管时释放自动层，仍用配置600ms衔接。句尾爱心等安排在末尾可播放窗口；没有实际播放TTS时不自动执行，句内字音位置为估算。

生效步骤：运行当前工作区源码的服务器需执行 `npm run restart:server`，然后刷新显示端页面。Offline正式环境需先发布并更新包含本次改动的新服务代码包，再重启服务、刷新显示端；仅重启已发布v64不能启用新逻辑。2026-10-12已核查启动器和模块加载方式，本次问答未执行重启。

正式显示页灯光/动作已随v64发布，TTS自动动作随后进入v65。新增左上角FPS、灯光CPU渲染耗时及正式物理耗时/角色控件隐藏详见[帧率与耗时](mmd-performance.md)，新服务包发布状态见changelog。

「灯光」「动作」「定位」顶部的“面板不透明度”共用一份本地设置，默认50%、范围0–100%，任意面板调整后立即同步，松开后保存。分类及子分类标题背景也随之调整，文字、开关及可用输入控件保持清晰；浅色主题标题不再被普通按钮的不透明渐变覆盖。此修复已完成源码与桌面浏览器回归，尚未进入新服务包，设备需后续更新代码并刷新显示端；Android实际观感待验收。

「灯光 → 灯光预设」可保存当前完整设置、覆盖/删除、导入/导出JSON。与独立页使用同一十组文件格式，正式本地库独立保存。首次缺省和恢复默认使用“日光”，已保存的设置优先；列表附带“傍晚”。正式页面没有AO法线或阴影贴图诊断预览，导入这些字段时固定关闭。

默认米娅在未指定动作时使用待机：双臂35°、双肘10°、双腕-10°，8秒循环。已选择的动作保留。「动作 → 高级动作」手动播放跳舞或其他动作；时长留空使用原时长，跳舞15.2秒。支持28类内置语义动作，常见Emoji及颜文字可在「AI回复」解析/无声预览，历史消息不会自动执行。

点击高级动作后，可用源码自动填入「MPL低级动作」，不展开分类、不滚动、不抢焦点。自行打开分类后可编辑、预览、下载；暂不提供保存入口。只有VMD的跳舞会提示暂无MPL源码，并保留当前编辑内容。后续服务器动作在mmd-actions.json增加条目，可附同源mmd目录下的mplUrl。

「Human」提供呼吸、眨眼、头眼跟随、模型能力、当前模型动作库与修正层。头部进入动作和恢复跟随均使用600ms过渡。「物理 → 手部防穿模」复用当前物理刚体，平滑避让并尝试回到原动作，开关本地保存。刚体避让不能保证所有服装网格绝对无穿模。

正式TTS继续随ttsAudio音频进度控制口型。真实TTS播放期间回复口型预览不会接管；停止回复预览不停止TTS。口型分类仍可关闭同步或停止当前句口型，声音继续播放。

开发或服务出包前执行npm run prepare:mmd-production，准备固定版本Worker编译资源/许可证、待机和舞蹈目录；build:server-package及build:offline-update已自动执行此步骤。验证命令为npm run test:mmd-production、npm run test:mmd-production:browser和npm run test:mmd-production:independent。Android观感/性能需真机验收。

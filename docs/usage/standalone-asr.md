# 独立 ASR

独立项目位于 `/mnt/asr`。在该目录运行 `npm start` 后访问 `http://127.0.0.1:3188/`，点击底部圆形按钮开始或停止监听，达到语音和静音条件时自动识别；也可选择 WAV 文件。网页模型和音频均在本地处理。APK 构建、模型要求及限制见 `/mnt/asr/README.md`。

线上静态网页：`https://c.aasc.us/mnt/asr/`。模型以相对网页入口的 `../aimodel/sensevoice/` 加载；本地预览同样提供该 URL 结构。

打开网页后等待模型下载和初始化，状态显示“模型已就绪”后才能录音；失败时可点击“重试加载”。圆形按钮内的红线是 VAD 阈值，填充表示实时音量；按钮上方和下方会显示语音时长及静音截止倒计时。

SenseVoice 模型和词表支持普通 HTTP 缓存：浏览器重新打开时会向服务器验证副本，未变更可收到 304 并复用。浏览器可能因容量策略清理或不保存大文件；即使命中缓存，仍需重新加载和初始化模型。

Android 调试版与网页一致：模型就绪前不可录音或选择 WAV；失败时可点击重试。圆形按钮中的填充为音量、红线为 VAD 阈值，下方显示语音时长和静音截止倒计时。

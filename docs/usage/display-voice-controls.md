# 显示端实时监听与单次语音输入

底部原停止播报位置现为实时监听开关，上方中央圆形按钮显示当前语音状态，状态文字位于按钮上方。开关首次默认开启，按显示端独立保存，刷新或重连恢复。

- 开启实时监听：持续采集，保持原有唤醒词、持续对话、声纹及播报暂停策略。点击圆钮打断本端播报并清空队列，继续监听。
- 关闭实时监听：不自动打开麦克风；点击圆钮先打断播报，再录一次。说完后的静音或再次点击结束录音，识别文字直接发送给当前聊天对象，支持群聊、助手和角色，不需唤醒词。一次最长 60 秒，没有有效语音不发送。
- 单次输入过滤未匹配声纹内容。控制端关闭该端的语音录音能力、暂停所有录音或 ASR 未就绪时，不能开始单次输入。
- 单次输入是点击开始/结束，不是按住说话。控制端单次录音/实时录音回传播放仍为独立用途，圆钮输入前需切回普通 ASR。

| 文字 | 当前状态 |
|---|---|
| 已停止 | 无录音或处理任务，麦克风未采集 |
| 空闲 | 实时监听待机 |
| 监听中 | 有效语音采集或单次录音 |
| 识别中 | 等待 ASR 结果 |
| 思考 | 等待当前聊天回复 |
| 说话中 | 本端音频实际正在播报 |

同时有多个任务时优先显示说话中、识别中、思考、监听中。隐藏顶部状态栏不隐藏这些入口。断线、关闭权限或切换模式取消旧录音，过期手动识别结果不再发送聊天。

2026-10-09 修复圆钮点击的播报处理函数名称：实时模式可执行打断，手动模式可在打断后进入“监听中”。修复通过服务代码包更新。

状态文字前显示当前助手名，例如“小爱 · 空闲”“妲己 · 监听中”；工作角色显示其角色名，群聊显示配置中的默认助手名。聊天面板关闭时名称仍随当前选择更新。

Offline APK重开后恢复已保存的聊天对象/私聊会话或工作角色，聊天面板保持关闭；有效私聊对象重新接入既有持续语音会话。旧版本未保存工作角色名字的会话需重新选择一次，之后可在重开时恢复。麦克风仍按原来的开关和权限运行。

以上修复已包含在2026-10-09发布的code v50服务包，更新后生效。

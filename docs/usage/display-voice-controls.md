# 显示端实时监听与单次语音输入

2026-10-10 原生录音音量柱修复已包含在code56服务更新：启用 Native AudioRecord 时，顶部柱状图读取原生 PCM 的真实音量并平滑显示；原生柱表示总体音量，浏览器采集仍显示频谱。暂停、停止和信号超时不会保持旧音量。状态栏隐藏时沿用原来的隐藏设置。

底部原停止播报位置现为实时监听按钮，上方中央圆形按钮显示当前语音状态，状态文字位于按钮上方。开关首次默认开启，按显示端独立保存，刷新或重连恢复。

- 开启实时监听：持续采集，保持原有唤醒词、持续对话、声纹及播报暂停策略。点击圆钮打断本端播报并清空队列，继续监听。
- 关闭实时监听：不自动打开麦克风；点击圆钮先打断播报，再录一次。说完后的静音自动结束；再次点击立即停止，只有有效语音和静音等待均满足才识别，否则丢弃本次录音。有效识别文字直接发送给当前聊天对象，支持群聊、助手和角色，不需唤醒词。一次最长 60 秒，没有有效语音不发送。
- 单次输入过滤未匹配声纹内容。控制端关闭该端的语音录音能力、暂停所有录音或 ASR 未就绪时，不能开始单次输入。
- 单次输入是点击开始/结束，不是按住说话。控制端单次录音/实时录音回传播放仍为独立用途，圆钮输入前需切回普通 ASR。

| 文字 | 当前状态 |
|---|---|
| 已停止 | 无录音或处理任务，麦克风未采集 |
| 空闲 | 实时监听待机 |
| 监听中 | 有效语音采集或单次录音 |
| 识别中 | 等待 ASR 结果 |
| 思考 | 等待当前聊天回复 |
| 说话中 | 本端音频实际正在播报 |

同时有多个任务时优先显示说话中、识别中、思考、监听中。隐藏顶部状态栏不隐藏这些入口。断线、关闭权限或切换模式取消旧录音，过期手动识别结果不再发送聊天。

2026-10-09 修复圆钮点击的播报处理函数名称：实时模式可执行打断，手动模式可在打断后进入“监听中”。修复通过服务代码包更新。

状态文字前显示当前助手名，例如“小爱 · 空闲”“妲己 · 监听中”；工作角色显示其角色名，群聊显示“群聊”。聊天面板关闭时名称仍随当前选择更新。

Offline APK重开后恢复已保存的聊天对象/私聊会话或工作角色，聊天面板保持关闭；有效私聊对象重新接入既有持续语音会话。旧版本未保存工作角色名字的会话需重新选择一次，之后可在重开时恢复。麦克风仍按原来的开关和权限运行。

最新代码增加底部ASR结果区，位于“助手名 · 状态”上方，保留最近一次结果，长文本可以滚动查看。实际监听采集时在同一个状态条末尾追加两位小数数字，如“小爱 · 监听中 0.03”；不单独显示VAD标签或背景，暂停或停止采集时去掉数字。再次点击未满足条件会直接停止，不继续等待静音；满足条件才识别。已包含在code v51服务包并发布内外网，Offline服务更新后生效。41项定向自测通过，Android实际录音需设备验收。

2026-10-10 本地最新代码纠正群聊状态名称，配置未到达或为空时不生成不存在的“助手”聊天对象；私聊显示所选真实名称。实时监听按钮开启时选中，关闭时中性；没有保存配置时默认开启，保存的关闭设置保持。本轮已包含在code56并发布LAN/WAN。

控制端进入“显示”面板并选中设备，在“监听 VAD / 底噪检测”卡片中点击“监听模式”按钮，可切换“实时监听／单次监听”。文字表示当前模式，保存回执到达后才更新；显示端下方按钮同步。单次模式仍需点击显示端中央圆钮开始录音。设备列表的“🎙️ 监听”只控制录音能力。断线和等待时模式按钮禁用，失败保留权威设置。

圆形状态按钮内部的小圆从底部按当前音量百分比填色，红线表示VAD阈值，两者使用同一刻度（RMS × 100%）；停止或暂停清空填色。识别结果位于状态文字上方，使用之前顶部文字的自适应字号和宽度，长内容可滚动，旋转后仍适配。

本轮所有界面及声纹路径修复均已包含在code56，Offline更新后刷新显示/控制页面生效；旧声纹恢复按用户要求不执行。

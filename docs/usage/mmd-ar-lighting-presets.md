# 独立 MMD-AR 灯光预设

打开「灯光 → 灯光预设」。该分类可展开/收起，全部预设操作集中在这里。

1. 调好灯光，输入名称，点击「保存新预设」。
2. 在列表选择预设，一次恢复完整灯光面板参数。继续调节会显示「已修改」；点击「覆盖所选」才会更新保存的记录。
3. 「导出所选」下载一个预设，「导出全部」下载整个预设库的JSON文件。
4. 「导入文件」选择JSON，导入后在列表手动选择应用。重名自动附加“导入”编号，保留原预设。
5. 「删除所选」只删除记录，当前灯光保持；「恢复默认」恢复“日光”完整灯光默认值，命名预设保留。

保存范围包含基础光照、主/补/边缘光、高光、阴影尺寸与范围/拟合/预览、补光明暗过渡、AO（含法线预览、半分辨率边界修正）、接触阴影、SSGI及TAA/FSR2/Canvas倍率。动作、物理、模型、Human、定位和相机独立；面板不透明度、折叠和临时读数不保存。

默认灯光采用用户提供的“日光”文件：环境光1、主光2.85、红色补光5、2048阴影/AO全分辨率/32采样/SSGI开启，抗锯齿关闭。首次没有有效当前设置的分组采用日光；已有保存设置优先。希望已有浏览器立即使用它时，点击「恢复默认」，十组设置会一起恢复并记忆。默认源在仓库`3rd/mmd-ar-test/web-lighting-default-preset.json`，更新默认参数后需要重新构建网页。

预设存在当前浏览器，刷新后保留。不同浏览器或设备之间通过导出/导入文件传递。每库最多100条，名称1至64字符，文件不超过256KiB。损坏文件会显示原因，保留已有库与场景。能力不足的设备沿用现有限制，预设中的原请求值保持；如果覆盖所选，则保存当前设备实际值。

本地web-dist已构建；外网独立网页尚未发布。当前功能范围为独立WEB页。

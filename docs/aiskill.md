# AI 助手技能
- 更新所有spec文档，使用伪代码描述
- 更新所有design文档，描述每个功能模块的需求设计

## 服务器重启规则

- AI 修改代码后需要重启或重载服务器时，只能使用控制端提供的重启/重载接口或控制端操作。
- 禁止直接控制服务器进程：不得执行 `kill`、`pkill`、`killall`、发送终止信号、查找并操作服务器 PID，或直接启动、停止、重启 `server-app.js`。
- 当前服务器由用户手动启动时，AI 不得终止、替换或接管该进程；控制端接口不可用时应报告给用户。
- 该规则适用于工作 AI、workgroup 子 agent 和控制端 AI 角色。

## 执行todo文档 
- 选择一个未完成任务，
- 分析需求写入design文档，
- 根据design文档，更新spec文档
- 写入执行任务到task.md (包含任务描述、design需求、spec设计，受影响的功能模块和代码，自测用例)
- 根据task.md 实现功能模块的代码
- 把任务从todo文档中移除，更新todo文档
- 更新design文档，描述已完成的功能模块
- 把task.md 归档到task目录里，名字为简要需求描述.md

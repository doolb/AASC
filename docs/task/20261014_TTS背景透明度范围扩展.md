# TTS 背景透明度范围扩展

## 任务描述

将控制端“界面主题”中的 TTS 字幕背景透明度范围从 0%–20% 扩大到 0%–100%，保留默认 20%。任务列表鼠标/触控笔拖动滚动不在本次实施范围，待用户真机试用后再决定。

## Design 需求

- 滑块范围 0%–100%，步长 1%，默认 20%。
- 控制端用百分比呈现，保存时转换为 0.00–1.00 alpha 比例。
- 服务端和 WebSocket 沿用现有比例值契约，校验 0–1 并按 0.01 规范化；缺省仍回退到 0.2。
- 不改显示端 CSS 变量协议、渐变结构、模糊、字幕文字和生命周期。

详见 `docs/design/display-tts-background-opacity.md` 与 `docs/spec/display-tts-background-opacity.md`。

## 自测用例

- 滑块属性为 min=0、max=100、step=1、value=20。
- UI 0%、20%、73%、100% 分别映射为 WebSocket alpha 0、0.2、0.73、1；权威配置反向映射显示正确百分比。
- 服务端接受 0、0.2、1，按 0.01 规范化；拒绝负数、大于 1 和非数值；缺省值仍为 0.2。
- 显示端渐变峰值接受 alpha 1，背景模糊保持 4px，文字 opacity 保持 1。
- WebSocket 保存、广播和连接补发契约保持不变。

## 兼容性测试

验证旧配置值 0.2 仍展示为 20%；未收到远端配置时显示端仍采用 alpha 0.2。范围变化只影响控制端选值上限，不改变消息名或比例值字段。

## 性能测试

滑块仅在用户输入及 WebSocket 配置消息到达时更新预览/CSS 属性，不添加逐帧任务；记录浏览器回归即可。

## 风险评估

高 alpha 会使黑色字幕背景更明显；百分比和 alpha 若转换两次或遗漏转换会造成显示值错误。测试需覆盖 UI 到远端、权威回传到 UI 的双向换算，以及 0/100 边界。

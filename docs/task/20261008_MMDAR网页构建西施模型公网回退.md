# MMD-AR web-dist 西施 GLB 公网回退

日期：2026-10-08。状态：实现与Web构建验证完成；浏览器测试受当前Windows环境缺少/usr/bin/chromium影响跳过。

## 任务描述

独立网页构建依赖未纳入Git的 `3rd/mmd-ar-test/output/xishi/xishi.glb`。本地模型导出物缺失或损坏时，当前 `npm run build:web:mmd-ar-test` 无法产出 `web-dist`。在网页构建模式下增加从现有公网资源清单读取版本化西施GLB并验证后回退的能力。

## Design 需求

- 仅 `build:web:mmd-ar-test` 的网页模式启用公网回退；APK构建仍要求本地资源，保持离线和可复现边界。
- 有效本地GLB优先使用；缺失或GLB头/长度无效时才下载，不覆盖Blend源文件或 `output/xishi/xishi.glb`。
- 公网入口为 `https://c.aasc.us/mnt/mmd-ar/mmd-resources.json`；按清单选择 `xishi-default` 静态GLB，模型URL限定同源HTTPS及 `/mnt/mmd-ar/mmd/xishi/` 版本化路径。
- 采用清单完整SHA-256验证下载字节，并校验GLB magic/version/声明长度；限制请求超时、manifest大小和模型最大64MiB。
- 任何HTTP、结构或哈希验证失败均清晰报错并终止构建，不降级为未验证内容。

## 自测用例

1. 本地GLB有效时复用本地字节且不触发网络。
2. Web构建缺失/损坏本地GLB时，使用mock fetch响应提供manifest和GLB，校验SHA-256后使用内容哈希文件名。
3. 非Web/APK构建缺少本地文件时仍失败且不触发fetch。
4. 拒绝HTTP、不受信host/path、错误角色ID/type、非法SHA字段、错误模型名、GLB头/长度错误、哈希不符、HTTP失败、超时和超大响应。
5. `node --test tests/mmd-ar-web-characters-build.test.js`：7/7通过；与阴影拟合回归组合运行19/19通过。
6. `npm run build:web:mmd-ar-test`：本地GLB缺失时成功读取公网清单，下载并校验 `xishi-ee3602cbb49e.glb`，生成 `web-dist` 及资源清单；Blender工作区依赖按仓库锁文件安装后构建成功。
7. 现有阴影浏览器测试2项因Windows环境缺少配置的 `/usr/bin/chromium` 跳过；未做真实浏览器/设备观感验收。

## 兼容、性能与风险

- 公网服务临时不可用时Web构建仍失败；错误须指出清单/模型下载阶段，保留本地GLB优先路径。
- 版本化静态资源及完整SHA保证清单切换时下载内容与宣告版本一致；限制域名和路径防止清单劫持到任意URL。
- 下载约11MiB GLB仅发生于本地模型不可用的构建过程，不影响运行时加载、显示端或APK构建。
- 不写入源码模型目录，避免把网络副本误认为新导出源。

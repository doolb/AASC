# AASC 网络演进流程记录

## 任务描述

记录 AASC 网络从固定主服务器入口开始的后续开发顺序和范围边界。当前主服务器入口固定为 `https://192.168.1.39:8081/`，不实现自动发现。

## Design 需求

演进顺序如下：

1. 服务器节点注册与心跳。
2. `/server` 服务器代码下发和 Bootstrap 更新。
3. 服务器媒体库索引共享。
4. 显示端优先的任务路由，必要时回退到主服务器或子服务器。
5. 网页版在已登记服务器之间手动切换。
6. 用户、节点、媒体库和操作权限认证。

## Spec 设计

```text
节点读取固定主服务器地址
    → 注册节点并维持心跳
    → 主服务器返回节点状态、能力和媒体索引摘要
    → 控制端展示服务器列表
    → Bootstrap 通过 /server 获取版本清单和代码包
    → 节点校验并启动代码
    → 服务器上报媒体索引
    → 任务优先投递到匹配显示端
    → 无匹配显示端时回退到服务节点
    → 网页端支持已登记服务器手动切换
    → 最后增加权限认证
```

## 当前不做

- 局域网自动发现；
- 最近服务器自动选择；
- 媒体文件全量同步；
- 主服务器故障转移；
- 权限认证实现。

## 自测用例

1. 文档明确固定主服务器入口和手动配置方式。
2. 文档按顺序记录六个后续开发阶段。
3. 文档明确显示端优先、子服务器按需回退。
4. 文档明确自动发现、全量同步和权限认证暂不实现。

## 兼容性与性能

## 风险评估

- 服务器节点注册协议需要在后续实现前确定身份、版本和能力字段。
- `/server` 代码下发需要在正式启用前补充代码包校验和访问控制。
- 媒体索引共享需要单独定义索引一致性、缓存和文件访问契约。

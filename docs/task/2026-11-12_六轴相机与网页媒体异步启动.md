# 六轴相机与网页媒体异步启动

需求：镜头使用网页加速度和角速度；Offline 启动不等待网页媒体。
设计及实现：见壁纸控制和网页媒体的 design/spec；复用实验室六轴去重力思路，限制镜头偏移；异步绑定并在首次使用时限时检测。
影响：壁纸网页、Android 服务和网页媒体适配器。
自测：静止、旋转、平移、屏幕方向、数据缺失及关闭；服务延迟就绪、鉴权错误和超时；Android 编译。
兼容：无传感器时提示，普通模式与壁纸共用；服务代码兼容旧 APK；异步启动需要更新 APK。
性能：每事件常数运算，服务探测仅首次使用。
风险：纯惯性存在漂移，镜头只作短时平滑反馈；需目标手机实测。预计工时：半天。

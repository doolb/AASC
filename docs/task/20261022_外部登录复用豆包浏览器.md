# 外部登录复用豆包浏览器

用户已确认：共用现有豆包浏览器，固定profile+本机debugPort，关闭只回收登录tab，禁用退出确认，不创建空白页。

设计与spec：chat2api-remote-login。enterprise主L6共享浏览器租约契约、次L5启动/重连/关闭流程；证据为共用宿主、固定profile/端口、独立标签三项，评分95/100，置信度0.90，可开发。下放到L4：按profile校验归属、分Context页面、pin阻止宿主切换。

实现：login-browser/remote-browser-session复用browser-port；bridge增加openLogin与默认Context整理过滤；launcher持久化active-browser.json、检查归属并重连、专用Vivaldi关闭退出确认；server-app退出停止共享桥。

风险：旧实例无enable-automation时须读取version页面校验profile；强制退出只恢复浏览器连接，WS登录需重新开始；登录Context仍隔离凭据，保存由OAuth处理。其他账号运行请求在登录占用期间明确busy。

自测：本地HTTP+隔离Vivaldi验证鼠标/中文文字输入/画面/凭据隔离、共享租约、CDP断开重连同端点、错误profile拒绝；bridge测试验证运行请求不会关闭登录Context。增加有窗口测试验证内置prefs API。兼容：Android原路径不接入；10种Provider官网仍待人工验收。性能：复用进程，不增加配置HTTP接口；无长期性能基准。预计1天；未明确需求无。

仅servicePackage保持true，文档和测试随代码提交；不操作正式账号、不发送模型测试消息、不出APK。

结果：13项定向和最终13项有窗口验证通过；Chat2API整套363通过/1毫秒间隔断言失败，该语音文件单独6项通过，完整回归未全通过。遗留登录Context记录按端点及ID定向回收测试通过。

# PMX 上一帧旋转物理时序试验

## 任务描述

现场反馈 PMX 中心枢轴缓动旋转期间布料仍会明显变乱。先试验把物理解算调整到本帧缓动之前，使 Bullet 使用上一渲染帧的角色角度；解算完成后再将本帧枢轴增量同步给所有刚体，并渲染当前角度。试验效果由真实 PMX 模型观察决定，不预先声明布料问题已修复。

## Design 需求

- 仅调整 PMX 渲染帧中的物理、缓动和刚体同步顺序，保留现有中心枢轴与缓动参数。
- 刚体位置、姿态、线速度、角速度和 MotionState 继续随枢轴增量整体同步，不复位布料物理状态。
- 当前帧显示当前角度；下一帧从已经同步到当前角度的刚体状态开始物理解算。
- VRM SpringBone、无物理 PMX、VMD/IK/grant、物理频率和模型加载时序保持现有行为。

## Spec 伪代码

```text
过程 renderMmdFrame(delta)
  使用上一渲染帧枢轴姿态调用 helper.update(delta)
  更新中心枢轴的 yaw/pitch 缓动
  pivotDelta = 当前 pivot 世界矩阵 × 上一渲染帧 pivot 世界矩阵的逆矩阵
  对所有 Bullet 刚体同步 pivotDelta 下的位置、姿态、线速度和角速度
  将当前 pivot 世界矩阵保存为下一渲染帧基线
  渲染本帧场景
```

## 自测用例

1. 连续 yaw/pitch 旋转、快速反向拖动期间观察布料是否爆散或穿模，停止后是否自然收敛。
2. 在 30、65、90 Hz 物理目标频率下重复观察，确认问题不会随频率严重恶化。
3. 模型加载后第一帧、VMD 播放、无刚体 PMX 和 VRM 显示行为保持正常。

## 兼容性测试、性能测试与风险评估

- 兼容性：不更改 Ammo vendor、刚体/关节配置、VRM 或持久化配置；仍使用现有 `MMDAnimationHelper`。
- 性能：每帧物理步数和刚体遍历次数不增加；仅移动调用顺序。
- 风险：布料物理对角色旋转的响应延迟一个渲染帧；同帧多个 Bullet 子步仍在同一旧枢轴姿态下运行，故该试验可能只能改变扰动时序，不能根治问题。若现场失败，再评审固定子步插值设计。

预计 20–40 分钟实现与静态检查；实机布料效果等待用户观察。当前代码已按试验方案调整；定向测试 23/23、相关 JavaScript 语法检查和差异检查通过，等待实际模型的布料观察结果。

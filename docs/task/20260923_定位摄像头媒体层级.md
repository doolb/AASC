# 2026-09-23 定位摄像头媒体层级

## 任务描述

定位中的摄像头画面只覆盖媒体内容，位于媒体层上方、语音和任务状态及 MMD/聊天交互层下方。

## Design 需求与 Spec 设计

- 将实时视频从 `displayStageLayers` 移为 `mediaContainer` 后的独立兄弟节点。
- 媒体层为 1，视频层为 2；保留其余界面的现有层级。
- 视口变化时让视频与 MMD 舞台尺寸一致，脚底锚点继续使用同一显示区域计算 `cover` 裁切。
- 停止定位时隐藏视频并释放摄像头流。

## 受影响模块和代码

- `display.html`、`css/display-mmd.css`、`js/display-stage.js`、`js/display-mmd-ar.js`。
- `docs/design/mmd-image-ar.md`、`docs/spec/mmd-image-ar.md`、`docs/todo.md`、`changelog.md`、`release/offline-release-status.json`。

## 自测用例

- 开始定位后视频覆盖图片/视频/文本媒体，不覆盖语音状态、任务状态、聊天和角色。
- 横竖屏及可视视口变化时视频与 MMD 画布保持同尺寸，脚底不因层级变化偏移。
- 停止定位和页面隐藏后视频隐藏、摄像头轨道释放。

## 兼容性、性能与风险

- DOM 层移动不改变摄像头权限、IndexedDB 目标格式和识别数据。
- 视频只创建一个元素并复用原摄像头流；预计工时约 1 小时。
- Android WebView 的可视视口与 CSS 视口差异可能影响对齐，需在目标设备观察。

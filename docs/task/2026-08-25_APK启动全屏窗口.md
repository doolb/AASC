# APK 启动全屏窗口

## 任务描述

修复 Samsung DeX 环境下 APK 启动为 `freeform` 小窗口的问题，使显示端启动时直接占满 DeX 屏幕。

## Design 需求

- 普通 Android 设备继续使用现有沉浸式系统栏隐藏逻辑。
- Samsung DeX 启动窗口宽高设置为 0，表示启动即全屏。
- 不误判 `minSdk` 版本变更：`minSdk 24→26` 只影响最低系统版本，`targetSdk` 保持 34。

## Spec 设计

- 在 `AndroidManifest.xml` 的 `application` 下增加 Samsung DeX 全屏启动元数据。
- 保留 MainActivity 的 `hideSystemUi()`，覆盖 DeX 全屏窗口内的状态栏/导航栏。
- 增加 Manifest 静态回归测试。

## 受影响的功能模块和代码

- `src/apps/android-display/app/src/main/AndroidManifest.xml`：DeX 启动窗口配置。
- `tests/apk-deploy-config.test.js`：全屏元数据回归检查。
- `docs/design/android-display.md`、`docs/spec/android-display.md`：设计与伪代码同步。

## 自测用例

1. Manifest 同时声明 `launchwidth=0` 和 `launchheight=0`。
2. 运行 APK 部署配置和 Android 相关静态测试。
3. 构建 APK 并安装到 SM-N9500，在 DeX 环境启动后确认窗口占满屏幕；若旧包签名不同，需先由用户确认是否卸载旧包再安装。
4. 普通 Android 窗口仍能隐藏状态栏和导航栏。

## 兼容性测试

- Android 9 / Samsung DeX。
- Android 7+ 普通显示端。
- 已有 WebView、ASR、TTS 和显示端 WebSocket 行为不变。

## 性能测试

- 仅增加 Manifest 元数据，无运行时循环和额外内存开销。

## 风险评估

- DeX 版本较旧时可能忽略新元数据；保留现有沉浸式标志作为降级路径。
- 重新安装 APK 后需要由 DeX 重新创建任务窗口，旧任务窗口可能保留原尺寸。

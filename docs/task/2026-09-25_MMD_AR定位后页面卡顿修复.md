# MMD AR 定位后页面卡顿修复

## 任务描述与设计

- HTTPS 测试网页找到定位图后摄像头仍更新，但页面按钮无法点击；只修测试网页，不重打 APK。
- 识别输入与可见预览分离：前者受像素预算约束，后者保持相机原分辨率；跟踪结果和模型姿态更新限速。
- 对应设计：`docs/design/mmd-ar-test-apk.md`；相机世界姿态跟踪是另一个待确认方案，不属于本次修复。

## Spec、受影响模块与风险

- 对应伪代码：`docs/spec/mmd-ar-test-apk.md` 的「MindAR 视频输入」。
- `3rd/mmd-ar-test/display-mmd-ar-benchmark.js`：独立识别画布、输入像素预算、画布刷新和姿态更新限速。
- `src/apps/web-mediacenter/ui/public/js/display-mmd-ar.js`：重复样本不再重复设置状态/模型姿态；正式旧跟踪器无 `newSample=false`，行为不变。
- `tests/mmd-ar-web-tracking.test.js`：1920×1080 合成相机、官方图首锁、页面点击响应、空白帧丢失与输入尺寸检查。
- 风险：移动端硬件 GPU、摄像头曝光和 PMX AO 性能与 Chromium 合成视频不同；真机仍需现场复测。预计工时半天。

## 自测与兼容性

- 运行 `npm run build:web:mmd-ar-test` 和定向 AR/面板回归；检查识别后点击和停止定位。
- 确认无 APK、Offline 服务、模型、正式显示端资源发布。
- 性能验收：识别画布不超过 640×480 像素预算，姿态写入不超过每 100 ms 一次。

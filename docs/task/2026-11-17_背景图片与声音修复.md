# 背景图片与声音修复

- 需求：通用背景支持图片；排查音频与视频背景无声并反馈真实播放失败。
- 设计与伪代码：`docs/design/audio-media.md`、`docs/spec/audio-media.md`。
- 范围：背景媒体控制端、显示端、服务端状态报告及自测。
- 自测：音视频有声音量及静音、播放拒绝、并发切换；图片/GIF 选择、切换、暂停、停止与重连；睡眠与主媒体隔离。
- 兼容：旧状态与旧客户端保持原默认值，旧客户端忽略新状态消息。
- 性能：同一时刻仅加载一个背景元素，状态报告只在状态变化时发送。
- 风险：终端自动播放策略、音频焦点、编码及外部地址仍可能阻止播放；真实声音需要目标设备验收。
- 预计工时：1 个工作日。

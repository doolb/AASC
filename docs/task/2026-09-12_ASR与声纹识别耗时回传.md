# ASR 与声纹识别耗时回传

## 任务描述

为正式显示端 `asrResult` 增加 ASR 和声纹识别模型处理耗时，便于服务端日志定位识别性能。

## Design 需求

- 增加 `asrElapsedMs` 和 `voiceprintElapsedMs` 两个毫秒字段。
- 只统计模型处理阶段，不统计 VAD、音频解码、网络和播放。
- 未执行的识别阶段返回 `null`；多人模式返回整段累计耗时。
- 网页显示端、服务端日志保持字段透传和旧字段兼容。

## Spec 设计

- Android `NativeBridge` 使用 `System.nanoTime()` 统计单调耗时。
- ASR 计时包围 `recognizeText`；声纹计时包围分段/提取/匹配流程。
- `display.html` 的原生结果回调透传两个字段。
- `asr-result-log-formatter.js` 在详细和简要日志中记录两个字段。

## 自测用例

1. 普通 ASR 结果包含 `asrElapsedMs`，声纹耗时为 `null`。
2. 单人声纹结果同时包含两个非负耗时。
3. 多人声纹结果包含整段累计两个耗时。
4. 网页和服务端日志不丢失耗时字段。
5. 缺少或非法耗时字段时日志规范化为 `null`。

## 兼容性测试

- 旧版 Native 结果不带耗时字段时仍可正常处理。
- 旧版服务端调用和无声纹路径不改变文本、speaker、分段和命令处理。
- Node 子显示端继续兼容服务端 ASR 响应中的可选字段。

## 性能测试

- 计时只增加单调时钟读取，不增加模型推理次数。
- Android JVM/静态契约测试通过后再执行正式 APK 编译检查。

## 风险评估

- 中风险：多人模式包含多个 ASR 分段，需要累计每段耗时，避免只记录最后一段。
- 低风险：新增字段均为可选诊断字段，不参与识别门控和命令路由。

- `asrResult` 新增 `asrElapsedMs` 和 `voiceprintElapsedMs`，普通 ASR、单人声纹、多人声纹及兼容回退路径均提供耗时。
- 服务端 HTTP ASR 响应和 `<< asrResult` 日志保留并规范化两个字段；旧结果缺少字段时返回/记录 `null`。

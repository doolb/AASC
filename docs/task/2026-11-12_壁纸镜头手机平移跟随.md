# 壁纸镜头手机平移跟随

- 任务：镜头跟随手机上下左右平移，每帧平滑回位；角色倾斜保持独立。
- 设计：Android 线性加速度传感器与网页 devicemotion 输入；屏幕轴换算、有界积分、速度阻尼与按时间指数回位。
- spec：分别处理姿态和运动；缺桥/传感器提示，切换或隐藏清状态；复用 PMX/VRM 镜头。
- 影响：原生传感器桥、壁纸网页及 UI、对应自测和文档；Offline min APK 与服务包待构建。
- 自测：移动/倾斜分离、屏幕旋转、每帧回位、停止/重启、传感器不可用及帧率差异。
- 兼容：旧 APK 不支持运动桥；浏览器需提供线性加速度。真实手机、壁纸生命周期和不同厂商传感器需现场验收。
- 性能：复用页面动画循环，仅在启用时进行少量标量运算；性能需实机确认。
- 风险：惯性估算非真实定位，姿态/零偏与旋转可能引起误触发；持续回中会丢失绝对位置。
- 预计工时：3–6 小时。

# Offline 控制端输入框自动缩放禁用

## 任务描述

Offline APK 打开控制端后，选中输入框并弹出软键盘时页面会自动放大。需要仅禁用 Offline 控制端输入框聚焦触发的页面自动缩放，保留 Offline 初始缩放比例，不影响显示端、普通 APK 和服务端浏览器控制端。

## design 需求

- 为控制端 WebView 增加独立的输入焦点缩放策略。
- 控制端页面加载完成后，将 viewport 约束为 `maximum-scale=1`、`user-scalable=no`。
- 不修改服务端 `upload.html`，避免影响浏览器控制端。

## spec 设计

```text
createWebView(url, offlineMode, isControlPage):
    webView = DisplayWebView(context, offlineMode, disableInputAutoZoom = offlineMode && isControlPage)
    页面加载完成时：
        如果 disableInputAutoZoom：更新或创建 viewport meta
        设置 maximum-scale=1、user-scalable=no
```

## 受影响的功能模块和代码

- `DisplayWebView.kt`：增加控制页标记和 viewport 注入逻辑。
- `MainActivity.kt`：只给 Offline 控制 WebView 启用策略。
- `tests/android-offline-apk.test.js`：增加控制页与显示页隔离的静态契约测试。
- `docs/design/android-display-offline-apk.md`、`docs/spec/android-display-offline-apk.md`、`docs/todo.md`、`changelog.md`：同步设计、实现和验证结果。

## 自测用例

- 普通 APK 控制端不注入禁用缩放策略。
- Offline 显示端不注入禁用缩放策略。
- Offline 控制端注入 `maximum-scale=1`、`user-scalable=no`。
- Offline 静态回归与 Android JVM 单测通过。

## 兼容性测试

- Android 9/API 28、SM-N9500、Display 2 Desktop 虚拟屏。
- 控制端输入框、聊天输入框和 VAD 配置输入框聚焦后不触发页面级自动放大。

## 性能测试

- 只在控制页加载完成后执行一次轻量 DOM viewport 更新，不增加服务请求和 APK 资源。

## 风险评估

- 禁用页面缩放可能影响控制端手势缩放；Android 原生 WebView 当前已关闭支持缩放，本策略只收紧输入焦点场景。
- 若页面没有 `head` 或 viewport 元素，脚本跳过更新，不阻塞控制端加载。

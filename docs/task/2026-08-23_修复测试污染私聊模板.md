# 修复测试污染私聊模板

## 任务描述

修复 Agent 模式测试将临时模板写入真实用户配置，导致服务器重启后私聊模板入口消失、历史记录无法从控制端进入的问题。

## design 需求

- 模板测试支持只更新内存，不修改用户配置文件。
- 恢复已有私聊历史对应的模板入口。
- 不删除或重写聊天历史文件。

## spec 设计

- `setTemplates(templates, { persist: false })` 只更新内存。
- 生产调用不传该选项时保持原有持久化行为。
- 测试结束只恢复内存模板。

## 受影响的功能模块和代码

- `src/external/llm/llm-service.js`
- `tests/llm-agent-mode.test.js`
- `~/.config/aasc-user/chat-templates.json`

## 自测用例

- `persist:false` 不调用模板文件写入。
- Agent 模式相关测试全部通过。
- 启动聊天服务后可读取小爱、妲己模板。
- 私聊历史至少保留小爱、妲己原有记录和会话。

# PMX AO 参数与去噪

## 任务描述

用户反馈 PMX 角色 AO 在浅色衣服上有明显颗粒噪点，同时要求灯光面板可调整 AO 颜色、强度和半径。仅修改显示端本地 PMX 渲染与灯光设置；不构建或发布 APK、服务包。

## Design 需求与 Spec 设计

- 需求来源：`docs/design/mmd-pmx-vmd-local.md` 第 13 节。AO 保持默认开启；新增黑色/1/角色高度 6% 的默认参数，分别限制强度 `0–2`、半径 `1–20%`。
- 伪代码：`docs/spec/mmd-pmx-vmd-local.md` 的 `normalizeMmdLighting`、`setMmdLighting`、`renderPmxWithAo` 与 `updatePmxAo`。半分辨率 AO 结果先水平、后垂直做视空间深度保边模糊；最终合成只改变 RGB，保持原 alpha。
- 兼容：旧 localStorage 缺字段时采用默认值；VRM 不使用 PMX AO 参数；亮度预设保留当前参数，恢复默认重置参数；模型切换重新按当前角色高度换算半径。

## 受影响模块

- `display-pmx-ao.mjs`：模糊通道、AO 颜色/强度。
- `display-pmx-runtime.js`：参数规范化、按角色高度换算半径。

- `tests/display-pmx-ao.test.js`、`tests/display-pmx-ao-browser.test.js`：状态和浏览器像素测试。
- `docs/design/mmd-pmx-vmd-local.md`、`docs/spec/mmd-pmx-vmd-local.md`、`docs/usage.md`、`docs/self-test.md`、`docs/todo.md`、`changelog.md`：文档同步。

## 自测用例

1. 旧设置默认黑色、强度 1、半径 6%；非法值被规范化，面板修改后保存，恢复默认重置。
2. 浏览器几何场景中强度 0 接近关闭 AO；红色遮蔽主要保留红通道；扩大半径增加接触暗部范围。
3. 真实本地米娅 PMX 的 AO 开关前后可见 alpha 一致，透明背景不变。
4. 目标 Android WebView 现场观察浅色衣服/头发的颗粒、轮廓串色与动作中的稳定性。

## 兼容性、性能与风险

- WebGL2 不可用时沿用直接渲染。两次半分辨率模糊增加 GPU 通道；关闭 AO 时不执行额外通道。
- 深度保边权重可能使复杂发丝边缘残留颗粒，半径太大可能造成暗部过宽；需目标设备现场比较画质与帧率。
- 不改 VMD、PMX 资源、物理步进、阴影开关或远端配置协议。

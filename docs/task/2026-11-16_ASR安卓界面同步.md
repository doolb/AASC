# 独立 ASR Android 界面同步

- 任务：将网页的 VAD 红线、音量和截止显示同步至独立 APK，并增加模型失败重试及就绪门禁。
- 设计：沿用日光配色和 0.01 RMS、300ms、500ms、59 秒参数；原生模型内置不使用 HTTP 缓存。
- 规格：见 `docs/spec/standalone-asr.md`，状态与识别实际使用同一 VAD 判断。
- 影响：`/mnt/asr/android` 的界面、VAD、模型加载及单元测试；重新构建 debug APK。
- 自测：模型就绪门禁、失败重试、音量和阈值、短语音、静音倒计时、59 秒上限、停止释放。
- 兼容：Android 8+、arm64；WAV 输入原能力保留。
- 性能：每约 100ms 更新一次显示，识别继续后台执行；无额外模型。
- 风险：低内存加载失败可重试；实际麦克风和布局须真机验收。
- 预计工时：半个工作日。

- 验证结果：debug APK 构建成功，2 项 Android VAD 单元测试通过，APK v2 签名校验及模型文件检查通过；当前无连接设备，真实界面和麦克风未验收。

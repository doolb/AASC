# 忽略打包生成目录任务

## 任务描述

为当前打包目录和本机编译缓存补充精确 `.gitignore` 规则。用户确认同时从 Git 索引解除对 Android `.cxx` 与 Puppeteer 临时 profile 的跟踪，但保留本地文件。

需求分级：主层级 L5（仓库产物与版本控制流程），次层级 L4（具体忽略规则）；风险低。需求范围明确，不涉及运行时功能或发布。

## Design 需求

- 忽略 APK profile 的生成子目录、Offline 更新构建输出、下载的 third-party build cache、Android 原生编译缓存和离线打包临时目录。
- 仅忽略命名为 `mmd-ar-publish-*` 的 `.cache` 快照，保留 `.cache` 中其他审计、测试和用户文件。
- 不忽略 `release/`、`build/`、`.cache/` 整树，不忽略模型、`release/task` 输入、任务结果、配置、源码和 `release/1.txt`。
- 对已跟踪的 `.cxx` 与 Puppeteer profile 只执行索引解除跟踪，本地文件不删除。

## Spec 伪代码

```text
ignoreGeneratedBuildDirectories:
    ignore profile gradle/output/runtime/package
    ignore offline-update output* and node-compile-cache
    ignore build/third_party and Android native/Kotlin build caches
    ignore offline build temporary directories and mmd-ar-publish-* snapshots

preserveReleaseSeedsAndUserFiles:
    keep app.json, release/config, release/userconfig, release/task/results
    keep res/models, other .cache files, source and unknown release files

untrackApprovedLocalCaches:
    remove .cxx and Puppeteer profile paths from Git index
    preserve existing local filesystem contents
```

## 影响范围

- 配置：根目录 `.gitignore`。
- 文档：`docs/design/release-build-profiles.md`、`docs/spec/release-build-profiles.md`、索引、`docs/rules.md`、`docs/spec/self-test.md`、`docs/todo.md` 和 `changelog.md`。
- Git 索引：`src/apps/android-display/app/.cxx/` 与 `tmp/puppeteer_dev_chrome_profile-BhTS0i/` 内已跟踪文件。
- 不修改 npm scripts、APK profile 配置、模型、任务运行数据或发布状态。

## 自测用例

1. 使用 `git check-ignore -v --no-index` 确认当前 APK/Offline 构建输出和缓存命中忽略规则。
2. 确认 profile `app.json`、`release/task/*/results/`、模型、普通 `.cache` 文件和 `release/1.txt` 不匹配新规则。
3. `git ls-files` 确认已批准解除跟踪的两类缓存不再由索引跟踪，本地路径仍存在。
4. `git status --short` 确认当前构建输出不再作为未跟踪目录列出，已跟踪缓存以待提交删除显示，其他用户文件与既有改动仍可见。
5. 执行 `git diff --check`；不运行 APK、服务包、模型下载或同步脚本。

## 兼容性、性能与风险

- 兼容性：打包输入与 `release/apkbuild/<profile>/app.json` 保持跟踪；`release/task` 结果仍可进入 APK 种子。
- 性能：无运行时或构建耗时影响；忽略目录只影响 Git 状态扫描。
- 风险：索引解除跟踪会形成待提交删除；仅针对用户已确认的缓存路径，工作区内容不删除。提交后这些本地生成缓存不会再出现在 Git 状态中。
- 预计工时：0.5 小时。

## 执行结果

- `.gitignore` 规则命中全部 12 组代表性 APK/Offline/cache 路径；`app.json`、release task results、模型、普通 `.cache` 文件和 `release/1.txt` 均未命中。
- `.cxx` 和 Puppeteer profile 共 232 个路径从索引解除跟踪，本地目录均仍存在；对应索引删除保留在暂存区等待提交。构建输出不再以未跟踪目录出现在状态中，release task results、模型、普通 `.cache` 和其他用户文件仍可见。
- `git diff --check` 与 `git diff --cached --check` 均通过；未执行构建、发布、同步或清理。

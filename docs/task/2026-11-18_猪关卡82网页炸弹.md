# 第 82 关网页炸弹

- 任务：将实机通关的第 82 关首屏及 104 步接入独立网页，支持炸弹计数、失败和撤回。
- 设计：碰撞影响相关炸弹，归零失败；显示剩余次数并允许撤回和重开。原地碰撞、两个炸弹互撞和爆炸表现尚无实机证据，暂按模型处理。
- 实现：先更新 `subproject/aasc-game/docs/spec/pig-game.md` 的状态、碰撞和回放伪代码；修改网页引擎、界面、关卡数据与静态服务注册。
- 影响模块：猪关卡网页及其本地静态服务、网页自测和使用说明；不改变 Offline 服务打包配置。
- 自测：完整路线的第 73 步计数、104 步胜利、碰撞方向、原地碰撞、爆炸、撤回及重置。
- 兼容性：回归已有 2～70 关完整路线与动画；检查关卡选择和本地资源访问。
- 性能：沿用单步网格碰撞检测，检查完整路线自测运行时间。
- 风险：部分炸弹边界规则未实机核验，后续依据真实画面修正；第 81 关首屏尚不完整。
- 预计工时：2～4 小时。
- 验证结果：`npm run test:pig-web` 80 项通过（含 2～70 关及第 82 关完整回放）；`npm run test:pig-animation` 浏览器验证通过（含计数、爆炸、撤回和胜利）；`npm run test:pig-locked` 10 项通过。第 82 关网页完整回放约 0.55 秒（并行运行时）。

# 全量配置与聊天数据 ZIP 导入导出

状态：功能已实现；定向自测与 Android 编译通过。

## 用户需求

新增全量配置导出和导入，包含全局配置、用户配置和聊天数据；用户明确压缩成 ZIP，导入后自动重启服务器，发布时生产依赖包重新生成。

## 已核对与 design/spec

现有 aasc-user JSON 备份覆盖用户目录，缺全局配置；普通/release 目录由 release-runtime-context 决定。用户目录包含群聊/私聊、角色与 Chat2API 持久化数据。现有配置缓存和聊天延迟保存不适合在线全量覆盖。APK 已有文件选择和16 MiB保存桥，本次扩展流式系统文档保存入口。

设计见 docs/design/full-config-backup.md；伪代码见 docs/spec/full-config-backup.md。默认文件合并、可选完整替换；确认导入后自动重启，在新进程加载配置前应用。

## 受影响代码

- 新增 src/apps/server/modules/config/full-config-backup-service.js：范围、ZIP、清单、校验、预览与恢复事务。
- 新增 src/apps/server/modules/config/full-config-backup-http.js：备份文件上传/下载接口；此为备份业务，不新增并行的运行参数读写接口。
- src/apps/server/boot/server-app.js：配置模块加载前应用待导入事务，接入备份路由。

- src/apps/web-mediacenter/ui/public/upload.html 与 js/aasc-user-config.js：新增 ZIP 入口、导入预览和恢复模式，保留旧 JSON 功能。
- Android Chat2ApiNativeBridge.kt、MainActivity.kt、ModelDownloader.kt 与保存策略类：扩展已有 NativeControl，系统创建文档和受限来源流式下载。
- package.json/package-lock.json：纯 Node ZIP 生成直接生产依赖；发布时按用户要求生成新依赖包。
- tests/full-config-backup.test.js、相关浏览器/原生测试与 js/self-test.js：有意义的往返、事务、边界和交互验证。
- design/spec/index、usage、self-test 文档、todo、changelog、release/offline-release-status.json。

## 自测、兼容与性能

使用独立临时配置目录与虚构凭证验证完整往返；测试不接触真实账号/聊天。覆盖普通与 release 目标映射、群聊/私聊/角色/Chat2API 文件、合并与替换、备份回滚及重启时应用。浏览器检查 ZIP 下载、选择、预览、取消与确认；APK 检查系统保存与选择、取消、失败回调。

兼容旧 aasc-user JSON 入口。ZIP 压缩与上传使用流式处理并设置总量和数量上限；恢复只在启动前执行，无逐帧成本。测试大聊天夹具的内存峰值和导入预览耗时。

## 风险与预计工时

主要风险是导入覆盖目标数据、旧进程回写、ZIP 非法路径与解压规模；对应措施为预览、独立备份/回滚、启动前应用和归档校验。预计4–6小时，含跨端实现与定向验证。实际实现后设置受影响发布状态；按用户要求发布代码包与新依赖包，原生导出改动对应 min APK，复用编译好的 MNN。

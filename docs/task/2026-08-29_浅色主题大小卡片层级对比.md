# 浅色主题大小卡片层级对比

## 任务状态

- ✅已完成 [2026-08-29][2026-08-29]

## 任务描述

修复浅色主题下大卡片与小卡片使用相同背景色、层级不易区分的问题。

## Design 需求

- 大卡片/内容分组 `.section` 使用 `bg-surface`。
- 小卡片/控件块 `.control-item` 使用 `card-background`。
- 任务卡片、媒体条目和弹窗保持各自既有语义变量。
- 深色主题和卡片内容、文字、边框行为不变。

## Spec 设计

```text
浅色主题:
    .section.background = bg-surface
    .control-item.background = card-background
    .task-card/.media-library-item.background = card-background
    modal-content.background = bg-surface-strong

主题切换:
    仅通过根节点变量提供颜色
    不改变控件结构和业务交互
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/css/theme.css`：拆分浅色主题大/小卡片背景规则。
- `tests/ui-theme-card-contrast.test.js`：验证两类卡片消费不同主题变量。
- `docs/design/control-ui-theme.md`：更新卡片层级设计。
- `docs/spec/ui-theme.md`：同步主题伪代码。

## 自测用例

1. 检查浅色主题 `.section` 使用 `var(--bg-surface)`。
2. 检查浅色主题 `.control-item` 使用 `var(--card-background)`。
3. 检查任务卡片、媒体条目和弹窗的既有背景语义未被移除。
4. 运行主题回归测试并执行 `git diff --check`。

## 兼容性测试

- 15 套主题继续使用现有根节点变量。
- 深色主题不新增浅色覆盖规则。
- 不修改 HTML 结构、JavaScript 事件和服务端主题协议。

## 性能测试

- 仅调整 CSS 选择器，不增加脚本、网络请求或运行时计算。

## 风险评估

- 低风险：只改变浅色主题下两个容器层级的背景变量引用，弹窗、内容区和交互状态规则保持不变。

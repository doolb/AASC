# 独立 WebGL 深度纹理诊断页

- 日期：2026-09-28
- 需求：用独立 HTML 在 Android 浏览器比较原始深度是标准透视、反向 Z，还是异常读数；不发布。
- 设计：见 `docs/design/mmd-ar-test-apk.md` 的“独立深度纹理诊断页”。
- 实现伪代码：见 `docs/spec/mmd-ar-test-apk.md` 的“独立 WebGL2 深度读数页”。
- 受影响文件：仅新增 `3rd/mmd-ar-test/depth-probe.html` 及本地设计、spec、任务、待办和变更日志；不改 AO 或构建脚本。
- 自测：桌面 Chromium/SwiftShader 打开 `file://` 单文件，检查 `0.01–100`、`0.1–10` 两组的已知值、片元深度和深度纹理读数、背景深度、WebGL 参数、结果表和错误路径；重复运行结果应一致。
- 兼容性：Android Vivaldi 与一款正常浏览器打开同一 HTML 比较读数；WebGL2 缺失时明确显示无法测试。
- 性能：固定 600×240 像素、两轮同步测试，不持续渲染、不加载模型或网络资源。
- 风险：此页只验证合成几何体的深度纹理，不代表 PMX 透明材质与 AO 法线已验证；浮点位模式编码虽增加了已知值对照，仍需比较移动设备三路结果才能定位阶段。
- 预计工时：1 小时。

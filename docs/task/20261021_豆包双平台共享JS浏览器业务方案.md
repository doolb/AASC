## 实际根因与实施

此前静态默认related_deleted_message_ids为[]，官网为{}；旧递归差分忽略空容器类型误报正文一致。Android旧实验采集模板覆盖为正确类型。修正默认值并加类型回归后，两端均成功，不需要额外操作官网输入框生成测试会话。共享bootstrap在文档开始截留SDK处理后的fetch，准备不联网；网页模式正常fetch。页面观察刷新版本/tab，不覆盖设备身份或从资源URL复制msToken。平台Cookie读出后再次核对账号，绝不写入私有签名文件。

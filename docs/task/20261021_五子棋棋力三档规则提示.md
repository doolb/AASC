# 五子棋棋力三档规则提示

## 任务描述与 Design 需求

用户反馈 AI 乱下，要求先预览普通、专业、资深三档规则，默认普通；预览后已确认“可以”。将已确认策略写入游戏专属规则，落子依据最新权威棋盘，信息不足先查看。

## 需求评审

enterprise：可开发，主等级 L5，次等级 L4，置信度0.90，低风险。证据为“三档普通/专业/资深”“默认普通”“在规则里提示”，三项强证据均对应明确策略。评分24/25、19/20、19/20、19/20、15/15，合96/100。规则可直接下放 L4；以共享规则追加文本即可，无需新增配置通道。模型是否遵循策略需真实模型验收。

## Spec 设计

```text
已有声明 := GOMOKU_RULES 与当前聊天上下文
新增定义 := 三档棋力策略；默认普通，用户切换后按新档执行
普通 → 自己连五优先，其次挡对手下一手连五，再发展棋形
专业 → 普通 + 活四、冲四、活三攻防
资深 → 专业 + 候选比较、双方应手、连续与双重威胁
所有档位 → 读最新棋盘、检查轮次坐标空位；信息不足先查看
```

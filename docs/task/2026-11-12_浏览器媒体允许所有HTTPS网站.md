# 浏览器媒体允许所有 HTTPS 网站

- 需求：允许的网站留空时可访问任意 HTTPS 站点；填写列表时继续限制目标站点。
- 设计：参见 `docs/design/browser-media-service.md`；保留会话同源、无凭据 HTTPS、代理、令牌与会话隔离。
- 伪代码：参见 `docs/spec/browser-media-service.md`；空列表与非空列表分别处理。
- 影响：浏览器媒体服务和任务参数说明、专项及自测、使用文档。
- 自测：空列表可访问多个 HTTPS 站点；指定列表仍拒绝其他站点；HTTP、凭据、跨源请求及跨站导航仍受限制。
- 兼容性：既有非空列表不变；已有空列表实例重启后允许访问所有 HTTPS 网站。
- 性能：仅变更一次列表判断，不增加浏览器和网络请求。
- 风险：允许所有网站包括机器可访问的内网 HTTPS 地址，接口令牌必须妥善保管。
- 预计工时：半天。

- 验证结果：浏览器服务、HTTP 接口与任务专项共 8 项通过；真实桌面浏览器和目标网站待验收。

## 自测用例

- 94项目录分组女32/男62、style_id唯一，精简JSON字段与默认音色存在。
- HTTP目录：有效代理Key返回94项，未授权401，缺失/重复/未知model为400；无合成账号仍可读静态目录，且没有上游/配置副作用。
- 音色选择透传到Chat2API与Frontier speaker，未知音色拒绝，旧缺省请求不变。
- 播放/停止限定自身目标；配置只可改共享AI默认方式/对应音色，失败/重连/权威回显和控制端同步正确。
- TTS方式对应正确目录，按方式记住音色且切回恢复，迟到查询不覆盖当前方式，无目录/未启用/错误状态明确。
- qwen-chat仅保留现有已知单项目录，不伪装完整音色库；显示端play/stop均不得越权操作其它端或控制端。
- 豆包静态目录无账号仍可离线读；配置字段级patch不丢并发修改，原模板优先级/系统原生生成路由保持；共享重播提供开始/生成失败/结束回执。
- AI/Agent完成消息和历史点击播放复用对应speech与模板上下文；不重发LLM、不读reasoning，重复点击/失败/停止及会话切换可恢复。
- 原qwen/system/API Provider、分句播放顺序、账号FIFO、音量、缓存、字幕和MMD口型回归。

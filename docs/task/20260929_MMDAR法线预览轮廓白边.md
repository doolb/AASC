# MMD AR 法线预览轮廓白边

- 需求：半分辨率法线预览的人物与背景边缘出现白条，横条修复保持有效。
- 设计/spec：`docs/design/mmd-ar-test-apk.md`、`docs/spec/mmd-ar-test-apk.md`。
- 影响文件：`web-ao-preview-edges.js` 从实际 AO shader 提取同一法线重建公式，注入预览合成轮廓回退；`build.js` 在预览转换后调用；`web-ao-texel.test.js` 增加真实 GPU 轮廓对照。
- 流程：低分辨率背景标记无效 → 全分辨率深度背景保留原色 → 前景缺失法线时按真实像素重建 → 原样保留颜色 alpha。
- 自测：倾斜轮廓与细条，透明/不透明背景，修复前后白像素数量，全/半模式 alpha 一致，之前八组法线色差及 shader 编译回归。
- 验证结果：透明背景旧版 73 个白像素、修复后 0；不透明背景旧版 14796 个白像素（包括被刷白背景）、修复后 0；全/半轮廓 alpha 无差异，前序法线回归通过。
- 性能：仅预览无效低分辨率样本对应的前景补算五点深度法线，不改常规 AO 通道数量。
- 风险：只修诊断上采样白边，不代表其他材质或正常 AO 边缘伪影均消失；手机现场待验证。
- 预计工时：半小时。本地构建完成，未发布。

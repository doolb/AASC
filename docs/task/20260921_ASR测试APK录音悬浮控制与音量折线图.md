# 2026-09-21 ASR 测试 APK 录音悬浮控制与音量折线图

## 任务描述

将原生 ASR 测试页的录音控制固定到屏幕底部中央，并在录音结束后展示完整录音时间轴的音量折线图。

## design 需求

- 录音按钮悬浮在滚动内容之上，位于屏幕底部中央。
- 录音期间保持现有麦克风选择锁定和蓝牙 SCO 路由逻辑。
- 复用录音线程已经读取的 PCM 数据，按约 100 ms 生成音量包络。
- 录音完成、选择 WAV 或开始新录音时更新音量图。
- 无声录音也要显示完整零线，便于诊断。

## spec 设计

- 根布局使用 `FrameLayout`，滚动内容预留底部空间。
- 新增 `VolumeChartView` 自定义视图，固定纵轴 0～1，按录音块顺序绘制折线。
- `AudioCaptureStats` 增加本次录音的 `volumeEnvelope` 数据。
- `AudioRecorder.recordLoop` 计算每个读取块的归一化峰值并在 `stop()` 返回。

## 兼容性测试

- Android 9/API 28、SM-N9500、arm64-v8a。
- 系统默认麦克风、内置主麦克风、蓝牙 SCO 麦克风。
- 有声音、全零无声、录音启动失败和选择 WAV 文件四种路径。

## 性能测试

- 音量图只保存每约 100 ms 一个浮点值，不保存第二份完整 PCM。
- 长录音不因图表点数线性创建大量 View；绘制在单个自定义 View 中完成。

## 风险评估

- 自定义 View 坐标计算错误可能导致小屏幕显示异常，需要真机检查。
- 录音停止和蓝牙 SCO 释放必须继续在后台线程执行，避免 UI 卡顿。

# 聊天快选回写当前 LLM 模型名

## 任务描述

修正双端模型快选：选择三档时修改控制端“LLM 服务器配置”中当前普通 LLM profile 的模型名；打开面板时按该模型名识别 Provider 和档位，并显著区分选中与未选中按钮。用户确认按配置名称反查，不读取 Chat2API 映射配置。`Qwen3.6-Flash` 因名称归入 Qwen 轻量档。

## Design 需求与 Spec 设计

- `docs/design/chat-system.md`：当前 profile.model 为权威模型选择；`chat.modelTierSelection` 只保留每个 Provider 的档位偏好；Agent 配置不由快选改写。
- `docs/spec/chat-system.md`：名称反查 → 服务端校验 → 一次持久化写入当前 profile.model、兼容 model 与档位偏好 → 广播 profile 和快选快照。手动编辑模型名或切换 profile 后重算快选；未知模型名保留原调用。
- Qwen 请求使用已有内部别名，避免旧公开别名兼容映射改写轻量目标；名称反查不调用 Chat2API 映射读取接口。

## 受影响模块与代码

- `src/apps/server/modules/chat/chat-model-tier-service.js`：当前模型名反查、选档保存和普通聊天解析。
- `src/apps/server/modules/chat/pi-profile-config.js`：当前普通 LLM 模型名与偏好配置在同一次配置写入中持久化。
- `src/apps/server/boot/server-app.js`：模型服务与 profile 配置接线，profile 变化后向两端广播快选快照。
- `src/apps/web-mediacenter/ui/public/js/chat-model-tier-picker.js`、`css/chat-model-tier-picker.css`：当前模型名显示和三档选中状态样式。
- `src/apps/server/modules/chat/chat-model-tier-service.test.js`、`tests/pi-optional-dependencies.test.js`、`tests/chat-model-tier-browser.test.js`：名称识别、配置写入、双端回显和样式验证。

## 自测与兼容性

- 当前模型名分别为 Qwen 三个名称、豆包三个名称、内部别名、未知名称和 Agent 模型时，核对识别结果；旧 `Qwen3.6-Flash` 显示轻量。
- 快选后当前 profile.model、兼容 model 和各 Provider 偏好一致；手工改名、切换 profile、双端重连后显示权威状态；失败时不改配置。
- 检查选中/未选中边框、背景、字重、`aria-pressed` 和窄屏位置；保持外部登录预留状态。
- 运行定向 Node/浏览器测试、Chat2API 检查和差异检查。真实上游账号及 Offline APK/ADB 继续在待办中验收。

## 性能与风险评估

名称反查使用固定的小型开发映射表，不发额外网络请求；每次选档只执行一次配置写入。当前 profile API URL 未因快选修改，三档聊天仍沿用已实现的运行中 Chat2API Responses 路径。Qwen 真实上游目标可调用性和豆包文字风控状态不能由本地测试证明。

# Android外部登录统一按钮与自动保存

状态：用户确认实施；请求会话列表验证仅记录为后续待办。

## 任务与design

豆包Android外部登录缺少Qwen同款完成/取消，原因是无capture profile导致window.open回退。所有10个内置网页Provider统一隔离登录、完成/取消与自动捕获保存；豆包允许本地格式校验后添加，明确未远端验证。已保存账号浏览模式统一按钮但不更新凭据。

## spec

```text
新增CookieBundle声明 → Native当前允许源Cookie筛选 → 必要sessionid+CSRF齐全 → 单cookie字段
豆包本地格式校验 → 规范化凭据 → 嵌套format-only元数据入库 → 控制端未验证提示
原Provider远端校验保持 → 登录状态匹配与失败不消耗state保持
统一按钮helper → 捕获模式完成采集/取消清理；浏览模式完成/取消只关闭
保存账号网页恢复 → 六Cookie按声明和来源恢复，不传未知Cookie
后续会话列表验证 → 用户明确先记录，不接线或发送真实请求
```

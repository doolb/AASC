# 任务：Pi Agent 主动压缩上下文（暂不实现）

## 任务描述

记录 Pi Agent 主动压缩上下文的需求。Pi RPC 已提供 `compact` 命令，但本次只记录，不增加运行逻辑、控制端按钮或自动触发策略。

## Design 需求

- 后续可以对指定聊天 session 主动发送 `{ type: 'compact' }`。
- 可选 `customInstructions`，用于要求摘要保留角色设定、指令规则和最近对话。
- 压缩操作必须与当前 session 的聊天请求串行，不能和 `prompt` 并发写入同一 Pi 进程。

## Spec 设计

- 当前 `PiRuntimeManager` 不封装 `compact`。
- 当前继续使用 Pi 自带的接近上下文窗口时自动压缩。
- 将来实现时需要处理 `compact` response、`compaction_start` 和 `compaction_end` 事件。

## 受影响的功能模块和代码

- 未来预计影响 `src/apps/server/modules/chat/pi-runtime-manager.js`。
- 未来预计增加控制端聊天设置或操作入口。
- 本次不修改生产代码。

## 自测用例

- 当前不执行主动压缩请求。
- 长对话继续由 Pi 自动压缩或按 Pi 错误策略处理。

## 性能测试

- Pi 自动压缩的摘要质量取决于当前模型和 Pi 默认策略。

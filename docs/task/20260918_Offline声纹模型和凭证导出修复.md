# Offline 声纹模型和 Chat2API 凭证导出修复

## 任务描述

修复 Offline APK 控制端声纹注册提示“模型未就绪”，并让 Chat2API 配置/账号凭证导出在 Android WebView
中稳定保存到系统 Download 目录。

## Design 需求

- full Offline profile 包含 `voiceprint` 模型目录；min update-only profile 不重复携带模型。
- Offline 原生声纹管理器直接使用 Node Runtime 解压后的 `aasc-server/res/models/voiceprint`。
- 在线 APK 保持原有远程下载流程。
- Chat2API 的 blob 导出优先调用原生保存桥；Android 10+ 使用 MediaStore，Android 9 使用公共 Download 目录。
- 文件名保持 `chat2api-config-时间戳.json` 和 `chat2api-accounts-时间戳.json`，原生接口拒绝路径穿越和超大输入。

## Spec 设计

1. `VoiceprintModelManager` 接收可选的内置模型目录，内置目录校验 embedding/segmentation 文件后回报 ready。
2. `NativeBridge` 在 Offline 模式向管理器传递 `files/aasc-server/res/models/voiceprint`。
3. `Chat2ApiNativeBridge.saveDownloadFile` 解码有限大小的 base64 JSON，并原子完成系统下载记录。
4. 网页端导出函数复用 native 保存辅助函数；非 Android 环境继续使用 `<a download>`。

## 自测用例

- 声纹模型目录缺 embedding 或 segmentation 时报告错误；两者齐全时报告 ready。
- full profile 选择 `voiceprint`，模型文件进入 Runtime manifest；min profile 仍为空模型。
- 文件名含 `/`、`\\`、控制字符或超过大小限制时原生保存拒绝。
- Android 9 和 Android 10+ 分别写入 Download 目录；网页浏览器仍可回退下载。
- 真机 Offline 启动后日志不再出现 voiceprint model 下载失败；控制端注册声纹成功。

## 兼容性测试

- Android 9/API 28 SM-N9500：公共 Download 路径、full v15 → min v16 原位更新。
- Android 10+：MediaStore Downloads pending 完成后文件可见。
- 在线 APK：声纹模型继续按原接口下载，控制端导出不受原生桥缺失影响。

## 性能测试

- 内置声纹模型不发起网络下载；首次引擎加载时间和内存占用记录在真机日志。
- 导出 base64 仅用于短 JSON 文件，限制最大 16 MiB，避免长时间阻塞 WebView bridge。

## 风险评估

- full APK 增加约 41 MiB embedding 模型和 1.5 MiB segmentation 模型，首次 Runtime 解压时间增加。
- Android 9 依赖已有存储权限；权限被拒绝时返回明确错误，不删除原文件。
- MediaStore 写入失败会清理 pending 条目，避免 Download 目录出现半文件。

# 普通聊天 Agent 后端控制端选择

## 任务描述

补齐普通聊天 profile 编辑器中已有 `mode=agent` 的 `backend=pi|codex` 配置入口，避免控制端只能保存为 Pi、无法选择或显示 Codex。

## design 需求

- 调用模式保留 `直接 LLM / Agent`。
- Agent 模式增加 `Pi / Codex` 后端选择；直接 LLM 模式隐藏后端选择。
- 编辑旧 Agent profile 缺少 backend 时默认 Pi；普通 LLM 不保存 backend。
- profile 列表显示实际 Agent 后端。

## spec 设计

```text
profileEditor:
    mode = llm 或 agent
    如果 mode == agent:
        backend = pi 或 codex
    保存 -> normalizeAgentProfile -> 对应 RuntimeManager
```

## 自测用例

- 控制端包含调用模式和 Agent 后端选择。
- 新建/编辑 Agent profile 能保存 `backend=pi|codex`。
- 直接 LLM profile 不显示 Agent 后端。
- profile 列表正确显示 Pi 或 Codex。
- 既有普通聊天 Agent、Pi、Codex 回归测试通过。

## 风险评估

- 旧 profile 可能没有 backend，必须回退 Pi，不能让已有聊天失效。
- 只修改 profile 控制端字段，不改变 Pi/Codex Runtime 的会话、权限和进程生命周期。

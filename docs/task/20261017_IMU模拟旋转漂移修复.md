# IMU 模拟旋转漂移修复

状态：已实现并通过专项回归；用户真实鼠标轨迹待刷新网页后现场观察。

## 任务描述与需求

用户报告模拟器加入旋转后估计位置明显偏移，并确认只使用六轴数据进行修复。房间轨迹中参考位置长期不动，估计位置却沿水平和竖直轴持续漂移。主需求为 L5 姿态约束与零速流程，次需求为 L4 重力模长、六轴门限和状态定义；风险中等。不得借用模拟真值、目标位置/速度或拖动状态修正估计。

## Design 与 Spec

需求、现场轨迹和限制见 `docs/design/imu-six-axis-test.md` 的“模拟器纯旋转重力泄漏修正”；已先更新 `docs/spec/imu-six-axis-test.md` 中对应伪代码。先保存扣除已有加速度零偏、比例后的机体系力模长，再在旋转且测量与重力一致时纠正俯仰/横滚；连续“仅旋转”清平移速度，断流和校准清状态。

## 自测用例、兼容性与性能

基线：固定种子默认噪声纯旋转30秒，旧估计器位置误差约99.6米；房间在线轨迹最近约30秒参考位置不动，估计值从约`[0.49,2.05,1.69]`漂至`[-41.61,-2.90,16.09]`米。修复后相同固定种子纯旋转误差0米、零速计数1；组合运动8秒不误触仅旋转归零；初始倾斜0.04弧度的静止输入恢复静稳评分与重力方向。独立浏览器纯旋转后，从实时轨迹接口读取的位置误差小于0.05米。`npm run test:imu:six-axis-test` 23/23通过，涵盖真实浏览器拖动和手机输入。每帧增加有限的向量/四元数计算；没有持久化轨迹或扩大窗口。

## 风险与现场验收

加速度只约束俯仰/横滚，不约束航向；短时加速度可能与倾斜混淆，匀速平移叠加旋转与原地旋转在六轴上可能相同，可能误清平移速度。该自动规则仅模拟器启用，手机和APK默认仍手动。当前房间里的旧网页代码要刷新并点击“重置实验”，历史位置误差不会回溯消除；刷新后的真实鼠标轨迹及不同噪声/转速组合待用户现场观察。预计工时约1小时。

# 控制端服务器列表只读页面

## 任务描述

在现有 `/upload` 控制端增加“服务器”页面，展示主服务器当前登记的全部服务器节点。页面只读，支持手动刷新，不新增自动发现、服务器增删改、权限认证或最近服务器选择。

## Design 需求

- 复用现有 `SubServerManager` 和 `GET /api/subservers`。
- 控制端通过侧边栏进入服务器页面。
- 展示服务器身份、地址、健康状态、延迟、最后检查时间、显示端数量，以及服务端快照中存在的可选元数据。
- `/server` 服务器代码下发入口不在本任务范围内。

## Spec 设计

```text
点击服务器导航
    → 显示服务器面板
    → 请求 GET /api/subservers
    → 成功则渲染只读服务器卡片
    → 失败则显示错误且保留已有数据
点击手动刷新
    → 重新执行上述请求流程
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/upload.html`：增加导航入口和服务器面板。
- `src/apps/web-mediacenter/ui/public/js/server-list.js`：服务器列表请求、状态处理和渲染。
- `src/apps/web-mediacenter/ui/public/css/upload.css`：服务器卡片和状态样式。
- `src/apps/server/boot/server-app.js`：确认并保持现有 `/api/subservers` 只读契约。
- `docs/design/sub-server.md`、`docs/spec/sub-server.md`、`docs/todo.md`、`changelog.md`：同步项目文档。

## 自测用例

1. 接口返回多个服务器时，页面显示全部服务器。
2. 接口返回空数组时，页面显示空状态。
3. 接口请求失败时，页面显示错误信息且不因异常中断。
4. 点击刷新按钮会重新请求接口。
5. 缺少可选字段时页面显示兼容文本，不出现 `undefined`。

## 兼容性测试

- 保持现有媒体、显示、提醒、聊天、地图等控制端面板可切换。
- 保持旧版 `/api/subservers` 响应结构不变。
- 浏览器支持现有项目使用的原生 HTML/CSS/JavaScript 环境。

## 性能测试

- 列表刷新只发起一次 HTTP 请求。
- 服务器数量增加时页面仍使用一次性批量渲染，不为每台服务器单独请求。

## 风险评估

- 当前服务器快照中的版本、能力等字段可能尚未统一，页面必须按可选字段兼容显示。
- 现有工作区存在大量与本任务无关的用户改动，实施时只修改本任务列出的文件。

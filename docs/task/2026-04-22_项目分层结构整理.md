# 项目分层结构整理任务

## 任务描述

- 目标：按 Core / Framework / External / App 对项目结构做第一阶段整理。
- 范围：先创建新目录骨架与设计/实现文档，不做一次性大迁移。

## design 需求

- 明确四层职责边界和依赖方向。
- 明确 AASC 在 Framework 层仅做消息总线。
- 明确提醒/聊天/媒体控制和页面属于 App 层。

## spec 设计

- 输出启动装配伪代码。
- 输出依赖校验伪代码。
- 输出 App 组装与 External 调用伪代码。

## 自测用例

1. 检查 `src/` 下是否存在 core/framework/external/apps 四层目录。
2. 检查 design/spec 索引是否新增分层架构文档入口。
3. 检查分层文档是否包含依赖方向和迁移策略。

## 兼容性测试

1. 本次不改现有运行入口，保持 `server.js` 可继续使用。
2. 旧目录暂不删除，确保现网行为不受影响。

## 性能测试

1. 本次为结构与文档变更，不涉及运行时性能变更。

## 风险评估

- 风险：新旧结构并行期间可能出现引用混乱。
- 缓解：先用文档和目录约束锁定分层边界，后续按模块逐步迁移。

# 豆包 LLM 网页兼容模式

## 任务描述

新增 `doubao.web` 内置服务任务，参考 SeiShonagon520/doubao2api 的浏览器内 `fetch()` 发送方式，逐项整合聊天、图片、视频、音乐与文件能力。桌面使用可配置浏览器名称或路径、本机调试端口和专用 profile；Android Offline 使用隔离进程中的持久 WebView。任务提供独立兼容 API 并接入 Chat2API，TTS 沿用现有实现。

## Design 需求

见 `docs/design/chat2api-doubao-web.md` 的“豆包网页内置任务”。每个账号有独立浏览器 profile；登录和安全验证由用户在官网页面处理。失败不自动重发、删除官网历史或切换账号。

## Spec 设计

见 `docs/spec/chat2api-doubao-web.md` 的“豆包网页内置任务与浏览器内请求”伪代码，及 `.src/framework/doubao-web.md`、`.src/app/doubao-web-task.md`；均在运行代码修改前写入。

## 受影响模块

- 服务端：豆包文字适配器、runtime、账号及会话生命周期、桌面浏览器启动和 UI 驱动、AASC/WebSocket 权威配置。
- 控制端：Chat2API 豆包模式、浏览器可执行文件和调试端口配置。
- Android：独立登录进程中的 WebView 常驻服务、本机受限 IPC、登录与人工验证入口。
- 文档及状态：design/spec/task/todo/changelog、`servicePackage` 与 `minApk`。

## 自测用例

独立 profile 和标签、账号指纹、首次与续聊、官网页内 `fetch()` 的同次 SSE、非空完成、取消/导航/断连/安全验证、两个并发会话隔离、桌面与 Android 回归、Node 显式模式及 TTS 不受影响。文件上传另核对 AWS V4 固定签名、CRC32、Prepare/Apply/TOS/Commit 顺序和文件问答附件块；媒体核对图片、音乐、视频结果及 multipart 编辑。真实官网测试只在专用 profile 中执行，并核对安全验证由用户手动完成。

## 实施与验证记录

- 已注册 `doubao.web` 常驻任务，提供专用桌面浏览器 profile 和 Android 隔离 WebView 的本机受令牌保护桥；聊天接入现有 Chat2API 流与原生会话状态。
- 已实现媒体、图片与文件上传、文件问答兼容 API；网页短任务页结束后释放，上传主机和 URI 受限。未迁移自动验证码求解、自动删官网会话或自动切账号。
- `npm run check:chat2api` 314/314 通过，`doubao.web` 任务定向 1/1 通过；Android `:app:compileDebugKotlin --offline` 通过。真实官网账号、Android WebView 加载和验证码流程仍待设备验收；服务代码包和 min APK 尚未构建发布。
- 按用户要求复用 `192.168.1.39` 当前登录的 Vivaldi 会话进行隔离验收：原官网页能生成 `X-Bogus`，在该页同源发送“早”得到 HTTP 200 和 `STREAM_ERROR/710020202`，未得到正文；新标签页导航及官网“新对话”页超时。现场资料与已保存账号不一致，未覆盖正式账号。修复桌面桥接层对 `www` 与父域双 `sessionid` 的误判，定向覆盖优先 www 身份及拒绝父域冒用；`npm run check:chat2api` 315/315 通过。后续需用专用 profile 完成登录后，再核对官网 UI 实际请求、续聊、媒体、文件及 Android 真机。
- 官网 UI 恢复后在新对话中发送“早”并收到可见回复。被动捕获该轮首发请求后，按现有规范化函数删除原消息和旧会话 ID，再在同一登录页用新消息进行同源 `fetch()`：HTTP 200，出现 `CHUNK_DELTA` 和 `SSE_REPLY_END`，无非零业务码。该模板只在内存中用于验收；当前正式账号设备资料不同，未更新账号。完整 SSE 导入观察器此前对 UI 成功回复仍超时，记录为独立待排查项；专用 profile、续聊、媒体/文件和 Android 真机未验收。

## 兼容性、性能与风险

现有 Responses 流结构与 120 秒/8 MiB 上限继续生效。官网签名或网络事件变化会使请求失败；Android 后台 WebView 对页面脚本和人工安全验证的实际表现、浏览器专用 profile 的登录态与构建产物需要设备验收。源码阶段已完成，现场验收与必要修正单列待办。

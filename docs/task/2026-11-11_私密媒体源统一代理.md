# 私密媒体源统一代理

- 任务描述：私密来源统一使用命名代理的逐源选择；未选择直连，不再按 jp/us 名称自动初始化；保留已有用户选择。
- design 需求：参见 `docs/design/media-library.md` 的媒体源统一代理。
- spec 设计：参见 `docs/spec/media-library.md` 的命名网络代理与来源选择。
- 受影响模块：`res/tasks/local-only/private-media/task.js`、`gallery.js`、`src/apps/server/boot/server-app.js`、`src/apps/server/modules/media/web-proxy-settings.js`、代理设置与画廊测试。
- 自测用例：来源注册不自动写入选择；显式选择保留；画廊页面、图片及封面均按请求读取代理；切换代理后缓存清空；代理失败不回退直连。
- 兼容性：保留持久化 `media.providerProxy` 已有值，不改变来源 ID 和播放接口。
- 性能：不增加网络请求，代理选项仅在发起请求时构造。
- 风险：未配置代理的私密来源改为直连；用户需在任务详情选择代理。外部站点可达性需要发布后现场验收。
- 预计工时：1 小时。
- 状态：代码和定向测试完成；实际代理网络待现场验收。

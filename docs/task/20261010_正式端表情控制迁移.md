# 正式端表情控制迁移

## 需求与方案

用户希望先接入表情控制，后续用于TTS口型。设计 `docs/design/mmd-display-expressions.md`；实现前伪代码 `docs/spec/mmd-display-expressions.md`。本轮默认先迁移面板与API，不自动驱动TTS。

## 执行清单

- 先写伪代码，迁移共享控制器/UI并接入正式Loader/runtime/display和动作面板。
- 独立构建移除重复注入，复用正式模块并保留内容指纹与MPL接口。
- 标记servicePackage=true，同步design/spec/usage/todo/changelog。
- 静态语法、差异检查及web-dist构建；不新增或运行测试。

## 人工验收用例、兼容性与性能

- 通用PMX分类、原始名称、独立强度、0值、组合与清除恢复VMD。
- 首次/换模型/物理重载/换VMD/暂停；GLB/无Morph/不支持类型。
- 正式桌面、Android WebView及独立MPL；页面隐藏停止UI轮询，无音频/麦克风访问变化。

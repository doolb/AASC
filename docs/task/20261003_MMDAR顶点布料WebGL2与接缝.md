# MMD-AR 顶点布料 WebGL2 与接缝修复

状态：2026-10-03 用户确认新增“顶点布料 GPU”独立选项，保留原CPU选项；源码已实现，接缝修复共用，待浏览器和真机运行验收。

## 需求与范围

将独立 mmd-ar 的顶点布料改为 WebGL2 GPU 计算，保留骨骼自动选区、固定点、风、碰撞、表情及现有子步设置，并修复部分布料分开。正式包仍不接入顶点布料。

## 参考与设计

- https://matthias-research.github.io/pages/tenMinutePhysics/index.html 第16节是 Python/NVIDIA Warp，借鉴 GPU 并行思路，不能直接作为 WebGL 代码使用。
- https://github.com/jspdown/cloth 使用 WebGPU/XPBD/小步长及约束图着色；拟把约束并行方法改写为 WebGL2 浮点纹理 ping-pong 通道。
- GPU 保留位置、速度与约束状态，按图着色处理拉伸和弯曲，各批约束不共享可移动粒子，避免写冲突。碰撞与风使用粒子邻接收集。沿用每帧子步数，不增加固定迭代倍数。
- 渲染直接采样模拟位置/法线纹理，覆盖主材质、阴影、AO与粒子预览，避免逐帧完整读回。保留非布料骨骼动画和原材质的 UV、透明度、硬边；需接入同一 renderer 并恢复渲染状态。
- 检查 WebGL2、浮点渲染目标和纹理容量；不支持或初始化失败时回退现有 CPU，状态中明确实际后端。上下文丢失、切换模型/VMD、重置、释放均处理纹理生命周期。
- 现有拓扑以坐标和精确归一化蒙皮权重共同焊接，因此位置重合但权重不同的接缝可能独立运动，尚未对用户模型复现。拟从成对边界边、骨骼区域、邻接面及表情兼容性识别接缝，使用共享物理粒子或缝合约束；不全局按位置焊接，避免误粘内外层。同步检查启用/禁用组边界。

## 验收计划与风险

接缝验收覆盖同位置不同权重、UV/材质拆点、内外层不误焊、固定/自由边界、不同组开关；渲染检查阴影/AO/透明材质/硬边/表情/VMD切换。兼容性包括桌面浏览器、Android WebView、能力不足回退和上下文恢复。性能对比相同模型与3/5/10/45子步，分别记录CPU提交耗时和可测GPU耗时，不能用提交耗时冒充GPU完成时间。小网格或高子步下多次绘制可能比CPU更慢，不承诺固定加速比。没有问题模型截图/部位信息，裂缝具体原因需实施阶段定位。预计工作量较大，GPU求解、渲染通道与接缝应分阶段完成。

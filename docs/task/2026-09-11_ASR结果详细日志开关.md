# 任务：ASR 结果详细日志与控制端开关

## 任务描述

服务端收到显示端 `asrResult` 时，增加 ASR 文字和声纹诊断信息的结构化日志；在控制端声纹面板增加详细日志开关，默认开启，关闭后保留摘要日志。

## Design 需求

- 使用已有服务端显示端 ASR/声纹处理链路，不更换模型、不改变分段和命令门控。
- 详细日志打印总文字、分段文字、说话人、相似度、阈值、时间、聚类 ID 和错误信息。
- 简要日志保留请求 ID、总文字、顶层声纹结果和错误摘要。
- 配置项为 `voiceprint.asrResultDetailLog`，缺省值为 `true`。

## Spec 设计

- 新增 `asr-result-log-formatter.js`，只输出 ASR/声纹诊断字段，避免把音频或无关对象写入日志。
- `server-app.js` 在显示端 WebSocket `asrResult` 入站日志处按配置选择详细或简要格式。
- `/api/voiceprint/config` 读写该配置；控制端 `upload.html` 与 `voiceprint-panel.js` 负责开关展示、加载和保存。

## 自测用例

1. 详细模式日志包含总文字和每个分段的声纹字段。
2. 简要模式日志不包含分段明细，但保留文字和顶层结果。
3. 控制端开关默认勾选，修改后提交布尔配置。
4. 服务端配置默认值为 `true`，收到 `asrResult` 时使用当前配置。
5. 缺少声纹字段或 `speaker=null` 时仍能安全打印。

## 兼容性测试

- 兼容 `SHERPA_SINGLE`、`SHERPA_MULTI`、`SHERPA_MULTI_FAST` 的顶层和分段结果。
- 兼容旧版显示端 `asrResult` 缺少可选字段的情况。
- 不改变 `/api/asr/recognize`、`voiceInput` 和 `asrResult` 数据契约。

## 性能测试

- 日志格式化只遍历已有分段，不增加 ASR 或声纹推理。
- 简要模式不序列化分段明细，降低日志体积。
- 执行定向测试、语法检查、`git diff --check` 和全量 Node 测试。

## 风险评估

- 详细日志可能增加日志文件体积，已提供控制端开关关闭分段明细。
- 日志包含 ASR 文字和声纹分数，属于诊断信息；不写入音频和 embedding 原始向量。
- 旧配置缺少新字段时按 `true` 回退，保证升级后保持原有可观测性。

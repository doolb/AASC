# 豆包与QwenChat回复速度实测

## 任务描述与范围

按用户要求测量当前服务器两种聊天的回复速度。复用Responses客户端和正式服务，以独立会话避免当前聊天/游戏测试污染。不修改业务代码，不需要新增功能方案确认。

## design与spec

对应docs/design/chat2api-global-responses.md及docs/spec/chat2api-global-responses.md的2026-10-22真实计时章节。第一非空正文事件、最后正文事件、completed分别计时，保留正文块数量与长度，不把response.created当首字。

## 执行与受影响模块

检查package.json没有实时回复速度脚本，使用临时Node脚本调用既有src/external/llm/llm-responses-client.js。目标192.168.1.39当前8083服务，不启动其它运行时、不切换网页任务、不更改凭据。豆包普通doubao确认node-http；国内Qwen请求aasc-qwen-flash，实际Qwen3.7。新会话一轮加同会话续聊两轮，交替发送相同自然消息早/今天过得怎么样/有什么适合放松的小事，无system提示，全部stream=true。六次均有正文与response.completed，未通过游戏或当前AASC聊天发送。

## 性能结果

| 消息 | 豆包首字/正文结束/请求完成（秒） | Qwen首字/正文结束/请求完成（秒） |
|---|---|---|
| 早 | 2.10 / 2.27 / 4.36 | 1.42 / 1.62 / 1.80 |
| 今天过得怎么样？ | 2.13 / 2.57 / 4.43 | 1.16 / 1.86 / 2.02 |
| 有什么适合放松的小事？ | 1.99 / 4.87 / 6.94 | 1.27 / 3.08 / 3.24 |

三轮平均首正文/正文最后分块/请求完成：豆包2.08/3.23/5.25秒，Qwen1.28/2.19/2.35秒。豆包224字/32块，Qwen289字/11块；第三轮185/190字，首字1.99/1.27秒，请求完成6.94/3.24秒。

## 自测与兼容性

6/6请求均非空正文且正常completed；核对服务端权威会话实际模型/传输及三轮历史。计时使用performance.now，不输出Cookie/令牌/签名或回复原文。豆包连续会话ready、node-http；Qwen按原SSE路径正常输出。没有修改代码，不重复执行与本次测速无关的回归测试。

## 风险、隔离和未决项

计时从本机HTTP请求前至收到事件，包含当前服务排队/签名/网络；新会话不是进程冷启动。模型、回复长度和上游状态不同，三次小样本不能推出固定性能。豆包正文结束至completed约1.9–2.1秒，Qwen约0.16–0.18秒；只记录现象，不把尾部耗时归因为已定位的某段代码。

两个独立API测试会话留作测量依据，未向当前AASC聊天/游戏发送，未删除用户旧历史或覆盖运行中的JSON集合；无新增Key、任务实例、ADB操作或浏览器生命周期操作需要清理。现有服务及账号保持。min73/服务包配套发布和正式设备重启/关闭页面行为继续原部署待办，本次不扩展为性能优化。

## 工时与状态

预计约5–10分钟；实际六次请求合计22.79秒，连同入口核查和记录完成。测量任务完成，不在todo保留已完成项；发布状态未改变。

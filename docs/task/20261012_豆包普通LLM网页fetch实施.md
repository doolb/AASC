## 全局约束及风险

- 开发不连接9222、不读真实Cookie/账号库、不聊天/合成；不操作主服务器。只用隔离测试。
- 默认关闭；必须绑定accountId、targetId及contextId并显式allowSessionCheck。运行时仅内存比较所选官方页面sessionid，不保存/输出秘密。
- 固定本机CDP和官方HTTPS来源；无法可靠验证身份拒绝；不换号/标签，不自动Node回退、重连、重试或验证码绕过。
- 120秒、256KiB请求、8MiB流、512KiB单块、64KiB桥接片段；同绑定单任务，无无界队列。
- 只断调试连接，绝不close浏览器或页面；取消覆盖连接迟到及异步释放。
- account/context冲突、iframe导航、真正主frame导航、配置/凭据变更是重点复核项；公开URL不代表登录校验。
- 其它Provider及已有WAV语音保持；Android无Chrome默认禁用，设备/真实官网验收另授权。

# 内置动作下半身微动作（已完成，待服务包更新）

用户确认在内置IK动作中加入轻微下半身表现：双脚原地、骨盆约1～2厘米/约2°、重心切换和自然屈膝。使用MMD-AR测正式模块，再在已安装Offline APK核对画面。按已确认范围实施，没有重新申请同范围授权。

## 需求与设计

主L6、次L5，按L4实施；既有声明为11类IK目标、physics rig/drive、内置模板、混合时间轴及TTS外部时钟；新增定义为三种下身配方和自动站姿取消回位。详见design/mmd-human-interface.md顶部。原预计2～4小时，模型适配与设备观感风险中；本轮范围无待确认项。

## spec与代码

先更新spec/mmd-human-interface.md伪代码，再更新以下模块：

- `mmd-reply-ik-gestures.mjs`：13类重心切换、5类轻沉、4类起伏；6类克制动作保持稳定；骨盆向量幅度受限，同四段时序和强度，沿用速度缩幅及最多41帧/16KiB。
- `mmd-human-ik-targets.mjs`：双脚锚定参考站姿，解除旧腿膝重复牵引，显式脚/膝优先。缺骨盆或任一可控脚则只播上身并告警。
- `mmd-human-physics-drive.mjs`：自动站姿取消时同一物理世界平滑回位，误差小后固定，最长0.8秒；新目标/手动/自由骨盆/reset/dispose清理。无额外原生对象，不修改输入数组。
- `tests/mmd-ik-motion.test.js`、`tests/mmd-builtin-ik-browser.test.js`：真实PMX/Ammo、源码边界、能力降级、脚锚定优先、实际下身运动及取消。

无需改Human装配，现有目标执行链已支持骨盆。无需原生Android修改。

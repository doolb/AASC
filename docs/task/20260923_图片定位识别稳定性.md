# 2026-09-23 图片定位识别稳定性

## 任务描述

用户反馈开始定位后基准图查找不出来，界面显示“目标丢失”。改进普通图片目标匹配，并让首次搜索状态准确表达当前进度。

## Design 需求与 Spec 设计

- 基准图与实时帧用亮度重心方向对齐局部描述子；实时帧按多个尺度采样。
- 最近邻比值匹配后使用内点比例和空间分布约束单应矩阵，减少错误定位。
- 首次匹配成功前显示“寻找中”；识别过目标后再次失败才显示“目标丢失”。
- 摄像头未就绪、画面纹理不足时显示可操作提示。

## 自测用例

- 启动定位尚未出现基准图：状态为“寻找中”。
- 从不同距离、轻微旋转拍摄已保存基准图：定位成功后模型脚底跟随图像。
- 成功后移开基准图：状态为“目标丢失”；重新进入画面后恢复。
- 纹理不足和摄像头未就绪：显示对应提示，界面不卡死。

## 兼容性、性能与风险

- 目标存储格式不变，已有 IndexedDB 定位图可继续使用。
- 每帧增加多个尺度的灰度采样，需在 Android WebView 上观察帧率；预计工时约 2 小时。
- 反光、失焦、大角度倾斜和低纹理图片仍可能无法稳定识别，需目标设备现场验证。

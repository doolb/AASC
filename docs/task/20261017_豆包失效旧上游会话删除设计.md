# 豆包失效旧上游会话删除设计记录

日期：2026-10-17
状态：仅记录，待协议核验与实施。

## 任务描述与需求

`doubao_session_uncertain` 自动重建成功后，只删除本次被替换的旧豆包网页上游会话。保留控制端当前会话、本地聊天历史、新建上游会话与账号下其他历史。用户要求本轮先不处理，仅记录。

## 设计与伪代码

- 设计：`docs/design/chat2api-role-session-lifecycle.md` 第 4.0 节。
- 伪代码：`docs/spec/chat2api-role-session-lifecycle.md` 的“豆包 uncertain 自动重建后的旧会话清理”。
- 旧 ID 和所属账号应在本地引用清除前记录；新会话成功且旧流结束后才可尝试按原账号清理。协议未核验前不发请求，不把清除本地引用当作远端删除。

## 受影响模块（预期）

`src/external/llm/llm-service.js` 的续接引用与自动重建流程、Chat2API 豆包会话状态及经验证的上游删除适配器；具体文件需实施前复核。本文未修改代码。

## 后续自测与兼容性

- 单轮无正文自动重建及已输出正文后下轮重建；仅删除被替换的旧 ID。
- 新会话建立失败、删除失败、超时、账号变化和并发旧流；不得误删新 ID 或其他会话。
- 控制端会话、历史、不同角色/账号/模式及现有 Qwen 流程保持可用。

## 性能、风险与预计工时

删除应在有界时间内完成，不让远端清理阻塞正常聊天；具体失败与重试策略待协议核验。最大风险是旧 ID 与账号对应错误导致误删，以及臆造删除接口。预计协议核验、自测与实现约半日至一日，以真实协议可获取为前提。本轮只做文档记录，未测试远端接口。

# MMD AR 测试网页动作播放开关

## 任务描述

在 HTTPS MMD AR 测试网页的灯光面板增加“播放动作”开关，用于排查 PMX 布料首屏漂移时区分 VMD 动作与物理模拟的影响。

## Design 需求

- 仅出现在 `3rd/mmd-ar-test` 生成的 HTTPS 测试网页，不加入 APK UI 或正式显示端 UI。
- 默认开启，使用独立 localStorage 键保存。
- 关闭后暂停 VMD 在当前帧；PMX 刚体/布料物理和渲染继续运行。
- 再开启时从暂停帧接续；页面刷新重新从 VMD 第 0 帧开始，再依持久化值决定播放或暂停。
- 不预先播放、不跳过 VMD 帧，不改动作播放默认配置。

## Spec 设计

- `DisplayMmd.setMotionPlaybackEnabled(enabled)` 保存规范化状态，并在 runtime 已创建时转发；runtime 创建时也应用当前状态。
- PMX runtime 只切换 `MMDAnimationHelper.enabled.animation`，不更改 `enabled.physics`。
- 测试页启动早期读取 `aasc.mmdArTest.motionPlayback.v1`，除明确字符串 `false` 外均视为默认开启；用户修改后尝试写回。
- 在灯光面板“动作”首分类中展示原生 checkbox，分类脚本仅在 HTTPS 网页构建模式执行。

## 自测用例

1. 新浏览器默认显示勾选并启用动作。
2. 关闭开关时 VMD mixer 时间不增加、helper physics 仍为 true；恢复后 mixer 从暂停处继续。
3. 新建动作 helper 继承关闭状态，且物理保持启用。
4. 保存关闭后刷新，开关仍关闭且动作从 VMD 第 0 帧暂停；无效值或无存储时默认开启。
5. 开关变更写入专用键；localStorage 写入失败时运行时开关仍可用。
6. 网页灯光分类、面板已有控件、正式显示端页面及 APK 构建模式无回归。

## 兼容性与性能

- 兼容现有 `MMDAnimationHelper` enabled 子状态和 PMX runtime 生命周期；VRM 路径不处理此测试功能。
- 不额外增加每帧计算；动画关闭期间仍需运行既有 helper 更新以维持物理。
- 浏览器禁用 localStorage 时本次开关仍有效，但刷新不保留选择。

## 兼容性测试与性能测试

- 兼容性：HTTPS 生成页显示该开关；APK 构建模式与正式 `display.html` 不插入该控件；默认开关不改变 VRM 和现有 PMX 动作行为。
- 生命周期：在模型创建前关闭、模型创建后关闭、加载新 VMD helper 后关闭三种时机，状态均由 DisplayMmd/PMX runtime 传递；切换动作不改变 VMD 初始帧规则。
- 性能：开关调用仅改一个 helper 状态并触发现有渲染循环，不新增轮询或逐帧分支；动作关闭时既有物理更新保持运行，不额外增加计算量。
- 验证结果：生成页及运行时定向自动化 37/37 通过；真实 Android WebView 体验未在本任务中发布或验收。

## 风险评估

- 若暂停实现关闭整个 helper 更新，会错误停止布料物理；测试必须同时断言 animation 与 physics 状态。
- 若开关在模型初始化后才应用，启动阶段可能推进 VMD；网页初始化脚本需早于 `display-mmd-ar.js` 的 DOMContentLoaded 模型加载逻辑。
- 本任务用于辅助诊断，不代表布料上漂已修复或完成真机验收。

## 预计工时

约 1–2 小时，包含运行时桥接、网页面板、定向自动化和文档同步。

## 执行结果

- 已实现：HTTPS 网页构建时向灯光面板注入“播放动作”开关，并归入首个“动作”分类；运行时在 PMX 创建及动作切换时应用当前状态。关闭只设置 `helper.enabled.animation = false`，不更改物理标志；刷新时继续从 VMD 第 0 帧加载并按本地保存状态暂停/播放。
- `npm run build:web:mmd-ar-test` 成功；`node --test tests/mmd-pmx-helper.test.js tests/display-mmd-runtime.test.js tests/mmd-ar-web-panel-groups.test.js` 37/37 通过；`git diff --check` 通过。
- 仅生成本地 `3rd/mmd-ar-test/web-dist`，未发布网页或 APK。真实 PMX 的暂停帧、布料运动与刷新首屏仍待浏览器/Android WebView 现场验收；原布料上漂任务继续保留在 todo。

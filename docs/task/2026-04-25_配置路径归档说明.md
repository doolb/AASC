# 任务：配置路径归档说明

## 任务描述

- 目标：统一说明 `src/core/config/config.js` 为历史路径，避免文档检索误导
- 范围：文档层修订，不改动运行时代码

## Design 需求

- 在变更日志中给出统一归档说明
- 在规范文档中定义历史路径标注规则
- 对关键模块文档把当前路径更新到 App 层

## Spec 设计（伪代码）

```
扫描 docs/changelog:
    找到 src/core/config/config.js

对于功能说明文档:
    替换为 src/apps/server/modules/config/config-app-service.js

对于历史任务/变更文档:
    保留旧路径并追加“现路径”注记
```

- 文档修订不影响运行时行为

## 风险评估

- 若过度替换历史记录可能丢失时间上下文，已采用“保留旧路径 + 现路径注记”策略

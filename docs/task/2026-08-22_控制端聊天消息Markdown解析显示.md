# 控制端聊天消息 Markdown 解析显示

## 任务描述

控制端聊天消息增加 Markdown 解析显示能力。用户消息和助手消息均按 Markdown 展示，但聊天输入框保持纯文本输入，不增加 Markdown 编辑器。

## Design 需求

- 覆盖群聊、私聊、普通 LLM 和工作 AI 角色消息。
- 历史消息、用户发送后的临时消息、助手流式消息和最终消息使用同一套渲染规则。
- 支持标题、粗体、斜体、删除线、列表、引用、表格、代码行、代码块、分隔线和链接等常用语法。
- 原始 HTML 必须转义；链接只允许安全协议和站内路径。
- 不依赖 CDN，适配现有原生 HTML/JavaScript 页面。

## Spec 设计

```text
ChatMarkdown.render(markdown):
    统一换行符并解析块级 Markdown
    解析标题、列表、引用、表格、代码块、分隔线和段落
    解析行内代码、强调、删除线和安全链接
    对普通文本和属性值执行 HTML 转义
    返回受控标签组成的 HTML

Chat.renderHistory():
    取当前模式消息内容
    调用 ChatMarkdown.render(content)
    写入消息气泡

Chat.showStreamingMessage(userMessage):
    调用 ChatMarkdown.render(userMessage)
    显示用户临时消息

Chat.handleChunk(data):
    requestId 匹配时调用 ChatMarkdown.render(data.message)
    更新助手流式气泡并保留光标

Chat.handleResponse(data):
    requestId 匹配时调用 ChatMarkdown.render(data.message)
    固化助手最终气泡并保留历史与语音逻辑
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/js/chat-markdown.js`：新增安全轻量 Markdown 渲染器。
- `src/apps/web-mediacenter/ui/public/js/chat.js`：历史消息、用户临时消息和助手流式消息接入渲染器。
- `src/apps/web-mediacenter/ui/public/css/chat.css`：增加 Markdown 块级元素、代码块、表格和链接样式。
- `src/apps/web-mediacenter/ui/public/upload.html`：在 `chat.js` 前加载 Markdown 渲染器。
- `tests/chat-markdown.test.js`：新增解析、安全过滤和页面接入测试。
- `docs/design/chat-system.md`、`docs/spec/chat-system.md`、`docs/spec/ai-roles.md`：同步设计与伪代码。

## 自测用例

1. 标题、无序列表、代码块和 HTTPS 链接能渲染为对应 HTML。
2. 用户消息中的 `<script>`、普通 HTML 标签不会被执行或成为真实标签。
3. `javascript:` 链接不会生成 `href`，站内路径仍可显示为链接。
4. 历史消息和流式消息均调用 `ChatMarkdown.render`。
5. Markdown 渲染器在 `chat.js` 之前加载。
6. 输入框仍为纯文本输入控件。

## 兼容性测试

- 保留原有消息字段 `content`、`user`、`assistant` 和历史存储格式，不改 WebSocket 协议。
- 不改变语音播报内容，TTS 仍读取原始文本而不是渲染后的 HTML。
- 不依赖外部网络资源，适配当前原生浏览器页面。
- 旧历史消息按纯文本输入处理，未包含 Markdown 标记时显示效果保持一致。

## 性能测试

- 渲染器只在历史刷新、流式增量和最终回包时处理当前消息，不改变消息传输量。
- 代码块和表格均限制在当前气泡内横向滚动，避免大段内容撑开页面布局。
- 以普通聊天长度消息执行 Node 回归测试，确认无异常递归或明显延迟。

## 风险评估

- 风险：Markdown 解析生成 HTML 可能引入 XSS。
  - 处理：所有文本和属性统一转义，链接执行协议白名单校验，不解析原始 HTML。
- 风险：流式消息可能处于未闭合 Markdown 状态。
  - 处理：未闭合结构按当前内容渲染，后续增量到达后重新生成完整消息。
- 风险：轻量解析器不覆盖全部 CommonMark 边界语法。
  - 处理：明确覆盖聊天中常用语法，复杂语法按安全文本显示，不影响消息可读性。

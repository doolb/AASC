# 五子棋游戏协议与本地显示

- 任务：实现位置参数 Game 标签、服务端权威五子棋、显示端全屏棋盘及语音/点击联动。
- Design：`docs/design/game-gomoku.md`。
- Spec：`docs/spec/game-gomoku.md`，修改代码前先写伪代码。
- 受影响：聊天服务端入口、游戏模块、显示端页面/脚本/样式、协议与页面定向自测、Offline 服务包状态。
- 自测：语音经 AI 调用 User 落子；点击直接落子并通知 AI；AI 落子；增量与恢复快照；非法坐标、错轮、重复/过期版本；尺寸确认和胜负。
- 兼容：普通聊天、现有 TTS 与临时对话计时不变；旧显示端忽略新消息。
- 性能：普通落子传单步增量，不重复传全盘；每显示端串行更新并原子保存。
- 风险：模型可能生成无效标签，须限制重试次数并保留原回合；上游错误不应提交未校验动作。
- 预计工时：约 1 天；服务端与网页源码已完成。
- 验证：`node --test tests/game-gomoku.test.js tests/display-game-browser.test.js` 7/7；聊天 requestId 与显示端普通语音合同测试通过；脚本语法和差异检查通过。`tests/chat-tts-interruption.test.js` 的一条旧静态断言失败，HEAD 页面同样缺少其要求的 `displayChatTtsStop`，与本功能无关。
- 后续：持有签名密钥的出包机生成服务代码包；Android 显示端实测全屏棋盘、语音与点按、断线恢复。

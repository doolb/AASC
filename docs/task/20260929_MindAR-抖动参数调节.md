# mmd-ar MindAR 抖动过滤参数调节

## 任务描述

在 mmd-ar HTTPS 网页上开放 MindAR One Euro Filter 的 `filterMinCF`、`filterBeta` 调节，供用户现场比较定位抖动与运动滞后。

## 设计需求

- 测试页提供独立“MindAR 抖动过滤”面板分类，默认沿用 MindAR 参数 `0.001` / `1000`。
- 设置保存在当前浏览器，不修改正式显示端和 APK。
- 新设置在下一次启动定位时应用；当前识别运行中不重启摄像头。
- 说明这两项不同于现有 PMX 相机跟随死区和缓动时间。

## 实现规范

- 从浏览器专用 localStorage 读取并校验设置，非法值使用默认值。
- 定位启动前写入 A-Frame MindAR image system，再创建 Controller。
- 拖动滑条立即显示数值并保存；页面明确提示停止后重启定位才能应用。

## 自测用例

1. 初次打开显示 `filterMinCF=0.001`、`filterBeta=1000`。
2. 移动滑条后数值同步变化并在刷新后恢复。
3. 新参数在下一次定位开始时传给 MindAR Controller；运行中的会话不被打断。
4. 无效存储值回退默认；不能写 localStorage 时当前页调节仍可用。
5. APK 生成模式和正式显示端不出现该测试参数 UI。

## 兼容性、性能与风险

- 两个值限制在 `filterMinCF=0.0001..0.02`、`filterBeta=0..2000`，保留正截止频率并覆盖默认附近的可比较区间。
- 调低最低截止频率可减少抖动但可能增加拖后；增大 beta 可改善快速运动响应但可能保留更多抖动。最佳值依赖设备、图像和运动速度。
- 滑条只改下一次 Controller 初始化参数，不增加每帧滤波器实例或重启相机开销。

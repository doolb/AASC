# 壁纸入口收起

需求：壁纸按钮不要遮挡显示端时间，并可像控制端入口一样收起。
设计：右侧中部放置半隐藏把手，首次点击展开，点击完整按钮进入系统预览；5 秒无操作、长按或返回时收起。
实现：先同步 `docs/spec/android-display.md`，再调整 MainActivity 的入口布局、交互和无障碍文字；不改变系统壁纸服务。
验证：Android debug APK 编译及相关回归；不同屏幕尺寸、时钟和手势的真机验收待完成。
兼容与性能：仅修改原生 UI，需更新 APK；单个主线程延时任务在暂停或销毁时清理。
风险：厂商屏幕边缘手势可能与把手竞争；预计工时 1 小时。

结果：noserver debug 编译成功，壁纸专项 2 项通过；Android 9 独立测试包确认把手位于右侧中部、点击展开及 5 秒自动收起。未替换正式 APK，其他尺寸和长按/返回行为待设备验收。

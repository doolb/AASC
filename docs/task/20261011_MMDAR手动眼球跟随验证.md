# MMD-AR 手动眼球跟随验证

## 任务描述
新增独立“眼球跟随”分类，用左右和上下滑块实时控制当前选中PMX人物眼球，验证眼球控制链路是否实际生效。

## Design需求
- 当前Human实例只控制当前PMX模型。
- 手动模式覆盖自动眼球跟随；恢复自动后重新跟随相机或临时点击目标。
- 左右范围-30°至30°，上下范围-20°至20°，默认0°。

## Spec设计
- Human gaze状态增加手动模式和两个角度字段。
- 渲染帧中手动模式使用固定眼球方向，继续保留显式动作占用权重和共有眼继承关系。
- UI input事件实时更新状态并唤醒渲染。

## 自测用例
- 检查分类、模式控件和两个滑块的范围及默认值。
- 拖动左右/上下滑块，确认状态实时变化并触发渲染。
- 开启手动模式后自动相机目标不覆盖手动角度。
- 恢复自动后状态使用自动目标。
- 检查边界值、模型切换和旧动作库兼容。

## 性能测试
- 不新增渲染循环；滑块只复用现有渲染唤醒和单一 RAF。
- 检查手动模式下每帧无额外模型遍历。

- 现场反馈确认目标模型左右眼骨骼名称为“左目先”和“右目先”，已纳入自动绑定别名。
- `gaze.set()` 不再因滑块更新清除逐骨骼缓动状态，动作结束后继续沿用 `headMs`/`eyeMs` 插值。
- 普通动作结束后，头部和眼球注视通道重新从零角度按各自缓动时长计时，不能沿用动作占用前的完成状态。
- 动作占用期间不写注视旋转但保留阻塞标志；占用释放后第一帧开始新的注视插值。

## 物理暂停恢复回归
- 现场反馈旋转速度超过阈值暂停物理后，拖动结束时布料出现一次跳动；历史行为没有该问题。
- 根因定位为恢复首帧新增 `MMDPhysics.reset()` 并清零动态刚体速度，使布料从暂停期间的世界姿态瞬移到当前骨骼姿态。
- 恢复策略按现场反馈调整为：先推进恢复帧的骨骼状态，再用该状态调用物理 `reset()`，并在同一帧执行一次物理；不能在旧骨骼状态下复位，也不能延迟到下一帧。
- PMX眼球骨骼命名、grant继承或物理控制可能导致实际动作不可用；面板状态必须显示能力原因。
- 正负方向受模型正面方向影响，需要以实际模型画面确认。

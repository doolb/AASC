# GPU 顶点布料 500ms 回退

## 需求与方案
用户报告计算耗时10秒且刷新仍卡死，确认超过500ms回退。保留既有Ammo骨骼实例；GPU刷新恢复改为Ammo；GPU计算分批与非阻塞栅栏控制在途任务，自碰撞按纹理4行切片。

## 实现
- 新增web-vertex-cloth-gpu-budget.mjs：墙钟500ms预算、每批至多4个pass、零等待栅栏查询、取消定时器/栅栏。
- 修改web-vertex-cloth-webgl.mjs/gpu-self.mjs：generator拆分、目标快照冻结、完整计算后写显示纹理；高DPI使用渲染目标像素裁切。
- 修改web-vertex-cloth-pmx.mjs：等待任务时骨骼照常运行；初始化/准备/复位超时与GPU错误退出顶点层、恢复网格并保存Ammo，禁止CPU整模回退。
- 修改web-physics-solver.js/inject.js：安全启动、刷新选择迁移、UI原因及状态同步、构建依赖指纹。

## 验证与限制
独立网页构建、静态语法解析；未新增或运行测试。真机超时、恢复、并发切换及正常计算观感待验收。500ms含调度等待，后台节流可能触发保守回退；无法抢占已经提交的GPU命令或驱动编译，不承诺首次阻塞最多500ms。未修改正式端或发布外网。

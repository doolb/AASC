# 显示端右侧面板互斥与 Android 色相渐变

## 任务描述

修复显示端右侧五个顶层设置面板切换时的重叠；修复 Android WebView 色相滑条呈白色的问题。

## Design 需求与 Spec 设计

- 面板设计与伪代码见 `docs/design/display-stage-panel-coordination.md`、`docs/spec/display-stage-panel-coordination.md`。
- 色相轨道见 `docs/design/android-color-picker.md`、`docs/spec/android-color-picker.md`。

## 受影响模块与代码

- `display.html` 与新增 `display-stage-panel-coordinator.js`：装配顶层面板互斥。
- `display-appearance-controls.js`、`tts-voice-picker.js`、`display-tts-voices.js`、`display-mmd-panel-groups.js`：暴露已有关闭流程。
- `android-color-picker.css`：渐变绘制在 WebKit 滑条轨道，元素背景保留回退。
- 定向浏览器测试、自测文档、待办、变更日志和服务代码包状态。

## 自测用例与兼容性

- 五个入口任意切换及再次点击，检查只一个面板可见且 ARIA 状态正确。
- 切走音色时取消定位请求；切走动作时停止定时器；子分类和弹层内按钮不受影响。
- Android UA 测试 WebKit 轨道计算样式及色相输入变化；PC 原生颜色控件保持现状。

## 性能与风险

捕获阶段只遍历五个固定入口；不增加轮询。风险是旧模块关闭时的内部状态未清理，因此必须调用各模块关闭方法。预计 2–3 小时。

## 未明确项

无。用户已确认五个右侧顶层面板互斥以及 Android 色相渐变一起修复。

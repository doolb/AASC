# 五子棋对话状态控制棋盘显示

- 任务：真实棋盘只在当前显示端 AI 对话活动时展示，退出后自动隐藏，棋局继续保存。
- Design：`docs/design/game-gomoku.md`；活动状态为 `activeGroup` 或 `activePrivate`，等待唤醒和关闭监听时隐藏；手动关闭优先，演示独立展示。
- Spec：`docs/spec/game-gomoku.md`；代码变更前已更新伪代码。
- 受影响模块：`display-stage.js` 缓存权威对话状态，`display-game.js` 应用状态门控，显示端浏览器测试和舞台状态测试。
- 自测：启动快照先到时不打开棋盘；活动群聊/私聊时展示；结束、超时或监听关闭后隐藏；重新唤醒时按持久化 `visible` 恢复；手动关闭保留；演示在非活动对话中仍显示。
- 兼容性：旧棋局文件与服务端协议不变；语音模块仍收到 `voiceConversationState`；重连时以服务端状态为准。
- 性能：对话状态变化只刷新棋盘容器可见性和已有交点的禁用状态，不重建棋盘。
- 风险：棋盘快照和对话状态到达顺序可能不同；未知状态默认隐藏，舞台缓存最近权威状态供游戏层初始化读取。
- 预计工时：约 1 小时。
- 验证：`node --test tests/display-game-browser.test.js tests/display-stage-rotation.test.js tests/game-gomoku.test.js` 21/21 通过；ADB 连接的 Note8 WebView 重载后，服务端状态为 `waitingWake`，已保存的四子棋局状态仍在，但棋盘、棋盘容器和恢复按钮均隐藏。

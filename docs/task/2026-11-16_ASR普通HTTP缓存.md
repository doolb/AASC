# ASR 普通 HTTP 缓存

- 任务：支持浏览器普通 HTTP 缓存，不使用 IndexedDB；适用于模型和词表。
- 设计：按 `docs/design/standalone-asr.md` 使用 max-age=0/must-revalidate，命中验证器返回 304。
- 规格：按 `docs/spec/standalone-asr.md`，本地预览实现 ETag/Last-Modified 和条件优先级；Apache 只匹配两个模型 URL。
- 模块：`/mnt/asr/server.mjs`、本地测试、Apache 精确路径配置及文档。
- 自测：200/304、ETag 不匹配优先级、修改时间、非模型资源、线上响应头和 304。
- 兼容性：标准 HTTP 缓存；缓存是否存下 229 MiB 文件由浏览器决定。
- 性能：命中时避免模型网络传输，重新加载内存及模型初始化仍需时间。
- 风险：Apache 配置语法和服务重载；安装后 configtest，失败回退；不改模型文件。
- 预计工时：半个工作日。

- 完成：本地 5 项测试通过，覆盖 ETag、修改时间、优先级和非目标资源；线上 Apache 语法校验成功，两个文件均返回缓存头及匹配 ETag 的 304，错误 ETag 返回 200，`.sha256` 不受规则影响。未验证特定浏览器是否会持久保存大文件。

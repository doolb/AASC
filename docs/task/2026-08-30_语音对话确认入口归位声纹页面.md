# 语音对话确认入口归位声纹页面

## 任务描述

将控制端“语音对话确认”模式开关从“显示控制”页面移动到“声纹管理 → 声纹识别设置”卡片内，避免语音相关全局设置分散在不同页面。

## Design 需求

- 保留 `off`、`manual`、`auto` 三档模式和全局配置行为。
- 删除显示控制页面的独立确认卡片。
- 在声纹识别设置卡片内显示确认模式下拉框。
- 由 `VoiceprintPanel` 负责配置展示、发送和 WebSocket 状态更新。

## Spec 设计

```text
控制端打开 panel-voiceprint
    VoiceprintPanel 初始化声纹配置和语音对话确认配置
    在声纹识别设置卡片渲染确认模式下拉框
    用户切换模式 -> setConversationConfirmationConfig
    服务端广播 conversationConfirmationConfig -> VoiceprintPanel 更新下拉框
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/upload.html`：调整卡片位置。
- `src/apps/web-mediacenter/ui/public/js/voiceprint-panel.js`：接管确认模式状态和保存逻辑。
- `src/apps/web-mediacenter/ui/public/js/device-list.js`：移除确认设置页面归属。
- `src/apps/web-mediacenter/ui/public/js/websocket.js`：把确认配置消息转发给声纹面板。
- `tests/display-voice-conversation-confirmation.test.js`：增加入口位置和模块归属契约。

## 自测用例

1. 显示控制页面不再包含 `voiceConversationConfirmationPanel`。
2. 声纹管理页面的声纹识别设置卡片包含确认模式下拉框。
3. WebSocket 配置广播由 `VoiceprintPanel` 更新，不依赖 `DeviceList`。
4. 三档模式选项和发送消息类型保持不变。

## 兼容性测试

- 服务端全局配置接口和语音命令不变。
- 声纹配置、服务端 ASR/TTS 开关和现有声纹注册流程不受影响。

## 性能测试

- 不新增定时器、请求或显示端连接。
- 配置消息仍只更新一个控制端下拉框。

## 风险评估

- 控制端 WebSocket 消息可能早于声纹面板初始化到达，因此面板需要先缓存模式，在页面初始化时渲染。

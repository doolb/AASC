# 20261010 MMD-AR 手动表情面板

## 需求/设计/实现

用户明确要求「先在动作面板加上表情分类，让我可以手动点」，并进一步确认通用、自动读取当前PMX。设计：`docs/design/mmd-ar-expressions.md`；伪代码：`docs/spec/mmd-ar-expressions.md`。独立网页里动态显示PMX表情，按钮可叠加、滑条控制强度、清除恢复VMD。

## 执行清单

- 先记录伪代码，再新增构建注入、实例控制器、面板模块。
- 在生成Loader保留Morph的原始名称/类型/面板类别；动态分组米娅29项。
- 逐帧维护VMD基线和手动覆盖，兼容无物理与物理前回调。
- 同步设计/实现/使用说明/todo/changelog，构建web-dist。

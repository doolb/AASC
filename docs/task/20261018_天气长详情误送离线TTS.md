# 天气长详情误送离线 TTS

## 任务描述与现场证据

2026-10-18 12:16:44 与 12:16:56 两次语音命令均为“今天天气怎么样”。服务端分别于 12:16:45、12:16:57 下发相同天气详情，文本约 1036 个 UTF-16 字符、2394 字节 UTF-8，包含当前天气及今日逐时预报；对应请求在 12:16:58、12:17:02 均由 Android Embedded Speech SDK 返回 `EMBEDDED_TTS_ERROR_UNKNOWN` / `80048028`。同一显示端在 12:16:31 成功合成较短媒体名称，说明模型并非一直不可用。当前配置为显示端生成、服务器 TTS 关闭、系统播报走 `system` Provider。仅凭该错误不能证明长文本是 SDK 唯一根因，但代码已确认天气控制端回调误用完整详情。
继续核对运行配置：`system.defaultSpeed=0`，对应原生 `SpeakText` 分支，不会调用项目生成的速度 SSML。SDK 文案“check your SSML”是该取消错误的提示，不能据此判定本次请求的 SSML 格式错误；设备对该长文本的具体失败边界仍待定向复测。

## Design 需求与 Spec 设计

天气朗读应使用已生成的 `speechText` 短摘要；完整 `detailText` 保留给天气详情展示。当前 `handleWeatherCommand` 在 `callbacks.onResult` 分支传入 `detailText`，而显示端 `onTts` 分支传入 `speechText`。经用户确认后，先更新 `docs/spec/display-voice-conversation.md` 的伪代码，再修改控制端分支，使两种播放路径使用同一摘要；详情展示的数据结构和旧端兼容保持现有契约。

2026-10-18 用户后续改变目标：完整 `detailText` 应在控制端和显示端均分段朗读；上面的短摘要方案不再作为实施目标。完整天气展示与播报都保留全部内容，应用层分段和其他播报入口共用同一上限。源码和定向测试已完成，真机待复测。

## 自测、兼容与性能

- 自测：运行天气定向测试和相关语音命令测试，核对“今天/明天/后天”短摘要与详情分离；复查语法和差异。
- 兼容：控制端 `playOnControl` 音频回包、显示端 `weatherResult` 详情和结构化天气数据保持原有消息协议。
- 性能：短摘要减少单次离线合成输入；现场设备复验仍需确认 SDK 在其他长文本下的限制。

## 风险与预计工时

若 Embedded Speech SDK 对短摘要也失败，仍需另查模型、资源或字符问题；服务器 TTS 关闭时当前没有回退来源。预计修改和定向验证约 1 小时，设备复验另计。源码修复须先取得用户确认。

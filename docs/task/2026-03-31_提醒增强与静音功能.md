# 任务：提醒增强与静音功能

**状态：✅ 已完成**

## 任务描述

实现以下功能：
1. 今日/明日提醒功能
2. ~~音量滑条拖动时显示禁止图标~~ (已移除，影响用户体验)
3. 静音/取消静音功能
4. 时间监听能力（重构报时和提醒）

## Design 需求

### 1. 今日/明日提醒功能

- 指令：`今日提醒` 或 `今天提醒`
- 指令：`明日提醒` 或 `明天提醒`
- 功能：搜索日期是今天/明天的提醒记录，通过语音播报出来

### 2. 静音功能

- 指令：`静音`
- 功能：将所有显示端的音量设置为0
- 同时显示静音图标
- 记录静音前的音量值

### 3. 取消静音功能

- 指令：`取消静音`
- 功能：将所有显示端的音量设置为上次静音前音量
- 同时隐藏静音图标、重置音量滑条到上次静音前音量

### 3. 时间监听能力

- 能力等级：L1
- 能力描述：监听系统时间变化，当时间变化时触发事件
- 重构报时能力和提醒能力，将时间变化能力移动到时间监听能力中

## Spec 设计

### 1. 今日/明日提醒功能

#### 服务端实现 (core/voiceCommand.js)

```
handleTodayReminders(displayId):
    获取所有提醒
    获取今天的日期
    过滤出今天触发的提醒:
        - type === 'daily' 的提醒
        - type === 'once' 且 nextTrigger 是今天的提醒
    如果有提醒:
        生成提醒列表文本
        生成 TTS 并播放
    否则:
        播报 "今天没有提醒"

handleTomorrowReminders(displayId):
    获取所有提醒
    获取明天的日期
    过滤出明天触发的提醒:
        - type === 'daily' 的提醒（每天都会触发）
        - type === 'once' 且 nextTrigger 是明天的提醒
    如果有提醒:
        生成提醒列表文本
        生成 TTS 并播放
    否则:
        播报 "明天没有提醒"
```

#### 语音命令处理

```
processVoiceCommand(text, displayId):
    如果 text 包含 "今日提醒" 或 "今天提醒":
        调用 handleTodayReminders(displayId)
        返回
    
    如果 text 包含 "明日提醒" 或 "明天提醒":
        调用 handleTomorrowReminders(displayId)
        返回
```

### 2. 静音/取消静音功能

#### 服务端实现 (server.js)

```
静音状态管理:
    mutedDisplays: Map<displayId, { muted: boolean, previousVolume: number }>

handleMuteCommand():
    遍历所有显示端:
        保存当前音量到 previousVolume
        发送音量为 0 的控制命令
        设置 muted = true
    广播静音状态到所有控制端

handleUnmuteCommand():
    遍历所有显示端:
        恢复 previousVolume
        发送音量恢复的控制命令
        设置 muted = false
    广播取消静音状态到所有控制端
```

#### 语音命令处理

```
processVoiceCommand(text, displayId):
    如果 text 包含 "静音" 且不包含 "取消":
        调用 handleMuteCommand()
        返回
    
    如果 text 包含 "取消静音":
        调用 handleUnmuteCommand()
        返回
```

#### 前端显示

```
静音图标:
    在音量控制区域添加静音图标
    静音时显示，取消静音时隐藏
```

### 3. 时间监听能力

#### 新模块 core/timeListener.js

```
class TimeListener:
    listeners: Map<string, Set<callback>>
    lastMinute: number
    timer: Interval
    
    on(event, callback):
        如果 listeners 没有 event:
            创建新的 Set
        添加 callback 到 listeners[event]
    
    off(event, callback):
        从 listeners[event] 移除 callback
    
    start():
        设置定时器每秒检查时间变化
        当分钟变化时触发 'minute' 事件
        当小时变化时触发 'hour' 事件
        当天变化时触发 'day' 事件
    
    stop():
        清除定时器
    
    checkTimeChange():
        获取当前时间
        如果分钟变化:
            触发 'minute' 事件
        如果小时变化:
            触发 'hour' 事件
        如果天变化:
            触发 'day' 事件
```

#### 重构报时能力 (core/timeAnnounce.js)

```
使用 TimeListener:
    timeListener.on('minute', () => {
        checkAndAnnounce()
    })
```

#### 重构提醒能力 (core/reminder.js)

```
使用 TimeListener:
    timeListener.on('minute', () => {
        checkReminders()
    })
```

# App 层第三步迁移任务

## 任务描述

- 目标：将提醒、语音命令、整点报时、时间监听从 `core/*` 迁入 `src/apps/web-mediacenter/modules/*`。
- 范围：迁移实现体、更新 `server.js` 引用、保留 `core/*` 兼容导出。

## design 需求

- App 模块承接业务规则实现体。
- server 入口直接依赖 App 模块。
- Core 仅保留兼容层，不承接业务实现。

## spec 设计

- 增加 App 第三阶段迁移伪代码。
- 明确 `server.js` 新模块引用路径。

1. `node --check server.js` 通过。
2. `node --check src/apps/web-mediacenter/modules/voice/voice-command-app-service.js` 通过。
3. `node --check src/apps/web-mediacenter/modules/reminder/reminder-app-service.js` 通过。

## 兼容性测试

1. server 对外接口与消息流程保持不变。
2. 旧 `core/*` 引用仍可工作。

## 性能测试

1. 本次为文件迁移与引用调整，运行时性能影响可忽略。

## 风险评估

- 风险：迁移后相对路径错误导致模块加载失败。
- 缓解：使用语法检查和兼容导出加载检查。

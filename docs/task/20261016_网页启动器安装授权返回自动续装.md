# 网页启动器安装授权返回自动续装

- 状态：代码与文档完成，Kotlin编译、网页脚本语法和diff检查通过；待出包/真机验收。
- 需求：系统安装来源开关未启用，授权返回后自动续接同一APK的系统安装确认。
- Design：docs/design/android-offline-js-launcher.md；Spec：docs/spec/android-offline-js-launcher.md，已先写草案。
- 影响：OfflineLauncherActivity.kt、启动页ui/index.html、release/offline-release-status.json的minApk/servicePackage与相关文档；不扩展服务业务范围。
- 实施：原生待办、打开授权设置、返回前台权限复查、一次消费、Activity重建恢复与网页状态反馈；沿用已有安装前验证。
- 自测场景清单：已有权限直接提交、开启后返回自动提交一次、不开启返回不循环、重复resume不重提、Activity重建、安装异常可重试。
- 兼容性：Android8+检查安装来源授权，旧系统保持直接提交；系统最终确认不变。
- 性能：缓存校验保留后台执行，不在主线程重新下载；不增加周期轮询；最终安装前SHA和系统会话写入也在后台。
- 风险：设置与安装界面生命周期时序、重建重复提交、RPC状态误报；以待办状态和真实权限判断约束。
- 预计工时：实现与静态检查约1小时，真机验收另计。
- 验证：Gradle :app:compileDebugKotlin --offline --no-daemon通过（3分24秒），启动页内联脚本node --check通过，git diff --check通过；未新增或运行测试，未构建APK/发布或真机验收。
- 出包：minApk/servicePackage设为true，其他产物状态保持；完整APK没有自动出包。

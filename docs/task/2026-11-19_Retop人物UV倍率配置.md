# 人物 UV 倍率配置

从高模独立重建人物，在固定图集内按美术优先级分配纹素。对应设计与伪代码见 docs/design/retop-texture-transfer.md、docs/spec/retop-texture-transfer.md。

- 涉及 uv-unwrap.js、engine.js、texture-transfer.js 的展开和烘焙，以及 app.js、index.html 和 styles.css 的本地配置。交付位于 subproject/retop/artifacts/moxing-uv-density-2026-11-19。
- 回归覆盖默认倍率、单独覆盖、非法输入、旧配置补默认、保留无关档位和几何、作废过期贴图以及 OBJ 逐角面积。浏览器检查应用和复位后的实际图集。
- 性能验收使用已生成几何重新展开人物档；大图烘焙复用原高模投影索引。预计验证耗时数分钟。
- 色彩对称复用可能使个别部位最终密度略有偏移。对同一张图同时记录有效覆盖面积和按表面累计面积。低模 2122 三角面，2048 图集覆盖 56.46%。相对上次成品，脸部 UV 面积增加 3.72%，胸前增加 9.49%，手臂增加 22.20%。
- 泛化试验使用另一套 idle099 模型的临时静态副本，11 个网格对象、9993 个三角面，人物入口在鼻尖定位阶段停止。该样例尚不能通过当前人物模板自动重建。
- 同一份 idle099 静态输入关闭人物模板后，常规特征减面实际生成 2122 个三角面，基础网格审计有效。本次没有对第二角色做美术质量验收。

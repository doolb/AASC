# HTTPS MMD AR 识别分辨率比例设置

## 任务描述与设计

- 2026-09-25 用户要求在定位面板调节 MindAR 识别输入分辨率；百分比相对于摄像头原始帧，默认 100% 必须等于原尺寸。
- 只控制独立识别画布，不改变相机采集、预览、正式显示端或旧测试 APK。
- 高分辨率 100% 可能使页面再次卡顿，因此提供 25%／35%／50%／75% 低档位及控件旁风险提示。
- 对应 `docs/design/mmd-ar-test-apk.md` 与 `docs/spec/mmd-ar-test-apk.md`。

## Spec、模块与测试

- `3rd/mmd-ar-test/build.js`：HTTPS 页生成分辨率选择与尺寸说明；`web-panel-groups.js` 沿用跟踪操作分组。
- `3rd/mmd-ar-test/display-mmd-ar-benchmark.js`：读取/保存浏览器本地档位，在下次启动 MindAR 时按原始视频宽高乘比例创建画布；运行中改档位不重启 Controller。
- `tests/mmd-ar-web-panel-groups.test.js` 与 `tests/mmd-ar-web-tracking.test.js`：检查控件分组、默认、持久化、35% 实际尺寸、定位后响应及运行中切换提示。
- 兼容性：旧测试 APK 不显示新控件，仍使用原像素预算；正式显示端无该设置。
- 性能风险：100% 输入像素数随手机相机分辨率增加；真机帧率/按钮可点性仍需现场验收。预计工时半天。

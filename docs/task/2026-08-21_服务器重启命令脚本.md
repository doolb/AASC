# 服务器重启命令脚本

## 任务描述

新增项目级服务器重启脚本，通过已有控制端接口重启服务器，并注册 npm 命令；脚本必须避免使用 HTTPS 代理。

## Design 需求

- 调用 `POST /api/restart`，不直接操作服务器进程。
- 使用 Node 原生 HTTP/HTTPS 客户端，不使用代理环境变量。
- 默认服务地址为 `https://192.168.1.39:8081`。
- 支持环境变量和命令行地址覆盖。

## Spec 设计

- 配置解析独立为可测试函数。
- 请求根据 URL 协议选择 `http` 或 `https`。
- 自签名 HTTPS 证书可用；请求超时、网络失败和 HTTP 非 2xx 均返回非零退出码。
- `npm run restart:server` 调用脚本。

## 自测用例

1. 默认地址解析正确。
2. `AASC_SERVER_URL` 可以覆盖默认地址。
3. 命令行地址优先级高于环境变量。
4. `/api/restart` 拼接不产生双斜杠。
5. 脚本源码不读取代理变量，不使用代理 Agent。
6. npm 命令配置正确。

## 兼容性测试

- HTTP 地址。
- HTTPS 自签名地址。
- Linux/macOS Node.js 环境。

## 性能测试

- 单次接口请求，无轮询和常驻进程。
- 请求超时后及时退出，不阻塞命令行。

## 风险评估

- 自签名证书兼容选项降低证书校验强度；脚本仅调用受控服务器重启接口，地址仍可由用户明确指定。
- 远程服务器不可达时只报告失败，不尝试直接操作服务器进程。

# Windows 语音输入超时、声纹策略与录音协议修复

## 任务描述

修复 Windows Node 子显示端语音输入流程：发送 Enter 后继续保持输入模式，连续 30 秒无输入才自动退出并播报结束提示；处理服务端下发的录音配置和临时录音请求，避免显示端打印未知消息；新增输入模式声纹策略本地开关，使用 `Alt+C` 在 `inherit` 与 `false` 之间切换。

## design 需求

- 语音输入普通文本发送到 Windows 当前前台窗口，不写入子显示端 TUI。
- “发送”只发送 Enter 并清空当前返回记录，不立即退出；30 秒无成功输入操作后自动退出并播报“已结束输入”。
- “结束输入”、输入模式快捷键关闭和进程停止清理超时计时器；开始/结束提示期间保持录音时序正确。
- `textInput.requireVoiceprint` 只保存在 Node 子显示端本地，默认 `inherit`；`inherit` 跟随服务器 `voiceprintConfig.enabled`，`false` 不要求输入模式 ASR 声纹匹配。
- 使用 `Alt+C` 切换本地声纹策略，只记录本地状态，不播报、不暂停录音，也不向服务器写回。
- 输入模式的有效声纹策略随当前 ASR 请求传到实际显示端；`false` 时跳过声纹提取和匹配，避免产生 `voiceprintElapsedMs`。
- Node 处理 `voiceRecordingConfig` 和 `displayRecordingRequest`，对暂不支持的临时录音能力回传明确错误，不再打印未知消息。

## spec 设计

- 在 `WindowsTextInputState` 中增加 `idleTimer`、`voiceprintPolicy` 和 `serverVoiceprintEnabled`。
- `sendTextInput()` 成功后保持 `active`，刷新空闲计时器；普通注入和返回成功后同样刷新。
- 声纹策略为 `inherit` 时使用最近一次服务器 `voiceprintConfig.enabled`；为 `false` 时跳过本地输入模式的声纹门控。
- 通过可配置的 Windows 全局快捷键实例注册 `Alt+C`，与 `Ctrl+Alt+Space` 分离。
- 对 `voiceRecordingConfig` 保存当前协议模式，对 `displayRecordingRequest` 按现有显示端录音回执协议返回不支持结果。

## 自测用例

1. 发送普通文本后说“发送”，目标窗口收到 Enter，输入模式仍为 active。
2. 发送或注入成功后重新计时；30 秒无成功操作后退出并播报结束提示。
3. “结束输入”和快捷键关闭立即清除计时器并播报结束提示。
4. `Alt+C` 在 `inherit` 与 `false` 间切换，重启后读取本地选择。
5. `inherit` 随服务器 `voiceprintConfig.enabled` 更新；服务器开启声纹且结果未匹配时不注入、不执行命令。
6. `false` 时即使 ASR 没有匹配说话人，普通文本和输入命令仍按输入模式处理。
7. `false` 时显示端不执行声纹提取/匹配，服务端 ASR 结果不再出现实际 `voiceprintElapsedMs`。
8. Node 收到 `voiceRecordingConfig` 和 `displayRecordingRequest` 时不打印未知消息，并按协议回传处理结果。

## 兼容性测试

- 非 Windows 平台不注册 `Ctrl+Alt+Space` 和 `Alt+C`，不影响原有 ASR。
- 未携带本地输入标记的旧客户端继续使用服务器原有语音流程。
- 保留现有 `Ctrl+Alt+Space` 输入模式快捷键及“返回”命令。
- 服务器未下发声纹配置时，默认按 `inherit` 的服务器默认值处理。

## 性能测试

- 定时器只在输入模式 active 时存在，退出时清理，不增加常驻轮询。
- 声纹策略只读取 ASR 返回的 `speaker` 字段，不在 Node 重复计算 embedding。
- `false` 输入模式请求跳过实际显示端的 embedding/声纹匹配，检查 `voiceprintElapsedMs=null` 和响应不含声纹说话人。
- 录音协议兼容处理不启动新的录音器或 ASR 任务。

## 风险评估

- `inherit` 依赖服务器声纹配置消息；断线期间保留最近一次权威值，首次未收到时使用安全默认值。
- `Alt+C` 可能与用户系统快捷键冲突，注册失败只记录日志，不影响输入模式快捷键。
- Node 暂不实现单次/实时临时录音回放，仅回传明确不支持结果，避免服务器临时会话一直等待。
- 当前环境不是 Windows，SendInput 和全局快捷键需在 Windows 10/11 实机验收。

- `false` 策略复用原生 ASR 的无声纹分支，声纹提取/匹配不执行，`voiceprintElapsedMs` 返回 `null`。

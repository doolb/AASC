## 自测与设备验收

- 环境构造：有效端点成对传递；缺失端点省略；非法端口/令牌拒绝。
- Kotlin定向单测与编译；现有JS启动器测试核对子进程环境继承兼容。
- SM-N9500/API28/WebView132：覆盖安装保留数据，创建/运行任务，登录前完成拦截、官网UI新会话成功回复后保存，Responses首轮与续聊。
- 性能：启动期绑定复用，不增加逐句聊天绑定；既有10秒绑定上限不变。
- 风险：网页SDK可能覆盖观察器；账号模板与实际Cookie须一致；验证未完成不得宣称兼容链路通过。
- 预计工时：实现和定向验证约1小时，真机与官网验证约1小时；现场登录/验证码等待另计。

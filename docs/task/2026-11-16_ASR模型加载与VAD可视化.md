# ASR 模型加载与 VAD 可视化

- 任务：独立网页加入实时音量和红色阈值、截止状态；模型未就绪禁止录音。
- 设计：复用现有 VAD 及模型路径；启动时加载识别器，加载失败可重试，显示进度；展示截止倒计时和短语音丢弃。
- 规格：见 `docs/spec/standalone-asr.md`；不改变 300ms 语音、500ms 静音、59 秒上限。
- 模块：`/mnt/asr/web` Worker、VAD、界面和测试；重新发布静态网页。
- 自测：模型加载/失败/重试、录音禁用、RMS 和红线、语音静音计时与上限；本地和线上资源验证。
- 兼容：现代浏览器 WebAssembly、Worker、Web Audio；不修改 APK。
- 性能：模型首次下载约 229 MiB；限幅并降低界面更新频率。
- 风险：低内存设备模型加载失败、噪声触发阈值；设备麦克风仍需现场确认。
- 预计工时：半个工作日。

- 验证：5 项 Node 自动测试通过；线上五个变更资源 HTTPS SHA-256 与本地一致。真实浏览器模型加载回归受本机运行缓慢影响未完成，设备麦克风待验收。

# MMD AR补光范围与骨骼遮挡透明度

## 需求与方案

补光背光过渡增加起点/终点设置（-1至1，默认-0.3/0.3），即时生效、本地保存、灯光恢复默认。骨骼保留小球相互遮挡，增加遮挡处不透明度（0至100%，默认50%），角色后方球面半透明、外露部分正常显示。

设计/伪代码见design/spec同名章节。需要lighting vec2 uniform及独立参数辅助、build/面板、骨骼模块/注入和角色深度辅助模块。角色深度纹理按像素判定遮挡，球间开启遮挡时使用球深度预绘避免透明后球残影；不通过暂停的AO算法实现。

## 检查计划

- 静态源/生成脚本语法、网页构建与资源指纹；本轮不新增或执行测试。
- 现场检查范围输入/顺序/保存/默认、强补光/转动角色与阴影模式。
- 检查球的角色内外、局部穿出模型、动作蒙皮/形变、AO开关与相互遮挡开关；透明度0/50/100、名称/轴/拾取、换模型/后台恢复/resize。

## 兼容、性能与风险

仅独立测试配置；缺失/非法设置明确默认，停用诊断或全不透明时不捕获角色深度。开启半透明诊断增加角色深度绘制，球间遮挡时另有球深度预绘；现场检查帧率。深度偏差、角色透明覆盖层、视口尺寸与透明混合顺序需认真处理，不影响角色本身渲染或修改模型。预计2至3小时，实际设备验收另计。

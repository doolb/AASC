# 混合播放列表文本接入

## 任务描述

将 txt/md 文本项接入现有 image/video/audio/html/gif 混合播放列表，并保持既有 playlistControl 协议兼容。

## 设计需求

- 文本项绑定播放列表上下文，只在最后一页完成时推进下一项。
- 列表级暂停、跳转和停止取消旧句子播放，避免过期 TTS 回包影响新项。
- 进度统一携带页面、句子与格式；非临时列表可恢复，base64 临时数据不可持久化。
- 控制端展示文本文件及页码，普通裁剪预览行为不变。

## 实现伪代码

```text
文本列表项 -> attachPlaylist -> load(pageIndex) -> 最终页回调 -> playlistNext
playlistProgress -> text 页面/句子/格式字段 -> server currentPlaylist 标量状态
重连 -> resumeIndex + resumeTextPage + resumeState -> 文本从该页第一句重新开始
```

## 受影响模块

- `display.html`、`server-app.js`、`websocket.js`、`media-library.js`
- `tests/text-media-playlist.test.js`、`tests/playlist-app-service.test.js`

## 自测与兼容性

- 文本末页推进、页码/格式进度、持久化恢复和控制端展示。
- image/video/audio/html/gif 原有播放列表、播放恢复和睡眠模式回归。

## 风险评估

- 异步 TTS 回包可能迟到：通过解绑 playlistContext 和播放器 playbackId 失效隔离。
- 临时数据较大：持久化状态只保存展示元数据与标量进度。

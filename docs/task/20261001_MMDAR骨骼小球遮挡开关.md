# MMD AR骨骼小球遮挡开关

## 需求

用户明确纠正为“前面的骨骼点挡住后面的”，开关应是“小球相互遮挡”，默认关闭、本地保存。开启后前方小球遮挡后方小球；始终可穿透角色显示。原“被角色遮挡”实现与用户意图不符，本轮沿用原实现授权修正。

修正伪代码先写入spec：开启时球同时depthTest/depthWrite，叠加绘制前clearDepth保留已绘颜色，只在球之间比较深度；取消骨骼角色深度请求。修改web-skeleton-debug.mjs、web-panel-groups.js及web-rigid-body-debug.js，既有显示接口/保存机制沿用，不增加pass。静态语法和网页构建后验收同类型/跨类型球、相机旋转、AO开关及重建保存。

## 设计与实现计划

对应design/spec同名章节已先更新。初次增加runtime/DisplayMmd接口、偏好与控件后，本轮纠正 `web-skeleton-debug.mjs`（球深度测试/写入、本层clearDepth）、`web-panel-groups.js`（文案）、`web-rigid-body-debug.js`（取消骨骼角色深度请求）。既有接口、保存、runtime重建补发沿用。构建复用已有模块复制和指纹流程。

默认false兼容旧偏好，存储受限时本次仍可切换；独立测试副本接入，正式显示端不新增配置。仅开启时清本层深度，球间按表面深度比较，不增加pass或角色深度遍；角色覆盖层不会挡球。清深度发生在角色/碰撞体颜色已绘制之后，后续新叠加若要复用角色深度需独立考虑。预计半小时，实际手机观感和帧率待现场验收。

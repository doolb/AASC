# 独立 APK 声纹模型 INT8 对比测试

## 任务描述

用户确认在 `3rd/tts-server/android-asr` 中保留三个 FP32 声纹模型，并增加对应 INT8 变体做性能和准度 A/B 测试。用户指定 `妲已妈妈.wav` 注册为“妲己妈妈”，再用 `你好，小爱.wav`、`你好啊你好啊你好啊.wav`、`zh.wav` 测试。

## Design 需求

- 原生页面和 HTTPS 测试网页都支持模型与精度选择，默认 FP32/base。
- INT8 使用静态校准生成，不改 ASR、分割、流式 ASR 和降噪模型。
- 切换组合时释放旧模型并清空注册库；结果记录变体、分数和耗时。
- FP32 继续作为默认和失败回退选项。

## Spec 设计

- 新增 `VoiceprintPrecision` 与 `VoiceprintModelVariant`。
- 模型资源复制任务包含 6 个 embedding 文件；HTTP 兼容未传 precision 的旧客户端。
- `VoiceprintTestCoordinator` 以变体加载，注册和测试结果携带精度字段。
- 量化脚本使用 80 维 Fbank 校准，并输出主机比较报告。

## 受影响功能模块和代码

- `VoiceprintModel.kt`、`VoiceprintModelFiles.kt`、`VoiceprintTestCoordinator.kt`、`HttpJson.kt`、`AsrHttpServer.kt`。
- `MainActivity.kt`、`AsrWebPage.kt`、原生布局和字符串资源。
- `app/build.gradle.kts`、声纹模型资源、量化工具和 Android/Node 契约测试。

## 自测用例

- Kotlin：精度解析、变体 ID/文件名、资源完整性、HTTP 状态/切换/结果字段。
- Node：网页精度选择器及模型切换请求包含 precision。
- 主机：六个 ONNX 文件可被 ONNX Runtime 加载，FP32/INT8 embedding 可计算 cosine。
- 真机：SM-N9500 上逐个加载三个 INT8；注册“妲己妈妈”后测试指定的三个 WAV 和 `zh.wav`，记录匹配结果、similarity、embeddingMs、elapsedMs。

## 兼容性测试

- 保持 `POST /api/voiceprint/model?model=eres2net-large` 继续加载 FP32。
- 旧状态字段和原有三个模型 ID 保持可读。
- APK 目标架构仍为 `arm64-v8a`，FP32 默认路径不变。

## 性能测试

- 每个模型/精度使用相同注册音频和测试音频，在同一 CPU 模式下比较 embeddingMs 与总耗时。
- 同时记录 APK 进程内存，关注 INT8 是否降低内存以及是否出现 native 崩溃。

## 风险评估

- 静态量化可能改变余弦分数，需要重新观察阈值；本次不自动调整生产阈值。
- Snapdragon 835 的 INT8 kernel 未必比 FP32 快，结果以真机实测为准。
- Sherpa AAR 若不支持量化图，需保留 FP32 并明确标记 INT8 不可用，不影响原有测试。

## 预计工时

约 2–4 小时，包含量化、APK 构建和真机四段音频回归。

## 执行结果

- ✅ 已完成三个静态 INT8 模型生成、主机 ONNX Runtime 校验、APK 资源打包和真机安装。

- ✅ 已完成对应 FP32 对照；量化分数变化小，但本轮测试中 `zh.wav` 与注册音频的相似度均低于 0.5，未匹配。

### 真机结果摘要

| 变体 | 你好，小爱 | 你好啊你好啊你好啊 | zh.wav |
| --- | --- | --- | --- |
| base INT8 | 妲己妈妈 / 0.6854 | 妲己妈妈 / 0.5414 | 未匹配 / 0.0370 |
| large INT8 | 妲己妈妈 / 0.6467 | 妲己妈妈 / 0.5110 | 未匹配 / -0.0090 |
| V2 INT8 | 妲己妈妈 / 0.6502 | 妲己妈妈 / 0.5476 | 未匹配 / 0.1733 |

结论：INT8 版本可用，但当前设备上的性能收益不稳定，因此默认仍为 FP32；INT8 保留为手动 A/B 选项。

## 分段复测结果

- ✅ 使用 `SHERPA_MULTI`、`speakerCount=AUTO` 完成三个模型/两种精度的独立进程复测。
- INT8 的 Pyannote 分段约 `0.23–0.28s`，与 FP32 基本相当；平均 embedding 阶段相对 FP32：base 降低约 57%，large 降低约 59%，V2 降低约 46%。
- `你好，小爱.wav` 均分为 1 段并匹配；base/large 对重复“你好啊”均分为 2 段，V2 均为 1 段；`zh.wav` 均为 1 段且未匹配。
- 连续切换模型时曾由 Android `lmkd` 以 `signal 9` 回收 APK 进程；逐模型/精度重启后所有分段测试完成，未发现 INT8 native 加载失败。

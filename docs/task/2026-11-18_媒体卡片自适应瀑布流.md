# 媒体卡片自适应瀑布流

- 任务：图片、视频和远程封面根据可用尺寸自适应宽高，横向更宽、竖向更高；未知尺寸和文件夹使用默认卡片。
- 设计：参见 `docs/design/control.md`；封面覆盖、底部浅渐变、主题及全部卡片操作保留。
- 实现：按 `docs/spec/upload.md` 监听媒体尺寸、卡片内容与容器变化，批量更新网格跨度，不使用固定行高约束实际卡片。
- 影响：控制端媒体库样式、布局脚本、HTML 入口及自测；不改变服务端协议。
- 自测：真实 Chromium 验证横竖图、视频元数据、未知尺寸、动态加载及缩放、重叠、封面、触屏和点击。
- 兼容性：桌面、移动设备、主题、远程来源与不可用缩略图；缺失尺寸时降级到默认比例。
- 性能：尺寸变动合并到动画帧处理，避免逐元素持续轮询；不额外读取远程视频。
- 风险：远程封面可能不同于原视频比例；动态加载时卡片会重新排列。
- 预计工时：约 3 小时；未明确事项：无。

# IMU 模拟器静止漂移修正

状态：用户已确认，修正和专用测试完成；真实浏览器鼠标轨迹及手机现场效果待复核。

## 任务描述与需求等级

用户反馈当前模拟偏移很大。房间 `AASCIMU1` 实时轨迹记录到：参考位置停稳后估计速度约 `[-1.120, 0.008, 1.913] m/s`，处理后加速度为零，最终位置误差约 16.22 m。原始加速度按当前姿态去重力的残差约 0.32 m/s²，持续超过停稳门限 0.12 m/s²。按项目需求分级规则，此问题的主层级为 L5 估计流程，次层级为 L4 采样数据流；停稳、倾斜对齐和阈值统计已拆成实现伪代码。用户未给出定量误差验收值，按“停稳后速度归零，误差不再线性扩大，现有无噪/带噪行为不退化”自测，真实手机精度另行验证。

## Design 需求与 Spec 设计

设计见 `docs/design/imu-six-axis-test.md` 的“模拟器静止后持续漂移修正”；伪代码见 `docs/spec/imu-six-axis-test.md` 的“模拟器静止漂移修正”。单朝向静置死区校准同时对齐含重力测量的倾斜，保留零偏和比例，使用候选姿态重算死区。线性加速度输入不做重力对齐。模拟器零速修正需要测量减速证据，估计器继续只看六轴测量，不读取模拟真值纠偏。

## 影响模块与代码

- `tests/imu-six-axis-engine.test.js`、必要时浏览器测试：倾斜静置、停稳归零、拒绝窗口保持原状态。

## 自测与兼容性

`npm run test:imu:six-axis-test` 最终 18/18 通过。增加固定种子带噪模拟，验证校准后倾斜对齐、平面往返运动途中不误清速度、停稳后归零及位置稳定；窗口失败保留姿态/阈值，线性加速度输入不改变姿态，手机默认不自动清速度。固定种子三段平面目标往返后静置 5 秒的最终误差约 0.46 m，运动中自动修正 0 次、停稳后 1 次；开发中仅完成重力对齐、尚未加入减速门控的中间实现，同轨迹在运动中误清速度，最终误差约 8.02 m。当前本地浏览器仍需刷新并重置实验生成新轨迹，不能拿旧轨迹当修复后的现场结果。真实手机位移仍可能漂移。

## 性能与风险

静置校准窗口仍以 1200 样本为上限，重算只在校准完成时进行；正常逐帧采样仅增加模拟器模式的向量点积。纯六轴无法严格区分静止与匀速，也无法从已产生的积分误差恢复真实位置；减速证据仅减小当前模拟器的匀速误判，死区仍可能吞掉慢动作。静置采样必须由用户确认实际静止。真实鼠标轨迹和 Android 实测另行验收。

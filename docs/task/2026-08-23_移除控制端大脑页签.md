# 移除控制端大脑页签

## 任务描述

控制端“大脑”页签是独立的日志摘要与诊断页面。日志问题改由工作 Agent 根据项目日志文件自行分析，因此移除该控制端页签及其专用前端资源；服务器端日志采集、`LogBrain` 和日志 API 保留。

## Design 需求

- 控制端侧边栏不再显示“大脑”入口。
- 控制端不再创建日志大脑面板，也不再加载日志大脑查看器脚本。
- 旧版本保存的 `lastPanel=brain` 自动回退到“媒体”，避免刷新后出现空白页面。
- 不删除服务器端日志大脑模块、日志诊断 API 和配置，保持后台能力及接口兼容。
- 不为 Agent 增加新的日志读取规则。

## Spec 设计

```text
控制端启动
  -> 加载媒体、显示、提醒、聊天、日志、设置、任务等现有页签
  -> 不注册 brain 导航项
  -> 不创建 panel-brain
  -> 不加载 LogBrainViewer

服务器启动
  -> LogBuffer 持续接收日志
  -> LogBrain 持续摄入日志并提供既有 API
  -> 与控制端是否显示大脑页签无关
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/upload.html`：删除导航入口、日志大脑面板和脚本引用。
- `src/apps/web-mediacenter/ui/public/js/main.js`：删除日志大脑初始化与面板切换钩子。
- `src/apps/web-mediacenter/ui/public/js/log-brain-viewer.js`：删除控制端专用查看器。
- `src/apps/web-mediacenter/ui/public/css/upload.css`：删除日志大脑专用样式。
- `src/framework/observability/log-brain.js`：保留，不改动。
- `src/apps/server/api/log-brain-api.js`：保留，不改动。
- `docs/design/log-brain.md`、`docs/spec/log-brain.md`、`docs/design/sidebar-registry.md`、`docs/spec/sidebar.md`：同步控制端页签移除后的设计和伪代码。

## 自测用例

1. `upload.html` 不包含 `data-target="brain"`、`panel-brain` 或 `log-brain-viewer.js`。
2. `main.js` 不包含 `LogBrainViewer`。
3. `upload.css` 不包含 `.brain-` 专用样式。
4. `log-brain-viewer.js` 文件已删除且无其他引用。
5. 服务端仍保留 `LogBrain` 装配和 `/api/logs/brain-*` API。
6. 既有日志大脑单元测试和 API 集成测试保持通过。

## 兼容性测试

- 控制端其他页签切换、最近页签恢复逻辑保持不变。
- 服务端日志缓冲、日志大脑摘要、判断上下文和诊断回退逻辑保持不变。
- 不触碰 Agent 后端、聊天流式显示和 TTS 播报链路。

## 性能测试

- 控制端不再加载日志大脑脚本和页面资源，减少初始化资源与事件监听。
- 服务端日志采集与 `LogBrain` 处理开销保持原有行为。

## 风险评估

- 低：修改范围限定在控制端日志大脑 UI，服务端模块和 API 不删除。
- 需要确认没有用户依赖通过控制端访问该页签；用户已明确要求移除。

## 预计工时

约 30 分钟（前端清理、文档同步和回归检查）。

# 显示端语音状态、旋转适配与监视图动画

## 任务描述

显示端当前语音状态只改变颜色和提示，不显示“未就绪、监听中、暂停监听”等明确状态；TTS 暂停录音时会被误显示为就绪。显示端音频监视图在无有效频谱时缺少稳定的动态反馈，并且旋转布局只调整监视图位置，没有让监视图本身跟随 90/180/270 度旋转。

## Design 需求

- 语音状态统一显示三种状态：未就绪、监听中、暂停监听。
- 未启用声纹识别且 TTS 暂停录音时显示暂停监听，恢复录音后显示监听中。
- 语音状态和音频监视图复用显示端的四向旋转布局，并以对应角点为变换原点。
- 监视图复用已有 AnalyserNode 和频谱数组，空闲或低信号时绘制动态占位柱，避免每帧分配数组。
- 监听状态与柱状图组成不换行的横向状态行，整体放在逻辑顶部边缘中间；最近识别文本放在下一行，柱状图宽度调整为 140px。
- 柱状图尺寸变化不重新绑定识别文本的定位锚点，避免语音文本位置跳动。
- 监听中与暂停监听使用明显区分的绿色、橙色背景和边框样式。

## Spec 设计

- `getVoiceDisplayState()` 按能力、TTS 暂停、监听中的优先级返回状态对象。
- `updateVoiceStatusDisplay()` 同步文本、class、title 和 data-state。
- `applyRotation()` 同时定位并旋转 `voiceStatus`、`monitorWrapper`。
- `animateMonitor(timestamp)` 使用帧时间增量绘制真实频谱或动态待机柱。
- `applyVoiceTopCenterLayout()` 统一设置状态行和识别文本的顺序、间距、宽度和四向边缘中心定位。
- `applyVoiceCenteredAnchor()` 按当前未旋转尺寸直接计算 90°/270° 的边缘中心锚点，重复排版不累加历史补偿。
- 文本更新调度只刷新尺寸限制和语音锚点，不重新初始化整套语音 UI。

## 自测用例

1. 不支持语音、监听未启动或监听关闭时显示“未就绪”。
2. 监听运行时显示“监听中”。
3. 未启用声纹识别的 TTS 播放暂停期间显示“暂停监听”，结束后恢复为“监听中”。
4. 旋转为 0/90/180/270 度时，语音状态、柱状图和识别文本均设置对应旋转并保持边缘中心排列。
5. 监听中复用 `monitorDataArray`，空闲时监视图仍有随时间变化的柱高。
6. 监听中和暂停监听的背景颜色、边框颜色明显区分，状态行不换行且柱状图宽度为 140px。
7. 连续更新短文本、长文本并重复旋转时，识别文本和状态行锚点不漂移、不越界。
8. 页面内联脚本可编译，既有显示端语音监听、会话、TTS 和旋转回归测试不退化。

## 兼容性测试

- 浏览器显示端默认方向及 90/180/270 度方向。
- 未启用声纹识别和已启用声纹识别两种 TTS 录音策略。
- 不支持语音识别、ASR 尚未就绪、监听关闭和正常监听状态。

## 性能测试

- 监视图动画每帧不新建频谱数组。
- 不新增 `AudioContext`、麦克风轨道或 WebSocket 连接。
- 页面脚本语法检查和 `git diff --check` 通过。

## 风险评估

- 旋转监视图的变换原点若设置不一致，可能造成顶部语音区域越界；通过四向静态契约和包围盒校正降低风险。
- 空闲占位动画仅用于状态反馈，不应被误认为真实音量；使用低幅、半透明样式区分。

## 预计工时

约 1 小时。

## 实现结果

- 语音状态按能力、TTS 暂停和监听状态显示“未就绪”“暂停监听”“监听中”，并同步 `data-state`。
- 语音状态和音频监视图纳入显示端四向旋转布局；监视图按角度设置角点变换原点并进行包围盒校正。
- 监视图使用帧时间推进动画，复用 `AnalyserNode` 频谱数组，低信号和非监听状态显示低幅动态柱。
- 监听状态和柱状图组成不换行的横向状态行并整体居中，最近识别文本位于下一行；0°顶部、90°右侧、180°底部、270°左侧，柱状图宽度为 140px 并继续跟随当前旋转角度调整方向。
- 识别文本保留独立固定边缘锚点，状态行宽度变化不会改变其逻辑中心位置；`applyVoiceCenteredAnchor()` 根据当前实际尺寸直接设置旋转补偿，重复文本更新不会发生补偿累加或位置跳动。
- 监听中使用绿色背景、暂停监听使用橙色背景，状态文字和动画保持可区分。
- 文本更新调度不再调用完整的语音 UI 初始化，只在下一帧重新测量首次显示的识别文本并稳定其锚点。
- 验证：页面内联脚本编译通过，显示端语音/旋转聚焦回归 14/14 通过，`git diff --check` 通过。

# 测试用户任务

## 任务描述
在 `res/tasks/` 中添加一个测试用户任务 `test-echo`，用于验证用户任务的提交、执行、日志、结果返回的完整流程。该任务接收任意参数，将其原样输出到日志和结果中。

## Design 需求
- 在 `res/tasks/test-echo/task.js` 新建测试任务
- 执行时将 `params` 原样输出到日志（stdout）
- 执行时将 `params` 写入结果文件 `output.json`
- 支持 `mode: "one-shot"`，执行完即返回
- 用于验证远程任务系统的端到端通信和文件传输

## Spec 设计
- 用户任务，提交参数：
  - `taskName: "test-echo"`
  - `taskType: "user"`
  - `entryFile: "task.js"`
  - `target: "server"`
  - `mode: "one-shot"`
  - `params: { ... }` — 任意参数，原样回显
- `task.js` 通过 `console.log` 输出参数到日志
- `task.js` 将参数写入 `results/{instanceId}/output.json`

## 受影响的功能模块和代码
- `res/tasks/test-echo/task.js` — 新建测试用户任务入口文件
- `src/apps/web-mediacenter/ui/public/js/task-panel.js` — 用户任务卡片增加快捷运行按钮

## 自测用例
1. 控制端提交 `test-echo`，传入 `{ message: "hello", count: 42 }`
2. 服务端收到任务后执行，日志输出 `{ message: "hello", count: 42 }`
3. 服务端返回 `output.json`，控制端可查看和下载
4. 控制端提交不传 params，任务仍正常执行，输出 `{}`

## 兼容性测试
- 新增用户任务文件，不影响已有任务
- 无代码侵入性修改

## 风险评估
无。纯新增用户任务文件。

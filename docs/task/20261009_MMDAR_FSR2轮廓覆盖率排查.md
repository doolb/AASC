# MMD-AR FSR2轮廓覆盖率排查

日期：2026-10-09。状态：用户确认后完成覆盖率修正、GPU回归、共享构建兼容与本地网页重建；手机观感仍待实测。

## 需求与证据

用户反馈“竖向和横向会改善，斜向反而加重”，本轮明确加重的是“锯齿更明显”。沿用现有MMD-AR FSR2上下文；现场设备、实际加载版本和静态/动画区别仍待确认。

现有代码已改成横纵亮度梯度估计切线，不能再次把该修改当成新方案。现有浏览器测试仅覆盖0/45/90度，断言部分覆盖数量与跨帧alpha RMS；这不足以证明空间轮廓更准确。

`reconstructCurrent`从四点无条件选最近前景深度，剔除背景颜色并归一化剩余权重。比例1、像素中心正好对应背景texel且邻接前景时，双线性权重为[1,0,0,0]；剔除背景后total=0，回退最近前景，把中心alpha从0变1。数值探针按当前分支已复现；尚未用真实GPU逐像素复现或确认是现场现象的唯一原因。

## 初始需求分析（enterprise，保留排查历史）

- 结论：需补充；主等级L6（抗锯齿模块质量契约），无架构改动。判级置信度1.00，仅表示三个同层证据的一致性，不表示根因置信度。
- 证据：[L6|强] 横竖改善；[L6|强] 斜向加重；[L6|强] 用户确认是锯齿。
- 评分：层级清晰度22/25、证据充分度14/20、实现完备度9/20、风险暴露度16/20、L4可落地性12/15，总分73/100；现场复现不足，直接开发风险中。
- 建议下放至L4：把颜色覆盖率、重投影深度与空间参考误差拆成独立数据流。
- 范围与目标：缺实际版本/设备；建议记录当前页面版本与环境，否则可能测到旧构建。
- 输入输出契约：缺真实斜边样本；建议同时测透明和不透明双色轮廓，否则alpha夹具可能遗漏内部色彩边缘。
- 验收与观测：缺空间准确度指标；建议以高分辨率参考覆盖率比较边缘误差和轮廓位移，否则模糊也可能通过现有测试。

## design需求与spec草案

保持普通TAA及FSR2比例设置；修复应保护轮廓覆盖率，不以增加模糊作为验收。先补空间误差测试并定位上采样和最终滤波各自的影响；颜色/alpha覆盖重建与最近深度重投影分开，避免零空间权重的前景替代背景中心。

已有声明：reconstructCurrent、presentShader、FSR2浏览器夹具。
新增定义：ReferenceCoverage、SpatialEdgeError、ContourShift。
操作流程：相同场景和采样相位 → 高分辨率参考覆盖 → FSR2重建与最终呈现分别取样 → 比较空间误差及轮廓位置 → 单独修正被验证的失败分支 → 回归横竖和斜边。

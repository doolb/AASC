# 六轴IMU共享3D测试网页

日期：2026-10-03。状态：实现完成，自动化与Android采集/校准/共享已验证；真实轨迹精度与iOS留待现场验收。

## 任务描述

先开发独立六轴惯性网页实验：电脑模拟角速度/加速度、零偏/噪声/漂移/丢样；真实手机授权采集；不同设备接入同一3D场景，观察物体平移/旋转、轨迹与诊断。原APK单目IMU方案保留后续。

用户已明确电脑页左右两份：左场景、右模拟陀螺仪，不手填六轴数值。右侧拖动虚拟设备的位置/旋转手柄生成六轴，具体交互与右相机跟随已获用户确认。左侧必须由经过估计器的传感器数据驱动，不能直接复制右侧真值。

## 需求明确性与待确认

- “物理”暂按“物体”理解，首版显示惯性估计的位姿，不额外加碰撞/场景重力。
- 多设备每台独立物体或轮流控制同一物体：已提问，默认草案为每台独立颜色物体。
- “接近真实运动”按短时惯性实验、可量化模拟误差和实机观测理解；不能承诺纯六轴长期绝对位置/航向准确。
- 手机使用浏览器DeviceMotion平台数据；原生未处理硬件IMU接入不是本轮既定范围。可明确显示数据能力，不能假造缺失轴。
- 本地测试服务提供房间共享；可信HTTPS/WSS接入环境需核对，当前请求不包含外网发布或生产代理变更。
- 使用者点击静置/六面校准及授权；单姿态静止不足以完整估计加速度零偏，匀速不能因低加速度而误判静止。

对应`docs/design/imu-six-axis-test.md`与`docs/spec/imu-six-axis-test.md`。已有声明：three/ws、浏览器事件与WebSocket；新增声明：SixAxisSample、ImuCalibration、ImuState、Simulator、RoomDevice、PublishedFrame、SceneDevice；统一测量入口，源端处理、观察端显示。

## 自测用例

- 三轴90度/组合旋转与不同dt；四元数归一与方向。
- 已知加速/匀速/减速三轴轨迹；默认不将低加速度直接清零速度。
- 静止与纯旋转含重力测量、线性测量两条路径；重力不重复扣除，世界轴与浏览器轴无重复屏幕旋转。
- 单姿态静置质量检查、陀螺仪零偏，六面加速度偏置/比例及运动/噪声不合格拒绝。
- 可重复种子、多组零偏/白噪声/随机游走，比较未处理和处理误差；模拟真值不进入估计器。
- 缺字段、null、重复/倒序时间、长断流/丢样、显式停稳与手持假设状态。
- 两输入/两观察端进入同房间；其他房间隔离，跨设备覆盖拒绝；晚加入、断线/重连、旧代次、慢连接及清理。
- 浏览器完整页面与模拟轨迹、授权拒绝/恢复、手机版布局与停止/后台资源释放。
- 桌面左右分栏、真实鼠标平移/旋转手柄、相机事件隔离；右侧突然拖动时六轴有限。中断传感器数据后右侧仍能操作、左侧不会直接随真值运动。

## 兼容性与性能测试

桌面Chromium无传感器也可模拟；Android/iOS浏览器按照实际能力处理授权，HTTPS/WSS与手机信任证书需验收。旋转屏幕不改变自然传感器坐标。渲染60Hz为目标，传感器实际Hz独立报告，网络发送限频；设备数、轨迹长度和消息缓冲有界，停止/断线需清理。数据面板批量低频更新，不每采样重建DOM；精度/性能结论只依据测量。

## 风险评估与预计工时

风险：加速度双积分漂移、姿态误差泄漏重力、低幅慢运动被死区遮蔽、匀速误判静止、浏览器数据被滤波/量化/限频、不同设备初始坐标未物理对齐、网络与数据断流。通过真值对照、显式数据种类、校准质量与假设、时间边界和设备隔离处理，不宣称消除不可观测误差。预计开发及定向自测8–16小时，手机HTTPS环境与现场验收另计；不是当前会话交付时间保证。

## 需求分析（enterprise，默认项已按本轮实现落地）

主等级L6、次等级L5/L7；架构含设备输入与房间共享，必须下放到L4数据/状态步骤。结论：需补充，风险中；不是不能开发，而是设备控制方式、真实精度口径与HTTPS现场条件需确认/验证。

证据：六轴控制3D运动（L6强3）；处理零偏/死区/噪声（L6强3）；电脑模拟输入及噪声（L6强3）；多设备接入同场景（L7中2）；校准/采集/断线状态流程（L5中2）。主等级权重9/13，相邻层一致性0.90，置信度0.623。评分：清晰22/25、证据18/20、完备12/20、风险19/20、L4可落地13/15，共84/100。分数不是精度承诺。

需补充：
- 业务规则：多设备控制方式未明确；建议每台独立物体，不确认会影响设备所有权与场景逻辑。
- 输入/输出：浏览器平台数据能力与初始设备坐标不同；显示能力/单位并独立校准，不确认会把不同数据当同一硬件真值。
- 验收/依赖：长期精度不可由纯六轴保证且手机需要可信HTTPS；明确模拟误差和现场验收、核对入口，否则界面可用不等于手机可采集或真实定位准确。

L4草案的已有声明/新增定义/操作流程已写入spec。用户确认具体交互后按本地JS模块实现；未应用跨语言翻译技能，也未修改APK。

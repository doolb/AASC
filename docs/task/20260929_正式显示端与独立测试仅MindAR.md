# 2026-09-29 正式显示端与独立测试仅 MindAR

## 任务描述

正式显示端的图片定位只保留 MindAR；独立 MMD-AR 测试 APK 不再提供当前 JS/MindAR 算法对比，也固定使用 MindAR。HTTPS 测试网页原已使用 MindAR-only A-Frame 流程，保持其独立标记和运行方式。

## Design 需求

- 正式定位面板只说明 MindAR，不提供算法选择；页面不加载旧 JS 图片跟踪器脚本。
- `aasc.display.mmdAr.engine.v1` 中以前保存的 `legacy` 值不能触发旧算法。
- 独立测试 APK 不包含当前 JS 跟踪器，不生成算法选择器或 A/B 结果列表；保留 MindAR 编译/首锁/帧率/可见率/丢失/抖动的单算法指标。
- 测试 APK 与正式显示端必须通过各自运行标记选择 MindAR 路径；HTTPS 测试网页保持 A-Frame MindAR 专用路径。
- MindAR 延迟加载、定位目标存储、摄像头生命周期和状态提示保持原有语义。

## Spec 设计

- `docs/spec/mmd-image-ar.md`：增加正式页 MindAR-only 路由与历史配置忽略伪代码。
- `docs/spec/mmd-ar-test-apk.md`：更新 APK 与 HTTPS 网页构建模式，记录仅 MindAR 运行与单算法指标。

## 受影响的功能模块与代码

- `src/apps/web-mediacenter/ui/public/display.html`：固定 MindAR 文案、运行标记并移除旧 tracker 脚本入口。
- `src/apps/web-mediacenter/ui/public/js/display-mmd-ar.js`：正式端固定路由到 MindAR，移除算法选择状态和 legacy 回退。
- `tests/display-mmd-ar-production.test.js`：验证正式入口只暴露 MindAR。
- `3rd/mmd-ar-test/build.js`：APK/网页构建不复制旧跟踪脚本，不插入 A/B 选择；APK 写入 MindAR-only harness 标记。
- `3rd/mmd-ar-test/display-mmd-ar-benchmark.js`：APK benchmark 固定调用 MindAR 并记录单算法指标。
- `tests/mmd-ar-benchmark-mindar-only.test.js`：验证独立 APK 构建配置和 benchmark 不含 current JS 执行分支。
- `3rd/mmd-ar-test/README.md`、design/spec/task/todo/changelog。
- `release/offline-release-status.json`：确保 `servicePackage` 为 `true`；不构建或签名生产 APK。

## 自测用例

1. 正式显示端页面没有算法下拉和旧 JS tracker script，只显示 MindAR。
2. localStorage 中遗留 `legacy` 时正式定位仍调用 MindAR，取消加载时能取消 MindAR pending。
3. 独立 APK harness 不打包 `display-mmd-image-tracker.js`，不生成 current 选项，benchmark 只创建 MindAR 测量。
4. 独立 APK 保留定位图校准、单算法测量、停止释放和报告重置；HTTPS 测试页构建成功，生成页包含 MindAR-only 标记且不含旧 tracker 或 current 算法选项。
5. JS 语法检查和相关契约测试通过；Android 构建因 Windows Gradle 启动器调用错误失败，直接调用 `gradlew.bat` 后又因环境无法建立 loopback 连接而失败，未生成测试 APK。

## 兼容性测试

- 检查正式页、HTTPS 网页与 APK harness 使用互不混淆的 marker。
- 检查旧浏览器存储中的算法选择不会阻止新路径初始化。
- 检查 MindAR 首次延迟加载、重新启动、停止、后台恢复和摄像头释放逻辑不变。

## 性能测试

- 正式页不加载旧图像匹配代码；独立 APK 不复制旧 tracker 资源，减少无用脚本解析及 APK 资源。
- MindAR 仍在用户开始定位后按需加载；不改变摄像头帧率调度和 MMD 渲染循环。

## 风险评估

- 浏览器可能保存旧 `legacy` 偏好；运行时必须完全不读取该值，不能只移除界面选项。
- APK 与 HTTPS 测试网页依赖不同 MindAR 入口，错误共用标记会使测试 APK 调用不存在的 A-Frame tracker。
- 旧 A/B 设备结果只作为历史数据，不能继续描述新版 APK 当前功能。

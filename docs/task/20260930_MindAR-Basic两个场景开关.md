# MindAR Basic 两个场景开关

- 需求：按图片可见/不可见分为两个开关，每个同时使用旋转与位置预测更新相机运动。
- design/spec：mindar-basic-web 两个场景开关章节和伪代码。
- 实现：移除第三个平移开关；可靠视觉判断选择场景；停用时保留姿态并清零速度，继续采样但停止运动积分，重新开启不补积分。
- 代码：index.html、mind-basic.js、mind-basic-imu.js；更新浏览器及算法回归。
- 自测：独立关闭可见场景，失锁场景继续旋转和平移；关闭失锁场景全部冻结；仅开启可见开关在失锁时不偷偷预测；重新开启与失锁时间保持。
- 兼容/性能：保留主按钮权限和校准、目标尺寸与平移上限；沿用原采样/渲染循环，无新识别任务。设备坐标系与真机帧率待验收。
- 风险：实验平移仍会漂移，图片可见时视觉持续纠偏；失锁预测受时长和距离约束。
- 预计工时：约 30 分钟。当前未发布。

- 完成结果：34/34 回归通过，定向 diff 空白检查通过；真机场景切换、精度与帧率待确认。

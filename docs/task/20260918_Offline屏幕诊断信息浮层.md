# Offline 屏幕诊断信息浮层

## 任务描述

在 Offline APK 屏幕右下角显示当前显示分辨率、DPI 和 WebView 缩放值，方便现场确认 Display 2 的缩放校正结果。

## design 需求

- 仅 Offline APK 显示诊断浮层，普通 APK 保持现状。
- 显示当前 `widthPixels×heightPixels`、`densityDpi` 和 `WebViewScalePolicy` 计算出的百分比。
- 浮层放在 `webContainer` 右下角，不接收输入；启动遮罩、更新卡片和控制端按钮保持更高层级。
- 配置变化时重新读取 metrics；不修改系统显示配置和既有输入/媒体协议。

## spec 设计

```text
OfflineDisplayInfo.refresh:
    如果 offlineMode == false：隐藏浮层
    metrics = 当前 display Context.resources.displayMetrics
    scale = initialScalePercent(true, metrics.widthPixels, metrics.heightPixels, metrics.densityDpi)
    显示“分辨率 {width}×{height} | DPI {densityDpi} | 缩放 {scale}%”

MainActivity.onConfigurationChanged:
    Offline 模式下调用 OfflineDisplayInfo.refresh
```

- `activity_main.xml`：新增右下角诊断 `TextView`。
- `MainActivity.kt`：读取当前 Display metrics，复用缩放策略并处理配置变化。
- `tests/android-offline-apk.test.js`：增加浮层布局、Offline 可见性和策略复用静态回归。
- `docs/design/android-display-offline-apk.md`、`docs/spec/android-display-offline-apk.md`、`docs/design/android-display.md`、`docs/spec/android-display.md`：同步设计与伪代码。
- `docs/todo.md`、`changelog.md`：同步任务状态和完成记录。

## 自测用例

- Offline Display 2 显示应用区域 `1920×1018 | DPI 160 | 缩放 75%`；底层虚拟屏物理/逻辑分辨率为 `1920×1080`。
- `1280×720@320dpi` 显示缩放 100%；`720×1480@280dpi` 显示缩放 101%。
- 普通 APK 隐藏浮层。
- 配置变化后文字重新读取当前 metrics。

## 兼容性测试

- Android 9/API 28、SM-N9500、Display 2 Desktop 虚拟屏。
- 启动遮罩、更新卡片、控制端按钮和诊断浮层同时存在时层级正确。

## 性能测试

- 仅在 Activity 创建和配置变化时计算一次，不增加 WebView 加载或服务请求。

## 风险评估

- Display 2 报告 `touch NONE`，无法通过 adb 定向触控确认右下角点击行为；浮层设置为不可交互以避免拦截页面输入。
- Android WebView 初始缩放只在构造时生效，配置变化仅刷新诊断文字；若系统在运行中改变 density，需重新创建 WebView 才能应用新比例。

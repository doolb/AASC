# MMD AR 测试网页相机裁剪范围读数

- 日期：2026-09-28
- 需求：仅在 `mmd-ar-test` 网页“基础光照”显示当前 near/far，帮助判断 AO 深度异常；不改正式显示端、测试 APK 或发布资源。
- 设计：见 `docs/design/mmd-ar-test-apk.md` 的“独立深度纹理诊断页”。
- 实现伪代码：见 `docs/spec/mmd-ar-test-apk.md` 的“测试网页基础光照实际相机裁剪范围”。
- 受影响模块：`3rd/mmd-ar-test/build.js` 在网页构建副本注入投影读取器；`web-panel-groups.js` 添加无 ID 只读标签并按当前矩阵刷新。
- 自测：`npm run build:web:mmd-ar-test`；`node --test tests/mmd-ar-web-panel-groups.test.js`；检查普通/AR 模式、模型未就绪、非标准矩阵和面板关闭状态。
- 兼容性：不增加正式显示端控件或 ID；测试 APK 不受网页构建分支影响；手机浏览器仍需现场核对。
- 性能：只在灯光面板可见时每 500 毫秒读一次 4×4 矩阵，不触发渲染或重新加载模型。
- 风险：非标准投影矩阵不能反解时显示明确提示；现场 near=24、far=75 是动态读数，不代表其他模式恒定值。
- 预计工时：1 小时。

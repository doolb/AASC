# 显示端主题面板光晕设置

## 任务描述

在显示端右下角“主题”面板加入背景光晕的中心颜色、中心亮度范围和扩散范围设置，复用控制端已经使用的全局配置。

## Design 需求与 Spec 设计

- `docs/design/display-background-glow.md`、`docs/design/control-ui-theme.md`：定义两端共用一组权威光晕值，以及显示端面板的视觉和交互。
- `docs/spec/display-background-glow.md`、`docs/spec/ui-theme.md`：描述显示端预览、提交、服务端身份校验、广播及断线恢复伪代码。

## 受影响模块与代码

- `src/apps/web-mediacenter/ui/public/display.html`：增加三个光晕控件及状态提示。
- `src/apps/web-mediacenter/ui/public/css/display-mmd.css`：适配主题面板中的控件和小屏布局。
- `src/apps/web-mediacenter/ui/public/js/display-background-glow.js`：复用控件绑定和预览，在显示端通过 DisplayStage 发送配置。
- `src/apps/web-mediacenter/ui/public/js/display-appearance-controls.js`：断线时恢复光晕预览。
- `src/apps/server/boot/server-app.js`：显示端接收相同配置消息并复用校验、持久化及广播流程。
- `tests/display-appearance-controls.test.js`、`tests/display-background-glow.test.js`：验证双端 UI、消息、预览及断线行为。

## 自测用例与兼容性测试

- 显示端主题面板中三个控件可见，滑动或选色可实时预览，提交发送正确的 WebSocket `type` 和配置。
- 权威广播更新显示端和控制端控件；服务端拒绝失效的显示端连接和无效值。
- 断线、失败回包恢复最后权威值，重连补发并回显；控制端原有光晕入口保持正常。
- 在窄屏检查面板位于按钮左侧、内容可滚动且不越界。

## 性能测试与风险评估

输入预览只写 CSS 变量，不新增轮询；提交只在 `change` 事件发送一次。两端共用全局配置，另一个端同时修改时以服务端最后广播的权威值为准。现有媒体与睡眠遮罩层级不变。

## 预计工时

约 1 小时；真实设备观感及网络异常仍需现场验收。

已完成显示端面板、共享 WebSocket 保存和错误恢复，并更新控制端自测接口检查。相关光晕、外观、主题及 TTS 透明度测试 14/14 通过，语法与差异检查通过；真实设备上的小屏观感和跨端同步列入 `docs/todo.md` 现场验收。

# 壁纸加速度传感器桥

需求：壁纸状态网页运动事件可能被系统暂停，经用户确认仅在壁纸使用原生加速度计；普通模式仍用网页事件。
设计：真实可见壁纸、非前台且镜头开关开启才注册含重力加速度，30Hz 向页面发送；来源互斥，沿用既有回中，角速度不参与。
实现：见壁纸控件 spec；Android 传感器生命周期与网页桥，网页根据壁纸状态选择输入，旧 APK 回退网页事件，缺传感器报告。
影响：Android 显示端、壁纸控件、自测、spec、design。
自测：壁纸与普通来源互斥，开关、前后台、壁纸隐藏和重新显示，有限值过滤、无传感器提示；Android 编译和单元测试。
兼容：旧 APK 继续网页路径；新 APK 需服务包配合；Android 加速度轴与网页相同，实机验证。
性能：仅可见时 30Hz 输入；禁用立即注销。
风险：壁纸 WebView 渲染调度仍受系统影响，快速旋转加速度基线存在暂态；目标手机需实测。
预计工时：半天。

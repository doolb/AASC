# 显示端 B 站首页与推荐

- 任务描述：显示端 B 站支持与控制端一致的热门首页、当前视频相关推荐及卡片操作。
- design：复用现有 B 站发现服务与播放、加入、下载、复制入口，保留既有收藏目录。
- spec：请求首页及相关推荐，按当前视频去重并防止过期响应；可信 BV 和分 P 经服务端校验及权威播放流程。
- 影响：显示端媒体库 HTML/CSS/JS、B 站虚拟来源与服务接线、定向自测和文档。
- 自测：热门与推荐展示、播放及卡片操作、切换当前视频的迟到响应和失败回退。
- 兼容性：验证普通浏览器、移动视口和已保存项目；真实上游及手机待验收。
- 性能：避免频繁重复请求与无限缓存，不新增常驻轮询。
- 风险：上游限流或网络不可用；目录缓存与播放授权需防止外部 URL 注入。
- 预计工时：4 小时。
- 验证结果：显示端媒体库、B 站来源和播放定向 35 项通过；真实 B 站网络、手机播放与下载仍待验收。

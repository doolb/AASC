# MMD AR 重力旋转叠加手动角度

- 需求：独立体感定位改为重力方向控制角色锚点旋转，手动旋转保持并可叠加。
- 设计：beta/gamma 推导重力上方向，忽略航向；初次样本为中性参考，手动和重力独立保存，最终四元数叠加。
- spec：网页构建注入控制器和 PMX runtime；先更新相机后转换重力倾斜并组合角色枢轴；居中/关闭不改手动角度，方向/后台切换重新参考。
- 实现：web-gravity-mode.js、build.js、web-panel-groups.js；网页控件改为独立重力旋转/重力灵敏度/重力居中。
- 待验证用例：alpha 缺失但 beta/gamma 有效、单纯航向转动不改重力层、前后/左右倾斜、手动后启用和启用后手动、居中/关闭保留手动、横竖屏/后台、权限取消及迟到授权、模型延迟/重载、IMU 相机融合同时开启。
- 兼容/性能：保留现有角色拖动/缩放、near=1、PMX 动作/物理、相机死区与第二层缓动；增加每帧四元数组合，无额外识别任务；手机性能待验证。
- 风险：设备姿态是浏览器融合结果，运动时的倾斜估计仍可能波动；角色枢轴旋转会牵引布料，快速转动沿用原物理限速保护。
- 预计工时：约 45 分钟。
- 完成结果：网页已重新构建并同步 web-dist，静态语法及定向差异空白检查通过，未新增/运行测试；按用户要求提交源码，未发布外网。

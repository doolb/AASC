# 任务记录：服务端入口迁移到 src

## 任务描述

- 需求来源：用户补充“server.js 也一起换了”。
- 目标：将服务端入口从根目录迁移到 `src/apps/server/boot/`，配合目录整理目标。

## Design 需求

1. 服务端入口归位到 `src/apps/server/boot/server-app.js`。
2. 根目录结构说明不再依赖根 `server.js`。
3. 设计/实现文档引用同步到新入口路径。

## Spec 设计

1. 更新 `package.json` 的 `main` 与 `start` 指向新入口。
2. 新入口内部统一使用 `PROJECT_ROOT` 拼装 `res/config/src/apps/web-mediacenter/ui/public` 等路径。
3. 迁移后保持对原有模块和 API 行为兼容。

## 影响模块与代码

- 入口代码：`src/apps/server/boot/server-app.js`（由 `server.js` 迁移）
- 启动配置：`package.json`
- 说明文档：`readme.md`
- 索引文档：`docs/design.md`、`docs/spec.md`
- 结构文档：`docs/design/project-structure.md`、`docs/spec/project-structure.md`
- 变更日志：`changelog.md`

## 自测用例

1. 执行 `npm start`，确认服务可正常启动。
2. 访问 `/upload` 与 `/display` 页面可返回。
3. 检查媒体库配置、地图配置、`3rd/voice-display-node/config.json` 路径可正常读写。

## 兼容性测试

- 启动命令兼容：继续使用 `npm start`。
- 模块兼容：AASC、ASR、TTS、提醒、日志大脑初始化流程保持不变。

## 性能测试

- 无算法与数据结构调整，性能无预期变化。

## 风险评估

1. 风险：入口迁移后相对路径失效。
2. 缓解：统一引入 `PROJECT_ROOT` 并替换关键文件路径拼装。

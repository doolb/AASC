# MMD 显示端灯光与阴影设置

## 任务描述

在本地显示端增加时间区域下方的灯光按钮和详细设置面板，使 PMX/VRM 角色可以实时调整环境光、主方向光、主光方向和角色阴影，并在当前浏览器保存设置。本任务不处理 Offline APK、外网资源上传和远端配置同步。

## Design 需求

- 在 `display.html` 的舞台交互层加入灯光按钮和面板。
- 面板包含环境光/主光颜色、强度、经度/纬度方向、亮度预设和恢复默认。
- 面板增加角色阴影开关，默认开启。
- 默认值保持播放器现有灯光：环境光 `1.8`，主光 `2.3`，方向约为经度 `31°`、纬度 `46°`，光源距离固定。
- 通过显示端本地 `localStorage` 保存规范化设置，不增加 WebSocket 或 HTTP 配置接口。

## Spec 设计

- `display-mmd.js` 持有默认灯光和规范化状态，runtime 创建后立即应用当前值。
- `display-pmx-runtime.js` 与 `display-vrm-runtime.js` 暴露 `setLighting()`，只更新已存在的 Three.js 灯光对象。
- `display-mmd-lighting.js` 管理表单、预设、恢复默认、面板开关和本地存储。
- 强度、经度和纬度限制在 spec 定义的范围内，颜色只接受 `#RRGGBB`；旧版 X/Y/Z localStorage 只迁移为经纬度，不再显示或输出。
- runtime 使用透明接收阴影平面；角色网格同时投射和接收自阴影，开关同步控制 renderer 阴影贴图与两类阴影。
- 阴影贴图提升为 `1024×1024`；模型加载后依据包围盒动态设置阴影相机范围和主光 target，避免固定 `10×10` 大范围降低人物阴影质量。

## 自测用例

1. 显示端 HTML 包含右上角灯光按钮和详细面板。
2. 点击按钮可以打开/关闭面板，按 Esc 或点击面板外关闭。
3. 调整强度、颜色和方向时，PMX/VRM runtime 调用 `setLighting()`，不重新加载模型。
4. 选择默认/柔和/明亮预设后立即更新表单和灯光。
5. 点击“恢复默认”恢复 `1.8 / 2.3 / longitude=31° / latitude=46°`。
6. 刷新显示端后从 `localStorage` 恢复规范化设置；非法存储值回退到安全范围和白色。
7. 阴影默认开启，关闭后不再显示角色阴影；刷新后保留开关状态。

## 兼容性测试

- 桌面 Chromium/Chrome：面板布局和颜色/范围输入。
- 移动 WebView：右上角安全区、触摸按钮和滚动面板。
- PMX runtime：不改变 staged 模型和 VMD 加载流程。
- VRM runtime：保留现有 VRM 代理和缓存流程。

## 性能测试

- 灯光调整只更新两个 Light 对象，不触发模型网络请求。
- 表单输入不创建新的 runtime、renderer 或动画循环。
- 页面刷新只读取一条小型 `localStorage` JSON。
- 阴影关闭时禁用 shadow map，降低 GPU 开销。

## 风险评估

- 开发 HTTPS 证书可能阻止浏览器自动化验证；需要在已信任本地证书的显示端或手工浏览器中确认视觉效果。
- 某些 WebView 可能禁用 `localStorage`，此时灯光仍能在当前会话生效，但刷新后回到默认值。
- 本任务不改变 Offline APK 和外网发布资源，后续发布时需要单独复核资源包边界。

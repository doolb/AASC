## 已确认的采样契约差异

Android MainActivity.kt在gyro.timestampNs时刻对前后两条加速度做线性插值，sample.time为该陀螺时刻，并附accelBeforeTime/accelAfterTime。server.mjs校验及透传这些字段，app.mjs逐条将完整sample送入引擎。Android事件时间是事件发生时间，不是区间平均，参考[SensorEvent.timestamp](https://developer.android.com/reference/android/hardware/SensorEvent#timestamp)。

imu-engine.mjs当前把本次gyro当整段角速度，用其推进q，同时以半段midpoint旋转本次accel；没有按APK瞬时采样与模拟器区间采样分路。imu-simulator.mjs生成的gyro正是区间平均值、force来自区间中点姿态，所以原模拟测试与该约定一致，不能覆盖原生瞬时输入。原生当前时刻的force应配当前时刻姿态；角速度积分也须同时修正，单换旋转姿态会引入另一项时间误差。

## 独立只读探针与限制

临时脚本`/tmp/aasc-imu-instant-probe.mjs`和`/tmp/aasc-imu-coning-probe.mjs`，另有带二样本交叉项的coning-corrected版本。真值由解析角度/角速度生成，不使用产品积分反推真值；全都关闭静稳、磁场、死区、低通，初始姿态已知，只检查数值时序。

- 50Hz、恒定7rad/s纯旋转无平移2秒：原引擎虚假线性加速度峰值0.686325m/s²、末Z约-1.371810m；瞬时端点配姿态及前后gyro均值传播的数学候选接近浮点零。该算例开始即非零角速度，不代表手机真实启停轨迹。

- 50Hz、10秒解析多轴旋转、峰值5.5493rad/s且真值无平移：原引擎末位置模长24.0679m、姿态峰值误差6.2712°；前后gyro均值+端点force候选1.0557m/0.4233°；加入二样本角速度交叉项的候选0.5909m/0.2481°。25/100Hz也已保存结果。候选仍有数值误差，尚无生产生命周期、原死区/磁辅助联动，不能直接称为产品修复收益或这次实测误差来源的完整解释。

# 历史临时会话下拉选择器

## 任务描述

控制端临时页签当前将每组历史临时会话显示为按钮，历史组较多时占用较多横向和纵向空间。将其改为单个下拉选择器，保留会话摘要、只读查看和返回当前对话的行为。

## Design 需求

- 历史会话使用原生 `select` 下拉控件呈现。
- 每个历史选项显示开始时间、角色名和消息数量。
- 下拉首项为“当前对话”；选择历史项只读查看该组，重新选择当前项返回实时会话并恢复发送。
- 无历史组时显示“暂无历史会话”，不影响角色选择和重新开始按钮。
- 不增加服务端消息、接口或持久化字段。

## Spec 设计

```text
renderTemporaryHistorySelector():
    创建“历史临时会话”标签和 select
    第一项 = 当前对话，value = 空字符串
    后续项 = 历史组，label 包含开始时间、角色和消息数
    当前查看历史组时按 sessionId 选中对应 option

select change:
    value 为空 -> 清除历史查看 ID，渲染当前消息，恢复发送
    value 非空 -> 校验历史组仍存在，设置只读查看 ID，渲染该组并禁用发送
```

## 自测用例

1. 有多组历史时显示一个下拉框，每个选项包含开始时间、角色和消息数量。
2. 选择任一历史会话显示对应消息，输入和清空保持禁用。
3. 选择“当前对话”恢复最新临时消息和发送能力。
4. 没有历史组时仍显示可用控件及“暂无历史会话”，当前对话不受影响。
5. 窄屏下下拉不撑破临时页签布局，角色切换和重新开始按钮可用。

## 兼容性、性能与风险

- 使用浏览器原生 select，不改变服务端协议或历史会话数据格式。
- 选择项数量与服务端现有历史组上限一致；没有额外网络请求和轮询。
- 历史组从新到旧的顺序沿用当前快照顺序。

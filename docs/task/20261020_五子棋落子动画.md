# 五子棋落子动画

- 任务：用户、AI 和演示的每次权威落子，给新棋子播放短暂的落下回弹动画。
- Design：`docs/design/game-gomoku.md`；动画只属于显示效果，不改变落子请求、权威棋盘或胜负。
- Spec：`docs/spec/game-gomoku.md`；实现前已更新伪代码。
- 受影响模块：`display-game.js`、`display-game.css`、`display-game-browser.test.js`。
- 自测：真实落子和演示落子在有效增量后播放；完成后清理临时类；初始与恢复快照不重播；版本缺口不播放；系统减少动态效果时静态展示。
- 兼容性：旧服务端消息不变；Android WebView 使用现有 CSS 动画能力；无动画支持时棋子仍直接显示。
- 性能：只更新一个交点及其棋子，不重建棋盘；动画仅改变透明度与 transform。
- 风险：动画中途收到新快照时旧节点被替换；事件监听随旧节点释放，不影响新棋盘。
- 预计工时：约 40 分钟。
- 验证：`node --test tests/display-game-browser.test.js tests/game-gomoku.test.js tests/gomoku-ui-demo-script.test.js` 17/17 通过；Note8 当前显示端重载并运行本机演示时，CDP 实测新棋子 `I5` 的动画名为 `display-game-stone-place`，演示结束后真实棋盘按 `waitingWake` 状态隐藏。

# 控制端一键暂停所有录音

## 任务描述

增加控制端右下角圆形图标浮动按钮，通过服务端运行时状态统一暂停或恢复所有在线显示端录音。

## Design 需求

- 使用独立的服务端内存状态，不持久化。
- 通过 WebSocket 同步控制端、浏览器显示端和 Windows/Android Node 显示端。
- 暂停普通监听、阻止新录音、终止临时录音并丢弃在途 ASR 结果。
- 恢复只恢复普通监听，不恢复临时录音。

## Spec 设计

- 控制消息：`setGlobalRecordingPause`。
- 权威状态消息：`globalRecordingPauseState`。
- 浮动按钮只显示状态图标，文字放入 title 和 aria-label。

## 自测用例

1. 控制端首次连接显示“暂停录音”图标。
2. 点击后服务端广播暂停状态，所有显示端停止普通监听。
3. 暂停时新 ASR、临时录音和在途 ASR 结果不进入命令链路。
4. 正在进行的单次/实时临时录音被丢弃，不自动恢复。
5. 点击恢复后仅普通 ASR 监听恢复。
6. 控制端或显示端重连后仍遵循服务端状态。
7. 服务端重启后默认恢复录音。

## 兼容性测试

- 浏览器显示端。
- Windows `voice-display-node`。
- Android 内置 Node 显示端。
- 声纹开启/关闭、不同录音模式和现有播放暂停配置。

## 性能测试

- 状态广播只发送一个布尔字段。
- 暂停不创建新音频线程、不持久化配置、不改变能力配置。

## 风险评估

- 主要风险是全局暂停与 ASR 异步返回、临时录音会话终止之间的竞态。
- 通过服务端异步完成后的二次检查和会话删除保证结果不进入命令链路。

## 预计工时

- 约 1.5 小时，包含协议、三端门控、测试和文档同步。

# MindAR Basic 死区翻倍与快速失锁衔接

- 需求：计算出的死区放大一倍，检查快速左右移动镜头时视觉定位丢失后重现。
- 设计/spec：mindar-basic-web 死区翻倍及首个跟踪失败帧接管章节。
- 完成：陀螺仪自适应低/高门限均×2；首个原始失败帧启用失锁逻辑；反复失败清空重获计数但不延长平移预测窗口。
- 代码：mind-basic-imu.js、mind-basic.js、index.html；算法和浏览器回归。
- 测试场景：死区迟滞、间歇失败不冒充连续三帧恢复、未收到正式 targetLost 也需稳定重获，原有漂移/融合/质量/拍照流程。
- 兼容：未改 MindAR 官方识别与滤波参数，没有新增识别或轮询循环；真机性能与快速横移实拍待测。
- 风险：死区扩大影响极慢转动，运动模糊/视野外仍可能失锁，无法保证视觉永不丢失。
- 预计工时：约 20 分钟；发布状态：尚未发布。

- 结果：33/33 定向回归通过，未收到正式 targetLost 的短失锁也正确要求连续三帧重获；真机效果待验证。

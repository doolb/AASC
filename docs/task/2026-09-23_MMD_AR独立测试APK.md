# 2026-09-23 MMD AR 独立测试 APK

## 任务描述

在 `3rd/mmd-ar-test/` 新增独立 Android 测试 APK，不连接或启动 AASC 服务；内置当前默认 `miya-default` PMX 及所需纹理/默认 VMD，支持本地图片基准图 AR。

## Design 需求

- 使用 APK 内置的回环静态 HTTP 服务（仅监听 `127.0.0.1`）运行 AR 页面和资源，不启动 AASC 服务。
- 保留现有显示端的灯光面板、PMX 布料/刚体物理及拖动旋转。
- 使用独立包名与独立构建目录，不覆盖正式 APK。
- 不带 AASC/Node 服务、控制端、聊天、LLM/ASR/TTS 和其他模型。
- 模型资源下载后须按固定大小和 SHA-256 校验，模型缓存和 APK 不提交 Git。

- `docs/spec/mmd-ar-test-apk.md` 描述模型资源准备、APK assets、本地 profile 响应、Android 相机授权、AR 生命周期和验证伪代码。

## 自测用例

1. Gradle debug APK 构建成功，applicationId 独立。
2. 包含当前固定 PMX、所有声明纹理和默认 VMD，逐文件 SHA-256 一致。
3. 不含 Node Runtime、AASC server/task、其他模型或外部 MMD URL。
4. WebView 本地资源能加载，摄像头授权拒绝/授予路径清晰。
5. 真机相机校准和本地图片跟踪可用；灯光、VMD/布料物理与拖动旋转均可交互。

## 兼容性测试

- Android 8.0/API 26 及以上；APK 不含 ABI 专用原生库；至少一台实际测试手机验证 WebView 版本与相机权限。
- Android WebView 未更新或不支持 WebGL 的设备应显示明确失败状态，不回退访问服务器。

## 性能测试

- 记录 APK 大小、PMX 初次解析时间、跟踪帧耗时和屏幕旋转期间布料运行状态；不预设未测数值。
- 相机停止、应用切后台和 Activity 销毁后确认摄像头轨道释放。

## 风险评估

- WebView 本地 origin 和 `getUserMedia` 权限链：回环 HTTP 服务严格限定资源路径和 WebView origin，并由 WebChromeClient 窄化 CAMERA 视频授权；禁止 LAN 监听和外部资源回退。
- 模型仅在公网静态目录：构建时按固定 IPv4 地址下载，并以已审核的文件长度/SHA-256 拒绝替换。
- 不同设备 GPU、WebView 与 PMX 物理差异：自动构建/资源校验后仍需真机视觉验收。

## 预计工时

- 约 5–8 小时，含独立工程、模型资源准备、WebView 权限、前端 harness、构建验证和文档；真机体验验收按设备可用时间执行。

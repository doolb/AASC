# 独立 MMD-AR：FSR2轮廓边缘滤波优化

日期：2026-10-09。状态：实现、定向Shader/模型回归与本地网页构建完成；手机实机验收仍待设备。

## 用户反馈与目标

用户指出FSR2边缘锯齿/爬行仍不如TAA，并补充内部比例设为1.0也无改善。由此不能仅提高比例或改变默认比例；本任务在保留原TAA与现有FSR2比例设置的前提下，优化FSR2输出轮廓。不得增加物体/骨骼运动矢量处理。

## 设计与实现契约

依据：`docs/design/mmd-ar-test-apk.md`“FSR2轮廓锯齿/爬行优化”节；`docs/spec/mmd-ar-test-apk.md`“FSR2轮廓边缘滤波”伪代码。

- 仅FSR2模式的最终输出pass读取输出分辨率颜色邻域，执行轻量FXAA风格边缘检测/滤波；常规TAA保持旧present行为。
- 只对超过对比度阈值的高对比轮廓低权重混合，限制方向和跨度；尽量保护内部平坦色、纹理细节与透明alpha。
- 沿用既有输出颜色目标与present pass，不新增历史目标、运动矢量、FSR2比例设置或持久化字段；保留当前`fsr2Scale`默认值/上下限。
- FSR2时域历史保持未滤波状态，滤波仅应用于最终呈现；保证既有色彩空间转换和预乘/非预乘切换顺序正确。

## 自测与兼容性

- 静态斜边：比较滤波前后部分覆盖像素数量和边缘方向错误；同一高对比场景跨多个jitter相位，比较输出边缘亮度/alpha变化范围。
- 检查平坦区域RGB变化在允许阈值内，透明/预乘alpha正确，图层无颜色晕边。
- 普通TAA结果不变：present pass不执行新滤波，既有真实GPU TAA像素/透明/背景测试继续通过。
- FSR2在比例0.5/1.0运行，输出尺寸、历史目标数和无运动矢量契约保持；TAA/FSR2切换、PNG旁路与相机恢复不回归。
- WebGL2能力旁路和异常恢复维持原行为。

## 性能与风险

输出pass增加邻域采样，只在FSR2模式执行，不新增target/显存；输出全分辨率采样可能增加GPU成本。边缘滤波有软化细线、纹理或alpha边界的风险，应以高对比阈值和限幅控制。没有物体运动矢量时，FXAA只能缓和空间锯齿，不能等同TAA完整时间稳定性；SwiftShader仅用于正确性与相对趋势，最终需手机/WebView实机验收。

预计实施2–4小时，另计设备性能验收。

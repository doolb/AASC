# MMD AR阴影像素网格对齐与基准半幅减半

## 需求与授权状态

用户要求网格对齐，并纠正“默认范围还是1倍，只是值默认缩小0.5”。方案解释为面板默认cameraScale继续1，自动拟合基准半幅乘0.5；保存值保持，以新基准计算。按AGENTS.md须先确认涉及文件与具体实现；用户已回复“是”确认含移动跟随的合并方案，先更新伪代码，再实施代码及验证。

## Design与Spec

沿用fitShadowCamera角色自动半幅，引入固定基准0.5，再乘cameraScale。绘制阴影前按每盏光实际贴图宽高，在相机平面将固定世界原点投影对齐整像素，通过偏移正交边界补偿，宽高与光向保持；方向/范围/尺寸变化重新计算像素步长，每次对齐先还原同宽高的基准中心，重复帧及连续小位移不积累偏移。已有默认1、保存/复位/非法值归一保持。详见design/spec同名2026-10-02章节。

## 追加角色移动跟随

用户要求移动角色时重新定位相机，按阴影上下文理解为阴影相机跟随。createArFootAnchor.translateBy/setPose/reset改变角色位置和比例，当前未同步fitShadowCamera。计划仅在测试runtime绘制前观察世界位置/比例：纯平移按差值同步两灯/target、缓存中心和承接面，保持光向/范围/NF；根节点更换或缩放重新拟合，再做像素对齐。拖动中持续更新，静止不逐帧算包围范围；主视角保持原行为。如用户指主视角自动追踪，需要另行补充方案。

## 自测与兼容

默认/旧偏好/复位均cameraScale=1；实际半幅为原0.5，手动0.1/0.5/1/2按新基准变化。真实Three矩阵验证两灯四档分辨率下参考原点整像素，小幅平移/反复拟合/尺寸变化不累计偏移；覆盖宽高、near/far/光向保持。真实PMX验证默认、预览覆盖/裁切、投影对齐、保存复位及资源回收，诊断比较宽高而非假设左右严格对称。新增真实PMX拖动中/停止、定位setPose、缩放、复位/换模型回归，检查灯位与目标跟随、范围/光向保持及最终网格对齐；纯平移不求新包围范围。手机动作/旋转/换模型效果另列现场验收。

## 性能与风险

向量复用，逐帧少量矩阵计算；不额外分配GPU目标或逐帧求模型包围范围。默认范围减半可能裁切角色/摆动布料，需要ShadowMap观察；像素对齐稳定固定光向/范围下的投影平移，不保证真实运动或光向/覆盖范围变化的阴影静止。预计实现/定向测试/网页构建20–30分钟，手机验收另计；不打包APK，独立测试页无新增Offline产物影响。

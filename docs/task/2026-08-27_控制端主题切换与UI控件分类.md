# 任务：控制端主题切换与 UI 控件分类

## 任务描述

控制端增加深色/浅色主题切换，并按当前实际使用的交互类型建立统一 UI 语义分类，覆盖静态页面和 JS 动态生成控件。

## Design 需求

- 主题默认保持当前深色外观。
- 设置面板提供主题选择并保存到浏览器本地。
- 通过 CSS 变量统一主题颜色，通过 `data-ui-type` 统一控件语义。
- 不修改 WebSocket、服务器配置和现有业务事件。

## Spec 设计

- `UiTheme.init/apply/readTheme/classify` 负责主题生命周期和控件标记。
- `MutationObserver` 处理动态弹窗、任务、媒体库和 Toast。
- 非法主题或本地存储异常回退深色且不阻断页面。

- 控制端页面：`src/apps/web-mediacenter/ui/public/upload.html`

## 兼容性测试

Chrome、Firefox、Safari、Edge 桌面端；窄屏控制端；动态弹窗和浮动控制条。

## 性能测试

主题切换只更新根元素属性，不重绘业务数据；MutationObserver 仅处理新增节点，不轮询。

## 风险评估

- 现有内联颜色较多，首期使用主题覆盖规则并逐步收敛，避免改变业务结构。
- 动态 HTML 由多个模块生成，需确保分类标记失败时不影响原有控件事件。

## 缺陷修复记录：浅色主题白底白字

- 发现：浅色主题将弹窗容器变为白色后，任务确认标题、媒体库/聊天弹窗标题、任务名称和部分动态内联文字仍使用 `#fff`，出现白底白字。
- 根因：旧组件的子元素选择器和动态 HTML 内联样式未被首版主题变量覆盖。
- 修复：在 `theme.css` 增加浅色主题兼容规则，覆盖旧文字和下拉选项；任务确认框同步使用浅色表面；按钮不纳入内联文字覆盖。
- 回归：新增测试断言弹窗遗留白字和动态内联白字均有浅色覆盖。

## 缺陷修复自测

1. 浅色主题下打开任务确认、媒体库、聊天和自测弹窗，标题与正文可读。
2. 浅色主题下查看任务列表、任务表单和下拉选项，文字与背景有对比度。
3. 浅色主题下查看提醒列表和动态任务字段，内联白字不再显示为白底白字。
4. 浅色主题下有色按钮仍保持白色文字。
5. `node --test tests/ui-theme.test.js`、脚本语法检查和 `git diff --check` 通过。

## 配色优化：浅色主题卡片与弹窗背景

- 需求：浅色主题的卡片和弹窗背景过白，统一改为浅蓝色。
- 设计：新增 `--card-background` 变量，浅色主题下将 `--card-background` 与 `--bg-surface-strong` 都设置为 `#eaf4ff`。
- 影响范围：卡片、内容分组、设备项、显示端项、任务表单分组、媒体库条目、聊天容器及各类弹窗。
- 验收：卡片和弹窗均呈浅蓝色，文字与按钮对比度不回归。

## 对比度修复：设备名、聊天消息和日志

- 发现：浅色主题下显示设备名、聊天消息和日志区域仍使用深色样式中的白字或深色底，文字与背景区分不足。
- 修复：新增 `--content-background`，适配设备列表、聊天消息列表、聊天历史和日志内容区；覆盖设备名、助手消息、普通日志消息及辅助信息的主题文字色。
- 兼容：用户消息渐变白字、日志错误/警告颜色、按钮文字和其他状态色保持原有语义。
- 自测：新增设备名、聊天消息和日志主题选择器回归，控制端相关测试通过。

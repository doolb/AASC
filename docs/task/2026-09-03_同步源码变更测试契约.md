# 同步源码变更测试契约

## 任务描述

针对 443 项自测中集中在 Android ASR、音频焦点、模型分发、Pi/Codex 会话、修复模式、搜索频道和 TTS 路由的 8 项失败，检查失败原因并同步已经发生源码变更的测试契约。

本次按用户决定暂不处理 DeX 多屏输入：不修改 `tests/display-native-bridge.test.js`，不改变现有生产触摸/滚轮实现。

## Design 需求

- Android ASR 测试应匹配当前 `AsrHttpServer` 的查询参数路由解析和网页请求格式。
- 正式显示 APK 的 GTCRN 测试应验证服务器分发模型，不再要求 Gradle 内置资源。
- 音频焦点、TTS 恢复、Pi/Codex 会话删除、修复模式配置、搜索频道和语音帮助测试应匹配当前实现接口。
- DeX 原生触摸/滚轮契约保持待处理状态，避免在本任务中扩大范围。

## Spec 设计（伪代码）

```
更新源码契约测试():
    对 7 个已发生源码变更的模块:
        读取当前源码
        匹配稳定的路由、公共行为或参数契约
        不匹配已删除的内部函数名和旧局部变量名

    对 DeX 输入模块:
        保留现有原生触摸/滚轮测试
        记录为暂不处理的已知失败
```

## 受影响的功能模块和代码

- `tests/android-asr-apk.test.js`：ASR 服务端根路由和带查询参数的识别请求。
- `tests/android-asr-options-integration.test.js`：GTCRN 远程模型清单、下载路由和快速多段能力。
- `tests/display-media-focus.test.js`：网页 TTS 恢复函数及音量/原生焦点边界。
- `tests/pi-agent-conversation.test.js`：Pi/Codex runtime manager 会话重置。
- `tests/repair-mode-server-contract.test.js`：修复模式配置类型和角色契约。
- `tests/search-channel.test.js`：Pi/Codex Agent 搜索频道的临时会话标记。
- `tests/tts-display-routing.test.js`：语音指令帮助文本的命令集和 topic 参数。
- `tests/display-native-bridge.test.js`：DeX 输入测试，本次明确不修改。

未修改生产源码。

## 自测用例

- 7 个更新后的测试文件分别执行 Node test runner。
- 7 个更新后的测试文件共 30 个测试用例通过。
- 全量 `npm test` 共 443 项：442 项通过、1 项失败；唯一失败为按要求暂缓的 DeX 输入契约。

## 兼容性测试

- 保持 Node.js `node:test` 运行方式不变。
- 保持正式 APK 的服务器模型分发兼容性断言。
- 不改变 DeX、Android 原生桥和生产服务器行为。

## 性能测试

本任务只调整源码契约测试，不增加运行时逻辑和模型推理路径；全量测试耗时约 112.7 秒，性能基线不变。

## 风险评估

- 风险：源码内部名称再次变化时，契约测试可能需要同步；通过匹配路由和公共行为降低脆弱性。
- 风险：修复模式密码属于部署配置，测试只校验字符串类型和角色，不固定具体密码值。
- 已知限制：DeX 原生触摸/滚轮旧契约仍可能失败，本次按用户要求延后处理。

## 预计工时

约 1 小时，包含失败定位、7 个测试更新、文档同步和全量回归。

# PMX 内置 Ammo 物理解算

## 任务描述

为浏览器显示端的 PMX 模型启用 Three.js r160 MMD 的 Ammo/Bullet 物理解算。用户要求将运行时提前下载并作为同源静态资源内置；刚体 PMX 要有布料、骨骼摆动等模型定义的物理效果，初始化失败时仍须保留原有动画显示。

## Design 需求

- Ammo JavaScript 与 WASM 必须固定为当前 Three.js r160 对应文件，放在既有 `public/js/vendor/three/libs/`，禁止 CDN 与任意外部运行时地址。
- 只检查 PMX 的 `geometry.userData.MMD.rigidBodies`；无刚体的 PMX 不应下载或初始化 Ammo。
- 初始化必须按页面单例去重、成功后复用、失败后可在下次模型加载重试。
- PMX 物理网格保持 `scale = (1, 1, 1)`，只平移至地面和水平中心；显示大小由原始模型边界驱动相机、灯光和阴影范围适配，避免 MMDPhysics 的非 1 缩放回写错位。
- PMX 先创建中心旋转枢轴，并以不可见状态加入最终场景后完成 helper 准备；带刚体时使用 `physics: true` 与 `warmup: 0`，首个物理步进仅在显示后的下一帧发生。
- 无 VMD 的带刚体 PMX 仍可建立物理 helper；VMD 的循环/单次、IK 与 grant 行为不得改变。
- Ammo 或物理 helper 失败时必须回退 `physics: false`，显示可观察状态，不影响模型、VMD、聊天、灯光和 Canvas 占位。
- PMX、VMD 和纹理继续不进入 Offline APK 或 Git；本任务不发布和不构建 APK/更新包。

## Spec 设计

```text
ensureAmmoPhysics -> 注入同源 ammo.wasm.js -> 工厂以 locateFile 指向同源 .wasm -> 校验模块 -> 缓存
hasMmdPhysics(mesh) -> rigidBodies 非空才返回真
createPmxMotionHelper -> 刚体模型 await Ammo 后 physics=true；失败则 physics=false 并返回 physicsError
preparePmxHelper -> 可选加载 VMD，再创建 helper
PMX load -> 原始单位定位模型 -> 创建中心枢轴 -> prepare helper(warmup=0) -> 提交 staged 资源 -> 按原始 bounds 适配相机/灯光/阴影
下一渲染帧 -> MMDAnimationHelper.update(delta) 同时推进动作、IK/grant 和可用的物理
```

## 自测用例

1. 校验两个内置 Ammo 文件的 SHA-256 与 r160 固定值一致。
2. 同页并发 PMX 加载只注入一次同源脚本、只初始化一次 WASM，并复用已初始化模块。
3. 初始化失败后，同一页面后续 PMX 加载可以重新初始化。
4. `rigidBodies` 缺失或为空时不请求 Ammo，仍可播放 VMD。
5. 有刚体时 helper 以 `physics: true` 建立，循环/单次动作语义保持。
6. Ammo 失败时 helper 以 `physics: false` 建立且保留 VMD；无 VMD 的刚体模型也可建立物理 helper。
7. 刚体 PMX helper 的 `warmup` 为 0，加载阶段不推进物理，首次 `helper.update` 留给下一渲染帧。
8. PMX 物理网格会恢复单位缩放并贴地居中；原始模型边界驱动相机 near/far 与距离计算。

## 兼容性测试

- Three.js 依赖保持 `0.160.0`；只使用其 `MMDAnimationHelper` 支持的 Ammo 运行时契约。
- PMX 有/无刚体、有/无 VMD 均覆盖；VRM runtime、Raycaster 点击互动、中心旋转枢轴和灯光不改动。
- 浏览器不支持或加载 WASM 失败时降级为原有骨骼动画，不阻断模型加载。

## 性能测试

- 无刚体 PMX 不产生 Ammo 网络/内存开销。
- 有刚体 PMX 只在第一次需要时加载一次同源脚本与 WASM；后续模型切换复用模块。
- 物理更新复用现有单一 `requestAnimationFrame` 中的 `MMDAnimationHelper.update(delta)`，不额外创建渲染循环。

## 风险评估

- 中等风险：Ammo/WASM 初始化失败、PMX 资源的物理数据异常或移动端内存不足可能导致物理解算不可用；已设计可重试和无物理回退。
- 上游二进制含末尾空白，不能自动格式化，否则会破坏固定 SHA-256 与原始许可内容。
- 全量测试需要 Linux 工具、符号链接权限和 Chromium；当前 Windows 主机不具备这些环境依赖，因此以针对本功能的行为测试为准。

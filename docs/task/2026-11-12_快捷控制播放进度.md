# 快捷控制播放进度

- 需求：播放控制下方显示音视频当前时间及总时长，拖动跳转当前显示端，兼容单媒体和批量播放。
- 设计：见 `docs/design/display-quick-control.md`；有限时长启用滑块，其他情况禁用。
- 伪代码：见 `docs/spec/display-quick-control.md`；复用现有 seek 百分比控制，拖动时避免刷新覆盖预览。
- 影响：显示页面和快捷控制脚本、样式、服务端操作校验、自测与文档。
- 自测：正常播放、拖动、切换媒体、无时长、断线及非法百分比；浏览器窄屏和现有面板回归。
- 兼容性：适用于音视频、单媒体与批量播放；时长未知时禁用。
- 性能：复用面板打开期间的既有刷新，不额外轮询服务端。
- 风险：实际媒体跳转能力取决于来源是否支持定位；Android 和真实媒体待验收。
- 预计工时：半天。

- 验证结果：快捷面板浏览器专项及播放进度、循环、媒体库回归通过；真实 Android 和媒体跳转待设备验收。

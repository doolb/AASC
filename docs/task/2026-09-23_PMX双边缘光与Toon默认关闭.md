# PMX 双边缘光与 Toon 默认关闭

- 日期：2026-09-23
- 状态：代码与自动化测试完成，待真实米娅及 Android WebView 现场视觉验收
- 预计工时：约 4 小时，现场画质与帧率验收另计

## 任务描述与 design 需求

保留现有补光，新增两组只对 PMX 角色轮廓生效的边缘光。每组有独立开关、颜色、强度和经纬度方向，默认关闭；不创建会照亮正面的方向光、不投射阴影、不改变 VRM。PMX Toon 明暗默认改为关闭，旧浏览器明确保存的开启状态仍保留。

## Spec 设计与受影响模块

先更新 `docs/spec/mmd-pmx-vmd-local.md`。`display.html` 与 `display-mmd-lighting.js` 增加两组控制和本地保存；`display-mmd.js` 规范化旧设置与新数组；`display-pmx-lighting-mode.mjs` 给 PMX 材质实例注入两组边缘光 uniform，在 shader 中以轮廓因子和方向点积筛选像素；`display-pmx-runtime.js` 在模型加载及灯光更新时同步值。亮度预设保留自定义边缘光，恢复默认关闭两组和 Toon。不修改 vendored shader、远端模型或 WebSocket 协议。

## 自测与兼容性

- 旧 localStorage 缺少新字段时两组边缘光关闭，缺少 Toon 字段时使用普通直射光；明确保存的 Toon true 不覆盖。
- 两组颜色、强度与方向分别生效，非法值规范化，单独开关互不影响；局部灯光更新保留已设置边缘光。
- 浏览器像素测试验证正面中心不变、左右对应轮廓显色、关闭后回到无边缘光画面；主光、补光、AO 和透明画布回归。
- 真实米娅及 Android WebView 检查发丝、裙摆边缘、双色叠加、动作中方向变化和帧率；VRM 应维持原样。

## 性能与风险

每个 PMX 材质仅首次加载时注入 shader，之后只改 uniform，不重建模型或动作。两组边缘光会增加少量片元计算，但不增加阴影贴图；复杂透明材质、轮廓宽度与不同设备色调映射效果需现场确认。

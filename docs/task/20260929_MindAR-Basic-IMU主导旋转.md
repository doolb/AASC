# MindAR Basic IMU 主导旋转

## 需求与授权

用户确认先优化现有 mind-basic，采用 IMU 主导旋转、视觉纠偏；保持位置/距离的视觉约束。2026-09-29 已确认文件与实现方案。

## Design / Spec

对应 `docs/design/mindar-basic-web.md` 与 `docs/spec/mindar-basic-web.md`。高频陀螺仪预测完整相对旋转变换，每渲染帧应用；视觉以时间常数纠偏并过滤突跳。矩阵分解、单调时间、传感器新鲜度及实物图宽换算是必要约束。位移积分默认关闭。

## 涉及文件

- `3rd/mind-basic/mind-basic-imu.js`：姿态积分、位置旋转、时间纠偏、突跳确认、静止校准、位移换算。
- `3rd/mind-basic/mind-basic.js`：矩阵读取、渲染帧驱动、传感器生命周期、参数及降级。
- `3rd/mind-basic/index.html`、`README.md`：调节控件和使用限制。
- `tests/mind-basic-imu.test.js`、`tests/mind-basic-custom-target-browser.test.js`：算法和模拟浏览器行为；清理旧静态测试对已删除参数的断言。

## 验证与兼容性

算法验证相机转动时位置/朝向一致、15/60Hz 纠偏等效、快速转动抑制旧视觉回拉、孤立跳变与一致观测恢复、短失锁平滑重获、过期重锚、米到场景单位换算、位移限幅及校准拒绝运动。

浏览器使用 Chromium、模拟传感器和 MindAR/A-Frame 事件接口，覆盖矩阵只更新而属性不变的锚点、无视觉帧时持续渲染、传感器过期回退、失锁保持超时、重获及方向切换、关闭 IMU 后持续视觉跟踪；继续验证原有拍照/裁剪/保存/模拟编译流程。模拟用例不代表真实摄像头算法精度或 Android 传感器轴向已验收。

## 性能与风险

每传感器样本和渲染帧均为固定规模向量/四元数操作，不增加视觉推理次数。未做真实设备帧率或精度基准。相机与 IMU 未硬件同步；低速匀速运动可能通过静止校准阈值；位移双积分漂移只能限制，不能消除。不同目标的实体宽度需用户填对。

## 预计工时

约 2–4 小时，涵盖算法、控件、回归与文档；真机验收另计。

本地实现完成，定向测试结果见 `docs/self-test.md`。未发布外网；手机横竖屏轴向、静止和快速运动观感、失锁恢复待现场验收。

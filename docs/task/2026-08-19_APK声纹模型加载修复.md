# APK 声纹模型加载修复

## 任务描述

启用声纹配置后，APK 加载私有目录中的声纹模型失败并退出；修复后使用已注册声纹和单个 WAV 完成端到端测试。

## Design 需求

- `SpeakerEmbeddingExtractor` 与可选 `OfflineSpeakerDiarization` 加载外部绝对路径模型时传入 `AssetManager=null`。
- 保持现有声纹库同步、阈值匹配和服务器中转协议不变。

## Spec 设计

```text
VoiceprintEngine.load:
  embeddingModel、segmentationModel 使用 APK 私有目录绝对路径
  SpeakerEmbeddingExtractor(null, embeddingConfig)
  multiSpeaker=true 时 OfflineSpeakerDiarization(null, diarizationConfig)
  加载成功返回 true，异常释放引擎并返回 false
```

## 受影响模块和代码

- `src/apps/android-display/app/src/main/java/com/aasc/display/VoiceprintEngine.kt`
- `tests/android-voiceprint-native-load.test.js`
- `docs/design/voiceprint.md`
- `docs/spec/voiceprint.md`

## 自测用例

- 旧实现回归测试失败，修复后源码回归测试通过。
- Android JVM 单测和 APK 构建通过。
- 注册 `zh.wav` 为“测试声纹”，启用声纹配置后使用同一个 `zh.wav` 调用 `/api/asr/recognize`，检查返回文本和 speaker。

## 风险评估

- 仅改变 AAR 的资源加载入口，不改变模型文件、hash、声纹库和协议。
- 多人分割路径同时使用绝对路径，因此必须与 embedding 提取器一起修复。

# 西施人物拆分与角色URL

## 需求和方案
用户确认西施暂不包含龙/龙须，人物头上的角保留。URL支持character=xishi与character=miya；URL优先于本地记忆，角色面板成功切换时同步地址且保留其他参数和hash。

## 实现
- export-xishi.py仅导出头发/角/脸/裙子/身体五个网格，源blend保持原样。
- web-characters-build.js生成启动选择逻辑：有效URL短名 > 有效本地resourceId > 默认米娅；使用固定映射，不接受URL作为任意模型地址。
- web-character-panel.mjs在服务器角色成功切换后使用history.replaceState更新character；失败不更新，已有参数在恢复默认角色时同步。
- 重新导出GLB并构建web-dist，模型内容hash变化，保留既有旧产物。

# 棋盘无效点击飘字与Qwen默认普通

## 需求与授权

玩家询问连续无效点击是否会在下一轮补执行，并要求不能落子时显示原因飘字；Qwen默认档改普通。已告知文件与方案，用户回复“是”授权实施。

## 需求等级与设计

主L5：点击、拒绝、反馈和恢复流程；次L4：默认请求名替换。依据：点击需即时反馈、无效点击不补执行、发行默认普通三项明确要求。建议下放L4，复用现有门控和AASC消息，不新增协议或持久化状态；风险低。企业评审评分：清晰度24/25、证据19/20、完备18/20、风险18/20、落地14/15，总93/100；主L5强证据6、L4中证据2，一致性0.9，置信度0.675；结论可开发。

已有声明：canPlay、pending、gameRecover、旋转游戏层、Qwen开发映射及发行配置。新增定义：单节点飘字和1500毫秒计时器、阻止原因表。流程：按下→判断→仅提示或允许click→同步加锁发送→权威回包→恢复；无效输入不排队。

design：`docs/design/game-gomoku.md`、`docs/design/chat-system.md`；spec：对应两模块伪代码先更新再实现。

## 验证、兼容、性能及风险

使用`npm run test:game-chat`，模型档位通过现有定向测试验证；JSON校验Qwen种子普通别名。无真实账号请求，不重启生产服务。兼容现有disabled按钮和click二次门控，既有请求编号/版本校验保持。飘字固定单节点和单计时器，连点不累积DOM或网络请求；四向旋转跟随原层。Android不同WebView的pointerdown事件和触屏感受待设备验收，默认种子只影响后续恢复/首装，不覆盖已有用户配置。预计工时约1小时。

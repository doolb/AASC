> 执行方式：使用 writing-plans / executing-plans / test-driven-development / verification-before-completion 技能，在当前master工作区内执行；用户已确认方案。

**Goal:** 全局阻尼叠加具有差异化默认值的部位系数，并经真实PMX验证。

**Architecture:** 共享部位预设与归一化；现有质量/有效惯量负责物理量换算，部位系数贯通目标、自然姿态、释放与原生耗散。设置仅当前会话。

**Tech Stack:** JavaScript模块、Three.js、Ammo、Node test、Puppeteer。

**Spec:** `docs/spec/mmd-human-interface.md`；Design：`docs/design/mmd-human-interface.md`。

## 全局约束与评审

- 需求L6模块契约+L5阻尼规则，下放L4伪代码；已确认输入为部位系数，范围0.2～2.5，全局范围不变。

- 不新增依赖、HTTP/远端协议、持久化或人体实测常数声明；不构建APK或发布二进制。
- 预估2～3小时；主要风险：多层阻尼重复耗散、低系数震荡、高系数牵引迟缓、旧阈值回归。
- 不明确项：其他模型及手机观感由现场验收；本地真实模型数值结果不能替代人体生物力学测量。

## Review Focus

- 只改一个部位时其他值必须保留，返回状态字典不能修改内部状态。
- 非法值/未知键不能传入Ammo；小于1的系数必须在自然姿态下限之后生效。
- On/Hold/Comply以及Off释放均需生效，保留动量衰减与限位约束。
- 窄屏滑条操作不能被定时同步覆盖，恢复默认须覆盖完整字典。
- 构建新增模块和内容指纹不可遗漏，PBD与关闭恢复回归。

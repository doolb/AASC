# 网页主题规则与服务器列表适配

## 任务描述

修复控制端服务器列表中 `main-server` 等服务器文字在亮色主题下对比度不足的问题，并把网页主题颜色约束整理为可复用的统一规则。

## Design 需求

- 网页普通文字、辅助文字、卡片、输入框、边框和阴影必须使用主题变量。
- 在线/离线、成功/危险、选中和按钮前景色可以保留语义颜色例外。
- 服务器节点列表必须遵守同一套规则，不能只增加亮色主题特例。

## Spec 设计

- `server-card` 使用 `card-background` 和 `border-color`。
- 服务器名称和字段值使用 `text-primary`。
- `main-server`、字段标签、心跳时间和辅助信息使用 `text-secondary` 或 `text-muted`。
- 在线/离线状态使用 `success-color`/`danger-color`。
- 服务器地址输入框使用 `input-background`、`text-primary` 和 `border-color`。
- 禁止普通服务器文字使用固定白色或深色主题专用颜色。

## 受影响模块和代码

- `src/apps/web-mediacenter/ui/public/css/upload.css`
- `tests/ui-theme.test.js`
- `docs/design/control-ui-theme.md`
- `docs/spec/ui-theme.md`

## 自测用例

1. 检查服务器列表样式消费 `card-background`、`border-color`、`text-primary`、`text-secondary`、`input-background`。
2. 检查在线/离线状态消费成功色和危险色。
3. 检查服务器名称、`main-server` 和字段值不再固定为白色。
4. 保持现有主题管理和 15 种主题配置测试通过。

## 兼容性测试

- 深色主题保持原有深色观感。
- 浅色主题及其他非深色主题中的服务器卡片文字保持可读。
- 不改变服务器列表数据、接口、事件和页面路由。

## 性能测试

- 只增加 CSS 变量引用和静态样式契约，不增加运行时请求或渲染循环。

## 风险评估

- 风险低：变更只涉及控制端样式和主题文档。
- 需注意：按钮上的白色前景色属于语义例外，不能被普通文字规则覆盖。

## 预计工时

- 约 30 分钟，包括测试、文档同步和 `git diff --check`。

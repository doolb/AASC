# 显示端快捷控制

- 需求与设计：媒体库入口上方增加快捷控制，仅作用于当前显示端，包含控制端已有的播放、文本、音量、填充、快速播放与批量播放操作。
- 实现：参见 `docs/design/display-quick-control.md` 和 `docs/spec/display-quick-control.md`；显示页面、样式、脚本、WebSocket 服务端接线与自测。
- 自测：核验操作映射、身份限定、断线提示、面板显示和返回关闭；回归媒体库与现有播放控制。
- 兼容性：移动端窄屏可滚动，壁纸页面遵守原有交互层显示规则。
- 性能：仅面板打开时刷新状态；不引入高频服务端轮询。
- 风险：需在真实 Android 显示设备复核触控与媒体播放；语音搜索结果依赖已有媒体索引。
- 预计工时：半天。

- 验证结果：快捷面板、目标白名单、名称搜索媒体消息、媒体库及游戏浏览器回归通过；真实设备待验收。按名称播放修复为显示端可识别的 URL 媒体类型。

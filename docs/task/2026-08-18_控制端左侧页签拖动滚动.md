# 控制端左侧页签拖动滚动

## 任务状态：✅ 已完成

## 任务描述

控制端左侧页签入口较多时，除滚轮和触控板外，增加类似移动端的按住拖动滚动方式，方便鼠标用户快速浏览入口。

## Design 需求

参考：design/control.md（左侧导航高度适配）。

- 鼠标左键按住导航区域上下移动时，导航内容跟随垂直滚动。
- 使用 Pointer Events，兼容鼠标、触摸和触控笔。
- 移动超过 6px 才进入拖动状态，避免普通点击被误判为拖动。
- 实际拖动结束后抑制由释放动作产生的页签误点击。
- 未发生有效拖动时，页签继续使用原有点击切换逻辑。

## Spec 设计

参考：spec/sidebar.md（导航拖动滚动）。

    初始化侧边栏:
        pointerdown 记录指针位置和 scrollTop，不立即捕获指针
        pointermove 超过阈值后捕获指针并更新 scrollTop
        pointerup/pointercancel 释放指针捕获并清理状态
        拖动结束后的短时间内阻止误点击

## 自测用例

1. 鼠标按住左侧导航向上/向下拖动，导航内容随之滚动。
2. 拖动超过阈值后释放，不应误打开释放位置的页签。
3. 轻微点击且移动未超过阈值，应正常打开对应页签。
4. 普通点击不应在 pointerdown 阶段被 setPointerCapture 截获。
5. node --test tests/sidebar-layout.test.js 通过。
6. node --check src/apps/web-mediacenter/ui/public/js/main.js 通过。

## 兼容性测试

- 滚轮、触控板滚动行为保持不变。
- Pointer Events 支持鼠标、触摸和触控笔。
- 入口少于可视高度时，拖动监听不改变页面布局。
- 与滚动条隐藏样式兼容，导航仍可滚动。

## 性能测试

- 仅在导航区域监听 Pointer Events，不增加全局事件监听。
- 拖动期间只更新单个导航元素的 scrollTop，不重建页签 DOM。

## 风险评估

- 低：拖动状态仅存在于侧栏导航内部，6px 阈值降低普通点击误触风险。
- 触摸设备上的默认滚动手势由 touch-action 配合自定义 Pointer Events 接管。

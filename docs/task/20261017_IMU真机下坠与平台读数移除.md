# IMU 真机下坠与平台读数移除

日期：2026-10-17。状态：代码、文档、26项自动回归和新版APK构建完成；真机安装与现场轨迹复核待设备连接。

## 任务描述与需求

用户反馈真机APK观察轨迹持续向下漂移，要求移除“平台线性加速度”读数。电脑端继续显示含重力原始加速度及估计器计算的世界线性加速度。APK固定房间和服务器原始六轴诊断保留。

## 设计依据

见 `docs/design/imu-six-axis-test.md` 的“APK 静置下坠修正与平台读数移除”。真机样本静置段含重力加速度模长约9.685 m/s²，与固定9.807 m/s²扣除值相差约0.122 m/s²，足以在积分后产生明显下坠。平台线性加速度原来未参与估计，单独删除读数不能修复。

## Spec 与实施

先更新 `docs/spec/imu-six-axis-test.md` 伪代码，再修改 `3rd/imu-six-axis-test/imu-engine.mjs`：只在电脑APK观察模式依据六轴连续窗口判断静稳，学习当前有效重力模长、纠正倾斜、清零速度并冻结静止位置；移动或断流撤销窗口。`app.mjs`按输入来源启用该模式；`imu-phone.mjs`、桌面及APK页面移除平台读数；Android `MainActivity.kt`取消平台传感器注册与回传；`server.mjs`忽略旧客户端附带字段。保持手机浏览器默认手动清零。

## 受影响模块与自测用例

- 估计器：静置重力模长偏小、移动后再静置、普通手机默认行为、线性种类输入、断流窗口。
- WebSocket服务：旧APK含额外字段仍可接入，但广播/缓存不包含该字段。
- Android原生：APK可构建；真机检查采样、房间、前后台和静置/移动轨迹。
- 兼容性：固定房间及地址设置不变；旧APK仍可发六轴样本。新版APK需覆盖安装，网页需刷新以启用新估计器。
- 性能：静稳窗口最多80样本，每次聚合扫描有固定上限，采样/发送速率不变。

## 风险、预计工时与结果

六轴不能区分真正静止与持续匀速，自动清零可能误判；运动中的偏置和已积累位置误差仍会保留。预计实施及自动回归约2小时；真机验证依赖设备连接。完成结果以 `changelog.md` 中本任务记录为准。

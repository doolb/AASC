# Pixiv 加入反馈、加载与媒体来源选中状态

- 需求：加入链接时展示处理与确认结果；Pixiv 避免重复请求；媒体来源选中项清晰可见。
- 设计：服务端保存成功后按请求标识确认，控制端显示目标文件夹；来源样式和无障碍状态随切换更新。
- 实现：按 `docs/spec/media-library.md` 修改媒体库前端、WebSocket 处理与分类服务、Pixiv provider 和测试。
- 自测：成功、拒绝、断开、超时、控制端切换及重复加入；代理变化、并发合并、缓存过期与停止；窄屏来源选中。
- 兼容性：旧客户端可忽略确认消息；原有分类存储及广播格式保持不变。国外任务不进入 release。
- 性能：缓存 60 秒并限制数量，避免重复详情请求；网络和上游限速仍影响首次加载。
- 风险：超时不代表服务端必然未保存，须显示待确认；跨控制端广播不当作当前请求确认。
- 预计工时：3 小时。真实 Pixiv 网络与设备播放仍待验收。
- 结果：Pixiv、媒体来源及浏览器回归 15/15，另含确认成功与失败的分类回归 4/4；日本代理真实只读验证首个作品解析约 2.5 秒，重复解析缓存命中、无新增请求；真实部署及设备验收待完成。

# 接入 Qwen3.5 视觉推理 MNN 模型

## 执行状态

服务端清单、ModelScope 代理和文本推理前置链路已完成；现场验证发现 APK 的开发证书指纹已过期且服务端丢失嵌套状态，已纳入本任务修复；真实 native 加载和图片输入仍待现场验收。

## 任务描述

接入用户指定的 `Qwen3.5-0.8B-Claude-4.6-Opus-Reasoning-Distilled-MNN`，使用 ModelScope 固定仓库和 revision 下载模型；保留 APK 单模型、等待推理完成、逐文件校验和原子切换约束。

## design 需求

- ModelScope 仓库固定为 `MNN/Qwen3.5-0.8B-Claude-4.6-Opus-Reasoning-Distilled-MNN`。
- revision 固定为 `c1bc31b15286afa708f37f690099d10f21d1cc74`。
- APK 下载 9 个运行文件，包含 `visual.mnn` 和 `visual.mnn.weight`；不下载说明文件。
- 当前阶段先验证文本推理；图片理解需要后续扩展 OpenAI content 到 NativeBridge 的图片传输协议。

## spec 设计

```text
addModelDefinition():
  modelId = "qwen3.5-0.8b-claude-opus-distilled-mnn"
  source = ModelScope("MNN/Qwen3.5-0.8B-Claude-4.6-Opus-Reasoning-Distilled-MNN", pinnedRevision)
  files = runtime files with size and sha256 from ModelScope API
  multimodal = true

selectModel(modelId):
  download only manifest files
  verify size and sha256
  load config.json through MNN-LLM
  retain old model if load fails
  report text-only capability until image bridge exists

handleLlmStatus(message):
  status = message.status if present else message
  preserve state=downloading/loading/ready/error for control UI

openDevelopmentHttps():
  validate the current repository certificate fingerprint
  reject an obsolete or unrelated certificate

streamModelScopeFile(url):
  add User-Agent and Accept headers to the HTTPS request
  follow the signed CDN redirect and validate status/size before streaming

downloadModelFile(url, expectedHash):
  retry only the failed file up to three times after transport EOF
  preserve completed files in staging and install only after all hashes pass
```

## 自测用例

- 模型清单包含固定 ModelScope source 和 9 个完整文件。
- 代理可下载 `config.json`，返回值和清单大小一致。
- 选择该模型时只下载该模型文件，不影响其他模型缓存。
- 文本推理加载失败时保留旧模型并报告结构化错误。
- 图片消息暂不进入文本推理路径，不伪装成已支持视觉推理。
- 选中模型后控制端能依次看到下载中、加载中、就绪或明确错误，而不是永久停留在已排队。
- ModelScope 302 到 CDN 后，代理返回最终 200 且大小与 manifest 一致。
- 视觉权重出现网络 EOF 时只重试该文件，不删除已完成的 staging 文件。

## 兼容性、性能和风险

- 旧 APK 忽略 `multimodal` 字段仍可按普通 MNN-LLM 模型下载；若 native 不识别 `qwen3_5`，模型切换必须失败并恢复旧模型。
- 约 518.93 MiB 的运行文件通过服务端流式代理，不在服务端内存中聚合。
- 视觉文件增加下载空间和加载内存；真实设备必须验证 192.168.1.6 的磁盘、内存和首 token 时间。

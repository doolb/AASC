# 资源目录整理任务

## 任务描述

- 目标：将资源目录统一到 `res/` 并移除旧路径依赖。
- 范围：代码路径装配调整、目录骨架创建、设计与实现文档补充。

## design 需求

- 定义 `res/models`、`res/uploads`、`res/temp`、`res/certs` 资源边界。
- 明确 `res/` 作为唯一运行路径。

## spec 设计

- 输出资源路径解析伪代码。
- 输出服务端路径装配伪代码。
- 输出 ASR 模型目录固定路径伪代码。

## 受影响模块与文件

- `server.js`
- `core/asr.js`
- `core/media-library.js`
- `res/README.md`
- `docs/design/resource-layout.md`
- `docs/spec/resource-layout.md`
- `docs/design.md`
- `docs/spec.md`
- `docs/task/2026-04-22_资源目录整理.md`
- `changelog.md`
- `docs/todo.md`

## 自测用例

1. 执行 `node --check server.js` 语法检查通过。
2. 执行 `node --check core/asr.js` 语法检查通过。
3. `res/certs` 放置证书后可正常启用 HTTPS。
4. `res/models/sensevoice` 放置模型后可正常初始化 ASR。

## 兼容性测试

1. 保持 `/uploads` 访问路径不变。
2. 保持已有上传和临时文件清理流程不变。

## 性能测试

1. 本次主要为路径解析与目录整理，运行时性能影响可忽略。

## 风险评估

- 风险：资源未迁移到 `res/` 会导致模型或证书加载失败。
- 缓解：迁移上传/临时/证书/模型到 `res/`，并在启动前校验目录完整性。

- 状态：code57已发布；最新code58布局修正与20项定向测试已完成，待构建发布，Android设备待验收。
- 需求：正式显示端灯光组移到界面右下角；设置面板从顶部显示并覆盖顶部文字；首次展开聊天应显示当前会话内容，无需再次关闭展开。
- design：[display-chat-mmd.md](../design/display-chat-mmd.md)。
- spec：[display-chat-mmd.md](../spec/display-chat-mmd.md)。

- 预计工时：实现及定向测试约1至2小时；服务发布全组件校验另计。
- 不明确事项：修改前真实模块浏览器复现历史默认群聊/首次展开未查询缺口；修改后9文件32项通过、零跳过，设备仍待现场验收。

# 显示端聊天 Markdown 列表缩进修复

## 任务描述

修复显示端聊天消息中 Markdown 有序列表序号、无序列表圆点超出气泡背景且正文没有缩进的问题。仅调整气泡正文列表样式，并把只读样式检查并入当前已授权的 LAN/WAN Offline 服务包批次。

## 需求等级与评审

- 主等级：L5，定义 Markdown 列表在聊天气泡中的缩进与背景边界。
- 次等级：L6，复用 `ChatMarkdown` 现有 `ul/ol/li` 输出和聊天气泡作用域。
- 结论：可开发；直接开发风险低；无协议或数据契约断点。
- 需求置信度：0.68（中）；复现原因已由全局 CSS reset 与缺失的聊天列表规则确认，实际设备视觉仍待验收。

## Design 需求

1. 显示端聊天气泡中的 Markdown `ul/ol` 正文向内缩进 24 CSS px。
2. 序号或圆点显示在实色气泡背景内，不超出气泡外缘。
3. 样式仅作用于 `.display-chat-message-body`，不改变 Markdown 渲染、安全转义、控制端聊天或媒体文本。
4. 更新只读自测，检查聊天气泡列表样式，不发送聊天消息。
5. 与本轮本机模型把手网页调整共用服务包，发布到 LAN/WAN；不重建 min APK。

## Spec 伪代码

见 `docs/spec/display-chat-mmd.md` 的“显示端聊天 Markdown 列表缩进”和 `docs/spec/self-test.md` 的显示端聊天列表检查。项目伪代码见 `.src/app/display-chat-markdown-list-spacing.md`。

```text
列表标记与文本留在气泡背景内
只读自测读取 display-chat.css，检查作用域与缩进值
```

## 自测用例

1. 有序列表 `1.` 和无序列表 `-` 的正文均向内缩进 24 CSS px。
2. 列表序号与圆点位于 `.display-chat-message` 实色背景范围内。
3. 列表多项及其换行内容与首行正文保持对齐。
4. 控制端聊天、媒体文本列表、Markdown 安全转义和非列表消息不变。
5. 自测只读获取 `/css/display-chat.css`，确认作用域选择器和 `padding-inline-start: 24px`。

## 兼容性与性能

- 复用浏览器支持的逻辑 padding 属性；不新增脚本运行路径、协议、存储或服务端逻辑。
- CSS 静态规则，不增加逐帧处理、定时器、网络请求或渲染开销。
- 只修改服务端网页资源，min APK 不重建；已安装 Offline 通过服务包更新获得样式。

## 风险评估与预计工时

- 低风险：极窄气泡宽度下 24px 缩进会减少列表正文可用宽度；继承现有控制端 24px 规范，长行仍由气泡 `overflow-wrap:anywhere` 换行。
- 预计工时：样式、自测与文档 30 分钟；服务包发布和设备观感验收另计。

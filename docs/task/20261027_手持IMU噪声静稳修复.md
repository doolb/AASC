# 手持IMU噪声静稳修复

状态：实现及42项自测完成，独立8769测试服务已更新，当前手机实际验收待重连。

目标：处理50Hz目标采集下手持静止、噪声较大时固定静稳门槛始终不通过而残留速度持续积分的问题。复用用户三秒静置校准学习噪声，不把任意显示死区当成静止依据。

设计：见imu-six-axis-test同日段落。原有50Hz采样/发送链路保持，用源时间积分；静稳窗口自适应已确认静置时记录的噪声均值和方差。没有学习依据时保持原固定规则。持续转动、大加速须退出；不按速度大小强制限速或回写位置。

伪代码：RestNoise记录校准后gyroMean/gyroDeviation/forceVariation/sampleCount/sampleRateHz；均值标准误差门槛与波动预算控制静稳，原0.7秒确认、重力对齐与零速修正复用。新诊断经现有消息/接口白名单，旧帧兼容。

影响：imu-engine.mjs、app.mjs、server.mjs，必要的index.html诊断提示；tests/imu-six-axis-engine/room/browser.test.js。无Android原生/生产包变更。

自测：50Hz有界高噪声静止学习后清残留速度；未学习不放宽；持续转动/大加速撤销；重复校准/线性来源/断流/重置语义；校准不改零偏；旧帧和非法诊断；真实浏览器/WS链路。npm run test:imu:six-axis-test；保存手机数据按相同输入回放。无运动真值时不能宣称绝对精度。

兼容：模拟器和浏览器手机静稳策略不变；显示死区不限上限仍保留。性能：窗口上限80、校准1200，25/50/100Hz有界运行。风险：校准包含真实移动可能误学，六轴不能区分恒速/静止；高噪声覆盖慢动作的边界须明确。预计2–4小时。

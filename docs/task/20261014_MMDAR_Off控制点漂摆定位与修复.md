# 2026-10-14：MMD-AR控制点Off漂摆定位与修复

## 任务与范围

用户反馈“VAM控制点自由时会乱飘”，已回复确认是某个控制点设为Off（放开），不是开启骨盆自由。用户确认修复方案并明确重力默认关闭；诊断与回归同时覆盖主动开启重力。期望释放单点后不持续乱摆，身体仍有惯性/重力和关节约束；Off不隐式保持旧目标、不强制整体重置。

沿用上一轮人体稳定性目标，新增明确的On→Off释放验收。此前保持目标35项定向及浏览器通过不覆盖此次静置/释放后的长期稳定。用户已确认具体方案，可以改产品/测试代码；先更新spec再实施。

## 诊断证据

/tmp/aasc-mmd-off-diagnostic.cjs读取已校验米娅PMX+待机VMD首帧、真实Ammo和当前rig/drive。手/脚/头/骨盆分别On偏移[0,3,3]模型单位3秒，然后Off10秒，60fps；全Off静置为对照。每种场景独立世界，最后60帧全部19骨骼相对最终位姿跨度。没有完整蒙皮/原生IK/grant/服饰/实时动画，网页和设备另测。

- 重力关/骨盆非自由：腕、头释放后末段位置跨度22.71/25.66mm；对应角跨度0.05032/0.05964rad。脚释放后峰值角速度达到8rad/s上限。
- 重力开/骨盆非自由：全部控制点一直Off，13秒末段位置跨度886.40mm，角跨度3.12509rad；手/脚释放亦有持续显著摆动。
- 单纯提高native阻尼或自然姿态驱动不能解决重力下漂摆；未采用这些候选参数。
- 临时关闭限位姿态写回native，保留最终骨架限位显示：重力全Off跨度约3.88mm/0.06108rad，末帧native最大角速度约1.386rad/s，表明仅位置小不等于物理稳定。速度反馈单独保留的试验也改善位置，但仍不足以完成全部验收。
- 开启骨盆自由的附加对照存在整体漂移，须区分自由物理运动与关节反馈注能；不扩大为默认锁定自由骨盆。

## 具体改动方案

- `3rd/mmd-ar-test/web-human-physics-drive.mjs`：修正关节限位反馈在重力/释放状态下的反复注能；以原生关节维持锚点/范围，避免直接瞬移显示投影姿态；释放后仍耗散相对关节运动，保留惯性、重力及其他目标。具体反馈方式以完整回归选择，不把临时移除所有反馈直接当成最终实现。
- `web-human-physics-rig.mjs`：复核默认/PMX关节框架和显示投影返回契约，继续固定骨长并严格执行PMX限位。

- `tests/mmd-ar-human-physics.test.js`/`tests/mmd-ar-human-physics-browser.test.js`：加入On→Off释放和全Off静置，重力开/关下全身位置/角度/速度持续采样，真实面板Off与标记跟随。

## 实施（2026-10-14）

按用户确认修改drive/rig/IK/UI。默认重力false，面板不勾选，显式true和本会话主动选择保留。rig只返回关节基准/限位相对角，停止把显示投影的COM/四元数瞬移回native。速度纠正以两端世界逆惯量换算等反角冲量；按work/curvature取耗能二次项最小点，避免各向异性惯量下直接夹速度也增能。Off关节相对角速度指数阻尼12/s，活动目标关节2/s；native线/角阻尼0.65/0.65；stop ERP=0.2，保持40迭代/90Hz。Off停止该点未完成拖动并立即更新标记，不清除其他状态，不隐式Hold或重置全身体。

实现中发现只去掉姿态瞬移仍有过长线动量尾部；native线阻尼由0.18调整到0.65后，无重力腕/头释放末秒跨度约1.12/0.63mm。原stop ERP=0.6有重力下短促角速度/能量尖峰；改0.2后19项身体测试通过，重力10秒后各场景末秒全身位置2.75–5.20mm、角跨度≤0.0562rad、native最大角速度≤1.621rad/s，仍有接触抖动而非完全静止。

提高自然姿态强度、按整条子链惯量放大回复力或直接增加关节阻尼的/tmp候选没有改善所有指标，未采用；没有把这些实验写进产品。组合39项、自由释放及网页1项已通过；未出APK/部署。

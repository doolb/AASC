# 夸克目录下载与双缓存

- 需求：将分享目录递归下载到用户选择的本地媒体库、记录映射供后续播放优先读取；临时缓存最多两个、下载串行。
- 设计与实现：见媒体库 design/spec；安全保存至目标库并持久化来源路径映射，通过媒体代理读取并支持 Range。
- 影响：服务端目录下载任务及媒体代理、控制端目录和目标库选择、夸克临时缓存。
- 自测：递归、不同目标库、已有文件、重启重用、Range、失败回退、双缓存和串行下载、浏览器交互。
- 性能与风险：目录下载逐文件流式写入、不覆盖旧文件；目录浏览仍需网络，目标为主服务器可写本地库；服务器重启中断当前下载，重新请求可补齐。
- 预计工时：一天。

# AASC 媒体索引、任务路由与服务器手动切换

## 任务描述

在不实现权限控制、自动发现和最近节点算法的前提下，一次完成服务器媒体索引共享、显示端优先任务路由和网页版服务器手动切换。

## Design 需求

- 各服务器保留本地媒体文件，通过 AASC 接口共享媒体库元数据和目录索引。
- 主服务器聚合已登记在线节点的索引，单个远程节点失败不影响其他来源。
- 播放地址指向媒体所属服务器，不复制媒体文件。
- `routing: display-first` 或 `target: auto` 的任务优先投递给能力匹配的在线显示端。
- 显式显示端目标和显式服务器目标保持兼容；首版服务器回退只执行当前主服务器。
- 控制端服务器页面支持在线节点连接和手动输入服务器地址，跳转到目标 `/upload`。

## Spec 设计

1. 新增媒体索引服务和 `/api/aasc/media-index` 接口，区分 `scope=local` 与主服务器聚合模式。
2. 新增任务路由器，读取在线显示端能力并返回显示端或当前服务器的确定性路由结果。
3. TaskManager 在实际执行前应用路由结果，显示端继续使用已有 `task:execute` 协议。
4. 服务器列表 UI 增加连接按钮和地址输入框，继续保留手动刷新与只读节点展示。

## 自测用例

- 本地媒体索引返回库和目录条目，并补全所属节点地址。
- 聚合索引包含在线远程节点，远程失败只产生错误来源。
- 显示端在线且能力匹配时，`display-first` 路由到显示端。
- 显示端不匹配或离线时，任务回退当前服务器。
- 显式 display/server 目标不被自动路由改写。
- 服务器页面在线节点可跳转 `/upload`，当前节点显示当前连接。
- 手动地址拒绝非法协议，合法地址补齐 `/upload`。

## 兼容性、性能与风险

- 保留现有 `/api/media-libraries/*`、`task:execute`、WebSocket 和 `/api/aasc/servers`。
- 远程索引请求采用有限超时和并发聚合，不阻塞本地索引返回。
- 索引仅内存生成，不新增磁盘数据和媒体复制。
- 当前接口无认证，仅适用于既有局域网测试环境；权限控制另行实现。

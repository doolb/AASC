# 媒体源统一代理

- 任务描述：B站、夸克和国内、国外任务来源自动使用各自选择的代理。
- 设计需求：保留来源选择和直连默认值，代理失败不自动直连，配置实时生效。
- spec设计：来源绑定 HTTP 客户端在每次请求时注入实时代理；任务独立进程沿用各自代理传递。
- 受影响模块：媒体代理、B站、夸克、媒体库控制端、代理自测。
- 自测用例：代理选择及切换、直连、代理错误、B站和夸克请求、Range 流与子进程。
- 兼容性测试：旧配置默认直连，保留自定义 HTTP 客户端和任务接口。
- 性能测试：复用代理 Agent，流式转发不缓存完整媒体。
- 风险评估：外部服务与设备实际网络环境需要现场验收；任务下载器的独立网络栈须单独检查。
- 预计工时：1 个工作日。

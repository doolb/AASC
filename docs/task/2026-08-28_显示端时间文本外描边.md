# 任务：显示端时间和媒体名增加主题色外描边

## 任务描述

显示端时间和媒体名在图片或视频上方显示时，部分背景较复杂，现有阴影不足以保持文字边缘清晰，需要增加主题色外描边；文字与阴影保持主题改造前的固定效果。

## Design 需求

- `#timeDisplay` 和 `#fileNameDisplay` 增加 1px 主题色外描边。
- 描边使用当前主题的 `--accent-color`。
- 时间和媒体名恢复固定白色文字与固定黑色阴影。
- 保留现有旋转和定位逻辑。
- 不改变文件名、连接状态、弹窗和媒体内容样式。

## Spec 设计

- `#timeDisplay` 和 `#fileNameDisplay` 使用 `-webkit-text-stroke: 1px var(--accent-color, ...)`。
- 两个元素的 `color` 和 `text-shadow` 使用主题改造前的固定白色与黑色值。

## 自测用例

1. 检查 `#timeDisplay` 和 `#fileNameDisplay` 存在 1px 主题色描边。
2. 检查两个元素仍使用固定白色文字和黑色阴影。
3. 检查显示端主题同步、旋转和定位契约不变。

## 兼容性测试

- Chromium/WebView 支持 `-webkit-text-stroke` 时显示真实描边；不支持时保留固定白色文字和黑色阴影。
- 0/90/180/270 度旋转下只改变时间元素变换，不改变描边方向。
- 图片、视频、网页媒体和其他显示端控件不受影响。

## 性能测试

- 仅增加 CSS 绘制属性，不增加脚本、请求或轮询。

## 风险评估

- 描边会略微增加文字视觉粗细，宽度限定为 1px 以控制影响。
- 主题色描边可能与媒体内容颜色接近，但可通过切换主题选择不同强调色；固定白字和黑色阴影保持基础可读性。

## 未明确需求

- 已确认：显示端时间和媒体名恢复不带主题的文字/阴影效果，并增加主题色外描边。

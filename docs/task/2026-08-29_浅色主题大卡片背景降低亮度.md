# 浅色主题大卡片背景降低亮度

## 任务状态

- ✅已完成 [2026-08-29][2026-08-29]

## 任务描述

降低浅色主题大卡片的背景亮度，避免大面积近白色表面造成刺眼和层级不明显。

## Design 需求

- `.section` 大卡片使用主题 `bg-secondary`。
- `.control-item` 小卡片继续使用 `card-background`。
- 弹窗继续使用 `bg-surface-strong`。
- 深色主题不改变。

## Spec 设计

```text
浅色主题:
    .section.background = bg-secondary
    .control-item.background = card-background
    modal-content.background = bg-surface-strong

主题切换:
    仅切换根节点变量
    不改变控件结构、交互和主题同步协议
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/css/theme.css`：调整浅色主题 `.section` 背景变量。
- `tests/ui-theme-card-contrast.test.js`：更新大卡片背景层级断言。
- `docs/design/control-ui-theme.md`：更新大卡片配色设计。
- `docs/spec/ui-theme.md`：同步主题伪代码。

## 自测用例

1. 浅色主题 `.section` 使用 `var(--bg-secondary)`。
2. 浅色主题 `.control-item` 仍使用 `var(--card-background)`。
3. 弹窗仍使用 `var(--bg-surface-strong)`。
4. 运行主题回归测试并执行 `git diff --check`。

## 兼容性测试

- 15 套主题继续使用现有根节点变量。
- 深色主题不新增浅色覆盖规则。
- 不修改 HTML、JavaScript 和服务端主题协议。

## 性能测试

- 仅改变 CSS 变量引用，不增加运行时计算或网络请求。

## 风险评估

- 低风险：只降低浅色主题大卡片背景亮度，不影响小卡片、弹窗和文字对比度。

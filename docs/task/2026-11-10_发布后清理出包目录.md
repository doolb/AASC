# 发布后清理出包目录

- 任务：在两端发布成功后清理出包目录中不再需要的旧版本包。
- 设计：保持最新及两端清单引用；保护未完成任务和未能确认安全的情况。
- Spec：验证签名与报告，建立保护集合；按固定目录、数字版本和普通文件筛选，再复核文件身份并删除。
- 影响：`release-offline.js`、`offline-output-cleanup.js`、既有清理辅助导出、发布文档和自测。
- 自测：旧包清理、清单和未完成报告引用、最高版本、符号链接、网络和报告异常。
- 兼容性：旧清单引用的依赖分组继续保留；旧报告不删除；失败后恢复发布可重试。
- 性能：仅读取报告/清单和目录元数据，清理与版本文件数量线性相关。
- 风险：无法读取任一保护信息时停止清理；发布成功不回滚；外部并发修改由既有发布锁约束本入口。
- 预计工时：2–3 小时。

# 聊天打开时隐藏播报文字

## 任务描述

显示端聊天层打开时隐藏播报文字，避免字幕遮挡聊天内容；语音播报音频仍继续播放，聊天层关闭后恢复文字显示。

## design 需求

- 聊天层显隐状态统一控制播报文字的可见性。
- 不暂停、取消或改变 TTS 播放队列。
- 关闭聊天后恢复原有 `voice-text-visible` 状态。
- 由于 TTS 和 ASR 当前共用 `voiceTextDisplay`，聊天打开时两类文字都隐藏。

## spec 设计

```text
setChatVisible(visible):
  state.chatVisible = normalize(visible)
  body.classList.toggle(display-chat-open, state.chatVisible)
  toggle chat layer and aria-hidden
  keep TTS audio queue and playback unchanged

display-chat-open CSS state:
  hide voiceTextDisplay with display:none !important

setChatVisible(false):
  remove display-chat-open
  let voiceTextDisplay follow its existing voice-text-visible/hidden class
```

## 自测用例

- 聊天打开时页面包含 `display-chat-open`，`#voiceTextDisplay` 不可见。
- 聊天关闭时移除状态类，已有播报文字可恢复显示。
- TTS 音频处理函数和队列逻辑不被聊天显隐逻辑修改。
- 显示端聊天/MMD 原有层级和输入交互测试保持通过。

## 兼容性测试

- 普通媒体、render-display、MMD、聊天气泡和控制按钮层级不变。
- Android WebView、桌面浏览器和旋转布局继续复用原有播报文字定位逻辑。

## 性能测试

- 仅切换一个 body 状态类，不增加渲染循环、音频处理或网络请求。

## 风险评估

- 当前 TTS 和 ASR 共用同一文字节点，聊天打开时 ASR 最近识别文字也会隐藏；音频识别链路本身不受影响。

# 语音帮助按关键词筛选

## 任务描述

支持通过“帮助静音”或“静音帮助”语音查询指定功能，只播报匹配的内置或自定义指令帮助；保留“系统”播报完整帮助的行为。

## design 需求

- 支持“帮助+关键词”和“关键词+帮助”两种表达。
- 内置命令和自定义关键词均可作为帮助主题。
- 只返回匹配主题的帮助行；未知主题返回提示，不执行命令。
- 保持现有帮助弹窗、显示端响应和 TTS 分句发送流程。

## spec 设计

```text
parseVoiceHelpRequest(text):
    规范化文本
    如果文本等于“帮助”:
        返回 { topic: '' }
    如果文本以“帮助”开头或以“帮助”结尾:
        提取另一侧文本为 topic
        返回 { topic }
    否则返回 null

processVoiceCommand(text):
    helpRequest = parseVoiceHelpRequest(text)
    如果 helpRequest 存在:
        返回 { type: 'showHelp', topic: helpRequest.topic }

getVoiceCommandHelpText(commandConfig, topic):
    topic 为空 -> 拼接完整内置、自定义和会话帮助
    topic 非空 -> 只拼接匹配 topic 的内置/自定义帮助
    没有匹配 -> 返回未找到相关帮助的提示
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/modules/voice/voice-command-app-service.js`：解析帮助主题并筛选帮助文本。
- `src/apps/server/boot/server-app.js`：将帮助主题传入帮助播报生成流程。
- `tests/display-voice-builtins.test.js`：增加帮助关键词、双向表达和未知主题测试。
- `docs/design/display-voice-conversation.md`、`docs/spec/display-voice-conversation.md`：同步设计和伪代码。

## 自测用例

1. “帮助静音”返回静音相关帮助，不包含天气/播放帮助。
2. “静音帮助”与“帮助静音”返回相同主题结果。
3. “帮助早安”可返回自定义指令帮助，但不执行“早安”。
4. 未知主题返回未找到提示，不执行任何命令。
5. “系统”继续返回完整帮助。

## 兼容性、性能与风险

- 保持现有 `showHelp` 事件、帮助弹窗和 TTS 分句接口不变，仅增加可选 topic。
- 帮助筛选只遍历当前内置命令和自定义配置，复杂度随命令数量线性增长。
- 关键词匹配沿用当前命令配置的包含语义；未知主题不会落入普通命令执行链。

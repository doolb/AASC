# 壁纸 FPS 状态栏避让

- 需求：壁纸 FPS 与系统状态栏重叠时只移动重叠距离，未重叠的位置和其他元素保持原状。
- 设计与实现：系统状态栏高度由壁纸服务通过共享原生桥提供，网页测量 FPS 物理位置并按画面旋转换算位移；返回前台清除偏移。详见 Android 显示端设计及实现文档。
- 验证：定向测试覆盖重叠、无重叠、四个旋转方向和返回前台；需在真实设备验证不同状态栏高度、壁纸预览与桌面切换。
- 性能：只在可见性、尺寸、旋转或壁纸状态变化时测量，不增加轮询。
- 风险：系统资源提供的状态栏高度可能与个别桌面或异形屏实际遮挡区域不同，需真机确认。
- 预计工时：约 1 小时，设备验收另计。

# 录音模式选项任务

## 任务描述
为 voice-display-node（子显示端）增加可配置的录音模式，支持 4 种模式：mute（现有）、cut（语音打断）、hard（系统 AEC）、soft（SpeexDSP AEC）。

## 自测用例

1. **mute（默认模式）**
   - 启动子显示端，确认录音正常
   - 播放 TTS，确认录音暂停
   - TTS 播放完毕，确认录音恢复

2. **cut（语音打断）**
   - 播放 TTS 时说话，确认播放立即停止
   - 确认打断时的语音被正确送往 ASR
   - 确认播放 TTS 但不说话时，不会误触发打断

3. **hard**
   - Windows：确认 WASAPI AEC 录音器初始化成功
   - Linux：确认 PulseAudio echo-cancel source 可用
   - macOS：确认自动降级到 mute

4. **soft（纯 JS NLMS AEC）**
   - 播放 TTS 时录音，确认回声消除效果（AECProcessor 处理）
   - 确认帧对齐正确处理
   - 确认播放参考信号正确传递给 AECProcessor

## 兼容性测试

- Windows 10/11：所有 4 种模式
- Linux (PulseAudio)：hard 和其余模式
- macOS：除 hard 外的 3 种模式
- 所有模式降级到 mute 后功能正常

## 性能测试

- 各模式 CPU/内存占用对比
- SpeexDSP AEC 处理延迟（每帧 < 1ms 为目标）
- 语音打断响应时间（从人声到 TTS 停止 < 200ms）

## 风险评估

- WASAPI AEC 需要调用 COM 接口，实现复杂度较高（当前为检测 + 降级）
- PvRecorder 录音器的 onSpeechStart 回调行为需实际测试
- NLMS AEC 效果依赖滤波器收敛条件（步长 μ、滤波器阶数）
- 帧对齐：播放参考信号先于麦克风信号到达时的同步处理

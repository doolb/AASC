# 任务种子通用升级自启动

- 需求：国内媒体加入任务种子，已安装 Offline 更新后自动启动；新任务通过种子声明即可复用通用机制。
- 设计：参见 `docs/design/task-code-sync.md`；仅显式标记的服务实例参与迁移，已有状态与用户停止选择保留。
- 伪代码：参见 `docs/spec/task-code-sync.md`，只使用签名服务包携带的种子定义与当前受管任务代码。
- 影响：release 任务种子、服务代码包构建、Offline 启动与任务引擎、自测及文档。
- 自测：打包过滤、首装恢复、旧设备无实例迁移、已有停止状态、重复启动、删除实例、缺失代码与失败处理。
- 兼容性：仅 Offline 启动执行迁移；兼容独立任务代码包及既有其他任务；不更改用户参数。
- 性能：启动时读取少量种子索引和一次迁移记录，不轮询。
- 风险：注册媒体源冲突或资源缺失会在任务中报告；真实 Android 及更新回滚需设备验收。
- 预计工时：1 天。

- 验证结果：首装、更新、保留停止与删除、代码延迟到位、中断恢复及签名代码包内种子快照均有自动测试；真实 Android 更新和媒体站点待验收。

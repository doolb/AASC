# RTMPose二维姿态三维映射修正计划

**Goal:** 修复图片应用时二维贴合却破坏实际三维姿态的问题，先保证真实骨架回环和关节可达性。
**Architecture:** 保留RTMPose二维输出，使用当前实际PMX父链/局部旋转的正向运动学与既有限位拟合图片；当前姿态作为完整候选及三维先验，拟合结果经原子提交进入既有VaM物理。
**Tech Stack:** Three.js、现有ONNX Runtime Web与Ammo、Node test、Edge/Puppeteer；不新增模型/生产依赖。
**Spec:** docs/spec/mmd-human-interface.md 的“3D映射回环修正”，对应design同名段。

状态：用户已回复“是”确认方案，inline实现及桌面验证完成。按executing-plans/test-driven-development先复现失败再改运行模块；深度歧义与手机验收保留待办。

## 需求与证据

用户“RTMPose应用到3d的有点问题”，追问后明确“每一张都有问题”。验收应覆盖转换链路，不能仅把失败归为个别原图关键点误识别，也不能以二维残差变小作为三维已正确。

已知当前实现使用肩肘腕髋膝踝12点、固定骨长、骨盆/躯干6旋转参和8段独立方向16参。它没有用PMX真实父子关节旋转生成全部位置，只在后续VaM写骨骼时限制角度；候选根据二维误差+弱段方向先验排序，根部初值恒0，不是完整当前姿态候选。

## 原因与边界

1. 骨段固定长度不等价于PMX骨架的父链/关节可达性。当前骨盆/躯干各自绕骨盆旋转位置，四肢方向独立；实际骨骼围绕各自关节旋转，还有PMX同级上下半身和中间骨。
2. 完整当前姿态没有作为零代价候选保留，二维近似相同的另一组深度仍可能获选并改动原本正确的身体部分。
3. 解算后才施加真实限位，会使“拟合目标”和“实际骨架”出现第二次偏差。仅整体图像残差改善无法验收前后方向与关节构型。

这是已复现的问题与代码结构证据，不能据此声称已经定位用户每张图的全部视觉偏差。单图真实前后深度仍不可唯一确定；本修正也不新增头部/脚掌朝向识别。

## 拟改文件与方法

- web-human-pose-lift.mjs：替换独立骨段方向拟合，读取当前实际骨架，在局部关节旋转参数上搜索；精确当前姿态先评估且保留；图片误差与完整旋转/深度先验共同排序，防止低二维误差替代正确3D。
- 新web-human-pose-fk.mjs：隔离的骨架快照/正向运动学，保持实际PMX父链和中间骨，只读原骨架；根/躯干/肢体目标位置与旋转必须来自同一个有效姿态。
- web-human-physics-rig.mjs及必要的新web-human-joint-limits.mjs：提取/复用既有约束坐标和限位计算供拟合与最终写骨架使用，保持现有物理规则，不放宽角度来凑误差。
- web-human-ik.mjs / web-human-interface.mjs / web-human-pose-ui.mjs：有界异步拟合、取消/代次/模型/相机/控制修改保护，先计算/校验全部候选再原子写入，失败保持旧目标；UI显示拟合限制和实际未到达信息。
- web-human-build.js：新模块复制与依赖指纹；tests/mmd-ar-human-rtmpose.test.js、physics及图片浏览器测试：增加真实三维回环、实际关节/骨长/原子提交、三张用户图实际骨架回读与多视角检查。
- 相关design/spec/usage/self-test/task/todo/changelog随最终实现同步。默认RTMPose权重和二维解码不改；功能仍仅全身IK，PBD页面继续屏蔽，不新增模型或出包。

## 风险、兼容性和性能

PMX中间骨/继承旋转与默认人体限位的坐标基必须与最终写骨架相同；提取共用计算时需回归既有VaM手动行为。碰撞/重力可能使合法运动学目标仍未完全到达，UI不能假报完整还原。单图深度多解用当前姿态先验选择，仍允许3D微调。桌面预算实测后才谈手机性能，当前手机未验。估计3～6小时，随真实父链/限位原型验证调整；本轮不自动引入3D识别权重。

## 执行裁定与接口

Ruling: 共享限位函数只提取现有twist/Euler裁剪，不改变物理规则；FK通过真实骨骼父链和物理约束坐标计算世界旋转，再换回实际父骨局部旋转。当前完整合法姿态为必选候选。
Ruling: 默认用参考相机真实透视并解析拟合图片等比缩放/平移；纯函数支持显式weak-perspective用于原闭环复现，生产不新增模式开关。
接口：createPoseFK(rig)提供初始关节角、边界和只读evaluate；fitImagePose2D为同步数学/兼容测试入口，fitImagePose2DAsync共享同一迭代器并每8次迭代让出。2D应用异步计算后再次验证模型/控制/相机/取消代次再提交，旧world路径保持同步兼容。

Ruling: 实际多图回读中骨盆/胸部相同偏移促使检查原生位置目标。确认骨盆旋转On解除根旋转固定后，根位置弹簧仍被“到骨盆距离0”的末端包络抹掉；新增25cm位置+0.25rad旋转测试，600帧旧代码误差.2499976场景单位。web-human-physics-drive.mjs仅将骨盆排除链长包络，修正后满足<.03m；不改变肢体包络、自由骨盆、原生限位或碰撞。该根目标传递属于本次实际3D映射闭环修正。

Ruling: 真实米娅PMX初始直膝0°小于显式最小0.5°，共享限位会产生约5.2mm合法纠正。精确回环测试先规范成合法姿态；非法输入另测限位，不把必要纠正与原26cm漂移混淆。Quaternion比较先归一化，避免原VMD浮点四元数微小非单位误差。

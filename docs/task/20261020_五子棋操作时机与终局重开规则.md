# 五子棋操作时机与终局重开规则

## 任务描述与 design 需求

用户在五子棋终局后说“再来一局”，模型只回复自然语言并询问先后手。规则需要逐项补充操作时机和参数，并在终局后的下一轮继续提供重开规则。固定用户黑先、AI 白后；不增加无调用行时的强制补判。

## Spec 设计

```text
读取权威棋局 → 进行中附 NowGame:五子棋 和规则
读取权威棋局 → 已结束附 NowGame:无、LastGame:五子棋,已结束,尺寸N 和相同规则
尚无棋局 → NowGame:无，按需查询规则
规则逐项解释开局、落子、查看、提议尺寸、确认尺寸、退出显示、恢复显示的时机和参数
终局后用户要求再来一局 → 模型发 GameUser 开局 → GM 创建原尺寸空棋盘，用户执黑先手
模型只回复自然语言 → 保留会话与棋局，不代发游戏指令
```

## 受影响模块和代码

- `game-chat-bridge.js`：规则按行展示及终局提示上下文。
- `tests/game-gomoku.test.js`：规则交付、终局普通聊天与同尺寸重开。
- 五子棋 design/spec/usage、todo、changelog；服务包状态保持待构建。

## 自测、兼容与性能

- `npm run test:game-chat`：48/48 通过，包含终局后聊天保持原棋局、再开保留 9 路尺寸、全空棋盘和用户先手。
- 保留既有 GM 权威校验、普通聊天行为及协议解析兼容；规则查询和 System 共用同一份多行规则。
- 无新增网络或文件操作；每轮终局上下文会增加一份五子棋规则文本。

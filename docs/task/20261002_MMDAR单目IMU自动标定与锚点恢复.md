# MMD AR单目IMU自动标定与锚点恢复

日期：2026-10-02。状态：功能目标已确认，具体文件修改方案待确认；未开始实施。

## 任务描述

测试APK启用单目相机与陀螺仪/加速度计的真实融合；参数尽可能自动获取，无需用户手填矩阵；同一有效地图和旧地图恢复时沿用图片首定位结果。真正无法关联的新地图才要求再次看图，界面区分暂时失锁、初始化、恢复及待对齐。

## 已知条件与待确认事项

- SM-N9500已连接ADB，存在LSM6DSL加速度/陀螺仪，Camera2时间戳UNKNOWN，现有代码仅接受REALTIME惯性输入。
- 相机焦距/物理尺寸能读取但只支持估算内参，不代表联合标定；相对外参、噪声和时间关系必须实采求解。
- 用户询问自动参数获取，方案采用手机引导采集、电脑自动求解再导入。是否已有可用文件仍待答复；有文件时可优先验证而不重复采集。
- 电脑现有NumPy/SciPy/OpenCV/PyYAML，无Kalibr/rosbags/Docker；求解工具环境需部署，不将工具存在当作求解完成。
- 用户需要按提示静置和多轴移动，并确认标定板实际尺寸。自动标定不是无数据/无运动的一键生成。
- UNKNOWN的跨会话时间关系不能假定固定，需采集检验稳定性和运行时适用性；无法验证时继续纯视觉。

## 自测、兼容性与性能

- IMU：合成时间偏移/不同采样率/加速度插值、回退/缺样/非法值、惯性初始化状态；取消/后台/旧事件不污染新会话。
- 标定：错误相机/尺寸/外参、UNKNOWN未验证、静置或单轴数据不足、工具缺失/失败不标定成功；实采需独立保留段验算。
- 原生锚点：同图恢复、A/B/A地图、地图重置、关键帧父链、合并及尺度变化；断言结果位置/方向/尺度，不能只匹配代码字符串。
- 网页：清晰状态、会话代次、采集取消与文件导入，MindAR回退/模拟输入及灯光动作保持正常。
- 兼容：Android8+既有APK范围；REALTIME/UNKNOWN、无IMU/不完整标定；横竖屏/180度和后台释放。
- 性能：有界采样队列、流式文件、采集与定位互斥，诊断仅状态变化/限频；记录实际采样Hz、帧延迟、缺样与资源释放，不承诺未经测量的手机帧率。

## 风险与预计工时

主要风险：UNKNOWN跨时钟关系、标定运动不足/模糊、设备参数适用性、地图合并并发与尺度迁移；处理原则是验证后使用，不能可靠恢复时保持最后显示并明确原因。开发与定向测试预计8–16小时，工具环境与实采标定另计，受真实数据和设备稳定性影响；不是当前会话的交付时长承诺。

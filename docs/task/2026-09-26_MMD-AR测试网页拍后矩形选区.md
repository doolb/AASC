# MMD AR 测试网页拍后矩形选区

- 日期：2026-09-26
- 需求：拍照校准后的操作改为矩形拖动，不再在测试网页独立移动四个角点。
- 范围：仅 `3rd/mmd-ar-test` 生成的测试网页；不改变模拟摄像头透视四角、正式显示端或旧测试 APK 的四角校准。

## Design 需求

拍照后默认显示照片四边各内缩 15% 的轴对齐蓝色矩形。拖动框体内部平移，拖动边或角改变尺寸，始终限制在照片内且面积足以保存。保存仍使用当前定位图结构，不迁移 IndexedDB 数据。

## Spec 伪代码

见 `docs/spec/mmd-ar-test-apk.md` 的“拍照校准”。测试网页标志 → 矩形绘制与命中 → 指针平移或缩放 → 矩形转 `selectedQuad` → 原保存流程；未启用网页标志 → 原四角点流程。

## 影响模块

- `src/apps/web-mediacenter/ui/public/js/display-mmd-ar.js`：网页模式的矩形交互与绘制，旧四角分支不变。
- `tests/display-mmd-ar-calibration.test.js`、`tests/mmd-ar-sim-camera.test.js`：几何与浏览器保存回归。
- `docs/design/mmd-ar-test-apk.md`、`docs/spec/mmd-ar-test-apk.md`、`docs/usage.md`、`3rd/mmd-ar-test/README.md`、`docs/self-test.md`、`docs/todo.md`、`changelog.md`。

## 自测、兼容、性能和风险

1. 测试网页移动与边角缩放后，保存的 `selectedQuad` 为左上、右上、右下、左下，仍可由 MindAR 编译。
2. 正式显示端的四角模式、旋转触控和指针取消继续通过现有回归。
3. 不新增图片复制或逐帧操作，拖动仅重绘当前校准 canvas；对定位运行时帧率无影响。
4. 风险：手机小屏的边角命中区域需真机触摸验证；模拟浏览器通过不等于实机验收。
5. 预计工时：约 2 小时。

## 完成与验证

- `npm run build:web:mmd-ar-test` 成功；校准单元测试 8/8、模拟摄像头浏览器端到端 1/1 通过。
- 浏览器已验证矩形移动、右边缩放和 IndexedDB 中的四角坐标，随后 MindAR 官方目标首锁成功。
- 未发布外网或重打 APK；待真机触控验收。

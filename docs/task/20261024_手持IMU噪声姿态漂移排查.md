# 手持IMU噪声姿态漂移排查

状态：只读诊断完成；修复待用户确认，未改产品实现。

需求：用户手持未主动移动、噪声较大，APK轨迹Z速度持续增大。目标是解释现场并修复已复现的软件错误。design/spec见imu-six-axis-test同日段落。

等级分析（analyze-requirement-level，enterprise）：主L6算法契约，次L5重置/静稳流程，必须下放L4。证据：initialized错配L6强；姿态/死区耦合L6强；手持/重置验收L5中。置信度(6/8)*0.9=0.675；层级24/25、证据19/20、完备17/20、风险18/20、落地14/15=92。明确重置错误可开发，噪声自适应需另评估；不额外调用翻译/伪代码技能。

现场：旧位置(-19.308,-16.764,101.974)m已停；随后Z速度峰值-15.432m/s，重力方向错28.56°，同帧原始角速度0.00124rad/s。实际样本约25Hz，服务器无拒绝。当前原生端使用旧单样本消息、缺新版配对时间元数据，不能断言已安装新配对实现。来源LAN .33，ADB设备为.6，未把另一台手机当当前采集端。

证据：/tmp/imu-live-capture.jsonl、imu-analysis.txt、imu-*trajectory.json、imu-*samples.json、replay-imu-reset.mjs/replay-imu-noise.mjs。原始轨迹不提交。固定倾斜噪声复现旧重置12秒Vz=-42.505m/s，仅恢复重力初始化即可为0。现场完整处理参数未知，大死区的单独重放有改善亦有变差，不能作为精度验收。

拟改：imu-engine.mjs统一重置、分离姿态/显示死区；app.mjs调用重置入口；server.mjs补现有诊断字段规范化；engine/server/browser测试覆盖实际按钮、姿态及协议。必要时同步index.html状态提示。APK原生采集不在此修复范围。

自测：固定倾斜噪声连续重置；低于大死区的小角度去重力；模拟器无噪声复合轨迹；保留校准/参数；暂停/断流/重连清理；旧帧兼容、新字段有界拒绝。统一命令npm run test:imu:six-axis-test。性能：25/50/100Hz回放、窗口有界。预计2–4小时含现场验证。

风险：高噪声与小运动不能完全区分；旧APK配对误差另验；重力不能观测航向；重置无法还原旧位置真值。自适应手持静稳、位置回正/隐藏阻尼、本轮APK安装及重启服务均需另定范围。

# MMD-AR 测试网页物理开关

- 日期：2026-09-26
- 状态：代码与自动化测试已完成；实际穿模观感待现场验收

## 任务描述与设计需求

在 HTTPS MMD-AR 测试网页的“物理”分类加入默认开启的开关，用于比较米娅 PMX 在有/无 Ammo 物理时是否穿模。仅测试网页显示该控件，不修改测试 APK 或正式显示端面板。依据 `docs/design/mmd-ar-test-apk.md` 与 `docs/design/mmd-pmx-vmd-local.md`。

## 实现规格与受影响模块

依据 `docs/spec/mmd-ar-test-apk.md` 与 `docs/spec/mmd-pmx-vmd-local.md`：测试页本地保存开关；切换时重新加载当前 PMX 并从 VMD 第 0 帧开始；关闭时新 helper 使用 `physics: false`，不加载 Ammo、不预热。受影响文件：`3rd/mmd-ar-test/build.js`、`3rd/mmd-ar-test/web-panel-groups.js`、`src/apps/web-mediacenter/ui/public/js/display-mmd.js`、`display-pmx-runtime.js`、`mmd-pmx-helper.mjs`、相关测试及文档。

## 自测与兼容性

- 有刚体且关闭物理时，验证 helper 使用 `physics: false`，Ammo 不初始化，VMD 仍播放。
- 网页菜单分类保留全部控件，默认开启，刷新恢复本地选择；切换失败恢复原值。
- 正式显示端和测试 APK 不新增控件；默认 PMX 路径保持原物理行为。
- 目标手机实际观察裙摆穿模、重新开启后的布料姿态与帧率，结果另行记录。

## 性能与风险

切换触发 PMX/VMD 重载，存在加载等待和额外内存峰值；测试页切换期间禁用控件。模型重载失败时恢复原开关并尝试重新加载原配置。预计实施约 2 小时；真机视觉验收依赖现场设备。

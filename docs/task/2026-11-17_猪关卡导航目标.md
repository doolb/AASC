# 猪关卡导航目标

- 需求：使用导航包 goals 驱动猪关卡采集、求解、执行和通关验证；由 agent 调用并可分析阻塞证据。
- 设计：导航包定义子目标；HIE 利用现有目标、进度和游戏桥接，以截图摘要绑定复核布局及完整求解结果；不支持的机制阻塞。
- 伪代码：见 `docs/spec/subprojects-hie.md` 和 `docs/spec/aasc-agent.md`。
- 影响：HIE 目标规划、导航包、游戏桥接和 agent 宿主，必要的 aasc-game 验证脚本与文档。
- 自测：目标条件、进度隔离、摘要不一致、未知和炸弹机制阻塞、完整求解与独立重放、胜利反馈；现有 HIE 和 agent 回归。
- 兼容性：已有 condition/when 前置条件不变；success 作为完成条件；已有桥接默认不运行。
- 性能：复用现有 auto 求解器及进程超时，单关只启动一次求解；大规模关卡的耗时由求解器限制。
- 风险：视觉误识别、特殊物件未建模和中断后状态漂移；现场不匹配或未确认胜利必须停止并保留证据。
- 预计工时：1～2 个工作日，复杂关卡及模型识别另计。

# Retop 目标模型 UV 和贴图输出

用户确认以 D:/down/小闪/moxing 的高低模接入测试，并实现低模、UV 和贴图输出。设计见 retop-texture-transfer，实施顺序为保留源逐角 UV 和材质，接入独立参考低模，烘焙新 UV 图集，再复查网页导入、颜色显示、ZIP 和导出回读。

影响 engine.js、app.js、viewer.js、index.html、build.mjs，以及新增 texture-transfer.js。测试源 UV 接缝与负索引、PNG/TGA 解码、参考低模统一缩放对齐、颜色光栅化和近邻投影。兼容旧 OBJ、STL、工程 JSON。性能测试使用 150 万三角面目标高模和 2122 三角面低模预算，测量图集烘焙时间。风险包括相近内外层串色和源 MTL 的失效绝对路径，需报告实际投影误差。预计 6–10 小时。

已接入实际目录，独立浏览器 Worker 从高模生成 2122 个三角面的工作版。参考低模统一缩放比为 0.0126975948。修正烘焙前的高拉伸图岛后，输出 210 个 UV 岛、2048 PNG、带逐角 UV 的 OBJ、相对 MTL 和 UV 布局 SVG。图集有效覆盖 1045427 像素，未命中为零，平均距离 0.00166076，最大 0.02726684。输出另存 `subproject/retop/artifacts/moxing-texture-2026-11-18`。

通过源 UV 及负索引、投影颜色、TGA 上下方向、材质回读、UV 重展开使旧图集失效及层级回归。真实网页同时读取 OBJ/MTL，解码 HIGH.png 与 lOW.tga，完成新 UV 和贴图输出及颜色预览。独立 Blender 回读 2122 个三角面、1 个 UV 通道、2048 颜色图，正背侧渲染已保存。几何属于混合拓扑工作版，脸、耳和手指的形状仍与参考低模有差异。

追加质量目标仍在实施。用户明确只从高模自动生成，LOW.obj 只作对照。先在同一高模的 30000 面工作副本上试验误差权重和位置正则，再检查源法线迁移与最终多视图。质量代码涉及 engine.js 的自动简化、texture-transfer.js 的源表面查询及 viewer.js 的逐角法线。

低模硬上限维持 2122。已对比局部权重和位置正则，复杂回退路径采用面积平方根权重及 0.5 正则；不引入参考几何。新增原 OBJ vn 与 s 的保存、源法线投影、按法线连续性恢复平滑分组，以及初次生成和两类重建中的自动恢复。法线查询无需 UV，多档共用一次只读索引。合成硬折边、跨折角光滑法线、无 UV 迁移及生成流程均有回归。独立 Blender 导入验证自定义法线、2122 三角面、1115 多边形和贴图引用通过，结果保存 moxing-quality-2026-11-18。脸、胸前装备及手部的示例视觉对照继续保留待处理。

用户再次指出胸前袋体效果错误。进一步将几何与着色分开：投影法线已在共享光滑扇区内统一，细节权重按三角面比例调整至约 3.76%；额外折痕回归通过。此前关闭源法线的对照脚本仍读取了导出 OBJ 的 vn，已纠正诊断方式，之后的 native 对照显式清空法线缓存。QEM 及其结构边、体积和表面过滤试验仍未通过袋体形体验收，均仅保留诊断产物。拟议的 CSI 块面构面另列任务，待确认后实施；整体质量任务未完成。

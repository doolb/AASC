# 壁纸角色倾斜与镜头平移增强

- 需求：角色实际倾斜幅度再增一倍；手机大幅移动时镜头效果不明显。
- 设计与伪代码：见壁纸控件 design/spec；修正模型入口二次限幅，提升加速度平移响应并保留回中和 ±0.14 上限。
- 影响：壁纸网页控制器、显示端模型入口、浏览器与真实相机单测；普通显示共用开关保持一致。
- 自测：角色小角度/上限通过真实入口；四向及横屏运动、弱移动、停止回中和真实 PMX/VRM 相机。
- 兼容性：保持手动、AR 和相机动画优先级，Android 是否接收有效线性加速度需实测。
- 性能：维持既有每帧计算，无新增传感器监听；风险为低质传感器噪声和更明显的回中。
- 预计工时：1–2 小时。

- 结果：壁纸/相机专项 3 项及真实 PMX 模型 IK 回归 21 项通过；角色小角度灵敏度和入口最大值相对原有实际效果均翻倍。真实设备运动效果待验收。

# MindAR 官方示例定位图内置 HTTPS 测试页

## 任务与设计

用户需要无需拍照校准即可选用官方样例，验证当前 JS 和 MindAR 对同一图像的定位效果。范围限定 `3rd/mmd-ar-test/` HTTPS 网页；正式显示端和原测试 APK 不出现该样例，不发布其他资源。

## 实现伪代码

参见 `docs/spec/mmd-ar-test-apk.md` 的“官方示例定位图”章节：校验并复制官方图；网页注册只读目标提供者；读取用户目标后合并；保留已有选择，否则优先用户目标，再选官方目标；提供查看图入口；删除只作用于用户目标。

## 受影响模块

- `3rd/mmd-ar-test/build.js`、`assets/mindar-official-card.png`：网页专用构建资源和入口。
- `src/apps/web-mediacenter/ui/public/js/display-mmd-ar.js`：可选内置目标合并，未设置提供者时保持原行为。
- `tests/mmd-ar-web-panel-groups.test.js`：真实生成页回归。
- `docs/design/mmd-ar-test-apk.md`、`docs/spec/mmd-ar-test-apk.md`、`docs/usage.md`、`docs/todo.md`、`changelog.md`：设计和验证记录。

## 自测、兼容性与性能

- 首次加载自动出现并选中官方目标；图片同源可读取，官方项不能删除。
- 添加用户定位图并选中后刷新，用户选择保持，官方项仍可切换。
- 原灯光/定位分类交互、AR 校准测试通过；正式页面未内置资源入口。
- 图片仅约 61 KB，仅网页加载且无需联网第三方；模型下载与 MindAR 编译耗时不因构建增加。
- 真机实际识别受印刷质量、屏幕显示、距离与光照影响，待现场验收。

## 风险与预计工时

风险为同一手机无法拍摄自身屏幕、示例图片本身局部纹理不足和浏览器相机权限；通过另一屏幕/打印、保留自定义定位图及现场复测处理。预计 1–2 小时。

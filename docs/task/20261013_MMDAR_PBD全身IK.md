# 2026-10-13：独立 MMD-AR PBD 全身 IK

## 任务描述与授权

用户提供《UE5 FullBodyIK学习》并确认按 PBD 思路改造独立 MMD-AR PMX 全身 IK。目标是让多个头/手腕/膝/脚踝位置目标通过共享骨盆、躯干及四肢祖先骨骼共同收敛，改善深屈膝与多目标姿态；保留现有镜头操作、控制点与 PMX IK link 角度限制。

范围仅限 `3rd/mmd-ar-test/` 独立 PMX 测试页，不修改正式显示端、VaM、Ammo/XPBD、软体、刚体碰撞或物理参数。算法参考 PBD/NPGS 的静态位置约束迭代，不实现 UE 或 VaM 的完整刚体动力学。

需求等级：主等级 L6（求解器及骨骼约束接口），次等级 L5（控制点拖动、目标优先与生命周期），L4 必须下放为逐帧伪代码。结论可开发，整体风险中高。需求评分：层级清晰度23/25、证据充分度18/20、实现完备度16/20、风险暴露度16/20、L4可落地性14/15，总分87/100；置信度0.78（中）。证据：[L6|强] 用户确认改为 PBD 全身 IK；[L6|强] 现有运行时提供七个 PMX 语义目标、骨骼父子链、刚体驱动标记和 IK link 限位；[L5|中] 当前活动目标有确定的拖动、重置和模型切换生命周期。主要风险为不同 PMX 膝轴/限位语义不一致、有限轮次下的目标竞争以及角度约束回写后误差增加。

## 设计与伪代码

- 设计文档：`docs/design/mmd-human-interface.md` 的“PBD 全身 IK 约束求解”。
- 实现前伪代码：`docs/spec/mmd-human-interface.md` 的“独立 PMX 全身 IK 控制点”。
- 数据流：当前帧VMD/原生IK姿态 + PMX骨架 + 活动目标 → 共享祖先约束图 → 有界PBD/NPGS迭代 → 受限本地骨骼旋转 → 既有手臂避让与物理流程。
- 活动目标误差按关节到末端的杠杆向量、骨段逆转动权重分配给整条可旋转祖先链；每轮应用后更新世界矩阵并执行本帧总修正预算与可用 PMX IK link 范围。
- 不旋转 PMX 根组骨骼、不移动角色根节点；center本地位置由骨架层级锚定但允许旋转分配目标误差；跳过 PMX 刚体驱动骨骼；旋转变量保持骨长，不修改骨骼平移/缩放。
- 踝目标活动而同侧膝目标未拖动时，使用基准髋/膝/踝姿势构造低强度膝盖弯曲面偏好；用户直接拖动膝点时以直接目标为准。
- 每帧开始恢复上帧IK增量，求解从本帧动作与原生IK/grant基准重新开始；仅活动目标期间运行，不增加 RAF 或网格碰撞扫描。

## 自测用例

1. 空闲/未拖动时不改变动作基准；拖动头、双腕、双膝、双踝任一目标后，在固定迭代预算内共同求解活动目标。
2. 单腕拖动时肩/肘/腕祖先共同分配误差；同一腿的膝/踝同时拖动时两目标均参与每轮求解，最终统一统计不可达目标。
3. 验证骨骼世界矩阵无 NaN/Infinity、骨长不变、角色根不漂移；膝优选弯曲只作用于脚目标且不覆盖直接膝目标。
4. 每轮增量和相对本帧基准总旋转受限；PMX IK link 的 rotationMin/rotationMax 始终是最终约束。
5. 不可达目标、缺少语义骨骼、空链或零长度骨段时安全降级；reset/close/model/helper切换/后台/销毁后姿态和资源恢复。
6. 真实米娅 PMX 浏览器拖动腕/膝/脚多个点，确认画面与镜头手势变化、无 pageerror；相关 WEB 构建成功。

## 兼容性测试

- 标准日文 PMX 与英文骨骼别名；缺失头/腕/膝/踝语义时按现有能力部分降级。
- PMX 提供或不提供 IK link 限位、刚体驱动骨骼、不同腿部轴向及伸直姿势。
- VMD播放/暂停、MMD原生IK/grant、手臂避让、Ammo/XPBD、切模型、helper重建、AR镜头保护。
- 只验证独立 MMD-AR PMX；正式显示端、VRM/GLB、VaM 与 Android UI 不扩展。

## 性能测试

- 求解最多七个目标、每个链最多12节骨骼，固定有界迭代；只有活动目标时计算，不拖动时不得增加骨骼扫描。
- 测量1/2/7个同时活动目标下的求解耗时；记录桌面真实模型结果，不从软件渲染推导移动端结论。
- 不增加RAF、网格碰撞、GPU读回、持久化或物理子步。

## 风险评估与预计工时

- PMX IK link 角度范围在各骨骼局部轴上定义；PBD旋转增量回写时可能造成目标误差上升，因此每轮限位后重算矩阵，结束后统一复核目标距离。
- 旋转梯度在接近伸直/杠杆臂退化时可能不可解；分母设安全下限并报告不可达，不以无限增量补偿。
- 多目标共享躯干可能竞争；使用确定顺序、有限轮次和逐目标残差，不承诺所有目标同时精确命中。
- 膝弯曲偏好依赖模型基准姿势；基准几何不足时跳过偏好并保留直接控制。
- 预计1–2个开发日，含实现、定向/浏览器测试、WEB构建和文档同步；不含手机观感/性能现场验收、APK构建或发布。

# 任务：无播放设备时文本媒体按字数翻页

## 任务描述

修复文本类型媒体在当前设备列表没有可用播放设备时快速连续翻页的问题。无语音播放设备时，文本按屏幕阅读速度等待后再推进；本次采用每秒 3 个有效字符（约 180 字/分钟）。

## Design 需求

- 见 `docs/design/text-media-routing.md` 的“无语音设备时的文本阅读回退”。
- 只有无可用 `voicePlayback` 设备使用阅读时间回退。
- TTS 合成失败、协议错误等其他错误保持既有处理方式。
- 暂停、停止、手动翻页和媒体切换必须取消回退计时器。

## Spec 设计

- 服务端 `textSentenceTtsError` 对无设备错误增加 `errorCode: noVoicePlaybackDevice`。
- 显示端按当前句去除空白后的字符数计算等待时长：`有效字符数 / 3 * 1000` 毫秒。
- 计时器回调必须校验播放标识、页码和句号，避免旧请求推进新媒体。

## 受影响的功能模块和代码

- `src/apps/server/modules/media/text-media-tts-service.js`：区分无播放设备错误。
- `src/apps/web-mediacenter/ui/public/js/text-media-player.js`：按字数延时推进并清理计时器。
- `tests/text-media-player.test.js`：增加无设备回退及中断回归。
- `tests/text-media-tts-service.test.js`：增加无设备错误码回归。
- `docs/design/text-media-routing.md`、`docs/spec/text-media-routing.md`、`docs/todo.md`、`changelog.md`：同步行为记录。

## 自测用例

1. 无播放设备错误不会立即推进下一句。
2. 计时结束后按每秒 3 字推进当前句。
3. 暂停、停止、上一页、下一页后旧计时器不再推进页面。
4. TTS 合成失败仍按原逻辑跳过，不套用阅读回退。
5. 预取错误不触发页面推进。

## 兼容性测试

- 有可用播放设备时仍以本地音频结束或远程播放回执推进。
- 旧服务端未返回错误码时保持原有错误处理。
- 图片、视频、音频、HTML 媒体播放流程不变。

## 性能测试

- 每个句子最多保留一个阅读回退计时器。
- 播放操作失效时立即清理计时器，不增加后台任务积累。

## 风险评估

- 每秒 3 字属于偏保守的屏幕阅读速度，可能比部分用户默读速度慢；该值作为当前明确业务参数，后续可再配置化。
- 设备在等待期间恢复时，当前句仍按已开始的回退等待完成，不重复发起 TTS 请求。

# 西施2实验绑定与AO默认角度

## 需求与方案

用户确认：独立西施2，尝试人体绑定及头发、衣物布料，AO默认法线抑制角45°。
设计/伪代码见 `docs/design/mmd-ar-test-apk.md`、`docs/spec/mmd-ar-test-apk.md`。
从无龙西施GLB创建独立工程，人体MMD骨架，空间权重，辅助骨链/刚体/弹簧关节，PMX导出；角色清单、URL、持久化扩展xishi2。保存过的AO值保持。

## 涉及模块

- `xishi2-rig.py`、`xishi2-pmx.py`、`export-xishi2.py`：骨架、权重、导出。
- `scripts/models/export-mmd-ar-xishi2.js`：导出命令入口。
- `web-xishi2-build.js`、`web-characters-build.js`、`web-character-panel.mjs`、`build.js`：模型资源接入。
- `web-panel-groups.js`：默认及重置AO45°。

## 验收与风险

本次只进行资源生成、结构检查和构建，不执行未请求的测试。
待用户实机确认：默认动作/抬手/转头/裙摆/头发权重，Ammo与XPBD碰撞，移动端负载，角色往返切换，AO重置和旧设置保留。
自动权重是初版，不能等同手工精修；手指与大角度动作、袖子和身体交界尤其需检查。
PMX采用经典材质，无完整GLB PBR及表情Morph；布料刚体之间暂不碰撞。
兼容目标为现有MMD运行链；Blender源工程仍保留原PBR。预计初版1个工作阶段，精修依实际反馈。

# MMD AR 平放定位图相机与纬度滑条

- 日期：2026-09-26
- 范围：仅 `3rd/mmd-ar-test` HTTPS 测试网页；不重打旧测试 APK，不修改正式显示端的 AR 入口，不发布外网。
- 需求：模拟摄像头纬度滑条过高；定位图平放时，希望 A-Frame 定位姿态驱动相机观察 MMD 角色。

## Design 需求

定位图中心作为世界原点，图面映射为水平地面，模型脚底置于原点。定位期间禁用普通环绕相机更新；丢失定位暂藏角色，结束定位恢复模型和相机。纬度滑条以横向经度滑条宽度、模拟取景画面 960×540 的比例计算，并受预览区高度限制。真实手机识别效果不由电脑模拟测试替代。

## Spec 设计与受影响代码

- `docs/spec/mmd-ar-test-apk.md`：先写相机矩阵、投影同步、失锁/恢复和滑条比例伪代码。
- `3rd/mmd-ar-test/build.js`、`display-mmd-ar-sim-camera.js`：仅调整网页滑条尺寸；A-Frame 目标标记置于 PMX 画布下方。
- `3rd/mmd-ar-test/display-mmd-ar-aframe.js`：从目标锚点读取姿态和投影，定位事件调用 PMX 相机适配接口。
- `src/apps/web-mediacenter/ui/public/js/display-mmd.js`、`display-pmx-runtime.js`：仅测试模式开放相机姿态接口；逆矩阵计算、模型脚底对齐、失锁与停止恢复。
- `tests/mmd-ar-sim-camera.test.js`、`tests/mmd-ar-camera-runtime.test.js`：浏览器自动回归。

## 自测、兼容性、性能与风险

- 自测：构建网页；无实体相机模拟图首锁及滑条尺寸；加载真实 PMX 后注入目标姿态，核对相机高度、横向变化、脚底落点、失锁和恢复；运行已有定位与校准回归。
- 兼容性：正式显示端与旧测试 APK 不进入本测试模式；停止后原环绕相机和模型变换应恢复。
- 性能：每个有效定位事件更新相机矩阵，不重新加载 PMX；与已有渲染循环共用帧。
- 风险：单图定位无 SLAM；不同手机的镜头裁切和目标图物理大小可能影响视觉对齐，需现场复测。
- 预计工时：约 3 小时。实际浏览器结果记录在 `docs/self-test.md`；不将模拟测试表述为真机验收。

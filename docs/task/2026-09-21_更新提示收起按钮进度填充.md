# 更新提示收起按钮进度填充

## 任务描述

更新提示面板自动收起到右侧后，收起入口不再始终显示橙色；下载时按完成字节比例填充，校验、安装、成功和失败状态显示对应颜色。

## design 需求

- 下载阶段使用 `completedBytes / totalBytes` 计算左侧填充比例。
- 无法计算字节比例时保留底色，不伪造进度。
- 校验/准备/安装使用状态色全量显示，成功为绿色，失败为红色。
- 展开面板和下载流程不改变，只同步更新收起入口背景。
- 控制端收起入口贴合左上角边缘，展开完整按钮时恢复 12dp 安全边距。

## spec 设计

```text
updateCollapsedTabProgress(phase, completedBytes, totalBytes):
    根据 phase 选择状态色
    downloading 且 totalBytes > 0 时按字节比例设置 ScaleDrawable level
    verifying/materializing/ready/installing/success/failed 时使用 100%
    其他状态使用 0%
    将底色和左侧进度层组合为收起按钮背景
```

- 现有 Offline 更新卡片测试保持通过。

## 兼容性、性能和风险

- 使用 Android 原生 Drawable，不引入第三方依赖；Android 26+ 可用。
- 只在进度回调时重建轻量背景，不读取文件或增加网络请求。
- 总大小未知时只显示状态底色，避免错误显示百分比。

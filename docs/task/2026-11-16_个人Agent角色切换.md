# 个人 Agent 终端角色切换

需求：通过 /role 查看并切换聊天角色，人仍输入自然语言，内部方括号命令只由模型提出。

设计与实现：见 `docs/design/aasc-agent.md` 和 `docs/spec/aasc-agent.md`。Agent 公开已注册角色的名称和人设；聊天时校验角色并传给模型，角色选择不扩大本地执行权限。终端提供 /role、/role 名称 和 /role --default；演示提供可切换角色。

范围：独立 Agent 终端、Agent 接口、测试和文档；真实模型和持久角色会话仍由宿主负责。测试覆盖列出、切换、重置、无效角色保留选择、身份传递、权限不提升及现有行为；伪终端手工验证。性能：角色列表内存查询，逐条顺序处理。风险：模型适配器须实际使用角色人设，并自行管理不同角色间会话；本次不实现持久会话。预计工时：半天。

完成情况：`/role` 查看列表、`/role 名称` 切换、`/role --default` 重置；选中角色名称和人设传入模型每一轮，错误角色保留当前选择。测试确认聊天角色不会扩大本地调用授权。`npm test` 21 项通过，伪终端实际切换和自然语言对话通过；真实模型与跨轮角色会话仍由宿主提供。独立子工程不改变 Offline 发布产物。

## 任务描述

实现 AASC（Actor-based Asynchronous Service Communication）系统，将现有系统重构为基于消息总线的执行者架构，支持分布式部署和用户权限管理。

## Design 需求

### 核心架构

1. **消息总线**
   - 基于发布-订阅模式
   - 支持点对点和广播消息
   - 消息过滤和路由

2. **执行者模型**
   - 统一的能力抽象
   - 动态注册和生命周期管理
   - 能力等级评级（L1-L5）

3. **用户模型**
   - 用户认证和会话管理
   - 保密等级（0-5级）
   - 权限控制

4. **能力继承**
   - 多级能力继承
   - 配置化能力定义

5. **分布式支持**
   - 集群节点管理
   - 跨节点消息路由
   - 边缘计算编排

### 消息格式

```typescript
interface Message {
  id: string;              // 消息唯一标识
  version: string;         // 协议版本
  type: MessageType;       // 消息类型
  priority: Priority;      // 优先级
  timestamp: number;       // 时间戳
  source: ActorAddress;    // 发送者地址
  target?: ActorAddress;   // 目标地址
  topic?: string;          // 主题
  payload: any;            // 消息内容
  ttl?: number;            // 生存时间
  requiresAck?: boolean;   // 是否需要确认
}
```

## 自测用例

### 消息协议测试

```javascript
const { Message, ActorAddress, MessageType, Priority } = require('./aasc');

const source = new ActorAddress('192.168.1.1', 'server', 'test');
const message = new Message({
  type: MessageType.COMMAND,
  source: source,
  payload: { test: true }
});

console.assert(message.id.startsWith('msg_'), 'Message ID format');
console.assert(message.type === 'command', 'Message type');
console.assert(!message.isExpired(), 'Message not expired');
console.assert(message.isBroadcast(), 'Message is broadcast');
```

### 消息总线测试

```javascript
const { getBus, Actor, MessageTopic } = require('./aasc');

const bus = getBus();

class TestActor extends Actor {
  constructor() {
    super({ ip: '127.0.0.1', role: 'server', name: 'test' });
    this.received = [];
  }
  async handleMessage(msg) {
    this.received.push(msg);
    return { ok: true };
  }
}

const actor = new TestActor();
actor.bus = bus;
await actor.init();

await bus.publish({ topic: 'test', payload: { data: 1 } });
console.assert(actor.received.length > 0, 'Actor received message');
```

### 用户模型测试

```javascript
const { User, UserStore, SecurityLevel, UserRole } = require('./aasc');

const store = new UserStore({ filePath: './test-users.json' });
const user = store.create({
  name: '测试用户',
  birthday: '2000-01-01',
  securityLevel: SecurityLevel.NORMAL,
  role: UserRole.USER
});

console.assert(user.id.startsWith('user_'), 'User ID format');
console.assert(user.canAccessLevel(2), 'User can access level 2');
console.assert(!user.canAccessLevel(4), 'User cannot access level 4');
```

### 能力继承测试

```javascript

const registry = new CapabilityRegistry();
initDefaultCapabilities(registry);

const chat = registry.resolve('chat');
```

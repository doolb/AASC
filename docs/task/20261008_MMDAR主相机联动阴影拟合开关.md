# MMD-AR 主相机联动阴影拟合开关

日期：2026-10-08。状态：实现、定向回归与Web构建验证完成；按用户选择默认关闭。自动浏览器验证受当前环境缺少Chromium限制，未执行。

## 任务描述

当前独立MMD-AR测试页始终使用联合拟合，根据主相机视锥/可见区域重算ShadowMap范围。为方便比较旧式角色包围盒范围与主相机联动范围，增加可持久化开关。

## Design 需求

- 主光设置增加“联动主相机计算”复选框，默认关闭。
- 开启使用现有联合拟合器，包含用户确认的额外0.5视野系数；关闭使用 `fitShadowCamera` 旧式角色包围盒自动范围，不随主相机缩放/转动更新。
- 关闭开关时即时重拟合到旧范围；重新开启时强制执行一次联合拟合，随后仅在相机/模型/灯光签名变化时更新。
- 复用 `aasc.mmdArTest.shadowMap.v1` 存储key新增 `jointFit` 字段。旧配置缺字段、首次访问和灯光复位均默认false；size、预览和cameraScale设置保留。
- 模型替换/缩放及角色平移跟随仍生效；只更改独立测试网页，不改正式display和APK。

## 自测用例

1. 无存储、旧存储缺字段、坏JSON和灯光复位都显示关闭；size/previewEnabled/cameraScale旧值不变。
2. 切换并刷新后复选框和联动状态本地持久化；初始默认关闭。
3. 关闭态使用旧包围盒拟合，cameraScale变化/角色缩放按旧路径重新拟合，主相机运动不触发联合拟合更新。
4. 开启态立即强制联合拟合，保留0.5系数；主相机视锥变化后重新拟合，静止帧由签名缓存避免完整计算。
5. 两种模式均跟随角色平移/换模型，设置贴图尺寸/预览开关不回归。
6. `node --test tests/mmd-ar-shadow-map-size.test.js`：15/15通过；与公网GLB回退测试组合22/22通过。`npm run build:web:mmd-ar-test`成功，检查生成 `index.html` 含复选框、运行时含模式路由；自动浏览器测试因环境缺少配置的 `/usr/bin/chromium` 未执行。

## 兼容、性能与风险

- 默认关闭是用户明确选择，会让新旧本地设置首次升级都使用旧包围盒范围；用户可启用并持久化联动模式。
- 关闭后减少联合拟合签名检查，但角色/尺度改变仍由旧fit逻辑更新；旧cameraScale半幅0.5行为保持。
- 模式变化需同一渲染帧内切换并即时拟合，避免两种相机范围混用；测试需覆盖开启/关闭往返。
- 不涉及正式显示端、服务器、APK或Offline发布配置。

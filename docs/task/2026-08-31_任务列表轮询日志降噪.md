# 任务：任务列表轮询日志降噪

## 任务描述

控制端任务页会重复请求 `task:list`，服务端为每次正常请求打印收发日志，造成高频刷屏。保持任务列表请求、响应和刷新行为不变，仅降低正常轮询日志噪声。

## Design 需求

- 正常 `task:list` 请求不输出普通 WS 收发日志。
- `task:list:result` 正常响应不新增普通 WS 日志。
- 任务列表处理异常保留错误日志。
- 提交、运行、停止、配置和其他任务操作日志不受影响。

## Spec 设计

```text
收到 task:list:
    执行原有任务列表查询
    成功返回 task:list:result
    不写普通 WS 操作日志

任务列表查询失败:
    保留错误日志
    返回 task:error
```

## 自测用例

1. 连续请求 `task:list` 时不出现普通 WS 收发日志。
2. `task:list` 仍返回任务、链接和 Sidebar 清单。
3. 任务列表处理失败时仍输出错误日志并返回错误消息。
4. 其他任务操作日志保持不变。

## 兼容性测试

- 控制端任务列表初始化、页签切换和任务状态刷新。
- Widget 刷新、任务提交、运行、停止和配置保存。

## 性能测试

- 高频轮询不再构造和写入两条普通 WS 日志，任务查询和响应开销保持不变。

## 风险评估

- 仅调整正常轮询日志，不改变 WebSocket 协议、任务数据和错误处理。
- 需要诊断正常轮询时，可通过控制端任务列表结果和任务专用日志确认。

## 预计工时

- 约 0.5 小时，包含日志规则回归和任务面板检查。

# 壁纸浮窗半圆与收起时间

- 需求：靠边收起显示与简略浮窗相同的半圆，点击展开；自动收起时间可设置，默认 2 秒，0 不收起；圆环外圈使用主题颜色。
- 设计：`docs/design/display-wallpaper-controls.md`；半圆显示在屏幕范围内，内圈保持语音状态，外圈使用当前主题强调色。
- 实现：`docs/spec/display-wallpaper-controls.md`；原生本机保存秒数并将输入规范化为 0 至 3600；0 时取消计时并展开；旧 APK 禁用输入。
- 模块：壁纸控制页、Android 原生桥、系统浮窗、主题与贴边状态、自测。
- 自测：网页时间读写、旧 APK、边界数值、左右半圆触摸和位置恢复；真机验证重启保存、主题切换、两侧贴边和系统缩放。
- 兼容：继续使用既有悬浮窗权限，普通网页语音按钮不变；圆角透明范围仍受 Android 系统浮窗矩形输入区域限制。
- 性能：维持原语音快照刷新频率，仅绘制可见半圆和设置单次计时。
- 风险：系统桌面、屏幕缩放、主题与 WindowManager 的表现可能有差异，需真机验收。
- 预计工时：约 2 小时；网页服务包及 min APK 均需更新。
- 验证：壁纸网页定向与全息浏览器回归 19 项通过；Android Kotlin 编译及计时、半圆命中、位置恢复和渐变 9 项单元测试通过。目标手机尚未更新验收。

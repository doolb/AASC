# 五子棋坐标标尺与默认专业棋力

## 任务描述与 Design 需求

用户要求显示端棋盘上方和左侧显示序号，并把默认智力调为专业。已确认方案：顶部列字母（包含I）、左侧行号，随棋盘旋转；四种棋盘尺寸共用实现，默认专业，保留三档切换。


## 自测、兼容及性能计划

通过现有 `npm run test:game-chat` 验证，另运行聊天覆盖棋盘的浏览器回归。真实旋转测试设置页面当前旋转值并调用现有舞台，检查实际角度；每种尺寸逐个核对标签中心与交点，在旋转后点击交点核对发送坐标。新快照不残留标签，增量不重建标尺。原JSON棋盘、GameMap、持久化和点击锁均兼容。每次重建增加2N个标签，最大30个，仍使用DocumentFragment批量更新。

新增标尺用例独立验证通过，覆盖320×640和740×390、四种尺寸、四向旋转共32种组合，点击未被既有工具栏覆盖的C3检查坐标；标尺逐个核对逻辑对齐及边界，标签不接受落子且不重复朗读。真实舞台从页面当前旋转变量计算几何，测试设置该变量并检查实际角度。`node --test tests/display-chat-opening-browser.test.js` 15/15通过，语法和差异检查通过。

最终 `npm run test:game-chat` 63/63通过、零跳过，含已有棋局、GameMap、终局、请求锁、演示和独立聊天入口回归；查询规则与活动提示均使用默认专业。

# 显示端 VAD 独立卡片布局

## 任务描述

将显示端 VAD 阈值、底噪检测和检测结果从设备列表条目移出，放入显示控制页的独立卡片，降低设备列表信息密度。

## design 需求

- 设备列表保留监听开关、监听状态和最近识别文字。
- 新增“监听 VAD / 底噪检测”卡片，按显示端展示阈值、检测按钮、统计结果和应用建议。
- 保留原有按 `displayId` 独立设置、持久化和 WebSocket 协议。

## spec 设计

- `upload.html` 增加 `voiceVadPanel` 容器。
- `DeviceList.renderVoiceVadPanel()` 独立渲染 VAD 卡片，`bindVoiceVadControls()` 处理输入与按钮。
- `renderVoiceControl()` 和 `renderVoiceControlHtml()` 不再包含 VAD 控件。

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/upload.html`

## 自测用例

1. 设备列表两种视图都不显示 VAD 阈值和底噪按钮。
2. 显示控制页独立卡片按在线显示端显示 VAD 配置。
3. 独立卡片仍能发送阈值、发起检测、展示结果并应用建议值。
4. 显示端列表更新或 WebSocket 回包后卡片同步刷新。

## 兼容性测试

- 保持 `setVoiceVad`、`detectVoiceNoise`、`voiceVadConfig` 和 `voiceVadNoiseResult` 协议不变。
- 旧显示端、浏览器显示端和 Android Display APK 不受控制端布局变更影响。

## 性能测试

- 卡片仅在设备列表或 VAD 结果变化时重新渲染，不增加轮询。
- 每台设备只保留一份最近检测统计。

## 风险评估

- 卡片与设备列表分离后需要同时响应设备上下线；由 `DeviceList.render()` 统一刷新，避免显示过期设备。

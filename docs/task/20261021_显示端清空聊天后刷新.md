# 显示端清空聊天后刷新

## 任务描述与 Design 需求

显示端点击“清空”后记录未刷新。清空后的全量历史仅剩其他会话，显示端按范围过滤而忽略回包；旧流式节点也会被普通历史刷新保留。需要成功后刷新当前范围，同时保留失败提示和会话隔离。

## Spec 设计

```text
清空请求 → source:displayChat + 独立requestId + 当前mode/target/sessionId
服务端清空当前范围 → 返回同一requestId、cleared:true和该范围历史
失败 → 回传关联编号的chatHistoryError
有效成功且仍在原范围 → 作废旧请求编号 → 清除旧流式状态 → 渲染权威历史
已切换范围或旧查询回包 → 不改当前内容
迟到旧请求输入、分片、协议提示、最终回复 → 忽略；忽略编号最多保留256项
```

## 受影响模块与代码

- `display-chat.js`：清空请求、成功刷新、失败处理和迟到消息隔离。
- `server-app.js`：范围历史、清空标记与成功/失败请求编号回传。
- `display-chat-opening-browser.test.js`：真实显示端舞台及服务端分支回归。
- display-chat-mmd design/spec、usage、todo、changelog；服务代码包保持待构建。

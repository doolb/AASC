# HMR2.0b 自选图片文件与粘贴

## 任务与需求

在独立本机HMR2.0b对照报告中选择或粘贴自有图片，输出HMR骨架和同图整图相对深度。保留固定三图及其原始结果，不修改正式全身IK。

## 设计与实现

参见[设计](../design/mmd-human-interface.md)与[伪代码](../spec/mmd-human-interface.md)。页面统一解码、限幅并编码PNG，显示可编辑整图人物框；本机回环服务接收PNG，临时调用Python单图HMR2.0b，浏览器ORT Web运行Depth Anything V2 Small。输入/输出临时文件在请求结束后删除；固定结果不覆盖。服务与报告源码在`tmp/mmd-pose/depth-eval/hmr2-sam3d/`，模型、私有图片、推理结果仍在忽略目录。

## 影响范围

`report.html`、`report.mjs`、`run-hmr2.py`、新增`custom-report-server.cjs`、`custom-depth.mjs`、`check-custom-report.cjs`；design/spec/usage/self-test/todo/changelog。没有生产依赖或Offline资源修改。

## 自测、兼容性与性能

文件与页面粘贴、人物框越界、真实浏览器深度和本机API；以官方模型跑动漫原图回读25点；固定三图及WebGL降级回归。单次HMR串行，模型占用内存较高；手机浏览器只运行相对深度，HMR必须由同机Python服务处理。实测耗时以运行日志为准。

## 风险与后续

自选图默认整图框可能包含道具或多人，需人工缩框。相对深度不是真实关节Z；HMR对既有真人左右腿与动漫脚掌错误尚未解决。用户未要求接入正式VAM。手机和更多图的姿态质量留待验收。

预计工时：本机实现与回归约4小时；更多图片的人工质量评估另计。

# PMX Toon / 普通光照切换

- 日期：2026-09-23
- 状态：代码和自动化测试已完成，待真实米娅模型现场视觉验收
- 预计工时：约 3 小时，Android WebView 现场验收另计

## 任务描述与 design 需求

用户在环境光与补光强度为 0、主光仍为 0.80 时发现米娅 PMX 背光面发亮。已按清单 SHA-256 校验远端 PMX：52 个材质都采用内置纯白 `toon00.bmp`，现有 Toon 直射光对背向法线仍提供亮度。灯光面板提供 PMX Toon 明暗开关，默认开启以保持兼容；关闭后主光和补光都按法线点积计算直射亮度，环境光、阴影、AO、VRM、ACES 色调映射不变。

## Spec 设计与受影响模块

先更新 `docs/spec/mmd-pmx-vmd-local.md` 中的设置与材质伪代码。`display.html`、`display-mmd-lighting.js` 增加开关和本地保存；`display-mmd.js` 规范化旧值；`display-pmx-lighting-mode.mjs` 为加载的材质实例加入运行时 shader 参数；`display-pmx-runtime.js` 在加载时准备材质，在 `setLighting` 时即时切换，不重载模型或动作。不修改 vendored shader 文件或远端模型。

## 自测用例与兼容性

- 配置层：旧值默认 Toon，显式关闭可保存，预设保留，恢复默认重新开启。
- 材质层：Toon 背光保留原结果，普通模式背向主光不受该直射光照亮；补光从正面照入时仍能照亮表面。
- 加载/切换：切换不重复注入 shader、不重载模型；VRM 忽略此 PMX 专用设置。
- 回归：显示端 MMD/PMX AO、浏览器 shader 像素测试与完整 `npm test`。

## 性能与风险

每个 PMX 材质仅首次加载时改写其私有 shader 字符串；切换仅更新 uniform，不重新编译。普通模式可能明显改变 Toon 质感，尤其在环境光低且无补光时；真实米娅和 Android WebView 的材质观感、边缘与帧率需现场验证。

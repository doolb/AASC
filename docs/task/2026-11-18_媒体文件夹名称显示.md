# 媒体文件夹名称显示修复

- 任务：文件夹卡片显示完整可读名称，长名称可换行，多个操作不压缩名称。
- 设计：保留默认最小尺寸，内容超过默认高度时增高并重排；主题和原有操作不变。
- 实现：参见 `docs/spec/upload.md`，调整文件夹 flex 收缩与操作换行。
- 影响：控制端媒体库 CSS、自测与文档；不改变媒体数据或播放协议。
- 自测：桌面、窄屏、明暗主题，包含长名称及多个文件夹操作，检查名称可见、可点击和卡片无重叠。
- 兼容性：浏览器与 Android WebView，文件夹导航及批量播放入口保持不变。
- 性能：仅改变样式，沿用已有尺寸监听，无额外请求。
- 风险：较长名称会增加卡片高度，超长连续字符需要换行。
- 预计工时：约 1 小时；未明确事项：无。

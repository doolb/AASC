# APK 控制端按钮移至左侧

## 任务描述

将 Android APK 原生“控制端”浮动按钮从 WebView 右上角移动到左上角，避免遮挡页面右侧 tips。保持按钮显示规则、点击切换控制页、浮层层级和现有边距不变；重打 offline APK 验证。

## Design 需求

- 入口按钮定位在 `webContainer` 左上角，控制端页面可见时仍处于 WebView 上方并可用于关闭。
- 不改变普通 APK 与 offline APK 的权限开放或按钮显隐规则。
- 同一 `MainActivity` 布局由普通/offline 变体共享，两个变体的可见按钮均使用左侧位置。

## Spec 设计

```text
activity_main.xml:
    controlToggleButton.layout_gravity = top|start
    controlToggleButton.margin = 12dp
    controlToggleButton.elevation = 12dp
    其他控件层级与尺寸保持不变

MainActivity.toggleControlPage:
    保持原有 /control WebView 显示/隐藏行为
    按钮保持在可见控制页之上
```

## 自测用例

1. 布局契约确认 `controlToggleButton` 位于 `FrameLayout` 左上角，保留 12dp margin 与浮层层级。
2. 离线 APK 静态测试确认原有按钮权限、可关闭控制页及顶层 WebView 关系不回归。
3. 执行 Android 离线 APK 构建，检查 APK 产物存在且 ZIP 完整性通过。

## 兼容性测试

- 普通 APK 与 offline APK 共用 `activity_main.xml`，检查两变体均不改变按钮显隐逻辑。
- 不改变竖屏/横屏布局方向适配；`start` 按照系统布局方向定位左侧。
- 不改变控制页 WebView 加载 URL、按钮文案和返回键关闭行为。

## 性能测试

- 仅变更原生 XML 定位属性，不增加运行时计算或页面渲染工作。
- 不增加启动任务、服务或权限请求。

## 风险评估

- 左上角可能遮挡显示页左侧内容；本次按用户指定移至左侧并保留原 12dp 安全边距，显示页提示区域右侧恢复可见。
- 控制按钮必须维持在控制 WebView 上方；回归测试与构建验证覆盖层级契约。

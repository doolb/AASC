# 基础主题色与控件继承

## 任务描述

将控制端主题颜色收敛为根节点基础变量，让显示端信息弹窗和设备树等上层控件继承基础颜色，修复浅色主题下白字、灰字和深色控件背景未随主题切换的问题。

## Design 需求

- 主题变量作为页面基础颜色来源，普通文字和容器优先继承父级颜色。
- 显示端信息弹窗、浏览器详情和设备树使用基础文字、背景、边框和控件变量。
- 在线、错误、支持/不支持、选中和危险操作保留语义状态色。
- 不改变显示端数据、树状视图事件和控件 ID。

## Spec 设计

- 在 `upload.css` 中将显示端信息与树状控件的硬编码颜色替换为主题变量或 `inherit`。
- 保留 `theme.css` 的既有主题变量和浅色状态覆盖，避免重复增加单个控件的主题补丁。
- 在 `tests/ui-theme.test.js` 增加基础主题色消费和继承契约测试。

## 受影响功能模块和代码

- 控制端主题：`src/apps/web-mediacenter/ui/public/css/theme.css`
- 显示端列表与信息弹窗、设备树：`src/apps/web-mediacenter/ui/public/css/upload.css`
- 主题回归测试：`tests/ui-theme.test.js`
- 设计与实现文档：`docs/design/control-ui-theme.md`、`docs/spec/ui-theme.md`

## 自测用例

1. 切换浅色、暖黄、淡粉和深色主题，显示端信息弹窗标题、浏览器详情和功能支持文字均可读。
2. 切换树状视图，设备名、浏览器信息、设置项、下拉选项、滑条数值和事件输入文字跟随主题。
3. 在线、支持/不支持和选中状态仍保留可辨识的语义色。
4. 运行 `node --test tests/ui-theme.test.js`。

## 兼容性测试

- 保留现有显示端信息弹窗、树状视图的 DOM 结构、事件监听和元素 ID。
- 深色主题继续使用原有深色变量；非深色主题复用统一变量，不依赖浏览器特有 CSS。

## 性能测试

- 仅调整静态 CSS 和文本契约测试，不增加运行时监听、网络请求或 DOM 重绘逻辑。

## 风险评估

- 主题变量缺失时可能影响旧页面显示，因此保留变量回退或现有深色默认值。
- 原生下拉选项的系统渲染存在浏览器差异，使用主题变量设置可控的背景和文字颜色。

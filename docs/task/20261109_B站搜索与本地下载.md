# B 站搜索与本地下载

- 需求：B 站视频搜索、保存视频到可选本地媒体库并优先播放本地副本。
- 设计与实现：见媒体库 design/spec；匿名会话和 WBI 签名搜索，下载分集或公开列表并持久化映射，优先 DASH 合并，回退单文件 MP4。
- 影响：服务端 B 站流、搜索、下载、播放列表路由，控制端 B 站面板。
- 自测：匿名真实搜索、分集合并和 ffprobe、搜索分类与目标库交互、列表/重复/失败、持久化与 Range、本地回放；B 站既有测试。
- 性能与风险：下载串行、流式写入；ffmpeg 合并需额外磁盘空间，缺少 ffmpeg 时降级。匿名搜索和播放受 B 站接口、权限和风控影响；整列表最多 500 分集。
- 预计工时：一天。

# 控制端修复模式设置

## 任务描述

在控制端声纹管理页面增加修复模式配置卡片，支持修改共用明文密码和工作 Agent 角色；空密码表示停用修复模式。

## Design 需求

- 服务端提供修复模式配置读取和保存接口。
- 读取接口不得返回密码原文，只返回是否已配置、当前工作 Agent 和可选角色列表。
- 密码输入框留空时保持原密码；单独清空操作将密码设置为空字符串。
- 工作 Agent 必须从当前 `aiRoles` 列表选择并在服务端校验。
- 配置保存后对下一次进入修复模式立即生效，当前会话不强制切换角色。

## Spec 设计

控制端通过 `GET /api/repair-mode/config` 加载脱敏配置，通过 `POST /api/repair-mode/config` 保存角色及密码变更。服务端只持久化合法角色和字符串密码，返回 `passwordConfigured`、`role`、`roles`，前端不从响应填充密码输入框。

## 受影响功能模块和代码

- `src/apps/server/modules/voice/repair-mode-config.js`：配置脱敏、角色校验和更新规则。
- `src/apps/server/boot/server-app.js`：新增修复模式配置 HTTP 接口。
- `src/apps/web-mediacenter/ui/public/upload.html`：新增控制端设置卡片。
- `src/apps/web-mediacenter/ui/public/js/voiceprint-panel.js`：加载、渲染和保存配置。
- `tests/repair-mode-config.test.js`：配置更新规则测试。
- `tests/repair-mode-config-ui.test.js`：页面与接口契约测试。

## 自测用例

1. GET 配置不包含密码原文，正确返回配置状态和角色列表。
2. 设置新密码和合法角色后保存；留空密码保存时旧密码不变。
3. 清空密码后返回未配置状态，修复模式不可进入。
4. 不存在的工作 Agent 被拒绝，且不保存配置。
5. 控制端卡片显示配置状态、动态角色下拉框和清空密码操作。

## 兼容性测试

- 现有修复模式显示端入口、密码校验、确认流程和工作 Agent 路由不变。
- 未配置修复密码的旧配置继续按停用处理。
- 现有声纹、服务器语音开关和 Agent 角色管理不改变接口行为。

## 性能测试

- 配置接口只读取内存配置和当前角色列表，不触发 ASR、TTS 或 Agent 启动。
- 页面只在声纹管理面板初始化时读取一次配置，保存时单次请求。

## 风险评估

- 密码按用户要求以明文保存，读取接口不回传原文，配置文件权限仍需受保护。
- 删除或重命名工作 Agent 后，保存配置会被拒绝；已有运行会话不受本次保存影响。

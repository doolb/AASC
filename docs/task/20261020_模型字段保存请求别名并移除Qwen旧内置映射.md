# 模型字段保存请求别名并移除 Qwen 旧内置映射

## 任务描述

控制端“LLM 服务器配置”的当前模型字段原来保存 Qwen 目标名称，即使普通聊天请求已经提交 `aasc-qwen-*` 别名。改为选档时直接保存请求别名；删除 Chat2API 内置的 `Qwen3.6-Flash → Qwen3.7` 兼容映射及发行种子行。

## Design 需求

- 当前普通 LLM profile 的模型字段与三档普通聊天提交给 Chat2API 的请求名一致。
- 旧 `Qwen3.6-Flash/Qwen3.7/Qwen3.7-Max` 配置仍可识别原档位，再次选档才更新保存值。
- 保留 `aasc-qwen-mini/flash/pro` 三条内置映射；运行时私人自定义映射保持原样。
- 不改 profile 名称，也不在用户可能同时编辑配置时覆盖当前运行中的选择。

## Spec 设计

```text
收到 setChatModelTierSelection → 校验 Provider、档位、账号和当前普通 LLM profile
选中档位 → tierRequestModel 生成请求名 → 当前 profile.model 和兼容全局 model 一次持久化为请求名
读取旧 profile.model → identifyModel 同时识别旧配置名和新请求别名 → 聊天始终发送档位请求名
Chat2API 默认表 → 删除 Qwen3.6-Flash→Qwen3.7 → 保留 aasc-qwen-mini/flash/pro
发行种子 → 删除相同旧映射行；私人自定义映射不做迁移或删除
```

## 受影响模块与代码

- `chat-model-tier-service.js`：选档保存请求名。
- `chat2api-default-model-mappings.js`：删除旧内置映射。
- `release/userconfig/chat2api/model-mappings.json`：删除旧种子行；`release/config/data-repair-state.json` 同步新种子的大小和 SHA-256。
- `chat-model-tier-service.test.js`、`chat2api-defaults.test.js`：更新保存值和默认规则断言。
- chat-system、chat2api-builtin-task 的 design/spec，模型快选及统一应用 usage，todo、changelog。

## 自测、兼容、性能与风险

- `npm run check:chat2api`；三档服务与浏览器定向测试；`npm run test:offline-data-repair` 检查发行种子。
- 旧配置名继续回显旧档位；自定义同名映射优先级不变；当前运行 profile 的新选择不被后台迁移覆盖。
- 纯字符串转换和一条默认规则删除，不新增网络请求或热路径 I/O；预估 1 小时。
- 若用户直接调用 `Qwen3.6-Flash` 而非三档别名，删除默认映射后由现有自定义映射或 Provider 自身规则决定目标；三档快选始终走 `aasc-qwen-*`。

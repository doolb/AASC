# 更新进度、诊断隐藏与面板返回键

- 任务描述：修复诊断文字偶发常驻与更新进度无法结束，支持返回键关闭聊天和媒体面板。
- design：隐藏计时不依赖单一广播；更新终态可靠恢复；返回键先关闭最上层面板。
- spec：启动/更新快照分离并补发，安装终态先持久化再消费，网页返回未处理时保持原生后退。
- 影响：Android 主 Activity、更新状态与安装接收器、显示端舞台与媒体控件、自测和文档。
- 自测：漏广播、成功/失败、后台恢复、重复恢复、诊断计时、面板优先级和原返回回退。
- 兼容：普通 APK 与 Offline；不同 Android 安装权限及配置变化需实机验收。
- 性能：复用已有事件、Handler 与一次状态查询，不新增轮询。
- 风险：更新事务不得被误报完成；返回异步回调不得关闭已切换页面。
- 预计工时：3 小时。
- 验证结果：Android 离线编译及单元测试 320 项、1 项既有跳过；聊天浏览器 16 项通过。APK 旧结构测试 5 项失败，与修改前基线相同；真实系统安装和返回键待设备验收。

# 二维投影直接驱动三维刚体姿态评估

状态：用户提出以三维刚体/物理方式替代线段骨架还原二维坐标。已核对本地架构并形成方案，待修改方案确认后执行临时原型；未修改运行代码或验证收益。RTMW停止新试验，像素深度模型不作为本轮前置条件。

## design需求与已有能力

目标是保留RTMPose-m二维点与人物左右，用有体积、固定骨长/关节锚点、角度限制与碰撞的三维人体刚体，直接让真实相机下的投影接近图片。需要可视化胶囊/躯干代理及实际关节点，不能仅把预览线段改粗或仅检查一份拟合目标。

本地`web-human-physics-drive.mjs`已经为人体节点建立胶囊/球刚体、质量/惯量、分部位阻尼及原生6DoF约束/碰撞；`web-human-pose-lift.mjs`仍先拟合合法FK三维姿态，产生世界位置/旋转目标，再交给刚体弹簧追随。新方案是更换图像驱动目标，不重新引入另一套引擎，也不把当前实现误称为只有二维线段。

投影残差/相机优化的数学参考为[Ceres重投影误差示例](https://ceres-solver.readthedocs.io/latest/nnls_tutorial.html#bundle-adjustment)；约束动力学参考[MuJoCo计算文档](https://mujoco.readthedocs.io/en/stable/computation/)。这些资料支持问题表述，不是本项目Ammo实现或收益已验证的证据；本轮仍复用已有Ammo，不安装Ceres/MuJoCo。

## spec与L4流程

```text
已有声明 := 原图/原RTMPose二维点及分数/左右语义 + 实际PMX骨架与绑定/当前Ammo胶囊刚体和原生关节 + 分部位质量阻尼估计 + 透视相机/取消代次
新增定义 := 图像目标/原图坐标到相机射线映射 + 关节点投影残差/投影导数/虚拟力预算 + 刚体与PMX双重回读 + 原生锚点/角度/接触误差诊断 + 同初值候选与收敛记录
视角初值 := 固定FOV与人体尺度 → 显式估计有界取景/骨盆支撑深度，保存相机矩阵；不能每步偷偷改变评分缩放去掩盖真正投影误差
空间约束 := 每个2D点对应空间射线 → 点到射线/屏幕投影误差产生虚拟驱动力；不把所有关节拉到图片平面或预填同一z
受力 := 使用实际关节点位置与速度计算误差 → 投影导数将屏幕残差映射为有界世界力 → 在刚体关节点施力产生力矩 → Ammo同一子步求解关节/碰撞/惯性，按部位质量阻尼与分数控制预算
避免双驱动 := 图片拟合期间关闭对应旧3D位置弹簧，不让既有世界目标与二维力争抢；姿态回正力弱化为明确的正则，试验参数统一、记录效果
物理边界 := 固定真实骨长/关节锚点，使用现有原生关节框架/角度范围，保留跨肢体碰撞；不为贴图放宽关节。重力拟合阶段关闭并明确骨盆/深度支撑，有已知座椅/地面后才讨论重力接触，不虚构坐姿支撑物
求解 := 相同初值/相机/预算的有限多候选 → 固定步长逐轮更新 → 记录投影/速度/锚点/限位/碰撞与目标落差 → 达到稳定阈值或预算耗尽 → 保留多解/失败原因
相机 := 姿态趋近后允许有界固定FOV相机匹配/交替迭代；固定身体尺度与根/相机规范，根朝向和镜头多解单列，不称真实镜头唯一恢复
输出 := 读取实际刚体姿态并通过现有父链映射到模型 → 同时检查实际PMX投影与原生刚体投影、锚点/角度和骨长 → 二者不一致保留失败，不拿刚体或target对齐代替显示人物对齐
生命周期 := 独立临时场景/世界，不写用户当前角色目标；换图/取消/超时停止预算与释放Ammo资源；仅正式接入另行确认后挂全身IK，PBD仍屏蔽
```

## 实施范围与任务

拟在忽略目录`tmp/mmd-pose/depth-eval/rigid-projection/`新增`projection-force.mjs`（图像/射线/投影导数与有界驱动）、`rigid-pose-drive.mjs`（复用当前Ammo构造与关节，替换图像驱动）、`run-rigid.cjs`（同三图/同初值实际求解）、`build-report.cjs`（原图/胶囊刚体/实际模型/正侧面/收敛）及必要`check-*.cjs`。仅临时服务器提供独立模块与观察引用；模型、原图、日志不提交Git。本轮不改生产默认、正式物理规则、模型分发/依赖/Offline状态。

- [ ] 确认方案后先验证真实关节绑定、骨长/锚点/角度框架与刚体→PMX映射；现有实际肩臂限位失败不能被新驱动绕开。
- [ ] 构造透视相机合成投影，验证力减小屏幕残差、对目标射线不人为钉深度、关节点力矩/父子受力、正深度/非法输入/力限幅和固定步长。
- [ ] 关闭对应旧3D目标弹簧，加入实际投影反馈、速度阻尼/预算、显式骨盆支撑；复用估计质量/分部位阻尼，不宣称真人生物参数已校准。
- [ ] 同三图/同骨架初值/固定相机策略，用无深度当前方案作历史对照；有限前后屈曲/根转向初值候选，不改RTMPose左右或手工换腿。
- [ ] 直接读回实际刚体和实际PMX，比较直接2D投影/骨长/关节锚点/实际相对限位/碰撞/正侧面，保留初值敏感、未收敛和多解，不能只报屏幕吻合。
- [ ] 报告显示胶囊刚体体积与关节点，分清虚拟力不是照片恢复出的真实受力；测试切图/取消/释放/原始保留/窄屏，记录耗时/子步/速度，手机另验。

## 风险、兼容性与预计工作量

单张图片的前后屈曲、肢体绕轴和全身朝向/相机仍可能多解。碰撞体和角度范围只能排除部分不合理解；没有座椅的坐姿不能靠重力自动解释。当前刚体-显示映射及实际肩臂限位已有失败，需要首先定位，否则二维力可能只让代理对齐、人物仍偏。只作浏览器本地原型，沿用同一角色和现有静态图片流程；旧默认不变，先不下载深度模型。

预计原型1～2天，原生约束框架/映射若需修正另记录具体证据；首阶段检查模块与代理/PMX一致性，再推进图片力。package.json无此临时原型script，复用现有Node/Three/Ammo；不并行重建web-dist。未承诺优于现有方案或真实3D恢复，验收由同图实际正侧与误差/约束共同决定。

## 需求分层（enterprise）

明确性：沿用RTMPose二维、浏览器本地、全身IK入口与三图，用户改变的是还原方法；先临时代理可视化/物理解算，正式接入不在本次确认范围。主L6（图像目标与动力学反馈/输出契约），次L5（预算/多解/失败/释放），必须下放L4。证据：三维刚体替代线段（L6强3）、物理还原二维坐标（L6强3）、既有本地全身IK生命周期（L5强3）；置信度6/9×.9=.60。层级24/25、证据19/20、完备13/20、风险19/20、落地13/15，共88/100。

结论：临时原型可评估，正式开发需补充。输入输出缺图像力单位/射线与相机规范，先合成验证和限幅否则可能发散或钉平；依赖约束缺现有原生框架/显示映射一致性，先查实际锚点与角度否则代理和人物两套结果；验收缺三图收敛/多解与性能，先同初值实际回读和失败证据否则只能得到一张贴合投影。L4拆解见spec；不因技能末尾选项重复询问用户流程选择。

# PMX 旋转缓动固定步进布料同步

## 任务描述

修复 PMX 角色中心枢轴旋转缓动期间布料明显扰动、旋转停止后才逐渐恢复的问题。现有逐渲染帧刚体同步已经在布料速度/姿态保持上尝试过，但现场仍可复现，因此本任务将枢轴轨迹推进到 Ammo/Bullet 实际固定物理子步边界。

## Design 需求

- 先由用户审阅 docs/superpowers/specs/2026-09-23-pmx-rotation-substep-sync-design.md；审阅通过后再实现。
- 只作用于启用 Ammo 的 PMX；VRM SpringBone 和不含刚体的 PMX 不改变。
- 物理子步逐个插值 yaw/pitch pivot 姿态，并同步动态刚体姿态及 type=0 运动学骨骼锚点。
- 速度在 pivot 参考系中进行搬运，保留布料自身相对线速度/角速度，并叠加枢轴移动产生的速度；不得通过重置或清零速度消除现象。
- 沿用灯光面板 physicsFps、unitStep、maxStepNum = 3 以及 warmup = 0。
- 不改 Three.js vendor、不更改刚体/约束/重力/风/阻尼，不构建或发布 APK/更新包。

## Spec 伪代码

```text
过程 renderPmxFrame(delta)
  更新中心枢轴缓动目标
  helper.update(delta)
    MMDAnimationHelper 更新动画骨骼及运动学刚体
    PMX 实例固定步进驱动累计 delta
    对每个真实固定子步
      在上一个已模拟枢轴与当前枢轴之间插值 pivot
      按相邻 pivot 增量变换动态刚体位置/姿态
      线速度/角速度 = 旋转后的 pivot 相对速度 + 新 pivot 参考系速度
      运动学锚点从插值后的骨骼更新
      执行一次 Bullet 固定步进
    恢复当前渲染 pivot
    按当前物理状态回写动态骨骼
  渲染场景
```

## 自测用例

1. yaw/pitch 单向缓动、反向快速旋转过程中布料不会爆散，停止后不依靠重置恢复。
2. physicsFps 为 30、65、90 时固定步进数量与时间余数符合设置，最大补算数不超过 3。
3. 渲染帧需补算多个子步时，运动学锚点和动态刚体使用相同的插值 pivot。
4. 首个物理步仍在模型显示后的下一渲染帧；warmup 为 0。
5. 播放 VMD 及普通无物理 PMX、VRM 行为不回归。

## 兼容性、性能与风险

- 兼容范围：Three.js r160 MMDPhysics、当前 Ammo WASM、PMX；不更改 VRM 与 Offline APK。
- 性能：每次 Bullet 子步最多遍历一次 PMX 刚体列表，最多 3 步；需避免每个子步创建未释放 Ammo 对象。
- 风险：依赖 MMDPhysics 私有 _stepSimulation 与 Bullet 单步入口；实施前核对 API 和资源所有权。若无法安全包装，停下重新评审。
- 边界：内置 Ammo 未暴露 JavaScript callback 函数表注册，因此使用每次一个恒定 unitStep 的 world.stepSimulation(unitStep, 0)；Bullet 每次调用后会清除累计力。当前 PMX 显示代码无显式施力调用，仅由 Bullet 每步施加世界重力；后续增加外力时需重新处理跨子步力保持。
- 验证限制：当前未获用户要求运行测试；实现后只做允许的静态语法/差异检查，行为验收需按手动场景确认。

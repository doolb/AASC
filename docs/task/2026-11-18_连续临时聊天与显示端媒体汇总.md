# 连续临时聊天与显示端媒体汇总

- 任务：临时消息连续显示和进入上下文；显示端各媒体来源汇总、媒体卡片按比例铺图。
- 设计：参见 `docs/design/display-voice-conversation.md`、`docs/design/display-ui.md`。
- 实现：按对应 spec 保留旧历史与内部来源标识，维持语音超时、角色、播放和安全校验。
- 影响：聊天服务与控制端、显示端媒体库 HTML/CSS/JS、自测与文档；网页和服务包受影响。
- 自测：旧消息合并、清空、角色切换、重连和上下文限制；多来源同名目录、单源失败、迟到响应、播放、批量、封面及横竖屏。
- 兼容性：保留既有 WebSocket 消息字段和内部分组 ID，旧数据可读取，沿用本机访问限制。
- 性能：来源并发读取；图片懒加载，视频仅获取元数据；上下文仍按现有预算限制。
- 风险：慢来源可能延迟汇总；远程封面可能与实际视频比例不同；真实设备待验收。
- 预计工时：约 6 小时；未明确事项：无。

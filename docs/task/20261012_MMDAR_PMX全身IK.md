# 2026-10-12：独立 MMD-AR PMX 全身 IK

## 任务描述与授权

用户询问 MMD-AR 是否可以接入 PMX，并已确认实施方案：在独立 MMD-AR PMX 模型上提供头部、左右手腕、左右脚踝的可拖动 3D 控制点；用 PMX 骨骼链限位求解，并保留现有原生 IK、动作、手部避让和物理流程。

需求分级：主等级 L6（控制器、骨骼链和帧钩子契约），次等级 L5（启停、拖动、重置和生命周期）；结论可开发，置信度0.74（中），直接开发风险中。评分：层级清晰度24/25、证据充分度18/20、实现完备度18/20、风险暴露度17/20、L4可落地性14/15，总分91/100。证据明细：[L6|强] 用户确认头/手/脚目标和受限PMX链求解；[L6|强] 项目已有PMX语义绑定、刚体驱动标记与IK link范围；[L6|强] 已有原生IK/grant之后、物理之前的Human回调和手臂避让；[L5|中] 面板启停、拖动和重置形成清晰状态流程。置信度按主等级证据9/全部证据11×邻层一致系数0.90计算。L4将数据流拆为当前帧基础姿态→控制目标→限位CCD→手部避让→原物理。主要风险为模型骨骼命名/拓扑不齐、目标不可达及多末端求解帧时；不承诺 VaM 等价或任意模型完全贴合。

## 自测用例设计

1. 具备标准日文语义名与英文别名的 PMX：启停、五末端标记、拖动和重置；拖动过程中不触发点击注视或相机旋转。
2. 缺头/腕/踝、非祖先链、刚体驱动链节、PMX IK范围及不可达目标：限制结果并提供清楚状态，不产生 NaN 或旋转累积。
3. VMD播放/暂停、原生IK/grant、手臂避让、Ammo/XPBD、模型切换、helper重建、后台/编辑阻断、销毁：原帧顺序、基础动作与资源释放保持。
4. 5个末端的固定迭代上限和有限骨链；普通动画帧无新增射线/碰撞扫描，拖动控制点外不创建额外 RAF。

## 兼容性测试

- 日文标准 PMX 与英文骨骼别名；缺少一个或多个语义末端的 PMX 应降级可用。
- 桌面鼠标、触屏/触控笔、相机旋转与舞台旋转映射；不支持 pointer capture 时用取消事件清理拖动。
- Ammo、XPBD 和物理关闭；VMD运行/暂停、动作遮罩及原 Human/MPL层。
- 验收不扩展到 VRM、VAM、GLB 或正式显示端。

## 性能测试

- 测量默认关闭与启用时每帧开销；固定最多五末端，每末端限定迭代次数与骨链长度。
- 验证普通帧不做射线求交、不刷新远端资源、不增加 RAF；拖动事件只唤醒既有渲染循环。
- 真实手机帧时作为后续设备验收，不从桌面构建结果外推。

## 风险评估与预计工时

- PMX语义映射可能匹配不到、映射歧义或骨链不符合人体拓扑；按已绑定的模型骨骼及祖先链检查，缺失链不求解。
- 约束角度的旋转顺序因PMX约束表达和模型基准姿态不同而有差异；首先遵从原生 IK link 范围，再限制每帧总修正，显示受限/不可达提示。
- 多个目标共用躯干骨骼可能互相影响；每帧固定顺序与迭代上限，重置从当前原动作重新开始。
- 预计约 1–2 个开发日，含实现、界面、构建与源码静态检查；不含真机观感/性能验收、APK构建、外网发布。

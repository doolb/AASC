# MindAR Basic 旋转和平移抗漂移

- 需求：用户确认同时处理旋转和平移漂移，保持 IMU/视觉融合方案。
- design/spec：mindar-basic-web 对应抗漂移章节与伪代码已更新。
- 实现：持续时间校准、双零偏估计、陀螺仪迟滞死区和轻量低通、视觉＋传感器静止归零/在线零偏、断流重置、原始/校正后诊断。
- 修改：mind-basic-imu.js、mind-basic.js、index.html；更新算法/浏览器测试和相关文档。
- 测试场景：短突发不允许完成校准、10 秒静止噪声不累计旋转和位置、慢转/快转响应、两类零偏补偿、视觉运动与无视觉不归零、断流清除记忆，原有融合/可信度/拍照流程回归。
- 兼容/性能：不切换传感器接口；保留屏幕方向换轴，原始视频不变，无新轮询循环；每次样本仅短向量运算，校准窗口完成前统计。真机帧率未测量。
- 风险：阈值是实验值，极慢运动可能落入死区；没有视觉时无法可靠辨认静止和匀速移动。未实现硬件时间同步。
- 预计工时：约 45 分钟。发布：尚未发布。

- 本地回归结果：31/31 通过；浏览器校准采用受控时间，未做真机漂移/性能验收。

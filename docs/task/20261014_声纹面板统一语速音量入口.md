# 声纹面板统一语速和音量入口

## 任务描述

将声纹面板“语音服务与音色”里的 Provider 专属默认语速和音量合并为一组全局设置，覆盖 AI/Agent 回复、文本阅读、系统播报和全部 TTS Provider。

## Design 需求

- 面板只显示一个语速输入（-10 至 10）和一个音量输入（0 至 100）。
- Provider、业务及模板的音色选择，以及 Provider 的启用和模型设置保持独立。
- 单次合成显式传入的语速或音量优先于全局默认值。
- 豆包网页朗读上游继续使用固定 1 倍速和 100% 音量，生成 WAV 后由本地处理应用全局值。
- 复用现有 WebSocket 权威配置流程，不增加 HTTP 配置端点。

## Spec 设计

- 在权威 TTS 配置快照根级定义 `defaultSpeed/defaultVolume`，主配置持久化到 `config.tts.sharedParameters`，分别校验到 -10..10 和 0..100。
- 首次迁移使用当前 `aiReplyDefault` Provider 的旧默认语速和音量；缺少旧值时使用 0/100。system 语速沿用原 `config.tts.defaultSpeed`。
- `config.set` 保存全局参数和业务选择，用户配置保存 Provider 服务偏好；保存失败回滚另一侧并广播旧权威快照。
- Provider 配置快照移除 Provider 专属默认参数，保留原有凭证脱敏、模型和音色行为。

## 自测用例

1. 面板中语速和音量控件各只有一个，显示范围和默认值正确。
2. 旧配置迁移使用 AI/Agent 默认 Provider 的旧值；无旧值回退 0/100；system 旧语速可保留。
3. 保存后控制端收到规范化权威值，其他控制端和重连快照显示相同全局值。
4. 语速/音量越界按现有数字规范化规则限制，非法非有限值拒绝并回传旧配置。
5. 多 Provider、多业务均消费全局默认值；单次显式参数优先；业务选择和音色继承不变。
6. 豆包网页朗读仍向上游发送固定参数，返回 WAV 再应用共享语速和音量。
7. 两侧配置任一保存失败时回滚成功侧，不广播未持久化的新值。

## 性能测试

- 不增加依赖和网络往返；常规 Provider 沿用现有参数路径。
- 豆包网页朗读仅增加现有 WAV 调整步骤，检查处理耗时、输出大小上限和缓存输入有效性。

## 风险评估

- 不同 Provider 原先参数可能不同；迁移仅以当前 AI/Agent 默认 Provider 的旧值初始化共享参数，其余旧值不再作为运行默认。
- 豆包网页朗读上游固定参数，需确认 WAV 后处理覆盖全局语速和音量；本地变速会改变音高。
- 主配置与用户配置需要保持事务式回滚，失败时不得广播部分成功状态。

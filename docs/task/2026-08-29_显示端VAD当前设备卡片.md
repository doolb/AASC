# 显示端 VAD 当前设备卡片

## 任务描述

将 VAD 独立卡片从同时展示所有显示端改为只展示当前选中的显示端，降低控制端配置区域的信息量。

## design 需求

- 卡片读取 `window.currentDisplayId`，只显示当前在线设备。
- 未选中设备或选中设备已离线时显示提示，不显示其他设备的 VAD 控件。
- 切换当前显示端后卡片自动刷新，阈值和底噪检测协议不变。

## spec 设计

- `DeviceList.renderVoiceVadPanel()` 使用当前选中 ID 查找一个显示端。
- 当前设备存在时复用 `renderVoiceVadCardHtml(display)`；不存在时写入空状态提示。
- `DeviceList.render()` 在设备选择、设备列表更新和 VAD 回包后刷新卡片。

## 自测用例

1. 多个显示端在线时卡片只出现当前选中的显示端。
2. 未选中或当前设备离线时显示提示。
3. 切换显示端后阈值、检测结果和按钮目标同步切换。
4. 设置阈值、底噪检测和应用建议仍发送当前显示端 ID。

## 兼容性测试

- 不改变 `setVoiceVad`、`detectVoiceNoise`、`voiceVadConfig` 和 `voiceVadNoiseResult` 协议。
- 设备列表监听开关、最近识别和显示端选择行为保持不变。

## 性能测试

- 卡片每次只生成一个设备卡片，不再为全部在线设备生成 DOM。

## 风险评估

- 当前选中设备离线后需要及时清空卡片，由设备列表更新和选择逻辑统一触发渲染。

## 预计工时

- 预计 15 分钟。

## 实际完成

- VAD 卡片现在只读取 `window.currentDisplayId`，只显示当前选中的在线显示端。
- 无选中设备或当前设备离线时显示明确提示；切换设备后自动刷新阈值、检测结果和操作目标。
- 自测：VAD 配置布局契约、设备列表监听状态回归、脚本语法检查和 `git diff --check` 通过。

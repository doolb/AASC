# 显示端控制页面重构任务

## 任务概述

重构显示端控制页面，实现播放命令、通用时间解析、天气语音播报、自定义指令持久化等功能。

## 任务状态：✅ 已完成

## 设计需求

参考：[design/display-control-refactor.md](../design/display-control-refactor.md)

## 功能列表

### 1. ✅ 通用时间解析功能
- 支持"今天"、"明天"、"后天"等相对日期
- 支持"X秒/分钟/小时/天/周/月/年前/后"等相对时间
- 支持"X月X日"、"X年X月X日"等绝对日期
- 支持中文数字和阿拉伯数字混合
- 返回时间戳和描述文本

### 2. ✅ 播放命令功能
- 指令格式：`播放{文件名}`
- 搜索所有媒体库中的文件
- 无匹配时提示用户
- 单个匹配时直接播放
- 多个匹配时让用户选择

### 3. ✅ 天气语音播报
- 天气查询成功后自动生成 TTS
- 发送到显示端或控制端播放
- 同时显示文本内容

### 4. ✅ 自定义指令持久化
- 保存到 `config/chat-commands.json`
- 服务启动时加载
- 支持添加、修改、删除

### 5. ✅ 浮动控制面板
- 固定在页面右下角
- 可展开/收起
- 显示常用控制功能
- 状态持久化到 localStorage

## 自测用例

### 时间解析测试
1. 输入"今天" → 返回今天 0 点的时间戳
2. 输入"明天下午3点" → 返回明天 15:00 的时间戳
3. 输入"3天后" → 返回 3 天后的时间戳
4. 输入"十分钟后" → 返回 10 分钟后的时间戳
5. 输入"3月15日" → 返回今年 3 月 15 日的时间戳

### 播放命令测试
1. 输入"播放不存在的文件" → 提示"未找到文件"
2. 输入"播放唯一文件名" → 直接播放
3. 输入"播放重复文件名" → 列出选项让用户选择

### 天气播报测试
1. 查询天气 → 自动播放语音结果
2. 无显示端时 → 在控制端播放

### 自定义指令测试
1. 添加自定义指令 → 保存到文件
2. 重启服务 → 指令仍然存在
3. 删除自定义指令 → 从文件中移除

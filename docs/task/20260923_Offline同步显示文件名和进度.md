# Offline 同步显示文件名和进度

## 任务描述

同步外网 Offline 资源时显示正在下载的文件名、当前文件进度和整体下载进度，方便观察大文件传输状态。

## Design 需求

- 使用已校验清单中的资源大小计算单文件和总进度。
- 显示资源相对路径、已接收/总字节数及百分比。
- 单文件和总进度均按字节加权；完整 APK 仍不参与同步。
- 交互终端节流刷新当前行；非交互日志按百分比节点节流输出。
- 下载大小/SHA-256 校验、原子清单替换、安全清理行为不变。

## Spec 设计

先更新 `docs/spec/android-offline-hot-update.md` 中 `syncOfflineUpdate` 伪代码，再实现下载进度回调与命令行显示。

## 受影响的功能模块和文件

- `scripts/ops/sync-offline-update.js`：流式下载进度与 CLI 输出。
- `docs/design/android-offline-hot-update.md`：同步进度需求。
- `docs/spec/android-offline-hot-update.md`：同步流程伪代码。
- `docs/usage.md`：命令行显示说明。
- `changelog.md`：变更记录。

## 自测用例

- code、dependencies、min APK、data-repair 逐项显示相对文件名和单项百分比。
- 总进度按所有选中资源总字节数计算，下载完成后到达 100%。
- 非交互环境输出节流，避免每个数据块都输出一行。
- 原有大小/SHA-256 失败仍中止，且不提前切换 manifest。
- `--skip-signature-verification` 的安全告警和同步参数行为不变。

## 兼容性与性能

- 仅增加下载进度回调与 CLI 输出，不改变脚本参数或清单协议。
- TTY 输出按时间节流；日志按百分比节点节流，避免高频 I/O。

## 风险评估

进度基于清单声明大小；实际下载超出大小仍立即失败，最终字节数或 SHA-256 不一致仍不会安装资源或切换清单。

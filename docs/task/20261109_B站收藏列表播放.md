# B 站收藏列表播放

- 需求：支持用户提供的 `list/ml` 列表，能加入分类、直接播放和随分类批量播放。
- 设计与实现：见 `docs/design/batch-playlist.md`、`docs/spec/batch-playlist.md`；每次播放分页读取公开收藏列表，展开分集，复用现有 DASH 与播放列表控制。
- 影响：B 站列表服务、控制端输入和播放请求、服务端列表生成。
- 自测：链接规范化、分类、分页、分集、接口失败和 500 项上限；浏览器加入/播放及现有 B 站回归。
- 性能与风险：只获取收藏夹元数据，视频播放地址按需解析；列表超过 500 项明确报错。依赖 B 站匿名接口与公开权限。
- 预计工时：半天。

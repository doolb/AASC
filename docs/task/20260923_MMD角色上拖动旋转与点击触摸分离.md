# MMD 角色上拖动旋转与点击触摸分离

## 任务描述

当前 MMD Canvas 仅从空白区域按下才能旋转角色；从角色网格按下只保留触摸候选。调整为角色上也能开始拖动，只有未达到拖动阈值的点击才触发角色触摸。

## Design 需求

- PMX 与 VRM 都可从角色或空白处开始拖动旋转，沿用当前方向、灵敏度和 8 像素启动阈值。
- 角色上按下时先保留触摸候选，不立即发送互动；达到拖动阈值后清除候选。
- `pointerup` 才能触发点击触摸；已旋转或 `pointercancel` 不发送 `mmd.interaction`。
- 指针捕获保证拖出 Canvas 仍能完成旋转，不改变聊天控件的事件路由。

## Spec 设计

见 `docs/spec/display-chat-mmd.md` 的 `handleMmdPointerDown`、`handleMmdPointerMove`、`handleMmdPointerUpOrCancel` 伪代码。统一维护当前指针的旋转拖动状态，触摸候选只记录命中角色的按下事件。

## 受影响模块和代码

- `src/apps/web-mediacenter/ui/public/js/display-mmd.js`：统一指针按下、移动、抬起和取消的手势判定。
- `tests/display-chat-mmd.test.js`：指针手势回归。
- `docs/design/display-chat-mmd.md`、`docs/spec/display-chat-mmd.md`、`docs/usage.md`、`docs/self-test.md`、`docs/todo.md`、`changelog.md`。

## 自测用例

- 角色上按下并移动至少 8 像素：只旋转，松开不触摸。
- 角色上按下并小幅移动后松开：只触摸，不旋转。
- 空白处拖动：旋转且不触摸。
- 角色上拖动后取消、隐藏或关闭交互：不触摸，清理拖动状态。

## 兼容性测试

- PMX/VRM runtime 旋转入口保持不变；Canvas 占位角色无 3D 旋转能力时不触发伪旋转。
- 聊天层控件和 MMD 隐藏状态不接收新增手势。

## 性能测试

- 每个指针事件仍只进行一次命中检查或固定次数的位移计算；运行 MMD 定向测试和 `npm test`。

## 风险评估

- 8 像素阈值附近可能出现用户预期分歧，需在触屏现场检查误触和拖动手感。

# 显示端补光源设置

- 日期：2026-09-23
- 状态：代码与自动化测试已完成，待真实 PMX/VRM 视觉验收

## 任务描述与设计需求

在现有显示端灯光面板加入独立补光源，支持开关、颜色、强度、经纬度方向；默认关闭且始终不投射阴影。保持主光阴影、AO、旧 localStorage 配置及预设行为。仅作用当前浏览器显示端，不新增远端配置和 APK 资源。

## Spec 设计与受影响模块

先更新 `docs/spec/mmd-pmx-vmd-local.md` 的默认值、规范化和渲染伪代码。修改 `display.html`、`display-mmd-lighting.js`、`display-mmd.js`、`display-pmx-runtime.js`、`display-vrm-runtime.js`；两个 runtime 各自创建无阴影方向光，按模型中心定位，面板通过既有 `setLighting` 和 localStorage 驱动。

## 自测与兼容性

- 自动测试：默认关闭；异常颜色/强度/方向规范化；面板字段齐全；PMX/VRM 补光不投影。
- 兼容性：旧保存配置缺失补光字段时维持旧画面；亮度预设保留当前补光值；恢复默认关闭补光。
- 现场测试：实际 PMX/VRM 调整补光、切换模型、打开/关闭主光阴影、重新加载页面。

## 性能与风险

补光关闭时第三盏方向光强度为零；开启增加一盏非投影方向光的着色开销，不分配额外阴影贴图。真实模型材质对补光响应及移动 WebView 帧率需现场验证。

约 2 小时，现场视觉验收另计。

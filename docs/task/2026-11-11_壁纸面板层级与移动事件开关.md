# 壁纸面板层级与内容交互开关

- 任务：壁纸面板置于网页普通内容最上层，增加面板以外内容交互的开关。
- 设计：开关默认开启并本机保存；关闭时屏蔽面板以外的触摸和鼠标交互，保留面板操作；桌面决定是否提供触摸事件。
- 伪代码：参考 `docs/spec/display-wallpaper-controls.md` 的面板和内容交互流程。
- 影响：显示页、壁纸控件样式与脚本、浏览器自测、服务更新包。
- 自测：覆盖层级、开关前后内容交互、面板点击和拖动、偏好恢复及前台不受影响。
- 兼容性：检查 pointer、touch、mouse 事件；Android 系统桌面触摸和 WebView 需真机验收。
- 性能：事件处理只做状态和目标检查，不引入定时器或额外渲染。
- 风险：系统桌面可能不提供移动事件，浏览器顶层元素及系统窗口的层级不受网页控制。
- 预计工时：约 1 小时。

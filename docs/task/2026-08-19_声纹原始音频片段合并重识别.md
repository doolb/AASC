# 声纹原始音频片段合并重识别

## 任务描述

声纹分段后直接对每个短片段 ASR，可能因分段边界导致文本内容丢失。需要先识别每段 speaker，再把同一 speaker 的相邻原始 PCM 区间合并，最后重新识别完整音频。

## Design 需求

- 合并原始 PCM 区间，不拼接已有识别文本。
- 先按 pyannote 的 `speakerIndex` 合并，再对完整原始区间做声纹匹配；随后把匹配到同一 speaker 名的原始区间再次合并，短于 1 秒的未匹配间隔可跨越，较长未知区间不跨越。
- 同一 speaker 的相邻区间合并后只执行一次 ASR。
- 保留 start/end/speaker 返回字段，兼容现有服务器和控制端协议。

## Spec 设计

```text
VoiceprintEngine.diarize → diarizedSegments(speakerIndex)
mergeBySpeakerIndex → raw PCM ranges
for range: extract/match → matchedRanges
mergeMatchedSpeakerRanges → raw PCM ranges
for range: AsrEngine.recognize(mergedSamples)
  return {start, end, text, speaker}
```

## 自测用例

- 同一 speaker 相邻区间合并为一个原始区间。
- 超过 1 秒的未知 speaker 片段阻断前后两个相同 speaker 区间的合并。
- 不同 speaker 不合并。
- 编译 APK，并用已注册声纹 WAV 回归识别。

## 风险评估

- 只改变 APK 多人声纹路径的切片与 ASR时机，不改变单段声纹匹配和声纹库。
- 合并区间可能包含同一 speaker 的短停顿，但能减少分段边界截断；超过 1 秒的未知 speaker 音频不会跨越合并边界。

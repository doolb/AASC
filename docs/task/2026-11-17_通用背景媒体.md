# 通用背景媒体

- 需求：独立播放音频或视频，可与任意主媒体并行；视频画面在主媒体下方。
- 设计和伪代码：见 `docs/design/audio-media.md`、`docs/spec/audio-media.md`。
- 影响：控制端、显示端、媒体库、WebSocket 状态同步和睡眠恢复。
- 自测：音视频选择、播放暂停停止、音量循环、切换主媒体、断线恢复、非法输入、睡眠唤醒。
- 兼容性：旧状态使用停止默认值；旧客户端忽略新增消息。
- 性能：仅多一个活动媒体元素；避免无变化时重新加载。
- 风险：浏览器自动播放策略、跨域及编码限制可能阻止播放；不透明主媒体遮挡背景画面。
- 预计工时：1 个工作日。

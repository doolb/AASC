# 临时上传视频循环区间修复

日期：2026-10-23。状态：源码与专项回归完成，待刷新显示页/Offline服务包更新后验收。属于原单轨双手柄功能的缺陷修正。

## 任务描述与design需求

临时模式上传的视频无法设置循环区间；临时视频和普通视频应同样支持单轨双手柄，加载后即提供时长，暂停时也可编辑。

根因：`display.html` 的URL视频分支设置了 `ontimeupdate`，Base64视频分支没有设置；首次播放临时视频不会上报 `videoProgress`。之前的测试直接加载底层循环模块，未覆盖正式页面临时上传链路。

- 修改 `src/apps/web-mediacenter/ui/public/display.html`：提取统一上报函数，持久监听两个媒体元素，删除分支内的重复监听和清理语句。

## 自测用例、兼容性与性能

- 真实浏览器首次临时上传视频 → 正式Base64分支 → 有限videoProgress → 双手柄启用 → 设置后播放到结束回跳。
- 暂停加载、普通URL音视频和Base64音频均可获取时长；非活动媒体与未知时长不上报有效进度。
- 仅注册一次监听，不随每次加载重复添加；每个媒体事件只发送一条进度，无额外轮询或高频远端seek。

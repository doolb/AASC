# 控制端右侧空白背景拖动滚动

## 任务状态：✅ 已完成

## 任务描述

为控制端右侧内容区域增加类似移动端的按住拖动页面滚动交互，限定在右侧 content 空白背景，避免影响面板内部控件。

## Design 需求

参考：design/control.md（控制端页面布局）。

- 仅 .content 元素自身作为 pointerdown 目标时启动拖动。
- 拖动过程中根据垂直位移更新 window.scrollY。
- panel、section、按钮、表单控件、图片、视频、iframe 等内容不启动拖动。
- 移动超过 6px 才进入拖动状态，普通点击不改变页面。
- 拖动结束后清理状态并恢复普通光标。

## Spec 设计

参考：spec/sidebar.md（右侧内容区拖动滚动）。

    初始化右侧内容区:
        获取 .content
        pointerdown 目标不是 .content 时直接忽略
        记录指针位置和 window.scrollY
        pointermove 超过阈值后更新 window.scrollTo
        pointerup/pointercancel 清理拖动状态

## 自测用例

1. 在右侧 .content 空白背景按住鼠标上下拖动，页面随之滚动。
2. 在 .panel/.section 空白区域点击或拖动，不启动右侧页面拖动。
3. 点击按钮、输入框、下拉框、图片、视频、iframe，原有操作不受影响。
4. node --test tests/sidebar-layout.test.js 通过。
5. node --check src/apps/web-mediacenter/ui/public/js/main.js 通过。

## 兼容性测试

- 左侧导航拖动滚动行为保持不变。
- 页面原有滚轮、触控板和触摸滚动行为保持不变。
- 右侧拖动不改变当前面板和表单状态。

## 性能测试

- 仅在 .content 元素监听 Pointer Events，不增加全局事件监听。
- 拖动只更新 window 滚动位置，不重建面板 DOM。

## 风险评估

- 低：启动条件限定为 content 自身，面板内部交互不会被接管。
- 页面内容不足一屏时拖动不会产生可见滚动变化。

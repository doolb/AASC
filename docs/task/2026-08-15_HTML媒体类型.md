# 任务：HTML 媒体类型

**日期:** 2026-08-15
**状态:** ✅已完成

## 任务描述

新增 `html` 媒体类型：媒体库识别 .html 文件、支持粘贴 HTML 代码发送，显示端以 iframe 全屏纯展示（不可交互），支持分页式/平滑/循环三种自动滚动模式。

## Design 需求

详见 `docs/design/html-media.md`（2026-08-15 已批准）：
- 媒体类型识别：服务端与上传端 `.html/.htm` → 'html'
- 三个发送入口：媒体库文件、工具栏粘贴代码（临时/保存媒体库）、裁剪框拖拽
- 滚动模式发送时选择：分页式（3/5/8 秒每屏）/ 平滑（慢/中/快）/ 循环（平滑滚到底回顶）
- 显示端 iframe 铺满、pointer-events: none、不加 sandbox（同源控制滚动）
- 批量播放 html 项用默认滚动参数（分页 5 秒），像图片一样按间隔切换

## Spec 设计

- `docs/spec/media-library.md`：detectMediaType 加 html；playMedia html 分支伪代码
- `docs/spec/batch-playlist.md`：MEDIA_TYPES 加 'html'

## 自测用例

1. 媒体库上传长页面 test.html（超一屏、含 JS 动画），点击发送 → 弹滚动设置框 → 分页式 3 秒 → 显示端 iframe 铺满，每 3 秒滚一屏到底停止
2. 平滑（快）/ 循环模式分别验证匀速滚动到底停止、滚到底回顶循环
3. 短页面（不足一屏）发送后静态显示不滚动
4. 裁剪框拖入 .html 文件：弹滚动设置框，确认后临时模式发送，裁剪预览区无图片/视频
5. 工具栏「发送 HTML」：粘贴含中文与 data: 图片代码 → 临时发送渲染正确；勾选「同时保存到媒体库」→ 媒体库出现 粘贴代码_*.html 且按 url 发送
6. 批量播放含 html 文件夹：按间隔切换、默认分页 5 秒滚动；暂停滚动冻结、恢复继续
7. 回归：图片/视频/gif 发送、裁剪、批量播放行为不变
8. 显示端刷新后临时 html 占位提示不异常

## 兼容性测试

- 现有 image/video/gif 识别与发送链路不受影响（node --test 9 项全通过）
- 批量播放现有逻辑（视频 ended 等待、图片间隔）不回归

## 性能测试

- 滚动控制器 rAF 时间步进，无滚动时无定时器残留；切换/停止/暂停均清理 timer/rAF
- iframe 内容不溢出时直接返回，零开销

## 风险评估

- iframe 同源信任：不加 sandbox 以保证滚动控制，媒体库文件与粘贴代码均来自用户本人
- srcdoc 粘贴代码相对资源失效：约定自包含（data: 内联）
- base64 消息体积：常规代码无影响（WebSocket 500MB 上限内）

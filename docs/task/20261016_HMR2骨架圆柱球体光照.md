# HMR2.0b 报告骨架圆柱、球体与光照

日期：2026-10-16。状态：已完成。

## 任务描述与设计需求

用户指出HMR2.0b坐姿识别仍不正确，希望报告里的骨骼连线显示为圆柱、关节点显示为球，并加光照。用户确认不需要投影阴影。仅改善独立测试报告的3D可读性；真人抬高膝的左腿归属仍按原始模型数据展示，二维叠点、相机、VAM和MediaPipe默认入口不变。设计见`docs/design/mmd-human-interface.md`。

## Spec设计与受影响代码

伪代码见`docs/spec/mmd-human-interface.md`。`tmp/mmd-pose/depth-eval/hmr2-sam3d/report.mjs`从已有本地网页构建加载Three.js，用24个圆柱连接BODY25关节、25个球表示关节点，左蓝、右橙、中轴浅色；一盏环境光和两盏方向光只产生曲面明暗。拖动旋转、双击复位；切图复用渲染器与几何体，仅替换骨架网格。WebGL不可用时用原2D线条绘制。`report.html`更新图注及识别偏差说明，`check-report.cjs`验证真实三图渲染和交互。三份报告源码选择性加入Git，模型、私人图片、推理输出和截图保持忽略。

## 自测、兼容性与性能

测试先在旧线条实现上因缺少WebGL网格而失败。实现后在Edge检查三图各24骨段/25关节、三盏灯、未启用投影阴影、拖动前后画面变化、双击复位、390px无溢出、本机GET且无脚本错误；模拟WebGL不可用时仍显示线条。截图目视检查真人、动漫、示意图及移动宽度的颜色和曲面明暗。仅重建切换样图时的网格，拖动只更新组旋转；单个420×420 WebGL画布，未新增模型下载或网页推理。手机真机和长时间GPU性能未验。

## 风险评估与预计工时

Three.js本地模块由既有网页构建提供；若模块缺失或WebGL不可用，报告回退线条。光照可能让错误姿态更易看清，但不能使预测关节变正确；报告需持续显示坐姿左右腿失败说明。仅本机独立报告，不影响Offline打包状态。预计约1–2小时。

## 完成结果

三图真实HMR2.0b结果、WebGL受光球柱、交互复位、WebGL失效回退和390px布局均经Edge检查通过，每图24骨段/25关节。未加投影阴影；原图二维叠点和模型JSON未改。正式IK继续使用MediaPipe，HMR2.0b的坐姿腿部误判仍未解决。

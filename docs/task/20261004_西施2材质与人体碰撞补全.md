# 西施2材质与人体碰撞补全

## 需求与方案


## 西施2材质与人体碰撞补全（2026-10-04）

西施2运行时按材质名称复用静态西施GLB的完整PBR材质，包括法线、金属粗糙度、透明和发光；保留PMX骨骼、UV、权重与物理。加载材质失败时整次加载失败，不静默显示失真材质。PMX单独导出仍是经典材质，完整外观依赖网页资源清单中的同源GLB。修正MMD Tools已翻转面索引后导出器又重复翻转的问题。

胸腹髋由盒体改为横向胶囊，尺寸按西施2身体截面拟合；补齐双手手掌、30个指节胶囊及肩/肘/腕/膝/踝共10个关节球。全部为跟随骨骼的静态碰撞体，与动态衣物碰撞，布料链的质量、弹簧和关节范围不变。刚体共159个。

## 受影响文件

- xishi2-pmx.py、xishi2-parts.py：导出面朝向和碰撞体。
- web-xishi2-materials.mjs、web-xishi2-build.js、web-characters-build.js：复用源材质、版本和构建加载接入。

## 验证计划

同相机同灯光浏览器截图对照；材质类型/贴图检查；159刚体结构审计；Ammo与XPBD动作、有限顶点和脚本错误检查。

## 兼容性、性能与风险

只影响独立mmd-ar的西施2；PBR效果与静态版一致，PMX专属Toon/高光等材质开关不控制该角色。复用已发布静态GLB，初次加载增加一次材质源读取，替换后释放旧材质和额外几何。仍需实机长测；袖片权重与穿插属于已有待调项目。本轮不发布、不提交。预计本轮完成导出及桌面短测。

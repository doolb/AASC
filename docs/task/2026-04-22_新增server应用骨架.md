# 新增 server 应用骨架任务

## 任务描述

- 目标：在 `src/apps/` 下新增 `server` 应用文件夹，支持后续独立服务型程序扩展。
- 范围：先建立目录骨架与文档，不修改现有运行流程。

## design 需求

- 在分层设计中明确多应用结构，补充 `server` 定位。
- 保持 `web-mediacenter` 与 `server` 并行，不互相耦合。

## spec 设计

- 增加 `StartServerApp` 启动伪代码。
- 说明 `server` 通过 External 层聚合外部能力。

## 受影响模块与文件

- `src/apps/server/README.md`
- `src/apps/server/bootstrap/README.md`
- `src/apps/server/modules/README.md`
- `src/apps/server/api/README.md`
- `src/README.md`
- `docs/design/layered-architecture.md`
- `docs/spec/layered-architecture.md`

## 自测用例

1. 检查 `src/apps/server/` 是否存在。
2. 检查其下是否包含 `bootstrap`、`modules`、`api` 目录说明文件。
3. 检查 design/spec 是否补充了该应用定位与启动伪代码。

## 兼容性测试

1. 不调整现有 `web-mediacenter` 运行入口。
2. 不影响现有 AASC 消息总线行为。

## 性能测试

1. 本次仅目录和文档变更，无运行时性能影响。

## 风险评估

- 风险：多应用并行后边界不清导致模块跨层引用。
- 缓解：在分层文档中明确依赖规则并保持应用目录独立。

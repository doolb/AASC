# MMD AR 跨Hz布料手感与小物件抖动

- 日期：2026-09-30；状态：已完成实现/构建/自测，现场模型观感待验收；未发布外网。
- 需求：继续Ammo，减小不同Hz响应差异与静止小物件抖动，保持180Hz上限与当前切换/循环语义；不要求有限步长的布料手感完全相同。用户使用本地web-dist、180Hz，关闭动作和停止旋转仍抖；实际PMX及部位尚未补充。
- design：`docs/design/mmd-ar-test-apk.md`同名章节，区分低频时间丢失、type2帧末位置回位与每步关节纠错。睡眠/接触/低惯量是影响因素，不认定某个为手机唯一根因。
- spec：`docs/spec/mmd-ar-test-apk.md`同名伪代码及`docs/spec/self-test.md`稳定性验证。已先更新伪代码，再实现。
- 受影响代码：`3rd/mmd-ar-test/build.js`、`web-physics-rate.mjs`、`web-physics-substeps.js`；新增`web-physics-stability.js`。只适配WEB_MODE物理副本，正式vendor/显示端/APK与Offline产物标记保持。
- 实现：全频率预算ceil(Hz乘0.1)加1；ERP为1减0.525的(65除Hz)次方，以65Hz原0.475归一单位时间纠错，只在初始化/变频刷新。仅有骨骼type2屏蔽自由平移力、每子步按目标端点计算线速度，旋转仍动态；取消帧末位置二次回位。受控积分期间跳过线性阻尼，finally恢复，旋转阻尼保持。无骨骼type2与type1自由动态；type0仍使用MotionState插值。
- 保持：PMX质量/角惯量/弹簧和10迭代；换模型/动作绑定姿态初始化清零与首两帧门控，循环/变频/后台历史同步不新增通用清零。池缓存复用、异常归还及销毁native归零。
- 自测代码：新增`tests/mmd-ar-physics-stability.test.js`9项，更新频率/子步/生命周期/动作切换及本地资源夹具，使测试接入同一稳定性补丁、65Hz预算8。实际PMX资源缺失时仅跳过PMX对照；其他真实WASM用例仍运行。
- 自测用例：30/65/90/120/180Hz与10/30/60/90/120/144FPS的一秒恒速不丢时间；关节六轴ERP热更新及0.1秒锁定误差；type2角速度/偏移/父骨骼旋转、动态父骨骼位置跟随、无子步帧、原阻尼1端点驱动、异常阻尼/池恢复；64轮受控刚体销毁和128轮生命周期释放。
- 真实PMX对照：米娅183刚体/261关节、60FPS、无VMD静止8秒末1秒15个小质量刚体角速度RMS(rad/s)，基线/修复：30Hz 1.958293/0.165598、65Hz 1.514808/0.063439、90Hz 0.653841/0.025390、120Hz 0.558105/0.084257、180Hz 0.315354/0.094321。180Hz约降低70%，其他Hz也降低；仅该模型/窗口结论。
- 兼容性：定向首批82加补充角冲量1项通过；实际浏览器3/3通过，已完成24次动作/4次模型切换、播放/暂停继承动作、两帧门控、变频不重建、存储480钳制180和native回收，约576秒创建32/销毁31/存活1、64MiB堆，探针跨度3227080字节，无OOM/页面异常。
- 性能：不增求解迭代；每渲染帧采目标，子步复用Three/Ammo临时值，预热后池不增长；仅在步进区间暂改受控平移阻尼。82项含多浏览器用例耗时约169秒；具体手机CPU、帧率和大PMX观感待验收。
- 风险：旧6DoF弹簧的数值响应仍随步长/迭代变化，ERP归一不能保证所有频率相同；动态父骨骼按帧前目标采样，最多一画面帧位置延迟；低惯量/接触/极端参数仍可能抖动，不强制睡眠、增质量或清零掩盖。
- 预计工时：实现与定向回归约1小时，另需真实浏览器压力/手机验收。
- 需求分级：沿用默认enterprise，主L6、次L5；邻层一致0.90、置信度0.675，95/100。L4下放为时钟预算、关节纠错、type2驱动及验证四模块。使用需求分析技能，未新增代理分工。

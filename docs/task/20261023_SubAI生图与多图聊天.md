# SubAI生图与多图聊天

状态：已完成实现和定向验证。

需求/design：两端独立生图Provider与模型；主AI调用SubAI,生图标签；任务分流；图片组占位与全部图片持久化。详见chat2api-image-generation设计。
spec：依照对应spec新增CSV解析、图像目录/适配、任务注册/资产、消息更新和远端配置。
影响：chat2api runtime/proxy/adapters、模型服务/picker、game桥、server-app、llm/history、chat/display-chat。
自测：路由、CSV、引用、空结果、失败、一次多图、重连不重发、历史恢复、配置权威广播。
兼容：旧Game及动作、主LLM配置、既有音乐/视频接口；不新增实际system消息。
性能：生成异步不占用聊天TTS；图片体积限制，流式响应有超时与取消。
风险：网页接口变化与安全验证；不伪报成功，不自动重试计费生成。
预计工时：跨模块实现和现场验证约一工作日，按验证结果更新。
现场结果：Qwen已确认snap最终图片与官方SDK上传签名；Android参考图明确返回不支持。已验证GLM/豆包/Qwen文字生图及桌面参考图，多图保存和浏览器展示。
测试：test:chat-images 21项、test:chat-streaming 63项、runtime/proxy/provider 31项通过。服务包待构建；未构建APK。

# HMR2.0b 报告整图相对深度

- 日期：2026-10-16
- 状态：已完成
- 预计工时：约1小时

## 任务与设计需求

用户希望HMR2.0b三图报告同时显示深度图，并选择复用现有整图相对深度。固定三张原图的SHA与既有Depth Anything V2 Small输出源一致；显示原图叠点、HMR 3D骨架和相对深度，说明两种模型输出互不等同。设计见[Human文档](../design/mmd-human-interface.md)。

## Spec、范围与受影响文件

按[实现伪代码](../spec/mmd-human-interface.md)先核对深度清单与HMR状态中的原图SHA，再加载`tmp/mmd-pose/depth-eval/rigid-projection/{seated,anime,diagram}-depth.png`，切图同步，HMR候选切换不改深度源；来源不符或缺文件显示提示并保留其他图。修改`tmp/mmd-pose/depth-eval/hmr2-sam3d/report.html`、`report.mjs`和`check-report.cjs`，同步design、spec、self-test、usage、todo和changelog。深度PNG、模型、私人原图仍留本机，不加入Git。正式MediaPipe全身IK与VAM不变。

## 自测、兼容性与性能

- 先写浏览器断言并确认旧页面因缺少深度图失败；更新后Edge三张图完整解码、图名对应与候选不串图通过。
- WebGL不可用时线条骨架与深度仍显示；模拟深度404或原图SHA不匹配时，原图叠点和24骨段仍显示。
- 1280px三列、390px单列无横向溢出；无页面脚本错误，普通请求均为本机GET。
- 仅读取约213–268KB既有PNG，不运行新ONNX推理；不构建APK或发布。

## 风险与结果

深度图每图按本图输出的5%–95%值归一化，黄色较近、蓝色较远；不是米制距离，也不反映被遮挡的内部关节。人物之外的椅子、猪、剑及衣物同样进入深度图。该显示便于观察表面前后关系，不能证明HMR识别准确或修正动漫脚掌、真人左右腿。

# MMD AR阴影相机范围倍率

## 任务与授权

用户要求“再加一个可以调阴影相机size的，0.1到2”。以当前自动拟合范围的倍率解释size，默认1；用户回复“是”确认具体方案；设计/伪代码已先行更新，代码、网页构建和定向验证已完成。

## Design需求与Spec设计

在灯光主光分组新增阴影相机范围倍率滑条0.1–2，步长0.01、默认1。主光/补光使用同一倍率：实际正交半幅=现有radius×1.18×倍率。保持围绕模型中心，以倍率缩小/扩大投影平面范围，预览整张ShadowMap即时反映角色占用和裁切。

复用阴影设置存储cameraScale字段，旧偏好缺失字段回1；更新两灯投影矩阵/阴影，变更时拟合一次，不每帧求包围范围；不累乘，换模型/旋转和灯光方向变化的已有拟合流程保留倍率。灯光恢复默认回1。实现伪代码见对应spec同名章节。

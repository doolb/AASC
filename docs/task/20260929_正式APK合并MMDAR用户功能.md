# 正式 Offline APK 合并 MMD AR 用户功能

- 需求：把测试页已验证的分类面板、动作/物理、灯光与 AO 渲染优化、MindAR 相机同步优化和模型加载百分比移到正式显示端；不带测试诊断工具。
- 设计：`docs/design/mmd-ar-production-offline.md`；伪代码：`docs/spec/mmd-ar-production-offline.md`。
- 评审：enterprise；主等级 L6、次等级 L5/L7，需下放到 L4；跨页面、渲染、定位三模块。主要风险为 Android WebView shader 兼容性、面板 ID/本地存储兼容及 MindAR 与 PMX 时序。
- 影响：正式 `display.html`、`css/display-mmd.css`、灯光/动作/定位 JS、PMX AO/材质运行时、相关浏览器测试与 Offline 代码包状态；测试页保留原诊断能力。
- 自测：面板互斥与窄屏滚动、开关与分类标题分离、VMD 进度/暂停/循环、AO 半/全分辨率、主/补光阴影、高光、MindAR 首锁/失锁/重锁/释放。
- 兼容性：已有存储配置、PMX/VRM 切换、无摄像头与权限拒绝、离线静态资源、旧 APK 通过 code-only 更新。
- 性能：AO 不增加第二张深度图；动作进度仅面板可见时低频读取；MindAR 仅定位启动时加载。
- 预计工时：跨模块，分 UI、渲染、定位、验证四阶段；真机视觉验收单列。

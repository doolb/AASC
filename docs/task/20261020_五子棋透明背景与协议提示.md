# 五子棋透明背景与协议提示

- 任务：棋盘外层去掉黑色遮罩；实际 Game 调用与 GM 回执在控制端、显示端聊天中以灰色小字提示。
- Design：`docs/design/game-gomoku.md`。
- Spec：`docs/spec/game-gomoku.md`，代码变更前已更新伪代码。
- 受影响模块：`display-game.css`、游戏聊天桥、聊天消息存储、服务端聊天 WebSocket、两端聊天 JS/CSS 与消息分发、定向测试。
- 自测：User/AI 调用与 GM 回执顺序；棋盘点按的 GM 增量；首轮恢复快照；普通聊天无提示；协议不进入 TTS 和模型正文；历史重载可见；演示不产生聊天记录；浅色/深色主题下背景透明且文字可读。
- 兼容：旧历史缺少 `gameTrace` 时正常显示；旧客户端忽略新 WebSocket 事件；模型上下文只读取原有正文。
- 性能：每轮事件有限记录，长快照在聊天提示中折叠棋盘编码，服务端权威协议保持完整。
- 风险：控制端/显示端同源消息可能重复；按请求 ID 和事件序号去重。
- 预计工时：约 3 小时。
- 补充范围：显示端 `games` 能力声明；AI 先查目录、再按需查规则；普通聊天不带完整五子棋规则。成功标签后自然语言保留，操作失败的预先宣称丢弃；GM 对模型续接改短回执，UI 只显示四位游戏编号。
- 验证：五子棋、演示脚本、双端聊天提示、流式请求 ID 和显示端普通语音聊天共 33 项定向测试全部通过，`git diff --check` 通过；覆盖目录/规则、无能力目录为空、两步叙述保留、短编号、无冗余续接、灰色提示去重与历史恢复，以及棋盘透明背景。
- 真机：Note8 显示端重载后 `displayList` 报告 `games:["五子棋"]`；连续演示分别显示“演示 · 你赢了”和“演示 · AI 赢了”，`displayGameShell` 计算背景为 `rgba(0,0,0,0)`，自动结束恢复原棋局，截图 `/tmp/aasc-gomoku-demo-transparent-ai-win.png`。真实上游模型对话未用测试消息污染。

# Node 子显示端常驻 mpv 跨平台播放

状态：用户已确认，源码完成；本轮独立包及目标设备验收待进行。

- 任务描述：现有控制端触发Node子显示端以常驻mpv播放视频/音频/图片；支持Linux/Windows命令配置及Linux DISPLAY/XAUTHORITY、四方向旋转和六种填充。
- design需求：见[设计](../design/node-display-mpv.md)，清空保留进程、退出关闭自有进程；TTS保留原PowerShell/aplay链路。
- spec设计：见[伪代码](../spec/node-display-mpv.md)，先更新声明级数据流，再实现平台、进程/IPC、几何和AASC协议适配。
- 实际代码：新增 `src/apps/voice-display-node/{mpv-player,mpv-platform,mpv-geometry,media-controller}.js`，修改同目录main/config.example/README及服务端server-app配置生成；新增fixtures/fake-mpv、专项测试与真实mpv自测、npm入口和使用说明。
- 自测用例：真实socket/子进程验证单实例、切换/清空/退出、临时资源回收、错误/超时、加载取消、崩溃后重建；VoiceDisplay真实分支连接控制器，权威能力/恢复、暂停断点、进度、correlationId和旧恢复隔离。
- 画面用例：四方向×六模式×两种媒体尺寸×两种窗口尺寸共96组，与网页真实applyCrop结果对照；动态模式与控制切换回收，属性实时调整且PID保持。
- 兼容性：Linux显式认证失败/xdpyinfo依赖、Windows含空格路径及管道格式；原配置缺省关闭、服务端保留本机配置与坏JSON；语音/重连和独立包回归。
- TTS补充（2026-10-22）：mpv可混合音轨但本轮不承载TTS；新增PowerShell/aplay实际分支与TTS/媒体停止互不影响回归，mpv使用非独占输出。实际混音依赖系统，未改系统设置。
- 性能：动态更新最多20Hz，等待IPC不堆积；进度最多每秒一次，播放状态仅变化上报，避免每秒触发服务端状态持久化；切换后无额外进程/临时目录增长。
- 风险：图形权限、版本/编解码器、音频设备共享、IPC竞态；由有界探测/回执、代次、参数数组和设备验收覆盖。
- 预计工时：原估实现与自动验证0.5～1天，追加画面约0.5天，双系统验收视环境另计。
- 范围：单媒体与基础控制/旋转/六种填充已实现；批量列表、HTML/文本和网页专用功能未接入。

# MMD-AR头部与眼球视角跟随

日期：2026-10-10。状态：实现、本地web-dist构建及静态检查完成；实际设备观感待验收。

## 需求与设计

角色头部、眼球跟随观看视角，接入HumanInterfaceElement生理层。建议目标为当前相机位置，眼球与头部单独启用，限角和平滑，默认启用，兼容动作、表情、口型。设计见docs/design/mmd-human-interface.md；默认相机；点击/轻触后停留3秒再平滑返回，可配置停留时间，拖动不触发。

## 实现方案与受影响模块

新增web-human-gaze.mjs；修改Human model/mixer/interface、storage、panel/ui、build模块，传入当前相机getter。先在spec记录伪代码，再按确认方案实现；按模型签名保存设置，换模型和暂停重置临时状态，明确动作优先。仅独立mmd-ar，生成本地web-dist；外网发布另按用户指示。

## 风险与工作量

非标准轴向、眼球grant和基础动作姿态影响注视效果，需要能力识别和模型映射；新增计算需仅处理少量骨骼，避免额外整模型遍历。预计一个实现轮次，实际工作量取决于骨骼继承适配。

## 同轮修复

身体动作报错Line 2: Invalid degrees number：固定MPL编译器按行解析骨骼指令，高级鞠躬/挥手模板含同一行多条指令；将模板统一为每条指令一行，保持动作语义与编译器版本。

## 实施结果

头部优先绑定頭/Head，缺失用颈部；眼球自动绑定両目/左右目并识别grant。新配置默认启用，3秒停留可配置；显式旋转轨道权重抑制注视，头部先计算，眼球按更新后的头部与预测grant方向计算。点击世界目标固定，8px及以上拖动/取消不触发；生命周期释放事件，不新增RAF。读取米娅PMX确认头15/双眼100/右96/左98，左右眼均从双眼继承非局部旋转比例1，与双眼同为头部子节点，可使用共有眼驱动。

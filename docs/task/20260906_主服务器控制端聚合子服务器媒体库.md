# 主服务器控制端聚合与管理子服务器媒体库

## 任务描述

在保留所有显示端连接主服务器的前提下，让主控制端统一浏览和管理在线子服务器的媒体库。播放时优先使用子服务器 URL，无法直连时回退到主服务器同源代理，并修复远程媒体库复合 ID导致的错误请求和 404 提示不明确问题。

## Design 需求

- 控制端媒体库统一读取 AASC 网络媒体索引。
- 主服务器库继续使用本地媒体库接口；子服务器库由主服务器通过已建立的 AASC `/server` WebSocket 管理。
- 主控制端可以向指定在线子服务器添加本地、HTTP 或 SMB 媒体库，也可以编辑、删除、设默认、上传、删除文件和管理目录。
- 子服务器媒体库配置只持久化在目标子服务器，主服务器不保存远程账号密码。
- 子服务器媒体播放优先使用目标节点原始 URL，主服务器代理 URL作为备用，不复制媒体文件。
- 不恢复显示端切换、显示端跨节点路由、自动发现或权限认证。

## Spec 设计

- `MediaLibrary.loadLibraries` 请求 `/api/aasc/media-index`，为远程库保留 `ownerNodeId`、`sourceLibraryId`、`directUrl` 和 `proxyUrl`。
- 添加媒体库弹窗提供目标服务器选择；主服务器目标调用 `/api/media-libraries`，子服务器目标调用 `/api/aasc/servers/:nodeId/media-libraries`。
- 远程配置和目录操作通过 `media.library.*` 节点命令下发；大文件上传和媒体读取通过主服务器同源代理转发。
- 控制端所有远程请求使用原始 `sourceLibraryId`，不将 `nodeId::libraryId` 展示 ID发送给目标 API。
- 播放先加载 `directUrl`；直连失败时改用 `proxyUrl`，错误提示包含目标节点、接口和 HTTP 状态。
- 远程批量播放通过子服务器节点命令生成播放列表，列表媒体仍使用子服务器 URL。

## 自测用例

- 主控制端显示主服务器和在线子服务器媒体库，并显示节点来源和读写状态。
- 从主控制端选择 Termux 子服务器，添加一个本地媒体库，子服务器成功初始化、持久化并注册静态路由。
- 编辑、删除、设默认、上传文件、删除文件、创建目录和删除目录均使用目标子服务器的真实媒体库 ID。
- 播放、图片缩略图和视频 Range 请求优先使用 `192.168.1.6:8081` 等子服务器原始 URL。
- 子服务器返回的媒体地址使用节点注册地址作为权威主机；空值、`null`、`undefined` 或非法地址按媒体库 ID 和路径补全为子服务器媒体 API 地址。
- 子服务器批量播放列表保留媒体 `path`；主服务器按节点注册地址重写直连 URL，并附加主服务器远程代理回退地址。
- 子服务器 URL 不可访问时，控制端和显示端可以使用主服务器代理 URL完成播放。
- 直连和代理地址均为空时不下发媒体，避免浏览器请求 `null` 并产生无意义 404。
- 子服务器返回 404、离线或 WebSocket 超时，控制端显示明确的节点和接口错误，不出现无法定位的通用资源错误。
- 媒体库目录项即使没有播放 URL 也保留进入子目录功能，不显示“媒体地址不可用”。
- 子服务器离线时，主服务器本地媒体库仍可用，聚合索引错误只标记对应节点。
- 显示端仍全部注册在主服务器，子服务器显示端统计保持独立且不被媒体库管理改变。

## 兼容性测试

- 本地媒体库、HTTP 媒体库和 SMB 媒体库的现有管理接口保持兼容。
- `/server` HTTP 代码清单/代码包接口、`/server` WebSocket 节点连接、`/control` 和 `/display` 路由保持兼容。
- HTTP 和 HTTPS 主服务器均能构造子服务器媒体代理地址；代理关闭 TLS 证书校验的行为与现有节点连接一致。
- 远程只读媒体库仍禁止文件和目录写入，但允许修改只读属性或删除媒体库配置。

## 性能测试

- 聚合索引并行读取在线子服务器，不因单个节点超时阻塞本地媒体库。
- 文件上传使用 HTTP 流式转发，不把完整大文件转成 WebSocket Base64 消息。
- 媒体播放代理转发 `Range`，视频可以正常拖动和分段读取。

## 风险评估

- 当前未实现权限认证，任何能访问主控制端 API 的客户端都可能操作已连接子服务器媒体库；后续 AASC 权限认证必须覆盖这些命令。
- 直连播放依赖显示端能访问子服务器上报地址；地址错误或网络隔离时由主服务器代理承担回退流量。
- 子服务器媒体库配置中的账号密码只在目标子服务器保存和使用，控制端页面及主服务器索引不得显示密码。
- 远程节点突然断线时，正在进行的控制请求失败；控制端必须允许刷新聚合索引后重试。

## 预计工时

- 服务端命令、远程 REST 接口和媒体代理：4 小时。
- 控制端目标服务器选择、远程操作和播放回退：3 小时。
- 测试、兼容性检查与文档：2 小时。

# 任务：显示端媒体底色固定黑色

## 任务描述

显示端切换控制端主题后，媒体画面后方的空白区域不应跟随浅色或彩色主题变化，需要恢复为固定黑色；显示端的信息、状态、弹窗和文本媒体仍保持主题联动。

## Design 需求

- 媒体画布与主题 UI 分离。
- `html/body`、`#mediaContainer` 和媒体睡眠遮罩使用固定黑色。
- 连接状态、文本媒体、天气/语音弹窗和任务提示继续使用主题变量。
- 不修改图片、视频、iframe 内容和显示端主题同步协议。

## Spec 设计

- 页面背景、媒体容器背景和媒体睡眠遮罩背景均为 `#000`。
- 显示端 UI 控件仍使用 `theme.css` 中的语义变量。
- 主题切换只更新根节点主题属性及 UI 样式，不改变媒体画布底色。

## 自测用例

1. 检查 `html/body` 背景固定为 `#000`。
2. 检查 `#mediaContainer` 背景固定为 `#000`。
3. 检查媒体睡眠遮罩背景固定为 `#000`。
4. 检查文本媒体、连接状态和临时弹窗仍引用主题变量。
5. 检查图片、视频和 iframe 不增加主题滤镜或内容覆盖。

## 兼容性测试

- 深色、浅色及 15 种主题下媒体画布均保持黑色。
- 图片、视频、HTML 媒体和文本媒体的既有播放、旋转、裁剪逻辑不变。
- 旧显示端未收到主题消息时仍保持原有黑色媒体底色。

## 性能测试

- 仅修改静态 CSS 和契约测试，不增加请求、轮询或运行时计算。

## 风险评估

- 主题切换后媒体空白区域不再显示主题背景，这是明确的视觉边界调整。
- 显示端 UI 控件仍依赖主题变量，若后续新增媒体外层控件，应明确归类为媒体画布或主题 UI。

## 未明确需求

- 已确认：显示端媒体后方背景恢复固定黑色，不随主题切换。

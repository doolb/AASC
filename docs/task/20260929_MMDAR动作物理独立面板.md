# MMD AR 测试网页动作与物理独立面板

- 需求：新增名为“动作”的面板入口；面板内分动作、物理两类。动作增加只读播放进度，不拖动跳转。
- 设计与实现：`docs/design/mmd-ar-test-apk.md`、`docs/spec/mmd-ar-test-apk.md`。
- 评审：enterprise，主等级 L6、次等级 L5，可开发；范围、输入输出与交互已确认。下放 L4：面板控件迁移 → 只读 action 状态 → 定时渲染 → 事件回归。主要风险是移动控件后原灯光设置事件丢失及非活动面板不能关闭。
- 影响：仅 `3rd/mmd-ar-test/build.js`、`web-panel-groups.js`、测试与文档，不改正式显示端或 APK。
- 自测：面板互斥/关闭、手机窄屏、动作/物理参数持久化、无模型占位、播放/暂停/循环进度；构建及浏览器回归。
- 性能：面板显示时低频读取当前 action，不新增渲染通道；隐藏时停止计时。
- 风险：VMD 切换或物理重新加载期间短暂无 action，进度显示未知；不把旧进度误报为新动作。
- 预计工时：约 1 小时。手机真机视觉验收后续进行。

# Node子显示端ASS文本媒体

状态：用户已确认单文档范围，源码与自动验证已完成；独立包/服务包待构建部署，Windows现场待验。

- 任务描述：使用同一常驻mpv的ASS正文层承接Node子显示端的文本媒体，Node负责分页、控制及逐句朗读。
- design需求：见 `docs/design/node-display-mpv.md` 的ASS文本媒体说明及 `docs/design/text-media.md` 的Node适配说明。
- spec设计：见 `docs/spec/node-display-mpv.md` 的L4伪代码流程；正文与信息字幕独立，保持原媒体和普通TTS生命周期隔离。
- 已实现首版：单篇txt原文、md可读正文，URL/base64、分页/页码、textStyle、播放/暂停/上页/下页/停止/清空、原分句TTS及路由、进度恢复；不默认扩展整个Node混合播放列表。
- 已确认：Markdown仅可读文本而非完整网页图片/表格排版；系统播放器暂停后从当前句重播，不承诺句内精确续播。此两点和单文档范围随具体方案一并确认。
- 受影响模块与代码：新增 `src/apps/voice-display-node/mpv-text-player.js`、`mpv-text-renderer.js`；修改main/media-controller/mpv-player/audio-player，复用共享分句器与现有文本协议，补专项/render/独立包回归与文档。
- 自测用例：中文长文/超长单行/换行/空文档/UTF-8与加载失败；正文不受字幕2048字符和三行限制；安全Markdown转换、ASS控制字符转义；最终翻页/样式改变、旋转与窗口重排不丢内容；playbackId/页/句/目标校验与停止后旧TTS回包隔离；本机/远程声音目标完成及无语音降级；普通TTS不被翻页取消。
- 兼容性测试：Linux/Windows既有MPV IPC、系统PowerShell/aplay、时钟/连接/TTS/ASR同屏，当前图像视频音频切换及权威能力；Windows实际画面另验。
- 性能测试：文档与单页均有界，避免长文本逐字符全量二次量测；取消下载/重排后不积压，句请求与本地音频队列有界，常驻PID及退出清理。
- 风险评估：ASS不是HTML渲染器；当前字幕上限会截断整篇文档；原系统播放器缺少句内暂停；文本/普通TTS共队列需要按所有者取消；权威语音目标可能在另一台设备，不能假设本机播放结束即推进。

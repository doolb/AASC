# 壁纸镜头随倾斜平移

- 需求：陀螺仪驱动镜头轻微上下左右移动，保持镜头朝向，普通模式和壁纸共用。
- 设计：见 `docs/design/display-wallpaper-controls.md`；沿相机本地横纵轴限幅、缓动并可恢复，角色倾斜独立。
- 实现：先更新 `docs/spec/display-wallpaper-controls.md`，修改传感器适配、显示端状态、PMX/VRM 相机运行时、自测和文档。
- 自测：水平/垂直传感器映射、限幅、开关独立、相机坐标变化而方向保持、停止恢复；回归手动视角、AR 及镜头动画。
- 兼容性：沿用既有传感器和本机开关，不增加原生权限；PMX、VRM、普通与壁纸共用。
- 性能：复用现有渲染帧缓动，不增加传感器或轮询。
- 风险：实际观感、横竖屏和设备姿态需手机验收。
- 预计工时：半天。

- 自动验证：真实 Three.js 相机验证 PMX/VRM 视角不变与复位，壁纸浏览器覆盖横竖屏、开关和限幅；真实手机观感仍待验收。

- 结果：`npm run test:hologram-camera` 3 项通过；真实 PMX 浏览器模型及 IK 回归 1 项通过；渲染性能 17 项通过、1 项因 GPU 查询不支持跳过。`display-chat-mmd.test.js` 13 项失败经原始 HEAD 复核为既有失败；真实手机仍待验收。

# MindAR 单算法、手机面板与补光阴影来源

## 任务与需求

根据 `testimg/` 的手机实拍与相同目标静态回放，将 HTTPS MMD AR 测试页改为仅 MindAR；修复手机相机显示时定位面板下方按钮触摸不可达；在补光设置中提供无阴影、主光源阴影、补光自身阴影三选一。正式显示端保留现有图片跟踪器，阴影设置同步正式源码但本轮仅发布 HTTPS 测试页。

## 设计与 spec

参见 `docs/design/mmd-ar-test-apk.md`、`docs/design/mmd-pmx-vmd-local.md` 和对应 spec 的伪代码。测试网页不加载自写跟踪器，MindAR 适配器仍提供共同 AR 会话接口；面板最大高度按动态视口计算并允许纵向手势；阴影来源迁移旧布尔开关，单一方向光投射阴影。

## 影响模块

`3rd/mmd-ar-test/build.js`、`display-mmd-ar-benchmark.js`、`web-panel-groups.js`；`src/apps/web-mediacenter/ui/public/display.html`、`js/display-mmd-lighting.js`、`js/display-pmx-runtime.js`；网页及显示端定向测试、design/spec、todo、usage、changelog。

## 自测、兼容性、性能

- 静态样本独立会话比较 MindAR/旧 JS；不将静态照片数据误报为实时准确率。
- 网页生成后确认没有自写跟踪器文件或算法下拉，MindAR 可初始化；旧测试 APK 生成路径保留。
- 手机竖屏展开面板、真实触摸上滑，底部两个定位操作可达；MMD Canvas 拖动不触发页面滚动。
- 阴影三选一及旧设置 false/true 迁移；补光关闭且选补光阴影时无投影；切换后仅一盏灯产生阴影贴图。AO/Toon/物理不受影响。
- 指纹 URL 避免旧 JS 缓存；真机连续视频、阴影画质/性能仍需现场验收。

## 风险与预计工时

MindAR 首次编译可能较慢；手机浏览器动态视口行为需现场验证。补光自身阴影质量受光方向、模型遮挡和 1024 阴影贴图限制，预计 2–4 小时。

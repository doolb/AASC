# 提醒时间统一与自定义指令免唤醒

## 任务描述

修复语音提醒只识别阿拉伯数字、时间文本残留到提醒内容的问题；允许已配置的自定义语音指令在显示端等待唤醒状态下直接执行。

## design 需求

- 语音提醒统一使用共享时间解析器，支持相对日期、相对时间、时段和中文数字组合。
- 提醒内容只保留用户要提醒的事项，不包含已识别的时间和重复规则。
- 自定义关键词命令纳入等待唤醒的免唤醒范围，普通聊天和会话控制词保持原有唤醒要求。

## spec 设计

```text
语音提醒:
    parsed = timeParser.parseTimeForReminder(text)
    targetTime = parsed.timestamp
    timeDescription = parsed.description
    content = 移除提醒标记、重复规则和解析成功的时间片段
    创建待确认提醒

显示端等待唤醒:
    isWakeFreeVoiceCommand(text) = 内置命令匹配 或 自定义关键词匹配
    若 isWakeFreeVoiceCommand(text):
        接受输入并进入现有命令执行链
    否则:
        保持等待唤醒并丢弃普通输入
```

## 受影响的功能模块和代码

- `src/core/utils/time-parser.js`：修正时段与具体时刻组合的共享解析行为。
- `src/apps/web-mediacenter/modules/voice/voice-command-app-service.js`：复用共享解析器、清理提醒内容、提供统一免唤醒判断。
- `src/apps/server/boot/server-app.js`：显示端门控使用内置或自定义命令免唤醒判断。
- `src/apps/server/modules/voice/display-voice-conversation.js`：复用既有等待唤醒状态机，补充自定义命令回归测试覆盖。
- `tests/time-parser.test.js`、`tests/display-voice-conversation.test.js`：新增解析和门控测试。
- `docs/design/reminder.md`、`docs/spec/reminder.md`、`docs/design/display-voice-conversation.md`、`docs/spec/display-voice-conversation.md`：同步设计和伪代码。

## 自测用例

1. `下午三点` 解析为 15:00，而不是默认 5 分钟或凌晨 3 点。
2. `明天早上八点` 解析为明天 08:00。
3. `三十分钟后` 解析为当前时间之后 30 分钟。
4. `提醒我下午三点开会` 的内容为“开会”。
5. 等待唤醒状态下自定义“晚安”被接受，普通文本仍被拒绝。
6. 自定义关键词仍通过现有 `processVoiceCommand` 和 `executeCommands` 执行。

## 兼容性测试

- 保持现有提醒确认、提醒存储和显示端弹窗协议不变。
- 保持内置命令、唤醒词、普通聊天和会话控制词的原有门控规则。
- 保持旧显示端沿用原有命令流程。

## 性能测试

- 时间解析只进行有限次正则匹配，复杂度随输入文本长度线性增长。
- 等待唤醒判断只读取当前命令配置，不创建定时器或网络请求。

## 风险评估

- 自定义关键词使用现有包含匹配规则，过短关键词可能扩大免唤醒范围；本任务不改变既有自定义命令匹配语义。
- 中文时间表达存在方言/ASR 变体，先覆盖共享解析器已有表达和常用组合。
- 未识别时间继续使用 5 分钟默认值，避免现有提醒流程中断。

## 预计工时

约 2-3 小时，包含共享解析器修正、门控调整、回归测试和文档同步。

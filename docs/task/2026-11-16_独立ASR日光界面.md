# 独立 ASR 日光界面

- 任务：拆出 Android APK 与纯网页到 `/mnt/asr`，复制 SenseVoice 模型和词表，保留原项目。
- 设计：明亮日光配色、底部圆形录音按钮、音量 VAD 自动分段，支持 WAV；不包含声纹、流式或降噪。
- 规格：见 `docs/spec/standalone-asr.md`；采集 16kHz 单声道，语音和静音阈值由默认值控制。
- 受影响模块：独立 Android、网页、模型及构建文档；AASC 原功能不变。
- 自测：VAD 起止、静音和短语音、模型加载与失败、WAV 和麦克风权限、释放资源。
- 兼容：Android APK 原生推理；网页需 WebAssembly、Worker、HTTPS 或 localhost 麦克风权限。
- 性能：模型约 229 MiB，首次加载与设备内存相关；限制单段长度。
- 风险：模型推理和 WebView 的性能依赖设备；噪声阈值可能需调整；真机效果待验证。
- 预计工时：1–2 个工作日。

- 当前验证：模型 SHA-256 与原文件一致；网页通过实际 WAV 推理输出“你好，小爱。”；静态服务与 VAD 自动测试 2 项通过。无连接 Android 设备；Android 调试 APK 已生成，包内模型和 v2 签名校验通过；麦克风真机验收待完成。

- 追加发布：网页使用相对入口 `../aimodel/sensevoice/`，本地预览模拟相同路径；静态网页部署到 `https://c.aasc.us/mnt/asr/`，复用同站点模型。验证本地与线上资源及模型路径。

# 确认倒计时高对比度

## 任务描述

提升显示端语音对话确认倒计时在深色、浅色及其他浅色主题下的可读性。

## Design 需求

- 确认倒计时必须有独立背景和边框，不能只依赖黄色文字。
- 深色主题使用白色文字配深红背景。
- 浅色主题使用深红文字配浅红背景。
- 不改变普通唤醒倒计时颜色和确认状态机。

## Spec 设计

```text
确认倒计时元素
    默认深色主题 -> 白字 + 深红背景 + 浅红边框
    data-theme-mode=light -> 深红字 + 浅红背景 + 深红边框
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/css/display.css`：确认倒计时高对比样式。
- `tests/display-voice-conversation-confirmation.test.js`：颜色样式契约。

## 自测用例

1. 确认倒计时包含背景、边框和加粗文字。
2. 深色主题的确认倒计时为白字深红背景。
3. 浅色主题存在深红字浅红背景覆盖。
4. 普通唤醒倒计时样式未被改变。

## 兼容性测试

- 深色、浅色及其他 `data-theme-mode=light` 主题均能使用对应配色。
- 确认弹窗、TTS 和倒计时计时逻辑不变。

## 性能测试

- 仅增加 CSS 规则，不增加运行时计算或网络请求。

## 风险评估

- 主题文件未加载时仍使用显示端默认深色规则，不影响倒计时显示。

约 15 分钟，包含样式契约和回归测试。

# 西施2浏览器测试与部件绑定修正

## 需求

用户要求自行浏览器测试权重和碰撞体问题。复用已有测试工具puppeteer-core、Chromium及本地HTTP服务，实际渲染对比，不要求用户再提供截图作为前提。

## 复现与修改

- 无物理动作也有袖片尖条，Ammo/XPBD可见异常衣物折叠与脚部附件。
- 工程读取：皮肤上身261、下身162、左右靴子各83顶点受>5%布料权重影响。
- 新增xishi2-parts.py，实际连通部件语义映射、人体保护、袖片统一上臂附着、头饰/小挂件权重转移和身体碰撞体截面拟合。
- 调整export-xishi2.py、xishi2-rig.py、xishi2-skin.py、xishi2-pmx.py。设计与伪代码见mmd-ar-test-apk文档。

## 测试结果

新资源935cb111b2ba，162骨/117刚体/78关节。主要皮肤和靴子布料权重归零。
实际浏览器运行：静止/默认动作、无物理、Ammo、XPBD、刚体覆盖显示；最终独立会话均pageerror=[]、27451顶点invalid=0。导出、Python语法和web-dist构建完成。

开始在800×900、默认45子步测试，取得多种截图；连续重载发生过TargetCloseError，未确定原因。最终独立会话480×720，10参考Hz/子步、SwiftShader、fromSurface=false截图，正常退出。AO和阴影在诊断中关闭，以观察蒙皮。该结果不能替代默认高负载长跑、硬件GPU或手机验收。

记录位于`3rd/mmd-ar-test/output/xishi2/browser-check/`：before-motion-no-physics.png、after-motion-no-physics.png、after-ammo.png、after-xpbd.png、rigid-overlay.png及日志/执行脚本。截图姿势时间与画布尺寸有差异，不作为逐像素对比。

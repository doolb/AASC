# 控制端主题预览器

## 任务状态

- ✅已完成 [2026-08-29][2026-08-29]

## 任务描述

在系统设置的主题选择框旁增加主题预览入口，集中展示当前主题的典型控件和状态样式。

## Design 需求

- 预览按钮紧邻主题选择框。
- 预览弹窗展示大/小卡片、按钮、开关、滑条、输入框、下拉框、标题、文本、Tip、状态、聊天消息、日志和弹窗样例。
- 预览临时应用选择的主题，关闭后恢复原主题，不保存配置。
- 支持按钮关闭、遮罩关闭和 Esc 关闭。

## Spec 设计

```text
点击主题预览按钮:
    theme = themeSelect.value
    保存根节点原主题
    临时设置根节点 data-theme/data-theme-mode
    创建预览弹窗并填充控件样例

关闭预览:
    删除预览弹窗
    恢复根节点原主题
    不写 localStorage
    不发送控制端主题 POST
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/upload.html`：主题选择框旁增加预览按钮。
- `src/apps/web-mediacenter/ui/public/js/ui-theme.js`：增加临时主题预览和关闭恢复逻辑。
- `src/apps/web-mediacenter/ui/public/css/theme.css`：增加预览弹窗及样例控件布局样式。
- `tests/ui-theme-preview.test.js`：验证入口、样例和临时恢复契约。

## 自测用例

1. 主题选择器旁存在预览按钮并调用预览方法。
2. 预览器包含各类典型控件样例。
3. 预览临时设置主题，不调用主题持久化接口。
4. 关闭逻辑恢复原主题并移除弹窗。
5. 运行主题、显示端同步及预览测试，执行脚本语法检查和 `git diff --check`。

## 兼容性测试

- 不改变既有主题选择、服务端持久化和显示端同步流程。
- 不引入第三方依赖。
- 移动端弹窗可滚动查看完整样例。

## 性能测试

- 预览仅在用户点击时创建 DOM，关闭后移除，不增加常驻监听器。

## 风险评估

- 低风险：预览只临时修改根节点属性，关闭时恢复，不改变实际主题配置。

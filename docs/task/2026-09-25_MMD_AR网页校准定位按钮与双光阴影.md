# MMD AR 测试网页校准、定位按钮与双光阴影

## 任务与设计

- 日期：2026-09-25；范围仅为 HTTPS MMD-AR 测试网页，不构建 APK，不改变正式显示端默认语义。
- 校准弹窗须在竖屏短视口和安全区中完整可达；预览可收缩，内容可滚动，四角映射不变。
- 第一分类用一个按钮在开始/结束定位间切换，复用原业务处理与相机释放流程。
- 主光继续投射自身阴影；补光可不受阴影、沿用主光阴影遮挡、或自己生成第二张阴影图。

## Spec 设计

- 对应 `docs/spec/mmd-ar-test-apk.md`“手机校准、定位切换与双光阴影”伪代码。
- 网页构建阶段注入测试页独有开关，原灯光值兼容；生成页面仍保留共享控件 ID。
- PMX 模型材质实例在测试模式下缓存主光遮挡因子并按补光模式复用；非测试模式不编译该补丁。

## 受影响代码

- `3rd/mmd-ar-test/build.js`、`web-panel-groups.js`：网页专用布局、控件、缓存指纹。
- `src/apps/web-mediacenter/ui/public/js/display-mmd.js`、`display-pmx-runtime.js`、`display-pmx-lighting-mode.mjs`：显式测试开关及 PMX 双光投影。
- `tests/mmd-ar-web-panel-groups.test.js`、`tests/mmd-ar-web-shadow.test.js`：手机布局和阴影渲染回归。

## 自测、兼容性与性能

- 自测：生成网页、竖屏短视口弹窗、定位按钮状态、真实 PMX WebGL 着色器编译与三模式切换。
- 兼容：正式显示端无测试开关，沿用原三选一阴影语义；旧测试 APK 不重新构建。旧浏览器灯光本地设置按现有 `shadowSource` 三值读取。
- 性能：补光自身阴影模式比原单灯阴影多一张 1024² 阴影贴图；其余两种模式复用主光阴影图，需在目标手机复测帧率。
- 风险：低视口下可滚动性、GPU shader 展开兼容、双贴图性能及现场摄像头首锁；以 Chromium 自动化和真机现场验收分别验证。
- 预计工时：半天；实际结果以变更日志和自测记录为准。

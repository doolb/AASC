## 已完成诊断

独立直接调用当前本机百炼账户。同文本“你好，语音测试。”、新模型与乔小娇，旧multimodal端点返回HTTP400/InvalidParameter；同主机SpeechSynthesizer加input.format=wav/sample_rate=24000生成84524字节。fmt为PCM1、mono、16bit、24000Hz；data实际84480字节，对应1.76秒；RIFF声明0x7fffffbf、data声明0x7fffff9b。严格原WAV校验失败，诊断副本wrapPcm与speed=1调整验证均通过，PCM逐字节相同。

诊断脚本和合成样本仅在.cache，凭证只在内存，签名音频URL与原始上游响应不输出，不提交Git；无生产配置修改或设备播放。本证据复现新模型相同报错，不据此保证历史21:43所有失败只有同一原因。

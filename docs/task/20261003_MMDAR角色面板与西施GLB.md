# MMD-AR 角色面板与西施GLB

## 需求与方案
用户确认新增角色按钮/面板，米娅与西施按需切换；西施源blend含完整材质但无骨架/动画，接入静态GLB。沿用现有场景/相机/AR/灯光，保留本地模型入口并移至角色面板。

## 实现
- export-xishi.py及scripts/models/export-mmd-ar-xishi.js：Blender后台只读加载源，导出七个角色网格；烘焙原输入图的颜色、粗糙度、金属度与发光，沿用法线，自定义头发高光用标准PBR近似。
- web-character-glb.mjs：复用PMX资源上下文，不创建动作/物理helper，准备成功后提交并释放旧模型。
- web-character-panel.mjs：角色按钮、50%透明面板、服务器角色列表/进度/选择记忆；静态角色禁用动作物理，本地模型仍可切换。
- web-characters-build.js/build.js：只改独立构建副本，GLB和模块带内容指纹；资源清单纳入西施；模型加载锁、默认角色恢复、本地资源释放。
- package.json新增export:mmd-ar:xishi，可指定BLENDER_BIN；正式端及Offline发布状态不变。

## 兼容性与待验收
米娅↔西施切换、网络失败保留旧模型、刷新记忆、存储受限、本地模型恢复、Android浏览器inert/触控面板、AR/重力/光照与材质效果、反复切换显存释放待人工验收。glTF不能完全复现Blender自定义着色；PMX专用卡通/高光/边缘光不等价于GLB PBR。模型文件不提交Git，web-dist随部署上传。

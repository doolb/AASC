# 深度采样器精度对照

- 需求：根据 d.jpg/d1.jpg 的纹理量化和 ao.jpg 条纹现象，验证采样器精度是否是原因。
- 设计与伪代码：`docs/design/mmd-ar-test-apk.md`、`docs/spec/mmd-ar-test-apk.md` 的独立深度诊断部分。
- 影响范围：仅 `3rd/mmd-ar-test/depth-probe.html`；创建默认/highp 两个程序，复用纹理、坐标和编码路径。
- 自测：桌面 Chromium/SwiftShader 显示四组对照，无 WebGL 错误；重复运行结果一致。
- 兼容性：Android Vivaldi 现场检查默认与 highp 差异；通过后再处理 AO 三阶段，不能用桌面测试代替真机结论。
- 性能：固定分辨率、两组裁剪参数各执行两个采样程序，测试结束释放资源，无持续渲染。
- 风险：测试模拟场景不覆盖 PMX 材质；当前模型 near=24/far=75 与诊断固定范围不同。
- 预计工时：半小时。

# MMD AR 相机跟随防抖与距离设置

- 日期：2026-09-26
- 范围：仅 HTTPS MMD AR 测试网页；不改正式显示端或旧测试 APK 的设置界面。
- 需求：定位时相机小幅抖动需要平移与旋转死区、逐帧缓动；定位面板可现场调节。相机距离只沿相机与定位图中心的连线拉近，100% 与原行为一致。

## Design 需求

定位面板新设“相机跟随”分类，平移死区按目标图世界宽度百分比计，旋转死区以角度计，缓动按真实帧间隔计算；相机距离 50%–100% 按相机到图中心向量缩放，不改 PMX 模型根节点、朝向或投影矩阵。四项设置在当前浏览器保存，异常值回退默认。首次定位立即对齐，失锁冻结当前画面，重新找到后平滑继续。

## Spec 设计与受影响代码

- 先更新 `docs/spec/mmd-ar-test-apk.md` 中的伪代码与距离语义。
- `3rd/mmd-ar-test/build.js`、`web-panel-groups.js`：测试页专用四个滑条、分类、值显示和本地存储。
- `src/apps/web-mediacenter/ui/public/js/display-mmd.js`：设置在 PMX runtime 初始化前暂存，初始化后补发。
- `src/apps/web-mediacenter/ui/public/js/display-pmx-runtime.js`：按定位图中心连线调整相机位置、姿态死区和按时间缓动；仅测试模式启用。
- `tests/mmd-ar-camera-runtime.test.js`、`tests/mmd-ar-web-panel-groups.test.js`：合成姿态、滑条及刷新保存回归。

## 自测、兼容性、性能与风险

- 自测：`npm run build:web:mmd-ar-test`，相机和面板定向回归、原定位/校准回归、JS 语法与差异检查。
- 兼容性：100% 距离还原原始相机中心线距离；正式显示端与旧测试 APK 不显示测试设置。
- 性能：每帧仅做向量插值和四元数插值，不增加相机流、WebGL 场景或模型计算。
- 风险：强死区会损失细微跟手，强缓动会增加延迟；用户可在面板调到 0 关闭。
- 预计工时：约 2 小时；实测结果写入 `docs/self-test.md`。

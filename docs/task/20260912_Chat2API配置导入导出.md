# Chat2API 配置导入导出

## 任务描述

为 Chat2API 控制端增加配置导出为 JSON 文件和从 JSON 文件导入功能。导出内容按原值保留持久化代理配置、Provider 用户配置、账号完整凭据和模型映射；暂不导出 API Key 原文。

## Design 需求

- 使用固定格式 `aasc-chat2api-config` 和版本 `1`。
- 导出接口以 JSON 附件返回配置快照。
- 导入复用现有预览/确认接口，按 ID 合并，未导入的数据保留。
- 账号 Token、Cookie 等凭据在导出文件中保持原值，预览响应必须脱敏。
- 不导出 API Key、Responses 会话、OAuth 临时状态和运行日志。

## Spec 设计

- 数据层新增 `exportConfiguration()`，读取 `config.json`、`providers.json`、`accounts.json`、`model-mappings.json`。
- `normalizeImport()` 接受可选 `config` 和固定格式标识。
- `mergeImport()` 合并配置并写回配置集合。
- 管理服务暴露 `exportConfig()`；代理提供 `GET /api/chat2api/export` 附件路由。
- 控制端增加导出下载、文件选择、预览确认和导入刷新流程。

## 自测用例

- 导出结果精确保留账号嵌套凭据、Provider、配置和模型映射。
- 导出 JSON 不包含 `apiKeys` 或 API Key 原文。
- 导出文件可通过预览/确认接口导入，配置和账号凭据恢复原值。
- 未确认导入不写入；相同键覆盖，未出现记录保留。
- 导出接口返回 JSON 附件响应。
- 控制端包含导出、文件导入、预览和确认请求流程。

## 兼容性测试

- 保持旧版无 `format` 字段的 version 1 导入文件兼容。
- 保持原 Chat2API `data.json` 迁移流程兼容。
- 运行 `npm run check:chat2api`。

## 性能测试

- 配置快照只读取四个小型 JSON 集合，不增加聊天请求路径开销。
- 使用现有请求体上限限制导入文件大小。

## 风险评估

- 导出文件包含账号敏感凭据，界面明确提示用户妥善保管。
- API Key 只保存哈希，无法原样导出；本任务不改变其存储安全模型。
- 导入失败时不主动删除未导入数据；保留现有原子写入机制。

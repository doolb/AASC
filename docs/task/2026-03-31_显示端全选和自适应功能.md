# 显示端全选和自适应功能

## 任务描述

新增显示端全选和自适应功能，支持将媒体下发到多个显示端。

## Design 需求

### 功能需求

1. **全选功能**
   - 全选时，下发到所有显示端
   - 点击"全选"按钮后，所有显示端都被选中

2. **自适应功能**
   - 根据显示端画面比例（包含旋转角度）和媒体比例来下发媒体
   - 横向的媒体，下发到横向显示端
   - 纵向的媒体，下发到纵向显示端

### 选择模式

| 模式 | 说明 |
|------|------|
| 单选 | 默认模式，选择单个显示端进行媒体下发 |
| 全选 | 选择所有已连接的显示端 |
| 自适应 | 根据媒体比例自动匹配显示端方向 |

## Spec 设计

详见 [display-selection.md](../spec/display-selection.md)

### 核心逻辑

1. **DisplayList 模块扩展**
   - 新增 `selectionMode` 属性
   - 新增 `setSelectionMode()` 方法
   - 新增 `getSelectedDisplayIds()` 方法
   - 新增 `getAdaptiveDisplayIds()` 方法
   - 新增 `isDisplayLandscape()` 方法

2. **WebSocketManager 模块扩展**
   - 修改 `sendMedia()` 方法支持多显示端发送
   - 新增 `getMediaRatio()` 方法获取媒体比例

3. **服务端修改**
   - 新增 `mediaBatch` 消息类型支持批量发送

## 自测用例

### 单选模式测试

1. 启动服务器，连接 2 个以上显示端
2. 确认默认为单选模式
3. 选择一个显示端，播放媒体
4. 确认只有选中的显示端播放媒体

### 全选模式测试

1. 切换到全选模式
2. 播放媒体
3. 确认所有显示端都播放媒体
4. 显示端列表中所有项都显示为选中状态

### 自适应模式测试

1. 连接横向和纵向显示端（或使用旋转模拟）
2. 切换到自适应模式
3. 播放横向媒体（宽 > 高）
4. 确认只有横向显示端播放
5. 播放纵向媒体（高 > 宽）
6. 确认只有纵向显示端播放
7. 播放正方形媒体
8. 确认所有显示端都播放

### 旋转角度测试

1. 将显示端旋转 90° 或 270°
2. 播放横向媒体
3. 确认旋转后的纵向显示端不播放
4. 播放纵向媒体
5. 确认旋转后的纵向显示端播放

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 媒体比例获取失败 | 自适应模式无法正常工作 | 默认发送到所有显示端 |
| 显示端旋转状态不同步 | 方向判断错误 | 使用服务端存储的旋转状态 |

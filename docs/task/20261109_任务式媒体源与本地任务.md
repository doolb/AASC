# 任务式媒体源与本地专用任务

- 需求：媒体源可由用户任务扩展，新增完全排除 release 的本地用户任务目录。
- 设计与实现：见媒体库 design/spec；服务任务按生命周期注册媒体源，配置独立持久化；`res/tasks/local-only` 中的任务使用保留前缀暴露给任务引擎；APK 与任务代码包排除该目录。
- 影响：任务引擎、媒体库提供者、控制端、离线打包与发布指纹。夸克和 B 站保持既有实现。
- 自测：本地任务发现及写入，服务注册/停止/恢复、真实 HTTP 清单和 Range、媒体库配置持久化、浏览器添加入口、发布目录排除和既有任务/媒体回归。
- 性能与风险：任务服务在服务端进程中执行，适合用户信任的代码；示例只支持 JSON 清单，其他网页需定制解析。Android 服务任务执行策略沿用现有限制。
- 预计工时：一天。

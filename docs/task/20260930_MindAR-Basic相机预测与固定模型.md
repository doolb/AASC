# MindAR Basic 相机预测与固定模型

- 需求：IMU 的旋转和平移用于预测相机定位，不能驱动角色的世界变换。
- design：固定世界锚点承载角色和参考图，MindAR 锚点只读；两个场景开关保持原职责。
- spec：目标相对相机位姿取逆得到世界相机位姿，以首次目标像素尺度为固定世界单位，保持相机单位尺度及 MindAR near/far。
- 实现：新增相机 rig 并关闭 look-controls/wasd-controls；参考图片移至固定锚点；统一视觉、预测、过期降级和失锁恢复的相机更新入口；停止/切换重置相机和世界尺度。
- 代码：index.html、mind-basic-imu.js、mind-basic.js；现有浏览器回归的运动断言改为检查相机。
- 待验证用例：纯旋转时相机方向改变而世界锚点不动；平移更新相机位置；视觉恢复只纠正相机；两个开关独立暂停/恢复；停止/换图无旧姿态残留。
- 兼容性：官方/自定义图片尺度、横竖屏、IMU 关闭后的纯视觉、原裁剪和拍照流程均待回归；模型原局部动画保留。
- 性能：复用原传感器和渲染循环，仅增加位姿取逆及相机世界矩阵更新；真机帧率待验收。
- 风险：浏览器 IMU 平移仍为短时积分；固定世界锚点不代表已经解决物理定位误差或漂移。
- 预计工时：约 30 分钟。
- 完成结果：代码及文档已更新，静态语法/差异空白检查通过，未运行测试，未发布外网；验证和发布留在 todo。

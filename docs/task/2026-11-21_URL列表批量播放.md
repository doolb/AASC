# URL 列表批量播放

## 需求

为外部控制端提供通用 URL 列表批量播放，不传输媒体内容。保持媒体库列表、临时 Base64 列表和显示端协议兼容，支持图片、动图、视频、音频、HTML 和文本。

## 设计与实现

依据 `docs/design/batch-playlist.md` 和 `docs/spec/batch-playlist.md`，新增 `playlistUrlRequest` 消息并提供 `urls` 数组；服务端验证 HTTP(S) 地址和类型、保留顺序并复用非临时列表的持久化、重连、循环、进度和控制。无效项整体失败，显式禁止与临时 Base64 模式混用。显示端无需变更。

## 验证与风险

- 单元测试覆盖顺序、类型、地址、凭据、数量和格式验证。
- WebSocket 集成测试覆盖列表启动、回复、显示端接收、进度、控制和重连恢复；回归媒体库和临时模式。
- 验证多 URL 仅传地址，媒体文件大小不影响请求；限制单次条目数量和地址长度以保护服务端。
- 签名链接可能过期；显示端必须能够访问地址；不由服务端预先下载或保证媒体播放成功。
- 预计工时：实现与测试约 2–4 小时；实际设备验收另行进行。

# 壁纸角色倾斜增强与镜头部署

- 任务：角色随手机倾斜转动的系数和限幅增至两倍，排查镜头无响应并验证外网 Offline 更新路径。
- 设计：角色 ±0.28 弧度、倾角系数 0.5；镜头仍使用独立线性加速度和平滑回中。
- spec：输入换算、独立限幅及 PMX/VRM 渲染一致；比较手机实际运行服务版本和发布服务包。
- 模块：壁纸网页控制器、PMX/VRM 运行时、定向测试、服务代码包。
- 自测：小角度两倍、限幅、角色与镜头同时独立、浏览器传感器和镜头回中；发布前校验签名、大小与 SHA-256，外网验证。
- 兼容：旧服务可能未包含壁纸面板；需更新服务后刷新；外网手机设备可达性待确认。
- 性能：保持既有传感器和渲染循环，传感器频率不变；实机观察。
- 风险：手机可能在外网、未连接本机 ADB；不可将局域网设备测试视为外网手机验收。服务打包应防止夹带无关工作区改动。
- 预计工时：2–4 小时。
- 结果：`npm run test:hologram-camera` 3 项通过；v190 以已发布 v189 包为基线，逐文件确认仅壁纸控制和 PMX/VRM 三个文件变更。签名清单及代码包已发布 LAN/WAN，外网 HTTP 清单、大小与 SHA-256 经发布器验证；外网手机更新及镜头实际效果待验收。

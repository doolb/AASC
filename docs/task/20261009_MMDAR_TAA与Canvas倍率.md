# 独立MMD AR：TAA与Canvas渲染倍率

日期：2026-10-09。状态：用户已确认方案，当前master实现完成，31项定向回归通过；手机验收待现场执行。

## 用户需求与候选契约

用户要求加入TAA，并允许设置Canvas分辨率倍率。建议本次覆盖独立MMD AR测试网页及其同源APK页面，沿用PMX/静态GLB共用场景；不扩大到正式AASC显示端或Blender导出。用户确认本任务的具体方案后，在当前master工作区按步骤实施。

- 正式“抗锯齿”分类提供TAA开关，默认关闭；历史累积强度默认0.9，范围0–0.95。
- 每帧一次场景绘制，使用8相位亚像素投影抖动；AO、接触阴影与SSGI合成后的最终RGBA进行历史重投影。
- 采用相机/深度重投影、深度和透明覆盖拒绝、邻域颜色限制及颜色变化降低历史权重。首版不增加PMX骨骼/morph运动矢量pass，动态稳定性有待真实角色验收，不能承诺快速头发/衣服运动完全无拖影。
- Canvas倍率放在当前实际分辨率显示附近，0.25–2.00、步长0.25、默认1。倍率相对现有自动DPR（限制1–2），实际像素为CSS尺寸×自动DPR×倍率；DPR2时0.5倍为CSS像素尺寸，1倍保持当前尺寸。
- 倍率按纹理/渲染缓冲上限等比例限制，显示实际尺寸及降档提示；本地保存、刷新恢复、复位回默认。
- 改倍率及后台恢复仅调整绘制目标或清除时间历史，保留角色变换和相机距离；绘制后恢复正常投影供拾取和AR使用。
- TAA有效时接触阴影使用时间采样相位；SSGI切断判断使用未抖动投影，历史重投影使用实际前帧抖动矩阵。

## 自测与兼容性

- 默认TAA关闭/倍率1保持当前实际像素和效果；有效开启后检查真实亚像素抖动及多帧边缘收敛，不能仅检查开关状态。
- 真实GLSL像素夹具验证遮挡揭露、深度/透明覆盖变化、颜色裁剪、历史UV越界、预乘alpha及读写目标隔离。
- 真实米娅动画和相机移动检查动态残影；静态GLB、透明发片/衣服、AO/接触/SSGI四种组合、诊断预览与图片导出按实际入口验证。
- SSGI不因每个抖动相位清空历史；接触时间相位仅在TAA有效时变化，关闭后静态噪声保持。
- DPR1/2分别检查0.25/0.5/1/1.5/2倍率、整数尺寸、设备上限、持久化与复位；比较角色根及相机变换，避免误触发fitCamera。
- 首帧、模型/动作跳转、相机切断、尺寸/倍率、后台/pageshow/上下文恢复等失效路径清旧帧；切后台/回前台及连续resize保留角色位置、旋转、缩放和相机距离。
- 异常也恢复投影/逆投影、渲染目标和主viewport；关闭、重复切换及resize释放旧目标。拾取使用恢复后的正常投影；AR原投影裁切保持。
- WebGL2不支持时明确禁用TAA，倍率仍可调；浮点目标使用能力检查与可用格式回退。
- 实际读取Canvas像素确认角色可见，不以modelReady代替画面检查。桌面软件GPU与模拟生命周期不替代手机WebView/实际AR/操作系统后台验收。

## 性能测试

固定真实模型、相机、效果及绘制尺寸，比较TAA开/关与0.5/1/2倍率。通过GPU计时或readPixels等待GPU完成，记录完整帧成本、目标数量/尺寸与估算显存；不得只测提交命令的CPU时间。倍率2使每维翻倍、像素约4倍，性能是否可接受由实际设备结果决定。

## 风险与处理

- 相机重投影不能精确还原骨骼/morph运动：使用深度/颜色拒绝并真实动画验证；若效果不足，重新明确运动矢量范围，不把静态结果当动态完成。
- 最终颜色/透明累积可能引入黑边或重复色彩变换：使用预乘alpha，显式保持现有颜色语义并比较TAA关闭/开启像素。
- AR裁切与SSGI历史可能被抖动破坏：区分基础投影及实际绘制投影，finally恢复，加入组合回归。
- 大倍率可能超过设备限制或显存能力：等比例限制尺寸、按需分配与销毁，实际显示降档结果；手机性能待设备验收。
- 已有后台保留变换修复必须保持：历史失效与位姿复位分离，复用并扩展真实浏览器回归。

预计实施4–8小时，另计目标设备观感与性能验收；该估计不包含完整动态运动矢量方案。

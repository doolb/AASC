# MMD AR 碰撞体按质量着色

- 日期：2026-10-01。
- 状态：已完成实现、构建与自动验证；未发布外网，待现场验收。
- 任务描述：在现有 PMX 碰撞体线框显示上加入刚体 weight（质量）可视化。
- design 需求：见 `docs/design/mmd-ar-test-apk.md` 的「2026-10-01 碰撞体按质量着色」。用户确认：线框按质量着色（取代 type 三色）；口径为物理有效质量（type0 恒为 0，type1/type2 取 weight）；着色与显示跟随当前选择过滤。
- spec 设计：见 `docs/spec/mmd-ar-test-apk.md` 的「碰撞体按质量着色（2026-10-01，已实现）」。有效质量推导、MassScale 固定范围、对数连续色带（蓝→青→绿→黄→红）、0 质量浅灰、逐实例颜色（分组键去掉 type）、图例与 500ms 刷新。
- 受影响模块和代码：`3rd/mmd-ar-test/web-rigid-body-debug.mjs`（质量/色带/逐实例颜色/分组键/状态）、`web-panel-groups.js`（图例元素、骨骼分组登记、轮询、CSS）；扩展 `tests/mmd-ar-rigid-body-debug.test.js`、`tests/mmd-ar-rigid-body-debug-browser.test.js`；仅 WEB_MODE 网页副本，正式显示端与旧 APK 不变。
- 自测用例：
  - 有效质量：type0→0；type1/type2 取 weight；weight 为 0/负数/非有限 → 0；
  - 色带：min/max 端点色正确、对数中点色、min==max 单色（色带中点）、无非零质量全灰；
  - 0 质量统一浅灰（不是 type0 红）；
  - 分组键去掉 type：相同形状不同质量的刚体在同一实例组内、逐实例颜色不同；
  - 过滤：选择过滤压缩 count 后，同一刚体颜色与过滤前一致（不漂移）；
  - 换模型重建 massScale 与颜色；关闭/销毁释放实例、几何、材质（无新增泄漏）；
  - 图例：骨骼分组存在 mmdArRigidBodyLegend，范围文字随 massScale 更新，含“灰＝有效质量 0”说明；
  - 既有：姿态（实际物理/配置预览）、形状尺寸、性能计数回归不变。
- 兼容性测试：物理开启/关闭、换 VMD、物理重载、换 PMX；骨骼小球 type 三色不受影响；桌面与手机面板滚动、窄屏布局；与相机动作/轨道等既有功能并存。
- 性能测试：实例组数量不高于改造前（分组键去掉 type 后应减少）；颜色只在模型提交时写入一次，逐帧仍只更新矩阵；无新增 Ammo/native 读取。
- 风险评估：type 三色语义被质量色替代（骨骼小球仍保留 type 色可互补，图例注明质量含义）；色阶范围随过滤重算会漂移（固定为全模型有效质量分布）；异常 weight（0/负/NaN）按 0 处理避免色带计算发散；连续色带在深色背景下的可读性待现场确认。

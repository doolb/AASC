# 其他控制面板横屏分栏

- 任务：服务器、搜索、日志、设置、提醒及声纹横屏使用多列，竖屏保持单列，兼容原有主题和操作。
- 设计：搜索输入和日志内容保留整行；聊天、任务、地图及 3D 保持适合内容的布局。
- 实现：按 `docs/spec/upload.md` 使用响应式网格，不修改控件标识或事件。
- 影响：控制页 HTML、控制端样式及控制端文档。
- 自测：Chromium 检查桌面、手机横竖屏的排列、溢出、主题和主要控件；运行已有控制页回归。
- 兼容性：深色、浅色、暖色主题以及 720px 横屏断点；动态列表和已有交互保持不变。
- 性能：纯 CSS 布局，无额外网络请求或持续运行的脚本。
- 风险：小屏横屏表单较窄，通过换行及最小宽度处理；真实设备观感仍需验收。
- 预计工时：约 2 小时；未明确事项：无。

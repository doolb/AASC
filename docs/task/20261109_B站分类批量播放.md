# B 站分类批量播放

- 需求：当前 B 站文件夹和未分类视频可批量播放，支持分集及现有播放控制。
- 设计与实现：见 `docs/design/batch-playlist.md` 和 `docs/spec/batch-playlist.md`；控制端提交文件夹，服务端生成播放列表，显示端 DASH 失败回退 MP4，失败后切换。
- 影响：媒体库控制页、播放列表服务和显示页；已有分类及单视频播放兼容。
- 自测：分类隔离、排序、分集、失效分类、浏览器入口与设置、回退后失败切换；现有 B 站和夸克专项回归。
- 性能：列表只生成代理地址，播放每项时再解析对应视频流，避免一次解析整批。
- 风险：实际可播放性依赖 B 站匿名接口及网络；真实设备联播仍需验收。
- 预计工时：半天。

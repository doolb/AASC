# MMD AR 继承当前动作与 T Pose 分帧初始化

- 日期：2026-09-30；状态：已完成实现与自动验证；发布及手机验收待处理。
- 任务描述：动作开关开启时，新选择 PMX 自动使用当前 VMD；模型/动作切换先绑定姿态初始化物理并清空速度，再在下一实际动画帧播放。
- design 需求：`docs/design/mmd-ar-test-apk.md` 同名已实现章节。当前动作包含内置和本地 VMD；没有动作时保持静态；动作关闭时新 PMX 不自动携带动作；物理关闭保持。自动循环不走新切换初始化。

- 受影响模块与代码：`3rd/mmd-ar-test/web-local-assets-ui.mjs` 继承当前 profile 与保留动作引用/标签；`web-motion-switch.mjs` 绑定姿态初始化及零速度；`web-local-assets-inject.js` 提交动作后的首帧延迟标记。`build.js` 现有复制/指纹流程需验证，仅发现必要适配时修改。
- 自测用例：更新 `tests/mmd-ar-motion-switch.test.js`、`tests/mmd-ar-local-assets.test.js`；必要时调整 `tests/mmd-ar-physics-lifecycle.test.js` 中原先依赖先第0帧的断言。真实 Three.js/Ammo 验证初始化骨骼为绑定姿态、全部刚体零速度/残留力、第一帧无动画、第二帧动作从头推进；本地与默认 VMD 换模型继承、标签和 URL 后续可用；暂停/物理关闭/无 VMD、错误回退及过期结果。

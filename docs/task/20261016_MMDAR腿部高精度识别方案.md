## 自测、兼容性、性能和风险

- 二维：已知bbox正逆仿射、非方形图、17点左右语义、SimCC尺寸/非法值、全身ROI覆盖、低分/出画/缺点；本坐姿/旧真人/二次元候选目视与数值回归。
- 三维：固定骨长/关节限位、已知深度/相机合成前后腿、无可行交点/多解、实际骨骼与目标分离、应用后相机接续；腿链实际投影必须比旧结果改善且无骨长篡改。
- 生命周期：下载/推理/拟合取消、换图/候选/模型/相机变化丢弃迟到结果，旧目标原子保留；现有粘贴、无人图、相机恢复保护。
- 兼容：桌面Edge WASM已临时运行；Android/iOS加载内存/耗时/缓存需实机验。不能套用原生RTMPose基准作为手机网页速度。
- 风险：新模型仅二维，接入不等于三维深度修复；遮挡关节仍可能错误、左右语义仍需核查。单图不唯一，失败保留手调路径。模型许可/指纹及实际输入尺寸在集成时再次核对。
- 预计二维接入与桌面回归2～4小时，腿链/相机一致性另需原型与合成验证，不预先承诺复杂遮挡3D一次全自动准确。正式代码未改，先确认修订方案。

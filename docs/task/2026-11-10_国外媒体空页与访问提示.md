# 国外媒体空页与访问提示

- 任务：修复日本代理下 YouTube 首页空白及 Pinterest 解析、访问受限提示。
- 设计：YouTube 无推荐时提示搜索；Pinterest 解析所有受支持的页面数据脚本，登录墙及 HTTP 访问拒绝给出明确提示。
- 实现：依 `docs/spec/media-library.md` 修改 YouTube、Pinterest 来源、任务媒体路由的固定安全提示白名单和相关测试，不将国外任务加入 release。
- 自测：空首页、正常首页、搜索、多个数据脚本、HTTP 401/403、已有 Cookie、其他网络错误与凭据脱敏。
- 兼容性：保留现有 ID、流、下载与代理契约，其他来源不受影响。
- 性能：页面仍受已有大小和请求时限限制；解析脚本按页面数量线性处理。
- 风险：上游登录和风控可能仍阻止首页及搜索；登录态真实验收尚待提供有效 Cookie。
- 预计工时：2 小时。
- 执行结果：国外来源与浏览器回归 20/20，媒体来源关联回归 8/8；真实日本代理下 YouTube 搜索返回 20 项，首页显示空推荐提示；Pinterest 匿名首页及搜索提示受限。登录态和真实播放待验收。

# 国内国外媒体用户任务

状态：主要代码已实现；上游适配、实机验收及发布兼容声明待完成（2026-11-10）

## 任务描述

实现国内媒体服务任务（红果短剧、番茄小说）和国外媒体服务任务（YouTube、Pinterest、Pixiv），复用任务媒体源协议与媒体库。国外任务仅保存在用户任务目录，不加入 release 清单或发布种子。

## Design 需求

各来源提供适用的首页、搜索、链接解析、相关推荐、播放与下载；番茄复用下载器服务及章节文本，YouTube 使用 yt-dlp，无法取得直链时返回错误。控制端按来源展示能力，失败局限在对应来源。命名代理按来源独立选择，未选择时直连；代理地址和 Cookie 不泄露到日志或显示端。详见 `docs/design/media-library.md`。

## Spec 设计

先遵循 `docs/spec/media-library.md` 中“地区媒体任务通用路由与下载”“国内媒体任务”“国外媒体任务”及命名代理伪代码实现。使用任务源能力校验、同源流、受限本地下载和下载索引；任务停止后撤销来源，番茄仅回收任务自行启动的进程。国内发布保留旧红果任务，来源冲突时先停止旧任务；国外任务不随 release 发布。

## 受影响功能模块和代码

- `res/tasks/domestic-media/`、`res/tasks/overseas-media/`：服务任务和各来源 provider。
- `src/apps/server/boot/server-app.js` 及媒体模块：通用任务源路由、流和下载索引。
- `src/apps/web-mediacenter/ui/public/`：任务来源工具栏、列表和播放下载交互。
- `release/task-code-files.json`：国内任务发布与旧红果兼容；国外任务不添加。
- 媒体库设计、伪代码、自测、使用说明、待办、变更日志及受影响发布状态同步更新。

## 自测用例

- 五个来源的首页、搜索、链接解析、相关推荐及能力缺失提示；切换或停止来源时清除视图，旧请求不能覆盖新结果。
- 红果公开剧集和可选 Cookie；番茄搜索、下载、书库、章节文本、TTS 与自建进程回收。
- YouTube 的 yt-dlp 首次准备、代理、播放错误提示和下载；Pinterest 匿名受限提示及 Cookie；Pixiv 多图、动图、Referer 和受限内容。
- 下载目标和路径校验、临时文件清理、防覆盖、索引与失效文件；Range 和来源停止时错误处理。
- 命名代理逐来源切换、未选择直连、凭据不泄漏；国内旧任务迁移和国外任务不进入发布产物。

## 兼容性测试

旧红果任务配置及记录、既有 B 站和夸克入口、无代理配置、缺少下载器或 yt-dlp、服务重启和任务停止均应保持可解释的行为。自动化采用隔离环境与模拟上游，真实网站及设备另作验收。

## 性能测试

检查分页和流式转发避免将完整媒体载入内存；验证下载临时文件和索引不因失败残留。上游接口、视频下载及代理吞吐受实际网络影响，必要时用真实环境测量。

## 风险评估

外部站点页面、接口和风控可能变化；凭证或下载器缺失会限制个别来源。文件路径、重定向及进程生命周期需严格校验，避免越界写入与残留子进程。新旧任务迁移不得删除用户配置或数据。

## 预计工时与待确认项

预计 3–5 个工作日，取决于站点实际接口和设备验收。实际匿名可用性、下载器部署路径和各站点风控以实施及实测结果为准；任务完成时记录未覆盖项。

# MMD AR 碰撞体实体模式与真实遮挡

- 日期：2026-10-01。
- 状态：已完成实现、构建与自动验证；未发布外网，待现场验收。
- 任务描述：碰撞体可视化从透过式线框改为「带 outline 的正常物体」，只显示未被角色遮挡的部分；并新增可单独隐藏角色、刚体可选线框/实体模式。
- design 需求：见 `docs/design/mmd-ar-test-apk.md` 的「2026-10-01 碰撞体实体模式与真实遮挡」。用户确认：不透明实体＋深色描边（默认实体、可切线框）；逐像素深度遮挡；选中骨骼过滤时保留穿透；可单独隐藏角色。
- spec 设计：见 `docs/spec/mmd-ar-test-apk.md` 的「碰撞体实体模式与真实遮挡（2026-10-01，已实现）」。模式/遮挡/穿透/隐藏规则、描边背面扩张、深度直写遍条件。
- 受影响模块和代码：`3rd/mmd-ar-test/web-rigid-body-debug.mjs`（样式/填充+描边实例/穿透/守卫/needsSceneDepth）、`web-rigid-body-debug.js`（深度遍、`setCharacterHidden`、显示层透传）、`web-panel-groups.js`（样式分段按钮、隐藏角色开关、提示文案）、`build.js`（必需控件）；仅 WEB_MODE 网页副本，正式显示端与旧 APK 不变。
- 自测用例：
  - 样式切换：wireframe/solid 资源重建、释放计数正确、几何共享；
  - 实体材质：填充不透明并开启深度测试/写入、保留逐实例质量色；描边为 BackSide 深色、实例矩阵放大 1.08；
  - 穿透：过滤激活时填充/描边关闭深度测试，取消过滤恢复；
  - `needsSceneDepth()`：仅 实体+全量+角色可见 时为 true；线框、过滤、角色隐藏时为 false；
  - 隐藏角色：`mesh.visible=false` 后叠加仍渲染（守卫不依赖 mesh.visible）、drawCount 继续增长；换模型后重应用；恢复显示；
  - 深度遍：AO 离屏生效（含 NormalPreview）且需要时执行 clearDepth+深度直写；AO 关闭时不执行（画布已有场景深度）；异常时恢复 overrideMaterial/autoClear；
  - 既有：质量色带、姿态（实际/预览）、过滤与选择、实例/几何释放、图例回归不变；
  - 面板：样式分段按钮默认实体与本地记忆、隐藏角色开关、提示文案与分组归属。
- 兼容性测试：物理开启/关闭、换 VMD、物理重载、换 PMX；AO 开/关与法线预览；骨骼小球并存；AR 失锁/首帧隐藏不因新守卫改变；横竖屏面板。
- 性能测试：实体模式实例组翻倍（填充+描边），分档数量与形状组一致；深度遍仅在实体+全量+角色可见+AO离屏生效时每帧一遍角色深度渲染，其余情况零开销；记录桌面软件光栅帧耗时作为环境参考，手机验收另计。
- 风险评估：AO 离屏合成清空画布深度（用条件深度遍解决，代价是实体模式下每帧一遍角色深度渲染）；实体模式下模型内部刚体不可见（提供选中穿透与隐藏角色两个出口）；描边为世界比例而非屏幕等宽（近距离与远距离粗细随形状尺寸变化）；隐藏角色只改 mesh.visible，需与 AR/首帧 pivot 门控区分并在换模型后重应用。
- 需求评审（enterprise 默认；可选 standard）：可开发；主等级 L6，次等级 L5；建议下放到 L4。
  - 强证据 L6：换成带 outline 的正常实体、只显示未遮挡、可隐藏角色、可选线框/实体（用户确认），共权重 9；中证据 L5：遮挡与 AO 管线配合、穿透规则，权重 2。置信度 9/11×0.90≈0.74。
  - 层级清晰度 22/25，证据充分度 18/20，实现完备度 16/20，风险暴露度 17/20，L4 可落地性 14/15；总分 87/100。直接开发风险中，关键在深度缓冲与渲染顺序。
  - 断点通过「条件深度遍」「过滤穿透」「mesh.visible 与 pivot 门控分离」解决；L4 三段草案已写入 spec。
  - 后续技能选项：ai-code-translation / project-pseudocode-sync / 仅保留判级；用户选择仅保留，按项目流程实施。

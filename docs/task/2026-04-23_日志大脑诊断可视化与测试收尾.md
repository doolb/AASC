# 2026-04-23 日志大脑诊断可视化与测试收尾

## 任务描述

- 为日志大脑新增 `brain-diagnose` 真 LLM 诊断接口。
- 控制端新增“日志大脑”可视化页面，支持摘要、时间线、一键诊断。
- 将日志大脑阈值配置化到 `config/config.json`。
- 增加最小自动化测试覆盖：单测、API 集成测、跨设备链路测。
- 补充目录映射规则，防止回退到旧路径。

## Design 需求

1. 保留 `brain-summary` / `brain-judge`，新增 `brain-diagnose`。
2. `brain-diagnose` 直接走 `src/external/llm/llm-service.js`。
3. 诊断输出标准化为：可能原因、证据日志、排查步骤、风险级别。
4. 前端页面必须支持快速人工验证“类人脑”行为。

## Spec 设计

1. `src/framework/observability/log-brain.js`
   - 新增阈值配置注入。
   - 新增诊断上下文构建和回退诊断。
2. `src/apps/server/api/log-brain-api.js`
   - 聚合 `brain-summary / brain-judge / brain-diagnose`。
   - 负责 LLM 响应 JSON 解析与 fallback。
3. `public/js/log-brain-viewer.js`
   - 管理摘要拉取、时间线渲染、诊断调用与结果展示。

## 自测用例

1. 打开控制端“日志大脑”页，刷新摘要，确认卡片和时间线刷新。
2. 输入诊断问题，点击“开始诊断”，确认结果面板输出四类结构化内容。
3. 断开 LLM 时，确认返回 fallback 诊断而非 500。
4. 执行 `npm run test:log-brain`，确认三类测试全部通过。

## 兼容性测试

1. 现有日志页（`panel-logs`）功能不受影响。
2. `brain-summary` 和 `brain-judge` 接口保持向后兼容。
3. `config/config.json` 新增 `logBrain` 字段后，旧配置可按默认值运行。

## 性能测试

1. `brain-summary` 默认 limit=300，验证响应时延在可接受范围。
2. 前端时间线渲染上限 80 条，避免大列表阻塞 UI。

## 风险评估

1. LLM 返回非 JSON 文本导致解析失败：已加 JSON 抽取 + fallback。
2. 阈值配置异常导致误报：已加数值归一化与默认值。
3. 诊断面板展示 XSS 风险：已统一 HTML 转义。

# PMX 旋转物理阈值默认值与上限调整

## 任务描述

将 PMX 快速旋转暂停物理阈值的默认值从 180°/秒提高到 720°/秒，滑块上限从 720°/秒提高到 1440°/秒。

## Design 需求

- 未保存阈值时使用 720°/秒；“恢复默认”也使用 720°/秒。
- 滑块保留最小值 30°/秒和步长 10°/秒，上限调整为 1440°/秒。
- 已保存的自定义值继续保留，不迁移或覆盖；PMX 旋转速度判断与物理暂停、恢复流程不变。

## Spec 设计

见 `docs/spec/mmd-pmx-vmd-local.md` 的 `MmdLightingSettings` 与 `normalizeMmdLighting` 伪代码。显示端主设置与 PMX runtime 均使用相同范围、默认值和对齐规则；面板默认、输出和复位行为与规范化结果一致。

## 自测用例

- 无保存值和旧保存对象缺字段时得到 720°/秒。
- 1440°/秒可输入并保存；超出上限被限制为 1440°/秒。
- 已保存的 180°/秒等自定义值保持不变；选择灯光预设仍保留该值。
- 点击“恢复默认”重置为 720°/秒。

## 兼容性测试

- PMX 物理频率、布料暂停及恢复流程不变；VRM 不读取该阈值。
- 旧浏览器 localStorage 不做强制迁移。

## 性能测试

- 仅调整常量与范围校验，不增加逐帧计算；运行现有 MMD 定向测试和项目 `npm test`。

## 风险评估

- 阈值提高后物理暂停触发更晚，真实模型在快速旋转下可能更容易穿模；保留滑块供现场调低。

# 媒体目录卡片对比度修复

- 任务：修复浅色目录卡片的文字和按钮不清晰，兼容普通目录及夸克分享目录。
- 设计：目录背景、名称、附加信息和按钮使用同一套主题变量，保留现有操作。
- 实现：按照 `docs/spec/upload.md` 调整目录专属样式，避免全局按钮规则覆盖。
- 影响：控制端媒体库 CSS、浏览器自测和控制端文档；不涉及播放逻辑。
- 自测：覆盖深色及现有浅色主题的名称、附加信息、按钮文字和背景对比度，检查手机、桌面及目录操作。
- 兼容性：主题切换、普通目录、夸克分享、窄屏和触屏。
- 性能：纯样式调整，无新增请求或运行循环。
- 风险：主题变量可能随未来主题调整；使用测试校验现有主题实际对比度。
- 预计工时：约 1 小时；未明确事项：无。

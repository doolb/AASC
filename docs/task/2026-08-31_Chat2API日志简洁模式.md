# Chat2API 日志简洁模式

## 任务描述

在已有 Chat2API 原始请求/响应调试日志上增加简洁模式，只保留请求模型、请求文本和最终输出，减少 URL、请求头及原始流量对日志的干扰。

## design 需求

- 增加 `rawTrafficMode=full|compact`，默认完整模式。
- 简洁模式支持非流式、SSE 和压缩 SSE，不改变上游请求与响应。
- 控制端可切换模式；保留最大字节数和敏感信息保护。

## spec 设计

```text
配置选择 compact:
    Provider adapter -> raw logger compact
    请求 -> {model, text}
    响应 -> {output}
    流式响应结束后只输出聚合结果
```

## 受影响模块

- `src/apps/server/modules/chat2api/chat2api-raw-traffic-logger.js`
- `src/apps/server/modules/chat2api/chat2api-management-service.js`
- `src/apps/server/modules/chat2api/chat2api-provider-adapters.js`
- `src/apps/web-mediacenter/ui/public/js/chat2api.js`
- 对应测试和项目文档。

## 自测用例

- 默认完整模式回归不变。
- 简洁非流式只输出 model/text/output。
- 简洁 SSE 聚合输出，不输出 URL、headers 或原始 chunk。
- 简洁 gzip SSE 聚合输出。
- 非法模式保存失败。

## 风险评估

- 不同 Provider 的请求/流格式不同，需要使用安全的通用文本提取和解压逻辑。
- 无法解析的二进制流不能输出原始内容，只返回安全的不可解析提示。

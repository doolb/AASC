# TTS 背景透明度设置

## 任务描述

在控制端“界面主题”中的显示端背景光晕设置后增加 TTS 字幕背景透明度设置。初始实现范围为0%–20%，已由 `20261014_TTS背景透明度范围扩展.md` 扩至0%–100%，默认20%。

## 自测用例

- 检查设置位置、默认20%、当前范围0%–100%和1%步长。
- 检查服务端校验、config.set持久化、权威广播及两类客户端重连补发。
- 检查0%、20%和100%分别应用alpha 0、0.2和1，默认回退为0.2。
- 检查背景模糊、白字/细边、三行字幕和隐藏生命周期不变。

## 兼容性测试

覆盖普通浏览器与 Android Offline WebView 的 CSS 自定义属性和 WebSocket 消息；未收到配置的旧显示页使用原有0.2效果。

## 性能测试

配置只在收到消息时更新CSS属性，不增加动画或逐帧计算。

## 风险评估

透明度变量如果误用于字幕根节点会同时淡化文字；实现只替换背景渐变的 alpha。配置默认值确保断线时外观兼容。

## 预计工时

约 1.5 小时。

## 实施与验证记录

初始版本在背景光晕设置后增加0%–20%滑块（步长1%，默认20%）；范围扩展任务将控制端滑块改为0%–100%，并保留服务端/WebSocket使用0–1比例值的协议。显示端两个渐变峰值使用 `--tts-subtitle-background-opacity`，未收到配置时仍使用0.2。

验证：`node --test tests/display-tts-background-opacity.test.js` 共3/3通过，覆盖默认/范围/规范化、远端配置契约及浏览器计算样式（alpha0.13、blur4px、文字opacity不变）。Offline Android WebView现场调节验收待完成；本轮未构建或发布服务包/APK。

## 执行步骤

1. 读取当前Git状态，盘点文件与两类试验传递依赖。
2. 生成本机精确保留/删除清单，逐项校验绝对路径、普通文件及链接边界；保存保留输入摘要。
3. 按清单删除专用资源；未知文件及工作区外路径不删除，保留共享依赖数据字节。
4. 调整共享静态报告入口和人物分割现行报告链接；不重启用户服务。
5. 检查删除结果、保留摘要、相对模块依赖、HMR/人物分割原始结果与浏览器报告。
6. 同步usage、self-test、design/spec/changelog；完成后从todo移除本任务。

- 兼容：默认静态入口为HMR，人物分割入口仍原路径；正式MediaPipe/IK与既有用户服务不被切换。

## 性能、风险与工时

仅删除专用缓存，不改变网络/物理算法，无新增每帧开销；模型数值一致和报告显示不等于识别质量改善。主要风险为人物分割跨目录依赖、历史protectedHashes引用及本机原图路径；通过传递依赖审计、完整摘要与既有检查降低风险。权重多未入Git，删除后恢复需要重新下载。预计0.5～1小时；不构建APK/发布包，不改Offline待出包状态。

# WebDAV、抖音和用户媒体采集

- 任务：新增并列 WebDAV 媒体库、抖音国内来源和油猴用户媒体采集。
- 设计：WebDAV 对接 AList 及通用服务，支持只读及写操作；用户媒体按站点、内容、播放列表保存；抖音支持公开分享链接。
- 实现：先同步媒体库伪代码，再增加 provider、控制端、采集和任务入口；保护认证、范围及用户数据。
- 影响模块：媒体库服务及 UI、国内任务、用户目录、Offline 服务包和任务代码包。
- 自测：WebDAV 认证、目录、Range、重定向、写入和只读；采集鉴权、路径和列表；抖音链接播放和下载。
- 兼容：保留原有本地/HTTP/SMB 行为和远端媒体库流程；Android 与 Linux 分别验收。
- 性能：媒体流按需转发，不全量缓冲；列表和上传大小有界。
- 风险：第三方 WebDAV 差异、浏览器无法发现的链接、过期地址、抖音登录和风控。
- 预计工时：3–5 工作日；真实 AList 和抖音账号验收依赖现场环境。
- 实施结果：WebDAV、抖音和采集入口已完成，47 项定向测试通过，覆盖真实本机 HTTP WebDAV、转封装、代理和凭据校验；真实匿名抖音链接提示需要新鲜 Cookie，AList 和带 Cookie 的抖音待现场验收。

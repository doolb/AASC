# MMD AR骨骼大小、名称、点选与碰撞累计

日期：2026-10-01。状态：用户已确认，已实现并验证。

## 任务与需求

用户要求手动控制骨骼小球大小并显示骨骼名称，继续增补点选后只显示发生过碰撞的相关碰撞体（允许累计），以及选中骨骼旋转轴。具体方案告知文件/行为后，用户回复“是”；结合原句“发生碰撞”“累计”，采用实际接触累计，实施前已说明该解释。

范围承接独立WEB_MODE“动作 → 骨骼”。新增大小倍率0.2～3、步长0.1、默认1和名称开关默认关闭，保存本地偏好。轻点小球选中、点空白取消，拖动及双指仍使用原操作；选中名称/白环/局部XYZ轴及末端字母，X红/Y绿/Z蓝。碰撞体开关打开时，只显示选中骨骼自身所有直接关联刚体与从选择开始累计的实际接触直接对手，不递归碰撞链；换选/取消/关闭骨骼/PMX或physics替换清累计，清空按钮主动重置。灰骨骼无关联刚体时不借父级接触，物理关闭只预览自身配置位置。

## 兼容性、性能与风险

面板8项包含窄屏/横竖屏、触摸滚动及既有交互。文字和点击共享renderer的本地CSS区域，屏幕外/相机后方跳过；关闭且无选择不遍历名称，隐藏后不重复清大画布，未选择不扫描接触。累计集合有界，native对象借用不销毁，模型替换/销毁释放轴及Canvas。

软件SwiftShader、同时运行面板回归的8帧采样：骨骼/名称关闭813.88ms/帧，骨骼/名称开启1027.91ms/帧；仅记录该环境，不能推断手机帧率。密集名称允许重叠，手机名称/轴可读性、触摸命中与开启180Hz时性能保留现场验收，不承诺自动排版。

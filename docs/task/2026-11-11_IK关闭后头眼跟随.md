# IK 关闭后头眼跟随

- 任务：修复关闭全身 IK 后头部与眼球跟随不生效。
- design：头眼注视不依赖身体 IK；手动目标和显式动作优先。
- spec：IK 不可用时恢复身体姿态基准后施加注视，PMX 继承后保持身体并保留头部注视；正常 IK 路径保持原混合顺序。
- 影响：正式 Human 接口、动作混合器及自测。
- 自测：IK 关闭、开启、手动目标接管和注视开关，验证实际骨骼而非仅状态。
- 兼容：不同 PMX 缺失或动态骨骼仍按原绑定能力降级；壁纸触摸仍受桌面事件转发约束。
- 性能：复用现有渲染帧，不增加计时器或异步循环。
- 风险：IK 关闭时姿态保持与物理更新顺序需验证；真实手机、模型视觉效果待设备验收。
- 预计工时：2 小时。
- 验证结果：正式真实 PMX 浏览器检查初始关闭不累积、关闭后头部和共有眼/左右眼转动通过；IK 专项其他 20 项、跟随与动作回归 33 项通过。真实手机和其他 PMX 待验收。

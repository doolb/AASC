# 恢复普通页面监听按钮

- 任务描述：恢复普通 APK 显示页面的实时/单次监听文字按钮及原位置，壁纸系统浮窗保留小圆点。
- design 需求：普通页面与系统浮窗分别使用各自原有外观，共用监听模式与操作。
- spec 设计：普通页面恢复舞台按钮及原位置；壁纸浮窗监听圆点继续调用原有桥接和服务端权威配置。
- 影响模块和代码：显示页面 HTML、语音控件 CSS、浏览器自测及相关文档；不改 Android 原生浮窗。
- 自测用例：普通页面按钮文字、位置、大小和主题，切换实时/单次后同步；系统浮窗模式桥继续切换。
- 兼容性测试：深色与浅色主题、不同视口和壁纸模式下网页控件隐藏；手机实机待验收。
- 性能测试：只恢复静态布局，无新增计时器或常驻计算。
- 风险评估：恢复旧布局可能与底部入口重叠，浏览器测试检查按钮边界与正常点击。
- 预计工时：1 小时。
- 验证结果：语音与壁纸定向 30 项通过，包含普通按钮位置及深浅主题切换、壁纸模式桥；Android 实机待验收。

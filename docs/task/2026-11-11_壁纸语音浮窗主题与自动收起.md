# 壁纸语音浮窗主题与自动收起

- 任务：将桌面系统浮窗改为语音状态、大圆和监听小圆点，支持主题及贴边自动收起。
- 设计及伪代码：见壁纸控件、语音控件对应 design 和 spec。
- 模块：Android 壁纸浮窗、显示端语音控制、语音自测及发布状态。
- 自测：语音状态和权威模式、主题、语音操作、贴边计时、展开和生命周期清理。
- 兼容性：旧服务代码缺少新桥接方法时浮窗保持不可操作；悬浮窗权限及不同桌面需真机验收。
- 性能：浮窗可见时低频同步状态，隐藏时释放回调和视图。
- 风险：Android 桌面权限、系统窗口层级和屏幕旋转在不同设备上可能不同。
- 预计工时：约 3 小时。

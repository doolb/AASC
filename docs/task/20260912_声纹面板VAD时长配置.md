# 2026-09-12 声纹面板 VAD 时长配置

## 任务描述

将播放期间录音相关的 VAD 参数 `silence=500ms`、`minSpeech=300ms` 加入控制端声纹面板，作为全局配置统一下发给网页显示端和 Node 子显示端。

## Design 需求

- 服务端保存 `voiceprint.vadSilenceDurationMs` 和 `voiceprint.vadMinSpeechDurationMs`。
- 默认值分别为 `500ms`、`300ms`，允许范围为 `100..5000ms`，异常值归一化到范围内。
- 声纹面板加载当前值，修改后通过 `/api/voiceprint/config` 保存。
- 服务端通过 `voiceprintConfig` 广播给所有在线显示端；新连接的 `voiceVadConfig` 也使用全局时长。

## Spec 设计

```text
声纹面板初始化:
  GET /api/voiceprint/config
  将 vadSilenceDurationMs 显示到静音时长输入框
  将 vadMinSpeechDurationMs 显示到最短语音输入框

声纹面板保存:
  读取两个 number 输入
  将值限制在 100..5000ms
  POST /api/voiceprint/config

服务器保存:
  归一化两个字段
  保存 voiceprint.vadSilenceDurationMs、voiceprint.vadMinSpeechDurationMs
  voiceprintConfig 广播两个字段

网页显示端 / Node 子显示端:
  收到 voiceprintConfig 后更新 VAD 静音结束时间和最短语音长度
```

## 自测用例

- 默认配置包含 `500ms/300ms`。
- GET 接口返回两个全局字段。
- POST 接口持久化并广播两个字段。
- 声纹面板包含两个带 `100..5000` 范围的输入框，并提交字段。
- 网页显示端和 Node 子显示端收到 `voiceprintConfig` 后应用两个字段。
- 旧配置缺少字段时回退到默认值。

## 兼容性测试

- 旧显示端忽略新增 `voiceprintConfig` 字段时，原有播放暂停和 VAD 默认行为不变。
- 旧 `voiceVadConfig` 的 per-display 阈值协议继续保留。
- Node 子显示端继续复用现有 `applyVadConfig`，不改变 PvRecorder/naudiodon 音频采集链路。

## 性能测试

- 配置只在保存和 WebSocket 广播时处理，不增加音频帧处理开销。
- 运行现有定向 Node 测试和全量 `npm test`。

## 风险评估

- 旧配置可能没有新字段，服务端统一回退 `500ms/300ms`。
- 输入过小或过大的值会被限制到 `100..5000ms`，避免 VAD 过早结束或长时间不结束。
- 当前 per-display VAD 时长字段协议保留兼容，但声纹面板设置的全局值在显示端最终生效。

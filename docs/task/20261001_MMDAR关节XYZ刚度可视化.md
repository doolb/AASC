# 2026-10-01 MMD AR关节XYZ刚度可视化

## 需求与状态

用户希望看PMX XYZ的K值分布和方向。当前明确为：单一开关显示平移XYZ/旋转XYZ K及轴限位，选中只显示对应、未选全部；选中再显示实际位移/角度变化。最新补充要求K用颜色可视化，候选六色标分别编码每轴K强弱；六K属于关节，现有模块没有专用显示。用户已确认完整方案并纠正显示方式：当前已改为局部平移箭头/旋转圆弧及图形限位/实际变化，模型旁文字卡片已移除，面板保留数值。本地web-dist已重建，以末尾最新实施说明为准。

## 设计与实现计划

见design/spec顶部最新伪代码。新增web-joint-stiffness-debug.mjs，修改web-skeleton-selection.mjs、web-skeleton-debug.mjs/.js、web-panel-groups.js、build.js；复用现有选择、物理姿态与生成指纹，支持Ammo/XPBD只读诊断。一个“显示关节K值与限位”开关、默认关闭、本地记忆；开启且骨骼总开关开启时，在关节附近显示名称、平移/旋转六K与十二上下限，XYZ用字母标识，颜色表示K强弱；平移模型单位、旋转度数，0K标弹簧关闭，等上下限标锁定，下限大于上限标自由。未选全量，选中按自身骨骼关联刚体的任一端关节去重，不扩展到累计碰撞对象；空关联提示。

选中时增加实时实际位移XYZ/旋转XYZ，按两端真实刚体的原关节局部框架计算，表示相对关节绑定姿态的变化；非相邻帧差或累计绕圈量。无物理显示未模拟，不用动画/配置预览替代。静态K/限位文本缓存、可见面板读数约10Hz刷新，叠加锚点跟随当前关节；关闭不更新，模型/后端/VMD切换重新读当前实例并清缓存。本轮替代原K对数箭头/模式及手动范围切换方案，不增加这些控件，也不实施质量/惯量曲线与独立参考模拟。

### 最新补充：K颜色编码

每关节平移XYZ/旋转XYZ两排六色标及数字，XYZ用字母标识，色标/数字按K强弱着色，替代上一段XYZ固定RGB的K展示约定。正K从低蓝经青/黄到高红，K0灰并标弹簧关闭。平移/旋转两组各取全模型正K对数范围，筛选不改变归一化；相同正K映射中点，无正K标全0，两组各有色带及min/max图例。静态颜色/字符串按模型缓存，不按最大值或均值混合六K给整骨骼着色。限位与选中实际变化需求保持；最新design/spec为准，代码已接入。

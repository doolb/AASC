# 控制端左侧页签溢出修复

## 任务状态：✅ 已完成

## 任务描述

控制端左侧页签入口数量增加后，导航内容会超过窗口底部，部分入口无法访问。需要让左侧导航在固定侧栏内部独立滚动，不影响右侧内容面板。

## Design 需求

参考：[design/control.md](../design/control.md)（左侧导航高度适配）。

- 左侧侧栏继续固定覆盖视口高度。
- 导航区域占用侧栏头部之外的剩余高度。
- 导航入口超出可视高度时，仅导航区域启用垂直滚动。
- 入口数量未超出时，保持现有布局和交互表现。

## Spec 设计

参考：[spec/sidebar.md](../spec/sidebar.md)（导航高度约束）。

```text
初始化侧边栏布局:
    侧边栏固定覆盖视口高度
    侧边栏导航区域占用头部之外的剩余高度
    允许导航区域收缩到剩余高度
    当导航项总高度超过可视高度时，仅导航区域出现垂直滚动
    导航区域滚动不影响右侧内容区域和当前面板状态
```

## 自测用例

1. 读取真实 `upload.css`，确认 `.sidebar-nav` 保留 `flex: 1`。
2. 确认 `.sidebar-nav` 包含 `min-height: 0`，允许 flex 子项收缩。
3. 确认 `.sidebar-nav` 包含 `overflow-y: auto`，入口超高时可垂直滚动。
4. `node --test tests/sidebar-layout.test.js` 通过。
5. `node --check src/apps/web-mediacenter/ui/public/js/main.js` 通过，确认导航脚本未受影响。

## 兼容性测试

- 入口高度未超出窗口时，不新增滚动行为，现有样式保持不变。
- 入口高度超出窗口时，滚动范围限制在左侧导航区域，右侧面板不参与滚动。
- 不改变硬编码入口、动态注册入口的顺序和点击切换逻辑。

## 性能测试

- 仅新增 CSS 布局属性，无 JavaScript 轮询、事件监听或额外网络请求。
- 导航滚动由浏览器原生滚动机制处理，复杂度不随入口数量增加额外计算逻辑。

## 风险评估

- 低：修改范围仅限 `.sidebar-nav` 布局约束。
- 窄屏或低高度窗口会显示原生滚动条，属于预期的可访问性行为。

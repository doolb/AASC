# MMD-AR编辑／预览／渲染首版

用户确认三个工作区、刚体/关节编辑、撤销重做、工程保存、动作预览、PNG导出。

## 设计和范围

新增独立web-editor-*模块，复用PMX加载、场景与物理；build.js仅添加构建入口。原始模型文件保留，项目覆盖物理字段，不改变模型顶点。编辑暂停模拟并显示绑定姿态，预览重建物理。工程ZIP包含源文件与材质扩展，跨机器可重新打开。

## 验证与风险

构建/浏览器检查编辑、撤销、重载、工程往返和PNG；物理重建不得丢弃覆盖值。大工程会占用内存，校验展开大小和引用。网页下载由浏览器处理；APK文件保存体验需设备验收。旧模型不支持的PMX特性保持原有加载器边界，源字节不丢失。预计本轮完成首版，后续另做权重/视频。

# 控制端监听开关与全局降噪配置

## 任务描述

- 修复控制端点击显示端监听开关无实际生效且无失败反馈的问题。
- 删除控制端“显示端 ASR 处理”区域和语言选择，正式显示端统一使用中文 ASR。
- 将降噪开关移动到声纹面板，并让普通 ASR、单段声纹、快速多段声纹共用。

## design 需求

- 监听开关只允许一条事件委托链路，发送前检查控制端 WebSocket，服务端回传后更新状态。
- 语言参数内部固定为 `zh`，控制端不显示语言选择。
- 声纹配置接口承载全局降噪状态，并同步给显示端的 ASR 与声纹流程。

## spec 设计

- `DeviceList.toggleVoiceListening(displayId, enabled)` 负责检查连接、显示发送状态、发送 `updateCapabilities`。
- `/api/voiceprint/config` GET/POST 增加 `denoise`；POST 后广播 `voiceprintConfig` 与 `asrConfig`。
- `display.html` 固定 `asrLanguageMode='zh'`，降噪读取全局 `asrConfig.denoise`。

## 自测用例

1. 树形和列表视图点击监听开关只发送一次 `updateCapabilities`。
2. WebSocket 未连接时开关恢复原状态并显示失败提示。
3. 声纹面板可加载、保存全局降噪状态。
4. 控制端不再出现 ASR 语言选择和独立 ASR 降噪区域。
5. 显示端收到配置后普通 ASR 固定使用中文，降噪状态同时作用于普通 ASR 与声纹流程。

## 兼容性测试

- 旧配置缺少降噪字段时按 `false` 读取。
- 旧显示端收到 `asrConfig.languageMode` 时仍可连接，但新正式页面固定传 `zh`。
- 浏览器端和 Android APK 均保持现有 ASR/声纹接口兼容。

## 性能测试

- 本次不增加识别步骤；仅调整配置入口与监听控制消息链路。
- 检查监听开关点击不会触发重复发送或重复渲染。

## 风险评估

- 控制端 WebSocket 断线时不能修改显示端状态，必须明确提示用户。
- 降噪配置同时影响普通 ASR，开启后会增加单次预处理耗时。

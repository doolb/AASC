## Review Focus

1. 最终骨架与IK目标不同：快照必须读真实骨骼，并兼容GPU直连同步。
2. 不同图片/主画布宽高与舞台旋转：等比投影，无拉伸；参考虚拟视角与主画布取景分离。
3. 读取时动画/物理或用户改变姿态/相机：应用前复核、过期拒绝。
4. 相机VMD/AR/编辑器覆盖：不抢占，恢复与手动旋转缩放必须接续。
5. 多次匹配或换图/模型：基线恢复可解释，隐藏停止刷新，错误不改骨骼或视角。

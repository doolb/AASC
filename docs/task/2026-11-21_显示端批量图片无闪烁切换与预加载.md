# 显示端批量图片无闪烁切换与预加载

## 任务描述

修复外部媒体服务通过 `playlistUrlRequest` 等方式下发图片播放列表时，显示端切换图片短暂露出 `#mediaContainer` 背景与光晕的问题。实现提前预加载下一张图片、新图就绪后再无缝替换画面、直连失败回退 `fallbackUrl`、全失败不卡死、快切/暂停/恢复/循环/列表替换防过期覆盖，且不影响视频/音频/文本/HTML/GIF/B站媒体及现有适配、裁剪、旋转和尺寸上报。

## design 与 spec 对应

- 设计文档：`docs/design/batch-playlist.md`（2026-11-21 节）
- 实现文档：`docs/spec/batch-playlist.md`（图片无闪烁切换、预加载与暂停/恢复伪代码）

## 自测与兼容性计划

1. 模拟慢速外部 URL 与 `fallbackUrl` 代理回退、全失败不卡死、不重复调度切页定时器。
2. 验证预加载命中、快速连续切页、暂停/恢复、循环、`playlistStart` 替换、切入视频/文本时旧异步结果丢弃。
3. 使用无头 Chromium/Puppeteer 验证真实 `display.html` 在切换慢速图片期间，`#mediaImage` 与 `#mediaImageHold` 无空白窗口露出背景，且适配/裁剪/旋转/尺寸上报正确。
4. 回归已有播放列表、媒体清理、休眠、动态适配与视频循环相关测试。

## 风险评估与预计工时

- 风险：现有单测通过文本切片提取 `display.html` 局部函数并注入 `const mediaImage`，因此不可更改 `mediaImage` 引用绑定，新模块需以 `window.DisplayImagePreloader?.` 安全降级调用；此外首张图定时时机调整后需同步校验 `tests/display-playlist-fallback.test.js`。
- 预计工时：2 小时。

## 实机待验项

- 真机（Android WebView / 平板 / 电视浏览器）上通过外部媒体服务 `playlistUrlRequest` 连续播放大分辨率外部图片和 `no-store` 代理图片，肉眼确认切换无闪屏、内存无持续增长、横竖屏旋转和动态填充平滑正常。

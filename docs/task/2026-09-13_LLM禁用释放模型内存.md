# LLM 禁用释放模型内存

## 任务描述

当控制端关闭显示端的 LLM 能力时，APK 释放 MNN-LLM 模型运行时内存；保留磁盘模型缓存，重新开启时从缓存加载。

## design 需求

- `capabilities.llm.enabled=false` 通过现有 `capabilitiesUpdated` 下发。
- 显示端等待当前推理和切换安全结束后释放 native engine。
- 只释放 LLM，不影响 ASR、TTS、CPU 配置和已下载文件。
- 状态上报 `disabled/ready=false`；重新启用优先加载缓存。

## spec 设计

```text
capabilitiesUpdated
  -> llmSetEnabled(false)
  -> wait current inference/switch
  -> MnnLlmEngine.release
  -> retain active directory and selectedModelId
  -> llm.status(state=disabled, ready=false)
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/display.html`：处理 LLM 能力开关并调用原生桥。
- `src/apps/android-display/app/src/main/java/com/aasc/display/NativeBridge.kt`：增加 LLM 启停桥接方法。
- `src/apps/android-display/app/src/main/java/com/aasc/display/MnnLlmModelManager.kt`：增加安全释放、禁用状态和缓存重载。
- `tests/apk-llm-capability-release.test.js`：增加桥接、释放和缓存保留契约测试。
- `docs/design/android-mnnchat-llm.md`、`docs/spec/android-mnnchat-llm.md`、`docs/todo.md`、`changelog.md`。

## 自测用例

1. 控制端关闭 LLM 后显示端收到 `capabilitiesUpdated`。
2. 当前推理未完成时不释放 engine，完成后释放。
3. 禁用状态为 `state=disabled`、`ready=false`。
4. `active` 模型目录和 `state.json` 保留。
5. 重新启用后从缓存加载，不重复下载。
6. ASR/TTS 状态和 CPU 配置不变化。

## 兼容性测试

- 没有原生 LLM 桥的浏览器显示端忽略该能力处理。
- 旧服务端未发送 `capabilities.llm` 时按启用兼容。
- 旧模型选择、推理、切换和回滚流程不变。

## 性能测试

- 禁用后 native 模型内存应释放，磁盘缓存不重复写入。
- 重新启用只进行本地模型加载，完整缓存时不访问下载接口。

## 风险评估

- 风险：关闭期间仍有推理任务时提前释放导致 native 崩溃。
- 控制：复用 `activeRequests/queueDepth` 等待机制，在模型管理器串行线程释放。

## 预计工时

约 1 小时，含 Kotlin 构建、静态契约测试和真机开关验证。

## 实施结果

- `display.html` 收到 `capabilities.llm.enabled=false` 后调用原生 `llmSetEnabled(false)`。
- `MnnLlmModelManager` 在模型切换线程中等待在途推理完成，释放 `MnnLlmEngine`，保留模型目录和选中状态。
- 重新启用时优先通过现有 `RemoteModelManager` 校验并加载本地缓存，不删除或重复下载已完成文件。
- ASR/TTS 代码路径和 CPU 配置未改变。

## 验证结果

- 定向 JavaScript 契约测试：15/15 通过。
- `npm run build:apk`：官方 MNN 依赖和 arm64-v8a Debug APK 构建成功。
- APK 已安装到 `192.168.1.6:5555`，并使用 `npm run start:apk:display` 无参数启动。
- 真机关闭 LLM：收到 `state=disabled、ready=false`；服务端 ready 映射移除；`active` 目录 9 个文件和 `state.json` 保留。
- 真机重新开启 LLM：从缓存进入 `switching -> loading -> ready`，未重新下载模型。
- 真机内存对比：禁用前 Native Heap PSS 为 `1,063,346 KB`，禁用后为 `957,662 KB`，下降约 `103 MB`；TOTAL PSS 从 `1,235,875 KB` 降至 `1,120,524 KB`，下降约 `113 MB`。
- 当前设备按用户手动设置保持 `LLM 已禁用`；重新开启后会复用已保留的本地模型缓存。

# MMD-AR 旋转暂停恢复布料跳动

- 日期：2026-10-11。
- 状态：用户确认后已完成实现、自测与本地网页构建；外网发布与设备验收待执行。
- 任务：旋转速度超过暂停物理阈值后，恢复布料不应沿旋转方向突跳。

## 需求分析

采用 analyze-requirement-level enterprise 模式。主等级 L5（暂停/恢复状态流转），次等级 L4（变换及历史同步）；邻层混合，建议下放到 L4，能力等级 L4。证据：用户明确指出阈值停止物理；用户指出恢复布料沿旋转方向跳动；源码恢复只重置锚点、动态刚体清零速度而保留旧位置。主等级强证据权重6、全部权重8、一致性系数0.9，置信度0.675。结论：方案可开发，代码需按项目规则确认；真实模型视觉验收仍待执行。评分：清晰度23/25、证据16/20、完备度16/20、风险17/20、L4落地13/15，总分85/100。风险中：非单位缩放、动画期间骨骼变化、求解器内部历史和GPU状态需一致同步。

## design 需求与 spec 设计

对应 `docs/design/mmd-pmx-vmd-local.md` 与 `docs/spec/mmd-pmx-vmd-local.md` 新增待确认章节。已有声明为 physicsGate、角色枢轴、当前物理、helper 和旋转阈值；新增暂停变换状态。操作流程为读取有效空间 → 暂停期间同步整体变换及历史 → 保留相对布料形状 → 恢复清零运动并重建驱动历史 → 正常求解。低速未暂停旋转继续原锚点牵引。

## 自测、兼容性与性能

- yaw/pitch/组合旋转、连续暂停、反向拖动、等阈值和零时间；动画只推进一次。
- 验证暂停/恢复布料相对形状、锚点与动态刚体位置一致、首个求解步不因旧位置差爆发速度。
- Ammo与XPBD、type=0/1/2、有无VMD/暂停动画、单位/非单位缩放、模型或物理实例切换。
- 后端状态与native资源不泄漏；同步只在暂停/恢复路径执行，普通帧不增加逐刚体搬运。
- 优先使用 `npm run build:web:mmd-ar-test` 构建；package.json 无定向物理测试脚本，使用 node --test 执行相关用例。
- 真机视觉与CPU/GPU耗时待现场验证，预计实现与自测2–4小时，不含设备验收和外网发布。

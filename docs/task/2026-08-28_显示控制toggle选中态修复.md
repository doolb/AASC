# 显示控制面板浅色主题 toggle 选中态修复

## 任务描述

修复显示控制面板中画面填充、裁剪旋转、中心缩放和播放状态按钮在浅色主题下无法区分当前状态的问题，同时覆盖浮动控制面板的同类控件。

## Design 需求

- 画面填充和裁剪旋转按钮：未选中使用浅色中性样式，选中使用主题强调色。
- 中心缩放按钮：根据 `active` class 区分关闭和开启。
- 主面板播放按钮：`playing` 使用成功色，`paused` 使用危险色。
- 浮动控制面板的画面填充和播放按钮复用相同的主题状态规则。
- 保留原有状态计算、控件 ID、点击事件和 WebSocket 消息。

## Spec 设计

```text
浅色主题显示控制:
    #panel-display [data-fit]:not(.active) = bg-secondary + text-secondary + border-color
    #panel-display [data-fit].active = accent gradient + white text + accent outline
    #panel-display [data-rotation]:not(.active) = neutral light style
    #panel-display [data-rotation].active = accent style
    #centerResizeBtn:not(.active) = neutral light style
    #centerResizeBtn.active = accent style
    #playPauseBtn.playing = success-color gradient
    #playPauseBtn.paused = danger-color gradient
    floating-control-panel data-fit and active playback = same light-theme states
```

## 自测用例

1. 浅色主题下切换“适应/铺满/动态/裁剪”，确认当前按钮有强调色，其他按钮为浅色中性样式。
2. 切换 0°/90°/180°/270°，确认当前旋转按钮可识别。
3. 切换中心缩放，确认开启和关闭状态不同。
4. 播放/暂停主面板媒体，确认按钮分别显示成功色和危险色。
5. 打开浮动控制，验证画面填充和播放状态与主面板同样清晰。
6. 回归深色主题，确认原有状态样式不变。

## 兼容性测试

- 不修改 `Controls`、`Crop`、`FloatingControl` 的状态计算。
- 不修改控件 ID、内联事件、`data-fit`/`data-rotation` 属性和 WebSocket 控制消息。
- 样式选择器限定在显示控制主面板和浮动控制面板，避免影响其他按钮。

## 性能测试

- 仅增加 CSS 选择器，不增加运行时轮询、网络请求或渲染循环。
- 状态 class 的更新路径和执行次数保持不变。

## 风险评估

- 浅色主题需要使用 `!important` 覆盖通用按钮和部分内联背景；选择器限定在显示控制容器内。
- 播放状态使用语义色，仍保持白色文字，适配现有主题变量。

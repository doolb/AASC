# 睡眠模式双遮罩保持画面填充

## 任务状态：✅ 已完成

## 任务描述

修复显示端睡眠期间通过 `display:none` 隐藏媒体容器，导致 `clientWidth/clientHeight` 变为 0，恢复临时激活后画面填充模式偶发丢失的问题。睡眠模式改为媒体区域遮罩，深度睡眠改为全屏 UI 遮罩。

## Design 需求

- 普通睡眠只显示媒体区域遮罩，UI 保持可见。
- 深度睡眠只显示全屏 UI 遮罩，覆盖 UI 与媒体。
- 不修改 `#mediaContainer` 的 `display`，保持媒体节点布局尺寸。
- 保留睡眠期间暂停媒体/TTS，临时激活时按原有播放状态恢复。

## Spec 设计

```text
若 sleepState == 'sleep': 显示 mediaSleepOverlay，隐藏 uiSleepOverlay
若 sleepState == 'deep': 隐藏 mediaSleepOverlay，显示 uiSleepOverlay
若 sleepState == 'normal' 或 'active': 隐藏两个遮罩
任意状态切换：不修改 mediaContainer.display
```

## 自测用例

1. 普通睡眠显示媒体遮罩，UI 遮罩隐藏。
2. 深度睡眠显示 UI 遮罩，媒体遮罩隐藏。
3. 睡眠切换前后 `#mediaContainer.style.display` 不变，容器尺寸不变。
4. 临时激活隐藏两个遮罩，已有画面填充样式继续生效。
5. 原有睡眠播放/暂停、手动覆盖、TTS 守卫测试保持通过。

## 兼容性测试

- Chromium/WebView：普通睡眠与深度睡眠遮罩层级正确。
- 图片、视频、HTML iframe 媒体节点均不因睡眠切换脱离布局。

## 性能测试

- 睡眠切换仅变更两个遮罩的 `display`，不新增定时器或媒体重排循环。

## 风险评估

- 低：媒体节点仍会暂停，遮罩只改变可见性；恢复逻辑沿用现有 `resumeSleepMedia`。
- 需注意全屏 UI 遮罩必须保持高于现有监控/任务覆盖层。

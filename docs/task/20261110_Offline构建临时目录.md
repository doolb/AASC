# Offline 构建临时目录

- 需求：避免系统 `/tmp` 用户配额导致 Offline 更新包复制失败。
- 实现：构建默认使用项目 `tmp/offline-build`，显式临时目录优先；统一出包入口向子进程传递选定目录，更新包、任务包、数据修复和独立 Node 包的独占暂存目录各自清理。
- 验证：目录选择、不可用时错误、现有更新包及数据修复回归共 25 项通过；语法和空白检查通过。
- 兼容性：Linux 和 Windows 临时目录环境变量优先；保留构建版本、产物和清理规则。
- 性能：暂存从系统内存盘转为项目磁盘，速度取决于磁盘；不增加额外文件复制。
- 风险：项目磁盘也可能空间不足或不可写，报错显示实际目录；真实出包环境需继续观察。
- 预计工时：约 1 小时。

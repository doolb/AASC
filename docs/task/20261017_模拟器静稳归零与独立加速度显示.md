# 模拟器静稳归零与独立加速度显示

## 任务状态

实施完成，传感器APK已构建；Android传感器现场验收待进行。用户同时要求电脑网页默认连接`AASCIMU1`，存在手动房间值时使用手动值，并要求发送拥塞时自动丢弃旧样本。

## 任务描述

修复图形模拟设备停止拖动后估计速度残留以及断流恢复提示过期问题；在Android原始含重力加速度之外读取和显示系统去重力线性加速度，并在桌面诊断页区分数据来源；电脑网页默认加入`AASCIMU1`，URL或房间输入框手动指定的房间优先；APK发送拥塞时只保留最新样本并丢弃旧值。

## Design需求

- 模拟器使用传感器样本静稳判断，角速度和去重力世界加速度均低于门限并持续0.7秒后清零速度；不读取模拟器真值，不对位置做真值校正。
- 静稳自动清零仅用于图形模拟器，不改变真实手机和远程APK的运动判断。
- 通过Android `TYPE_LINEAR_ACCELERATION`可用性读取独立平台线性加速度，作为可选`linearAccel`字段；原始`accel`仍为含重力加速度并继续供估计器使用。
- APK、桌面及loopback样本接口分别保留原始加速度、平台线性加速度和估计器世界线性加速度语义；平台数据不可用或过期时显示不可用。
- 默认房间为`AASCIMU1`；显式URL参数或手动输入优先，连接成功后保留到URL，切换输入来源不清空。
- Android到WebView桥接只保留一个待处理样本；网页按约25Hz发送并只保留一个待发样本，达到服务端频率上限时自动丢弃旧样本并降低发送速率，不排队累积。
- 误差评估要求先完成陀螺仪静置校准和模拟器加速度六面校准；不承诺纯六轴绝对位置精度。

## 自测与验收用例

1. 默认噪声/零偏下先完成静置陀螺仪校准与模拟器自动六面校准；拖动平移/旋转/复合运动后停住，传感器安静持续0.7秒后估计速度归零，位置保持连续，运动中不得错误清零。
2. 关闭或恢复模拟数据流，确认首个恢复样本从零速度重建时间基线，状态不继续显示旧的断流提示。
3. 切换模拟器、浏览器手机和APK来源，确认自动静稳只用于模拟器。
4. APK可用`TYPE_LINEAR_ACCELERATION`时同时显示原始含重力与平台线性值；缺少该传感器时明确显示不可用，原始六轴仍可采集。
5. 桌面诊断页同时区分原始含重力加速度、Android/浏览器平台线性加速度、估计器世界线性加速度；`/api/imu/samples`保留可选平台值。
6. 无room参数首次打开默认加入`AASCIMU1`；URL参数、手动房间输入能覆盖默认值；来源切换后保留房间。
7. APK传感器采样快于网络或WebView处理时，待发数据最多保留一项；服务端频率反馈后自动放慢发送，不出现旧样本队列增长。

本轮只做静态检查并构建独立传感器APK；不运行自动测试套件。模拟精度阈值和Android传感器可用性仍需设备现场验收。

## 兼容性测试

- Android没有`TYPE_LINEAR_ACCELERATION`或注册失败时继续使用陀螺仪与原始加速度，不影响旧APK客户端样本格式。
- 旧浏览器/样本消息不含`linearAccel`仍可通过服务器校验并进入既有估计器。
- 默认固定房间不变；已有自定义`room`URL和房间输入可继续连接其服务端已有房间。
- 模拟器静稳参数仅应用在模拟输入，不修改手机/远程传感器默认配置。

## 性能测试

- 新增传感器监听为系统已有虚拟线性加速度传感器，Android最多约50Hz采集，网络约25Hz发送；两级桥接均采用单项最新值覆盖，不增加服务端任务或轮询。
- 静稳检测仅增加每样本的向量模长和计时比较；页面继续沿用现有诊断刷新频率。
- 样本增加最多三个浮点值，远低于既有16KiB WebSocket消息限制。

## 风险评估与预计工时

- 系统线性加速度由Android融合传感器生成，部分设备无此传感器或存在延迟/漂移；该数值只用于诊断，不替代原始估计器输入。
- 加速度/陀螺仪安静不能从数学上证明静止；静稳规则限制在模拟器来源和明确短时窗口，移动时门限超出会清除窗口。匀速近似恒定运动仍有低加速度误判风险，但此功能只启用于虚拟模拟输入。
- 零速修正只能抑制停止后的速度残留，不能消除此前积累的位置偏差；六轴校准与短时位移仍受噪声、航向漂移限制。
- 预计代码、APK构建和文档同步约2小时；真机传感器现场验收另计。

## 执行结果

- `imu-engine.mjs`按传感器静稳窗口对模拟器输入执行一次零速修正，并在暂停/断流恢复首个样本更新状态；手机输入不启用模拟器自动静稳。
- Android APK、浏览器手机及桌面诊断分别保留原始加速度、可选平台线性加速度和估计器世界线性加速度；服务器将可选值透传至房间帧及本机样本接口。
- 网页默认加入`AASCIMU1`，URL和输入框手动房间优先，来源切换保留房间；固定房间可容纳网页输入端、观察端及一个APK传感器。
- Android到WebView采用单待办样本覆盖，WebView联网目标约25Hz；超过服务器频率或缓冲上限时丢弃旧样本，服务端限频反馈会逐步降低发送频率。

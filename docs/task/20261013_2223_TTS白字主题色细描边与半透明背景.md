# TTS白字主题色细描边与半透明背景

状态：最终要求明确，实施中。

## design需求

用户澄清旧“都是白字黑底”是观感反馈，要求参考时间文本、背景0.3半透明并模糊，最后明确主题色细描边。文字固定白色，描边随主题accent变化；字号不改，保留上下渐变及三行/100行/按音频进度/30秒隐藏保留历史。

## spec设计

```text
文字 := 时间文本rgba白色填色；0.5px主题色描边，stroke fill顺序；复用时间文本阴影
背景 := 黑色alpha0/0.3/0.3/0（0%/18%/82%/100%），仅背景blur8px
主题 := accent变化只更新边缘颜色；移除TTS浅色主题深字/白底覆盖
生命周期 := 字号、字重、三行、音频推进、100行和30秒隐藏历史保持
```

浏览器核对dark/light/mint/new-year-red白色填色一致、描边匹配accent、0.3峰值/blur8px与三行字号一致；已有旋转/DPI兼容继续适用。ADB更新code73、实际播报截图、主题切换后还原原主题。阴影使用时间文本已有兼容写法，color-mix保留旧fallback；细描边保留白色字面。没有逐帧媒体采样或新DOM观察器，最多三行可视，无额外循环。预计20–40分钟含出包/HTTP传输。

## design需求

用户澄清旧“都是白字黑底”是观感反馈，要求参考时间文本、背景0.3半透明并模糊，最后明确主题色细描边。文字固定白色，描边随主题accent变化；字号不改，保留上下渐变及三行/100行/按音频进度/30秒隐藏保留历史。

## spec设计

```text

背景 := 黑色alpha0/0.3/0.3/0（0%/18%/82%/100%），仅背景blur8px
主题 := accent变化只更新边缘颜色；移除TTS浅色主题深字/白底覆盖
生命周期 := 字号、字重、三行、音频推进、100行和30秒隐藏历史保持
```

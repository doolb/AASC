# 显示器播报文本汉字旋转修正

## 任务描述

修正上一项播报文本旋转适配中汉字字形方向不正确的问题。`writingMode: vertical-rl` 只改变排版方向，会让汉字保持正立；本任务要求播报文本整体随显示器角度旋转。

## design 需求

- 90°使用 `rotate(90deg)`。
- 180°使用 `rotate(180deg)`。
- 270°使用 `rotate(270deg)`。
- TTS 播报文本、语音识别结果和状态提示继续共用 `#voiceTextDisplay`。
- 保留上一项已完成的字号调整：桌面端 36px、移动端 27px。

## spec 设计

- `applyRotation()` 每次先清除 `writingMode`、`textOrientation` 和旧 `transform`。
- 90°/270°给 `voiceTextDisplay` 设置与显示器一致的整体旋转角度。
- 淡入动画只改变透明度，不覆盖整体旋转。

## 自测用例

- 回归测试验证 90°/180°/270°的播报文字整体 `transform`。
- 回归测试验证 90°/270°不再设置竖排 `writingMode`。
- 回归测试确认字号 36px/27px 不回退。
- 运行显示端和文本媒体相关回归测试。

## 兼容性、性能与风险

- Chromium/WebView 原生支持 CSS `transform`，不引入协议变化。
- 只改变现有文字节点的内联变换，不增加网络请求或定时器。
- 旋转后的文本框边界可能因字号放大和旋转变化，需要保留 `max-width: 50vh` 约束。

# 控制端其他状态按钮浅色主题选中态修复

## 任务描述

盘点并修复控制端除主题路由和基础显示控制外的同类状态按钮，重点覆盖语音识别/生成设备、自动播报、文本播放、批量播放和动态选择模式。

## Design 需求

- 语音识别/生成设备按钮通过 `active` class 标识当前设备。
- 自动播报通过 `active` class 标识开启状态。
- 文本播放和批量播放通过 `playing`/`paused` class 标识状态。
- 设备选择模式、日志筛选/自动滚动、任务选项的 active 状态在浅色主题中清晰可见。
- 纯导航、弹窗显示、媒体条目高亮不强行套用按钮状态规则。

## Spec 设计

```text
AsrDevice.updateUI:
    data-asr=server/display active = currentDevice == 对应值

TtsDevice.updateUI:
    data-tts=server/display active = currentDevice == 对应值

Tts:
    autoTtsBtn active = autoTtsEnabled

Controls/FloatingControl/MediaLibrary:
    文本播放和批量播放按钮 playing = state == playing
    文本播放和批量播放按钮 paused = state == paused 或停止态

浅色主题:
    状态按钮未选中 = bg-secondary + text-secondary + border-color
    状态按钮选中 = accent gradient + white text + accent outline
    播放中 = success-color gradient
    暂停/停止 = danger-color 或中性样式
```

## 盘点结果

- 显示控制：语音识别设备、语音生成设备、自动播报、文本播放、批量播放。
- 设备列表：单选/全选/自适应、树形选择模式。
- 日志：自动滚动、日志筛选按钮。
- 任务面板：目标、模式、环境等 `task-btn-option`。
- 已排除：侧栏导航、弹窗 active、媒体条目 active 等非同类按钮状态。

## 自测用例

1. 切换语音识别设备和语音生成设备，确认每组只有当前设备为强调色。
2. 切换自动播报开/关，确认按钮颜色随状态变化。
3. 播放/暂停文本和批量播放，确认主面板与浮动面板状态清晰。
4. 切换单选/全选/自适应、日志筛选和任务选项，确认未选中项不会与选中项同色。
5. 切换全部浅色主题，确认颜色跟随主题变量。
6. 回归深色主题，确认原有按钮视觉和业务行为保持兼容。

## 兼容性测试

- 保留现有按钮 ID、`data-asr`、`data-tts`、`data-selection-mode`、`data-value`、点击事件和 WebSocket 消息。
- 不改变设备选择、播放控制和任务提交逻辑。
- 纯导航、弹窗和媒体条目使用原有专属样式。

## 性能测试

- 仅增加少量 class 更新和 CSS 规则，不增加网络请求或定时任务。
- 各状态刷新仍为现有按钮数量的线性遍历，复杂度不变。

## 风险评估

- 设备按钮保留内联背景作为深色主题兼容；浅色主题用限定容器选择器覆盖。
- 批量播放停止时面板会隐藏，下一次播放状态更新时重新设置状态 class。

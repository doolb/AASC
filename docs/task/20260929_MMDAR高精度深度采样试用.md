# MMD AR 高精度深度采样试用

- 需求：将诊断中的 highp 采样用于 mmd-ar 并发布外网，供 Vivaldi 真机对照。
- 设计/spec：`docs/design/mmd-ar-test-apk.md`、`docs/spec/mmd-ar-test-apk.md`。
- 影响：测试网页构建器修改复制后的 AO 模块三处 tDepth 精度；追加 AO 内容指纹并向 runtime、页面引用传递。
- 自测：网页构建、三处声明检查、阴影回归、生成 shader 编译；发布文件大小和 SHA-256 校验。
- 兼容性：WebGL2 highp 采样；正式显示端和旧独立 APK 不变。
- 性能：不新增采样次数或渲染通道，手机性能与画质待现场观察。
- 风险：highp 改善诊断精度不保证完全解决 AO；原视觉参数保持一致以便比较。
- 预计工时：半小时。
- 执行结果：网页构建与浏览器 shader 回归 2/2 通过；12 个变化文件发布完成，关键四文件公网 HTTPS SHA-256 与本地一致。真机观感待验收。

# MMD 空白区域拖动旋转角色

## 任务描述

为显示端 `displayMmdCanvas` 增加空白区域拖动旋转。按下时使用现有 Raycaster 判断：命中角色时继续执行既有轻点互动；未命中角色时，水平拖动转身、上下拖动俯仰当前 PMX 或 VRM 角色。

## Design 需求

- 角色命中判定必须发生在按下时，防止从角色拖向空白区域时误触发旋转。
- 旋转仅改变本地模型朝向：水平位移控制 Y 轴，纵向位移控制 X 轴；X 轴俯仰限制在上下各 45°，不写入远端配置、不发送 WebSocket 消息。
- PMX/VRM 模型归一化并贴地后，必须围绕包围盒中心枢轴旋转；拖动目标以约 140ms 指数缓动收敛，阴影范围只在收敛后按最终姿态刷新。
- 聊天层打开、MMD 隐藏、模型未加载时不响应拖动。
- 使用 Pointer Capture 覆盖拖出 Canvas 的结束场景；取消、松开和模型切换后不得残留拖动状态。
- Canvas 降级占位保留现有点击反馈，不模拟 3D 旋转。

## Spec 设计

```text
pointerdown 计算 Raycaster 命中
命中角色 -> 记录点击候选
空白 -> 记录 pointerId 和坐标，捕获 pointer
pointermove 的空白 pointer -> 计算 deltaX 和 deltaY，更新当前 runtime 的 Y 轴与受限 X 轴目标角度
runtime -> 将模型挂到包围盒中心枢轴，按帧缓动至目标角度
pointerup/cancel -> 释放 pointer，等待缓动结束后完成阴影范围刷新，清理状态
角色点击候选的位移小于阈值 -> 发布既有 mmd.interaction
```

## 自测用例

1. 空白区域按下后水平拖动控制 PMX/VRM 的 Y 轴，纵向拖动控制 X 轴。
2. X 轴俯仰累计到边界后保持在上下各 45°。
3. PMX/VRM 都围绕模型中心枢轴缓动，不绕脚底旋转，动作与射线命中保持可用。
4. 命中角色后的轻点仍发布 `mmd.interaction`。
5. 命中角色后拖动不进入空白旋转。
6. `pointerup` 和 `pointercancel` 都释放拖动状态，并在角度收敛后刷新阴影。
7. 聊天层打开、MMD 隐藏或模型未加载时不旋转。

## 兼容性测试

- PMX 和 VRM runtime 使用一致的 `rotateModelBy`/`finishModelRotation` 接口。
- 触摸、鼠标和触控笔均沿用 Pointer Event。
- 运行时降级为 Canvas 占位时不抛错，既有轻点反馈保持可用。

## 性能测试

- 每次 `pointermove` 只更新水平与纵向目标角度；复用既有渲染循环执行缓动，阴影范围仅在旋转收敛后刷新。
- 不创建额外 WebSocket、网络请求、模型副本或动画循环。

## 风险评估

- 低风险：改动局限于现有 Canvas 交互和两个本地 runtime。
- 需防止 Pointer Capture 未释放导致后续点击失效，因此所有结束路径统一清理。

# 测试 APK 当前音频播放与中英混合过滤

## 任务描述

- 在独立测试 APK 原生页面播放当前已选择或已录制的音频。
- 在测试网页播放当前选择或录制的 WAV。
- 在测试网页增加离线 ASR 语言模式，支持自动、中英混合过滤、中文和英文。
- 中英混合模式识别后过滤日文假名、韩文等非中英文脚本；不承诺区分中文与日文共用的 Han 字符。
- 不改生产 display APK，不给当前流式 Zipformer增加语言过滤。

## Design 需求

- 原生播放使用已解码的 16 kHz 单声道 PCM 和 `AudioTrack`。
- 网页播放使用当前 Blob/File 的 object URL，并在替换时释放旧 URL。
- `/api/asr`、`/api/voiceprint/test` 增加 `language` 参数。
- SenseVoice 只保留一个活动 recognizer，语言切换时同步重建，避免多份模型常驻。
- 过滤器保留 Han、ASCII 英文、数字、空白和常用标点。

## Spec 设计

```text
网页选择语言 -> languageMode
音频请求 -> 解析 languageMode -> SenseVoice auto/zh/en
识别结果 -> ZH_EN_FILTER 时执行文字过滤 -> 返回文本

原生当前音频 -> Float32 转 PCM16 -> AudioTrack 播放 -> 停止/切换/销毁释放
网页当前音频 -> object URL -> audio.play() -> 替换时 revokeObjectURL
```

## 自测用例

- 语言参数缺失、`auto`、`zh-en-filter`、`zh`、`en` 和非法值解析正确。
- 中英混合文本保留中文、英文、数字、标点，删除日文假名和韩文。
- 中日共用 Han 字符不被错误删除。
- 网页 HTML 包含播放器、语言选择和 `language` 查询参数。
- `/api/asr` 与 `/api/voiceprint/test` 不传 language 时保持 auto 兼容。
- 原生选择/录音后播放、停止、重复播放和切换音频不崩溃。

## 兼容性测试

- Android 9 / arm64-v8a 真机。
- 浏览器 HTTPS 页面选择 WAV、网页录音、播放、停止和识别。
- 原有降噪、Sherpa 单段/多段/快速多段、流式 ASR 回归。

## 性能测试

- 语言不切换时复用当前 recognizer。
- 语言切换仅重建一个 SenseVoice recognizer，不常驻多份模型。
- 文本过滤只遍历识别结果，不增加音频推理耗时。
- 播放使用独立线程分块写入 PCM 流式缓冲，不阻塞 ASR 推理线程。

## 风险评估

- SenseVoice 不支持 `zh,en` 双语言配置；中英模式必须使用 auto。
- 过滤器无法区分中文 Han 与日文 Kanji，不能修复语言误判。
- `AudioTrack` 在低端设备上可能初始化失败，需要将错误显示到原生状态文本。
- 语言切换会带来一次模型重载耗时；服务端需保持请求串行/引擎同步。

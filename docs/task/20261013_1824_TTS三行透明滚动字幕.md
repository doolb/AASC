# TTS 三行滚动字幕

状态：2026-10-13按用户确认及补充完成源码实现，待设备播放验收。

## 任务描述与design需求

固定三个视觉行的可视高度，背景黑色0.1不透明度加8px背景模糊。每个新TTS从新行开始，按音频进度逐行追加并向上滚动；最多100个已显示字幕行。最后一行显示后30秒无新字幕行只隐藏并保留历史，新TTS恢复后追加。普通结束继续显示，主动停止隐藏并保留。ASR/模型提示复用节点时取消TTS旧任务但保留历史。

## 需求评审

使用analyze-requirement-level enterprise；主L5（追加/闲置状态规则），次L6（固定高度、背景和历史上限）。证据：固定3行、背景0.1加模糊、新TTS换行、30秒隐藏、最长100行、隐藏不清空。状态规则证据12/18×0.9=0.60；已通过用户修订补齐历史边界，结论可开发，风险低。评分：24/25、20/20、19/20、19/20、15/15，总97/100。建议下放L4：分别声明历史、计时器和滚动帧，将追加/超时/来源切换串联到现有队列入口。后续技能未调用。

# 壁纸控件与监听状态

- 任务：修复监听按钮，完善壁纸的独立浮动控件、时间避让和关闭任务后的渲染暂停。
- Design：见 `docs/design/display-wallpaper-controls.md`；普通显示端不改变布局，原壁纸恢复暂不处理。
- Spec：见 `docs/spec/display-wallpaper-controls.md` 与 `docs/spec/display-voice-controls.md`。
- 模块：Android 壁纸 Engine、共享协调器与原生桥，显示端语音控件、页面样式及壁纸面板。
- 自测：监听开关状态、壁纸/前台切换、独立显示开关、拖动收起和旋转时间避让。
- 兼容性：普通浏览器和前台无壁纸桥时使用普通模式；桌面触摸和任务关闭需 Android 真机检查。
- 性能：不新建持续渲染循环；状态变化时更新面板及时间布局。
- 风险：系统可能不转发桌面触摸，进程强杀不保证回调；暂停不恢复旧壁纸。
- 预计工时：4–6 小时。

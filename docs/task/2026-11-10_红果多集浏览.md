# 红果多集浏览

- 任务：修复剧集只能看到首集；用 ADB 只读观察设备上短剧应用，核实公开页面的能力边界。
- 设计：同剧集链接按页面顺序列出；逐页核验公开地址，缺失或请求失败时保留不可播放的分集。
- 实现：参照 `docs/spec/media-library.md` 的国内媒体任务伪代码，修改 `res/tasks/domestic-media/providers/hongguo.js`。
- 自测：覆盖多集、外站与其他剧集过滤、缺少地址、请求失败、播放下载校验、停止及浏览器行为。
- 兼容性：旧的公开视频 ID 和无分集链接页面保持兼容；不改变其他媒体来源。
- 性能：最多 200 集、4 个页面并发及有限缓存；大剧集可能需要等待上游响应。
- 风险：网页结构、站点访问限制或应用接口变化会影响结果；不推测或绕过受限地址。
- 预计工时：2 小时。待确认：应用内部访问机制仅以实际观察证据为准。
- 执行结果：国内任务、红果及浏览器定向测试 10/10；`npm run test:task-code-sync` 71/71；`git diff --check` 通过。真实公开页面列出 3 集，首集声明视频，另外两集未声明。ADB 观察到设备正在播放短剧，但未取得应用内部接口；部署及真实播放待验收。

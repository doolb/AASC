# 壁纸浮窗返回桌面闪烁

需求：浮窗在边缘消失后又出现一次，位置已恢复。
设计：仅延迟显示直到桌面和壁纸状态短暂稳定，切换其他应用仍立即隐藏；显示前准备主题和语音状态，未就绪有时限与默认样式。
实现：见壁纸控件 spec；Android 浮窗与壁纸引擎可见状态合并，异步操作在隐藏后取消或丢弃；复用持久位置。
影响：Android 系统浮窗显示生命周期与初始化。
自测：可见/隐藏事件短时交替、待显示取消、隐藏立即执行、首次无缓存及旧回调防护；已有位置和壁纸回归。
兼容性：无障碍不可用时沿用壁纸可见状态；新旧页面不可用时有时限回退。
性能：仅返回桌面延迟 250ms，首次读状态最多等待 400ms；隐藏不延迟。
风险：不同桌面切换时序可能超过消抖时长，真实设备仍需观察；不保证系统动画绝无闪烁。
预计工时：半天。

验证结果：壁纸生命周期和浮窗回归 7 项、Android 编译及浮窗去抖/坐标/桌面策略 8 项单元测试通过。真实手机返回桌面闪烁和延迟效果仍待验收。

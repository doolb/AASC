# 控制端媒体循环区间调整

日期：2026-10-23。状态：源码与本地自测完成，服务包和Node独立包待构建部署。

## 任务描述与需求

控制端“媒体播放”卡片增加循环开始和结束调整。用户确认使用一条滑条两个手柄，不手输；左侧开始、右侧结束，区间高亮并只读显示起止时间。支持鼠标、触摸及键盘，拖动预览、释放提交。

## design需求与spec设计

- 设计：`docs/design/control.md` 的“媒体播放区间循环”。
- 伪代码：`docs/spec/control-media-loop.md`；实现前先按确认结果修订。
- 复用 WebSocket、配置持久化、权威广播与初始化补发；按媒体隔离，默认关闭。
- 已明确交互：一条轨道上的两个手柄；其它行为沿前次方案执行，作用于当前媒体，切换清除，默认关闭。

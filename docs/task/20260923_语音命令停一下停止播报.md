# 语音命令“停一下”停止播报

## 任务描述

将“停一下”作为“停止播报”的语音命令别名，复用现有 TTS 停止目标、停止消息和确认提示。

## Design 需求

- 在内置 `stopTts` 命令注册表中列出“停一下”。
- “停一下”与“停止播报”“中止播报”触发同一处理逻辑。
- 不改变当前语音会话实际播放目标的停止路由及“已停止播报”确认。

## Spec 设计

- 命令帮助和语音命令匹配均从 `stopTts` 注册项读取别名。
- 语音处理入口识别到“停一下”后，复用 `stopTts` 分支，调用当前会话的停止回调或向目标发送 `tts/stop`，再按现有行为播报确认。

## 自测用例

1. 说“停一下”时进入 `stopTts` 分支，当前播报停止并沿用“已停止播报”确认。
2. 说“停止播报”或“中止播报”时行为保持不变。
3. 动态语音命令帮助中显示“停一下”示例。
4. 控制端和显示端语音来源继续停止各自当前会话实际选择的播放目标。

## 兼容性

- 不新增消息类型、配置项或 TTS 协议字段；现有客户端兼容。

## 性能与风险

- 只增加一个字符串匹配条件，不增加 TTS、网络请求或状态读写。
- “停一下”出现在语音文本中时按内置命令优先级停止当前播报，与现有停止短语的匹配方式一致。

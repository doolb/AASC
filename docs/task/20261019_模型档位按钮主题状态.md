# 模型档位按钮主题状态

## 任务描述

控制端与显示端右下角的模型面板中，轻量、普通、专业按钮沿用当前主题已有的选中和未选中按钮样式，替换独立的字重、勾号和混色背景。

## Design 需求与 Spec 设计

- `docs/design/chat-system.md`：选中状态与主题预览一致，使用强调色渐变、白字及外圈；未选中状态使用中性背景、次要文字和主题边框。
- `docs/spec/chat-system.md`：根据服务端回显的档位设置 `aria-pressed` 和状态类；深色、浅色主题均应用对应的主题变量，不修改模型选择协议。

## 受影响模块与代码

- `src/apps/web-mediacenter/ui/public/css/chat-model-tier-picker.css`：替换三档按钮的状态样式。
- `tests/chat-model-tier-browser.test.js`：用主题预览按钮作为参照，比较控制端与显示端的两种状态。
- `docs/usage/chat-model-tiers.md`：更新按钮外观说明。

## 自测用例与兼容性测试

- 深色与浅色主题中，控制端和显示端的选中、未选中档位分别与主题预览按钮的背景、文字、边框及外圈一致。
- 每组只有一个 `aria-pressed=true`；Provider 变更、Agent 禁用、窄屏面板定位沿用原有浏览器回归。
- Offline APK/ADB 实际主题观感留在 `docs/todo.md` 待设备验收。

## 性能测试与风险评估

只调整 CSS 状态规则，不增加网络请求或模型切换计算。浅色主题的全局按钮规则使用高优先级覆盖，档位未选中状态也需明确覆盖以保持中性色；真实设备的 WebView 渲染待验收。

## 预计工时与结果

预计 0.5 小时。浏览器定向测试 2/2 通过；服务代码包状态标为待出包。

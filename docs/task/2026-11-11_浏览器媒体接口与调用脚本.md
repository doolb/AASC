# 浏览器媒体接口与调用脚本

- 任务：开放浏览器媒体业务接口并提供独立 Node.js 脚本，不接入 Pi Agent。
- 设计：复用运行中任务、白名单和浏览器会话；独立环境令牌保护接口，挑战需用户处理。
- 实现：按 spec 注册状态、请求、提取接口，二进制使用 base64；脚本支持命令行及模块调用。
- 影响：服务端路由、启动入口、脚本、使用说明和自测；不改变现有媒体源默认行为。
- 自测：鉴权、任务关闭、挑战、正常文本/二进制/提取和脚本调用；兼容现有浏览器任务。
- 兼容性：Node.js 内置 fetch，Linux 桌面浏览器任务；Android WebView 尚不支持。
- 性能：复用既有会话与 2 MiB 响应限制；不新增浏览器进程管理。
- 风险：令牌持有者可使用白名单站点的浏览器会话，须保密并使用 HTTPS；真实 Cloudflare 挑战通过需现场验收。
- 预计工时：2–4 小时。

# MMD AR主光阴影偏移

## 需求及授权

用户反馈拉近镜头后主光阴影有条纹，确认先处理阴影，暂不处理AO。沿用已告知的独立测试页bias/normalBias滑块方案，修改`web-panel-groups.js`与`build.js`，新增小模块`web-shadow-bias.js`集中参数/校验/注入。设计与伪代码先于代码更新，见对应mmd-ar-test-apk文档。

## 设计及实现

- 主光bias范围-0.005–0.005/步长0.0001/默认-0.0005；normalBias范围0–0.1/步长0.001/默认0.02场景单位。
- 同一字段定义生成控件、默认值、数值校验，非法/空/缺失值回默认，合法值限幅并对齐步长。
- localStorage键`aasc.mmdArTest.keyShadowBias.v1`；即时发布冻结设置对象、保存、灯光恢复默认重设两值。
- 独立生成runtime在渲染前同步主光shadow参数，未变化快速返回，变化时标记shadow.needsUpdate；无新增定时器/全局回调。
- 不改正式runtime/AO/模型/阴影贴图与相机；本次提交仅覆盖独立测试网页，APK共享构建的其他改动另行维护，本轮只同步web-dist。

## 兼容、性能与风险

保持当前PCFSoft/1024²/全角色阴影范围，保持灯光初始值及独立补光参数。无额外渲染通道，每帧只比较设置对象身份，变化才规范化与写shadow参数。较大的偏移可能产生阴影脱离，默认不主动增大，实际模型条纹改善待用户调参验收。预计实现及构建约15分钟；手机验收另计。

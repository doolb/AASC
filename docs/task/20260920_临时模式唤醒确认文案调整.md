# 任务：调整临时模式唤醒确认文案

## 任务描述

将纯助手名唤醒临时模式时的随机快速回复“哎，我在”替换为“啊，我在”。

## Design 需求

- 仅调整纯助手名唤醒的确认候选文案。
- 保留“嗯，我在”“我在呢”“在呢”“听着呢”及助手名带内容时的确认候选。
- 不改变临时会话状态、聊天消息提交、TTS 路由和一次性群聊行为。

## Spec 设计

```text
waitingWake + 纯助手名:
    temporaryWakePrompts = ['嗯，我在', '啊，我在', '我在呢', '在呢', '听着呢']
    随机选择 temporaryWakePrompts 中一项并发送
```

- `src/apps/server/boot/server-app.js`：替换纯助手名唤醒确认候选。
- `docs/design/display-voice-conversation.md`：同步用户可见行为设计。
- `docs/spec/display-voice-conversation.md`：同步伪代码候选池。
- `docs/task/20260919_临时模式唤醒确认提示区分.md`：同步原任务的实现约束。

## 自测用例

1. 检查服务端纯助手名唤醒候选池包含“啊，我在”。
2. 检查候选池不再包含“哎，我在”。
3. 检查其他四条纯唤醒回复和带内容确认候选保持不变。
4. 运行临时语音会话相关定向测试和 JavaScript 语法检查。

## 兼容性测试

- 纯助手名唤醒仍只播报快速回复，不产生聊天消息。
- 助手名带内容、临时模式连续消息和一次性群聊行为不变。

## 性能测试

- 仅替换静态候选字符串，不增加请求、TTS 播放次数或持久化操作。

## 风险评估

- 低风险：仅影响一条用户可听见的随机确认文案。

## 预计工时

- 约 10 分钟，含代码、文档同步和定向检查。

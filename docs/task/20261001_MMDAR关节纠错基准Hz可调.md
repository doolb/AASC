# MMD AR 关节纠错基准 Hz 可调

- 日期：2026-10-01。
- 状态：已完成实现、构建与自动验证；未发布外网，待现场验收。
- 任务描述：把物理稳定性补丁中写死的“关节纠错基准 65Hz”做成可调；测试网页“物理”分类新增“纠错基准 Hz”滑条。
- design 需求：见 `docs/design/mmd-ar-test-apk.md` 的「2026-10-01 关节纠错基准Hz可调」。已确认：滑条 30–180、5Hz 步长、默认 65、本地记忆、实时重算六轴 STOP_ERP；只改纠错强度，不动弹簧/质量/阻尼。
- spec 设计：见 `docs/spec/mmd-ar-test-apk.md` 的「关节纠错基准Hz可调（2026-10-01，已实现）」。`normalizeWebStabilityReference`、步进参数增加 `stabilityReferenceHz`、补丁记忆双条件＋`setStabilityReferenceHz`、运行时/显示层透传与补发。
- 受影响模块和代码：`3rd/mmd-ar-test/web-physics-rate.mjs`（归一化＋参数对象）、`web-physics-rate.js`（运行时两处携带参考值）、`web-physics-stability.js`（补丁记忆双条件＋setStabilityReferenceHz＋运行时/显示注入）、`web-panel-groups.js`（物理分类滑条＋说明＋本地记忆）、`build.js`（注入链与必需控件）；测试 `tests/mmd-ar-physics-rate.test.js`、`tests/mmd-ar-physics-stability.test.js`、`tests/mmd-ar-web-panel-groups.test.js`。仅 WEB_MODE 网页副本。
- 自测用例：
  - 归一化：缺失/NaN/Infinity/非数值回退 65；30/65/90/95/130/177/178/999 的截断与 5Hz 取整；0/-1 截到 30（与 physicsFps 规则一致）；
  - 步进参数：默认参考 65；指定 130 时同 Hz 下选项携带 `stabilityReferenceHz: 130`；
  - 补丁：默认 65 在各 Hz 与原值一致；`setStabilityReferenceHz(130)` 立即重算六轴（= 1-0.525^(130/180) @180Hz）；回退 65 立即恢复；NaN 按 65 并回读 65；步进参数路径（创建/变频）经复位刷新生效；65Hz 基准恢复原库 0.475；
  - 运行时：滑条变更转发当前物理并立即生效；runtime 重建后补发；存储受限仍即时生效；非法值回退；
  - 面板：滑条位于“物理”分类、默认 65、数值显示与本地保存；说明文字注册为分类控件；
  - 既有回归：变频只刷新六轴一次、跨 Hz 残余、频率上限 180、子步预算、本地资源 ERP 默认 65 断言保持。
- 兼容性测试：换模型/物理重载后参考值继承；物理关闭时滑条仍可设置（下个物理实例生效）；与 physicsFps 滑条独立；横竖屏面板布局。
- 性能测试：参考值变更只写六轴关节参数一次（与变频同量级），无逐帧开销；构建产物体积不变。
- 风险评估：参考值是关节纠错的时间归一基准，改动影响所有物理频率下的关节手感（默认 65 与现状对等，现场对照后再定）；四层归一化规则需保持一致（共享函数＋显示/面板两处内联注释说明）；只改参考不触发变频检测，必须显式立即重算（已由 setStabilityReferenceHz 解决，测试覆盖）。
- 需求评审（enterprise 默认；可选 standard）：可开发；主等级 L6，次等级 L5；建议下放到 L4。
  - 强证据 L6：基准 65 可调、滑条 30–180 默认 65（用户确认），共权重 6；中证据 L5：实时生效与本地记忆规则，权重 2。置信度 6/8×0.90≈0.68。
  - 层级清晰度 22/25，证据充分度 18/20，实现完备度 17/20，风险暴露度 16/20，L4 可落地性 14/15；总分 87/100。直接开发风险中（改物理手感参数）。
  - 断点通过「共享步进参数携带参考值」「显式立即重算」「四层一致归一化」解决；L4 三段草案已写入 spec。
  - 后续技能选项：ai-code-translation / project-pseudocode-sync / 仅保留判级；按既有约定仅保留，按项目流程实施。

# Offline 任务依赖兼容预检

- 任务：依赖升级时避免旧任务包精确绑定导致耗时构建后失败。
- 设计：旧任务包绑定精确依赖且重建依赖时联动任务包，按任务实际依赖维护声明。
- Spec：构建前聚合任务声明，比较目标依赖版本和锁指纹；不兼容时停止并报告两侧的值。
- 影响模块：Offline 发布计划、更新包构建、任务选择清单、自测和使用文档。
- 自测：精确依赖匹配、版本不符、锁指纹不符、无精确依赖；现有更新包和任务包测试；实际基线 dry-run 检查联动。
- 兼容性：已有精确绑定保持严格校验；无精确绑定不对依赖版本施加额外约束。
- 性能：预检只读取小型 JSON，不构建或复制依赖树。
- 风险：win-monitor 的 systeminformation 为可选能力，实际采集能力依赖运行环境，失败采用现有降级路径。
- 预计工时：1–2 小时。

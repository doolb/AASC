## design需求与边界

同一适配器实例中，同账号请求按入队顺序执行，不同账号继续并行。按用户最新补充，执行权只覆盖WS合成到完整TTSEnded音频到达并清理连接，WAV解码不占执行权；不同批次共享该实例队列。当前批次内豆包并发1保持，Qwen/API路径不变。此队列不提供多进程或不同服务实例之间的分布式互斥，不把本地限制宣称为官网限制。

每账号最多等待16项，实例最多等待256项；满队列明确提示稍后重试。等待使用请求原deadline，不重新计时。等待期间取消或超时立即移除，无上游请求，不阻塞后续任务；这些本地失败不计为账号上游失败。活动任务成功、失败或取消均释放执行权，解码保持原取消/截止检查，已释放执行权后的失败不得释放下一条任务。

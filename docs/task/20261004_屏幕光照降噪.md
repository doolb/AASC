# 屏幕光照降噪

## 需求

用户反馈接触阴影和GI有噪点，已确认同时优化。

## 设计与实现

见design/spec的“接触阴影与SSGI降噪”。修改web-screen-lighting-shader.mjs、web-screen-lighting.mjs及构建接入。两遍几何引导滤波、命中细化、亮点抑制，质量档位和默认关闭保持。

## 验证

Chromium + SwiftShader，同一西施2静止场景，分别关闭/只阴影/只GI/同时开启，比较截图与帧间隔；检查Shader错误，额外覆盖高质量、缩放目标及关闭后的资源释放。

## 风险与性能

软件渲染耗时不代表硬件GPU；低射线数量仍可能有残余条纹，屏幕外信息和透明多层不可恢复。新增两张半分辨率目标及两遍滤波；不增加历史反馈。预计本轮完成本地构建与桌面测试，外网发布另行请求。

## 验证结果

本地构建、JS语法和独立滤波测试通过；双效果独立浏览器短测完成。软件渲染新增开销和连续会话SIGKILL记录在self-test，保留后续实机/长测任务。滤波fixture通过方差、边界、低高档和资源释放断言。

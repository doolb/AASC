# MMD AR 半分辨率 AO 像素对齐

- 需求：修复半分辨率法线预览与 AO 同位置、固定屏幕横条；全分辨率正常。
- 设计/spec：`docs/design/mmd-ar-test-apk.md`、`docs/spec/mmd-ar-test-apk.md`。
- 影响文件：新增 `3rd/mmd-ar-test/web-ao-texel.js` 转换生成的 AO shader，`build.js` 在注入预览前执行转换；正式源码不变。
- 流程：整数中心及邻点取深度 → 用实际像素中心重建位置 → 边缘差分保护 → 原遮蔽采样同样对齐；保留 highp 与法线预览。
- 自测：`node --test 3rd/mmd-ar-test/web-ao-texel.test.js` 用真实 GPU 渲染已知法线倾斜平面，覆盖偶数、奇数、尺寸预算缩放和单像素的全/半模式；比较修复前后 RGB 误差并检查 shader/WebGL 错误。
- 兼容性：WebGL2 texelFetch；手机 Vivaldi 实际画面待对照；不更改模型材质或光照参数。
- 性能：保持五个法线深度采样及原 AO 样本数，无新增绘制通道或全尺寸 AO 分配。
- 风险：遮挡边界仍有屏幕空间方法的固有限制，整数对齐不能替代透明材质与其他算法问题的排查。
- 预计工时：1 小时。
- 结果：桌面旧偶数半分辨率色差最大 37/255，修复后全部八组最大色差为 0；网页构建通过，未发布。

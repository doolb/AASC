# PMX 首次动作延迟一帧

- 日期：2026-09-27
- 状态：实现完成；真机布料观感待验收

## 需求与设计

新 PMX 模型成功加载后，首个实际渲染帧只更新物理、不绘制模型，第二帧开始推进 VMD 并显示。显式切换动作和暂停后恢复播放不延迟。见 `docs/design/mmd-pmx-vmd-local.md`、`docs/design/mmd-ar-test-apk.md`。

## 实现规格与影响模块

先按 `docs/spec/mmd-pmx-vmd-local.md` 更新伪代码。`src/apps/web-mediacenter/ui/public/js/display-pmx-runtime.js` 在模型提交时记录一次性 helper 标记；首个可见渲染帧临时关闭 animation，物理照常步进，绘制时暂时隐藏 PMX 枢轴，帧后恢复原可见性和用户播放开关。模型销毁和显式动作切换清除该标记。`tests/display-mmd-runtime.test.js` 增加边界与首帧实际渲染回归。无需改 Three.js vendor、模型资源或 Android 原生代码。

## 自测与兼容性

- 首载有动作且物理开启：首帧动作不推进、模型不绘制，物理继续；次帧动作推进并绘制模型。
- 首载播放开关关闭：首帧仍保持关闭；用户后来打开时不再重复延迟。
- 模型不可见时标记不消耗；失败加载或过期 staged 模型不设置标记。
- 首帧绘制完成恢复 PMX 枢轴原有可见性，不覆盖 AR 失锁状态。
- 显式切换 VMD、暂停恢复、无物理 PMX 及 VRM 保持原行为。
- 执行定向 Node 测试、网页构建、语法与差异检查；真实手机首屏布料抖动需现场验收。

执行结果：`npm run build:web:mmd-ar-test` 成功，定向 Node 测试 40/40、MindAR 网页定位浏览器回归 1/1 通过，JavaScript 语法检查通过。外网三个变化文件 SHA-256 与本地构建一致，HTTPS 首页 200；未打 APK。首屏布料是否更稳定仍待真机视觉验收。

追加修正：用户反馈第一帧仍看得到动作起始姿态，因此首帧在保持物理更新的同时暂时隐藏 PMX 枢轴，仅第二帧显示并推进动作。新增运行时行为测试，定向回归 41/41 通过；重新构建并发布外网测试网页，三个变化文件公网 SHA-256 与本地一致。AR 可见状态在首帧绘制后恢复，真机视觉仍待验收。

## 性能与风险

不增加计时器、隐藏物理预热或网络请求；只增加一次首帧状态切换，预计性能影响可忽略。首帧物理先于 VMD 的相对状态可能改变布料初始观感，需用测试页对照。预计实现与回归约 1 小时，现场验收另计。

# Core 第七步剩余模块迁移任务

## 任务描述

- 目标：迁移 core 目录剩余模块并删除空 core 目录。
- 范围：迁移 config/timeParser/console-redirect/connection/tui/tui-utils/data-snapshot/viewbind 到新分层目录，替换引用并完成收口。

## design 需求

## spec 设计

- 增加 Core 第七阶段迁移伪代码。
- 更新核心模块索引中的 config/connection 新路径。

- 缓解：语法检查 + 模块加载冒烟测试 + 全量 grep 检查。

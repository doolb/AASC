# MMD AR 角色拖动和连续缩放

## 任务描述

为 HTTPS mmd-ar 测试网页和正式 Android 显示 APK 增加角色摆放手势。桌面使用滚轮连续推拉相机和右键拖动角色；手机两指同时支持移动角色与捏合推拉相机。现有左键/单指旋转和角色轻点互动保持原语义。

## Design 需求

- 右键按住并拖动平移角色；鼠标滚轮连续改变相机与角色的距离，不改变角色缩放。
- 手机两指中点移动平移角色，指间距比值连续改变相机距离；两个效果可在同一手势同时发生。
- 相机连续缩放无档位，距离倍率限制为 0.1 至 10；AR 模式下在定位跟随相机姿态上应用该倍率，不修改 MindAR 锚点矩阵。
- mmd-ar 测试页和正式显示端的 PMX 相机 near 固定为 1；AR 投影保留视角与 far，仅重建深度裁剪矩阵参数。VRM 正式显示相机 near 同样固定为 1。
- 保留单指/左键拖动旋转、未拖动时轻点角色互动和 8 CSS 像素旋转阈值。
- 任一双指手势开始即取消单指旋转和点击候选；pointerup、pointercancel 和指针捕获释放都清理完整手势状态。
- 角色平移偏移只保存在当前运行时；AR pose 更新、失锁和重锁期间都保留偏移。相机缩放只保存在当前运行时，停止 AR、重载模型或刷新页面后复位。不更改校准数据、服务端协议或远端配置。
- 仅 MMD 可交互画布拦截滚轮默认行为和右键菜单，聊天、面板及其他控件维持原事件路由。

## 自测用例

- 右键拖动调用角色平移且不旋转、不触发角色互动；鼠标左键拖动仍旋转。
- 滚轮上/下连续推拉相机；非法倍率无副作用，倍率边界不越界，角色根缩放保持不变。
- 双指同时变化中点和间距时移动角色并推拉相机；结束或取消后不误触发轻点/旋转。
- 单指轻点仍只触发一次互动；单指拖动仍旋转角色。
- AR 连续 pose 更新、失锁和重锁保留角色手动偏移；捏合改变 AR 相机距离但不改写锚点矩阵；停止后相机缩放复位。
- npm run build:web:mmd-ar-test 生成的网页包含共享 runtime，基础资源仍同源加载。

## 兼容性测试

覆盖 PMX 与 VRM 正式 runtime、PMX mmd-ar 测试网页，以及 Chromium PointerEvent 和 Android WebView 触摸事件语义。聊天控件、AR 校准拖动和定位面板不接收新增角色手势。

## 性能测试

单 pointermove 只进行常数次向量投影/反投影；双指每帧只计算一次中点、距离及一次投影变换，不新增逐帧计时器或定位识别循环。

## 风险评估

双指第二根手指加入时必须取消首指旋转/点击候选，否则会同时旋转并误触。AR 自动 pose 必须在不包含用户偏移的基准上收敛，否则每帧会抵消手动拖动。Android 实际手感和 WebView 多指兼容性仍需真机验收。

# Offline 本机模型收起把手半宽露出

## 任务描述

将 Offline 显示页左上“本机模型”入口收起把手继续向屏幕外移，使把手只露出半宽、竖排文字约露半个字，观感与 Android 控制端收起按钮一致；展开后的入口布局和交互保持原样。完成后把网页服务包同步发布到 LAN 与外网。

## 需求等级与评审

- 主等级：L5，收起态把手的屏幕位置和可见宽度规则。
- 次等级：L6，复用既有展开/收起状态与原生模型列表接口。
- 结论：可开发；直接开发风险低；没有未决范围或接口断点。
- 需求置信度：0.68（中）；位置意图明确，实际设备显示边缘仍需验收。

## Design 需求

1. 入口整体仍位于 FPS 下方，继续避开 Android 原生控制端按钮占用区域。
2. 收起把手保持 32 CSS px 宽，向左偏移 16 CSS px，屏幕边缘只显示半宽及约半个竖排字。
3. 只移动收起把手本身；入口容器、展开按钮组、安全区/软键盘左侧内缩、模型列表行为不变。
4. 网页服务包修改需标记 `servicePackage=true` 并同步发布 LAN 与外网；`minApk=false`，不重建 APK。

## 自测用例

1. Offline 模型能力有效时初始把手只露出约半字，仍可点击展开。
2. 展开后模型按钮、收起按钮保持原位置，且继续遵守左侧安全区和键盘内缩。
3. 收起后恢复半宽露出的把手；主按钮仍调用既有原生模型列表。
4. 无模型能力时入口仍隐藏；把手不覆盖 FPS 或控制端按钮。
5. `offline_native_models` 只读结构检查覆盖 `width: 32px`、`left: -16px` 与展开安全区规则。

## 兼容性与性能

- 仅调整现有网页按钮 CSS，并扩展既有只读结构自测；不新增 DOM、原生桥、协议或配置。
- 无逐帧逻辑、定时器、下载或模型加载变化。
- 适配现有显示舞台旋转、安全区和键盘内缩；仅在收起态利用舞台裁切。
- 属于服务代码包资源；LAN/WAN 服务包同步即可，不构建 min APK。

## 风险评估与预计工时

- 低风险：设备密度与 WebView 裁切可能让“半个字”呈现略有差异；按 32 px 控件半宽设定，并待 Offline 设备确认触控区域和实际观感。
- 预计工时：样式、自测和文档 30 分钟；打包发布与设备验收另计。

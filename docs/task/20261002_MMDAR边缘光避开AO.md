# MMD AR边缘光避开AO区域

## 需求与授权

用户要求“边缘光可不可以加上不在有ao的地方显示”。当前rim先加至材质颜色，AO后处理统一乘色，不能单独门控rim。候选新增默认开的共用开关，用当前帧最终AO遮蔽量平滑衰减至0。按AGENTS.md先提交具体方案待确认，本任务未开始写代码；阴影对齐和移动跟随独立完成。

## Design与Spec

边缘光1组共用“边缘光避开AO”开关，两灯共用、本地记忆/复位。遮蔽0.01–0.08平滑淡出，AO关闭/无AO不抑制。生成当前帧全尺寸AO遮蔽图，复用最终合成的深度/保边/边界修正，再用此图门控材质rim并重绘角色颜色，最后沿用原AO合成。只在AO与边缘光同时开启且开关打开时生效；法线预览旁路。不使用上一帧AO，不把阴影或背光冒充AO，不改变主/补/高光。候选伪代码详见spec对应章节。

## 自测/兼容/性能

对比开/关rim贡献，在无遮蔽区保持，有明显AO处贡献0、过渡连续；AO强度0/关闭恢复、全/半分辨率/边界修正/法线预览、两rim组合、材质透明/alpha、resize/模型切换/失败/关闭/dispose无反馈环和资源泄漏，偏好保存/坏值/复位。测启用路径与旁路资源数量、绘制次数/耗时；仅两灯rim共用一张全尺寸遮蔽目标，额外一次全屏合成加一次角色绘制，额外角色绘制复用阴影、不推进物理。手机效果/性能另行验收。

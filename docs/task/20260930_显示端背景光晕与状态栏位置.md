# 任务：显示端背景光晕与状态栏设置位置

## 任务描述

将显示端媒体空白区域的纯黑底色改为 MMD-AR 风格的中心亮、向外渐变背景；在控制端“系统设置 → 界面主题”增加全局共享的亮度和扩散范围参数。将每台显示端的状态栏开关从设备树/列表行移到 VAD 面板当前显示端卡片，并将控制端主导航调整为竖屏底部横向、横屏左侧纵向。

## Design 需求

详见 `docs/design/display-background-glow.md`、`docs/design/display-status-bar.md` 和 `docs/design/control-sidebar.md`。背景默认值为亮度 100%、扩散范围 58%，使用 MMD-AR 的深色中性渐变；睡眠遮罩和媒体本身不变。背景配置全局共享，状态栏显隐继续按 `displayId` 独立保存。

## Spec 设计

详见 `docs/spec/display-background-glow.md`、`docs/spec/display-status-bar.md` 和 `docs/spec/sidebar.md`。新配置经 WebSocket 由服务端校验、规范化、持久化并广播；控制端及显示端连接初始化时收到当前权威配置。状态栏开关沿用既有 `setDisplayStatusBarConfig`。

## 受影响模块与代码

- 显示端 `display.css` 与新增背景配置前端模块：渲染 CSS 渐变、应用亮度与扩散参数。
- 控制端 `upload.html`、`display-background-glow.js`、`websocket.js`：界面主题设置滑块、实时预览和 WebSocket 权威值同步；`self-test.js` 增加设置、开关位置与横竖屏布局自测。
- 控制端 `device-list.js` / `upload.css`：状态栏开关从树形/列表行迁移至 VAD 卡片，并继续按显示端独立提交；`upload.css` / `main.js` 按视口方向切换主导航位置与拖动滚动方向。
- 服务端 `server-app.js` 与配置规范化模块：默认值、消息校验、`config.set` 持久化、广播和重连补发。
- `display.html`：接收服务端配置并应用到背景 CSS。
- Offline 服务代码包状态保持 `true`；本任务不构建或发布 APK。
- design/spec/task、索引、usage、自测模块与文档、todo 和 changelog。

## 自测用例

1. 旧配置缺少背景参数时显示默认 MMD-AR 渐变；在控制端拖动亮度/扩散滑块时预览更新，提交后所有在线显示端同步更新。
2. 刷新控制端、刷新/重连显示端后，系统设置滑块和显示端背景恢复服务端保存值。
3. 畸形消息不覆盖权威值；亮度按 0–100、扩散范围按 25–90 规范化。
4. 两台显示端分别关闭/开启状态栏，确认开关位于 VAD 当前设备卡片、互不覆盖，时间仍显示。
5. 竖屏时主导航位于底部并横向排列，页面内容不被遮挡；横屏时导航保持左侧。媒体本身和黑色睡眠遮罩不受光晕影响。

## 兼容性测试

- 新服务端与旧显示端：旧端忽略新增全局背景消息，继续使用既有纯黑背景。
- 新显示端与旧配置：使用默认亮度/扩散值。
- 多控制端：任一端调整后，其余控制端收到同一组服务端权威参数。

## 性能测试

- 配置只在连接初始化和用户提交参数时传输；背景只通过 CSS 自定义属性刷新，不增加媒体渲染或轮询任务。
- 导航方向切换不改变媒体尺寸；竖屏内容区为底部导航预留空间。

## 风险评估

- 旧显示端短期内保持黑色背景，升级后才应用光晕；新旧客户端使用各自明确默认值。
- 扩散范围可能在不同纵横比设备上观感不同；采用椭圆渐变并保留滑块范围调节。
- 睡眠遮罩需保持纯黑，避免睡眠状态仍露出底层光晕。

## 预计工时

- 约 2 小时，含配置消息、控制端/显示端界面、文档同步和静态检查；多设备现场验收另计。

# 任务记录：根目录收敛迁移

## 任务描述

- 需求来源：用户确认继续收敛根目录，并将 `bootstrap` 简化为 `boot`。
- 目标：根目录仅保留核心目录（`3rd/config/docs/res/node_modules/skills/src`），其余业务目录归位。

## Design 需求

1. 将 AASC、Auto-Brain、脚本、静态资源迁入 `src`。
2. 将多语言子显示端迁入 `3rd` 统一托管。
3. 保持 `npm start` 与主要 API 路径兼容。

## Spec 设计

1. 目录迁移：
   - `aasc -> src/aasc`
   - `auto-brain -> src/auto-brain`
   - `scripts -> src/scripts`
   - `public -> src/apps/web-mediacenter/ui/public`
   - `voice-display* -> 3rd/voice-display*`
   - `self-test-results-*.json -> docs/self-test-results/`
2. 入口适配：`src/apps/server/boot/server-app.js` 更新路径拼装。
3. 启动脚本适配：`test:log-brain` 指向 `src/scripts/run-log-brain-tests.js`。

## 影响模块与代码

- 运行入口：`src/apps/server/boot/server-app.js`
- 启动配置：`package.json`
- 测试脚本：`src/scripts/run-log-brain-tests.js`
- 忽略规则：`.gitignore`
- 项目说明：`readme.md`
- 结构文档：`docs/design/project-structure.md`、`docs/spec/project-structure.md`
- 任务状态：`docs/todo.md`
- 变更日志：`changelog.md`

## 自测用例

1. 根目录检查是否仅保留目标目录集合。
2. 执行 `node --check src/apps/server/boot/server-app.js`。
3. 执行 `npm start`，确认服务启动成功。
4. 检查 `npm run test:log-brain` 的脚本路径是否可解析。

## 兼容性测试

- 入口命令兼容：`npm start` 不变。
- HTTP 页面兼容：`/upload`、`/display` 继续由服务端返回。

## 性能测试

- 目录重排与路径修正，不涉及性能敏感逻辑。

## 风险评估

1. 风险：目录迁移后相对路径失效。
2. 缓解：统一改为基于 `PROJECT_ROOT` 的路径拼装，并进行启动验证。

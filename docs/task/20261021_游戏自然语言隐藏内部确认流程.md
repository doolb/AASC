# 游戏自然语言隐藏内部确认流程

## 任务描述与设计需求

按用户原文在游戏 System 第一段后增加“自然语言中不要透露等待状态确认,GM的信息, 这些是内部流程。”，减少角色把内部确认机制说给用户。

## Spec 设计

```text
拼接 GAME_PROMPT → 协议格式段后加入指定句子 → 原有角色、目录与规则提示继续拼接
用户可见自然语言遵循内部流程隐藏约束 → 调用与 GM 回执仍走已有解析和权威校验
```

## 受影响模块

`game-chat-bridge.js`、`game-gomoku.test.js`、五子棋 design/spec/usage、todo、changelog；`servicePackage=true`。

## 自测、兼容与性能

`npm run test:game-chat` 48/48 通过，覆盖实际交给模型的完整提示中新增句子的原文及位置。调用解析和普通聊天保持原测试覆盖；仅增加一行提示，无新增网络和文件操作。

## 风险与预计工时

真实模型可能仍透露内部信息，需实际角色聊天验收；预计 15 分钟。

# Android 动态壁纸显示端

需求：将 APK 显示页面作为 Android 桌面背景，并由系统选择器确认启用。
设计：WallpaperService 的 Surface 接收私有 VirtualDisplay/Presentation 中 WebView 输出；壁纸拥有独立显示端身份，避免与普通显示页争抢连接。
实现：增加壁纸服务、系统预览入口、wallpaper 身份隔离、生命周期释放及资源配置。
自测：系统预览 WebGL、图片和视频；屏幕可见性、尺寸和旋转、普通显示端身份隔离；构建 noserver debug profile。
兼容性：目标 Android 8+；壁纸页没有 Activity 原生录音、摄像头和输入桥。Offline 模式需要本地服务已运行。
性能：不可见时销毁渲染资源，避免后台持续 WebGL；可见时连接服务器。
风险：不同厂商桌面、进程回收及休眠策略可能影响；视频和 WebGL 需真机验证。
预计工时：8 小时。

结果：实现壁纸服务和入口，壁纸及预览各有独立身份；设置入口先保存服务器地址。专项测试 7 项通过，noserver debug 构建通过。Android 9 系统预览以隔离测试页面验证 WebGL 显示和循环视频时间推进；未更改系统壁纸。实际 AASC 模型、桌面应用后的生命周期及其他系统版本待验证。正式 APK 和服务包尚未发布。

2026-11-09 用户修订：壁纸及预览沿用原显示端身份与保存的状态，前台和壁纸按可见性切换连接；前述独立身份方案已替换。正常和 Offline 身份分别沿用网页 localStorage 和 offline-display。7 项专项测试及 noserver debug 构建通过；Android 9 隔离页面验证前台→系统预览→前台同一 ID 依次连接。真实桌面切换、不同系统版本及原有恢复机制的覆盖范围待验收。

# 代理及媒体用户配置迁移

- 任务：将主配置中的代理和媒体用户数据迁移到用户配置目录。
- Design：network、media 使用 userconfig.json；已有用户字段优先；媒体连接列表维持原路径。
- Spec：先保存用户分区再清理旧分区，失败保留旧数据并重试；统一配置接口按分区路由。
- 影响：配置服务、代理和媒体库读取、备份恢复及 Offline 服务代码包。
- 自测：迁移、冲突优先级、失败重试、分区读写、重启与原数据保留。
- 兼容性：普通及 release 用户配置路径、原 WebSocket 协议、旧配置与备份。
- 性能：仅启动时合并一次，配置写入保持原有同步持久化方式。
- 风险：写盘失败或进程中断可能留下两份数据；用户配置优先且重复迁移幂等。
- 预计工时：2 小时。

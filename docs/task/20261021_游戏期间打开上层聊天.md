## Spec 设计

```text
已有声明 := 游戏层、交互层、聊天层、body.display-chat-open
新增定义 := 游戏关闭聊天时层级49；打开聊天时层级14
聊天关闭 → 游戏低于入口50 → 点击原聊天入口
聊天打开 → 使用既有状态类降低游戏层 → 聊天层15/20接收交互
聊天关闭 → 恢复游戏层 → 原棋局数据、版本、棋子及请求状态保留 → 继续落子
```

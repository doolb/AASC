# Offline 仅发布已有产物

- 需求：发布最新构建结果，无需重新打包或递增版本。
- 实现：新增 `--publish-only`，匹配同一产物目录和发布目标的最新报告，仅在报告完整、文件摘要和签名有效时复用现有发布流程；支持 `--dry-run`。
- 验证：最新任务未完成、文件缺失或变更时拒绝；源码发生变化提示但不重建；原发布器回归与定向测试共 22 项通过。完整报告副本通过只读预览，真实最新失败报告被拒绝。
- 兼容性：其他构建及恢复入口保持原行为；服务器基线、签名和版本保护继续生效。
- 性能：复用产物，校验时读取文件并计算摘要，无构建开销。
- 风险：已有产物可能落后于源码，输出明确提示并保留待出包标记；最新未完成时不会自动选择旧版。
- 预计工时：约 2 小时。

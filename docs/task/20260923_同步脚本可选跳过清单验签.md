# Offline 同步脚本可选跳过清单验签

## 任务描述

外网 `aasc-offline` 的同步脚本目前要求本机提供 Offline 更新公钥。若本机没有公钥，允许用户显式跳过本地清单 RSA 验签完成同步，并在命令行清楚提示风险。

## Design 需求

- 默认行为不变：必须加载公钥并验证 `manifest.json` 的 RSA 签名。
- 新增布尔参数 `--skip-signature-verification`，不接收参数值。
- 开启后只跳过本机 RSA 验签和公钥加载；仍执行清单结构、组件白名单、路径安全、文件大小、SHA-256、原子替换和安全清理。
- 命令行显式警告：未验签时，清单内的 SHA-256 仅能确认下载内容与该清单一致，不能认证清单来源。
- Android 客户端仍强制验签。

## Spec 设计

见 `docs/spec/android-offline-hot-update.md` 中 `syncOfflineUpdate` 与 `securityBoundary` 伪代码。先更新伪代码，再修改同步脚本。

## 受影响的功能模块和文件

- `scripts/ops/sync-offline-update.js`：参数解析、可选验签、警告输出。
- `scripts/ops/offline-update-package.js`：拆分清单签名包络格式校验与 RSA 验签，确保跳过 RSA 时仍检查包络格式。
- `docs/design/android-offline-hot-update.md`：同步行为与风险设计。
- `docs/spec/android-offline-hot-update.md`：同步流程伪代码。
- `docs/usage.md`：命令行用法和安全边界。
- `changelog.md`：记录变更。

## 自测用例

- 默认执行时仍加载公钥并验签；无公钥或签名无效时失败。
- 带 `--skip-signature-verification` 时不读取公钥，流程继续校验清单和下载文件。
- 结构无效、越权组件/路径、文件大小不符、SHA-256 不符仍失败。
- 缺失签名包络或签名算法/编码字段无效时，即使跳过 RSA 验签仍失败。
- 参数值、重复参数和未知参数均拒绝。
- 跳过验签模式输出来源未认证警告。
- 完整 APK 仍不被同步，清单仍在资源安装后原子替换。

## 兼容性与性能

- 现有参数和默认调用方式保持兼容；无需修改 Android 客户端或服务端协议。
- 仅在明确传入新参数时跳过一次本地 RSA 验证，资源下载与校验工作量不变。

## 风险评估

跳过验签会失去对清单来源的认证。攻击者若能替换清单，也能提供与恶意资源相符的哈希，因此参数必须显式、输出警告；Android 客户端仍会在应用更新前验签。

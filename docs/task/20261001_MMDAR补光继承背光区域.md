# MMD AR补光继承背光区域

## 需求与原因

用户确认修复“补光沿用主光阴影”照亮背光面。原系数只有shadow map可见度，未遮挡的背光面仍返回1。

## 设计与实现

后续用户反馈高强度补光使原0至0.05过渡产生硬折线，要求过渡延伸到负点积。本轮沿用实现授权把范围扩大到-0.3至0.3；点积0时保留一半补光，-0.3以下完全抑制，0.3以上完整继承可见度。共享模块与web-dist同步，无新增控件；实际高强度视觉仍待现场验收。

对应design/spec同名章节先记录方案和伪代码。修改共享 `display-pmx-lighting-mode.mjs`，主光遮挡×smoothstep(0,0.05,主光方向与片元法线点积)作为继承系数，在阴影条件之外缓存，每盏光采样默认重置1。仅由原pmxFillUsesKeyShadow开启；主光关闭回退沿用既有逻辑。

## 检查与验收

源语法和 `npm run build:web:mmd-ar-test`通过，web-dist已生成；未新增或运行测试。现场对照受光/背光、遮挡、交界，以及主光阴影/补光三模式切换，检查普通/Toon、双面材质及旋转模型后的方向响应。实际画面待验收。

## 兼容、性能与风险

主光自身光照及补光独立/无阴影沿用原行为。只增加点积与smoothstep，无新贴图/采样/pass。使用着色法线，异常法线和透明覆盖层仍可能影响观感；交界固定0至0.05无新增滑块。预计半小时实施与构建，现场验收另计。

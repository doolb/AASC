# 豆包按会话复用直连签名

## 需求与确认

用户询问每个会话生成签名，隔离实测可短时复用后确认按会话复用。适用Android Node LLM直连；网页兼容和桌面现状保持。需求为会话级流程优化，L5下放L4缓存/失效步骤；官方有效期未知，不能承诺永久签名。

## design与spec

见chat2api-doubao-web模块对应新节。先更新伪代码，再改适配器及定向测试；不修改原生API。内存LRU128，绑定账号、凭据摘要、内部AASC及权威上游会话和模式，成功后才缓存；新会话/变化/明确失效重新生成，失败请求不自动重发。

## 受影响模块

chat2api-doubao-chat-adapter.js、chat2api-doubao-android-prepare.test.js，按需补Responses集成测试；design/spec/task/todo/changelog/self-test；servicePackage标记待构建，不需要新APK。

## 自测、兼容与性能

先使用当前Note8/min72、独立源码/账号目录、真实Responses协议完成一次签名三轮对话：14/26/10字，最后签名年龄83843毫秒，同上游ready/3轮。仅按隔离记录删除该测试官网会话（status_code0），登录样本也已自动删除，临时API Key为0；隔离目录和新ADB转发已清理，原9222保留。

定向测试覆盖签名次数、正文/唯一键变化、成功后提交、会话/凭据/模式隔离、重建、HTTP与SSE失效、取消和LRU淘汰；执行npm run check:chat2api。普通模式续聊可省去一次WebView IPC/SDK准备，缓存容量固定，网页兼容及桌面回归不变。

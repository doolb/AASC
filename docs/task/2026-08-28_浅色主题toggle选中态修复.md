# 浅色主题 toggle 与 LLM/系统路由按钮选中态修复

## 任务描述

修复控制端浅色主题下自定义 toggle 无法清晰区分选中状态的问题，并覆盖设置页天气/搜索指令中 LLM 与系统路由按钮的选中状态。

## Design 需求

- 自定义 toggle 关闭态使用浅灰轨道、边框和可见滑块。
- 自定义 toggle 开启态使用当前主题强调色轨道和白色滑块。
- 原生复选框/单选框使用主题强调色。
- LLM/系统路由按钮通过 `active` class 表示选中项；未选中项使用浅色背景，选中项使用主题强调色渐变。
- 保留深色主题既有显示效果、控件 ID、事件和路由数据协议。

## Spec 设计

```text
浅色主题:
    checkbox/radio accent-color = accent-color
    crop-debug-slider off = bg-secondary + border-color + text-muted thumb
    crop-debug-slider on = accent-color track + white thumb
    routing-grid button without active = bg-secondary + text-secondary + border-color
    routing-grid button with active = accent gradient + white text + accent outline

Settings.updateUI:
    weather/search LLM button active = current value == llm
    weather/search system button active = current value == system
    保留原有内联背景，兼容深色主题和旧样式
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/css/theme.css`：新增浅色主题原生控件、自定义 toggle 和路由按钮选中态样式。
- `src/apps/web-mediacenter/ui/public/upload.html`：`Settings.updateUI()` 为 LLM/系统路由按钮同步切换 `active` class。
- `tests/ui-theme.test.js`：增加浅色 toggle 和路由按钮选中态契约测试。
- `docs/design/control-ui-theme.md`、`docs/spec/ui-theme.md`、`docs/todo.md`、`changelog.md`。

## 自测用例

1. 加载浅色主题，检查调试/控制 toggle：关闭态轨道、边框、滑块可见，开启态轨道为强调色、滑块为白色。
2. 在设置页分别选择天气和搜索的 LLM/系统，检查每组仅当前选项为 active，另一项保持未选中样式。
3. 切换暖黄、淡粉、淡紫黄、红蓝、尊贵金、藻盐、少女粉、玫瑰金和新年红等浅色主题，确认控件颜色跟随主题变量。
4. 回归深色主题，确认路由按钮仍保留原有内联绿色/半透明背景行为。

## 兼容性测试

- 保留四个路由按钮 ID、`data-routing`、`data-value` 和点击事件。
- 不修改 WebSocket 路由消息结构。
- 原生 checkbox/radio 继续使用浏览器控件，仅增加 `accent-color`。

## 性能测试

- 仅增加 CSS 选择器和 class 切换，不增加网络请求、轮询或渲染循环。
- `Settings.updateUI()` 仍为每种路由各更新两个按钮，时间复杂度不变。

## 风险评估

- 浅色主题样式需要覆盖按钮内联背景，因此路由按钮规则使用 `!important`；选择器限定在 `.routing-grid`，不会影响其他控制按钮。
- 自定义 toggle 增加 1px 边框并使用 `box-sizing: border-box`，不会改变外部尺寸。

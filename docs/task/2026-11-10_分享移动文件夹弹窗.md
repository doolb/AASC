# 分享移动文件夹弹窗

- 任务：将 B 站和夸克分享移动时的浏览器编号输入框替换为 HTML 文件夹选择弹窗。
- Design / Spec：见 `docs/design/media-library.md` 与 `docs/spec/media-library.md`。
- 模块：媒体库移动逻辑和样式，沿用服务端分类消息。
- 自测：两种来源、当前分类预选、未分类、确认/取消/Escape、异常文件夹名、断线和目标删除。
- 兼容性：不改变 WebSocket 消息和服务端持久化；桌面与窄屏均可访问。
- 性能：仅在点击时创建一次轻量 DOM。
- 风险：分类快照可能在弹窗打开期间变化，确认时重新校验目标并等待广播。
- 预计工时：1–2 小时。

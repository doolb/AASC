# PMX AO 采样次数与空间降噪优化

## 任务描述

用户反馈 PMX AO 在全分辨率下仍有颗粒，高强度时更加明显，角色移动时会闪烁。灯光面板提供可调采样次数，同时增强现有降噪。

## Design 需求

- 仅修改 PMX AO；VRM、阴影、物理和透明舞台保持现状。
- 采样档位为 12、24、32 次，默认 24；旧本地设置缺字段时补 24，已有合法选择保持不变。
- 改善静止颗粒与移动闪烁，不承诺仅靠空间滤波完全消除移动闪烁。
- 参数即时生效，沿用灯光本地保存，不新增服务器配置或依赖。

## Spec 设计

见 `docs/spec/mmd-pmx-vmd-local.md` 第 12 节：面板读取采样档位 → `DisplayMmd` 规范化 → PMX runtime 传入 AO uniform → 着色器按实际次数采样并归一化 → 扩展两次按深度保边的空间模糊 → 保持透明 alpha 合成。

## 自测用例

1. 旧设置缺少采样字段时默认 24；12/24/32 即时更新并保存，恢复默认回 24。
2. 三档采样均有可见 AO，透明背景及角色 alpha 不变，调成零强度不改变原色。
3. 全分辨率、半分辨率切换后采样设置保留，不重新加载 PMX。
4. 对比 12/24/32 次在静止角色、动画和旋转时的噪点与帧率；若移动闪烁仍明显，后续评估安全的时域累积。

## 兼容性测试

- 只依赖既有 Three.js/WebGL2；不支持 AO 时保留直接渲染。
- 原 `localStorage` 键不变，旧设置自动采用默认采样次数。
- HTTPS 独立测试网页由现有 `npm run build:web:mmd-ar-test` 构建并复用共享显示端代码；停止维护独立 APK。

## 性能测试

- 采样次数直接影响 AO pass 的深度读取量，空间模糊核扩大到每轴 7 个点；手机 GPU 实际帧率需现场比较。
- 默认半分辨率缓解开销；32 次加全分辨率属于高画质组合，不默认启用。

## 风险评估

- 低性能手机可能掉帧；可切回 12 次或关闭 AO。
- 空间滤波不能完全解决动作时闪烁；直接混合旧帧可能产生拖影，因此本轮不引入无重投影的时域累积。
- 强度 2 和大半径可能放大剩余噪点及光晕，需要目标设备视觉验收。

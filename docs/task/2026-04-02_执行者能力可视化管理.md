# 执行者能力可视化管理

## 任务描述

新增执行者和能力的可视化管理功能，采用2D地图方案展示系统中的执行者（人物）和物理设备（房子），支持用户直观地查看和管理系统状态。

## 需求来源

- docs/todo.md: 新增执行者和能力，支持用户可视化管理

## Design 需求

### 核心功能

1. **地图界面**：展示系统拓扑结构
2. **房子可视化**：代表物理设备（服务端、显示端、控制端）
3. **人物可视化**：代表执行者
   - 人物状态：显示执行者的实时状态
   - 人物服饰：代表执行者具备的能力
   - 人物大小：根据执行者的能力自动调整大小

### 可视化规则

| 元素 | 可视化方式 |
|------|-----------|
| 设备类型 | 不同图标和颜色 |
| 设备状态 | 发光效果、透明度、动画 |
| 执行者状态 | 颜色/光环 |
| 能力等级 | 人物大小 |
| 能力类型 | 服饰/图标 |

### 技术方案

- 2D渲染：PixiJS
- 3D扩展：Three.js（后续）
- 架构：分层设计，数据与渲染解耦

## Spec 设计

### 模块结构

```
public/js/map/
├── core/
│   ├── map-data.js        # 数据模型
│   ├── data-adapter.js    # 数据适配器
│   └── constants.js       # 常量定义
├── renderer/
│   ├── i-renderer.js      # 渲染器接口
│   └── renderer-pixi.js   # PixiJS 渲染器
├── sprites/
│   ├── building-sprite.js # 房子精灵
│   └── actor-sprite.js    # 人物精灵
└── map-panel.js           # 地图面板入口
```

### 数据模型

- BuildingData: 房子/物理设备数据
- ActorData: 执行者/人物数据
- ConnectionData: 连接线数据

### API 接口

- GET /api/actors: 获取所有执行者数据
- GET /api/buildings: 获取所有设备数据
- WebSocket: 实时状态更新

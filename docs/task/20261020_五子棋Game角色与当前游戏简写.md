# 五子棋 Game 角色与当前游戏简写

日期：2026-10-20

## 任务描述

用户给出的模型回复以 `User:落子,A9`、`AI:落子,F5` 独立行开头，原解析器只识别 `Game:` 和尖括号外形，导致棋盘未变并触发补判。用户进一步要求游戏角色统一改为 `GameUser`、`GameAI`，包括 GM 回执，旧 `User`/`AI` 游戏调用不再兼容。

## Design 需求与 Spec 设计

见 `docs/design/game-gomoku.md` 和 `docs/spec/game-gomoku.md`。活动棋局允许 `GameUser:落子,A9` / `GameAI:落子,F5` 行首简写，由目标显示端权威快照补游戏名。完整行、简写和尖括号外形共用权威校验，角色必须是新名称。GM 中的落子者、下一手、胜方也使用新名称；内部棋盘和显示端 WebSocket 数据保留现有值。

## 受影响模块与代码

- `src/apps/server/modules/game/gomoku-game-service.js`：解析新角色与活动棋局简写，输出新 GM 字段。
- `src/apps/server/modules/game/game-chat-bridge.js`：提示、逐轮快照、文本过滤、协议摘要与原子执行。
- `tests/game-gomoku.test.js`、`tests/game-chat-session.test.js`、浏览器协议提示测试：迁移调用样例并核对简写和回执。
- 五子棋 design/spec/usage、todo、changelog、Offline 服务包状态。

## 自测用例、兼容性与性能

运行 `npm run test:game-chat`，验证 A9→GM→F5、同回复抢跑只执行用户步、无活动棋局不执行简写、旧角色拒绝、终局 GM 状态。运行控制端和显示端相关浏览器测试，确认灰色协议提示仍可显示。旧角色的协议调用按用户要求不兼容；尖括号外形仅保留新角色解析。简写只增加少量正则匹配，不改变棋盘计算和显示端数据。

## 风险评估与预计工时

旧模型会话若继续生成 `User`/`AI` 游戏角色，会收到格式错误并需按新提示重试。真实模型可能继续输出无效调用；GM 校验保证棋盘不会误落子。预计约两小时。

## 执行结果

`npm run test:game-chat` 41/41 通过，包含活动棋局 A9→GM→F5、同回复预写两步只执行用户步、旧角色拒绝、行内文字与无活动棋局不触发简写、双方终局 GM 状态。控制端协议提示和显示端聊天浏览器测试 12/12 通过；`git diff --check` 通过。服务包状态已有 `servicePackage=true`，仍待构建与真实两端验收。初次实现时没有调用真实模型或修改真实棋局。

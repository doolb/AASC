# 媒体库和紧凑竖屏布局

- 需求：媒体库封面铺满卡片，来源导航更紧凑；显示和其他控制面板尽量在首屏展示常用功能，适配竖屏。
- 设计/伪代码：`docs/design/control.md`、`docs/design/media-library.md`、`docs/spec/upload.md`、`docs/spec/media-library.md`。
- 范围：媒体库卡片、分类导航、控制端面板布局及原有主题。
- 自测：图片/视频/音频/目录、媒体源和操作、键盘/触屏、15 套主题及横竖屏；显示控制与媒体回归。
- 兼容：保留功能标识、事件、权限和媒体数据；非首屏内容可展开或滚动。
- 性能：CSS 布局为主，不额外加载媒体或引入依赖。
- 风险：不同比例封面会裁边；大数据列表和实际设备仍需现场验收。
- 预计工时：1 至 2 个工作日。

# 2026-09-23 图片定位视频帧尺寸修复

## 任务描述

用户反馈已保存图片后持续显示“查找中”。检查发现实时视频取帧时先读取元素 `width/height`，可能与摄像头原始帧的 `videoWidth/videoHeight` 不同，导致识别画面变形。

## Design 需求与 Spec 设计

- 实时视频优先使用 `videoWidth/videoHeight` 生成识别帧，保存图片继续使用图像自身尺寸。
- 识别失败返回明确阶段原因：摄像头未就绪、纹理不足、匹配不足或几何位置不稳定。
- 定位面板根据原因提示增加光线、靠近并摆正图片或保持镜头平稳。

## 受影响模块和代码

- `src/apps/web-mediacenter/ui/public/js/display-mmd-image-tracker.js`
- `src/apps/web-mediacenter/ui/public/js/display-mmd-ar.js`

## 自测用例

- 摄像头原始宽高与视频元素显示宽高不同时，识别帧保持原始宽高比。
- 基准图出现在画面时，匹配并更新角色脚底位置；移走后显示丢失。
- 光线不足、图片太远或镜头晃动时，面板显示对应阶段提示。

## 兼容性、性能与风险

- IndexedDB 目标格式和摄像头权限流程不变；无新增依赖。
- 仅修正画布目标尺寸和提示映射，不增加每帧算法复杂度；预计工时约 1 小时。
- 需在目标 Android WebView 上验证实际识别效果；低纹理、反光或大角度拍摄仍有识别限制。

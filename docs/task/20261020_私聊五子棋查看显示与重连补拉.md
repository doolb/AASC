# 私聊五子棋查看显示与重连补拉

日期：2026-10-20

## 任务描述

用户反馈私聊时棋盘没有显示，并明确要求除 `退出显示` 外，对棋盘的操作都应显示棋盘，尤其是 `Game:五子棋,GameAI,查看`。现场日志中显示端处于 `activePrivate`，AI 的“查看”只产生 GM 状态；显示端重连后没有首次 `gameRecover`，本地没有棋盘快照。

## Design 需求与 Spec 设计

见 `docs/design/game-gomoku.md` 和 `docs/spec/game-gomoku.md`。WebSocket 可发送后总是补拉权威棋盘，即使本地状态为空。GM 查看保留原状态回执并下发完整快照；已隐藏的棋局在查看、落子或提议尺寸时恢复可见并持久化版本。退出显示仍主动隐藏；等待唤醒时显示端继续隐藏真实棋盘。

## 受影响模块与代码

- `src/apps/web-mediacenter/ui/public/js/display-game.js`：连接与重连后无条件请求恢复快照。
- `src/apps/server/modules/game/gomoku-game-service.js`：查看下发快照，非退出的棋盘操作恢复可见。
- `tests/display-game-browser.test.js`、`tests/game-gomoku.test.js`：覆盖初始请求失败、私聊状态、查看和隐藏态操作。
- 五子棋 design/spec/usage、todo、changelog 与 Offline 服务包状态。

## 自测用例、兼容性测试与性能测试

运行显示端浏览器测试与 `npm run test:game-chat`，核对首次 WebSocket 尚未连接、已有棋局查看、隐藏后查看和落子、退出显示仍隐藏、普通可见落子继续只发增量。查看最多补发当前棋盘一份快照，不轮询；重连每次补拉一次，额外传输受 15×15 棋盘大小约束。

## 风险评估与预计工时

查看从仅返回状态变成同时刷新显示端；若此前已隐藏，会递增棋局版本，调用方须使用新版本继续操作。服务包更新后仍需在真实私聊和显示端重连过程中观察界面及 TTS。预计约一小时。

# MMD AR 法线预览诊断

- 需求：定位 highp 后残留轻微横条是否来自 AO 深度重建法线。
- 设计/spec：`docs/design/mmd-ar-test-apk.md` 与 `docs/spec/mmd-ar-test-apk.md`。
- 影响：`web-ao-preview.js` 对生成的 AO 模块注入只读可视化分支；`build.js` 调用转换并更新内容指纹；`web-panel-groups.js` 增加本次页面有效的预览开关。
- 流程：使用原法线计算、编码 RGB、跳过遮蔽和模糊、合成保留透明度；关闭后恢复原有参数。
- 自测：网页构建、面板回归、真实 PMX 加载后的预览开关和 shader 编译，截取桌面预览验证画面。
- 兼容性：仅测试网页，正式显示端和 APK 不变；手机 Vivaldi 的横条仍需现场验证。
- 性能：预览减少 AO 遮蔽及模糊运算，保留当前 AO 目标尺寸，不新增常驻绘制通道。
- 风险：低分辨率预览包含原 AO 采样网格的影响，颜色用于诊断方向，不能当作模型原始法线。
- 预计工时：半小时。

# 静置死区校准

需求：单朝向静置自动求角速度与去重力后加速度死区，无需零偏/六面校准。
设计/spec：对应 imu-six-axis-test 文档末节；先文档再实现。
涉及：imu-engine.mjs、app.mjs、index.html、算法/浏览器自测与使用说明。
自测：静态带偏置输入得出非零门限，偏置不改；运动/断流不能污染窗口，取消保留原值；UI成功后滑块同步。
兼容：模拟器/手机/远程APK共用估计器；平台通道不切换。
性能：窗口最多1200样本；采集结束排序一次，常态不额外统计。
风险：缓慢匀速运动不可单凭IMU识别，用户需实际静置；阈值仅代表当前环境/朝向。
预计工时：半小时；真机效果待验。

结果：实现完成，专项16/16通过；先前一次浏览器失败为点击下方按钮后视口滚出屏幕，调整用例滚动后通过。原始偏置保持、静态阈值估计、运动/断流重采、取消/超限与手机UI同步均已覆盖。实际手机效果保留todo验收。

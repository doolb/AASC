# 六轴IMU测试页亮色界面

日期：2026-10-17。状态：已完成。

## 任务描述

将独立六轴IMU测试页的深色界面改为统一亮色界面，覆盖页面控件与左右3D视口；保持桌面双列、手机单列、采集/估计/校准/共享行为不变。

## design需求

- 固定使用亮色主题，不依赖系统深浅色偏好。
- 页面背景、面板、按钮、输入框、数据读数、状态提示采用协调的浅色表面、深色文字和清楚的边框/焦点层级。
- 左侧估计场景和右侧模拟场景采用浅色背景与低干扰网格；设备、坐标轴、轨迹在浅底保持可辨。
- 样式调整不得进入传感器数据、估计状态、校准参数和WebSocket房间消息。

## spec设计

伪代码已先写入`docs/spec/imu-six-axis-test.md`：新增`ThemePalette`视觉调色板声明；页面控件与3D场景分别应用亮色表面、深色文字和高对比设备色；手机继续复用同一主题；主题颜色不参与IMU数据流。

## 受影响的功能模块和代码

- `3rd/imu-six-axis-test/style.css`：页面、控件、标签、读数、徽标、焦点状态和响应式界面配色。
- `3rd/imu-six-axis-test/imu-scene.mjs`：估计场景/模拟器视口共用背景、网格、照明和设备面板颜色。
- `3rd/imu-six-axis-test/app.mjs`、`imu-simulator-view.mjs`、`server.mjs`：调整本机、模拟器及远端设备颜色，保证浅底可见。
- `docs/design/imu-six-axis-test.md`、`docs/spec/imu-six-axis-test.md`、`docs/usage/imu-six-axis-test.md`、`docs/usage.md`、测试页README、`docs/todo.md`、`changelog.md`：同步需求、伪代码、使用说明及完成记录。

## 自测用例

- 桌面双栏中页面、按钮、输入框、数据读数和提示均呈亮色，文字与边框保持清晰。
- 左右两个WebGL视口均显示浅色背景；网格、坐标轴、模拟设备、估计设备、多设备轨迹仍可区分。
- 手机单列视图沿用亮色主题，页面横竖屏布局和交互状态保持原行为。
- 颜色调整不改变传感器采集、估计位姿、校准、房间共享消息和设备所有权。

## 兼容性测试

- 桌面Chromium及Android/iOS浏览器通过同一CSS和Three.js主题配色显示。
- 页面尺寸、现有响应式断点与触屏/鼠标交互不变；不引入新依赖。

## 性能测试

- 仅修改CSS颜色和Three.js静态材质/背景颜色，不新增渲染循环、DOM更新或采样工作。
- 性能预算与原页面一致，不预期增加持续CPU/GPU负载。

## 风险评估与预计工时

- 风险低；主要风险是亮色背景下网格或浅色设备颜色对比不足，通过低干扰灰蓝网格及较深设备色处理。
- 预计实现与文档同步约1小时；本次不改变IMU算法和发布产物。

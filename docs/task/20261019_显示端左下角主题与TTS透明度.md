# 显示端左下角主题与 TTS 字幕背景透明度

## 任务描述

在显示端左下角按钮区增加“主题”按钮，展开面板后选择现有 15 套全局主题，并调整现有 TTS 字幕背景透明度。用户确认两项设置均使用服务端全局配置。

## 需求与设计

- 入口与“聊天／角色”共用左下角安全区，面板向上展开，支持点击外部或 Escape 收起。
- 主题选择沿用 `ui.controlTheme` 的 15 项白名单；显示端通过 WebSocket 写入，服务端持久化后广播控制端和显示端。
- 字幕背景透明度沿用 `ui.displayTtsBackgroundOpacity`；滑条 0–100%，1% 步长，默认 20%，拖动预览，松开保存。
- 两项设置由服务端回传权威值，失败回退；重连补发当前值。字幕文字、媒体画布和 TTS 播放流程不受设置操作影响。

## 伪代码设计

见 `docs/spec/ui-theme.md` 与 `docs/spec/display-tts-background-opacity.md`：面板事件发送带 `type` 的 WebSocket 配置消息；服务端校验、`config.set`、广播；客户端按权威值回显。

## 受影响模块和代码

- `src/apps/web-mediacenter/ui/public/display.html`、`css/display-mmd.css`、`js/display-appearance-controls.js`：入口、布局与交互。
- `js/ui-theme.js`、`js/websocket.js`：主题读取竞态保护及控制端同步。
- `src/apps/server/boot/server-app.js`：显示端配置入口、共享校验持久化及广播。
- `tests/display-appearance-controls.test.js`、`tests/ui-theme.test.js`：面板和主题时序回归。

## 自测、兼容与性能

- 定向测试：面板展开、15 项主题、0–100% 滑条、预览、两项配置消息、断线回退、初次读取与广播竞态、旧控制端配置入口。
- 兼容：旧显示端忽略新增消息；旧控制端仍可用现有主题 HTTP 保存和透明度 WebSocket 保存。刷新与重连由已有补发流程恢复配置。
- 性能：滑条拖动仅更新本页 CSS 属性，松开才写服务器；主题变化只更新主题属性和已有控件变量。

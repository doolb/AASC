# 修复 Claude 超时重建测试误判

## 任务描述

修复 ClaudeBridge 超时重建回归测试中，第二轮新进程冷启动耗时被短响应超时误判，导致 `echo:b` 未返回的问题。

## 根因

测试把首轮“验证卡死并超时”的 `readTimeoutMs=150ms` 延续到重建后的新进程。新进程启动和加载 Node/Claude CLI 的时间可能超过 150ms，第二轮因此在尚未完成正常响应前再次超时。生产默认响应超时为 600 秒，不存在该测试阈值问题。

## 修复方案

- 首轮继续使用短超时，验证无响应进程会被清理。
- 等待旧进程退出后，第二轮恢复正常响应窗口，再验证完整 FIFO/进程重建和消息回包。
- 不改变生产 ClaudeBridge 的默认超时策略。

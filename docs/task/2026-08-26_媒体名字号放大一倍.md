# 媒体名字号放大一倍

## 任务描述

将显示端媒体名 `fileNameDisplay` 的文本字号放大一倍，同时保持各旋转角度的位置适配和覆盖层避让。

## design 需求

- 桌面端媒体名字号由 24px 调整为 48px。
- 移动端媒体名字号由 16px 调整为 32px。
- 放大后继续通过实际包围盒执行旋转位置适配：0°覆盖层位于媒体名上侧，90°/180°/270°分别从右侧/下侧/左侧避让，避免重叠或超出视口。

## spec 设计

- 修改 `display.css` 的 `#fileNameDisplay` 桌面端和移动端字号。
- 复用现有 `display.html` 旋转布局及 `render.js` 媒体名避让逻辑；字号增大后 0°也重新计算覆盖层位置，不改变媒体播放和通信协议。
- 在显示端旋转测试中增加字号规则断言。

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/css/display.css`
- `res/tasks/render-display/render.js`
- `tests/display-broadcast-text-rotation.test.js`
- `docs/design/display.md`
- `docs/spec/display-ui-rotation.md`

## 自测用例

- 检查桌面端媒体名为 48px。
- 检查移动端媒体名为 32px。
- 运行显示端旋转、render-display 位置及显示端集成回归。

## 兼容性、性能与风险

- 仅调整 CSS 字号，不改变媒体数据、WebSocket 协议和播放逻辑。
- 字号增大后文本占用空间增加，由现有最大宽度、包围盒和旋转定位逻辑继续约束。
- 小屏设备文字可能更容易触发省略号，但不会破坏布局边界。

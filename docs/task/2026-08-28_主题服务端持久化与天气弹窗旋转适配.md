# 任务：主题服务端持久化与天气弹窗旋转适配

## 任务描述

将控制端主题从单浏览器缓存扩展为服务端全局配置，并修复控制端输入“今日天气”后，显示端天气响应文本弹窗未随显示器旋转角度适配的问题。

## Design 需求

- 服务端在主配置中保存 `ui.controlTheme`，提供主题读取和更新接口。
- 主题更新只允许当前已注册的 15 种主题；控制端保留 `localStorage` 作为离线和旧服务端兼容回退。
- 控制端启动时先快速应用本地主题，再异步以服务端全局主题覆盖；选择主题时立即更新界面并异步保存服务端。
- “今日天气”显示使用的控件是显示端 body 下动态创建的 `.voice-response-popup`，不是 `#mediaText`；该弹窗以及同类临时响应弹窗需跟随 0/90/180/270 度旋转。
- 90/270 度使用交换后的逻辑宽高限制弹窗内容区域，防止长文本越界。

## Spec 设计

- `GET /api/config/controlTheme` 返回 `{ status: 'success', theme }`。
- `POST /api/config/controlTheme` 接收 `{ theme }`，非法值返回 400，合法值写入 `ui.controlTheme` 并返回主题。
- `UiTheme.init()` 应用本地回退后启动 `ready` 异步读取；服务端读写失败只记录警告，不阻断页面。
- 显示端增加临时弹窗查询和旋转布局函数；弹窗创建及 `applyRotation()` 时都重新设置旋转、最大宽高和溢出策略。

## 自测用例

1. 服务端主题白名单可识别 15 种主题，非法值回退或拒绝更新。
2. 控制端初始化可读取服务端主题；服务端失败时继续使用本地主题。
3. 控制端切换主题会立即更新页面并发起服务端保存请求。
4. 显示端动态天气弹窗在 0/90/180/270 度下整体旋转，最大宽高随逻辑画布变化。
5. 语音确认、搜索结果、播放选择和提醒等同类弹窗不回归。

## 兼容性测试

- 旧服务端、服务端接口不可达、浏览器禁用 `localStorage` 时控制端仍可初始化。
- Chrome/Chromium 窄屏和横竖屏下检查长中文天气文本不越界。
- 深色和 14 种浅色主题均继续使用既有控件对比度规则。

## 性能测试

- 主题只在初始化增加一次 GET，切换增加一次 POST，不轮询、不刷新页面。
- 弹窗旋转复用已有角度布局，仅在旋转、窗口尺寸变化和弹窗创建时更新。

## 风险评估

- 主题白名单在服务端和控制端各维护一份，后续新增主题必须同步两处。
- 动态弹窗使用 CSS 动画，旋转变换需避免动画结束后覆盖角度；通过 CSS 变量统一变换。
- 服务端配置写入失败时只能保证当前浏览器会话主题，无法保证跨浏览器同步。

## 未明确需求

- 主题作用域已确认采用服务端全局控制端主题；显示端不切换主题。

## 预计工时

约 1.5 小时，包含接口、控制端加载保存、显示端旋转修复、测试和文档同步。

## 风险评估

- 迁移重写 `network.globalWebProxy` 和 `providerProxy`，需保留配置备份。日志与业务配置同一文件，只保证普通 set 失败及完整写入间中断恢复，不保证底层写入中断截断恢复，也非多个 set 瞬时原子事务。
- 服务端操作令牌、连接/来源复核及浏览器 requestId 过滤旧扫描；单文件先可信解析持久化再 displayMediaStart 确认，失败不替换旧播放。文本路由固定当前显示端并终止旧朗读。
- 本地库使用完整路径段边界，符号链接行为保持原有兼容，不等于新增真实路径隔离。
- 真实代理走线、SMB/SAF、Android 触屏和真实下载保留 docs/todo.md；本轮未构建发布或控制现场服务器。

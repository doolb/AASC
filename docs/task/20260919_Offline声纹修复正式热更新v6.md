# Offline 声纹修复正式热更新 v6 发布任务

## 任务描述

将声纹启动预热、注册等待和断线回收修复通过 Offline 正式服务热更新流程发布，使已安装 Offline APK 的设备可以从外网更新清单发现并安装代码修复。

## Design 需求

- 使用 `code-only` 模式生成 code v6。
- 复用已发布 dependencies v3，不重复发布生产依赖。
- 清单保留 apkMin v16，完整 APK v17 不写入服务更新清单。
- LAN/WAN 清单必须签名有效、内容一致并原子替换。

## Spec 设计

- code v6 的 `requiredDependencyVersion` 必须为 3。
- `code/code-v6.zip` 必须包含最新 `display.html` 和 `server-app.js`。
- 发布器先校验本地工件，再上传版本化代码包，最后切换 `manifest.json`。
- 发布后更新客户端应能通过 `manifest.json` 发现 code v6。

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/display.html`：声纹模型 ready 等待。
- `src/apps/server/boot/server-app.js`：声纹注册超时和断线回收。
- `release/offline-update/output/code/code-v6.zip`：正式服务代码包。
- `release/offline-update/output/manifests/manifest-code-v6.json`：签名发布清单。
- LAN `/mnt/aasc-offline` 和 WAN `as@120.79.245.103:~/a/aasc-offline`：热更新目标。

## 自测用例

- code v6 构建包 SHA-256 与清单一致。
- code v6 zip 中的页面和服务端文件 hash 与当前源码一致。
- LAN/WAN `manifest.json` 签名有效且 JSON 内容一致。
- 清单组件为 code v6、dependencies v3、apkMin v16。
- code v6 HTTP 返回 200 和正确 Content-Length，远端 hash 与本地一致。

## 兼容性测试

- code-only 不改变 dependencies v3 和 min v16。
- full v15、full v17 和已有 Offline Runtime 均可使用该代码包。
- 完整 APK v17 仍作为独立安装包，不参与服务更新清单。

## 性能测试

- code 包大小约 14 MB，LAN/WAN 下载和 hash 校验均完成。
- 未重新上传 100 MB dependencies 包，降低正式更新耗时和设备流量。

## 风险评估

- 设备需要能访问正式更新源并通过更新客户端校验签名。
- 现场更新后仍需验证 Runtime 的 active release 切换和声纹注册流程。
- 清单切换成功后不自动回滚，若设备现场失败需要按发布器规则补发更高版本。

# 镜头加快回中与壁纸诊断

需求：镜头回中系数在现有值上增大 3 倍，排查壁纸时无效。
设计：回中指数系数由 5 改为 15，同步将移动输入增益增加 3 倍以补偿持续移动幅度；网页传感器在壁纸 Presentation 丢失可见性或焦点时可能被系统暂停，设备上的具体原因有待验证。
实现：先更新壁纸控件 spec，再调整网页回中、自测与文档；传感器获取方案仍等待用户决定。
影响：普通和壁纸显示端全息镜头。
自测：回中系数、四向位移、开关和动画生命周期。
兼容：无需更新 APK 即可应用回中参数；壁纸数据是否可用取决于 WebView。
性能：常数变化，无额外持续开销。
风险：短时移动的幅度与持续移动仍会受更强回中影响；强回中无法修复缺失传感器事件。
预计工时：半小时。

# PMX 始终忽略材质环境色

## 任务描述

用户确认所有 PMX 模型始终忽略模型自带的材质“环境色”。原 `MMDLoader` 将该值映射为 `MMDToonMaterial.emissive`，使环境光与主光都为 0 时人物仍显灰。仅调整显示端 PMX 加载行为，不修改 VRM、模型资源、第三方加载器、APK 或发布资源。

## Design 需求与 Spec 设计

- 设计依据：`docs/design/mmd-pmx-vmd-local.md` 第 7 节。加载完成但尚未显示时，将 PMX Toon 材质的 `emissive` 清零；其他材质字段不变。
- 伪代码：`docs/spec/mmd-pmx-vmd-local.md` 第 3 节 `loadPmxResource`。处理所有 PMX 网格的单材质和多材质，保持加载暂存与一次性显示流程。
- 需求等级：局部 PMX 加载规则，主等级 L5、落地能力 L4；按“加载 → 遍历材质 → 清零环境色映射 → 进入暂存/提交”执行，无远端协议变更。

## 受影响模块

- `src/apps/web-mediacenter/ui/public/js/display-pmx-runtime.js`：PMX 加载后材质处理。
- `tests/display-pmx-ao-browser.test.js`：真实米娅 PMX、两盏灯为 0 的浏览器像素回归。
- `docs/design/mmd-pmx-vmd-local.md`、`docs/spec/mmd-pmx-vmd-local.md`、`docs/usage.md`、`docs/self-test.md`、`docs/todo.md`、`changelog.md`：文档同步。

## 自测与兼容性

1. PMX 加载、纹理和动作保持正常；环境光和主光强度都为 0、AO 关闭时，角色不再因材质环境色显灰。
2. 恢复正常光照时，diffuse、贴图、透明度和 toon 阶调仍显示；PMX 换模后重复生效。
3. VRM 不执行该 PMX 专属规则；不改变阴影、AO、物理、VMD 与同源资源白名单。

## 性能、风险与工时

- 加载完成时遍历一次材质，无逐帧额外开销。普通光照下模型会比之前略暗，这是忽略环境色的预期影响。
- 预计工时：1–2 小时。

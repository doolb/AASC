## 自测、兼容性、性能与风险

- 单测：7×7局部峰加权质心、低峰保留、边界截断/出ROI、张量维度和非有限值、只改二维不变世界坐标/置信、输入副本和ROI反投影方向。
- 浏览器：新图候选/椅背肘部改善坐标和目视对照；旧二次元3候选仍选回女孩；已有照片左右/11目标/270子步、粘贴/取消/无人保护、实际骨架/相机拟合与恢复回归。
- 兼容：仍ORT Web WASM/本机Worker，无新依赖；桌面Edge先验，Android/iOS真实设备耗时和效果另验。
- 性能：每候选最多1911次热图采样，最多3候选；不增加推理轮数，预期较ONNX推理开销小，最终以实际计时为准。
- 风险：热图可能定位错误、遮挡关节不可观测、world三维仍为估计；不可用单张图局部改善代替整图精度验收。后续如需更强模型或参考点手工纠正须另列方案，不自动改变已选的图片只对照/3D拖点交互。
- 预计实现与桌面回归1～2小时；用户确认后开始运行代码修改。

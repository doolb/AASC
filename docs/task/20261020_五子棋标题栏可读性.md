# 五子棋标题栏可读性

- 任务：五子棋标题和回合状态在明亮、复杂的显示端画面上保持可读。
- Design：`docs/design/game-gomoku.md`；只给标题栏添加类似 TTS 字幕的半透明深色渐变、轻微背景模糊与白字阴影，棋盘外层保持透明。
- Spec：`docs/spec/game-gomoku.md`；代码修改前已更新伪代码。
- 受影响模块：`display-game.css`、`display-game-browser.test.js`。
- 自测：标题与状态在浅色主题下有渐变背景、4px 模糊和内边距；棋盘外层仍透明，关闭按钮可点击；模糊不受支持时仍有渐变背景。
- 兼容性：不改 HTML、游戏协议、落子事件或 TTS 字幕透明度配置。
- 性能：单个标题栏使用固定 4px 背景模糊，不参与棋盘点按或落子重绘。
- 风险：旧 Android WebView 可能忽略 `backdrop-filter`；半透明深色背景和文字阴影仍可读。
- 预计工时：约 30 分钟。
- 验证：`node --test tests/display-game-browser.test.js tests/game-gomoku.test.js` 16/16 通过；当前 Note8 显示端演示时计算背景为深色渐变、模糊为 `blur(4px)`，截图 `/tmp/aasc-gomoku-header-bg-note8.png`，结束后恢复原棋盘。

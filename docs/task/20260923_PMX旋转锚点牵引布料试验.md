# PMX 旋转锚点牵引布料试验

状态：代码与自动测试完成；真实 PMX 布料效果待现场确认。

## 任务描述与需求

用户反馈 PMX 水平和俯仰旋转缓动期间布料乱，停止后恢复；要求角色本身旋转并保留布料惯性。当前实现将中心枢轴增量整批传送给 Bullet 刚体。简化 Ammo 关节复现显示，整批传送会放大转动期间的关节误差；再补同一次旋转的速度还会让动态刚体在下一步重复位移。本任务先试验只移动角色枢轴和运动学锚点，让动态刚体由约束牵引。

## Design 需求与 spec 设计

- 设计依据：`docs/design/mmd-pmx-vmd-local.md` 的 PMX 物理旋转章节；保留角色真实旋转、指数缓动、现有 Ammo/VRM 路径。
- 实现依据：`docs/spec/mmd-pmx-vmd-local.md` 的 `renderMmdFrame` 伪代码；每帧先推进枢轴，再更新世界矩阵及 helper；不再搬运 type=1/2 动态刚体或重写线/角速度。
- 物理初始化保持 `warmup=0`，首次解算仍在模型显示后的下一帧；频率设置和 `maxStepNum=3` 不变。

## 受影响模块与代码

- `src/apps/web-mediacenter/ui/public/js/display-pmx-runtime.js`：调换旋转/物理时序，移除枢轴同步状态。
- `src/apps/web-mediacenter/ui/public/js/mmd-pmx-helper.mjs`：移除整批刚体传送入口。
- `tests/display-mmd-runtime.test.js`、`tests/mmd-pmx-helper.test.js`：旋转先于物理、动态刚体不传送的回归覆盖。
- `docs/spec/mmd-pmx-vmd-local.md`、`docs/design/mmd-pmx-vmd-local.md`、`docs/self-test.md`、`docs/todo.md`、`changelog.md`：同步设计、测试和状态。

## 自测、兼容性、性能

- 自动测试：先见到旧帧序回归测试失败，再在修改后通过；运行 PMX 定向测试与 `npm test`，语法及差异检查。
- 现场自测：带布料 PMX 连续 yaw、pitch、反向和停转，分别试 30/65/90 Hz；观察穿模、关节爆散、自然摆动与收敛。
- 兼容性：无刚体 PMX、VRM SpringBone、VMD/IK/grant 和灯光面板保持原有语义。
- 性能：去掉每帧全刚体矩阵搬运；仍按现有物理子步上限运行。

## 风险、未明确项与预计工时

- 快速旋转下约束可能短暂拉伸，实际 PMX 骨骼与多关节行为无法由简化复现替代；现场效果待确认。
- 低渲染帧率下运动学锚点在一次 `stepSimulation` 内仍可能跨多个 Bullet 子步移动；若试验仍乱，需要重新评审固定子步方案。
- 预计 1–2 小时，含代码、文档、自动验证；现场观察另计。

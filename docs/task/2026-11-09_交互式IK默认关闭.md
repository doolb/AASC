# 交互式 IK 默认关闭

需求：显示端初次加载模型时默认关闭交互式 IK，保留手动开启。
设计：Human 实例初始 `ikWanted` 为 false，沿用原有手动启停及可见性恢复；不修改模型手势逻辑。
实现：同步 `docs/spec/mmd-human-interface.md` 的伪代码；修改 `mmd-human-interface.mjs` 及依赖旧默认的测试，标记服务代码包待构建。
验证：真实 PMX 与 Ammo 生命周期验证默认关闭、手动启用、隐藏恢复及关闭；浏览器验证真实面板和模型；手动未开启时身体 IK 自动动作不可用。
兼容与性能：新显示端实例默认关闭；手动开启在同一实例隐藏恢复时仍保持意愿，避免默认加载 IK 的开销。
风险：内置身体 IK 自动动作需要用户手动开启；服务端网页须更新后生效。预计工时：1 小时。

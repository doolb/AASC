# MMD AR衣服自然受风

## 需求与确认状态

用户同意推进衣服自然摆动，并明确“先不处理顶点布料”。本次范围确定为Ammo/刚体XPBD；具体文件和受风方案已获用户确认，已完成实现及定向验证。旧顶点相对气流方案已撤出本任务。

## Design需求与Spec设计

见design/spec对应2026-10-02刚体衣服章节。复用风开关/0–30等级/经纬度/阵风，使用球/盒/胶囊代理迎风面积及相对受力点气流，连续空间阵风和子步隐式阻力；type2维持位置驱动和原12rad/s²角加速度限幅。第一阶段不处理顶点求解器、挡风和完整流体；碰撞代理与实际衣服面积有误差。

## 自测与兼容

球/盒/胶囊正侧面与旋转投影；相对同速为0、顺/逆风差异；强度30/微小质量不出现过冲/NaN，不同子步与渲染FPS近似一致；空间/时间连续且可复现，阵风0为均匀场。关闭/暂停/重置/换模型/VMD释放，无风回归，type0不受风，type2位置保持且力矩限幅。真实模型整体摆动、小物件稳定性和手机性能另行验收。

## 性能、风险与工时

每个动态刚体每子步有限标量运算，复用矢量缓存；风关闭不增加遍历；不新增GPU目标/依赖。代理面积有误差，等级系数须保持可用的模型量级；不可把任意骨骼轴当布面法线。正式共享适配器在并发迁移，需验证生成Ammo方法确为新版本。预计实现及定向验证30–45分钟，设备效果另计。仅独立测试页，不因本任务改Offline发布状态，不构建APK。

主L4：投影面积、相对速度、子步有效阻力（强证据各3）；次L5：开关/暂停/释放（中证据2）。置信度9/11×0.90=0.736；评分24+18+18+18+14=92/100，能力L4无需下放。风险为代理面积和强度校准、测试与正式共享源码边界；拆解为数值计算、Ammo注入、XPBD接入及定向验证。范围已确定，具体实现已获用户确认并验证通过；未自动调用其他技能。

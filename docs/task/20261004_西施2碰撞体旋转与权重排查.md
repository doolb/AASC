# 西施2碰撞体旋转与权重排查

用户反馈权重与碰撞体仍不对。检查xishi2-rig.py、xishi2-pmx.py、生成PMX和实际MMDPhysics欧拉读取方式。

已确认旋转导出约定错误：74个胶囊轴偏差>1°，最大89.17°。修正xishi2-pmx.py的矩阵转Three XYZ角度，重新生成模型、工程和web-dist。权重保持当前版，等待具体错误部位以做正确的分区归属调整。

本次只做静态资产方向检查、语法及构建，不新增或运行测试。风险：方向修正后碰撞接触会改变，尺寸/位置与蒙皮分区仍需设备确认；不把轴对齐解释为碰撞体完整拟合。预计旋转修复一个短阶段，权重修正待错误部位明确。

# 任务：服务器 TUI 默认关闭

## 状态

- ✅ 已完成 [2026-08-29]

## 任务描述

当前服务器只要未传 `--no-tui` 就会启用 TUI，执行 `npm start` 时默认占用控制台界面。调整为默认关闭 TUI，只有显式传入 `--tui` 才启用，同时保留 `--no-tui` 兼容参数。

## Design 需求

- `npm start` 默认以普通日志模式启动，不显示 TUI。
- `npm start -- --tui` 显式启用 TUI。
- `--no-tui` 继续强制关闭 TUI；当同时传入 `--tui --no-tui` 时以关闭为准。
- 双进程启动器继续原样传递命令行参数给 `server-app.js`。

## Spec 设计

```text
commandArguments = 启动器传给 server-app 的命令行参数
useTUI = commandArguments 包含 '--tui' 且不包含 '--no-tui'
server-app 初始化 ServerTUI(enabled = useTUI)
```

## 自测用例

1. `npm start` 不包含 `--tui`，默认关闭 TUI。
2. `npm start -- --tui` 启用 TUI。
3. `npm start -- --tui --no-tui` 仍关闭 TUI。
4. 启动器将参数继续传给服务器子进程。
5. 相关 Node 测试 12/12、语法检查和 `git diff --check` 通过。

## 风险评估

- 默认输出从 TUI 变为普通标准输出日志，已有依赖 TUI 的启动方式需要显式增加 `--tui`。
- 双进程 TTY 继承和服务器重启 IPC 不变，风险集中在启动参数解析。

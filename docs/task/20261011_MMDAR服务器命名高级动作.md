## 自测与兼容性

- 待机裙子避让：以用户指定物理刚体接触为运行时依据，真实手臂/手指蒙皮与裙子观感作为验收；循环小幅呼吸、停止舞蹈/挥手回待机，保留裙子物理/碰撞。
- 刚体检测：球/盒/胶囊在旋转、角色缩放/移动下的接触方向与物理一致；碰撞组/掩码与自身排除；读取实际物理姿态，不以绑定骨骼位置代替动态刚体。
- IK：接触减少、无接触时不改动作、肩肘腕关节限位、有限迭代/最大修正、连续动画与开关关闭平滑释放、不累计修正；不可达目标/无手部刚体/无可靠骨骼链明确降级。
- 开关：默认开启、即时生效、刷新保存、模型/后端重建保留、存储失败使用明确默认；物理暂停/恢复不重置裙子、不使用已销毁实例。
- 默认待机/刷新循环与跟随/呼吸/眨眼；跳舞不自动播放，手选/停止回待机；旧内置默认偏好迁移与其他手选保持，WEB与APK隔离。
- 真WASM编译挥手+米娅PMX骨骼：上举阶段腕高于肩、摆动与回落连续，其他部位不被修改；手机视觉待验收。
- 空目录/非法schema/id重名/name重名/无效URL/文件缺失/有限参数验证；目录动态增加第二动作可显示/调用。
- 跳舞按原15.2秒播放、次数与强度、显式时长覆盖；[动作:跳舞]不被默认2秒压缩，动作真正结束前队列/停止状态正确。
- 模型本地同名登记版本优先，内置MPL五动作仍可播放；服务器不可用不阻止模型与本地动作。
- 同源mmd路径/边界校验保持；停止/快速换模型/后台/新动作取消旧请求，迟到加载不写新模型。
- 沿用物理/口型/基础VMD、600ms头部进入与恢复，现有23项定向回归；服务器VMD按需加载并受既有16MiB上限，缓存有界，手机首次下载/播放帧时待设备验收。
- `npm run build:web:mmd-ar-test`后验证JSON目录、资源文件、开关接线与导入指纹。增加IK后预计5–7小时，不含外网发布和设备验收；记录开关前后候选数量/求解耗时，手机帧时待实测，不承诺未测定毫秒值。

## 待机裙子避让补充

用户要求待机避免裙子穿模。米娅PMX只读检查：左右腕x=±4.91/y=12.32，裙子材质横向范围约±3.80，模型原绑定臂姿已有外展间距。因此待机优先基于当前模型安全自然站姿，避免任意加65°旋转把手贴到身体；采用略外展手臂、裙摆外侧手掌、很小的躯干动态，不增加大幅腿部动作。构建姿态需结合实际蒙皮/裙面与物理验证，检查循环和回待机；必要时按模型微调臂肘角/幅度，不能关闭裙子物理或删除网格作为修复。包围盒仅是选择姿态依据，当前未验证网格穿模或实施修复。

## IK与物理刚体开关补充

按“加入IK检查避免手部与衣服穿模”理解前一条输入；用户随后明确“使用和物理同样的刚体检查，同时在物理里加个开关是否启用”。运行时仅检测既有PMX刚体，不引入衣服三角网格BVH检测/整片GPU布料读回。现有物理使用球/盒/胶囊与双方组掩码，Human回调当前在原模型IK/grant之前；拟新增后置避让回调，确保原IK/grant不会覆盖自有修正，之后继续原物理。手部相关刚体接触 → 有界外推目标 → 肩臂/肘/腕IK → 检查剩余接触，修正按当前动作姿态重新计算。

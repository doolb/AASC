# 显示端聊天超时即时隐藏棋盘

## 任务描述

修复显示端本地语音聊天倒计时到期后，语音状态已进入等待唤醒而五子棋棋盘仍暂时显示的问题。

## 设计需求

真实棋盘只在 `activeGroup` 或 `activePrivate` 对话中显示；本地倒计时到期应立即隐藏棋盘和游戏菜单。棋局数据及手动可见性保留，服务端权威状态抵达后仍可重新覆盖本地状态。

## Spec 设计

见 `docs/spec/game-gomoku.md`。显示端本地倒计时触发 `waitingWake` 时，通过 `DisplayStage.handleServerMessage` 发布已有 `voiceConversationState` 消息，由游戏模块现有状态门控刷新可见性；服务端后续状态沿原路径处理。

## 受影响模块与代码

- `src/apps/web-mediacenter/ui/public/display.html`：本地倒计时回调发布舞台状态。
- `tests/display-game-browser.test.js`：以浏览器执行真实倒计时函数，验证隐藏与服务端恢复。
- `docs/design/game-gomoku.md`、`docs/spec/game-gomoku.md`、`docs/usage/game-gomoku.md`：同步行为与伪代码。

## 自测用例

1. 加载进行中的棋局并进入活动对话，确认棋盘显示。
2. 本地倒计时到期，确认 `waitingWake` 通过舞台广播、棋盘和菜单立即隐藏。
3. 服务端随后恢复 `activeGroup`，确认原棋盘重新显示。
4. 保留服务端直接发出 `waitingWake` 的既有回归。

## 兼容性测试

保留既有 WebSocket 消息格式、棋局快照和演示棋盘独立展示；本地状态消息仅在显示页内发布，不向服务端写配置。验证游戏聊天回归不受影响。

## 性能测试

超时仅额外分发一条本地状态事件，复用现有棋盘刷新，无轮询或新增网络请求；浏览器回归检查回调完成后的隐藏状态。

## 风险评估

若本地与服务端计时略有偏差，棋盘以先到的本地 `waitingWake` 立即隐藏；后续服务端权威消息可恢复活动状态。真实设备的时序仍需服务包更新后验收。

约 1 小时，包含代码、浏览器回归与文档同步。

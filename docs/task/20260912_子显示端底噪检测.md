# 子显示端底噪检测兼容

## 任务描述

修复 `voice-display-node` 收到 `voiceVadNoiseTest` 时打印未知消息的问题，使 Node 子显示端能够响应控制端的底噪检测请求。

## Design 需求

- 复用当前已启动的 PvRecorder 或 naudiodon 录音输入，不重复打开麦克风。
- 在录音帧 RMS 计算链路中收集指定检测窗口的样本。
- 返回均值、峰值、P95、建议 VAD 阈值和请求 ID。
- 录音器未启动、暂停、重复检测或采集失败时返回错误结果。

## Spec 设计

- Node 消息分发增加 `voiceVadNoiseTest`。
- 两种录音器提供统一 `startNoiseTest(durationMs)` 接口。
- 结果沿用 `voiceVadNoiseResult`，由服务端转发到控制端。

## 自测用例

1. Node 子显示端识别 `voiceVadNoiseTest` 消息并调用录音器。
2. PvRecorder 与 naudiodon 都包含底噪采集入口和统计字段。
3. 结果保留 requestId，并回传 `voiceVadNoiseResult`。
4. 录音器未启动或重复检测时返回错误。

## 兼容性测试

- 网页显示端原有底噪检测协议不变。
- Node 子显示端的正常 ASR/VAD 分段不改变。
- PvRecorder 和 naudiodon 两条录音实现保持相同结果字段。

## 性能测试

- 检测期间只保留 RMS 数值，不缓存完整 PCM 音频。
- 检测结束后释放样本数组和定时器。

## 风险评估

- 录音器暂停期间无法获得有效样本，应返回明确错误或空统计结果。
- 底噪检测与正常 VAD 同时运行，需要避免重复创建音频输入。

# 地区媒体中心、弹幕与下载统一

## 任务描述

在现有媒体库基础上完成以下能力：

1. 媒体源按地区统一管理：一个“国内媒体”任务提供红果短剧、番茄小说等多个来源；一个“国外媒体”任务提供 YouTube、Pinterest、Pixiv。B 站保持原生实现，前端归入国内分组。小红书暂不实现，保留扩展位。
2. 统一媒体源协议：首页、搜索、粘贴链接、相关推荐、下载；每个来源默认进入首页。
3. 服务设置增加 `globalWebProxy`，每个媒体源有独立代理开关。
4. B 站：弹幕开关、显示端弹幕、搜索 502 修复、热门首页、相关推荐、已下载状态。
5. 夸克分享：分享卡片与文件/文件夹条目支持与 B 站一致的下载入口，已下载显示“已下载”。
6. 红果短剧：页签去掉“（网页公开视频）”，支持首页、搜索、粘贴链接、可选 Cookie。
7. 番茄小说：通过 `/mnt/novel/TomatoNovelDownloader-Linux_amd64-v2.4.13 --server` 提供搜索、下载、书库与章节文本阅读。
8. 国外来源：YouTube（yt-dlp）、Pinterest、Pixiv，支持分来源代理。

## 需求设计

详见 `docs/design/media-library.md` 的“地区媒体中心与统一媒体源协议”章节。

关键约束：

- B 站不迁移为任务，避免重构现有播放/下载链路。
- 番茄小说不反推网页搜索/正文接口，统一调用下载器 server 模式。
- 小红书跳过；YouTube 允许首次自动下载 yt-dlp 到数据目录。
- 代理只作用于服务端外部请求；每个来源独立开关，国内来源默认关闭。
- 相关推荐只在控制端展示，显示端保持全屏播放。

## 自测用例

1. B 站搜索连续 10 次，正常返回；模拟 412 后回退 WBI 或退避，不返回 HTML 错误页。
2. 播放 B 站视频，弹幕开关开启时显示滚动/顶部/底部弹幕；暂停、恢复、seek 同步；关闭后不显示；iframe 回退无叠加。
3. B 站首页热门、相关推荐加载与点击播放；搜索/收藏/列表卡片显示“已下载”。
4. 夸克分享卡片、文件、文件夹下载到本地媒体库；完成后显示“已下载”；重复下载跳过完整文件。
5. 红果搜索关键词、粘贴 player/detail/ID 链接、配置 Cookie 后请求携带 Cookie。
6. 番茄任务自动拉起下载器，搜索、下载、浏览书库、章节文本在显示端阅读/TTS；停止任务结束托管的下载器进程。
7. 国外任务三种来源的首页、搜索、链接解析；逐来源切换“使用代理”，关闭后请求不走代理。
8. yt-dlp 首次自动下载、YouTube 播放与下载、直链失败回退 iframe。
9. 地区分组显示：国内媒体、国外媒体；任务停止后页签移除，当前页签回退正常。
10. 原有本地媒体库、夸克播放/下载、B 站 DASH/MP4 回退、批量播放回归。

## 兼容性测试

- 不配置 `globalWebProxy` 时所有来源按原方式访问。
- 旧版任务媒体库配置保留；`hongguo` 退役后已保存配置可迁移到 `domestic-media` 或提示重新添加。
- 未开启弹幕的 B 站播放与现有行为一致。
- 代理依赖未安装或版本不匹配时给出明确错误，不影响服务启动。
- Android 端/不同分辨率显示端弹幕层不阻挡触控与视频黑边裁剪。

## 性能测试

- 弹幕 XML 解压后限制大小，热门视频 1 MB 量级；按 cid 缓存，重复播放不重复拉取。
- 搜索缓存 60 秒，412 退避避免放大风控。
- 番茄下载器进程复用，任务停止时回收；章节文本按需流式返回。
- YouTube yt-dlp 下载到临时文件后原子发布，Range 由媒体代理；避免并发重复下载。
- 夸克下载复用现有串行队列和 300 MiB 播放缓存限制。

## 风险评估

- 小红书需要登录 Cookie 与签名，暂缓实现。
- YouTube 直链受 PO Token、风控和 yt-dlp 版本影响，可能回退 iframe；需要定期更新 yt-dlp。
- Pinterest 匿名搜索/首页受登录墙影响，可能需要 Cookie；匿名时降级并提示。
- Pixiv 受限内容需要 Cookie；CDN 必须带 Referer，否则 403。
- 下载器二进制路径/端口/数据目录可能变化，任务参数允许覆盖。
- 全局代理配置错误会影响所有开启代理的来源；通过来源开关和隔离错误降低影响。

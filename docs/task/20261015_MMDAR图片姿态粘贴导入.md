# 全身IK图片姿态粘贴导入

状态：用户已确认方案，已实现并完成本地回归。

## 任务与设计

用户提出“图片可不可以支持粘贴”。依据前文，范围为全身IK图片姿态；拟增加Ctrl+V和「粘贴图片」按钮，复用现有本机图片校验/解码/缩放/预览，不自动识别或应用。对应`docs/design/mmd-human-interface.md`与`docs/spec/mmd-human-interface.md`顶部候选段。

快捷键只在IK可见、图片区展开、非可编辑目标且粘贴含支持图片时接收；纯文本维持原行为。按钮明确点击后调用Clipboard.read；失败保留旧图/目标并提示其他入口。文件/粘贴共用导入，晚到读取与Bitmap解码受代次及可见性守卫，销毁释放监听。

## 自测、兼容性与性能

- 截图/复制图片粘贴后显示原图，旧候选清除，仍需显式识别和应用；原文件入口继续可用。
- 文字/输入框/折叠或关闭面板不误拦截；剪贴板无图片、权限拒绝或API缺失时保留已有图与目标。
- 延迟读取后换图/收起/销毁不得覆盖新状态；Bitmap和监听释放。
- 真实ONNX图片识别/候选切换/取消/无人保护回归；浏览器按钮测试与系统真实剪贴板验证分别记录，模拟ClipboardEvent不宣称验证OS剪贴板。
- 复用现有像素/文件上限，不增加模型推理次数；桌面浏览器验证，Android/iOS具体权限行为待设备验收。

# 壁纸系统浮窗与显示层级

- 任务：新增桌面系统浮窗，普通页保留网页面板和壁纸入口，监听开关缩为圆点，媒体库覆盖 MMD。
- 设计及伪代码：见 `docs/design/display-wallpaper-controls.md`、`docs/spec/display-wallpaper-controls.md`、语音和媒体库对应文档。
- 模块：Android 壁纸服务、权限与原生桥、显示页控件、语音按钮、媒体库样式和自测。
- 自测：验证模式切换、授权与清理路径、偏好同步、监听状态与媒体库叠层。
- 兼容性：悬浮窗需 Android 用户授权；不同桌面及系统版本必须设备验收。
- 性能：仅浮窗可见时更新状态；隐藏立即释放窗口和定时任务。
- 风险：系统可拒绝悬浮窗或不转发桌面触摸；系统特殊窗口不受应用控制。
- 预计工时：约 4 小时。

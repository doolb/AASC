## 自测、兼容性和性能验收

1. 分类红0/黄2/绿1、灰色无关联、非法索引、同骨骼多类型、加载后的type2转type1结果。
2. 动作和物理更新后的世界坐标，以及父级平移/旋转/缩放；无额外骨骼或Ammo状态写入。
3. 默认关闭、偏好恢复、未加载模型先开关、换模型继承；局部存储不可用时仍可操作。
4. 独立叠加不进入包围盒/AO/阴影；绘制异常后renderer状态恢复；角色首帧隐藏时无小球提前出现。
5. 真实网页切换动作/PMX、暂停/恢复、刷新，无页面异常；重复换模型释放旧球资源。
6. 球几何共享、按颜色实例化，关闭时无逐骨骼更新；记录真实网页开启后的实例/几何数量和帧耗时，手机观感另现场验收。
7. 优先 `npm run build:web:mmd-ar-test`；无独立测试script时使用node --test定向运行，并核对生成模块语法/内容指纹。仅独立网页受影响，不触发Offline产物构建。

## 风险、未明确项与预计工时

- PMX加载器会将部分type2转换为type1：读取最终刚体参数，测试防止原始骨骼元数据误判。
- 多刚体关联和灰色骨骼显示是拟定边界；已纳入方案而非隐含需求，实施后仍可按用户观感调整。
- 透视叠加可能出现密集骨骼重叠：默认关闭，按高度控制球大小，先保证诊断位置可见。
- 模型切换曾有OOM：小球不分配Ammo对象，释放Three资源并验证数量不持续增加。
- 真机帧率影响不能用桌面测试保证；预计实现与定向自动验证1至2小时，另需手机现场验收。

# 2026-09-22 显示端聊天下拉菜单选中态修复

## 任务描述

修复显示端聊天对象和会话两个 HTML 下拉菜单中，选中项和未选中项底色接近、难以区分的问题。

## Design 需求

- 两个菜单继续复用现有 `display-chat-dropdown-option` 状态类。
- 未选中项直接复用主题小卡片的 `--card-background`，不再透出菜单容器底色，也不随群聊/助手类型染色。
- 选中项使用主题强调底色、主文字、加粗和左侧标记。
- 悬停/聚焦与选中悬停/聚焦使用不同底色，普通交互样式不得覆盖选中态。
- 不改变对象、会话选择逻辑和 WebSocket 协议。

## Spec 设计

- `aria-selected="true"`、`data-selected="true"` 和 `.is-selected` 共同表达选中状态。
- `.display-chat-dropdown-option` 提供 `--card-background` 非透明基础底色。
- 选中态使用 `--dropdown-option-selected-background`，选中悬停态使用 `--dropdown-option-selected-hover-background`。
- `data-target-kind="group"` 与 `data-target-kind="assistant"` 仅可覆盖选中色；会话菜单使用通用状态色。

1. 未选中项与选中项底色明显不同。
2. 悬停/聚焦项与选中悬停/聚焦项底色不相同。
3. 对象和会话两个下拉菜单共用状态样式。
4. 现有对象切换、会话切换和聊天 WebSocket 流程不变。

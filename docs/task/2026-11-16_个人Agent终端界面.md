# 个人 Agent 终端界面

需求：为现有独立 Agent 提供手写终端界面，保留角色权限边界，不引入完整 Agent 框架。

设计和实现：见 `docs/design/aasc-agent.md` 和 `docs/spec/aasc-agent.md`；增加可选事件观察器、可注入的 readline 界面、显式演示入口和宿主模块加载。

范围：`subproject/aasc-agent/src`、测试、使用说明及本任务对应文档。真实模型、HIE 和持久会话仍由宿主提供。

自测与兼容：执行 npm test，覆盖多轮输入、错误恢复、结束输入、退出、事件顺序、权限拒绝与既有调用方式。性能：单进程顺序处理，逐行输出，无忙等；高频流式显示不在本次范围。风险：中断界面不等于取消已经执行的外部任务，演示模式不连接外部服务。预计工时：半天。

完成情况：新增 `tui.js`、`tui-cli.js` 和 `npm run tui`，Agent 增加可选状态事件，演示模式仅回显，宿主可通过本地模块注入 Agent。验证：npm test 共 10 项通过，伪终端演示启动、指令执行和退出通过；真实模型与 HIE 未接入。该独立子工程未接入 Offline APK、服务包或任务包，发布状态无需更改。

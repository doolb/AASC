# MMD-AR主相机联动改为CSM式视锥切片

日期：2026-10-08。状态：代码、回归测试与Web构建完成；GPU画面验收待可用浏览器/设备。用户选择CSM视锥切片，联动模式不再乘额外0.5。

## 任务描述

用户指出现有“联动主相机计算”仍按角色/接收面和地面影子范围求投影中心，导致角色固定在阴影贴图中心。需要改为CSM式相机前向区域：使用主相机near至固定shadowDistance的视锥切片定义阴影范围，中心跟随相机前方而非角色。

## Design 需求

- `shadowDistance = min(camera.far, targetModelHeight × 4)`；目标角色高度1.75时默认约7世界单位。
- 使用主相机near/far切片角点构造8个世界点，中心取角点平均，稳定范围半径取最大角点距中心距离；将切片中心变换至各方向光阴影相机空间。
- 用切片半径及ShadowMap宽高比确定光相机正交范围，`targetOccupancy=0.78`留边；既有`cameraScale`继续乘范围，默认1。
- CSM联动模式取消旧角色中心拟合时确认的额外0.5；关闭联动时旧角色包围盒拟合及0.5行为不变。
- 角色/接收面范围只用于光空间near/far深度裁剪，不决定XY中心/尺寸；不移动方向光及target，保持光线方向。
- 保留shadow map像素对齐、签名缓存和单帧更新；仅独立MMD-AR测试页。

## 自测用例

1. 默认shadowDistance为`min(camera.far, targetModelHeight*4)`；射线沿主相机near至切片远端求交，获得有限8角、切片中心和稳定半径。
2. 联动开启时，角色root仅平移而主相机不变：两个方向光的阴影相机XY中心、宽高不因角色移位而重新居中；near/far仍包含角色和接收面。
3. 主相机移动/转向后，切片中心随相机前向区域改变；FOV/aspect/shadowDistance不变时切片半径和光空间拟合尺寸稳定。
4. 联动模式`cameraScale=1`无额外0.5；0.5/2倍率按比例改变宽高。联动关闭仍用legacy角色包围盒和原0.5基准，灯光方向不变。
5. 保留ShadowMap像素吸附，不产生小位移累计漂移；无效投影安全回退且无NaN/零宽高。
6. `node --test tests/mmd-ar-shadow-map-size.test.js tests/mmd-ar-web-characters-build.test.js`与`npm run build:web:mmd-ar-test`通过。

## 验证结果

- `tests/mmd-ar-shadow-map-size.test.js` 15/15通过；与公网GLB回退测试组合22/22通过。
- 回归覆盖near到7单位切片、角色和方向光一起平移仍锚定主相机、caster离开相机切片不重居中、主相机移动时中心跟随/尺寸稳定，以及0.5/1/2的cameraScale。
- `npm run build:web:mmd-ar-test`成功，构建产物包含CSM式切片实现；当前Windows环境无配置`/usr/bin/chromium`，未进行GPU阴影画面的实际角色覆盖/分辨率验收。

## 兼容、性能与风险

- 联动开关仍默认关闭，已有关闭模式不改；联动开启由角色中心收紧范围改为相机前向切片，适用范围和阴影细节分布会变化。
- 切片半径基于主相机视锥，旋转时投影尺寸稳定，但可能比紧凑AABB更占用ShadowMap分辨率；可用cameraScale调大小。
- 不在联动模式复用额外0.5，避免完整视锥切片被收窄裁边；legacy关闭模式继续保留0.5。
- 仅改独立测试网页，不改正式显示端、APK或Offline状态；GPU画面/设备需要手动验收。

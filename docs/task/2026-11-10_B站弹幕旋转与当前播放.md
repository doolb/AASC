# B 站弹幕旋转与相关推荐当前播放

- 任务：弹幕及开关适配显示端旋转；相关推荐首项展示当前 B 站视频。
- Design / Spec：`docs/design/media-library.md` 与 `docs/spec/media-library.md` 对应章节。
- 模块：显示端弹幕宿主、旋转布局、控制端媒体状态与相关推荐列表。
- 自测：四角度弹幕轨道/滚动范围/开关、暂停和 seek；当前项、去重、失败回退、切换和过期响应。
- 兼容性：非 B 站媒体与普通视频行为保持；分 P 保留播放地址。
- 性能：复用既有弹幕动画及请求，不新增持续轮询。
- 风险：显示端播放确认依赖控制端收到权威状态；无元数据时使用 BV 号。
- 预计工时：2–4 小时。

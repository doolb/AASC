# 日志大脑与 LLM 判断上下文任务

## 任务描述

- 目标：新增日志大脑能力，生成可供大模型判断问题的上下文。
- 范围：新增 Framework 日志大脑模块，新增日志大脑 API，补充设计与实现文档。

## design 需求

- 定义感知记忆、工作记忆、情景记忆、元认知四层日志抽象。
- 明确日志管理模块与 LogBuffer/SystemMonitor 的关系。
- 定义认知摘要与诊断上下文接口。

## spec 设计

- 输出摘要生成伪代码。
- 输出记忆体构建伪代码。
- 输出认知 API 伪代码。

## 自测用例

1. `node --check src/framework/observability/log-brain.js` 通过。
2. `node --check server.js` 通过。
3. `GET /api/logs/brain-summary` 返回摘要结构。
4. `POST /api/logs/brain-judge` 返回 `summary`、`memory`、`prompt`。
5. 旧接口 `cognitive-summary/cognitive-judge` 不再暴露。

## 兼容性测试

1. 原 `GET /api/logs`、`GET /api/system-stats` 行为不变。
2. 现有日志广播链路不受影响。

## 性能测试

1. 认知摘要默认 limit 控制在 200 条内，避免大对象阻塞主线程。

## 风险评估

- 风险：日志模式提取可能误归类。
- 缓解：保留原始时间线和模式计数，允许人工复核。

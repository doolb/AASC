# Offline 热更外网域名解析访问

## 任务描述

将 Offline APK 外网热更源从固定 IP 配置改为 `http://c.aasc.us/mnt/aasc-offline/`。
APK 需要解析域名得到 IP，并使用解析后的 IP 替换更新 URL 主机访问；不保留或覆盖原域名 Host，
更新路径、内网优先和外网 fallback 规则保持不变。

本轮发布补充要求：完整 Offline APK 跟随当前 min 最新版本；当前 min 为 versionCode `9`，full
使用 versionCode `9`、版本名 `0.2.7-offline`，发布文件名为 `apk/aasc-display-offline-v9.apk`。
同版本已有不同 SHA 时禁止覆盖，必须按新版本重新构建后发布。

## design 需求

- LAN 源继续使用 `http://192.168.1.39/mnt/aasc-offline/`。
- WAN 配置使用 `http://c.aasc.us/mnt/aasc-offline/`，当前解析目标为 `120.79.245.103`。
- 域名解析返回多个地址时按返回顺序逐个尝试。
- 实际请求 URL 的 host 使用解析出的 IP，不设置 `Host: c.aasc.us`。
- 域名解析失败或所有 IP 连接失败时，沿用现有 LAN/WAN 更新失败处理，不应用未经校验的资源。

## spec 设计

```text
fetchUpdateSource(configuredBaseUrl):
    sourceUrl = parse configuredBaseUrl
    if sourceUrl.host is a literal IP:
        candidateUrls = [sourceUrl]
    else:
        addresses = DNS.lookup(sourceUrl.host)
        candidateUrls = addresses.map(address -> replaceHost(sourceUrl, address))
    for candidateUrl in candidateUrls:
        request manifest or component relative path from candidateUrl
        do not set Host header
        if request succeeds:
            return candidateUrl
    return sourceUnavailable

checkAndApplyServiceUpdate:
    try LAN source first
    then try WAN domain source
    if no source succeeds:
        keep installed release

alignFullApkVersion:
    fullVersionCode = read allserver-min.versionCode
    update allserver.versionCode to fullVersionCode
    require published full APK with this version is absent or has the same SHA-256
```

## 自测用例

1. 域名 `localhost` 解析后请求候选 URL 的 host 不再是 `localhost`，路径和端口保持不变。
2. IP 源不执行不必要的域名替换，原 URL 保持可用。
3. WAN 常量使用 `http://c.aasc.us/mnt/aasc-offline/`。
4. 更新请求不调用 `setRequestProperty("Host", ...)`。
5. LAN 失败后仍能进入 WAN 源；多 IP 连接失败后继续尝试下一个地址。

## 兼容性测试

- Android API 26+ 的 `HttpURLConnection` 保持现有连接超时、读取超时、签名和 SHA-256 校验。
- LAN 固定 IP 更新源行为不变。
- 已发布清单中的组件相对路径仍可由解析后的基地址拼接。

## 性能测试

- 每次更新检查最多执行一次域名解析，并复用解析结果访问 manifest 和组件。
- 不增加更新包大小，不引入新的常驻线程或定时器。

## 风险评估

- DNS 变化后会使用新的 IP，若 DNS 返回不可达地址则按顺序尝试并最终回退到当前已安装版本。
- 不保留 Host 时，依赖域名虚拟主机的服务器可能不响应；当前 HTTP 发布目录按 IP 访问，因此按用户要求使用 IP Host。
- 仍使用 HTTP，来源可信性继续由 APK 内置 RSA 公钥和组件 hash 保证。

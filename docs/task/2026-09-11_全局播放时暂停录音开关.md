# 全局播放时暂停录音开关任务

## 任务描述

在控制端声纹管理面板增加全局“播放时暂停录音”开关，默认开启；关闭时所有显示端播放 TTS 期间继续普通 ASR 录音。

## Design 需求

- 配置保存为 `voiceprint.pauseRecordingDuringPlayback`，默认 `true`。
- 服务端通过已有 `voiceprintConfig` 消息广播给所有在线显示端。
- 单次录音、实时录音和控制端聊天录音保持现有行为。

## Spec 设计

- GET/POST `/api/voiceprint/config` 读取、校验和保存布尔配置。
- 控制端声纹面板 checkbox 修改全局配置。
- 显示端 `pauseVoiceRecordingForTts` 仅在配置为 `true` 时暂停普通 ASR。

## 自测用例

1. 缺少配置时面板默认勾选，显示端默认暂停。
2. 保存 `false` 后所有在线显示端收到 `false`，播放期间不暂停录音。
3. 保存 `true` 后播放期间暂停，播放完成后恢复。
4. 非布尔值被服务端拒绝。
5. 单次录音和实时录音不进入 TTS 暂停逻辑。

## 兼容性测试

- Web 显示端普通 ASR。
- APK WebView 显示端声纹开启/关闭。
- 已有旧配置文件缺少新字段时回退 `true`。

## 性能测试

- 配置变更仅发送一条小型 WebSocket 配置消息。
- 播放开始/结束不新增音频处理线程和音频缓存。

## 风险评估

- 低风险：沿用现有全局声纹配置广播链路和 PCM 暂停/恢复逻辑。
- 主要风险是旧显示端不识别新字段；旧端会继续使用默认暂停行为。

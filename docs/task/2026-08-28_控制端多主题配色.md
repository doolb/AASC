# 任务：控制端多主题配色扩展

## 任务描述

在控制端已有深色、浅色和特色浅色主题的基础上，增加薄荷青、海洋蓝、森林绿、极简灰和藻盐五套常用配色，使主题总数达到 12 种。

## Design 需求

- 主题选择继续由控制端本地 `localStorage` 保存，不影响显示端和服务端业务通信。
- 新主题使用独立 CSS 变量定义背景、卡片、内容区域、文字、边框、输入框、强调色和阴影；藻盐主题采用盐白与藻绿组合。
- 新主题复用既有浅色主题的控件分类、卡片、弹窗、设备名、聊天消息和日志对比度规则。
- 按钮渐变使用当前主题强调色，保持交互控件的可读性。

## Spec 设计

- `UiTheme.themes` 扩展为 `dark`、`light`、`warm`、`pink`、`lavender-yellow`、`red-blue`、`gold`、`mint`、`ocean`、`forest`、`slate`、`algae-salt`。
- `UiTheme.apply` 为深色主题设置 `data-theme-mode=dark`，其余主题设置 `data-theme-mode=light`。
- `theme.css` 为五套新主题提供颜色变量，并通过 `data-theme-mode=light` 复用浅色组件样式。
- `upload.html` 的主题选择框增加五个对应选项。

## 自测用例

1. 主题管理器返回完整的 12 种主题清单。
2. 主题选择框包含四个新增主题，CSS 包含对应变量块。
3. 新主题应用后根元素的 `data-theme` 和 `data-theme-mode` 正确。
4. 卡片、弹窗、设备名、聊天消息和日志区域继续使用主题变量并保持文字对比度。
5. `node --test tests/ui-theme.test.js` 通过。

## 兼容性测试

- Chrome、Firefox、Safari、Edge 桌面端主题选择和刷新恢复。
- 窄屏控制端、动态弹窗、任务面板、媒体库、聊天和日志区域。
- 深色主题保持原有变量和交互表现。

## 性能测试

- 主题切换只更新根元素数据属性和选择框，不刷新业务数据。
- 不新增轮询和网络请求，不改变 MutationObserver 的动态控件处理范围。

## 风险评估

- 新主题统一复用浅色覆盖规则，主要风险是个别第三方或内联颜色未使用主题变量；通过主题回归和浏览器检查确认关键区域可读。
- 颜色变量只作用于控制端 CSS，不改变 WebSocket、服务器配置和业务事件。

## 预计工时

约 1 小时，包含主题变量、选择项、测试和文档同步。

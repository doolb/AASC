# UE 风格 SSGI 历史输入与间接光分类

日期：2026-10-08。状态：实现完成；SwiftShader/自动化和构建通过，目标设备画面与性能待验收。

## 任务描述

用户要求参考 `D:\down\UE5 SSGI源码解析 - 知乎.mhtml` 改造独立 MMD-AR 测试页的 SSGI，并选择实现完整 UE 风格流程。文章说明的核心处理为：前帧 SceneColor Reduction/HZB、重投影后进行屏幕空间射线查询、SS Denoiser 双边滤波；不是简单高斯模糊，也不是对上一帧 SSGI 结果不加校验地平均累积。UI 新增“间接光”分类，SSGI 作为其子类；接触阴影保持独立分类。

## Design 需求

- 将控制面板组织为独立“接触阴影”与“间接光”分类；“间接光”下提供 SSGI 子类和 SSGI 控件。去掉可见的“实验”标签，不改变功能仅存在于独立测试页/测试 APK 副本的边界。
- 在每帧场景基础颜色/深度完成后、SSGI 合成前，生成当前帧历史候选；颜色和深度历史双缓冲，读写目标不得相同，SceneColor 历史不得包含已合成的 SSGI。
- 用效果分辨率构建前帧 SceneColor Reduction 层级与 HZB 深度层级；SSGI 将当前表面/命中点投影到上一帧坐标，历史深度验证通过才使用历史颜色，越界/深度冲突/首帧时拒绝历史并回退当前场景颜色。
- 采用 HZB 从粗层级到细层级查找潜在屏幕空间交点，并保留当前已有命中厚度验证、区间细化和亮度限幅。
- 对 SSGI RGB 使用深度引导的双边空间降噪；保留几何边界，接触阴影 alpha 使用中心值。不要实现对上一帧 SSGI 输出的无条件时域累积。
- 相机切断、尺寸/质量切换、资源重建和失效历史需清除历史有效标记；关闭/隐藏/销毁需释放历史与层级纹理。
- 保留现有实验开关默认关闭、`aasc.mmdArTest.screenLighting.v1` 存储键、质量/强度/半径值以及既有 AO 独立运行行为。

## 自测用例

1. 自动测试验证首帧无历史回退、第二帧历史有效；历史采集输入是未合成GI的 `ao.colorTarget`，输出纹理不与任一输入别名。
2. 自动测试验证质量变化与大幅相机平移令历史失效；代码还对尺寸/投影变化、上下文丢失/恢复废弃历史，目标尺寸变化重建纹理。
3. Shader将历史命中投回当前深度并校验遮挡；真实WebGL2编译/链接通过。角色运动/薄边的拒绝率与视觉效果仍需用户模型同视角验收。
4. 单测覆盖奇数尺寸Reduction/HZB尺寸到1x1；普通Z HZB保存near=min/far=max并以near=1/far=0表示空层，双16位打包；Shader完成真实WebGL2编译。运行时逐级命中/漏光仍需画面验收。
5. 单测确认双边空间滤波仅输出RGB、中心alpha原样保留；真实GLSL可编译链接，边缘保留程度需实机观察。
6. 自动测试验证“接触阴影”与“间接光 -> SSGI”控件父子结构、默认值、本地键、重置和持久化。
7. `node --test tests/mmd-ar-screen-lighting.test.js tests/mmd-ar-contact-shadow-browser.test.js`：12/12通过，含SwiftShader WebGL2真实Shader编译/链接；`npm run build:web:mmd-ar-test`成功。
8. 仍待用户模型相机运动、角色动作、薄发丝/透明衣物、切模型/尺寸及开关组合的画面对照和移动GPU帧时；自动Shader测试不代替上述验收。

## 兼容性测试

- 旧存储对象缺少新增历史字段时使用安全默认值，既有 GI 强度、半径、质量、模糊参数保持。
- WebGL2 是现有屏幕光照前提；HalfFloat 不可用时回退现有颜色附件类型。降低分辨率/画布尺寸时重建 history/HZB。
- AO 仍可单独使用；仅接触阴影时不启动 SSGI 历史颜色采样及 GI 降噪。

## 性能测试

- 默认1080p画布时，历史更新的全屏pass数量静态为：低档15（3深度Reduction+9个HZB级+3颜色Reduction）、中档13（2+9+2）、高档14（2+10+2）；另有当帧SSGI与默认两轮双边滤波。此为draw pass计数，不是GPU帧时数据。
- 比较历史有效/首帧回退和GI关闭的纹理数、分配量与渲染开销；高DPI/长宽比画布核对目标尺寸上限。目标手机帧时尚未测量。
- HZB与低分辨率颜色历史增加的全屏pass和历史纹理可能造成较大移动GPU成本，不凭SwiftShader耗时推断硬件性能。

## 风险评估

- 当前 runtime 没有通用 motion vector；模型动画区域只能靠历史深度校验拒绝不匹配样本，可能导致动态区域历史复用较少。
- 历史相机矩阵/UV 约定、深度非线性转换或 reduction 顺序错误会产生拖影/漏光；首帧回退及历史验证必须保守。
- HZB 作为粗筛时不能让远处/空背景的最大深度造成错误命中，粗层命中必须下钻并用细层原始深度验证。
- 额外历史目标增加显存/GPU成本；所有 resize、hide、disable、dispose 路径必须确定释放。
- MHTML 文章描述是技术参考，不是 UE 官方源码保证；实现需以本项目 Three.js/WebGL2 能力及独立测试数据为准。

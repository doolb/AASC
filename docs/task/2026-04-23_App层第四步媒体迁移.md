# App 层第四步媒体迁移任务

## 任务描述

- 目标：将媒体库实现从 `core/media-library.js` 迁入 App 模块目录。
- 范围：迁移实现体、更新 `server.js` 引用、保留 `core/media-library.js` 兼容导出。

## design 需求

- 媒体库业务实现归属 App 模块。
- server 入口直接依赖 App media 模块。
- core 仅保留兼容导出。

## spec 设计

- 增加 App 第四阶段媒体迁移伪代码。
- 明确 server 与 core 的导出关系。

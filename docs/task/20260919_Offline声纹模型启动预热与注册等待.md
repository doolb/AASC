# Offline 声纹模型启动预热与注册等待

## 任务描述

修复 Offline APK 启动后声纹模型仍在异步加载时，声纹注册请求直接返回“模型未就绪”的问题；同时明确声纹模型在注册、单人识别和多人识别中的共享生命周期。

## Design 需求

- 显示端初始化时，按服务端配置与原生 ASR 一起触发声纹模型预热。
- 区分模型文件、声纹引擎、声纹库和 ASR 的 ready 状态。
- 声纹注册请求在引擎加载期间等待，不要求用户重新录音。
- 模型加载失败、配置关闭、连接断开或超过 60 秒时返回明确错误。
- Offline 使用已解包模型；在线 APK 保持现有按需下载行为。

## Spec 设计

1. `voiceprintConfig.enabled=true` 到达后调用原生 `voiceprintConfigure`，触发声纹模型和引擎加载。
2. `onVoiceprintModel(ready, engineReady=true)` 释放声纹提取等待队列；error 拒绝队列。
3. `onVoiceprintDb` 只更新声纹库状态，不能单独把声纹识别状态设置为 ready。
4. `voiceprintExtract` 通过 JS 等待器等待引擎 ready，最长 60 秒后回传失败。
5. 服务端 display 注册等待时长与显示端等待时长统一为 60 秒。

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/ui/public/display.html`：ASR/声纹启动预热、声纹 ready 状态和注册等待队列。
- `src/apps/server/boot/server-app.js`：display 声纹注册等待超时。
- `docs/design/voiceprint.md`：启动预热和共享生命周期设计。
- `docs/spec/voiceprint.md`：伪代码与桥接契约。
- `tests/`：声纹 ready 状态、等待队列和服务端超时回归测试。

## 自测用例

- Offline 声纹配置到达后，ASR 和声纹预热均被触发。
- 声纹引擎加载中收到 `voiceprintExtract`，请求保持等待，ready 后成功提取。
- 声纹模型 error 时，等待中的请求返回模型错误。
- 未收到声纹配置、声纹库未同步时，不误报声纹识别 ready。
- 等待超过 60 秒时，显示端和服务端都返回超时错误。
- 声纹引擎 ready 后，单人匹配、多段识别和注册仍复用同一引擎。

## 兼容性测试

- 完整 Offline APK：使用 `aasc-server/res/models/voiceprint` 内置模型。
- Offline min APK：不内置模型，完整 APK 未安装时保留明确不可用提示。
- 在线 APK：模型仍通过既有 `/api/voiceprint/model` 下载。
- 无 `NativeDisplay` 的普通浏览器：不进入原生等待队列。

## 性能测试

- 记录 ASR 与声纹预热的首次加载耗时。
- 检查受控调度下的峰值内存，确认不因重复加载产生额外引擎实例。
- 验证模型 ready 后注册请求不发生额外模型加载。

## 风险评估

- 启动预热会增加 Offline 首次可用时间和内存占用。
- 低内存设备可能出现 ASR/声纹任一引擎加载失败，需要分别提示并保持另一能力可用。
- 等待队列不能无限增长，服务端请求超时后应由显示端回收对应请求。

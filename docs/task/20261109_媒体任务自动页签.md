# 媒体任务自动页签

- 需求：运行中的用户媒体任务直接显示顶部页签，移除返回与添加两个按钮。
- 设计与实现：见 `docs/spec/media-library.md`，任务注册与注销广播来源快照；缺少旧配置时使用临时只读来源，配置来自任务参数或默认配置，不写入媒体库配置文件。已有配置优先。
- 自测：浏览器验证多个页签、浏览根目录、来源停止后移除与回退；服务端验证任务注册、既有配置复用、临时库不持久化、停止与重启。
- 兼容性：夸克、B 站与普通媒体库保持原有入口；来源需要自带默认地址或任务参数，依赖 URL 的任务未设置地址时不能浏览。
- 性能与风险：只有点击任务页签才请求其目录；来源依赖的外部网站可用性由任务自身处理。
- 预计工时：半天。

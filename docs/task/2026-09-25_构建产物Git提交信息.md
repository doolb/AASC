# 构建产物记录 Git 提交信息

## 任务描述

为 APK 整包和 Offline 热更新包记录其来源 Git 提交 hash，便于根据产物追溯构建代码。工作区未提交时同时记录 dirty 标记，避免将 HEAD hash 误认为完整源码快照。

## Design 需求

- APK 构建输出的 `build-manifest.json` 增加 `source.gitCommit` 和 `source.gitDirty`。
- Offline 签名清单在 `components.code` 记录代码包来源；`all` 模式中为本次新建的依赖包记录来源。
- min APK 签名清单从 APK build manifest 复制来源字段到 `components.apkMin`。
- Git hash 使用完整提交 ID；没有 Git 仓库或有效提交时使用 `null`，dirty 状态也使用 `null`。
- source 元数据参与 Offline 清单签名；不改变客户端更新行为，旧清单继续兼容。

## Spec 设计

```text
readGitSourceMetadata(projectRoot):
    若 projectRoot 不是有效 Git 工作区或没有 HEAD 提交:
        返回 { gitCommit: null, gitDirty: null }
    gitCommit = git rev-parse --verify HEAD
    gitDirty = git status --porcelain 非空
    返回 { gitCommit, gitDirty }

buildApk:
    在构建开始时读取 source
    写入 build-manifest.source

createOfflineUpdateArtifacts:
    在打包开始时读取 source
    写入新 code 组件 source
    如果生成新 dependencies，写入 dependencies.source
    使用包含 source 的完整 payload 签名

createOfflineMinApkArtifact:
    从 buildManifest.source 读取来源
    如存在则复制到 apkMin.source 并重新签名
```

## 受影响文件

- `scripts/ops/git-source-metadata.js`：读取 Git commit 和 dirty 状态。
- `scripts/ops/build-apk.js`：在 APK build manifest 写入来源。
- `scripts/ops/offline-update-package.js`：将来源写进服务代码及新依赖组件的签名清单。
- `scripts/ops/offline-min-apk-package.js`：复制 min APK 来源到签名清单。
- `docs/design/release-build-profiles.md`、`docs/spec/release-build-profiles.md`、`docs/design/android-offline-hot-update.md`、`docs/spec/android-offline-hot-update.md`、`docs/self-test.md`、`docs/todo.md`、`changelog.md`：同步设计、伪代码和验收要求。

## 自测用例

1. Git 工作区干净时构建 manifest 使用完整 HEAD hash 和 `gitDirty=false`。
2. 工作区有修改时保留 HEAD hash 并写 `gitDirty=true`。
3. code-only 服务清单记录新 code 的来源，同时保留旧 dependencies 的来源。
4. all 服务清单对新 code 和新 dependencies 均记录本次来源，且 RSA 签名校验通过。
5. min APK 清单复制 build manifest 来源到 `components.apkMin.source`，签名校验通过。
6. 非 Git 测试夹具返回 null 来源；旧清单仍能被签名验证和 Android 解析。

## 兼容性、性能与风险

- Git 元数据仅用于追溯，不影响安装、热更新选择或服务切换。
- Android 先对原始完整 JSON payload 验签，再读取已知组件字段；未知 source 字段参与签名但不会改变更新行为。
- 查询两条 Git 信息只在构建开始执行一次，开销可忽略。
- 无 Git 元数据时显式输出 null，避免生成伪造的提交 ID。

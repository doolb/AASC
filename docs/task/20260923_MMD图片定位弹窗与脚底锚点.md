# 2026-09-23 MMD 图片定位弹窗与脚底锚点

## 当前结果

页面、离线图片跟踪与 PMX/VRM 脚底屏幕锚点已接入；JavaScript 语法解析和 `git diff --check` 通过。目标 Android 设备视觉位置与跟踪帧率仍待现场验证。

## 任务描述

定位面板的拍照校准改为上层独立弹窗，拍摄和四角编辑共用一个画面位置；开始定位后摄像头置于 MMD 下方，角色脚底对齐识别到的基准图中心。

## Design 需求

- 校准弹窗覆盖定位面板，包含拍摄态和编辑态；关闭时释放临时资源。
- 摄像头背景与透明 MMD 画布同属显示端舞台，按 `cover` 统一坐标。
- 自然图片识别在显示端本地进行，目标丢失时保留最后脚底锚点。
- 停止时清空跟踪状态、恢复角色位置和释放摄像头轨道。

## Spec 设计与代码范围

- 先更新 `docs/spec/mmd-image-ar.md` 的 L4 伪代码，再修改 `display.html`、`display-mmd.css` 和 `display-mmd-ar.js`。
- 新增 `display-mmd-image-tracker.js`，用局部角点、归一化描述子和 RANSAC 单应矩阵返回基准图中心与尺度。
- 新增 `display-mmd-ar-pose.js`，由 `display-mmd.js`、PMX/VRM runtime 共同接入脚底屏幕锚点。
- 更新设计、使用、待办、变更日志及 Offline 发布状态。

## 自测用例

- 弹窗拍摄态与编辑态占用同一预览区域；四角拖动坐标对应原图。
- 目标保存后刷新仍可选择；开始定位后视频在 MMD 画布下方。
- 识别移动中的自然图时脚底跟随中心；短暂丢失不跳回初始位置。
- 切换目标、停止、页面隐藏和权限拒绝时视频轨道正确释放或复用。

## 兼容性、性能与风险

- 兼容支持 Canvas、IndexedDB、getUserMedia 和 WebGL 的浏览器及 Android WebView。
- 识别帧缩至最大宽度 320 像素；以视频帧回调运行，MMD 渲染保持独立。
- 自然图低纹理、反光、旋转和大尺度变化可能降低匹配可靠性；单目屏幕锚点不提供真实深度、遮挡或精确物理尺度。需要在实际 Android 设备验证帧率和视觉位置。

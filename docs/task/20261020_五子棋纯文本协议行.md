# 五子棋纯文本协议行

日期：2026-10-20

## 任务描述与需求

用户要求游戏 MCP 新调用不再使用 `< >`，避免被外部模型或通道当作标签；随后明确旧格式仍须支持解析。新提示、AI 调用、目录/规则查询和 GM 回执改为独立 `Game:` 文本行，使用英文逗号；旧 `<Game:...>` 调用仍按原规则执行，既有业务权限、棋局状态和 `gameTrace` 语义保持一致。

## Design 与 Spec

设计见 `docs/design/game-gomoku.md` 的“无尖括号协议行”；伪代码见 `docs/spec/game-gomoku.md` 开头。新格式命令必须位于回复开头的独立行，普通行内 `Game:` 不触发操作；旧格式保留原解析边界。两种调用都在 UI 和 TTS 中过滤，GM 继续作为权威回执。

## 受影响代码

- `src/apps/server/modules/game/gomoku-game-service.js`：解析、剥离和 GM 回执格式。
- `src/apps/server/modules/game/game-chat-bridge.js`：模型提示、批量调用、流式缓冲、GM 续接和摘要。
- `src/apps/web-mediacenter/ui/public/js/chat.js`、`display-chat.js`：协议摘要回退识别。
- `tests/game-gomoku.test.js`、`tests/display-chat-opening-browser.test.js`、`tests/gomoku-chat-tip-browser.test.js`：新格式及回归断言。
- 五子棋 design/spec、usage、todo、changelog 与服务包状态。

## 自测、兼容与性能

验证目录/规则/开局/落子、GM 回执、双端灰色提示、流式半截前缀不泄漏；正文行内的无尖括号 `Game:` 不执行；非法字段、中文逗号拒绝，旧尖括号单条与多条仍执行。旧历史 `gameTrace` 仍按已有摘要显示。协议解析为本地文本操作，不增加网络请求。

## 风险与预计工时

风险是无包围符时误识别普通文字或流式泄漏半截协议；用回复开头与独立行边界、严格字段校验和流式回归覆盖。预计约 2–3 小时，包含文档、代码与自测。

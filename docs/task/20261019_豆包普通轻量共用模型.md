# 豆包普通与轻量共用实际模型

## 任务描述

豆包快选轻量保存 `doubao`，普通保存 `doubao-think`；两者经 Chat2API 默认映射实际发送 `doubao` 思考 0。专业仍为 `doubao-expert` 思考 3。

## Design 需求与 Spec 设计

- `docs/design/chat-system.md`：普通与轻量保留不同 LLM 模型名；实际目标在同一开发映射文件中指定。
- `docs/spec/chat-system.md`、`docs/spec/chat2api-doubao-web.md`：按当前模型名反查档位；默认映射将 `doubao-think` 指向 `doubao`。

## 受影响模块与代码

- `src/apps/server/modules/chat2api/chat2api-default-model-mappings.js`：三档定义每档只保留一个 LLM 配置模型名；Chat2API 默认映射另行声明请求别名和实际目标。
- `src/apps/server/modules/chat/chat-model-tier-service.js`：读取统一映射，按当前名称反查和回写。
- `src/apps/server/modules/chat2api/chat2api-provider-registry.js`：由默认映射生成豆包内置映射，避免覆盖实际目标。
- `src/apps/server/modules/chat/chat-model-tier-service.test.js`、`src/apps/server/modules/chat2api/chat2api-defaults.test.js`、`tests/chat-model-tier-browser.test.js`：覆盖名称与实际调度。
- `docs/usage/chat-model-tiers.md`、`docs/todo.md`、`changelog.md`：同步说明与验收状态。

## 自测用例与兼容性测试

- 轻量和普通分别选择后，当前 LLM 模型名为 `doubao`、`doubao-think`；Chat2API 实际目标均为 `doubao`。
- 重新选择 Provider 或收到权威配置时，按当前模型名回显档位；专业 `doubao-expert` 和 Qwen 三档保持原目标。
- 使用真实 Provider 注册表和核心调度链测试普通档最终发送 `doubao`；自定义映射仍可覆盖默认目标。
- 运行模型快选服务、双端浏览器和 Chat2API 定向测试。

## 性能测试与风险评估

反查最多遍历固定三档，每次选档仍只保存一次配置。档位名称相互独立，无需凭偏好消歧。改变默认映射只影响未配置自定义覆盖的请求；现有会话续接仍按目标模型兼容性校验。

## 预计工时与结果

预计 0.5 小时。服务、双端浏览器与默认映射定向测试 15/15 通过；服务代码包待出包，真实两端和 Offline APK/ADB 仍待验收。

# 豆包普通与轻量共用模型

## 任务描述

按用户要求，豆包快选的“普通”档与“轻量”档使用同一个 `doubao` 模型名及思考 0 请求；“专业”继续使用 `doubao-expert`。

## Design 需求与 Spec 设计

- `docs/design/chat-system.md`：两个档位共用模型名时，当前普通 LLM profile.model 仍是 Provider 和可调用模型的权威来源，已保存的豆包档位偏好负责区分按钮选中状态。
- `docs/spec/chat-system.md`：保存时两档均写 `doubao`；读取同名模型时优先使用 `tiersByProvider.doubaochat`，缺省轻量；直接手工配置旧 `doubao-think` 时沿用原调用，不由快选接管。

## 受影响模块与代码

- `src/apps/server/modules/chat/chat-model-tier-service.js`：调整开发维护的豆包映射和同名反查。
- `src/apps/server/modules/chat/chat-model-tier-service.test.js`：覆盖同名双档保存、请求和回显，以及旧模型名不被快选接管。
- `docs/usage/chat-model-tiers.md`：更新档位表和同名回显说明。
- `docs/todo.md`、`changelog.md`：记录已完成源码与仍待设备验收事项。

## 自测用例与兼容性测试

- 轻量和普通分别选择后，当前 LLM 模型名均为 `doubao`，请求模型均为 `doubao`，选中按钮随档位偏好变化。
- 重新选择 Provider 或收到权威配置时使用保存的偏好；没有偏好时同名模型显示轻量。
- 手工 `doubao-think` 不误识别成新普通档；专业 `doubao-expert` 和 Qwen 三档保持原映射。
- 运行模型快选服务和双端浏览器定向测试；浏览器用例核对两端同为 `doubao` 时“普通”按钮选中；旧 Chat2API 别名适配测试仍覆盖模式 1。

## 性能测试与风险评估

反查最多遍历固定三档，每次选档仍只保存一次配置。两个档位共享模型名，配置文件单独无法区分上次选择，因此必须随当前模型读取已保存偏好；旧数据无偏好时采用轻量。

## 预计工时与结果

预计 0.5 小时。服务与双端浏览器定向测试 8/8 通过，服务代码包待出包；真实两端和 Offline APK/ADB 仍待验收。

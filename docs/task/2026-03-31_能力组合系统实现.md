## Design 需求

参考：[docs/design/aasc.md](../design/aasc.md) 第12章

### 核心概念

1. **原子能力（Atomic Capability）**
   - 最小功能单元，不可再分
   - 包含：输入输出模式、默认执行者、超时、重试策略

2. **能力与执行者解耦（重要）**
   - 能力是独立定义的功能单元，不绑定到特定执行者
   - **一个能力可以被多个执行者共享使用**
   - 执行者通过能力ID引用能力，声明自己拥有哪些能力
   - 能力的执行由具备该能力的执行者来完成

3. **能力组合（Capability Composition）**
   - 定义多个能力如何协同工作
   - 包含：触发条件、执行管道、降级管道

4. **能力管道（Pipeline）**
   - 顺序执行或并行执行
   - 支持条件执行和错误处理

5. **能力等级评估**
   - 综合等级计算
   - 分类得分、组合得分

## 自测用例

### 1. 能力注册测试

```javascript
const { CapabilityRegistry, CapabilityBuilder } = require('./aasc');

const registry = new CapabilityRegistry();

const timeParser = new CapabilityBuilder()
  .withId('time-parser')
  .withName('时间解析')
  .withCategory('basic')
  .withLevel(2)
  .withDescription('解析自然语言时间表达式')
  .build();

registry.register(timeParser);

assert(registry.get('time-parser') !== null);
assert(registry.get('time-parser').level === 2);
```

### 2. 能力组合测试

```javascript
const { PipelineExecutor, CapabilityComposition } = require('./aasc');

const composition = {
  id: 'time-announce',
  name: '报时功能',
  pipeline: [
    { capabilityId: 'time-parser', inputMapping: { static: { expression: '现在' } } },
    { capabilityId: 'voice-broadcast', inputMapping: { fromContext: ['parsedTime.formatted'] } }
  ]
};

const executor = new PipelineExecutor(registry, bus);
const result = await executor.execute(composition, {});

assert(result.success === true);
assert(result.steps.length === 2);
```

### 3. 能力等级计算测试

```javascript
const { CapabilityLevelCalculator } = require('./aasc');

const calculator = new CapabilityLevelCalculator();
const score = calculator.calculateActorLevel(actor);

assert(score.overallLevel >= 1 && score.overallLevel <= 5);
assert(score.maxLevel >= 1);
```

# MMD AR 电脑模拟视角滑条

- 日期：2026-09-26
- 需求：电脑上的模拟摄像头不用随机拖动四个角点，改为上方缩放、右侧纬度、下方经度三个滑条，拖动图片平移，保留重置。
- 范围：仅独立 MMD AR HTTPS 测试网页；正式显示端和旧测试 APK 不加入模拟视角控件。

## Design 需求

图片是一张固定的平面。视角由经度、纬度、缩放和二维平移组成；同一平面的四角通过固定焦距透视投影得到，不能各自自由移动。滑条位置与语义固定，拖动预览只平移；重置回到正面、100% 缩放和居中。拍照后的蓝色矩形框选仍是独立流程。

## Spec 伪代码

见 `docs/spec/mmd-ar-test-apk.md` 的“无实体摄像头的透视模拟输入”。本地图片 → 图片宽高比 → 平面局部四角 → 经度/纬度旋转 → 固定焦距投影 → 缩放/平移 → 逆单应纹理映射 → 960×540 模拟视频流。

## 自测、兼容、性能与风险

1. 默认视角保持按原图比例居中；经度/纬度分别让两侧/上下产生合理近远差，缩放不改变角度，图片拖动不改变旋转。
2. 控件布局应为上、右、下，重置值回 100%／0°／0°／居中；无效/退化视角拒绝并保留上一帧。
3. 现有 WebGL 模拟流、拍照校准、IndexedDB 保存与 MindAR 官方目标识别继续可用；不请求实体摄像头。
4. 只在姿态变化时重算四角和单应矩阵，视频逐帧继续复用同一矩阵；额外计算不进入每帧识别路径。
5. 风险：网页真实宽度较窄时右侧竖滑条可能压缩预览；自动布局回归外仍需桌面手动查看。模拟首锁不代替真机识别。
- 预计工时：约 2 小时。

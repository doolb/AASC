# PMX 中心旋转物理同步

## 任务描述

修复显示端 PMX 角色在空白区域拖动后，中心旋转枢轴已转而 Ammo/Bullet 动态刚体仍使用旧世界坐标，导致裙摆、头发等布料约束失稳的问题。

## Design 需求

- 仅处理已启用 `MMDPhysics` 的 PMX；无物理 PMX 和 VRM SpringBone 不改变。
- 每次物理解算前都必须经过同一 PMX 枢轴同步入口；只有实际发生 yaw 或 pitch 枢轴变更时才变换 Bullet 刚体。
- 同步入口必须递归刷新中心枢轴及子骨骼矩阵，并以本帧与上一物理帧枢轴世界矩阵的增量变换所有刚体。
- 同步刚体的位置、姿态、线速度和角速度，保持布料惯性与关节相对关系；不得在缓动期间清零速度、角速度或外力。
- 旋转停止后继续沿用已有的 `MMDAnimationHelper.update(delta)`，不修改 PMX 刚体、关节、重力、风、阻尼和模型资源。

## Spec 设计

```text
过程 synchronizePmxPhysicsWithPivot(helper, mesh, pivot, previousPivotMatrix)
  physics = helper.objects.get(mesh).physics
  pivot.updateWorldMatrix(true, true)
  deltaMatrix = pivot.matrixWorld × inverse(previousPivotMatrix)
  physics 不存在或 deltaMatrix 是单位矩阵时保存当前矩阵并返回 false
  对 physics.bodies 的每个 body
    位置/姿态 = deltaMatrix × 原刚体变换
    线速度/角速度 = deltaMatrix 的旋转部分 × 原速度
    同时写入 body 与 MotionState，并唤醒 body
  保存当前矩阵并返回 true

过程 renderMmdFrame(delta)
  更新中心枢轴缓动
  每帧调用 synchronizePmxPhysicsWithPivot(helper, mesh, pivot, previousPivotMatrix)
  helper.update(delta)
  渲染场景
```

## 自测用例

1. 物理 helper 在中心枢轴旋转后先刷新完整世界矩阵，再将同一增量施加到刚体变换与线/角速度。
2. 枢轴未变或没有 physics 时不同步 Bullet 刚体，正常物理解算不受影响。
3. 渲染循环每帧在 `helper.update(delta)` 前接入统一同步步骤。
4. 既有 PMX/Ammo、聊天 MMD 和布局测试继续通过。

## 兼容性、性能与风险

- 兼容性：使用 Three.js r160 已内置 Ammo `btRigidBody` 和 `MMDPhysics` 的刚体/内存池接口；无 physics 的模型走空操作，VRM 不受影响。
- 性能：每个渲染帧仅比较一次枢轴矩阵；枢轴变化时按刚体数量分配并复用 MMDPhysics 的临时对象池，不新增渲染循环、WASM 实例或预热步进。
- 风险：同步中必须同时更新刚体、MotionState 和两类速度，漏掉任一项会重新引入约束错位或惯性方向错误；回归测试覆盖 90° 旋转的位置、姿态和速度结果。

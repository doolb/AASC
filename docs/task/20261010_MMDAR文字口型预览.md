# MMD-AR文字口型预览

## 需求、设计与实现

用户要求动作面板新增口型分类、文本输入与播放。默认按无声文本预览实施，设计 `docs/design/mmd-ar-lipsync.md`，实现前伪代码 `docs/spec/mmd-ar-lipsync.md`。精确TTS时间/音素不在此轮；保持此前正式表情/MPL迁移未提交改动。

## 执行

- 文档伪代码先行，加入独立面板分类、口型时间线与UI模块。
- 固定本地pinyin-pro资源和许可证/来源/校验，按需加载。
- 独立构建副本新增临时表情层，恢复原动画与手动表情，避免覆盖正式src。
- web-dist重建、源/产物语法与指纹静态检查，同步usage/todo/changelog。

## 人工验收、兼容性、性能

米娅不同元音、中文标点/多音字/数字、仅空白/超长输入、缺失嘴型手工映射、手动表情和MPL/VMD恢复、模型异步切换、暂停/后台/连续点击、桌面和Android。只在播放期间逐帧计算少量Morph，本轮不新增或运行测试。

## 风险与预计工时

预计1–2小时。无真实声音/音素时间，节奏估算和英语拼写元音不能保证发音准确；PMX嘴型支持范围沿用现有Three加载器，映射可手工调整。首次下载固定构建资源需要网络，运行页面只取本地同源文件。

## 完成结果

用户进一步确认「口型应该可以和动作同时播放」，本轮通过独立临时Morph层满足，原有VMD/MPL继续运行，停止只释放口型。文本/播放/停止、默认/手动映射、固定拼音资源、平滑开合/标点停顿和模型/异步/后台保护已实现。

# 六轴IMU原生APK固定房间转发

## 任务状态

实现完成，debug APK已构建；待Android真机连接、采样与断线行为验收。用户已确认独立轻量APK、电脑本地测试服务、固定房间`AASCIMU1`、六轴传感器、可读取服务器状态用于调试，并确认APK默认服务器地址包含`192.168.1.39`。

## 任务描述

新增Android原生六轴采集APK，将陀螺仪与加速度计原始样本回传现有六轴IMU测试服务器。电脑网页可接收该房间样本并通过既有估计器观察旋转和短时位移。服务提供loopback限定的状态和最近样本读取接口。APK地址预填`192.168.1.39:8769`，允许修改主机地址。

## Design需求

- 复用独立测试服务，不新增生产显示端或Offline APK能力。
- 固定房间为`AASCIMU1`；桌面观察端可先加入创建房间，固定房间最多一个在线sensor。
- APK通过SensorManager采集TYPE_GYROSCOPE和TYPE_ACCELEROMETER，使用自然设备轴、rad/s、m/s²（含重力），仅前台采集。
- 原始样本进入桌面ImuEngine；服务端不代替客户端做惯性积分。
- `/api/imu/status`与`/api/imu/samples`仅对本机loopback开放，样本只在内存保留。
- 调试APK输出`3rd/imu-six-axis-test/android-sender/output/aasc-imu-sender.apk`，不提交APK、不更新Offline状态。

## Spec设计

伪代码先更新于`docs/spec/imu-six-axis-test.md`。服务端规范化样本后按固定房间广播；消息使用room.join/imu.sample/sensor.sample，绑定设备id、代次和递增序号。桌面切换至“手机APK回传”后作为viewer只接收样本。调试样本环形缓冲最多500条，接口单次最多120条。

## 受影响功能模块和代码

- `3rd/imu-six-axis-test/server.mjs`：固定房间、原始样本转发、状态和样本API。
- `3rd/imu-six-axis-test/imu-room.mjs`、`app.mjs`、`index.html`：接收协议、桌面viewer模式。
- `3rd/imu-six-axis-test/android-sender/`：新建独立Android项目、WebView本地页和原生传感器桥。
- `scripts/ops/build-imu-sender-apk.js`、`package.json`、`.gitignore`：APK构建入口及产物忽略。
- `docs/design/imu-six-axis-test.md`、`docs/spec/imu-six-axis-test.md`、`docs/usage/imu-six-axis-test.md`、`3rd/imu-six-axis-test/README.md`、索引、todo与changelog。

## 自测与验收用例

1. 运行`npm run start:imu:six-axis-test`，桌面模式选择“手机APK回传”，确认房间固定为AASCIMU1。
2. APK首次启动地址为192.168.1.39、端口8769、房间AASCIMU1；改变主机地址可连接另一台电脑。
3. APK连接后服务端status显示设备在线；开始采集后samples返回有限且递增的时间/序号及三轴值，停止后计数不再增加。
4. 桌面页显示APK设备，实时原始角速度/加速度和估计姿态更新；断开或后台后停止接收并冻结估计位置。
5. 非loopback调用调试接口返回403，状态/样本接口不写文件且无CORS。
6. APK传感器缺失、连接失败、房间已被占用时显示可理解状态。

本轮执行构建APK和静态差异检查；不运行专用测试套件。APK真机安装及传感器现场验收需连接Android设备后完成。

## 兼容性测试

- Android 6.0/API 23及以上WebView和SensorManager；无Google服务依赖。
- 服务桌面运行在Node.js项目现有版本，保留模拟器、浏览器手机与随机房间模式。
- Android设备不要求HTTPS，因为采样来自原生SensorManager，局域网服务默认使用ws://。

## 性能测试

- 采集发送频率限制约50Hz，WebSocket消息小于16KiB，服务端调试环形缓冲最多500条。
- 观察端本地估计，不让服务器为每个设备执行积分；面板按现有低频刷新。
- 不在APK后台持续采样，Activity暂停时释放传感器监听。

## 风险评估

- 纯六轴推算位置存在显著漂移，短时位移用于调试，不作为绝对定位精度承诺。
- 不同厂商传感器时间戳、采样率及偏置不同，需现场检查实际数据。
- loopback调试接口只保护服务主机本地访问；服务器所有者仍可读取测试样本。
- 原生APK为debug签名测试构建，不进入正式发布渠道。

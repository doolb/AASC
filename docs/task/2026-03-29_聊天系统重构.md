# 聊天系统重构任务

## 任务描述

重构现有的聊天系统，支持群聊和私聊模式，统一管理所有角色的聊天记录，整合语音播报和搜索功能。

## Design 需求

详见 [design/chat-system.md](../design/chat-system.md)

### 核心需求

1. **聊天模式**
   - 群聊模式：所有消息广播，系统和AI助手根据规则响应
   - 私聊模式：只与指定AI助手通信

2. **角色系统**
   - 系统：系统消息、指令响应
   - AI助手：各个AI聊天助手
   - 显示端：显示端语音输入
   - 控制端：控制端语音/文本输入

3. **消息格式**
   - `角色: 消息内容`
   - 系统消息：`系统: 消息`
   - AI助手消息：`{助手名字}: 消息`
   - 显示端消息：`{显示端名字, IP}: 消息`
   - 控制端消息：`{控制端名字, IP}: 消息`

4. **系统指令**
   - `系统帮助`：查看系统指令帮助
   - `私聊{助手名字}`：进入私聊模式
   - `退出私聊`：退出私聊模式
   - 自定义指令组合

5. **语音播报增强**
   - 显示端播报（默认）
   - 控制端播报（无显示端或勾选时）
   - 显示端播报时同时显示文本

6. **搜索功能整合**
   - 移除独立搜索页面
   - 搜索功能整合到聊天系统

7. **聊天记录存储**
   - 所有聊天记录保存到文件
   - 支持按角色、时间查询

## Spec 设计

### 数据结构

```javascript
// 聊天记录
{
  id: string,
  timestamp: number,
  role: 'system' | 'assistant' | 'display' | 'control',
  name: string,
  ip: string,
  content: string,
  mode: 'group' | 'private',
  target: string,
  displayId: string
}

// 会话状态
{
  mode: 'group' | 'private',
  privateTarget: string,
  playOnControl: boolean,
  commands: {}
}

// AI助手配置
{
  defaultName: string,
  assistants: [{
    id: string,
    name: string,
    template: string,
    enabled: boolean
  }]
}
```

### API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/chat/history | GET | 获取聊天历史 |
| /api/chat/session | GET/POST | 获取/设置会话状态 |
| /api/chat/commands | GET/POST | 获取/设置自定义指令 |
| /api/chat/assistants | GET/POST | 获取/设置AI助手配置 |

### WebSocket 消息

| 类型 | 方向 | 说明 |
|------|------|------|
| chatMessage | 双向 | 聊天消息 |
| chatMode | 双向 | 切换聊天模式 |
| systemCommand | 控制端->服务端 | 系统指令 |
| playOnControl | 控制端->服务端 | 控制端播放语音 |

## 实现步骤

### 阶段一：数据结构和存储

1. 定义新的聊天记录数据结构
2. 更新 chat.js 核心模块
3. 创建会话状态管理
4. 实现数据迁移（兼容旧数据）

### 阶段二：群聊/私聊模式

1. 实现模式切换逻辑
2. 更新前端UI显示当前模式
3. 实现私聊消息路由
4. 更新WebSocket消息处理

### 阶段三：系统指令

1. 实现内置指令处理
2. 实现自定义指令配置
3. 实现指令组合执行
4. 添加指令帮助显示

### 阶段四：语音播报增强

1. 实现控制端语音播放
2. 添加播放位置选择UI
3. 实现显示端文本同步显示
4. 处理无显示端情况

### 阶段五：搜索功能整合

1. 将搜索功能整合到聊天
2. 移除独立搜索页面
3. 更新侧边栏导航
4. 清理无用代码

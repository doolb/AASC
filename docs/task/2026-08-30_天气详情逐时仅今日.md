# 天气详情逐时仅今日

## 任务描述

天气详情弹窗保留当前天气、未来约 3 天的逐日预报和天文信息，但逐时天气只展示接口返回的今日数据，未来日期不在详情文本中展开逐时明细。

## Design 需求

- `formatWeatherDetail()` 继续输出当前天气和全部逐日汇总。
- 仅第一天预报视为接口返回的今日，保留其逐时天气。
- 未来日期保留日汇总和天文信息，逐时部分显示为无逐时数据。
- `normalizeWeatherData()` 保留结构化天气对象中的完整逐时数组，兼容其他调用方。

## Spec 设计

```text
formatWeatherDetail(weather):
    遍历 weather.forecast，并记录当前日期索引
    当前日期索引为 0:
        拼接该日逐时天气明细
    当前日期索引大于 0:
        只拼接逐日汇总和天文信息
        不拼接该日 hourly 数组
```

## 受影响的功能模块和代码

- `src/apps/web-mediacenter/modules/voice/voice-command-app-service.js`：天气详情文本按日期筛选逐时内容。
- `tests/weather-command.test.js`：验证今日逐时保留、未来逐时不显示。
- `docs/spec/voiceCommand.md`：同步天气详情输出伪代码。
- `docs/design/display-control-refactor.md`、`docs/design/display-voice-conversation.md`：同步天气详情展示口径。

## 自测用例

- 天气归一化仍保留 3 天结构化逐时数据。
- 天气详情包含今日 `00:00` 逐时数据。
- 天气详情不包含未来日期的 `03:00` 逐时数据。
- 天气语音摘要继续不包含逐时数据。

## 兼容性测试

- 缺失 `hourly`、缺失天气字段和旧天气响应仍能生成详情文本。
- 旧客户端继续使用 `text` 字段，不受详情筛选影响。

## 性能测试

- 仅减少详情文本拼接内容，不增加 API 请求和归一化遍历复杂度。

## 风险评估

- 风险低：结构化 `weather.forecast[*].hourly` 不删除，只调整 `detailText` 的展示范围。

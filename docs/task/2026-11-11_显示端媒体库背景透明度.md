# 显示端媒体库背景透明度

- 任务描述：媒体库顶端增加背景透明度滑块，本机保存。
- design：0% 不透明、100% 透明；文字、按钮及图片清晰。
- spec：滑动实时计算背景 alpha 并存储，重开恢复；无有效值沿用原背景。
- 影响：显示端媒体库 HTML、CSS、JS、自测及文档。
- 自测：范围两端、即时更新、重开恢复、非法存储和文字不透明。
- 兼容性：移动窄屏与主题下布局可用；Android 真机待验收。
- 性能：仅 input 时修改一个 CSS 变量，不增加计时器。
- 风险：极透明背景可能降低对比度，用户可随时调整。
- 预计工时：1 小时。
- 验证结果：浏览器覆盖透明度两端、文字清晰、重开恢复及无效值回退；定向 35 项通过，Android 实机待验收。

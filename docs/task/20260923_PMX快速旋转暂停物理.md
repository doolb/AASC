# PMX 快速旋转暂停物理

## 任务描述

MMD 模型快速旋转时，运动学锚点移动快于动态布料刚体跟随，可能出现穿模。在显示端灯光面板增加可调速度阈值，超过阈值时仅暂停 PMX 物理更新。

## Design 需求

- 以模型中心枢轴实际 yaw/pitch 角位移计算每帧角速度，单位为度/秒。
- 阈值默认 180 度/秒，可在灯光面板调节并沿用现有 localStorage 保存。
- 快速旋转期间 VMD、IK、grant、渲染继续运行；减速后同步刚体到当前姿态并恢复物理。
- VRM 不受影响，不新增网络配置接口。

## Spec 设计

见 `docs/spec/mmd-pmx-vmd-local.md` 中 `rotationPhysicsLimit`、`renderMmdFrame` 的伪代码。阈值范围为 30–720 度/秒，步长 10；从暂停恢复时在物理关闭的帧完成动画和刚体重置，下一帧恢复模拟。

## 受影响模块和代码

- `src/apps/web-mediacenter/ui/public/js/mmd-pmx-helper.mjs`：帧更新与物理暂停、恢复状态。
- `src/apps/web-mediacenter/ui/public/js/display-pmx-runtime.js`：实际旋转速度与当前 PMX 配置。
- `src/apps/web-mediacenter/ui/public/js/display-mmd.js`、`display-mmd-lighting.js`、`display.html`：阈值规范化、面板设置和保存。
- `tests/mmd-pmx-helper.test.js`、灯光设置相关测试：行为回归。

## 自测用例

- 低于阈值时每帧正常物理更新，超过阈值时仅暂停物理而动画继续。
- 恰好达到阈值仍更新物理；零时长帧不误判。
- 从暂停恢复时刚体重置、旧速度和外力清除；下一帧重新模拟。
- 面板滑块保存、刷新恢复、预设保留、恢复默认，以及非法旧值回退。

## 兼容性测试

- 无物理 PMX 和 VRM 路径行为保持原状。
- 旧 localStorage 没有新字段时使用 180 度/秒。

## 性能测试

- 角速度计算仅在现有逐帧更新中增加常量时间运算；快速旋转时减少 Ammo 步进。
- 定向测试后运行 `npm test`，记录与本次无关的既有失败。

## 风险评估

- 恢复物理时布料可能有一次可见的姿态重置，需现场用真实 PMX 和 Android 显示端观察。
- 180 度/秒为初始经验值，保留面板调节能力供现场校准。

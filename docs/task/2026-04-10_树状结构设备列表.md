# 2026-04-10_树状结构设备列表

## 任务描述

将控制端的显示端列表从平铺列表改为树状结构，支持设备分组、设置展开/收起、设备连线/掉线自定义指令配置。

## ✅ 已完成 [2026-04-10][2026-04-10]

## Design 需求

- 树状结构设备列表：以服务器为根节点，设备为子节点，设备设置为叶节点
- 可以在控制端查看和修改设置
- 设置列表可以展开和收起，显示或隐藏子项
- 可以设置设备连线和掉线时，服务器自定义指令，并且需要保存到配置文件中

## Spec 设计

- 后端：config.js 添加 deviceEvents 配置管理，server.js 添加 API 端点和连线/掉线指令执行
- 前端：新建 device-tree.js 树状组件，修改 upload.html 和 upload.css

## 自测用例

1. 显示端连接后，设备树正确显示服务器和设备节点
2. 点击设备节点可以展开/收起子项
3. 展开"画面设置"可以查看和修改旋转、填充、音量等设置
4. 展开"事件指令"可以设置连线/掉线指令
5. 设置连线指令"早上好"后，显示端重新连接时服务器执行该指令
6. 设置掉线指令"晚安"后，显示端断开时服务器执行该指令
7. 事件指令保存到 config.json，服务器重启后保留
8. 多个显示端同时连接时，设备树正确显示所有设备
9. 子显示端在设备树中有特殊标识
10. 选中设备后，控制面板的其他功能（裁剪、播放等）正常工作

## 兼容性测试

- 与现有 DisplayList 模块兼容，选中设备时同步更新 currentDisplayId
- 与现有 Controls、Crop 模块兼容
- 与 AASC 系统兼容，连线/掉线事件通过 voiceCommand 执行

## 性能测试

- 设备树渲染不应影响 WebSocket 消息处理速度
- 展开/收起操作应即时响应
- 大量设备（10+）时树渲染不应有明显延迟

## 风险评估

- 低风险：前端树组件为新增模块，不影响现有功能
- 中风险：连线/掉线指令执行依赖 voiceCommand，需确保异步执行不阻塞连接处理
- 低风险：配置持久化使用现有 DataSnapshot 机制，稳定可靠

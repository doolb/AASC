# 加速度镜头与加快回中

需求：镜头平移不受角速度数据影响，回中更快；保留十倍幅度和角色旋转。
设计：以含重力加速度低通基线估计短时变化，不依赖陀螺仪；回中系数从 2.5 提高为 5。详见壁纸控件 design。
实现：见壁纸控件 spec；无效样本忽略，长间隔重置基线，保留屏幕轴变换和限幅。
影响：网页镜头运动估计、壁纸控件与内置自测。
自测：静止、四向平移、角速度不变性、数据缺失、采样间隔、基线收敛及回中；壁纸与普通页回归。
兼容：无需陀螺仪或平台线性加速度；旧 APK 可使用服务代码更新。
性能：每次事件常数次运算。
风险：单加速度不能彻底区分旋转和位移，快速旋转会造成短时误移动；用户需真机验收。
预计工时：1 小时。

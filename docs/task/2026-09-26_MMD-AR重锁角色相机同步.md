# MMD AR 重锁角色相机同步

- 日期：2026-09-26
- 任务：修复测试网页中蓝色定位框已贴图而角色相机偶尔停在旧视角的同步缺口。
- 设计：MindAR 蓝框与 PMX 分属两个渲染器；`targetUpdate` 即时同步，锚点可见期间按帧核对最后成功采纳的位姿和 PMX 活跃状态；失败后重试，停止时清理。
- 实现：先更新 `docs/spec/mmd-ar-test-apk.md` 伪代码，再修改 `3rd/mmd-ar-test/display-mmd-ar-aframe.js`；`display-mmd.js` 与 `display-pmx-runtime.js` 只新增轻量 active/trackingLost 状态读取，不改变原有距离、死区、缓动和失锁冻结语义。
- 影响模块：仅 HTTPS MMD AR 测试网页；正式显示端和旧测试 APK 不受此适配器影响。
- 自测：`npm run build:web:mmd-ar-test`；MindAR 蓝框首锁、失锁、无后续 `targetUpdate` 的重锁补偿；PMX 相机失锁后恢复及角色脚底中心投影对齐。
- 兼容性：不改变定位图、localStorage 设置和模型资源格式。
- 性能：每显示帧比较 16 元素锚点矩阵与投影矩阵；仅变化或未同步时提交 PMX 位姿。停止定位时取消帧循环。
- 风险：真实手机持续识别时仍可能受摄像头抖动或用户设置的缓动时间影响；需要现场观察蓝框与角色的重锁效果。
- 预计工时：约 1 小时。

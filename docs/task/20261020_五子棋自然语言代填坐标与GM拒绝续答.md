# 五子棋自然语言代填坐标与 GM 拒绝续答

日期：2026-10-20

## 任务描述

用户说“我下最中间的那个位置”，AI 把 15 路中心填为 H8 后，GM 因用户原话没有逐字出现 H8 而拒绝。随后 AI 根据错误生成的道歉未进入聊天，界面改显示固定的“棋盘未变化”提示。

## Design 需求与 Spec 设计

见 `docs/design/game-gomoku.md` 与 `docs/spec/game-gomoku.md`。`GameUser` 坐标由 AI 按自然语言代填；GM 只校验棋局权威条件。失败调用所在回复的叙述丢弃，GM 错误后的新回复若没有声称未确认棋步成功则进入聊天和朗读；空回复或虚假成功宣称继续使用权威提示。

## 受影响模块与代码

- `gomoku-game-service.js`：移除用户原话与协议坐标逐字一致的限制，保留轮次、范围、占位和版本校验。
- `game-chat-bridge.js`：GM 拒绝后的新自然语言优先作为最终回复。
- `tests/game-gomoku.test.js`、`tests/game-chat-session.test.js`：覆盖中心代填、错误后自然语言、虚假成功宣称及非法调用。
- 同步五子棋 design/spec/usage、todo、changelog 和 Offline 服务包状态。

## 自测用例、兼容性测试与性能测试

运行 `npm run test:game-chat`。核对 15 路中心 H8 经 GM 确认后棋局继续，越界、轮次和被占位置继续拒绝；失败回复里的预写成功说法不展示，模型收到 GM 错误后的道歉可显示和朗读。没有新增网络往返和持久化字段。

## 风险评估与预计工时

AI 对含糊的用户话意可能猜错坐标，GM 无法判定用户真实意图；界面仍有 GM 落子提示与棋盘供核对。虚假成功叙述采用保守的文字模式识别，遇到复杂说法可能回退权威提示。预计约一小时。

## 验收和边界

模拟的Android结果→正式JS→保存接口→公开账号列表可见；失败保留登录session，取消和错会话不提交。列表校验只拉一项且不取消息，正常/空数组、登录失效、风控、超时、重定向、超大/HTML/异常结构均有确定结果。验证失败不再次阻断添加；复验过程中换凭据或删除账号不串旧结果。只验证会话列表访问，不宣称普通LLM/TTS可用或身份已实名验证。

优先npm run check:chat2api；针对UI浏览器及新增本地HTTP用node --test（无专用script）；三项Windows chmod既有失败需区分。性能固定15秒/512KiB，不循环/翻页/自动重试。预计半天至一天量级，真实接口语义或平台差异可能需独立验收。

不把本次任务理解为授权工具读取用户浏览器凭据或进行真实会话列表验收。若需要一次真实只读验证，将先给出具体范围再请求授权；其内容只留内存，禁止打印/保存Cookie、会话标题和正文。此前聊天/合成额度授权不复用。当前公开资源和诊断均在.git临时目录，不进入Git或生产运行。

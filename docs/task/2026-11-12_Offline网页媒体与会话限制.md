# Offline 网页媒体与会话限制

- 需求：Android Offline 像豆包网页一样运行独立 WebView 并可查看，浏览器媒体会话数可配，默认 1，上限 4；衔接抖音精选推荐试播。
- 设计：见 `docs/design/browser-media-service.md` 和 `docs/design/media-library.md`；保留站点权限、同源与任务生命周期。
- 伪代码：见 `docs/spec/browser-media-service.md`、`docs/spec/media-library.md`；本机令牌桥接，超限拒绝，用户可前台完成验证。
- 影响：Android 独立 WebView 服务/Activity、Node 启动桥、网页媒体平台适配器和任务、抖音来源、显示端列表、自测与发布状态。
- 自测：会话上限、身份与同源限制、连接终止、代理错误、查看/关闭与重启、抖音推荐解析；Android 编译与真机。
- 兼容：Linux Vivaldi 继续支持；Android 不支持逐会话代理时明确提示；多 WebView 共用该进程 Cookie 存储。
- 性能：按需创建 WebView，最多 4 个，默认 1；停止任务释放资源。
- 风险：抖音风控与登录、Android 厂商 WebView、后台限制及可播放地址依赖真实设备与上游。
- 预计工时：2–3 天。

- 实施状态：抖音来源可自动启动网页媒体、读取精选卡片并获取视频地址；桌面真实站点读取推荐及 Range 通过。Android 真机验收须使用包含新原生服务的 APK、新版服务包及任务代码包。

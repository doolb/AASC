# 显示端界面优化

- 任务：优化快捷控制、聊天、媒体库、外观/音色/MMD 设置和壁纸控制的视觉与横竖屏布局。
- 设计：参见 `docs/design/display-ui.md`，播放区域与交互层级保持原有行为。
- 实现：遵循 `docs/spec/display-ui.md`，以独立样式覆盖现有组件，复用主题与透明度变量。
- 影响：`display.html`、显示端样式、设计与实现文档、浏览器测试；无消息或配置变更。
- 自测：Chromium 覆盖横竖屏、窄屏、主题、来源导航、快捷面板、聊天和透明度；回归媒体库、聊天与壁纸。
- 兼容性：原控件事件、隐藏状态、安全区域、旋转、输入键盘避让与 Android WebView。
- 性能：样式重排随尺寸变化发生，无额外网络或运行循环。
- 风险：真实设备触摸、壁纸和键盘需实机验收；透明背景下内容可读性依赖背景画面。
- 预计工时：约 3 小时；未明确事项：无。
